The biggest correction

기능을 더하기보다,
다시 읽게 하는 이유를 좁혔습니다.

처음 book tracking

  • 책장과 마지막 페이지 기록이 중심이었습니다.
  • 진도 관리는 필요하지만 이미 익숙한 기능입니다.
  • 기록을 다시 볼 이유가 약했습니다.

지금 reading return

  • 잊었던 문장을 다시 보여줍니다.
  • 문장의 출처 책을 바로 꺼내 펼칩니다.
  • 새 독서 세션이 끝날 때 페이지 증가를 확인합니다.

저장량이 아니라, 문장이 실제 독서를 다시 시작하게 했는지를 봅니다.

What must be true

클릭보다 중요한 건,
실제로 더 읽었는가입니다.

Phase 0 5명 프로토타입

  • 최소 3명이 안내 없이 실제 문장을 입력합니다.
  • 최소 3명이 다시 본 문장의 출처 책을 엽니다.
  • 하나라도 실패하면 구현보다 흐름을 먼저 고칩니다.

2주 사용 행동 검증

  • 문장을 저장한 사용자 중 3명이 출처 책을 다시 엽니다.
  • 그중 2명이 독서를 끝내고 더 높은 페이지를 남깁니다.
  • 인터뷰에서 문장이 독서 재개의 이유였는지 확인합니다.

“이어서 읽기” 클릭은 중간 지표일 뿐, 독서 완료 기록을 행동의 증거로 봅니다.
