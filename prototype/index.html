Portfolio Writer Agent

포트폴리오에 붙일 수 있는 기획 초안 생성

게임 콘셉트

플레이어는 붕괴된 마법 도서관을 탐험하며 위험한 방을 선택하고, 전투 보상으로 덱을 성장시키는 로그라이크 덱빌딩 RPG를 경험합니다.

기획 의도

매 전투 이후 주어지는 보상 선택이 다음 경로의 위험도와 전투 전략을 바꾸도록 설계해, 짧은 반복 안에서도 의미 있는 선택을 느끼게 합니다.

주요 시스템

  • 경로 선택: 안전한 방, 위험한 방, 희귀 보상 방 중 하나를 선택
  • 덱 성장: 카드, 유물, 일회성 주문으로 다음 전투의 전략 변화
  • 위험 누적: 강한 보상을 고를수록 다음 전투에 추가 조건 발생

Critic Agent

루프의 약점과 개선 방향 피드백

강점

보상 선택이 다음 전투와 경로 선택에 영향을 주기 때문에 반복 동기가 분명합니다.

주의점

위험 선택이 항상 정답처럼 느껴지면 전략이 단조로워질 수 있습니다.

개선 제안

안전한 선택에도 장기 성장 보너스를 넣어, 위험과 안정 사이의 판단을 더 어렵게 만듭니다.

프로토타입 결론

Core Loop Builder의 핵심은 결과 문서가 아니라, 입력된 아이디어를 반복 가능한 플레이 구조로 바꾸는 사고 과정을 보여주는 것입니다.
