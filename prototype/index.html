분석하고 싶은 프로젝트의 Git Repository 주소를 입력해보세요.

대상 프로젝트 경험을 쌓는 대학생 개발자
문제 프로젝트 종료 후 역할과 핵심 구현 내용을 잊어버림
해결 저장소를 분석해 참여자와 작업 흐름 확인
형태 GitHub Repository 기반 AI Agent
01 Core Features

핵심 기능

  • Repository 입력 GitHub Repository URL을 입력합니다.
  • 참여자 분석 contributors API 기준 참여자와 기여도를 확인합니다.
  • 작업 내용 정리 최근 commit message를 바탕으로 주요 작업 단서를 보여줍니다.
02 Problem

문제 정의

대학생들은 동아리, 해커톤, 부트캠프, 개인 프로젝트를 통해 많은 결과물을 만듭니다. 하지만 프로젝트가 끝나고 시간이 지나면 내가 맡은 역할, 핵심 구현, 기술적 고민, 문제 해결 과정이 흐려집니다.

03 Solution

해결 방안

사용자가 GitHub Repository를 입력하면 PtoP가 참여자, 기여도, 최근 커밋 흐름을 정리합니다. 사용자는 이 결과를 바탕으로 프로젝트 경험을 다시 복기할 수 있습니다.

04 Next

추가 핵심 기능 고려사항

  • PR/Issue 분석 논의, 리뷰, 해결한 문제를 경험 자료로 정리합니다.
  • 회고 초안 생성 작업 단서를 바탕으로 회고 문장 초안을 만듭니다.
  • Markdown 내보내기 포트폴리오에 바로 옮길 수 있는 문서로 제공합니다.
05 Resources

기획 문서와 프로토타입

기획서 문제 정의, 사용자 시나리오, 화면 구조 프로토타입 Repository 입력 기반 동작 흐름 GitHub Wiki 제출용 기획 문서
06 Summary

한 줄 소개

PtoP(Project to Portfolio)는 GitHub Repository를 분석해 대학생 개발자의 프로젝트 경험을 포트폴리오와 회고 형태로 정리해주는 AI Agent 서비스.
