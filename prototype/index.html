PtoP

GitHub Repository를 분석해 프로젝트 참여자, 기여도, 내가 주로 작업한 내용을 정리합니다.

01 Input

Repository 입력

GitHub 공개 API에서 참여자와 최근 커밋을 가져옵니다. API 제한이나 비공개 저장소 때문에 실패하면 임의 결과를 만들지 않고 오류를 표시합니다.

02 Process

분석 진행

  1. Repository 확인대기 중
  2. 참여자 수집대기 중
  3. 최근 커밋 확인대기 중
  4. 내 작업 요약대기 중
03 Result

분석 결과

프로젝트 참여자 및 기여도

Repository URL을 입력하고 분석을 시작하세요.

내가 주로 작업한 내용

내 GitHub ID를 입력하거나 Repository owner 기준으로 분석합니다.

복사용 요약

분석 결과가 여기에 표시됩니다.
