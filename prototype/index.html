Discord University Notice Service

필요한 대학 공지를
Discord에서 더 편하게

IRIS는 대학 공지를 자동으로 수집해 Discord로 전달하는 봇입니다.카테고리 알림과 키워드 DM으로 필요한 공지만 빠르게 받아보세요.

실시간 공지 알림

새로운 공지가 올라오면 Discord에서 바로 알림을 받습니다.

카테고리 알림

카테고리별 Discord 채널과 역할을 연결하고 알림을 받습니다.

키워드 알림

관심 키워드가 포함된 제목의 공지를 개인 DM으로 받습니다.

('/') 슬래시 명령어

Guide

  1. 공지 사이트 정보를 입력합니다.
  2. 목록, 제목, 링크, 날짜, 카테고리 Selector를 입력합니다.
  3. 검증을 위해서 테스트 크롤링 버튼을 눌러 최근 공지가 보이는지 확인합니다.

💡 Selector 설정은 HTML 구조를 이해해야 하므로 직접 입력하기 어려울 수 있습니다.

직접 설정이 어려운 경우, 개발자 요청을 통해 등록을 도와드립니다.

Guide

  1. 사용할 수 있는 카테고리를 확인합니다.
  2. 해당 카테고리의 알림을 보낼 Discord 채널을 선택합니다.
  3. 역할 이름을 입력하면 저장 시 Discord에 자동 생성됩니다.
    사용자가 카테고리를 구독하면 해당 역할이 자동으로 부여됩니다.
