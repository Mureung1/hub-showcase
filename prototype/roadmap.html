    STEP 01 · 3주

    기본 CRUD REST API를 DB와 연결해 배포하기

    우선순위: 매우 높음

    한 도메인(예: 주문·게시판)을 정하고 Spring Boot + JPA + MySQL로 생성·조회·수정·삭제 API를 만들어 배포까지 완성하세요. 채우는 항목: CRUD REST API 프로젝트.

    Spring Boot CRUD JPA 연관관계 MySQL 스키마
    i

    왜 먼저 해야 하나요?

    Java·Spring·JPA·MySQL 조합이 13/30으로 가장 많이 함께 요구됩니다. 한 도메인을 끝까지 완성하면 직무 공통 기대치를 한 번에 채웁니다.

  2. 2
    STEP 02 · 3주

    예외·검증과 트랜잭션 처리까지 다루기

    우선순위: 높음

    요청 검증, 에러 응답, 트랜잭션과 롤백을 추가하고 실패 케이스를 문서로 남기세요. 채우는 항목: 예외·에러 응답 설계, 트랜잭션·동시성 이해.

    에러 응답 설계 트랜잭션·롤백 실패 케이스 문서화
    i

    왜 두 번째인가요?

    REST API + 예외·상태 처리 조합이 9/30에서 반복되고, 핀테크·금융 기업군은 트랜잭션 정합성을 특히 강조합니다(공고 편차 27%).

    STEP 03 · 2주

    Redis 캐시 / 인덱스·쿼리 튜닝 / 테스트·CI 중 하나를 골라 개선 전후 지표를 남기세요. 채우는 항목: 성능 개선 경험(우대).

    Redis 캐시 인덱스·쿼리 튜닝 테스트 · CI
    i

    왜 우대사항을 골라야 하나요?

    Docker 37%·Redis 27% 등 성능·인프라 요구가 이전 1년보다 늘고 있습니다. 개선 전후 지표는 면접에서 설득력 있는 근거가 됩니다.
