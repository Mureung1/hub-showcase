# PR 본문 템플릿

`CLAUDE.md`의 PR 규칙(`.github/pull_request_template.md` 기반)을 따른다. 타이틀은 `[N100_실명] 작업 한 줄 요약`.

```markdown
## 주요 작업 리스트

<이번 PR이 무엇을 했는지 한 문단 요약>

- **<영역 1>** (`파일 경로`, 신규/수정)
  - <구체적 변경>
- **<영역 2>**
  - <구체적 변경>

### 동작 확인

\`\`\`
$ npm test          # N passed
$ npm run lint      # 통과
<수동 검증 로그 — curl 응답, db:check 출력 등>
\`\`\`

## 내가 설명할 수 있는 부분

<핵심 설계 결정과 그 이유. 왜 이렇게 했는지 스스로 설명>

## 아직 이해 못 한 부분

- <남은 의문점, 미해결 리스크>

## 새로 알게 된 것

- <이번 작업에서 배운 점>

## 범위 외 (이번 PR 아님)

| 항목 | 담당 이슈 |
|------|-----------|
| <미룬 작업> | #N |

## 테스트

- [x] `npm test`
- [x] `npm run lint`
- [x] <수동 검증 항목>

Closes #N
```

## 규칙

- 본문 마지막에 **`Closes #N`** 을 넣어 머지 시 이슈가 자동 종료되게 한다.
- `동작 확인`에는 실제 실행 로그(테스트 결과, curl 응답, `db:check` 출력)를 넣어 검증 가능성을 보인다.
- `gh pr create --base main --title ... --body "$(cat <<'EOF' ... EOF)"` 로 HEREDOC 전달.
