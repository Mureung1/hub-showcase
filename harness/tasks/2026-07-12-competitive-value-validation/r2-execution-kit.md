# R2 무참여자 모델 벤치마크 실행 킷

> 목적: R1(평가자 2인 블라인드 검수) 통과 직후 준비 지연 없이 R2를 실행하기 위한 복붙용 자료. 규칙 원문은 `docs/COMPETITIVE_VALIDATION.md` 7장이 정본이며, 이 킷과 어긋나면 7장을 따른다.

- [ ] 통과한 콘텐츠 버전 동결 — 커밋 해시 기록: `______`
- [ ] 아래 "답냥이 고정 12문구"가 동결 버전과 일치하는지 대조

## 답냥이 고정 12문구 (2026-07-12 콘텐츠 버전 — R1 통과 후 재대조)

| 세트 | 기본 | 더 부드럽게 | 더 분명하게 |
|---|---|---|---|
| C1 | 확인했어요 알려주셔서 고마워요 | 챙겨주신 덕분에 잘 확인했어요 고마워요 | 내용 확인했어요 고마워요 |
| C2 | 안녕하세요 여쭤볼 내용이 있는데 면담 가능한 시간을 알려주실 수 있을까요? | 안녕하세요 여쭤볼 내용이 있는데 편하실 때 면담 가능한 시간을 알려주실 수 있을까요? | 안녕하세요 여쭤볼 내용이 있습니다 면담 가능한 시간이 언제일까요? |
| C3 | 저한테는 말 편하게 하셔도 되고 존댓말로 하셔도 괜찮아요 | 혹시 편하시면 저한테는 말 편하게 하셔도 괜찮아요 | 저한테는 편하게 말씀하셔도 괜찮아요 |
| C4 | 이번에는 어려울 것 같아 미안해 | 미안한데 이번에는 어려울 것 같아 | 이번에는 어려워 |

답냥이는 위 결정적 템플릿을 **한 번** 추출하며(과업당 재실행 없음), 품질 평가 단위는 8 task × 3 = 24 task-conditioned judgments다.

## 범용 모델 실행 규칙 요약 (7장)

- ChatGPT·Gemini 각각, **관련 맥락 없는 새 채팅**, 개인화(Memory·Custom Instructions·Gem) 미사용 — 해제 확인 불가 시 `personalization=unknown`으로 분리 기록
- 과업당 **독립 3회** 실행 (도구별 8 task × 3 runs = 24 runs, 72 candidate judgments)
- 기록: 도구명, 화면 표기 모델·플랜, 실행일시, 프롬프트 원문, **첫 결과 원문**, 응답 지연. 모델 표기 미확인 시 추정 금지
- 실패 재추출·좋은 결과 선별 금지. 정규화는 공백·감싼 따옴표·code fence·선두 번호/불릿/톤 라벨 제거만
- `format_fail`(정규화 후 3개 아님/설명 혼입) → 그 run의 후보 3슬롯 전부 `blind_pass=false`. refusal 동일. `technical_missing`만 동일 조건 1회 재시도
