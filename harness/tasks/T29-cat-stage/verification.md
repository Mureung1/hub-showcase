## 5. 정본·규칙 확인

- 작업별 정본(PRD/MVP/SPEC/SCREENS/DESIGN/UX/EDGE_CASES/CICD 등) 정합성: DESIGN·SCREENS·SPEC에 정적 아바타/관계 전신/생성 생각냥과 단일 Canvas 경계를 동기화했고, `public/cats/README.md`에 PNG 원본과 WebP 런타임 파생본 역할·규격·용량을 기록했다.
- MVP 범위 준수: 단일 Canvas 2.5D와 정적 폴백만 구현, 완전한 3D·백엔드 기능 미추가
- 코드 작업인 경우 `any` 미사용 확인 방법: `rg -n "(:|<|\\bas\\s+)\\s*any\\b|\\bany\\[\\]" src` 검색 결과 0건
- 미치환 필수 항목 없음: T29 계획·검증 문서 확인 완료
- 남은 위험·알려진 한계: PNG 원본은 보존되어 배포 산출물 전체에는 함께 복사되지만 앱 런타임 경로는 512,178-byte WebP만 참조한다. 사용자 직접 검증의 원시 스크린샷·좌표·콘솔·성능 로그는 하네스에 저장되지 않았으므로 별도 증빙이 필요하면 T31에서 다시 수집한다. Three.js 지연 청크는 T31 최종 통합 성능 회귀 대상이다.
