## 5. 변경 경계와 위험

- 허용된 변경: 승인된 T29 범위의 이미지 사본, 에셋 매핑, 정적 이미지 렌더, 단일 스테이지 텍스처 전환, 관련 테스트·정본 기록
- 명시적으로 제외한 변경: 원본 이미지 편집/삭제, 크로마키 런타임 사용, 완전한 3D 모델·리깅, Canvas 추가, T30 백엔드·DB, 말투 선택 구조
- 구조·계약·의존성 승인이 필요한 지점: 새 Canvas/3D 모델 도입, 원본 가공, 상태 종류 추가, 백엔드 연계는 재승인 필요
- 예상 위험과 대응: 공개 PNG 원본은 보존하되 런타임 경로는 품질 92·알파 100의 투명 WebP로 바꿔 전송량을 줄인다. 카드·헤더는 384px, 스테이지는 1024px이며 대표 답냥이 1024px은 약 56KiB라 두 용도에 공유한다. 선배냥은 전용 얼굴·상반신 아바타 384px과 전신 스테이지 1024px을 분리해 임시 CSS 크롭을 제거했으며 실제 원형 배치는 실브라우저에서 확인한다.
