# T23 실기기 수동 체크리스트

> 대상 URL: `https://dabnyang.vercel.app/`
>
> 실제 이름·학교·학번·메시지를 쓰지 않는다. 아래 합성 값만 사용하고 결과에는 환경·통과/실패·오류 현상만 기록한다.

## 공통 기록

- 기기·OS:
- 브라우저 또는 카카오톡 버전:
- viewport 또는 화면 크기:
- 확인 시각:
- 가로 넘침: 없음 / 있음
- 중단 오류: 없음 / 있음

## 1. 320×568 — 카드·guided AI·결과 다듬기

1. `답장` → `팀플·조모임` → `일정 조율`로 이동한다.
2. 질문에서 `가능한 시간 묻기`를 골라 AI 세 후보를 만든다.
3. 다음을 확인한다.
   - [ ] 생성 중 안내 뒤 기본·더 부드럽게·더 분명하게 세 후보가 보임
   - [ ] 임의 날짜·시간이 추가되지 않음
   - [ ] 화면을 좌우로 밀지 않아도 모든 문구·버튼을 볼 수 있음
4. 첫 후보의 `직접 수정`을 열어 합성 문구 한 글자를 바꾸고 복사한다.
   - [ ] `복사됨 ✓`, `텍스트 선택됨`, 또는 명시적인 `복사 실패` 중 하나가 표시됨
5. `이 선택으로 새 초안 3개 만들기`를 누른 뒤 `이전 초안`→`이전 초안으로 복원`을 확인한다.
   - [ ] 생성 중에도 현재 후보가 사라지지 않음
   - [ ] 이전/현재 후보 전환 뒤 가로 넘침과 초점 손실이 없음

## 2. 375×667 — 정적 기본 초안·말투·manual AI

1. `먼저 보내기` → `선배·동기` → `일정 조율`로 이동한다.
2. `질문 없이 바로 초안 보기`를 선택한다.
   - [ ] 로딩 없이 세 후보가 즉시 표시됨
   - [ ] `말투 바꾸기`에서 네 말투를 바꿔도 API 대기 없이 같은 상황 후보가 교체됨
3. 상황으로 돌아가 `내 상황을 직접 설명하기`를 선택한다.
4. 목적은 `질문`, 말투는 `요체`, 상황은 `동아리 운영진에게 다음 회의 시간을 물어보는 합성 테스트`만 입력한다.
   - [ ] 외부 provider 전송과 탭 임시 보관 안내를 확인할 수 있음
   - [ ] AI 세 후보가 표시되고 입력 수정으로 돌아가도 합성 입력이 보존됨
5. 키보드 또는 외부 키보드가 있다면 Tab·Shift+Tab·Enter/Space로 주요 선택과 복사를 반복한다.
   - [ ] 초점 표시가 보이고 단계 전환 뒤 현재 제목·결과로 이동함

## 3. 모바일 — 교수·조교 이메일

1. `먼저 보내기` → `교수님·조교님` → 연락 형식 `이메일` → `수업·과제 질문`을 선택한다.
2. 아래 합성 값만 입력한다.
   - 받는 분: `김민서 교수님`
   - 학과: `테스트학과`
   - 학번: `00000000`
   - 이름: `테스트학생`
   - 전달 내용: `합성 과제의 제출 형식을 확인하고 싶습니다`
3. `이메일 3가지 만들기`를 누른다.
   - [ ] 정석·더 정중하게·더 간결하게 세 후보가 보임
   - [ ] 제목·본문·전체 메일 복사 버튼이 각각 보임
   - [ ] 입력·결과가 서버나 AI로 전송되지 않는다는 안내를 확인할 수 있음
4. 제목·본문·전체 메일을 각각 한 번 복사한다.
   - [ ] 각 버튼에 `복사됨 ✓`, `텍스트 선택됨`, 또는 명시적인 실패가 표시됨

## 4. 카카오톡 인앱 브라우저 — 복사 fallback

1. 본인과의 채팅방에 대상 URL을 보내고 카카오톡 인앱 브라우저로 연다.
2. 1번 카드 경로의 `질문 없이 바로 초안 보기`까지 이동한다.
3. 후보 하나의 `복사`를 누른다.
   - [ ] clipboard 성공이면 `복사됨 ✓`가 표시됨
   - [ ] clipboard API가 막히면 후보 텍스트가 자동 선택되고 `텍스트 선택됨`이 표시됨
   - [ ] 두 방식이 모두 실패하면 `복사 실패`가 숨지 않고 표시됨
4. 선택 또는 복사된 문구를 실제 상대에게 보내지 말고 본인과의 채팅 입력칸에서만 붙여넣기 가능 여부를 확인한 뒤 지운다.

375×667 template/manual/키보드: 통과 | 실패 — 환경/현상
모바일 이메일 세 복사: 통과 | 실패 — 환경/현상
