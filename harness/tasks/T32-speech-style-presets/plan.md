## 1. 목표와 완료조건

- 해결할 사용자/제품 문제: 직접 설명 AI는 사용자가 고른 평소 말투를 반영해야 하지만, 빠른 카드 경로는 말투 선행 질문 없이 즉시 쓸 수 있어야 한다. 현재 코드는 이 두 경로를 하나의 `speechStyleId`로 다루면서 관계·카드 선택 때 사용자 선호를 기본값으로 덮고, S3의 정적 말투 전환 UI도 아직 없다.
- 목표 결과: `습니다체 / 요체 / 이다체 / 용용체`를 세 톤과 독립된 선호로 완결한다. 카드는 명시 선호가 없으면 관계 안전 기본값을 쓰고, 직접 설명은 신규 세션에서 반드시 사용자가 고른 뒤만 AI를 호출한다. 정적 카드 결과는 S3에서 API·로딩·어미 변환 없이 같은 상황의 4개 검수 세트 사이를 바꾼다.

## 5. 변경 경계와 위험

- 허용된 변경: 이미 승인된 T32 흐름의 마감인 명시 말투 선호·카드 기본값 분리, 세션 정규화, template S3 로컬 전환 UI, 관련 테스트·문서.
- 명시적으로 제외한 변경: 288문구 재작성, AI 응답 스키마·provider·prompt 구조, 런타임 어미 변환, 자유 말투 입력, DB·계측, 이메일, 영구 프로필, 새 의존성, 커밋·push·배포.
- 구조·계약·의존성 승인 지점: 카드 선행 질문 제거·S3 정적 말투 전환은 2026-07-20 사용자가 승인한 흐름이다. 이 계획은 새 스키마나 새 의존성 없이 그 미완료 흐름만 마감한다. 이 범위를 넘거나 정본과 추가 충돌하면 중단·제안·재승인한다.
- 예상 위험과 대응: 카드 기본값을 선호로 저장하면 직접 설명의 명시 선택 조건이 깨지므로 nullable 선호를 유지한다. 말투 전환으로 수정문·복사 상태·이전 초안이 섞이는 위험은 전환 핸들러의 명시 초기화와 회귀로 차단한다. 기존 dirty diff 충돌은 해당 함수·테스트만 최소 편집하고 전체 diff를 마지막에 다시 대조한다.
