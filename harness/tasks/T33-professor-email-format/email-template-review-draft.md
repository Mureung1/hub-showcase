# T33 교수·조교 이메일 18후보 사용자 검토표 — 초안

> 상태: **사용자·외부 평가 전 초안 — 검수 완료 아님**
>
> 작성일: 2026-07-16

## 검토 목적

교수·조교 이메일 6상황에서 `정석 / 더 정중하게 / 더 간결하게` 세 후보의 제목과 본문이 자연스럽게 읽히는지 확인한다. 아래 문구는 로컬 정적 템플릿의 현재 출력이며, 자동 테스트 통과만으로 문구 검수를 완료 처리하지 않는다.

## 공통 샘플 입력

- 받는 분: 김민서 교수님 (호칭 포함)
- 학과: 국어국문학과
- 학번: 20260001
- 이름: 이다은
- 면담 가능 시간: 월요일 오후 2시, 화요일 오전 11시, 수요일 오후 4시
- 면담 방식: 대면 또는 온라인
- 각 상황의 구체 내용은 표의 본문에 그대로 표시했다.

## 검토 기준

- 사용자가 입력한 성함·학과·학번·이름·구체 내용이 빠지거나 바뀌지 않았는가?
- 입력하지 않은 날짜·시간·수업명·사유가 새로 생기지 않았는가?
- 세 후보는 같은 사실을 유지하면서 `정석 / 더 정중하게 / 더 간결하게`의 차이가 읽히는가?
- 제목, 인사, 자기소개, 용건, 맺음말이 교수·조교에게 보내는 이메일로 자연스러운가?
- 같은 의미의 표현이나 감사 인사가 불필요하게 반복되지 않는가?
- 받는 분에 입력한 이름과 `교수님` 또는 `조교님` 호칭을 별도 호칭 추가 없이 그대로 사용했는가?
