# T22 참여자 모집·세션 안내문

> 이 문서는 T22 운영자가 같은 안내를 제공하기 위한 문안이다. 실제 연락처·실명·학교·보상 명단·응답은 이 파일과 Git 저장소에 기록하지 않는다.
>
> 연구윤리 심의나 법률 검토를 받았다고 표현하지 않는다. 참여자의 자발성·수집 범위·중단 권리를 설명하는 MVP 사용성 테스트 안내다.

## 1. 모집 안내문

안녕하세요. 대학생이 보내기 어려운 메시지의 초안을 빠르게 준비하도록 돕는 서비스 ‘답냥이’의 사용성 테스트 참여자를 모집합니다.

- 예상 시간: 약 35~50분
- 대상: 만 18세 이상 현재 재학 중인 대학생
- 필요한 경험: 최근 30일 안에 보내기 망설인 메시지 경험, 최근 3개월 안에 ChatGPT 또는 Gemini로 메시지 초안을 만든 경험
- 진행 내용: 실제 대화가 아닌 가상 상황으로 답냥이와 평소 사용하는 ChatGPT 또는 Gemini에서 보낼 문구 준비
- 수집하지 않는 정보: 실제 메신저 원문·캡처, 실명, 학교·학과·학번, 연락처, 개인 AI 대화 목록
- 참여 여부와 평가 결과에 관계없이 안내된 보상은 동일하게 제공
- 원하지 않는 질문은 건너뛸 수 있고 언제든 중단 가능

참여 의사가 있으면 모집 글을 받은 채널의 회신 기능으로 알려주세요. 참여 조건 확인과 일정 조율 정보는 테스트 기록과 분리해 관리합니다.

## 2. 비식별 사전 확인

운영자는 아래 항목을 `Y/N`으로만 확인하고 학교명·정확한 나이·실제 메시지 내용은 묻지 않는다.

1. 만 18세 이상이며 현재 대학에 재학 중인가요?
2. 한국어 메신저를 주로 사용하나요?
3. 최근 30일 안에 보내기를 망설인 메시지가 한 번 이상 있었나요?
4. 최근 3개월 안에 ChatGPT 또는 Gemini로 메시지 초안을 만든 적이 있나요?
5. 답냥이 프로젝트 제작·시드/템플릿 검수·사전 사용에 참여하지 않았나요?
6. 연구자와의 관계 때문에 참여를 거절하기 어렵지는 않나요?
7. 평소 사용하는 ChatGPT 또는 Gemini 계정에서 실제 대화가 아닌 가상 과업을 수행하는 데 동의하나요?

1~7을 모두 충족하지 않으면 T22 유효 paired 참여자로 등록하지 않는다. 개인 계정 비교를 원하지 않아도 불이익은 없으며 답냥이 사용성 결과와 보상은 유지할 수 있지만, 경쟁 판정 분모에는 넣지 않는다.

## 3. 세션 시작 안내

진행자는 아래 내용을 읽고 참여자가 이해했는지 확인한다.

> 오늘은 참여자분이 아니라 제품을 테스트합니다. 실제 메시지나 개인정보를 입력하지 않고 제공된 가상 상황만 사용합니다. 화면 녹화와 개인 대화 목록 수집은 기본 진행에 포함되지 않습니다. 원하지 않는 질문은 건너뛸 수 있고 언제든 이유 없이 중단할 수 있으며 보상에는 영향이 없습니다.
>
> 테스트 중에는 어떤 카드나 문구가 정답인지 알려드리지 않습니다. 평소라면 어떻게 하실지 진행해 주세요. 기술 문제나 개인정보 노출이 생기면 바로 말씀해 주세요.
>
> 비식별 원시 기록은 판정 확정 후 30일 안에 삭제하고, 연락·보상 연결표는 보상 완료 후 7일 안에 삭제합니다. Git 저장소에는 집계 결과와 익명 점수만 남깁니다.

시작 전 확인 항목:

- [ ] 테스트 목적과 약 35~50분 소요를 이해함
- [ ] 가상 상황만 사용하고 실제 원문·캡처를 수집하지 않음을 이해함
- [ ] 언제든 건너뛰거나 중단할 수 있음을 이해함
- [ ] 비식별 기록과 삭제 일정을 이해함
- [ ] 평소 사용하는 도구와 답냥이의 가상 과업 수행에 자발적으로 동의함

확인은 실명 서명 대신 분리된 접근 제한 기록에 `participant_code`, 안내 version, `confirmed=Y/N`, 확인 시각만 남긴다. `N`이면 세션을 시작하지 않는다.

## 4. 과업 중 통일 문구

> 평소 하시듯 이 상황에서 실제로 보낼 수 있는 최종 문구를 준비해 주세요. 마음에 드는 초안이 나오면 공통 편집칸으로 가져와 필요한 만큼 고친 뒤 “이대로 보내기”를 눌러주세요.

질문을 받으면 먼저 아래 문장만 사용한다.

> 평소라면 어떻게 하실지 진행해 주세요.

30초 정지 또는 명시적 도움 요청 2회 뒤에만 표준 힌트 1회를 제공하고 `assisted=true`로 기록한다. 카드 추천·프롬프트 예시·정답 확인·칭찬이나 실망 반응은 하지 않는다.

## 5. 세션 종료 안내

이해 확인 질문을 먼저 마친 뒤 아래 내용을 설명한다.

- 상황 카드 경로는 받은 원문을 읽지 않고 사용자가 고른 카드와 선택 ID만 사용한다.
- 직접 설명 내용은 현재 탭에 마지막 활동 뒤 30분까지 임시 보관되며 생성할 때 외부 AI provider로 전달된다.
- 서비스 서버·분석·DB에는 사용자 원문을 저장하지 않는다.
- 교수냥은 교수님·조교님, 선배냥은 선배·동기, 연인냥은 친구·연인을 함께 포함한다.

마지막으로 철회할 내용이나 우발적으로 입력된 개인정보가 있는지 확인한다. 개인정보가 있었다면 해당 원문을 24시간 안에 삭제하고 `redaction_applied`만 남긴다.
