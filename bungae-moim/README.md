# 번개모임 & 소모임 — 프론트엔드 프로토타입

`hub` 저장소 위키의 [기획서](../../wiki/기획서), [DB 스키마 설계서](../../wiki/번개모임_소모임_DB_스키마_설계서), [API 명세서](../../wiki/번개모임_소모임_API_명세서)를 바탕으로 만든 **디자인/플로우 확인용 프론트엔드 목업**입니다.

- 백엔드/DB 없이 `src/data/mockData.js`의 고정 데이터로 동작합니다.
- 디자인은 `clab-design-system` 스킬(웜 샌드 배경, 글래스/솔리드/다크 카드, 오렌지 포인트)을 그대로 적용했습니다.
- 실제 API 연동은 API 명세서의 엔드포인트로 교체하면 됩니다 — `src/context/AppStateContext.jsx`의 액션 함수들이 그 경계입니다.

## 실행

```bash
npm install
npm run dev
```

## 화면 구성 (기획서 8번)

| 경로 | 화면 |
|---|---|
| `/` | 메인 페이지 |
| `/meetings` | 모임 목록/검색 (유형·카테고리·지역 필터) |
| `/meetings/:id` | 모임 상세 (참여 신청 / 모임장 승인 관리) |
| `/meetings/new` | 모임 등록 |
| `/login` | 로그인 (구글/카카오 버튼 — 실제 OAuth 없이 로그인 상태만 시뮬레이션) |
| `/mypage` | 마이페이지 (내가 등록한 모임 / 참여한 모임) |

## 목업으로 시뮬레이션한 것

- 번개모임은 신청 즉시 확정, 소모임은 모임장 승인 필요 (기획서 5번)
- 번개모임 정원 도달 시 자동 마감, 참여자가 취소하면 재오픈
- 소모임은 정원 제한 없음
- 신뢰도 점수는 강제 제재 없이 전 사용자에게 공개
- 지난 모임(종료/취소)은 목록에서 자동 제외
- 지역 3단계(시/도 · 시/군/구 · 읍/면/동) 필터

## 목업이라 비워둔 것

- 실제 소셜 로그인(OAuth), 백엔드 API, DB 연동
- 알림 기능 (기획서에서 제외 결정)
- 신고 처리, 계정 정지 등 관리자 동작 (개발자가 DB로 수동 처리하는 정책이라 UI 자체가 없음)
