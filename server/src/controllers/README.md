# server/src/controllers

이 디렉토리는 라우터로부터 전달받아 실제 비즈니스 로직(DB 쿼리, 외부 연동 처리 등)을 직접 구현하고 처리하는 컨트롤러 파일들이 위치하는 곳입니다.

## 역할 및 설계 방향
- `auth.ts`: 메일 전송, SMS 인증 확인, 로그인 유효성 검사 등 실질적인 회원 연동 비즈니스 알고리즘을 담당할 파일입니다.
- **인증 연동 계획**: 초기 가상 유저 단계에서는 비어 있으나, 나중에 Nodemailer 메일 발급이나 PortOne 본인확인 SMS 검증 코드가 여기에 구현되어 백엔드 서비스의 중추 역할을 수행하게 됩니다.
