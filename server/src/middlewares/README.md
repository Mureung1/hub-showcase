# server/src/middlewares

이 디렉토리는 클라이언트의 API 요청이 비즈니스 로직(컨트롤러)에 도달하기 전 거치는 미들웨어들이 위치하는 곳입니다.

## 역할 및 설계 방향
- `auth.ts`: 들어온 요청의 인증 여부를 가려내는 미들웨어입니다.
- **인증 연동 계획**: 초기 가상 유저 테스트 시 모든 요청에 가짜 유저 세션을 항상 부여해 주는 Mock 역할을 하다가, 나중에 로그인/회원가입 기능이 완성되면 헤더의 JWT 토큰을 직접 디코드하여 유효한 사용자인지 판별하고 차단/승인하는 실체 로직으로 교환하게 됩니다.
