# Server Source 디렉토리

백엔드 서버의 실제 애플리케이션 코드가 들어있는 디렉토리입니다.

## 주요 파일 및 구성
- **index.ts**: 서버의 시작점이자 Express 앱 설정 및 포트 바인딩을 수행하는 진입 파일입니다.
- **controllers/**: API 요청을 처리하고 비즈니스 로직을 수행한 후 응답을 반환하는 컨트롤러 계층입니다.
- **middlewares/**: 요청과 응답 사이에서 인증, 로깅, 예외 처리 등을 담당하는 미들웨어 계층입니다.
- **routes/**: 각 엔드포인트(URL)와 컨트롤러를 연결해주는 라우팅 설정이 모여 있습니다.
