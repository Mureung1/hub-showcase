# Design Skill

## 목적
이 문서는 프로젝트의 UI를 일관되게 만들기 위한 디자인 규칙이다.

## 디자인 방향
- 밝은 회색 배경
- 흰색 카드 UI
- 노란색 포인트 컬러
- 둥근 모서리
- 부드러운 그림자
- 왼쪽 사이드바 + 중앙 카드 리스트 + 오른쪽 상세 패널 구조

## 색상 규칙
- 주요 색상: 노란색 계열
- 배경색: 연한 회색
- 카드 배경: 흰색
- 본문 텍스트: 진한 회색
- 보조 텍스트: 연한 회색

## 컴포넌트 규칙
- 버튼은 노란색 배경과 둥근 모서리를 사용한다.
- 카드는 흰색 배경, 둥근 모서리, 부드러운 그림자를 사용한다.
- 가게 목록은 카드 그리드로 보여준다.
- 선택된 가게 정보는 오른쪽 상세 패널에 보여준다.

## 개발 규칙
- 새 화면을 만들 때 이 디자인 규칙을 따른다.
- 임의의 색상을 추가하지 않고 디자인 토큰을 우선 사용한다.
- CSS 변수는 frontend/src/styles/design-system.css에 정의한다.
