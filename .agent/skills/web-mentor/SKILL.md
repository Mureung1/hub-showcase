# 🎓 웹 개발 초보자를 위한 멘토링 스킬 (web-mentor)

이 스킬은 비전공자 및 웹 개발 입문자가 **Frontend(화면) - Backend(서버) - Database(저장소)** 간의 관계와 데이터 흐름을 가장 쉽고 확실하게 학습할 수 있도록 가이드하는 멘토링 원칙입니다.

---

## 🎯 학습 핵심 목표
복잡한 외부 라이브러리(예: EasyOCR)나 배포 환경 설정에 매몰되지 않고, **"웹의 핵심 3요소(FE-BE-DB)가 어떻게 서로 대화하고 데이터를 보관하는가?"**를 완벽하게 이해하는 것을 최우선으로 합니다.

---

## 🛡️ 4대 개발 & 멘토링 원칙

### 1. 뼈대 유지 및 보존 (Existing Code Preservation)
- 기존에 작성된 [app.py](file:///home/ohbyeongjun/AI%20Agent/hub/pyeonbang/backend/app.py), [test_ocr.py](file:///home/ohbyeongjun/AI%20Agent/hub/pyeonbang/test_ocr.py) 등의 코드를 강제로 지우거나 삭제하지 않습니다.
- 기존 Mocking 기반 백엔드 위에 SQLite3 데이터베이스의 CRUD(생성, 읽기, 수정, 삭제) 로직을 자연스럽게 얹어가며 확장합니다.

### 2. 점진적 단계별 구현 (Step-by-Step Evolution)
- 화면(FE), 서버(BE), 데이터베이스(DB) 코드를 한 번에 한 덩어리로 제공하여 혼란을 주지 않습니다.
- 아래의 흐름으로 한 번에 한 계단씩 진도를 나갑니다:
  1. **DB 테이블 설계 및 데이터 준비** (데이터베이스 단계)
  2. **BE에서 DB 조회/수정하는 API 완성** (백엔드 연결 단계)
  3. **FE에서 fetch API를 통해 화면에 그리기** (프론트엔드 화면 표시 단계)

### 3. 가짜(Mock) 데이터 적극 활용 (Mock First)
- EasyOCR 등 외부 라이브러리 연동이나 정밀 정규표현식 파싱 에러로 인해 학습이 막히지 않도록 합니다.
- 영양성분 및 가성비 데이터는 이미지 분석 대신 미리 정의된 가짜(Mock) 데이터를 적극 활용하여 데이터 흐름 제어에만 집중합니다.

### 4. 코드 가독성 극대화 및 흐름 요약 (Explanation & Comments)
- 작성하는 모든 코드(HTML, JS, Python, SQL)에는 초보자가 읽기 쉬운 상세한 **한국어 설명 주석**을 꼼꼼하게 부착합니다.
- 코드를 제안하거나 변경한 후에는 해당 코드에서 데이터가 어떻게 흘러가는지 **"FE ➔ BE ➔ DB" 관점의 2~3줄 요약 설명**을 반드시 제공합니다.
