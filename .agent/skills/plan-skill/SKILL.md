# Reusable Agent Skill: High-Quality MVP Plan Builder

## Description
이 스킬은 방대한 개발 요구사항이 들어왔을 때, 불필요한 기능을 과감히 도려내고 핵심 데이터 흐름이 한 번에 연결되는 '수직 관통(Vertical Slice) 파이프라인'을 설계하는 능력입니다. 비전공자도 이해할 수 있는 직관적인 자동차/찰흙 모형 등의 비유를 들어 설명합니다.

## Critical Requirements
1. **수직 관통 최우선:** 화려한 UI나 예외 처리는 무조건 배제하고, "인풋 ➔ 가공 ➔ 아웃풋"의 데이터 고속도로를 가장 먼저 뚫는 일정을 설계하세요.
2. **기술적 치트키 제시:** 개발 기간을 획기적으로 줄여줄 수 있는 브라우저 내장 API나 HTML5 기능(예: `<input capture="environment">`)이 있다면 무조건 대안으로 제시해야 합니다.
3. **데이터 의존성 정렬:** 일정 단계를 나눌 때는 '앞 단계의 데이터가 확보되어야 다음 단계가 돌아가는 구조'를 계산하여 선후 관계를 엄격히 배치하세요.

## 💡 Few-Shot Example (성공 레퍼런스)
사용자가 촉박하거나 빠른 프로토타입 완성을 원할 때, 에이전트는 반드시 아래의 형태로 계획을 도출해야 합니다.

*   **유저 입력:** "스마트폰 카메라로 제품 찍으면 영양성분이랑 가성비 점수 바로 나오는 웹 시스템 내일까지 만들고 싶어."
*   **에이전트 출력 행동:**
    1. 대량의 카메라 스트리밍 코딩 대신 HTML5 순정 카메라 앱 호출 치트키(`<input type="file" capture="environment">`)를 제안하여 프론트엔드 개발 시간을 반나절로 단축시킵니다.
    2. [원래 계획 vs 비상 압축 계획] 비교 테이블을 제시하여 유저에게 기능 타협 없이 일정을 당기는 확신을 줍니다.
    3. 일정을 무조건 `[프론트 카메라 전송] ➔ [백엔드 파일 수신] ➔ [EasyOCR 텍스트 추출] ➔ [Regex 정밀 정제] ➔ [화면 표출]` 순서로 쪼개어, 개발자가 통신 에러(들여쓰기, 모듈 누락 등)를 단계별로 격파할 수 있게 만듭니다.
