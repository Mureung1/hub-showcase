주식회사 커머스히어로 프론트엔드 개발자 (신입·주니어) 채용

[회사 소개]
커머스히어로는 월 500만 명이 방문하는 패션 커머스 플랫폼을 운영합니다.
상품을 탐색하고 장바구니에 담아 결제하기까지, 사용자가 실제로 만지는 모든 화면을 프론트엔드 팀이 만듭니다.
화면이 0.5초 늦게 뜨면 이탈이 눈에 보이게 늘어나는 서비스라, 저희는 만든 화면의 지표를 스스로 확인하는 문화를 갖고 있습니다.
예쁜 화면을 넘어 빠르고 누구나 쓸 수 있는 화면을 함께 만들 분을 찾습니다.

[주요업무]
- 커머스 웹 서비스의 상품 탐색·주문 화면 개발
- 디자인 시스템 컴포넌트 설계와 유지보수
- 핵심 지표 개선을 위한 A/B 테스트 구현과 측정
- 백엔드 팀과 API 스펙을 함께 설계

[자격요건]
- React 기반 웹 애플리케이션 개발 경험이 있으신 분
- JavaScript와 TypeScript로 협업해 보신 분
- 웹 성능 지표(LCP·INP)를 측정하고 개선해 보신 분
- HTML·CSS로 반응형 레이아웃을 구현할 수 있으신 분
- Git 기반 협업이 익숙하신 분

[우대사항]
- 웹 접근성 지침(WCAG)을 고려해 화면을 만들어 보신 분
- Next.js 등으로 서버 사이드 렌더링을 다뤄 보신 분
- 상태 관리 라이브러리를 사용해 보신 분
- 커머스 도메인에 관심이 있으신 분
- 컴포넌트 테스트를 작성해 보신 분

[전형절차]
- 서류 전형 (포트폴리오 필수, 배포 링크 권장)
- 과제 전형 (48시간, 소규모 화면 구현)
- 1차 기술 면접 (60분, 과제 리뷰 중심)
- 2차 협업 면접 (45분)
- 처우 협의 후 최종 합격

[복리후생]
- 유연 근무제와 주 3회 재택근무
- 연 150만 원 자기계발비와 도서 무제한 구매
- 디자인 시스템 스터디와 사내 컨퍼런스 참가비 지원
- 최신 사양 노트북과 듀얼 모니터 제공
- 점심 식대 지원과 무제한 간식, 종합 건강검진
