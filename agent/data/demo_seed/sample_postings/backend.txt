주식회사 페이먼트랩 백엔드 개발자 (신입·주니어) 채용

[회사 소개]
페이먼트랩은 온라인 가맹점의 결제와 정산을 대신 처리하는 지급결제 서비스를 만듭니다.
국내 3만여 개 가맹점의 거래를 매일 집계하고, 다음 날 아침까지 정산 금액을 계산해 지급합니다.
저희 팀이 다루는 숫자는 곧 누군가의 매출이기 때문에, 빠르게 만드는 일보다 틀리지 않게 만드는 일을 먼저 이야기합니다.
함께 일할 백엔드 개발자를 찾습니다. 경력보다 문제를 끝까지 파고든 기록을 봅니다.

[주요업무]
- 정산·지급대행 서비스의 서버 API 개발 및 운영
- 일 단위 정산 배치와 거래 데이터 파이프라인 개발
- 가맹점용 정산 어드민 백엔드 개발과 화면 연동
- 재무·정책 부서와 협업해 정산 규칙을 시스템에 반영

[자격요건]
- Java 또는 Kotlin 기반 서버 개발 경험이 있으신 분
- 관계형 데이터베이스 모델링과 쿼리 작성에 익숙하신 분
- 대용량 트랜잭션을 정확하고 안전하게 처리한 경험이 있으신 분
- REST API 설계와 개발 경험이 있으신 분
- Git 기반 협업과 코드 리뷰 문화에 익숙하신 분

[우대사항]
- 장애 상황에서도 데이터 정합성을 지키는 방법을 고민해 보신 분
- 초당 수천 건 규모의 트래픽을 다뤄 보신 분
- Kafka 등 메시지 큐를 사용해 보신 분
- 금융·결제 도메인에 관심이 있으신 분
- 테스트 코드 작성이 습관화되어 있으신 분

[전형절차]
- 서류 전형 (자기소개서·포트폴리오)
- 1차 기술 면접 (60분, 프로젝트 기반 질의)
- 2차 협업 면접 (60분, 팀 리더·동료)
- 처우 협의 후 최종 합격
- 전형 일정은 지원자 상황에 맞춰 조정 가능합니다.

[복리후생]
- 자율 출퇴근제와 주 2회 재택근무
- 연 200만 원 교육비 지원 (도서·강의·컨퍼런스)
- 사내 기술 세미나 격주 운영과 발표자 인센티브
- 노트북·모니터 등 장비 자율 선택
- 명절 상여와 종합 건강검진, 단체 상해보험
