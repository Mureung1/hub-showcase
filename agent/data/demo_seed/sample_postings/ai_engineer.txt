주식회사 뉴럴스택 AI 엔지니어 (신입·주니어) 채용

[회사 소개]
뉴럴스택은 기업 내부 문서를 검색해 답하는 업무용 AI 어시스턴트를 만듭니다.
고객사의 규정과 매뉴얼 수십만 건을 색인해, 담당자가 묻는 질문에 근거 문서와 함께 답을 돌려줍니다.
그럴듯한 답보다 틀리지 않은 답이 중요한 제품이라, 저희는 모델을 바꾸기 전에 평가 세트부터 만듭니다.
모델을 쓰는 사람이 아니라 모델의 품질을 측정하고 개선하는 사람을 찾습니다.

[주요업무]
- 문서 검색 기반 질의응답(RAG) 파이프라인 개발과 운영
- 프롬프트 설계와 응답 품질 평가 체계 운영
- 임베딩 색인 구축과 벡터 검색 성능 개선
- MLOps 팀과 협업해 모델 서빙 파이프라인 운영

[자격요건]
- Python으로 데이터 처리 코드를 작성해 보신 분
- 머신러닝·딥러닝의 기본 개념을 이해하고 계신 분
- LLM 응답 품질을 정량적으로 평가해 보신 분
- REST API 형태로 모델을 서빙해 본 경험이 있으신 분
- Git 기반 협업이 익숙하신 분

[우대사항]
- 검색 품질을 개선해 보신 분 (청킹·재랭킹 등)
- GPU 자원 사용량과 추론 비용을 관리해 보신 분
- PyTorch 등 프레임워크로 모델을 학습시켜 보신 분
- 논문을 읽고 구현해 본 경험이 있으신 분
- 실험 결과를 재현 가능하게 기록해 오신 분

[전형절차]
- 서류 전형 (깃허브·기술 블로그 링크 권장)
- 사전 과제 (48시간, 소규모 검색 파이프라인 구현)
- 1차 기술 면접 (60분, 과제 리뷰와 평가 설계 질의)
- 2차 협업 면접 (45분)
- 처우 협의 후 최종 합격

[복리후생]
- 완전 유연 근무제와 원격 근무 병행
- 연구용 GPU 자원과 상용 모델 API 크레딧 지원
- 연 200만 원 학습비와 논문 스터디 시간 보장
- 국내외 컨퍼런스 참가와 발표 지원
- 스톡옵션, 종합 건강검진, 점심 식대 지원
