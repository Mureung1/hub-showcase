## 방향

**Pastel glassmorphism + game HUD.** 전기적인 블루 → 바이올렛 → 시안으로 흐르는 쿨톤 그라디언트 배경 위에, 크고 부드럽게 표류하는 블러 오브가 떠 있고, 그 위에 반투명 화이트 글래스 패널이 콘텐츠를 담는다. 배경을 의도적으로 쿨톤(블루/바이올렛/시안)으로만 구성해 코랄·핑크 같은 따뜻한 색을 배제했다 — 웜톤 그라디언트는 인스타그램류 라이프스타일 앱으로 읽히기 쉽고, 블루-바이올렛-시안(esports/사이버펑크 톤)이 "설계 콘솔"에 더 맞는 정체성이라 판단했다. 게임감은 어두운 네온이 아니라 "성취/진행" 모티프(진행바, 배지, 순환하는 루프 노드)로 표현한다.

## 색상 역할

| 토큰 | 값 | 역할 |
|---|---|---|
| `--clb-sky` / `--clb-violet` / `--clb-cyan` | #3a5be3 / #8b3ff2 / #1fe0cf | 배경 그라디언트 3스톱. 쿨톤 고정 — 코랄/핑크 등 웜톤을 배경에 섞지 않는다. 새 화면을 추가해도 이 3색과 각도(160deg)는 고정한다 |
| `--clb-gold` | #ffcf7a | 유일한 강조색. "선택됨", 추천 배지, CTA 포인트, 루프의 "반복" 노드에만 쓴다 |
| `--clb-success` | #baffd9 | 상태 점(활성 세션 등) 전용. gold와 함께 남용하지 않는다 |
| `--clb-ink` / `--clb-muted` / `--clb-muted-dim` | 흰색 계열 3단계 | 배경이 항상 채도 높은 그라디언트이므로 텍스트는 흰색 계열만 사용. 어두운 텍스트는 gold 배지 안(`--clb-gold-ink`) 등 명도 대비가 필요한 곳에서만 예외적으로 쓴다 |

새 악센트 색을 추가하고 싶을 때는 gold를 대체하지 말고, 이 표에 먼저 추가하고 역할을 정의한 뒤 사용한다.

## 글래스 패널 레시피

모든 카드/패널/네비는 아래 4가지를 항상 함께 적용한다. 하나라도 빠지면 "그냥 반투명 사각형"이 되고 유리 질감이 사라진다.

1. `background: var(--clb-glass)` (배경 강도에 따라 `-strong` / `-faint` 사용)
2. `backdrop-filter: blur(...)` + `-webkit-backdrop-filter` — 패널은 28px, 네비는 24px, 작은 루프 노드는 16px
3. `border: 1px solid var(--clb-edge-soft)` (강조 필요 시 `--clb-edge`)
4. `box-shadow`는 반드시 `inset 0 1px 0 rgba(255,255,255,0.35)` 하이라이트를 포함한 값을 쓴다 (`--clb-shadow-panel` 등) — 그림자만 있고 inset 하이라이트가 없으면 유리가 아니라 그냥 카드로 보인다

Radius: 큰 패널 26px(`--clb-radius-panel`), 인풋/카드/작은 컨트롤 18px(`--clb-radius-control`), 버튼/필/네비는 완전한 pill(`--clb-radius-pill`).

## 컴포넌트 패턴

- **카드 (candidate-card 등)**: 아이콘 배지(원형, 반투명 화이트) → 태그 라벨 → 제목 → 설명 → 진행바 순서 고정. 선택 상태는 gold 톤 배경 + gold 배지로만 표시하고, 별도 체크 아이콘이나 색을 추가하지 않는다.
- **진행바/스탯 (score-track/fill)**: 배경은 `rgba(255,255,255,0.18)`, 채움은 기본 흰색, 선택된 카드 안에서만 gold. 수치는 항상 라벨과 함께(`추천도 92`) 표기해 스크린리더/저시력 사용자도 의미를 알 수 있게 한다.
- **루프 노드 (loop-node)**: 원형 배지 + 라벨의 프로스티드 칩. 원형 배치는 데스크톱 전용이며, 640px 이하에서는 세로 리스트로 전환한다(기획서 5번 요구사항과 동일). 마지막 노드("반복")만 gold 톤으로 순환을 강조한다.
- **스테이지 네비**: pill 안에 3개 탭. 활성 탭은 `--clb-glass-strong` 배경 + gold 아이콘 배지. 탭 개수가 늘어나도 pill 형태와 아이콘-배지 우선순위(아이콘이 먼저, 라벨이 보조)를 유지한다.

## Game-feel 모티프 규칙

- **배경 오브**: 항상 최소 2개, 서로 다른 애니메이션 주기(24~45초 권장)로 천천히 표류. 동시에 같은 방향으로 움직이면 "회전판"처럼 보이므로 방향/타이밍을 어긋나게 한다. `prefers-reduced-motion: reduce`에서는 반드시 정지.
- **성취 언어**: "선택됨", "추천도", 순번 배지처럼 진행/성취를 나타내는 요소만 게임 모티프로 인정한다. 무기/캐릭터 아이콘 같은 장식적 게임 클리셰는 쓰지 않는다 — 이 서비스의 사용자는 게임을 "플레이"하는 게 아니라 "설계"하는 사람이라는 톤을 지킨다.
- **호버/포커스**: 카드·버튼은 hover 시 `translateY(-1~2px)` + 그림자 강화만 사용. 회전, 튐(bounce) 같은 과한 모션은 쓰지 않는다.

## 접근성 체크

- 텍스트 대비: 그라디언트 배경 위 `--clb-muted`(76% 흰색)가 최소 대비 기준. 이보다 낮은 투명도로 본문 텍스트를 두지 않는다.
- 포커스: 모든 인터랙티브 요소는 `outline: 2px solid #fff` + `outline-offset: 3px`를 유지한다.
- 순환 다이어그램에는 항상 `role="img"` + 전체 흐름을 서술하는 `aria-label`을 붙인다(개별 노드 텍스트만으로는 순서가 스크린리더에 전달되지 않음).
