# MoneyMate Web MVP

친구와 함께 금융 습관을 만드는 AI Agent 기반 웹 MVP입니다.

## 핵심 컨셉

- 나만 보는 간단한 소비 기록
- 기록과 목표 기반 오늘의 금융 미션 추천
- 친구 한 명과 금액이 아닌 습관 진행 비교
- 공동 미션, 스트릭, Money Level
- Rule Engine 방식의 AI Agent 피드백

## 실행

```bash
npm install
npm run dev
```

## MVP에서 의도적으로 제외한 것

- 계좌/카드 연동
- 실제 결제 내역 자동 수집
- OCR
- 금융상품 추천
- 친구와 금액 비교
- 모바일 앱 출시
