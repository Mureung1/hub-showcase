## 📌 1. 프로젝트 학습 목표
- **Frontend (화면)**: 사용자 인터페이스 제공 및 `fetch` API를 이용한 Backend 비동기 통신 학습
- **Backend (서버)**: API 라우팅 설계, 비즈니스 로직(가성비 검증) 처리, Database 제어(SQL 실행) 및 데이터 중개 역할 학습
- **Database (저장소)**: 관계형 데이터베이스 SQLite3 테이블 구조 이해 및 데이터 영구 저장(CRUD) 학습
