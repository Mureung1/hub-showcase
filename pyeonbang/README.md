# 편의점 식비·건강 구원 투수 : [편방]

## 2. 문제 정의 (Problem Statement)
* **지갑의 위기:** 고물가가 지속되고 가파른 배달비 상승으로 인해 대학생 및 자취생들의 한 끼 식비 부담이 극에 달함.
* **건강의 위기:** 비용을 아끼기 위해 편의점 식을 이용하지만, 복잡한 영양성분을 비교하기 어려워 영양 불균형(고나트륨, 고탄수화물)에 쉽게 노출됨.
* **유저의 페인 포인트:** 편의점 매대 앞에서 "도시락 단품을 먹을까? 라면에 삼각김밥으로 먹을까?" 고민할 때, 가격 대비 영양을 직관적으로 저울질해 줄 실질적인 기준이 부재함.

## 3. 핵심 타겟층
* 식비를 절약하면서도 최소한의 건강(식단)은 챙기려는 **실속파 자취생 및 대학생**
* 늦은 밤 배달 앱의 유혹 앞에서 지갑과 뱃살 때문에 흔들리는 **야식 고민족**
* 바쁜 일과 중 편의점에서 빠르고 편리하게 식사를 해결하고 싶은 **혼밥 중심의 식사족**

## 4. 핵심 기능 (MVP Specification)

### [1] 홈 화면 (트랙 분리)
* 진입 시 유저의 목적에 맞는 두 가지 장바구니 트랙 제공
    * ['식사 해결하기' 장바구니] (도시락, 컵라면, 김밥 등 식사류 조합)
    * ['간식/디저트' 장바구니] (음료, 과자, 크림빵 등 디저트류 조합)

### [2] 편의점 꿀조합 대결 (조합 VS 조합)
* **Multimodal AI API (OCR 기반) 실시간 분석:** 사전 제품 학습 없이, 촬영된 이미지 패키지에서 상품명, 가격, 영양 성분을 즉석 추출.
* 유저가 고민 중인 ['후보 A 조합'] vs ['후보 B 조합']을 1:1 카드 레이아웃으로 매칭하여 가격, 칼로리, 영양소 우위를 직관적으로 비교 대조.

### [3] 시간대별 2분할 가변형 코멘트 큐레이션
* ☀️ **일상 식사 모드 (04:31 ~ 21:29):** 평균적인 식당 외식 물가(제육볶음, 돈까스 등) 대비 비교하며 직관적인 [식비 세이브] 금액과 영양 우위 코멘트 제공.
* 🌙 **야식 방어 모드 (21:30 ~ 04:30):** 고비용 배달 음식(치킨, 피자 등) 가격과 비교하여 야식 유혹을 참아낸 성취감을 자극하는 위트 있는 팩트 폭행 코멘트 제공.

### [4] 직관적인 '편방 팩트 장부'
* 메인 화면 하단 '편방 완료!' 버튼을 누르면, 별도의 복잡한 인증 절차 없이 관심 기반으로 데이터가 누적 대시보드에 업데이트됨.
* 추상적인 게임 점수 대신 유저가 가장 직접적으로 체감할 수 있는 리얼 데이터 두 가지만 콤팩트하게 표기:
    * 💰 **누적 세이브 금액 (원)**
    * 🔥 **누적 세이브 칼로리 (kcal)**

## 5. 기술 스택 및 데이터 구조 (예정)
* **Frontend:** Vanilla JS / HTML5 / CSS3
* **AI Engine:** Multimodal AI API (Gemini Vision API 등 실시간 이미지 OCR 및 프롬프트 분석)
* **Data Storage:** 로컬스토리지 (LocalStorage)를 이용한 서비스 데이터 영구 보존 (초고속 MVP 구현 방식)
