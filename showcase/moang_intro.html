Project

Moang은 무엇인가요?

여러 개인 카페의 지류 스탬프 쿠폰을 하나의 모바일 웹에서 통합 관리할 수 있게 만든 서비스입니다. 고객은 스탬프와 쿠폰을 확인하고, 사장님은 매장 화면에서 고객을 조회해 스탬프를 적립합니다.

AI Collaboration

AI에게 맡긴 것이 아니라, AI와 일하는 방식을 만들었습니다.

문서로 범위를 고정하고, Agent가 그 안에서 움직이게 하기

Moang에서는 AI를 단순 코드 생성 도구로 쓰지 않았습니다. 먼저 제품 목적, 아키텍처, 개발 규칙, 체크리스트를 문서화하고, 매 작업마다 Agent가 그 기준을 참고하도록 만들었습니다.

Retrospective

아쉬운 점

이번 프로젝트에서는 Superpowers 플러그인에 많이 의존했습니다. 플러그인 안에 계획, 테스트, 개발, 검증에 필요한 스킬과 에이전트가 이미 준비되어 있었기 때문에, 직접 제품에 맞는 AI 작업 구조를 설계하며 능동적으로 활용한 부분은 충분하지 않았습니다.

프로젝트 규모가 작아 별도의 TDD 흐름을 깊게 적용하지 않았고, 보안 역시 RLS 설정처럼 필요한 부분은 챙겼지만 전문적인 보안 검토 워크플로우까지 만들지는 못했습니다.

Next Workflow

다음 프로젝트에서 개선하고 싶은 점

다음에는 개발 중인 프로덕트에 맞춰 직접 에이전트, 스킬, 훅을 만들어가며 AI를 더 광범위하고 복합적인 방식으로 사용하고 싶습니다. 단순히 AI에게 일을 맡기는 것이 아니라, 여러 AI 작업 단위를 내가 통솔하는 방식으로 프로젝트를 진행하는 것이 목표입니다.

특히 QA 에이전트, 보안 에이전트, 테스트 설계 에이전트처럼 역할이 분명한 AI들을 구성하고, TDD와 보안 점검까지 포함한 더 고도화된 AI 중심 개발 워크플로우를 만들고 싶습니다.
