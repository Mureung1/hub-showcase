# 데모용 Mock 데이터 — 1인분 밀키트 구독 서비스

영상 시연용으로 만든 가짜 인터뷰 데이터입니다. 개인정보 없이 임의로 작성했습니다.

## 사용 방법

1. 입력 페이지(`가설 입력 화면`)에서 아래 값을 그대로 입력합니다.
2. 인터뷰 전사문 3개는 각각 `.md` 파일 업로드 버튼으로 올리거나, 파일 내용을 textarea에 붙여넣습니다.
3. "AI 분석 시작" 클릭 후 대시보드/상세 화면에서 근거 드로어, 리파인, 버전 히스토리를 시연합니다.

## 입력값

- **프로젝트 제목**: `1인분 밀키트 구독 서비스 - 해지 원인 인터뷰`
- **문제 정의**: `demo_project.json`의 `problem_definition` 참고
- **추가 컨텍스트**: `demo_project.json`의 `additional_notes` 참고

### 가설
| # | 원인 | 결과 |
|---|---|---|
| 1 | 요일별 메뉴를 앱에서 최소 1주 전에 미리 확인할 수 있게 하면 | 메뉴가 취향에 안 맞아 해지하는 비율이 줄어 해지율이 낮아질 것이다 |
| 2 | 1인분 소포장 옵션을 2인분 옵션과 나란히 제공하면 | 손질/보관 부담이 줄어 재구매율이 높아질 것이다 |

### 인터뷰 (3명)
- `interview_01_kimjiyeon.md` — 김지연
- `interview_02_parkminsu.md` — 박민수
- `interview_03_leeseohyun.md` — 이서현

## 시연 포인트 (의도적으로 설계한 근거 패턴)

이 데이터는 세 인터뷰이가 서로 다른 입장을 갖도록 일부러 구성했습니다. 실제 분석 결과가 정확히 아래와 같이 나온다고 보장하지는 않지만(AI 판단이므로), 대략 이런 대비를 보여주기 위한 의도입니다.

- **가설 1 (메뉴 미리보기)**: 김지연은 강하게 지지(해지 결정적 이유), 박민수는 부차적이라고 언급, 이서현은 무관하다고 언급 → "근거 부족" 또는 "검토 필요" 정도로 나올 가능성이 높아 근거를 드로어에서 대조하는 장면을 보여주기 좋음.
- **가설 2 (1인분 소포장)**: 박민수는 강하게 지지(결정적 이유), 김지연·이서현은 "양은 문제 아니었다"고 명시적으로 반박 → **엇갈리는 근거**를 보여주기 좋아, "AI와 논쟁하며 리파인" 기능을 시연할 때 활용하기 좋습니다. (예: "박민수 발언만 근거로 삼은 것 아니냐"고 하이라이트 후 반박 프롬프트 입력)
- 이서현 인터뷰에는 두 가설과 무관한 발언(포장/시간 부족)이 섞여 있어, AI가 관련 없는 발언은 태깅하지 않는지 확인하는 용도로도 쓸 수 있습니다.

## 참고
- `demo_project.json`은 사람이 읽기 편하도록 구조만 정리한 참고용 파일입니다(전사문은 `transcript_file`로 분리 표기). 실제 API 요청 바디와 1:1로 맞추려면 각 `.md` 파일 내용을 `transcript` 필드에 합쳐 넣으면 됩니다.
