# gates

작업 완료 전 반드시 통과해야 하는 게이트다.

## 범위 게이트

- MVP 작업인지 Phase 2 작업인지 확인했다.
- 자동 리뷰 수집, 자동 답글 게시, 챗봇 알림, 멀티 플랫폼 확장을 임의로 추가하지 않았다.
- PRD와 다른 요구사항이면 사용자 확인 없이 제품 기준을 바꾸지 않았다.

## 안전 게이트

- 악성 의심 리뷰에 자동 답글을 만들지 않았다.
- 자동 신고, 자동 게시, 자동 법적 판단을 만들지 않았다.
- 보상·환불 약속을 자동 답글에 넣지 않았다.
- 확인되지 않은 사실을 단정하지 않았다.

## 법률·개인정보 게이트

- 법적 안내는 일반 정보로 제한했다.
- “법률 자문 아님” 고지를 필요한 화면에 유지했다.
- 닉네임, 주문 기록, 증거 파일 등 개인정보성 데이터는 최소 수집 원칙을 따른다.
- 자격증명 저장이나 플랫폼 자동화가 들어가면 별도 ADR이 필요하다.

## UI 게이트

- 한국어 존댓말을 사용했다.
- 다음 행동이 명확한 버튼으로 제공된다.
- 위험 상태는 색상과 텍스트를 함께 쓴다.
- 모바일에서 읽기 어려운 정보 밀도를 만들지 않았다.

## 테스트 게이트

- 정적 프로토타입 변경이면 브라우저에서 주요 앵커 이동을 확인한다.
- 로직 구현이면 단위 테스트 또는 최소 수동 검증 절차를 남긴다.
- 테스트를 실행하지 못했으면 이유를 최종 보고에 쓴다.

## 문서 게이트

- 기능 또는 정책이 바뀌었으면 관련 문서를 갱신했다.
- 작업 상태가 바뀌었으면 `TODO.md`와 `LOG.md`를 갱신했다.
- 새 결정을 했다면 ADR을 작성했다.
