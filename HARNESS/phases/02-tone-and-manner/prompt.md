# Phase 02 — 톤앤매너·매장 프로필 (PRD 2.2)

현재 step만 수행하고 `allowed_paths` 밖은 수정하지 않는다. 매장 프로필은 이후 답글 생성(Phase 03)과 문의 답변의 유일한 정보 출처가 되므로 데이터 계약을 명확히 한다. 이 Phase는 LLM을 호출하지 않는다(샘플 미리보기는 템플릿 기반).

## 공통 불변조건

- 프로필은 5개 그룹이다: 기본 정보, 답글 톤(말투/인사말/맺음말/이모지), 운영 정보, 이벤트(기간 포함), 금지 표현.
- 이벤트는 기간 만료 시 답글 근거에서 자동 제외된다. 이 규칙은 순수 TS 모듈로 두고 단위 테스트로 고정한다.
- 문의 답변의 근거는 운영 정보에 등록된 항목뿐이다. Phase 03이 이 규칙을 소비하므로 조회 시 등록/미등록을 구분할 수 있어야 한다.
- store_profiles 테이블은 RLS로 본인 매장 프로필만 읽고 쓸 수 있다.

## `store-profile-data`

`supabase/migrations`에 store_profiles 스키마+RLS를 추가하고, `frontend/src/features/store-profile`에 5개 그룹의 저장·조회·수정과 유효성 검사를 구현한다. 금지 표현 목록 관리와 만료 이벤트 자동 제외를 테스트로 고정한다.

## `settings-ui-preview`

⑦ 매장 설정 화면을 구현한다. 그룹별 섹션 배치, 저장, 선택한 톤·인사말·이벤트가 즉시 반영되는 샘플 답글 미리보기(템플릿 기반)를 포함한다. "답글 자동화 수준" 라디오 카드는 "Phase 2 예정" 칩과 함께 비활성 상태로만 배치한다.
