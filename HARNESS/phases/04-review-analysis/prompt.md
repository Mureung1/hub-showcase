# Phase 04 — 리뷰 분석 (PRD 2.4)

현재 step만 수행하고 `allowed_paths` 밖은 수정하지 않는다. 분석은 조회형 대시보드다. 정기 리포트 발송(푸시)은 제품 Phase 2이므로 만들지 않는다. 이 Phase는 LLM을 호출하지 않는다.

## 공통 불변조건

- 집계 4종: 긍정/부정/중립 비율(도넛), 주차별 평균 별점 추이(라인), 카테고리별 언급량·긍부정(막대), 메뉴별 핵심 키워드(태그). 집계는 Postgres 뷰/함수(`supabase/migrations`)로 구현한다.
- AI 인사이트 카드는 직전 동기간 대비 급변(예: 2배 이상) 감지 기반, 최대 3개. 감지는 순수 TS 결정적 규칙으로 구현하고 문구는 템플릿을 우선한다.
- 기간은 주간/월간/직접 선택.
- 콜드 스타트: 누적 리뷰 10건 미만이면 리포트 대신 안내 + 진행 표시를 보여주고 과거 리뷰 일괄 입력을 유도한다.
- 집계·조회도 RLS 안에서 본인 매장 데이터만 대상으로 한다.

## `analysis-engine`

`supabase/migrations`에 집계 뷰/함수를 추가하고 `frontend/src/features/review-analysis`에 조회·인사이트 감지·기간 필터를 구현한다. 경계값(10건 전후, 직전 동기간 데이터 없음, 리뷰 0건)을 테스트로 고정한다.

## `report-ui`

⑤ 분석 리포트 화면을 구현한다: 기간 선택, 도넛·라인·막대·키워드·인사이트 카드, 콜드 스타트 안내 상태, 기간 변경 시 전체 갱신.
