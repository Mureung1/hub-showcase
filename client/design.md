# Planning Web — UI/UX 디자인 문서

- 기술 스택: 순수 HTML, CSS (프레임워크/JS 없음)
- 반응형: 미지원 (고정 데스크톱 레이아웃, 기준 폭 1280px)
- 톤앤매너: 밝고 미니멀, 여백 중심, 굵은 타이포와 파스텔 핑크 포인트

---

## 1. 개요

할 일과 일정을 관리하는 플래닝 웹. 다음 3개 화면으로 구성한다.

1. 메인 화면 (대시보드) — 오늘의 요약, 빠른 진입점
2. 할 일 목록 — 태스크 추가/체크/분류
3. 캘린더 뷰 — 월간 일정 한눈에 보기

세 화면은 동일한 상단 네비게이션, 컬러/타이포 시스템을 공유한다.

---

## 2. 레퍼런스 분석 (HUSH 브랜드 사이트)

레퍼런스 이미지에서 가져올 핵심 무드:

- **화이트 베이스 + 핑크 블록**: 배경은 대부분 흰색, 특정 섹션만 큰 핑크색 블록으로 강조
- **굵고 큰 타이포**: 헤드라인은 두껍고 큰 산세리프, 자간 좁게
- **알약(pill) 버튼**: 모서리를 완전히 둥글린 버튼, 우측에 원형 화살표 아이콘 동반
- **라운드 카드**: 큰 radius를 가진 카드/이미지 프레임
- **여백 중심 레이아웃**: 콘텐츠 사이 넉넉한 여백, 섹션 구분이 색 블록으로 명확
- **작은 배지(badge)**: 캡슐 형태의 작은 라벨 (예: "ECO")
- **좌측 정렬 내비 + 중앙 로고**: 텍스트 링크 내비게이션, 중앙에 워드마크

이 무드를 플래닝 앱에 맞게 다음과 같이 치환한다:

- 상품 카드 → 할 일 카드 / 날짜 카드
- "NEW ARRIVALS" 핑크 블록 → "오늘의 할 일" / "이번 주 요약" 핑크 블록
- "ECO" 배지 → 카테고리 태그, 우선순위 배지
- "Learn more" 버튼 → "추가하기", "더보기" 등 알약 버튼

## 3. 컬러 팔레트

| 이름 | 역할 | HEX |
|---|---|---|
| Base White | 기본 배경 | `#FFFFFF` |
| Ink Black | 헤드라인, 강조 텍스트 | `#17171A` |
| Body Gray | 본문/보조 텍스트 | `#6B6B70` |
| Muted Gray | placeholder, 비활성 텍스트 | `#A7A7AC` |
| Primary Pink | 메인 포인트, 버튼, 강조 블록 | `#E38AA0` |
| Deep Pink | 버튼 hover, 강조 텍스트 | `#C96C83` |
| Soft Pink | 연한 배경, 태그, 카드 배경 | `#FBE6EC` |
| Line Gray | 구분선, 테두리 | `#ECECEE` |
| Success Green (완료 표시) | 체크 완료 상태 | `#7FBF8E` |

사용 원칙:
- 배경은 White 우선, 섹션 강조 시에만 Primary Pink 풀블록 사용 (레퍼런스의 "NEW ARRIVALS" 블록처럼 한 화면에 최대 1~2곳)
- 텍스트는 Ink Black / Body Gray 두 단계만 사용해 위계를 단순하게 유지
- Soft Pink는 카드 배경, hover, 오늘 날짜 강조 등 저채도 강조에 사용

## 4. 타이포그래피

| 용도 | 폰트(권장) | 굵기 | 크기 | 자간 |
|---|---|---|---|---|
| 대형 헤드라인 (예: "Today", "1월") | Pretendard 또는 시스템 Bold 산세리프 | 800 (ExtraBold) | 56–72px | -0.02em |
| 섹션 타이틀 | Pretendard | 700 (Bold) | 22–28px | -0.01em |
| 본문 / 리스트 텍스트 | Pretendard | 400–500 | 15–16px | normal |
| 보조/캡션 (날짜, 태그) | Pretendard | 500 | 12–13px | 0.02em, 대문자 시 사용 |
| 버튼 라벨 | Pretendard | 600 | 14px | normal |

- Pretendard가 없는 환경 fallback: `-apple-system, "Segoe UI", "Noto Sans KR", sans-serif`
- 레퍼런스처럼 초대형 헤드라인은 이미지/일러스트와 겹쳐도 좋으나, 본 프로젝트는 텍스트 정보 밀도가 높으므로 겹침 연출은 메인 화면 상단 인사말(예: "Hi, 오늘도 화이팅")에만 제한적으로 사용

## 5. 레이아웃 & 그리드

- 기준 캔버스: 1280px 고정 폭, 중앙 정렬, 좌우 여백 64px
- 12컬럼 그리드, 컬럼 gap 24px
- 섹션 간 수직 여백: 80px (대), 40px (중), 24px (소)
- 카드 radius: 24px (대형 블록), 16px (일반 카드), 999px (알약 버튼/배지)
- 그림자: `box-shadow: 0 8px 24px rgba(23,23,26,0.06)` — 은은하게, 카드에만 사용

## 6. 공통 컴포넌트

### 6.1 상단 네비게이션
- 좌측: 로고 텍스트 (예: "PLAN.") — Ink Black, Bold
- 중앙 또는 좌측 이어서: 메뉴 링크 3개 — `메인` / `할 일` / `캘린더` (현재 페이지는 Primary Pink + 옆에 작은 점)
- 우측: "+ 새 할 일" 알약 버튼 (Primary Pink 배경, White 텍스트)
- 배경 White, 하단 1px Line Gray 구분선, 높이 80px

### 6.2 알약 버튼 (Pill Button)
- 기본형: White 배경 + Ink Black 텍스트 + 1px Line Gray 테두리, 우측에 원형 화살표 아이콘(→)
- 강조형: Primary Pink 배경 + White 텍스트, 아이콘 원은 White 배경에 Pink 화살표
- radius 999px, 좌우 padding 20px, 상하 padding 10px, hover 시 Deep Pink로 배경 전환

### 6.3 배지 / 태그
- 캡슐형, Soft Pink 배경 + Deep Pink 텍스트, 12px, 좌측에 작은 아이콘(●) 선택적
- 우선순위: 높음(Primary Pink), 보통(Muted Gray 배경), 낮음(Line Gray 배경)

### 6.4 체크박스 (할 일)
- 원형 체크박스, 미완료 시 1.5px Line Gray 테두리 + White
- 완료 시 Success Green 배경 + White 체크 아이콘, 텍스트에 취소선 + Muted Gray 색상 전환

### 6.5 카드
- White 배경, radius 16px, 얇은 Line Gray 테두리 또는 은은한 그림자
- 카드 내부 padding 20–24px

## 7. 화면 1 — 메인 화면 (대시보드)

레퍼런스의 히어로 섹션(대형 타이포 + 이미지) + "NEW ARRIVALS" 핑크 블록 구조를 차용.

```
┌───────────────────────────────────────────────────────┐
│  PLAN.        메인  할 일  캘린더            [+ 새 할 일]│  ← 상단 내비
├───────────────────────────────────────────────────────┤
│                                                         │
│   안녕하세요 👋                     7월 9일 목요일        │
│   오늘도 계획대로,                   오늘 할 일 4개 중 1개│
│   화이트/블랙 초대형 타이포            완료                │
│                                                         │
│   [ 할 일 보러가기 → ]   [ 캘린더 보기 → ]                │
│                                                         │
├───────────── (Primary Pink 풀블록 섹션) ─────────────────┤
│   오늘의 할 일                                     [전체보기]│
│   ┌───────────┐ ┌───────────┐ ┌───────────┐          │
│   │ ○ 배지     │ │ ○ 배지     │ │ ✓ 배지     │  (White  │
│   │ 태스크명    │ │ 태스크명    │ │ 태스크명    │   카드,  │
│   │ 시간/태그   │ │ 시간/태그   │ │ 시간/태그   │   핑크 배경│
│   └───────────┘ └───────────┘ └───────────┘   위에 얹힘)│
├───────────────────────────────────────────────────────┤
│  이번 주 진행률                    이번 달 요약           │
│  (도넛/바 형태의 단순 CSS 그래프)     완료 12 · 진행 3 · 예정5 │

- 상단 히어로: 좌측에 인사말 + 초대형 타이틀(Ink Black), 우측 상단에 오늘 날짜 + 진행 요약을 작은 텍스트로 배치 (레퍼런스의 "your choice" 대형 텍스트 대응)
- 히어로 하단에 알약 버튼 2개로 할 일/캘린더 화면 진입
- "오늘의 할 일" 섹션은 Primary Pink 풀블록 배경 위에 White 카드 3~4개를 얹어 레퍼런스의 "NEW ARRIVALS" 카드 캐러셀 톤을 재현 (실제 캐러셀 기능 없이 정적 3~4개 노출)
- 하단은 White 배경으로 돌아와 진행률 요약을 2컬럼으로 배치

## 8. 화면 2 — 할 일 목록

```
┌───────────────────────────────────────────────────────┐
│  PLAN.        메인  할 일  캘린더            [+ 새 할 일]│
├───────────────────────────────────────────────────────┤
│  할 일 목록                                              │
│  전체(12)  진행중(3)  완료(9)     [ 전체 ▾ ][ 오늘 ▾ ]     │  ← 필터 탭 + 정렬(pill)
├───────────────────────────────────────────────────────┤
│  ○  운동하기                    #건강   오전 7:00        │
│  ○  기획서 초안 작성              #업무   오후 2:00        │
│  ○  장보기                      #개인   오후 6:00        │
│  ✓  이메일 회신                  #업무   완료             │  ← 취소선, Muted Gray
├───────────────────────────────────────────────────────┤
│  + 새 할 일 추가... (입력 필드, 항상 리스트 하단 고정)      │
└───────────────────────────────────────────────────────┘
```

- 각 항목은 얇은 Line Gray 구분선을 가진 리스트 행 (카드가 아닌 리스트 스타일로 밀도 확보)
- 좌측 원형 체크박스 → 태스크명(Ink Black, 완료 시 Muted Gray+취소선) → 우측 정렬로 태그 배지 + 시간
- 상단 필터는 텍스트 탭(현재 탭은 Ink Black+하단 Primary Pink 밑줄, 비활성은 Muted Gray), 정렬/기간 선택은 작은 알약 드롭다운
- 리스트 최하단에 인풋 형태의 "새 할 일 추가" 행을 고정 배치 (별도 모달 없이 인라인 추가)
- 빈 상태: 리스트가 없을 때 중앙에 Soft Pink 원형 아이콘 + "오늘은 할 일이 없어요" 문구 + 추가 버튼

```

│  일   월   화   수   목   금   토                         │

│ │   │   │   │●●│   │●  │   │     원형 배경, 날짜 아래 ●는│
│ ├───┼───┼───┼───┼───┼───┼───┤     할 일 개수 dot        │

- 달력 셀: 7열 그리드, 정사각형에 가까운 비율, 셀 사이 얇은 Line Gray 구분선 (테두리 없는 표 형태)
- 오늘 날짜: Primary Pink 원형/라운드 배경 + White 숫자
- 일정이 있는 날짜: 숫자 아래 작은 dot (최대 3개, 4개 이상은 "+N") — dot 색상은 Deep Pink
- 선택된 날짜: Soft Pink 배경으로 셀 강조 (오늘과는 다른 톤으로 구분: 오늘=꽉 찬 핑크 원, 선택=옅은 핑크 배경)
- 하단에는 선택한 날짜의 할 일을 화면 2와 동일한 리스트 스타일로 노출 (컴포넌트 재사용)
- 상단 우측 "월/목록" 토글은 알약 버튼 그룹으로, 목록 모드는 화면 2 스타일 재사용 가능 (본 문서에서는 월간 뷰를 기본으로 정의)

## 10. 아이콘 & 일러스트 가이드

- 별도 이미지 에셋 없이 CSS 도형(원, 배지, 화살표)만으로 구성 — 순수 HTML/CSS 제약에 맞춤
- 화살표 아이콘: `→` 문자 또는 CSS로 그린 화살표를 원형 배경 안에 배치
- 체크 아이콘: 완료 시 CSS `::after`로 체크 모양(두 개의 회전된 선) 또는 유니코드 `✓` 사용
- 인사말 이모지(👋 등)는 시스템 이모지 폰트로 대체 가능 (이미지 에셋 불필요)

## 11. 파일 구조 제안

```
/
├── design.md          (본 문서)
├── index.html          (메인 화면)
├── todo.html           (할 일 목록)
├── calendar.html        (캘린더 뷰)
└── css/
    ├── base.css         (리셋, 컬러/타이포 변수, 공통 레이아웃)
    ├── components.css   (버튼, 배지, 카드, 체크박스, 내비 등 공통 컴포넌트)
    ├── main.css         (메인 화면 전용)
    ├── todo.css         (할 일 목록 전용)
    └── calendar.css      (캘린더 전용)
```

- `base.css`에 CSS 커스텀 프로퍼티로 컬러 팔레트(3장) 정의 후 전 페이지에서 `var(--primary-pink)` 형태로 재사용
