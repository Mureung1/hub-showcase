# Client 디렉토리

이 디렉토리는 서비스의 프론트엔드(클라이언트) 소스 코드가 포함된 공간입니다.

## 역할 및 기능
- **Vite & React**: 빠른 개발 환경과 효율적인 렌더링을 제공하는 React 프레임워크 기반으로 구성되어 있습니다.
- **JavaScript**: 빠르고 유연한 프론트엔드 개발을 지원합니다.
- **프로젝트 구성**:
  - `src/`: 실제 프론트엔드 소스 코드가 위치하는 디렉토리입니다.
  - `vite.config.ts`: Vite 설정 파일입니다.
  - `tsconfig.json`: TypeScript 설정 파일입니다.
  - `package.json`: 프론트엔드 라이브러리 및 의존성, 실행 스크립트가 정의되어 있습니다.

## 실행 및 빌드 방법
- 의존성 설치: `npm install`
- 로컬 개발 서버 실행: `npm run dev`
- 프로덕션 빌드: `npm run build`
