# client/src/stores

이 디렉토리는 애플리케이션의 클라이언트 전역 상태(Global State)를 관리하는 스토어들이 위치하는 곳입니다.

## 역할 및 설계 방향
- `authStore.ts`: 유저의 로그인 여부, 가상/실제 유저 인적 정보(이름, 학과, 학년 등)를 보관하여 애플리케이션 전체 컴포넌트에서 활용할 수 있게 합니다.
- **인증 연동 계획**: 초기 가상 유저 테스트 시 가짜 데이터를 이 스토어에 보관하여 쓰고, 나중에 로그인 API가 구현되면 백엔드로부터 받아온 실제 유저 데이터로 상태를 갱신하도록 처리합니다.
