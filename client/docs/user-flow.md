# Frontend User Flow

## 기준

- 대상은 PC 웹 MVP다.
- 상위 로드맵은 GitHub Wiki의 [Frontend Priority Roadmap](https://github.com/Tapha-K/hub/wiki/Frontend-Priority-Roadmap)을 기준으로 한다.
- 이 문서는 Wiki P0/P1 범위를 화면 단계 단위로 상세화한다.
- 제품 본질은 `짧게 시작 -> 정해진 시간 동안 읽기 -> 끝난 직후 기록 -> 내 기록에서 다시 읽기` 루프다.
- P0/P1은 백엔드 없이 `localStorage`로 닉네임, 방, 세션, 완료 기록을 유지한다.
- 빠른 시작 템플릿은 방 상세를 `시작 전 확인` 화면으로 먼저 보여준 뒤 세션을 시작한다.
- 세션은 타이머가 끝난 뒤 `기록 작성하기` CTA가 활성화된다.
- `readyToRecord`는 내부 상태명이고, 사용자 화면에서는 `기록 대기`로 표시한다.
- 완료 기록은 책 제목, 시작 페이지, 끝 페이지, 감상을 모두 필수로 받는다.
- `14일 내 3회 세션` 목표는 `source = user`이고 `session.status = completed`인 기록만 계산하며 샘플은 제외한다.
- 모바일 반응형, 실시간, 외부 도서 검색, 신뢰도/추천 고도화는 MVP 이후로 둔다.

## 문서 관계

- 제품 본질, MVP 범위, 용어, 목표 지표, 데이터 정책은 `client/docs/product-prd.md`에서 관리한다.
- 이 문서는 전체 사용자 플로우를 화면 단계 단위로 정리한다.
- 화면별 클릭, 모달, 상태 변화는 `client/docs/click-unit-ui-spec.md`에서 관리한다.
- 컴포넌트별 책임, props, state, handler 후보는 `client/docs/component-implementation-notes.md`에서 관리한다.
- 설계 토론 근거는 `client/docs/archive/agent-discussion-summary.md`에 보관한다.
- UX 위험 검토는 `client/docs/archive/ux-friction-review.md`에 보관한다.
- 핵심 루프의 화면 연결은 [`client/prototype/index.html`](../prototype/index.html) 정적 프로토타입에서 먼저 확인한다.

## 전체 흐름

```text
온보딩
-> 방 목록
-> 빠른 시작 또는 방 생성
-> 방 상세
-> 세션 타이머
-> 완료 기록
-> 내 기록
-> 방 목록 또는 다시 읽기
```

보조 복귀 흐름은 다음과 같다.

```text
세션 타이머 종료
-> 기록 대기
-> 방 목록 또는 내 기록
-> 완료 기록
-> 내 기록
```

## 1. 온보딩

### 사용자 의도

- 서비스를 처음 이해하고 빠르게 독서 세션을 시작하고 싶다.
- 정식 회원가입 없이 닉네임만으로 시연 흐름에 들어가고 싶다.

### 표시 요소

- 서비스 핵심 설명
- `14일 내 3회 세션` 목표 안내
- 닉네임 입력 필드
- `시작하기` CTA
- `샘플 데이터로 둘러보기` CTA
- `데이터 초기화` CTA

### 다음 흐름

- 닉네임 입력 후 시작하면 방 목록으로 이동한다.
- 샘플 데이터로 둘러보기를 누르면 샘플 방과 샘플 기록을 만든 뒤 방 목록으로 이동한다.

### 상태 변화

- `user.nickname` 저장
- `hasOnboarded = true`
- 샘플 선택 시 `rooms`, `sessions`, `readingRecords` 초기 데이터 생성

## 2. 방 목록

### 사용자 의도

- 지금 들어갈 수 있는 독서방을 찾거나, 빠른 시작으로 바로 흐름을 만들고 싶다.

### 표시 요소

- 빠른 시작 CTA
- 방 만들기 CTA
- 내 기록 CTA
- 방 카드 목록
- 빈 상태 안내
- 샘플 데이터 생성 CTA
- 데이터 초기화 CTA

### 방 카드 표시 정보

- 방 제목
- 설명
- 세션 시간
- 토론 여부
- 입문자 환영 여부
- 누적 참여 수
- 최근 완료 기록
- 방 감상 수

### 다음 흐름

- 빠른 시작을 누르면 빠른 시작 템플릿 화면으로 이동한다.
- 방 만들기를 누르면 방 생성 화면으로 이동한다.
- 방 카드를 누르면 방 상세 화면으로 이동한다.
- 내 기록을 누르면 내 기록 화면으로 이동한다.

### 상태 변화

- 기본적으로 조회 중심이다.
- 진행 중 세션이 있으면 복귀 CTA를 표시할 수 있다.
- 기록 대기 세션이 있으면 기록 작성 CTA를 표시할 수 있다.

## 3. 빠른 시작

### 사용자 의도

- 조건을 많이 고르지 않고 정해진 템플릿으로 바로 독서방을 시작하고 싶다.

### 표시 요소

- `30분 조용히 읽기`
- `15분 짧게 시작`
- `토론 없이 한 줄 감상`
- `입문자 환영 방`

### 다음 흐름

- 템플릿을 누르면 해당 조건의 방 상세 화면으로 이동한다.
- 타이머로 바로 이동하지 않는다.

### 상태 변화

- 템플릿 기반 방을 생성하거나 선택 상태를 구성한다.
- 생성된 방은 즉시 시작 가능한 방으로 취급한다.

## 4. 방 생성

### 사용자 의도

- 원하는 제목, 설명, 시간, 분위기의 독서방을 직접 만들고 싶다.

### 표시 요소

- 제목 입력
- 설명 입력
- 세션 시간 선택: 15분, 30분, 60분
- 토론 여부 선택
- 입문자 환영 여부 선택
- 방 만들기 CTA
- 취소 CTA

### 다음 흐름

- 유효한 입력으로 방을 만들면 생성된 방 상세 화면으로 이동한다.
- 취소하면 방 목록으로 돌아간다.

### 상태 변화

- `rooms`에 새 방 추가
- 생성자를 현재 사용자로 저장
- 누적 참여 수, 최근 완료 기록, 감상 수는 초기값으로 저장

## 5. 방 상세

### 사용자 의도

- 방의 성격과 세션 조건을 확인한 뒤 실제로 시작할지 결정하고 싶다.

### 표시 요소

- 방 제목
- 빠른 시작 유입 시 `시작 전 확인` 안내
- 방 설명
- 세션 시간
- 토론 여부
- 입문자 환영 여부
- 누적 참여 수
- 최근 완료 기록
- 방 감상 수
- 세션 시작 CTA
- 빠른 시작 유입 시 템플릿 결과와 연결된 CTA 예: `30분 읽기 시작`
- 목록으로 CTA

### 다음 흐름

- 세션 시작을 누르면 세션 타이머 화면으로 이동한다.
- 목록으로를 누르면 방 목록으로 돌아간다.

### 상태 변화

- 세션 시작 시 현재 방 기준 `session`을 생성한다.
- `session.status = active`
- `leaveCount = 0`
- `startedAt`, `endsAt` 저장

## 6. 세션 타이머

### 사용자 의도

- 정해진 시간 동안 방해 없이 읽고, 끝난 뒤 기록을 남기고 싶다.

### 표시 요소

- 큰 타이머
- 방 제목
- 세션 시간
- 남은 시간
- 이탈 횟수
- 이탈 경고
- 기록 작성하기 CTA
- active 상태의 `세션 나가기` CTA
- 기록 대기 상태의 `기록 나중에 작성` CTA

### 다음 흐름

- 타이머가 끝나면 `기록 작성하기` CTA가 활성화된다.
- `기록 작성하기` CTA를 누르면 완료 기록 화면으로 이동한다.
- 이탈 기록을 누르면 이탈 확인 모달을 연다.

### 상태 변화

- 진행 중: `session.status = active`
- 타이머 종료: `session.status = readyToRecord`
- 이탈 확정: `session.status = abandoned`, `leaveCount += 1`
- 사용자 노출 상태명: `readyToRecord`는 `기록 대기`

## 7. 완료 기록

### 사용자 의도

- 방금 읽은 책과 페이지, 짧은 감상을 기록하고 싶다.

### 표시 요소

- 세션 요약
- 책 제목 입력
- 시작 페이지 입력
- 끝 페이지 입력
- 감상 입력
- 저장 CTA
- 필수값 오류
- 페이지 범위 오류

### 다음 흐름

- 저장에 성공하면 내 기록 화면으로 이동한다.
- 오류가 있으면 현재 화면에 머물며 필드별 메시지를 보여준다.

### 상태 변화

- `readingRecords`에 기록 추가
- `session.status = completed`
- 방의 누적 참여 수, 최근 완료 기록, 감상 수 갱신

## 8. 내 기록

### 사용자 의도

- 내가 얼마나 읽었고 어떤 감상을 남겼는지 확인하고 싶다.

### 표시 요소

- `14일 내 3회 세션` 목표 진행률
- 완료 세션 수
- 최근 기록 목록
- 책 제목
- 페이지 범위
- 감상
- 방 목록으로 CTA
- 다시 읽기 CTA

### 다음 흐름

- 방 목록으로를 누르면 방 목록으로 이동한다.
- 다시 읽기를 누르면 해당 기록과 같은 조건의 방 상세 또는 빠른 시작 기반 방 상세로 이동한다.

### 상태 변화

- 기본적으로 조회 중심이다.
- 다시 읽기를 누르면 새 방 또는 새 세션 준비 상태를 만들 수 있다.
