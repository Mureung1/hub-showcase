# Phase 0 글귀 재개 루프 사용성 테스트

이 테스트는 수요나 장기 재방문을 증명하지 않는다. 사용자가 안내 없이 `독서 종료 → 글귀 저장 → 다시 노출된 글귀 → 출처 책 → 이어서 읽기`를 완료할 수 있는지만 확인한다.

## 실행

```bash
cd client
npm run prototype:quote-loop
```

- 참여자 화면: `http://127.0.0.1:5173`
- 상태 확인이 필요한 사전 점검: `http://127.0.0.1:5173/?moderator=1`
- 입력은 메모리에만 있으며 새로고침하면 초기화된다.

## 참여자

- 동시에 여러 권의 종이책을 읽는 사람 5명
- 별도 독서 기록 습관이 강하지 않은 사람을 우선
- 프로젝트 제작자는 통과 인원에 포함하지 않음

## 준비

1. 참여자에게 화면을 보여주기 전에 “최근 읽은 책에서 도움이 됐던 문장 하나를 떠올려 달라”고만 말한다.
2. 프로토타입의 책은 테스트 편의를 위해 `데미안`, 시작 상황은 84쪽 이후로 고정됐다고 설명한다.
3. 버튼이나 입력란의 용도, 오른쪽 글귀 영역, 목표 경로는 설명하지 않는다.
4. 참여자의 말과 클릭을 기록하되 막히기 전까지 개입하지 않는다.

## 진행 문구

### 과업 1 — 독서 마무리

> 데미안을 오늘 96쪽까지 읽었다고 생각해 주세요. 방금 떠올린 문장이 이 책에서 나온 문장이라고 가정하고, 이 화면에서 독서를 마무리해 주세요.

관찰할 것:

- `남기고 싶은 문장`을 별도 지시 없이 발견하는가
- 실제 문장을 입력하는가
- 선택 사항이라는 문구가 입력을 포기하게 만드는가
- 저장 결과를 이해하는가

문장을 입력하지 않고 저장하면 실패로 기록하되, 다시 하도록 유도하지 않는다.

### 과업 2 — 다시 방문

저장 완료 뒤 다음 문장만 말한다.

> 며칠 뒤 다시 서재에 들어왔다고 생각하고, 화면을 계속 사용해 주세요.

관찰할 것:

- 다시 만난 문장을 발견하는가
- 출처가 `데미안`임을 이해하는가
- `이 책 다시 열기`를 선택하는가
- 펼쳐진 화면에서 현재 페이지와 다음 행동을 이해하는가
- `이어서 읽기`까지 완료하는가

책등의 `데미안`을 직접 누른 경우 기능 완료와 별개로 “글귀 기반 재개 실패”로 기록한다.

## 개입 규칙

- 10초 이상 멈추면 “지금 무엇을 찾고 계세요?”라고만 묻는다.
- 30초 이상 진행하지 못하면 과업 실패로 기록하고 다음 화면으로 이동할 수 있다.
- 버튼 위치나 정답 경로를 알려주지 않는다.
- 오류나 데이터 손실이 발생하면 즉시 중단하고 재현 단계를 기록한다.

## 통과 기준

- 5명 중 4명이 과업 1과 과업 2를 모두 도움 없이 완료
- 데이터 손실 또는 진행 불가 오류 0건
- 이 기준은 사용성 통과이며 제품 수요의 증거로 사용하지 않음
