# 👗 Pick My Clothes

> **상황 맞춤 옷 코디 추천 AI Agent**

AI Agent 서비스 개인 프로젝트

약속에 나가기 전 "뭐 입지?" 고민하다 늦어본 경험, 있으신가요?  
**Pick My Clothes**는 사용자의 **옷장**, **오늘의 상황(장소·일정·날씨)**, **대화**를 AI Agent가 분석해 빠르게 코디를 추천하는 서비스입니다.

---

## 🎯 해결하는 문제

> **"약속에 나가기 전, 무엇을 입을지 고민하다가 약속에 늦은 적이 있다."**

| 원인 | 설명 |
|------|------|
| 선택 과부하 | 옷은 많지만 상황에 맞는 조합을 떠올리기 어렵다 |
| 상황-옷 매칭 부재 | 회의, 데이트, 친구 모임마다 적합한 스타일이 다르다 |
| 날씨·장소 미반영 | 날씨와 장소를 고려하지 않아 다시 갈아입느라 시간을 낭비한다 |
| 시간 압박 | 출발 직전에 결정해야 해서 고민 시간이 길어지고 지각한다 |

**Pick My Clothes**는 "무엇을 입을지" 고민하는 시간을 줄여, **상황에 맞는 코디를 빠르게 결정**할 수 있도록 돕습니다.

---

## ✨ 핵심 기능

### 1. 상황 기반 코디 추천
장소, 상황(목적), 날씨를 입력하면 AI Agent가 그에 맞는 코디 2~3개를 추천합니다.  
예: *"강남 / 회의 / 흐림 18°C"* → 블라우스 + 슬랙스 + 가디건

### 2. 내 옷장 기반 추천
사용자가 업로드한 **실제 보유 의류**만으로 코디를 구성합니다.  
AI가 카테고리·색상·스타일을 자동 태깅하고, **지금 바로 입을 수 있는** 조합을 제안합니다.

### 3. AI Agent 대화형 추천
단순 버튼 클릭이 아니라 Agent와 대화하며 상황을 확인하고, 코디와 추천 이유를 설명받습니다.

### 4. 새 옷 포함 코디 + 구매 링크
미래 약속 코디를 미리 계획할 때 **"새로운 옷"** 버튼으로 옷장에 없는 아이템을 포함한 코디를 추천하고, 구매 링크를 함께 제공합니다.

### 5. 대화형 코디 피드백
이미 정한 코디(또는 일부)에 대해 자연어로 질문하면, Agent가 부족한 아이템만 추천합니다.

- **옷장 리마인드** — 업로드해 둔 옷 사진을 다시 보여줘 구매 없이 코디 완성
- **쇼핑 링크** — 옷장에 없을 때 추천 아이템 구매 링크 제공

> 예: *"오늘 블라우스에 치마 입을 건데, 신발을 뭐 신을지 모르겠어"*  
> → *"블라우스와 치마 조합이면 메리제인 구두나 로퍼가 잘 어울릴 것 같아요."* + 옷장 신발 사진 or 쇼핑 링크

## 🧭 사용자 시나리오

### 시나리오 A — 오늘 나갈 때 (내 옷장 기반)

```
고민 → 서비스 접속 → 상황 입력 → 옷장 확인 → AI 코디 추천 → 코디 결정
```

1. 약속 전 "뭐 입지?" 고민
2. Pick My Clothes 접속
3. **장소·상황·날씨** 입력 (또는 프리셋 선택: 회의 / 데이트 / 친구 모임 등)
4. (최초 1회) 옷장에 옷 사진 업로드
5. AI Agent가 **내 옷장**에서 2~3개 코디 추천
6. 코디 선택 후 출발

### 시나리오 B — 미래 코디 계획 (새 옷 포함)

```
미래 약속 계획 → 상황 입력 → "새로운 옷" 버튼 → AI 코디 + 구매 링크 → 쇼핑 or 저장
```

1. 다음 주 데이트 등 미래 약속 코디를 미리 정하고 싶음
2. 장소·상황·날씨 입력
3. **"새로운 옷"** 버튼 클릭
4. 기존 옷 + **구매 필요 아이템** 포함 코디 추천
5. 쇼핑 링크로 이동 or 코디 저장

### 시나리오 C — 대화형 코디 피드백

```
코디 일부 결정 → Agent에게 질문 → AI 피드백 → 옷장 리마인드 or 쇼핑 링크 → 최종 결정
```

1. 상·하의는 정했지만 신발·가방·아우터 등이 고민
2. Agent 채팅에 자연어로 질문
3. Agent가 어울리는 아이템 추천 + 선택 이유 설명
4. **내 옷장**에 있으면 사진 리마인드 / 없으면 쇼핑 링크
5. 대화로 코디 확정
