# 🅿️ ChaSeWar (차세워)
> 주차 전쟁에서 한 발 앞선 선택을 돕는 서비스
> 
> 서울시 공영주차장의 위치·요금·운영시간과 **실시간 주차 가능 대수**를 한눈에

## 📌 소개

목적지 근처에 어떤 공영주차장이 있고 **지금 자리가 있는지**를 미리 확인할 수 있는 웹앱입니다.
운전자가 주차 공간을 찾는 시간을 줄이고, 비싼 사설 주차장 대신 저렴한 공영주차장을 우선 고려할 수 있도록 돕습니다.

📋 **[프로젝트 기획서](https://github.com/geunnseung/hub/wiki/ChaSeWar-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EA%B8%B0%ED%9A%8D%EC%84%9C)**

## ✨ 주요 기능 (MVP)

- **동(洞) 기준 주차장 탐색** — 목적지 인근 동을 기준으로 공영주차장 목록을 좁혀 탐색
- **주차장 상세 정보** — 요금·운영시간·주소 등 선택에 필요한 정보 제공
- **실시간 주차 가능 대수** — 실시간 데이터가 제공되는 주차장의 현재 가용 대수 표시

> 🔜 확장 예정: 목적지 주변 거리순 추천, 지도 기반 검색
