# 미리캣

미어캣 무리는 보초를 세운다. 한 마리가 망을 보는 동안 나머지는 각자 일을 한다. 미리캣은 내 출근길의 보초다 — 흩어진 게시판의 통제·우회 공지를 매일 대신 확인하고, 이상 없으면 한 줄 보고, 영향이 있을 때만 근거가 담긴 경보를 보낸다.

## 프로젝트 기획

### 문제 정의

축제·공사·사고로 대중교통 노선이 변경되거나 도로가 통제되면 지자체·버스조합 게시판에 공지가 올라오지만, 공지는 한 번 게시되고 다시 노출되지 않는다. 공지가 올라오는 시점과 그 정보가 필요한 시점(이동 직전)이 어긋나 있고 소스도 여러 게시판에 흩어져 있어, 이용자는 공지가 존재했음에도 예고 없는 지연을 겪는다. 실제로 2026년 3월 갑천도시고속도로 원촌육교가 지반침하로 긴급 통제되어 B1이 우회 운행했지만, 이 사실은 대전시 공지 게시판에만 안내됐다.

### 사용자 시나리오

1. 사용자가 고정 경로를 한 번 등록한다 (출발지·도착지·시간대 → 경로 후보 중 평소 다니는 길 선택).
2. 에이전트가 매일 해당 경로의 관할 소스(시 공지, 버스조합, 주변 시설 이벤트 일정)를 조사한다.
3. 이상 없는 날은 디스코드로 확인 보고 한 줄이 온다 — "출근 경로 이상 없음 · 확인: 대전시 공지, 버스조합, KBO (06:30)".
4. 영향 공지를 발견하면 경보가 온다 — "갑천도시고속도로 전면 통제 (3.30~4.3), B1 우회 · 출처: 대전시 공지".
5. 경보의 링크를 열면 브리핑 리포트에서 영향 구간 지도, 영향권 밖 대안 경로, 에이전트의 조사 과정(trace), 공지 원문 링크를 확인할 수 있다.
6. 사용자는 이 정보를 참고해 경로와 출발 시간을 결정한다.

### 사용자 흐름

```
경로 등록 (1회)
   └→ 매일 자동 조사: Planner → Scout ⇄ Verifier → Analyst → Reporter
        ├─ 영향 없음 → 확인 보고 한 줄 (확인 소스 + 시각)
        └─ 영향 발견 → 경보 → 브리핑 리포트 (지도·대안·trace·원문)
```

### 핵심 기능 (2개)

- **기능 A — 조사 에이전트 (LangGraph)**: 경로가 주어지면 조사 계획을 스스로 세우고(Planner), 게시판을 탐색해 비정형 공지에서 구조화 정보를 추출하며(Scout), 추출 결과를 원문과 대조 검증한다(Verifier, 실패 시 재추출 루프). 전 과정이 Langfuse에 트레이싱되고, 공지 평가셋으로 추출 정확도를 회귀 테스트한다.
- **기능 B — 경로 매칭 + 신호 무게 분리 알림**: 추출 정보를 경로 객체와 4단계(노선 → 정류장 → 도로명 → 반경)로 매칭해 영향을 판정한다. 예측은 하지 않고 공지된 사실과 경로의 겹침만 전달하며, 확인 보고는 매일 조용한 한 줄로, 경보는 임계값을 넘을 때만 무겁게 보낸다.
