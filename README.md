# 답냥이

대학생이 꺼내기 어려운 메시지를 관계와 상황에 맞춰 빠르게 작성하도록 돕는 서비스입니다.

## 핵심 경험

1. 답장 / 먼저 연락을 고릅니다.
2. 관계(팀플·조모임, 교수님·조교님, 선배·동기, 친구·연인)를 고릅니다.
3. 자주 쓰는 상황 카드를 고르면 검수된 3톤 템플릿을 즉시 복사합니다.
4. 카드에 없는 복합 상황만 목적과 맥락을 입력해 AI 생성 경로로 보냅니다.

## 왜 모든 요청을 AI로 처리하지 않나요?

답냥이는 정형 상황과 복합 맥락을 구분하는 하이브리드 구조를 사용합니다.

| 경로 | 처리 | 장점 |
|---|---|---|
| 상황 카드 | 로컬 템플릿 | API 호출 없이 즉시 응답, 비용 0, 검수된 문구 품질 |
| 다른 상황이냥 | 구조화된 AI 생성 | 받은 메시지·감정·관계를 함께 반영한 맞춤 후보 |

AI는 카드로 해결할 수 없는 구체적 맥락에서만 가치를 만듭니다. 한 번의 AI 요청으로 기본/더 부드럽게/더 분명하게 후보 3개를 받아 사용자가 직접 고르게 합니다.

## AI 설계

- 공용 요청·응답 계약과 런타임 검증으로 후보 수, 톤 순서, 빈 문장, 과도한 길이, 명백한 공격 표현을 방어합니다.
- 모델은 톤 레벨과 문장만 반환하고, UI 라벨은 서비스가 고정 규칙으로 부여합니다.
- 관계·목적·안전·few-shot·출력 스키마를 조합하는 서버 전용 프롬프트 빌더를 설계했습니다.
- 교수님·조교님·선배·친구 관계의 평가 케이스를 코드로 관리합니다.
- 입력 원문은 서버·분석 이벤트에 저장하지 않으며, 탭 복원용 임시 보관은 30분 만료와 즉시 삭제를 제공합니다.

현재 직접입력 AI 경로는 외부 API 연결 전의 개발용 목 응답입니다. 실제 provider 호출은 아직 하지 않으며, 이후 Vercel 서버리스 함수 `/api/generate`에서만 연결합니다.

상세한 선택 근거와 실패·비용·개인정보 정책은 [AI 설계 노트](docs/AI_DESIGN.md)에서 확인할 수 있습니다.

## 개발

```bash
npm install
npm run dev
```

검증 명령:

```bash
npm test
npm run lint
npm run build
```

## 기술 스택

- React 19 + TypeScript + Vite
- Vitest + React Testing Library
- 계획된 운영 AI 경계: Vercel Serverless Function 1개 → AI provider

로그인, 데이터베이스, 결제, 영구 히스토리는 MVP 범위에 포함하지 않습니다.
