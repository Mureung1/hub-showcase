# 🎵 SWIM

> **One Day. One Song. One Memory.**

**Record your day with music.**

SWIM은 하루를 대표하는 노래 한 곡과 짧은 감정을 기록하는 **음악 기반 SNS**입니다.

사용자는 매일 하나의 **Music Card**를 만들고,
이 카드들이 시간순으로 쌓여 **Music Diary**가 됩니다.

단순히 음악을 추천하는 서비스가 아니라,
**음악을 통해 사람의 하루와 감정을 기록하고 공유하는 경험**을 제공합니다.

---

## ✨ 주요 기능

- Spotify OAuth 로그인
- Music Card 작성
- Music Diary
- Home Feed
- 사용자 검색
- Follow
- Like
