# 🏋️‍♂️ FitCheck (핏첵)

> 비대면 피드백과 위치 기반 매칭으로 PT 진입 장벽을 낮추고 골목상권과 상생하는 스마트 피트니스 플랫폼
>
> > 🔗 [Notion Workspace 바로가기](https://app.notion.com/p/FitCheck-396c0be45234802a8690e99fc0ab2146?source=copy_link) (프로젝트 상세 기획 및 진행 상황)

`FitCheck`는 고비용 등의 이유로 오프라인 PT를 받아보지 못한 입문자(PT를 고민 중인 사람)를 위한 스마트 피트니스 가이드 플랫폼입니다.

사용자에게는 비용 부담 없는 비대면 운동/식단 가이드를 제공하여 개인 맞춤형 성장을 돕고, 정체기나 전문적인 관리가 필요한 순간 위치 기반(지도) 시스템을 통해 내 주변의 우수한 골목 헬스장(소상공인) 및 개인 트레이너와 연결해 줍니다. 이를 통해 대형 프랜차이즈에 밀려 신규 회원 유치에 어려움을 겪는 피트니스 소상공인의 마케팅 문제를 해결하고 상생하는 건강한 지역 체육 생태계를 구축하고자 합니다.

---

## 💡 Project Background & Problem (기획 배경 및 문제 정의)

### ❌ 입문자 및 소상공인이 겪는 페인 포인트

- 높은 PT 진입 장벽: 건강 관리를 위해 전문적인 가이드와 식단 관리를 받고 싶지만, 수십 ~ 수백만 원에 달하는 오프라인 PT 비용은 입문자들에게 큰 심리적·경제적 진입 장벽이 됩니다.
- 마케팅 자본력의 한계: 막대한 자본을 바탕으로 SNS 광고 및 가격 덤핑을 진행하는 대형 프랜차이즈 피트니스 센터들 사이에서, 동네 소규모 1인 숍이나 골목 헬스장(소상공인)은 지역 잠재 고객에게 센터를 홍보하고 신규 회원을 유치할 수 있는 채널이 절대적으로 부족합니다.

## 🚀 Core Value & Differentiation (핵심 가치 및 차별화 요소)

`FitCheck`는 단순히 정보를 나열하는 앱을 넘어, 개인의 홀로서기를 돕는 자동화 가이드와 지역 상권을 살리는 매칭 시스템의 본질에 집중합니다.

### ⚡ 3대 핵심 차별화 시스템

#### 1. 비용 부담 제로, 스마트 비대면 셀프 케어 (General User)

- 당장 비싼 PT를 등록하지 않더라도, 부위별/목적별로 세분화된 운동 강좌 가이드와 AI 기반의 자동 식단 피드백 시스템을 통해 혼자서도 헤매지 않고 체계적인 건강 관리를 시작할 수 있습니다.

#### 2. 골목상권 상생형 로컬 오프라인 매칭 (Shared Growth)

- 혼자 운동을 진행하다가 한계(정체기, 자세 불확실성 등)에 부딪혀 "진짜 제대로 배워보고 싶다"고 느끼는 최적의 타이밍에, 지도 API를 활용하여 내 주변의 소상공인 헬스장과 트레이너를 추천합니다. 사용자는 신뢰할 수 있는 로컬 전문가를 만나고, 소상공인은 비용 부담 없이 진성 유저를 신규 회원으로 유치할 수 있습니다.

#### 3. 유기적인 데이터 기반 상담 연계 (O2O Bridge)

- 사용자가 앱 내에서 혼자 성실하게 기록해 온 식단 데이터와 운동 히스토리는 매칭된 소상공인 트레이너의 대시보드로 자연스럽게 연동될 수 있도록 확장하여, 오프라인 방문 시 훨씬 더 정밀하고 압도적인 고품격 맞춤 상담을 가능하게 만듭니다.

## ✨ Key Features (주요 기능)

### 📱 회원 전용 서비스 (Web to Mobile)

_생산성 및 빠른 배포를 위해 모바일 반응형 웹을 기반으로 빌드한 후 하이브리드 앱으로 전환_

- 부위별·목적별 맞춤 PT 강좌/VOD: 혼자서도 정확한 자극과 운동법을 익힐 수 있도록 부위별(가슴/등/하체 등) 및 목적별(다이어트/벌크업) 맞춤형 가이드 영상 제공
- 자동 AI 식단 피드백 타임라인: 식단 사진을 업로드하거나 칼로리를 입력하면, 실시간으로 탄단지(탄수화물/단백질/지방) 비율 분석 및 맞춤형 가이드 라인을 제공하는 자동 피드백 시스템
- 지도 기반 우리 동네 헬스장 추천 (소상공인 연계): GPS 기반 지도 API를 통해 내 반경 내에 위치한 골목 헬스장 및 1인 PT숍, 개인 트레이너 프로필을 한눈에 확인하고 즉각 상담을 신청할 수 있는 상생 창구

### 🖥️ 트레이너 전용 웹 대시보드 (Web)

- _추후 오프라인 매칭 연동 시 회원 정보 및 이전 비대면 운동/식단 히스토리를 모니터링하고 관리할 수 있는 트레이너 통합 관리 웹 뷰 확장 플랫폼_

## 💻 Getting Started (시작하기)

### Prerequisites (사전 준비)

- Node.js v18+
- Expo Go App (iOS/Android) 또는 시뮬레이터 (모바일 앱 확인용)

### Installation & Run

#### 🖥️ 1. Backend Server (Express) & Database (Supabase)

```bash
# 백엔드 디렉토리 이동
cd server

# 패키지 설치
npm install

# 환경 변수 설정 (.env 파일 생성 후 Supabase Key 및 포트 설정)
# PORT=5000
# SUPABASE_URL=your_supabase_url
# SUPABASE_KEY=your_supabase_anon_key

# 서버 실행
npm run dev
```
