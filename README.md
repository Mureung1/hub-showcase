# 홈키퍼 (HomeKeeper) 🏠

> 매달 나가는 고정 지출을 등록해두면, 납부일이 임박했을 때 알려주는 지출 관리 서비스

사회초년생과 대학생이 월세·관리비처럼 매달 반복되는 고정 지출을 놓치지 않도록 돕는 웹 서비스입니다.

## 💡 어떤 문제를 풀었나요

사회초년생과 대학생은 월세·관리비 같은 고정 지출의 납부일을 놓치기 쉽고, 이번 달에 아직 나갈 돈이 얼마인지 한눈에 파악하기 어렵습니다.

홈키퍼는 고정 지출을 한 번 등록해두면, 납부일까지 남은 날짜를 D-day로 보여주고 임박한 지출을 미리 알려줘서 "돈 걱정"을 덜어줍니다.

---

## ✨ 주요 기능

- **고정 지출 등록·관리** — 월세, 관리비 등 매달 나가는 지출을 등록하고 수정·삭제할 수 있습니다.
- **D-day 표시** — 각 지출의 납부일까지 남은 날짜를 D-day로 계산해 보여줍니다.
- **임박 알림** — 납부일이 3일 이내로 다가온 지출을 따로 모아 알려줍니다.
- **이번 달 남은 금액 요약** — 이번 달에 아직 납부하지 않은 지출 금액을 요약 카드로 보여줍니다.

---

## 🛠 기술 스택

- **프론트엔드**: React (Vite)
- **백엔드**: Express
- **데이터베이스**: Supabase (PostgreSQL)
- **배포**: 화면은 Vercel, 서버는 Render

---

## 🔍 기술적 특징 · 문제해결 과정

- **화면–서버–DB를 연결한 완결된 지출 CRUD**
  등록·조회·수정·삭제가 프론트엔드에서 Express 서버를 거쳐 Supabase DB까지 이어지도록 구현했습니다.

- **정확한 D-day 계산**
  단순히 날짜를 빼는 것을 넘어, 매달 말일 처리(예: 31일이 없는 달), 연도 넘김, 윤년까지 고려해 D-day를 계산하는 순수 함수로 분리했습니다.

- **이중 입력 검증**
  잘못된 값이 들어가는 것을 막기 위해 프론트엔드와 서버 양쪽에서 입력값을 검증합니다.

- **배포 과정에서의 문제해결**
  프론트엔드와 백엔드를 각각 Vercel과 Render로 분리 배포하면서, 환경변수(`VITE_API_URL`)로 서버 주소를 주입해 로컬 개발과 배포 환경을 모두 지원하도록 구성했습니다.
