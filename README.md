# Opportunity Agent Intro

장학금, 공모전, 대외활동 정보를 검색하고 정리하는 에이전트 프로젝트를 소개하는 React/Vite 예제입니다.

## 구성

- Vite + React
- 단일 소개 컴포넌트: `src/App.jsx`
- 전역 스타일: `src/styles.css`

## 실행

```bash
pnpm install
pnpm dev
```

## 빌드

```bash
pnpm build
```
