# TMI 서비스 구현 요청

## 서비스 소개

**TMI**는 처음 만난 사람, 어색한 친구, 연인, 팀플·동아리 구성원과 대화할 때 사용할 수 있는 아이스브레이킹 대화 주제 추천 서비스다.

사용자는 현재 관계와 상황을 선택하고, 서비스는 그 상황에 어울리는 질문과 대화 주제를 추천한다.

단순 랜덤 질문 서비스가 아니라, 사용자가 선택한 관계와 분위기에 맞춰 부담스럽지 않은 질문을 제공하는 것이 핵심이다.

모바일 앱처럼 사용할 수 있는 웹 서비스 형태로 구현한다.

## 핵심 기능

### 1. 대화 상황 선택

대화 시작 전 사용자가 아래 항목을 선택한다.

* 누구와 대화하는지: 처음 만난 사람 / 친구 / 연인 / 팀플·동아리
* 어디서 대화하는지: 카페 / 식당 / 산책 / 술자리 / 온라인
* 대화 목적: 어색함 풀기 / 친해지기 / 재밌게 놀기 / 진지한 대화
* 원하는 분위기: 편안한 / 웃긴 / 설레는 / 진지한

### 2. 상황 맞춤 질문 추천

선택한 상황에 맞춰 대화 질문 카드를 추천한다.

예시:

* 처음 만난 사람: “요즘 가장 자주 듣는 노래 있어?”
* 친구: “최근에 제일 재밌게 본 콘텐츠 뭐야?”
* 연인: “요즘 서로에게 고마웠던 순간이 있었어?”
* 팀플·동아리: “일할 때 미리 끝내는 편이야, 마감 직전에 집중하는 편이야?”

### 3. 정적 탈출 기능

대화가 끊기거나 어색해졌을 때 바로 누를 수 있는 버튼이다.

버튼을 누르면 가볍고 즉시 꺼내기 좋은 질문을 추천한다.

예시:

* 지금 당장 떠날 수 있다면 어디 가고 싶어?
* 최근에 은근히 자랑하고 싶은 일 있었어?
* 요즘 가장 자주 쓰는 앱 하나만 추천해줘.

### 4. AI 후속 질문 추천

상대방의 답변을 짧게 입력하면, 그 답변과 자연스럽게 이어지는 다음 질문을 추천한다.

예시:

상대 답변:
“나는 여행 가면 계획 없이 돌아다니는 편이야.”

추천 질문:
“그럼 가장 기억에 남는 즉흥 여행지는 어디야?”

### 5. 질문 반응 기능

각 질문에 대해 사용자가 반응할 수 있다.

* 좋았어요
* 별로예요
* 다른 질문 보기

반응을 바탕으로 이후에는 비슷한 분위기나 주제의 질문을 더 자주 추천한다.

### 6. 함께 사용하는 대화방

친구나 연인에게 링크를 공유해 같은 질문 카드를 함께 볼 수 있다.

* 대화방 만들기
* 링크 공유
* 같은 질문 카드 보기
* 함께 다음 질문으로 넘기기
* 간단한 밸런스게임 또는 선택형 질문 제공

## 화면 구성

* 시작 화면
* 대화 상황 선택 화면
* 질문 카드 화면
* 정적 탈출 질문 화면
* AI 후속 질문 화면
* 대화방 공유 및 입장 화면
* 대화 종료 화면

## 디자인 방향

* 모바일 앱처럼 보이는 웹 화면
* 질문이 가장 잘 보이는 카드형 UI
* 밝고 편안한 분위기
* 복잡한 입력보다 선택형 버튼 중심
* 처음 사용하는 사람도 빠르게 시작할 수 있는 구조

우선은 위 기능을 기준으로 화면과 사용자 흐름을 구현하고, 질문 데이터는 더미 데이터로 구성한다.
