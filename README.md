# We should do..

친구와 개인 일정 및 할 일을 공유하고, 영상 인증으로 포인트를 모아 캐릭터 **두두(DODO)**와 마이홈을 꾸미는 소셜 일정 앱 프로토타입입니다.

이번 버전은 핵심 경험인 `활동 입력 → 영상 인증 → 친구 반응 보너스 → 두두의 오늘 일기` 흐름을 React 컴포넌트로 구현했습니다.

![We should do 실행 화면](./docs/we-should-do-preview.png)

## 주요 기능

- 활동 종류, 이름, 수행 시간 입력
- 영상 파일 선택 또는 샘플 인증
- 인증 완료 후 두두의 일기 자동 생성
- 친구 눈빛 반응과 포인트 보너스
- 한 눈·두 눈을 선택할 수 있는 두두 배리에이션
- 저해상도 파스텔 픽셀 아트 캐릭터와 마이홈
- 반응형 레이아웃

## 실행 방법

Node.js와 pnpm이 설치된 환경에서 다음 명령을 실행합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:5173`으로 접속합니다.

프로덕션 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
pnpm build
```
