이 프로젝트는 복잡한 개발 서버 설정이나 의존성 설치가 전혀 필요하지 않은 **가볍고 독립적인 단일 HTML 파일**입니다.

1. 프로젝트 폴더 루트에 있는 **[index.html](file:///Users/tatata/Desktop/Ai_agent/hub/index.html)** 파일을 더블클릭합니다.
2. 사용하시는 인터넷 브라우저(Chrome, Safari 등)에서 즉시 화면이 나타납니다.
3. 별도의 서버 구동이 필요 없으므로 **오프라인 상태에서도 100% 정상 작동**합니다.

## ✨ 핵심 기능

1. **🖤 August* Style 프리미엄 Brutalist 디자인**
   - 피치 블랙 배경과 순백색 대형 타이포그래피, 라임 그린 포인트 컬러의 조화.
   - 메인 화면에 겹쳐서 플로팅되는 고해상도 자산 이미지(`artist_bw.png`, `tunnel_green.png`)의 오프셋 배치.
   - 드롭 예측 라이프사이클을 안내하는 구불구불한 4단계 프로세스 SVG 곡선 연출.

2. **🔮 Zero-Risk 방향성 예측 투표 (Up/Down)**
   - 복잡한 가격 계산 장벽을 없애고, 카드의 **[▲ 오를까]** / **[▼ 내릴까]** 단 2개의 버튼으로 가볍게 시장 심리 예측에 참여합니다.

3. **📊 집단지성 가격 연산 (Consensus Price)**
   - 유저들의 상승/하락 투표율과 상품의 출시 정가 데이터를 연동하여, 대중이 예상하는 실시간 합의 시세 가격(Consensus Price)을 연산해 화면에 노출합니다.

4. **⚡ 실시간 상세 분석 패널**
   - 카드를 클릭하면 나타나는 슬라이드 오버레이 패널을 통해 6개월 관심도 그래프(SVG Sparkline) 및 실시간 롱/숏 비율(Bullish/Bearish)의 게이지 바 시각화를 제공합니다.
