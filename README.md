# 답냥이

대학생이 꺼내기 어려운 메시지를 관계와 상황에 맞춰 빠르게 작성하도록 돕는 서비스입니다.

## 핵심 경험

1. 답장 / 먼저 연락을 고릅니다.
2. 관계(팀플·조모임, 교수님·조교님, 선배·동기, 친구·연인)를 고릅니다.
3. 자주 쓰는 상황 카드를 고르면 3톤 템플릿 초안을 즉시 확인합니다.
4. 카드에 없는 복합 상황만 목적과 맥락을 입력해 AI 생성 경로로 보냅니다.

## 현재 구현 상태

| 상태 | 범위 |
|---|---|
| 구현됨 | S0~S3 흐름, 카드용 72문구 초안 연결, 직접입력 목 응답, 계약 검증, 실패·타임아웃, 입력 복원·삭제, 복사 폴백 |
| 검증 대기 | 시드 제3자 블라인드 검수(T16), 템플릿 전수 검수(T25), 외부 사용자 파일럿 |
| 구현 예정 | 독립 라우터·템플릿 엔진, 실제 AI 프록시·프롬프트, 배포·CI, 조건부 계측 |

현재 카드는 UI 흐름 검증용 초안이다. “검수 완료”는 CHECKLIST의 T16·T25가 통과한 뒤에만 사용한다.

## 왜 모든 요청을 AI로 처리하지 않나요?

답냥이는 정형 상황과 복합 맥락을 구분하는 하이브리드 구조를 사용합니다.

| 경로 | 처리 | 장점 |
|---|---|---|
| 상황 카드 | 로컬 템플릿 | API 호출 없이 즉시 응답, 비용 0, 전수 검수 가능한 결정적 문구 |
| 다른 상황이냥 | 구조화된 AI 생성 | 받은 메시지·감정·관계를 함께 반영한 맞춤 후보 |

AI는 카드로 해결할 수 없는 구체적 맥락에서만 가치를 만듭니다. 한 번의 AI 요청으로 기본/더 부드럽게/더 분명하게 후보 3개를 받아 사용자가 직접 고르게 합니다.

## AI 설계

- 공용 요청·응답 계약과 런타임 검증으로 후보 수, 톤 순서, 빈 문장, 과도한 길이, 명백한 공격 표현을 방어합니다.
- 모델은 톤 레벨과 문장만 반환하고, UI 라벨은 서비스가 고정 규칙으로 부여합니다.
- 관계·목적·안전·few-shot·출력 스키마를 조합하는 서버 전용 프롬프트 빌더를 설계했으며, 구현은 T19에서 진행합니다.
- 교수님·조교님·선배·친구 관계의 평가 케이스를 코드로 관리합니다.
- 입력 원문은 서버·분석 이벤트에 저장하지 않으며, 탭 복원용 임시 보관은 30분 만료와 즉시 삭제를 제공합니다.

현재 직접입력 AI 경로는 외부 API 연결 전의 개발용 목 응답입니다. 실제 provider 호출은 아직 하지 않으며, 이후 Vercel 서버리스 함수 `/api/generate`에서만 연결합니다. 실 연동 전에는 입력이 외부 provider로 전송된다는 사실과 당시 보존 조건을 사용자에게 고지합니다.

상세한 선택 근거와 실패·비용·개인정보 정책은 [AI 설계 노트](docs/AI_DESIGN.md)에서 확인할 수 있습니다.
현재 제품 가치와 미완성 지점은 [제품 6축 점검표](docs/PRODUCT_REVIEW.md)에서 확인할 수 있습니다.
[문헌 기반 제품·검수 근거](docs/RESEARCH_REVIEW.md)는 AI 글쓰기·관계 영향·구조화 UI·한국어 공손성 연구와 답냥이에 적용할 수 없는 과해석을 함께 정리합니다.
ChatGPT·Gemini 대비 검증은 [경쟁가치 검증 절차](docs/COMPETITIVE_VALIDATION.md)의 문헌 → 무참여자 모델 벤치마크 → T22 짧은 과업 순서로 진행합니다. 아직 모델·참여자 비교 결과는 없습니다.

## 기술 스택

- React 19 + TypeScript + Vite
- Vitest + React Testing Library
- 계획된 운영 AI 경계: Vercel Serverless Function 1개 → AI provider

로그인, 데이터베이스, 결제, 영구 히스토리는 MVP 범위에 포함하지 않습니다.
