# 👗 Pick My Clothes

AI Agent를 활용하여 사용자의 상황, 날씨, 선호 스타일, 보유한 옷을 분석하여
가장 적합한 코디를 추천하는 서비스입니다.

---

## ✨ 주요 기능

- 🌤️ 날씨 기반 코디 추천
- 📅 일정(학교, 데이트, 발표 등) 기반 코디 추천
- 👕 보유한 옷 사진 업로드 및 AI 옷장 생성
- 🤖 AI와 대화를 통한 맞춤형 코디 추천
- 🛍️ 새로운 옷을 포함한 코디 추천 및 구매 링크 제공
