# Amadda

아맞다(Amadda)는 저장해둔 링크와 메모를 현재 상황에 맞춰 다시 찾게 해주는 개인 인사이트 저장소입니다. MVP는 링크 저장, 카테고리 기반 보관함, 상황 기반 꺼내보기를 중심으로 검증합니다.
