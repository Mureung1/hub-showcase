# 하루 체크아웃 (가제)

정리되지 않은 감정을 날것 그대로 입력하면 AI가 감정·원인·다음 행동으로 구조화해주는 대학생용 하루 체크아웃 도구.

## 해결하는 문제
- 교내 학생상담센터는 무료지만 인력 부족으로 대기가 길고, 공공 지원 제도는 절차가 복잡해 학생이 스스로 찾아 이용하기 어렵다.
- 상담 이용에 대한 심리적 부담(낙인)도 여전해 많은 학생이 AI 챗봇에 고민을 털어놓지만, 일반 챗봇은 과도하게 동조(sycophancy)하고 대화가 휘발되어 자기 상태를 축적적으로 파악하기 어렵다.
- 이 서비스는 조언·진단·위로 대신 정리만 제공하고, 기록을 누적해 반복되는 감정 패턴을 보여주며 필요할 때 실제 지원 제도로 연결한다.

## 핵심 기능
- 입력창에 하루의 감정을 자유롭게 입력 → [정리하기]로 감정/원인/내일의 행동 3개 카드로 구조화
- 결과 수정 및 저장, 캘린더 형태로 기록 누적
- 반복되는 감정 패턴 감지 시 교내 상담센터·심리상담 바우처 등 지원 정보 안내
