# 아이디어 고민

## Personalized Notice Bot (가제)

대학생들은 학교 홈페이지, 학과 홈페이지, 교육원, 학생회 등 여러 공지 사이트를 직접 확인해야 하며, 중요한 공지를 놓치는 경우가 많습니다.

이를 해결하기 위해서 Personalized Notice Bot은 원하는 공지 사이트를 Discord와 연동하여 새로운 공지를 자동으로 알려주고, 관심 키워드에 맞는 공지만 받아볼 수 있도록 도와주는 서비스입니다.

---

## 해결하고자 하는 문제

* 여러 공지 사이트를 반복해서 확인해야 하는 불편함
* 필요한 공지가 다른 공지에 묻혀 놓치는 문제
* Discord를 자주 사용하는 학생들이 공지를 확인하기 위해 다시 홈페이지를 방문해야 하는 문제

---

## 주요 기능 (MVP)

### 공지 사이트 등록

* 공지 사이트 URL 등록
* 등록된 공지 사이트 크롤링
* 새로운 공지 자동 감지

### Discord 연동

* Discord 서버 및 채널 설정
* 새로운 공지 자동 알림

### 키워드 구독

* 관심 키워드 등록
* 키워드가 포함된 공지만 알림

### 웹 관리 페이지

* Discord 연동
* 공지 사이트 설정
* 키워드 관리
* 알림 설정

## 향후 발전 방향

* AI를 활용한 공지 사이트 HTML 구조 분석
* URL만 입력하면 크롤링 규칙 자동 생성

* 마감일 자동 추출 및 재알림
