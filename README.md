# 취미·성향 기반 대학생 매칭 플랫폼 (가칭)

학교 인증을 받은 대학생을 위한 **과팅(그룹 매칭) + 룸메이트 매칭** 서비스입니다.
하나의 취미·성향 테스트 엔진을 기반으로 두 가지 매칭 카테고리를 제공합니다.

## 프로젝트 소개

- 취미가 뚜렷하지 않은 사용자를 위한 **취미 발견 테스트**로 온보딩
- 목적에 따라 **연애 성향(과팅)** 또는 **생활 성향(룸메이트)** 질문으로 분화
- 과팅은 동성 그룹 매칭 → 이성 그룹 매칭의 2단계 구조
- 룸메이트는 생활 성향 기반 개인 대 개인 매칭

## 핵심 기능 (기획 중)

- [ ] 학교 이메일 / 학생증 인증
- [ ] 취미 발견 테스트
- [ ] 연애 성향 테스트 (과팅용)
- [ ] 생활 성향 테스트 (룸메이트용)
- [ ] 동성 그룹 매칭 알고리즘
- [ ] 이성 그룹 매칭 (과팅)
- [ ] 개인 대 개인 매칭 (룸메이트)
- [ ] 신고 / 후기 / 매너 점수 시스템

## 왜 만드는가

- 기존 소개팅 앱(썸타임, 짝꿍 등)은 1:1 매칭 중심이라 초면 부담이 큼
- 룸메이트 매칭 앱(cozymate 등)은 기숙사 중심이라 자취·타 학교 간 매칭이 약함
- 과팅과 룸메이트 매칭을 하나의 성향 엔진으로 함께 다루는 서비스는 아직 없음
