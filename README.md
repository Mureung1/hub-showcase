#### ## 주요 작업 리스트
서비스 기획: 신상 과자 제품 출시 알림과 함께 리뷰의 광고성 정보를 걸러주는 에이전트 기획.
UI 구현: 사용자가 제품 정보를 확인하고 만족도를 정량적으로 볼 수 있는 대시보드 컴포넌트 설계.

#### ## 내가 설명할 수 있는 부분
UI 설계: 리액트 컴포넌트 구조를 이해하고 카드형 디자인으로 가독성 최적화.

#### ## 아직 이해 못 한 부분
데이터 자동 연동: 외부 API를 활용한 실시간 재고 데이터의 동적 렌더링.
실시간 NLP: 실제 SNS 후기를 실시간으로 요약하는 정교한 모델 구현.

#### ## 새로 알게 된 것
`package.json`과 폴더 구조를 통해 프로젝트 의존성 관리의 기초를 이해함.
명령어 기반의 개발 환경 구축 및 디버깅 프로세스 숙달.
버전 관리 시스템과 오픈소스 협업 프로세스(Fork/PR) 습득.
환경 설정 및 권한 문제를 해결하며 개발의 기초 체력을 기름.
