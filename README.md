# N015_김규태

## 주요 작업 리스트

- `connect-AIAgentChallenge-26-1/hub` 원본 저장소의 `N015_김규태` 브랜치를 기준으로 작업 브랜치를 만들었습니다.
- PR 템플릿에서 요구하는 4개 항목을 기준으로 README를 작성했습니다.
- 변경사항을 fork 저장소의 작업 브랜치에 푸시했습니다.
- 원본 저장소의 `N015_김규태` 브랜치를 base로 PR을 생성할 수 있도록 준비했습니다.

## 내가 설명할 수 있는 부분

이번 작업에서는 원본 저장소의 `N015_김규태` 브랜치를 기준으로 새 작업 브랜치를 만들었습니다.  
이렇게 하면 내 제출 내용은 별도 브랜치에 남기고, PR에서는 `N015_김규태` 브랜치와 내가 작성한 변경사항의 차이만 확인할 수 있습니다.

또한 PR 템플릿의 4개 항목을 README에 그대로 반영했습니다.  
단순히 작업 결과만 쓰는 것이 아니라, 내가 설명할 수 있는 부분과 아직 이해하지 못한 부분을 함께 남기기 위한 구조라고 이해했습니다.

## 아직 이해 못 한 부분

- 원본 저장소의 자동 병합 워크플로가 PR 라벨, 리뷰 상태, 충돌 상태를 어떤 순서로 판단하는지는 아직 완전히 설명하기 어렵습니다.
- PR이 자동으로 병합되지 않을 때 GitHub 화면에서 어떤 항목을 먼저 확인해야 하는지는 더 익숙해질 필요가 있습니다.

## 새로 알게 된 것

- fork 저장소에서 작업 브랜치를 만들고, 원본 저장소의 특정 브랜치를 base로 PR을 올릴 수 있다는 것을 알게 되었습니다.
- PR의 base 브랜치를 잘못 잡으면 비교 대상 자체가 달라지므로, 제출 전에 base와 head를 반드시 확인해야 한다는 것을 알게 되었습니다.
- PR 템플릿의 `주요 작업 리스트`, `내가 설명할 수 있는 부분`, `아직 이해 못 한 부분`, `새로 알게 된 것` 항목은 작업 결과와 학습 상태를 함께 정리하기 위한 기록이라는 점을 알게 되었습니다.
