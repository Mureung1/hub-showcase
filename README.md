# Bridge

## 프로젝트 소개
편지를 매개로 사람과 연결되는 플랫폼입니다.
빠르게 소비되는 SNS와 달리, 천천히 쓰고 기다리는 편지의 감성을 디지털로 구현하고자 합니다.

## 편지 작성 제한
- 하루 최대 한 개의 편지만 작성가능합니다.(단, 답장의 경우에는 카운트되지 않습니다.)
- 붙여넣기 기능이 작동하지 않습니다. 모든 글은 직접 타이핑해야 합니다.

## AI 활용 부분
- 모든 편지는 AI를 통해 내용에 따라 분류됩니다.
- 작성자의 선호 카테고리와 편지내용을 참고하여 다른사람의 편지를 가져옵니다.

## 동작 순서
- 편지 작성 후 모음소로 이동(모음소에는 답장을 기다리는 다양한 편지가 있음)
- 다음 날 AI가 적절한 편지를 매칭해서 전달
- 받은 편지에 답장하거나 새 편지 작성 선택 가능
