# hub
# 1. 프로젝트 개요

1.1 문제 정의

한국의 분리수거 제도는 지자체(구/시/군)마다 세부 규정이 다르고, 애매한 품목(영수증, 젖은 종이, 우산, 커피컵 등)에 대한 판단 기준이 명확하지 않아 내국인도 혼란을 겪는다. 특히 외국인 유학생과 자취를 처음 시작하는 청년층은:


모국과 다른 분리배출 체계(종량제봉투, 음식물쓰레기 별도 배출 등)에 익숙하지 않다.
한국어 위주의 안내 자료(지자체 홈페이지, 안내문)에 언어 장벽을 느낀다.
"이 물건은 어디에 버려야 하는지" 즉각적으로 확인할 방법이 없다.
잘못 배출 시 과태료, 이웃과의 마찰, 환경 오염으로 이어진다.


1.2 타겟 사용자


1차 타겟: 한국 거주 외국인 유학생 (교환학생, 어학연수생 포함)
2차 타겟: 자취를 처음 시작하는 한국 대학생/사회초년생


1.3 차별점 (기존 지자체 앱/안내와 비교)

기존 방식본 프로젝트텍스트 위주 안내문, 검색 어려움사진 촬영 → 즉시 분류 결과 제공한국어 전용다국어 지원 (영어, 중국어, 베트남어 등)지자체별 정보 파편화지역 설정 기반 맞춤 안내애매한 품목에 대한 답이 없음Q&A 데이터베이스 + 커뮤니티 참고자료일회성 정보 제공배출 요일 알림 등 반복 사용 유도


# 2. 핵심 기능

2.1 MVP 필수 기능


사진 기반 분류 (Photo Classifier)

품목 사진 촬영 → 멀티모달 LLM API 호출 → 분리배출 카테고리 반환
카테고리: 일반쓰레기 / 재활용(종이·플라스틱·비닐·유리·캔·금속·스티로폼) / 음식물쓰레기 / 대형폐기물
배출 전 처리방법 안내 (예: "라벨 제거 후 배출", "이물질 세척 필요")



지역별 규정 검색 (Location-based Rule Lookup)

사용자 거주 지역(구/동) 설정
종량제봉투 필요 여부, 배출 요일/시간대 등 지역 맞춤 정보 제공



애매한 품목 Q&A 검색

자주 헷갈리는 품목 목록 텍스트 검색 (영수증, 우산, 건전지, 커피컵 등)
공식 답변 + 필요시 네이버 블로그 등 커뮤니티 참고자료 링크 (보조 정보로 명확히 구분 표시)



다국어 지원

UI 및 분류 결과 다국어 제공 (한국어/영어 최소, 확장 가능)





2.2 추가 기능 (시간 허용 시)


배출 요일 알림 (Push Notification)
대형폐기물 신고 가이드 (스텝별 안내 + 관련 지자체 신고 페이지 연결)
분리수거 습관 트래커 (선택적 게이미피케이션)
