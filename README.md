# about-me
프로젝트 주제

AI 기반 혼자 여행자를 위한 여행 도우미 웹·앱 서비스

기획 배경

혼자 여행을 하다 보면 예약 일정, 이동 동선, 교통편, 언어 문제 등을 모두 혼자 해결해야 한다. 특히 일정이 변경되거나 예상치 못한 상황이 발생하면 여러 앱을 오가며 정보를 다시 찾아야 하는 번거로움이 있다.

이 프로젝트는 이러한 불편함을 줄이고, AI가 여행 상황에 맞는 정보를 실시간으로 제공하여 보다 편리하고 안전한 여행을 지원하는 것을 목표로 한다.

웹(Web) 주요 기능

1. 여행 일정 통합 관리
	•	항공권, 숙소, 기차, 공연 등 예약 정보를 한곳에서 관리
	•	여행 일정을 캘린더 형태로 확인

2. AI 일정 조정
	•	비행기 지연이나 일정 변경 발생 시 AI가 자동으로 새로운 일정을 제안
	•	예약 시간과 이동 시간을 고려하여 현실적인 계획 제공

3. AI 동선 추천
	•	현재 위치와 예약 일정을 기반으로 최적의 이동 경로 추천
	•	이동 중 방문 가능한 관광지, 카페, 식당 등을 함께 추천

4. 공항 길찾기
	•	출국 및 환승 시 공항 내부 이동 경로 안내
	•	체크인 카운터, 보안검색, 게이트까지의 이동 순서를 쉽게 확인

앱(App) 주요 기능

1. 실시간 번역
	•	카메라를 이용하여 표지판, 메뉴판, 안내문 등을 즉시 번역

2. AI 이미지 검색
	•	카메라로 상품이나 사물을 비추면 AI가 인식
	•	해당 물건의 이름, 용도, 가격대, 특징 등을 한눈에 제공

3. 현지 정보 제공
	•	교통 이용 방법
	•	결제 방식
	•	문화 및 에티켓
	•	긴급 상황 대응 방법 등을 AI가 빠르게 안내

기대 효과
	•	여러 여행 앱을 번갈아 사용할 필요 없이 하나의 서비스에서 여행 정보를 관리할 수 있다.
	•	일정 변경에도 AI가 자동으로 계획을 재구성하여 여행의 부담을 줄인다.
	•	언어 장벽을 낮춰 혼자 여행하는 사용자의 불안감을 줄이고 더 자유로운 여행 경험을 제공한다.
