# 프로젝트 기획

자취생이 냉장고 재료와 유통기한을 관리하고, 보유 재료를 활용한 식단과 구매 항목을 추천받는 웹 서비스입니다.

## 개발 시작

```powershell
npm.cmd install
Copy-Item .env.example .env
npm.cmd run dev
```

- 웹: `http://localhost:5173/hub/`
- API 상태: `http://localhost:3000/api/health`

상세 환경과 협업 규칙은 `docs/DEVELOPMENT_GUIDE.md`, Agent 규칙은 `Agent.md`, UI 기준은 `design.md`를 참고하세요.
