# 프로젝트 주제 정하기
여러가지 주제를 생각해 보는 중 입니다.
그 중, 현재까지 나온 아이디어를 정리해 놓았습니다.
아이디어는 계속해서 추가해 나갈 예정입니다.
### 1. 자취생 식재료 관리 플랫폼
자취생과 같은 1인 가구는 식재료 소비량이 크지 않기 때문애, 식재료 구매와 소비에 있어 다양한 문제가 발생합나다.
- 식재료를 다량 구매 후 재때 소비하지 못해 식재료를 버리게 되는 상황
- 소분된 1인용 식재료를 구매하기 위해 비싼 값을 주고 식재료를 구매하는 상황
이런 문제를 해결하기 위해 아래와 같은 솔루션을 제공합니다.
- 식재료 공동구매 매칭(지역, 평소 소비 재료 기반)
- 인공지능을 활용한 식재료 소비기한 경고 및 식재료 추천

### 2. 소상공인 법률 지원 서비스
소상공인은 임대차계약, 노무 분쟁 등 다양한 법률 문제를 맞이할 상황이 많습니다.
그러나 소상공인들은 변호사의 도움 없이 당장 무엇부터 시작해야 하는지 막막하기만 합니다.
이런 문제를 해결하기 위해 아래와 같은 솔루션을 제공합니다.
- 사용자가 상황을 설명하면 인공지능이 법률적 언어로 재해석
- 수집해야할 증거 등 대응 방안 수립
