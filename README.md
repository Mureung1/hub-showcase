# MBTI 기반 공부법 및 스트레스 관리 웹앱

MBTI를 학습 선호를 탐색하는 출발점으로 사용하고, 공부 습관과 피로 반응 설문을 함께 반영해 오늘 바로 실행할 공부 루틴과 회복 루틴을 추천하는 웹앱입니다.

MBTI는 사람을 고정적으로 판단하는 기준이 아닙니다. 이 프로젝트는 유형명만으로 결과를 만들지 않고, 사용자의 실제 응답을 행동지표로 정리해 인지과학 기반 학습법과 연결합니다. 스트레스 관련 기능은 생활관리 관점에서 피로 신호와 회복 루틴을 다룹니다.

## 핵심 기능

1. 성향·상태 점검  
   MBTI 선택 또는 "MBTI를 몰라요" 흐름과 공부·스트레스 설문을 통해 학습 선호와 현재 상태를 점검합니다.
2. 인지과학 학습법 매칭  
   인출 연습, 분산 학습, 자기설명, 교차 학습, 오답 분석, 환경 설계, 짧은 집중 블록 중 사용자 응답에 맞는 학습법을 추천합니다.
3. 오늘의 공부·회복 루틴  
   결과를 20~30분 공부 루틴과 짧은 회복 루틴으로 바꾸고, 완료 여부와 집중도·피로도를 저장합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소로 접속하면 프로토타입을 확인할 수 있습니다.

## MVP 포함 범위

- MBTI 선택 또는 모름 선택
- 공부 성향 설문
- 스트레스 반응 설문
- 행동지표 기반 결과 요약
- 추천 공부법 TOP 3와 추천 이유
- 피해야 할 공부 방식
- 피로 신호와 회복 루틴
- 오늘의 20~30분 실천 카드
- 완료 여부, 집중도, 피로도 localStorage 저장

## MVP 제외 범위

- 회원가입
- AI API
- 의학적 판단
- 성적 예측
- 커뮤니티

## 표현 원칙

- MBTI는 학습 선호를 탐색하는 출발점으로만 사용합니다.
- 결과는 "그럴 가능성이 있습니다", "이 방식이 더 편할 수 있습니다", "먼저 시도해볼 수 있습니다"처럼 가능성 중심으로 표현합니다.
- 스트레스 관련 결과는 피로 신호와 회복 루틴을 다루는 생활관리 기능으로 제한합니다.
