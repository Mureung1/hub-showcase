# hub
오늘 뭐부터 공부하지?
문제정의
대학생들은 시험기간에 여러 과목을 동시에 준비해야 한다. 하지만 과목마다 시험 날짜, 시험 범위, 난이도, 현재 이해도, 중요도가 다르기 때문에 어떤 과목을 먼저 공부해야 할지 판단하기 어렵다. 이로 인해 공부 시간이 부족한 상황에서 비효율적으로 시간을 쓰거나, 중요한 과목을 뒤늦게 준비하는 문제가 발생한다.

해결 방법
학생이 각 과목의 시험 날짜, 시험 범위량, 현재 이해도, 중요도 등을 입력하면 우선순위 점수를 계산한다. 점수가 높은 과목을 먼저 공부하도록 정렬해주고, 오늘 집중해야 할 과목을 추천한다. 이를 통해 학생이 막연한 불안감 대신 구체적인 공부 순서를 정할 수 있도록 돕는다.
