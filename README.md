# 미루지마 / 잔소리봇

## 한 줄 소개

대학생의 미루기 패턴을 관찰하고, 스스로 알아채기 전에 먼저 개입해 실행을 유도하는 AI 에이전트

## 문제 정의

대학생은 과제·복습을 미루고 있다는 사실을, 마감이 코앞에 닥치기 전까지 아무도(본인조차) 지속적으로 인지시켜주지 않는다는 문제가 있습니다.

- 직장인은 마감을 넘기면 즉각적인 페널티(상사 질책, KPI)가 있어 미루기가 빠르게 교정됩니다.
- 수험생은 학원/독서실 등 강제 감독 환경이 존재합니다.
- 반면 **대학생은 마감까지 아무 피드백 없는 "침묵 구간"이 길게 이어지다가 D-day에 몰아서 터지는 구조**이며, 자기주도 관리 인프라가 거의 없습니다.

기존 대안들의 한계:

- 방해금지모드/Forest 등: 시간만 막을 뿐, 실제로 할 일을 하게 만들지는 못함
- ChatGPT/Claude 직접 질문: 사용자가 먼저 말을 걸어야 응답, 매일 패턴을 기억하고 스스로 개입하지 않음

## 사용자 흐름 (예시: 1주일)

1. **Day 1** — 온보딩, 과목/과제 등록 → 첫 미룸 발생 (기준 데이터 수집)
2. **Day 3** — 3일 연속 미룸 → 약한 리마인드 발송
3. **Day 6** — 누적 미룸 + 과거 패턴 일치 → 톤을 강화해 근거를 제시하며 개입
4. **Day 10** — 마감 임박 → 캘린더에 복습 슬롯 강제 삽입
5. **Day 14** — 주간 결산 → 패턴 분석 및 다음 위기 예측 리포트 제공

## 핵심 서비스 기능

- **일정/할일 입력**: 고정 반복형(수업/시험 일정)과 마감형(과제) 태스크 등록
- **일일 체크인**: 매일 지정 시각에 완료 여부 확인, 무응답은 자동으로 "미룸" 기록
- **미루기 패턴 추적 엔진**: 항목별 연속 미룸 카운터 + 개인별 미루기 프로파일 산출 + 위험도 스코어 계산
- **넛지(Nudge) 메시지 생성**: 위험도에 따라 강도(Lv1~4)를 나눠, 개인 히스토리를 반영한 맞춤 메시지를 AI로 생성
- _(추가 예정)_ 캘린더 자동 슬롯 삽입, 주간 리포트, 넛지 톤 커스터마이징 등

## 화면 구성 (예정)

- **온보딩 화면**: 과목/과제 등록 폼
- **홈 화면**: 오늘의 체크인 현황, 위험도 요약
- **히스토리 화면**: 개인 미루기 패턴 그래프
- **주간 리포트 화면**: 완료율 통계 및 다음 주 예측
