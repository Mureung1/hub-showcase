# AI Tutor Agent 기획서

## 1. 서비스 개요

본 서비스는 대학생을 위한 **강의 자료 기반 AI Tutor Agent**이다.

학생이 강의 자료 또는 교재 PDF를 업로드하면 AI Agent가 자료를 분석하여
학습 내용을 이해하고, 학생과 지속적으로 대화하며 학습을 진행한다. AI
Agent는 학생의 답변을 기반으로 이해도를 진단하고, 부족한 개념을 보완하며
각 학습 단위를 충분히 숙달할 수 있도록 맞춤형 학습을 제공한다.

기존의 AI 챗봇이 사용자의 질문에 답변하는 데 초점을 맞춘다면, 본
서비스는 학생의 학습 상태를 지속적으로 진단하고 학습 전략을 조정하는 AI
Tutor를 목표로 한다.

## 2. 문제 정의

-   대학 강의는 학생 개개인의 이해 수준에 맞춰 진행되기 어렵다.
-   학생은 무엇을 모르는지보다 **왜 이해하지 못하는지**와 **무엇부터
    다시 공부해야 하는지**를 파악하기 어렵다.
-   기존 AI 챗봇은 질문에 답변할 뿐, 학습을 진단하거나 관리하지 못한다.
-   따라서 학생의 이해도를 진단하고 숙달할 때까지 이끄는 AI Tutor Agent가
    필요하다.

## 3. 사용자 시나리오

1.  학생이 강의 자료(PDF)를 업로드한다.
2.  AI Agent가 자료를 분석하고 학습 계획을 생성한다.
3.  학생에게 질문하여 이해도를 진단한다.
4.  답변을 분석해 부족한 개념을 파악한다.
5.  힌트, 선행 개념 설명, 쉬운 예시 등을 제공한다.
6.  다양한 질문으로 숙달 여부를 확인한다.
7.  숙달 시 다음 개념으로 이동하고, 종료 시 복습이 필요한 개념을
    제공한다.

## 4. 핵심 기능

### 강의 자료 기반 학습 계획 생성

PDF를 분석하여 핵심 개념과 학습 순서를 구성한다.

### 이해도 진단

학생의 답변을 분석하여 현재 수준과 부족한 개념을 파악한다.

### 적응형 학습 지원

학생 수준에 맞는 힌트, 예시, 선행 개념 설명 및 질문 유형을 제공한다.

### 숙달 기반 학습 관리

다양한 질문을 통해 숙달 여부를 판단하고 다음 학습을 결정한다.

## 5. 기대 효과

-   개인 맞춤형 복습 지원
-   강의 자료 기반의 정확한 학습
-   AI Agent 기반 적응형 학습
-   학습 효율 향상
