# Week 2 Development Plan

## 🎯 Goal

이번 주 목표는 CampusCart의 핵심 기능(MVP)인

> 상품 검색 → AI 공동구매 추천 → 공동구매 참여 → 공동구매 생성

흐름을 구현하는 것입니다.

이번 주에는 Frontend, Backend, Database를 연결하여 하나의 Vertical Slice를 완성하는 것을 목표로 합니다.
