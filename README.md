# hub
# review analyzer project InsightFlow
### AI 기반 고객 리뷰 분석 및 인사이트 제공 서비스

> "수백 개의 리뷰를 읽지 않아도,
AI가 고객의 목소리를 분석하여
가장 중요한 문제와 개선 방향을 알려드립니다."

---

# 프로젝트 소개

소상공인들은 네이버 플레이스, 카카오맵, 구글맵 등 다양한 플랫폼에서 고객 리뷰를 받습니다.

하지만 리뷰가 많아질수록
모든 리뷰를 직접 읽고 분석하는 것은 매우 어렵습니다.

실제로는

- 무엇이 가장 큰 문제인지
- 고객들이 어떤 부분을 좋아하는지
- 최근 어떤 문제가 증가하고 있는지

파악하기 어렵습니다.

InsightFlow는 AI를 활용하여
고객 리뷰를 자동으로 분석하고,
소상공인이 빠르게 의사결정을 내릴 수 있도록 도와주는 서비스입니다.

---

# 해결하고자 하는 문제

기존 방식

✔ 리뷰를 하나씩 직접 읽는다.

✔ 감으로 문제를 판단한다.

✔ 개선 효과를 측정하기 어렵다.

↓

InsightFlow

✔ AI가 리뷰를 자동 분석

✔ 주요 이슈 자동 분류

✔ 긍정/부정 감정 분석

✔ 변화 추이 시각화

✔ 개선 우선순위 추천

---

# 핵심 기능

## 1. 리뷰 업로드

- CSV 업로드
- 직접 복사하여 붙여넣기
- 샘플 데이터 제공

---

## 2. AI 리뷰 분석

AI가 리뷰를 분석하여

- 긍정 리뷰
- 부정 리뷰
- 중립 리뷰

를 분류합니다.

---

## 3. 토픽 분석

리뷰를 자동으로 분류합니다.

예시

- 맛
- 가격
- 친절
- 대기시간
- 위생
- 분위기
- 주차
- 서비스

---

## 4. 대시보드

한눈에 확인 가능한 분석 결과

- 리뷰 수
- 평점 변화
- 감정 분석
- 토픽 비율
- 키워드
- 최근 증가한 문제

---

## 5. AI 인사이트

단순 요약이 아니라

AI가

- 가장 시급한 문제
- 개선 우선순위
- 추천 액션

을 제공합니다.

예시

"고객들은 최근 점심시간 대기시간에 대한 불만을 많이 남기고 있습니다.

12시~1시 사이 직원 추가 배치를 고려해보세요."

# 기대 효과

소상공인은

✔ 리뷰를 모두 읽지 않아도 된다.

✔ 고객이 원하는 개선점을 쉽게 파악한다.
