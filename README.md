## 문제 정의
대학생은 자취를 처음 시작하는 경우가 많고 부동산 계약에 익숙하지 않기 때문에 정보의 비대칭성으로 인한 다양한 문제가 발생합니다.
- 가격이 지역의 시세 대비 적절한지 판단이 어려움.
- 관리비가 정상적으로 책정되어 있는지 판단이 어려움.
- 계약서에서 무엇을 확인해야 하는지 모름.
- 온라인 부동산 플랫폼에 올라와 있는 매물이 실제 존재하는 매물인지 판단이 아려움.
- **통학시간과 통학 비용 등 숨겨진 비용을 고려하기가 어려움**
>즉, 매물을 찾기보다 매물을 계약해도 되는지 제대로 결정하기가 더 어렵다.

그리고 첫 자취방을 구하는 대학생은 부동산 용어가 너무 어렵습니다.
- 공급면적/전용면적이 무엇인가? 그 면적이 대체 어느정도인가?
- 동향? 남향? 어느게 좋은 것인가?
>이런 복잡한 부동산 용어들을 혼자서 모두 알아보고 고려하기가 너무 어렵다.

현재의 서비스들은 매물 찾기에 집중되어 있으나, 첫 대학생활의 자취를 꿈꾸는 학생들에게는 의사결정을 도와줄 서비스가 필요합니다.
## 해결 방법
사용자가 입력한 매물 정보와 개인 정보를 바탕으로 AI가 여러 관점에서 분석한 뒤, 개인화된 의사결정 지원 서비스를 제공합니다.
- 해당 매물이 주변 시세, 환경을 고려했을 때 적절한지 검토
- 온라인에 올라와 있는 매물이 실제 존재할 확률이 높은지 검토
- 사용자의 통학 환경 등 개인 환경에 해당 매물이 합리적인지 검토
- 어려운 부동산 용어를 사용자가 쉽게 이해하고 체감할 수 있도록 재해석

## 기능 및 작동 플로우
사용자 정보 입력 -> 매물 스크린샷 업로드 -> AI 분석 -> 분석결과 제공 -> 저장 -> 비교

### 사용자 정보 입력
아래의 입력 데이터를 입력한다.
서비스에 처음 접속할 때 한 번만 작성하도록 한다.
외부 서버 DB가 아닌 localstorage 기능을 사용해 사용자 로컬에 정보를 저장한다.

### 매물 스크린샷 업로드
사용자가 부동산 플랫폼에 올라와있는 매물을 캡처하여 이미지를 업로드한다.
이미지가 업로드되면 Tesseract.js를 통해 이미지를 OCR 방식으로 분석한 뒤 저장한다.

### 지도 기반 통학 분석
서버에서 카카오 지도 API를 호출해 매물 주소와 사용자의 학교 사이 이동 시간과 거리를 계산한다.
환경변수 `KAKAO_REST_API_KEY`가 필요하며, 키가 없거나 지도 API 호출에 실패하면 지도 계산은 생략하고 AI 분석은 계속 진행한다.
