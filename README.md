# 게임 기획 도우미 AI 에이전트

## 프로젝트 소개
게임 개발의 **기획 단계부터 개발까지** 함께하는 AI 에이전트를 만드는 프로젝트입니다.
아이디어 구상, 세계관 설정, 캐릭터 디자인, 게임 시스템 설계는 물론 실제 개발 진행까지
막막함을 느끼는 개발자/기획자를 돕는 것을 목표로 합니다.

## 배경 및 목표
- 게임 개발은 기획부터 실제 구현까지 방향을 잡기 어려운 경우가 많음
- AI 에이전트가 대화를 통해 아이디어를 구체화하고, 문서화 및 개발 진행까지 지원
- 최종적으로는 기획서 초안 자동 생성과 개발 단계 지원까지 이어지는 것을 목표로 함

## 주요 기능 (예정)
- 아이디어 브레인스토밍 지원
- 세계관/스토리 설정 도우미
- 캐릭터 및 시스템 기획 가이드
- 기획서 문서 자동 정리 및 생성
- 기획 이후 개발 진행 지원

## 진행 상태
현재 프로젝트 초기 단계로, 주제 정의 및 소개 자료를 준비 중입니다.
