# AI 분리배출 도우미 (AI Recycling Assistant for Korea)

## 프로젝트 개요

### 프로젝트명

**AI 분리배출 도우미 (AI Recycling Assistant for Korea)**

### 프로젝트 한 줄 소개

> **사진 한 장으로, 한국의 올바른 분리배출 방법을 공식 데이터와 AI를 통해 쉽고 정확하게 안내하는 서비스**

개발 컨벤션(코드 스타일, 커밋 메시지 규칙)은 [CONTRIBUTING.md](./docs/CONTRIBUTING.md) 참고.

# 프로젝트 배경

한국의 분리배출 규정은 국가 공통 규정과 지자체별 규정이 함께 존재하며, 품목별 처리 방법도 매우 다양하다.

특히 다음과 같은 사용자들은 분리배출 과정에서 많은 어려움을 겪는다.

* 외국인 및 교환학생
* 자취생 및 대학생
* 한국의 분리배출 규정을 처음 접하는 사람
* 애매한 품목(종이팩, 아이스팩, 우산, 전자제품 등)의 처리 방법을 모르는 사용자

대부분의 사용자는 인터넷 검색이나 블로그를 통해 정보를 찾지만,

* 정보가 오래되었거나
* 지역별 규정이 다르거나
* 신뢰하기 어려운 경우가 많다.

본 프로젝트는 **공공데이터포털의 공식 데이터를 Source of Truth로 사용**하고, AI는 이를 쉽고 직관적으로 이해할 수 있도록 설명하는 역할을 수행한다.

# 프로젝트 목표

사용자가

> "이거 어디에 버려야 하지?"

라는 고민을

> "사진 한 장이면 끝."

으로 해결하는 서비스를 구축한다.

AI는 물체를 인식하고,

공식 정부 데이터를 기반으로

* 올바른 분리배출 방법
* 준비 과정
* 주의사항
* 지역별 규정

을 안내한다.

---

# 핵심 컨셉

**AI는 분리배출 방법을 '판단'하지 않는다.**

AI의 역할은

* 물체 인식
* 설명
* 번역

이며,

분리배출 규정은 반드시 **공식 정부 데이터**를 기반으로 제공한다.

이를 통해

* 정확성
* 신뢰성
* 유지보수성

을 확보한다.

# 주요 기능

## 1. AI 사진 인식 (핵심 기능)

사용자가 사진을 촬영하거나 업로드하면

Vision AI가 물체를 인식한다.

### 처리 흐름

사진 촬영

↓

Vision AI

↓

물체 이름

↓

정부 API 조회

↓

공식 분리배출 정보

↓

LLM 설명

↓

결과 화면

---

### 결과 화면 예시

**🥤 플라스틱 음료병**

🟢 **PET 재활용**

#### 분리배출 방법

1. 내용물을 비운다.
2. 물로 헹군다.
3. 라벨을 제거한다.
4. 뚜껑을 분리한다.
5. 압착한다.
6. PET 재활용함에 배출한다.

#### 부품별 분리

* 병 몸체 → PET
* 뚜껑 → PP
* 라벨 → 비닐

#### 자주 하는 실수

* 라벨을 제거하지 않고 배출
* 내용물이 남아있는 상태로 배출

#### 왜 이렇게 버려야 하나요?

PET의 재활용 품질을 높이기 위해서는
라벨과 내용물을 제거해야 한다.

---

## 2. 품목 검색

사진 촬영이 어려운 경우

직접 품목명을 검색할 수 있다.

예시

* 건전지
* 우산
* 종이팩
* 아이스팩

검색으로 선택한 물품의 결과는 사진 인식 결과와 동일한 화면을 제공한다.

---

## 3. 지역별 분리배출 규정

사용자는

* 시/도
* 구/군

을 선택한다.

예시

부산

↓

해운대구

↓

* 배출 요일
* 지역별 규정
* 추가 안내사항

을 확인할 수 있다.

---

## 4. 다국어 지원

Translate 버튼 하나로 한국어 ↔ 영어 전환

이를 통해

* 외국인의 이해를 돕고
* 공식 용어를 함께 학습할 수 있도록 한다.

---

## 5. 대형폐기물 신고 가이드

가구나 가전제품과 같은 대형폐기물은

지역별 신고 절차와 수수료가 다르다.

사용자는

품목 선택

↓

지역 선택

↓

수수료 확인

↓

공식 신고 사이트 이동

↓

신고 방법 안내

를 받을 수 있다.

---

## 6. 주변 수거 장소 안내

건전지

형광등

소형가전

종이팩

등의

전용 수거함 위치를 지도 기반으로 제공한다.

---

## 7. 오늘의 배출 일정

사용자가 설정한 지역을 기준으로

홈 화면에서

오늘 배출 가능한 품목을 안내한다.

예시

오늘은

* 플라스틱
* 종이

배출일입니다.

MVP에는 별도의 Push Notification 없이

앱을 실행하면 바로 확인 가능하도록 설계한다.

# AI 역할

## Vision AI

담당 역할

* 물체 인식
* Top Prediction 생성
* Confidence Score 계산

예시

* Plastic Bottle
* Detergent Bottle
* Cooking Oil Bottle

---

## Object Normalizer

Vision AI의 다양한 예측 결과를

서비스 내부의 표준 품목명으로 변환한다.

예시

"Coke Bottle"

↓

"plastic_bottle"

이를 통해

정부 API와 안정적으로 연결할 수 있다.

---

## Government API

프로젝트의 **Source of Truth**

담당 역할

* 공식 분리배출 규정 제공
* 지역별 규정 조회
* 수거 정보 제공

AI는 규정을 생성하지 않는다.

---

## LLM

LLM은

공식 정보를

* 이해하기 쉬운 문장으로 변환
* 단계별 안내 생성
* 번역
* 이유 설명

에만 사용한다.

즉,

LLM은

규칙을 만드는 것이 아니라

공식 정보를 사용자에게 쉽게 전달하는 역할을 수행한다.

# 핵심 차별점

기존 검색 서비스는 사용자가 여러 웹사이트나 블로그를 찾아 정보를 비교해야 하는 경우가 많다.

본 서비스는 **Vision AI**, **공식 정부 데이터**, **LLM**을 결합하여 한 번의 사진 촬영만으로 정확한 분리배출 정보를 제공한다.

또한 AI가 규칙을 임의로 생성하지 않고, 정부의 공식 데이터를 기반으로 설명과 번역만 수행하도록 설계하여 정확성과 신뢰성을 확보한다.

이를 통해 사용자는 보다 쉽고 빠르게 올바른 분리배출 방법을 확인할 수 있으며, 한국의 복잡한 분리배출 규정을 누구나 이해할 수 있는 형태로 제공하는 것을 목표로 한다.
