# 소상공인 폐업 도우미 서비스

폐업을 준비하는 소상공인에게 흩어진 정보를 모아, **내 상황에 맞는 절차만 추려서 보여주고 진행 상태를 추적**하게 해주는 무료 셀프가이드 서비스입니다.

**라이브 서비스:** https://glittering-tapioca-39242f.netlify.app

## 문제 정의

폐업 시 필요한 정보(폐업신고 절차, 세무 신고, 정부 지원금)는 홈택스, 정부24, bizinfo.go.kr, 소상공인시장진흥공단 등 여러 공식 사이트에 흩어져 있습니다. 게다가 업종·직원 유무·임대 여부에 따라 실제로 필요한 절차가 달라, 사용자가 스스로 뭐가 해당되는지 판단하기 어렵고 세무 신고 같은 마감기한도 놓치기 쉽습니다.

이 서비스는 상황을 한 번 입력하면 그에 맞는 절차·일정·지원금만 추려서 보여주고, 마감이 임박한 순서대로 무엇을 먼저 해야 하는지 안내하며, 지금까지 얼마나 처리했는지 한 곳에서 확인할 수 있게 합니다.

## 핵심 기능

1. **상황 진단 온보딩** — 업종 / 개인·법인 여부 / 직원 유무 / 임대 여부 / 폐업 예정일 5문항으로 프로필 생성
2. **맞춤 체크리스트 대시보드** — 프로필에 맞는 항목만 필터링, D-day 임박 순 + 완료 항목 하단 정렬
3. **폐업 신고 절차 안내** — 각 항목에 "왜 나에게 해당되는지" 근거, 준비 서류 sub-체크리스트 제공
4. **세무 신고 일정 안내** — 부가세·종합소득세 신고 일정 안내, 구체 세율은 홈택스 공식 링크로 위임
5. **지원금 및 재기 지원** — 희망리턴패키지 등 조건에 맞는 정부 지원사업과 근거 함께 제공
6. **완료 날짜 기록** — 체크 처리한 날짜를 카드에 표시
7. **메모 기능** — 각 카드에 짧은 메모 입력, 블러 시 자동 저장 (체크 초기화 시에도 보존)
8. **마감 임박 브라우저 알림** — D-7 이내 미완료 항목이 있을 때 알림 (허가 기반)
9. **관할 세무서 찾기** — 시/도 선택 시 담당 지방국세청 전화번호 + 네이버 지도 링크
10. **관련 기관 전화번호** — 홈택스, 소상공인시장진흥공단, 고용보험 등 주요 연락처

## 차별점

기존 서비스(희망리턴패키지, 폐업119 등)는 "신청 → 전문가 배정/매칭"의 유료·중개형 흐름입니다. 이 서비스는 중개·거래 없이 **무료로 자가진단하고 스스로 진행 상태를 추적**하는 셀프서비스형 도구로 차별화합니다.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프론트엔드 | React + Vite + TypeScript |

## 로컬 실행 방법

### 프론트엔드

```bash
npm i            # 의존성 설치
npm run dev      # 개발 서버 실행 (http://localhost:5173)
npm run build    # 프로덕션 빌드
```

`.env.local` 파일을 루트에 생성하세요:

```
VITE_API_URL=http://localhost:4000
```

### 백엔드

```bash
cd server
npm i                    # 의존성 설치
npm run dev              # 개발 서버 실행 (http://localhost:4000)
npm run prisma:migrate   # DB 마이그레이션
```

`server/.env` 파일을 생성하세요 (`server/.env.example` 참고):

```
DATABASE_URL=
PORT=4000
CORS_ORIGIN=http://localhost:5173
NODE_ENV=development
```

### FE + BE 동시 실행

```bash
npm run dev  # 루트에서 실행 — concurrently로 FE·BE 동시 기동
```

## 법적 고지

본 서비스는 세무·법률 대리 업무를 수행하지 않으며, 절차 안내와 공식 출처 링크만 제공합니다. 정확한 세율·금액·기한 등은 반드시 관할 기관(세무서, 홈택스, 정부24 등)에서 확인하세요.
