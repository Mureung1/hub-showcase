# 내 취향 맞춤형 매장 추천 시스템

### 문제 정의

개인별 취향이 배제된 일률적 별점 시스템으로 인해 **소비자**는 주관적 리뷰에 의존해 광고성·비취향 가게를 고르는 피로를 겪고, **소상공인**은 특정 요소에 대한 일부 유저의 불만족(예: 매운맛 등)으로 인한 무분별한 낮은 별점 타격을 입는다.

### 사용자 시나리오

1. 사용자는 앱 진입 시 매운맛, 가성비, 분위기, 웨이팅, 조용함 등 5가지 성향 항목을 1~10점으로 초기 설정한다.
2. 주변의 특정 메뉴(예: 수플레 카페)를 검색하면 지도와 함께 근처에 있는 가게 리스트(예: 3~5개의 카페)가 나타난다.
3. 여러 후보군 중 어디로 갈지 고민될 때, 목록 상단의 **[우선순위 추천]** 버튼을 눌러 자신이 중요시하는 가치(1순위 분위기, 2순위 매운맛 등)를 설정하여 맞춤형 최적의 가게를 추천받는다.
4. 결정된 가게의 상세 페이지로 이동한 뒤, **[나와 비슷한 사람 리뷰 보기]** 탭을 클릭해 취향 유사도가 높은 유저들이 남긴 신뢰도 높은 별점과 상세 의견을 확인한다.
5. 가게에 직접 방문한 후에는 사진인증을 통해 실제 방문을 인증하고 리뷰를 남기며 다른 유저의 평가에 공감/비추천 피드백을 보낸다.

### 핵심 기능

- **취향 유사도 기반 리뷰 필터링 & 정렬**: 나랑 성향 설정이 유사한 유저들의 별점을 우선 노출하고 카드에 "나와 취향 X% 비슷함"을 표시하여 리뷰 신뢰도 구축.

```jsx
취향 유사도 =
{1 - (점수 차이 합계 / 45)} × 100
```

- **우선순위 가중치 기반 맞춤형 가게 추천**: 목록 단계에서 유저가 지정한 우선순위(1~3순위)와 베이지안 보정 호평률을 결합해 최적의 후보지를 상위에 추천.

```jsx
보정 호평률 =
(카테고리 호평 수 + 5)
÷
(전체 리뷰 수 + 10)

1순위 = 5점
2순위 = 3점
3순위 = 1점

**최종 점수** =
 1순위 보정 호평률 × 5
+ 2순위 보정 호평률 × 3
+ 3순위 보정 호평률 × 1
```

(리뷰 수가 너무 적은 가게가 우연히 높은 평점을 받아 과대평가되는 것을 막기 위해, 전체 평균을 함께 반영한 보정 점수를 사용한다.)

⇒사용자가 중요하게 생각하는 기준을 1~3순위로 선택하면, 각 기준에 가중치를 부여하고 리뷰 신뢰도와 보정 평점을 함께 반영해 가장 적합한 가게를 추천한다.

- **내 서비스가 해결하는 문제**
    - 리뷰 작성자의 주관적인 성향 차이로 인해 평점 시스템의 신뢰도가 떨어지고, 그 결과 소비자는 가게 선택에 어려움을 겪으며 소상공인은 억울한 낮은 별점 피해를 입는 문제를 해결한다.
- **핵심 기능을 이 2개로 고른 이유**
    - **취향 유사도 리뷰**: 타인의 주관적 평가가 내 기준과 맞지 않아 생기는 '리뷰 불신'을 해결하기 위해, 나와 기준점이 비슷한 페르소나의 데이터만 발라내어 신뢰도를 주기 위함
    - **우선순위 가중치 추천**: 검색 목록에서 단순 별점 높은 순으로만 나열하면 내 목적(ex: 맛은 평범해도 조용하고 분위기 좋은 곳)에 맞는 가게를 한눈에 비교하기 어렵기 때문에, 선택의 기로에 놓인 유저의 결정 프로세스를 단축시켜 주기 위함
