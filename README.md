# 🐣 One-Step

> 도전을 시작하지 못하는 대학생을 위한 **캐릭터 육성형 도전 앱**

작은 도전을 하나씩 해내며 나만의 캐릭터를 키워가는 앱입니다.
"내가 할 수 있을까?" 망설이는 사람도 부담 없이 **첫걸음(One-Step)**을 뗄 수 있도록 돕습니다.


## 어떤 앱인가요?

대외 공모전이나 대외 활동은 좋은 기회지만, 자존감이 낮으면 시작조차 어렵습니다.
One-Step은 도전을 **아주 작은 퀘스트**로 쪼개고, 완료할 때마다 **코인과 경험치**를 줍니다.
그 보상으로 캐릭터를 키우고 꾸미다 보면, 어느새 도전이 습관이 됩니다.

### 사용자 플로우
**도전(퀘스트) → 보상(코인, 경험치) → 캐릭터 성장**

이 선순환으로 **직접 해야 한다**는 부담을 덜고, 작은 성취를 쌓아 자신감을 회복하는 것이 목표입니다.


## 주요 특징

- 🎯 **퀘스트**: 하고 싶은 도전을 직접 등록하고 완료하면 코인과 경험치 획득
- 🐦 **캐릭터 육성**: 알에서 시작해 레벨업으로 단계별 진화 (알 → 참새 → 매 → 독수리)
- 🛍️ **꾸미기**: 모은 코인으로 배경과 이펙트 등 치장 아이템 구매
- ✨ **환생**: 50레벨 달성 시 환생, 표식을 모으며 새로운 캐릭터(알) 해금
- 📸 **성취 보관함**: 완료한 도전을 사진과 메모로 기록하고 자랑
