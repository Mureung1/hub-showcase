# 리뷰 관리 AI 에이전트 

> 소상공인의 리뷰 관리를 대신해주는 AI 에이전트 — 답글 자동 작성 · 리뷰 분석 · 블랙컨슈머 대응

**📌 현재 상태: 기획 단계** — 상세 내용은 [기획서](docs/기획서.md)를 참고하세요.

## 왜 만드나요?

배달 매장을 운영하는 사장님은 매일 쏟아지는 리뷰에 답글을 달 시간이 없습니다. 리뷰가 매출에 직결된다는 걸 알면서도 데이터를 모아 분석하기는 어렵고, 악성 리뷰나 블랙컨슈머를 만나면 어떻게 대응해야 하는지 막막합니다.

이 프로젝트는 **리뷰 수집 → 답글 작성 → 분석 → 악성 리뷰 대응**까지, 리뷰 관리의 전 과정을 AI 에이전트가 대신하는 것을 목표로 합니다.

## 핵심 기능

### ✍️ 리뷰 답글 자동 생성
리뷰를 칭찬/불만/문의/악성으로 자동 분류하고, 매장의 톤앤매너를 반영한 답글 초안을 생성합니다. 게시 방식은 사장님이 직접 선택합니다 (수동 승인 / 조건부 자동 / 완전 자동).

### 📊 리뷰 분석
감성 분석, 키워드·토픽 추출(맛/양/배달/포장/서비스), 주간·월간 리포트를 제공하고 "최근 2주간 배달 지연 불만 3배 증가" 같은 실행 가능한 인사이트를 뽑아냅니다.

### 🛡️ 블랙컨슈머 대응
악성 리뷰(욕설, 협박, 환불 강요, 허위 사실)를 감지해 위험도를 3단계로 분류하고, 답글 가이드부터 플랫폼 신고 절차, 증거 수집 체크리스트, 법적 대응까지 단계별 매뉴얼을 제시합니다.

## 어떻게 동작하나요?

```
리뷰 수집 → 유형·위험도 분류 → 답글 초안 생성 / 대응 매뉴얼 제시 → 게시 (자동화 수준 선택) → 분석 리포트
```

인터페이스는 **웹 대시보드**가 메인이며, 추후 카카오톡/텔레그램 **챗봇 알림**을 추가할 예정입니다.

## 로드맵

| 단계 | 범위 |
|---|---|
| **Phase 1 (MVP)** | 리뷰 수동 입력 기반 — 분류 + 답글 초안 + 기본 분석 + 대응 매뉴얼, 웹 대시보드 |
| **Phase 2** | 배달의민족 리뷰 자동 수집, 답글 게시 자동화, 정기 리포트, 챗봇 알림 |
| **Phase 3** | 네이버 스마트플레이스 · 쿠팡이츠 · 요기요 · 구글 등 멀티 플랫폼 확장 |

첫 타겟 플랫폼은 **배달의민족**이며, 수집·게시 로직을 플랫폼별 어댑터로 분리해 모든 리뷰 채널로 확장하는 것이 최종 목표입니다.
