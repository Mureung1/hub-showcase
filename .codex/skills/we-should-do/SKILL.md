# We should do..

## 먼저 읽을 것

- 제품 기획서: @서비스 기획서.md
- 프로토타입 README: @README.md
- 메인 프로토타입 코드: @src/components/Scheduler.tsx
- 스케줄러 스타일: @src/components/scheduler.css
- 미리보기 이미지: @docs/prototype-preview.png, @docs/myhome-preview.png

## 제품 규칙

- 정식 명칭은 `We should do..`를 사용한다.
- 생산성이 우선, 게임은 그 다음.
- 비율 유지: 생산성 70 / 게임 30.
- 타깃 사용자: 20대.
- 핵심 무드: 귀엽고, 부드럽고, 파스텔톤이고, 도트풍.
- 핵심 순환: 할 일 → 완료 → 영상 인증 → 친구 반응 → 포인트 → 두두/마이홈.
- 모든 일정은 개인 일정이다.
- 일정 공유는 카테고리 공개 설정 단위로 한다.
- 친구 그룹 안에 일정을 만들지 않는다.
- 새 카테고리는 기본적으로 비공개.
- 일정별 공개 범위 예외 설정을 허용한다.
- 캘린더 아젠다는 모든 일정을 함께 보여준다.
- 요청이 없으면 아젠다를 카테고리별로 묶지 않는다.
- 탭 구성: 홈, 두두, 친구, 마이페이지.
- `두두` 탭은 `할 일` 탭이 아니다.

## 두두(DODO) 규칙

- 캐릭터명: 두두 / DODO.
- 두두는 미루는 마음에서 태어났다.
- 두두는 절대 사용자를 혼내지 않는다.
- 못 끝낸 날에도 두두는 사용자 곁에서 기다린다.
- 두두가 유일한 마스코트 종이다.
- 다른 마스코트를 추가하지 않는다.
- 저해상도 도트 그래픽을 사용한다.
- 몸통: 모서리가 둥근 직사각형 몬스터.
- 눈: 2~4px 크기의 검은 점눈.
- 눈 개수는 커스터마이징에 따라 달라질 수 있다.
- 다리: 몸통과 같은 색의 굵은 선형 다리.
- 더듬이는 없다.
- 파스텔톤 몸 색상을 사용한다.

## 일기 규칙

- 영상 인증 후에 두두가 짧은 일기를 쓴다.
- 말투: 귀엽고, 따뜻하고, 장난스럽게.
- 죄책감을 유발하지 않는다.
- 부끄럽게 만들지 않는다.
- 예시 말투: "오늘 주인은 40분 동안 운동했다. 나는 소파에서 응원했다."

## UI 규칙

- 파스텔 컬러를 사용한다.
- 픽셀/도트 그래픽 무드를 사용한다.
- 그라데이션보다 단색을 우선한다.
- 블러보다 블록형 그림자를 우선한다.
- 4px 그리드를 사용한다.
- 둥근 카드에 픽셀 디테일을 더한다.
- 가독성을 최우선으로 유지한다.
- 짧고 친근한 한국어 UI 문구를 사용한다.

## 코드 규칙

- React 컴포넌트는 `.tsx`를 사용한다.
- 가능하면 상태 로직을 큰 UI 파일 밖으로 분리한다.
- 실용적인 경우 시각 스타일은 CSS로 처리한다.
- UI, 데이터, 상태, 스타일을 하나의 거대한 컴포넌트에 몰아넣지 않는다.
- 목데이터는 별도로 분리해서 관리한다.
- 타입은 별도로 분리해서 관리한다.
- 캘린더 일정 항목은 다음 4가지를 항상 지원해야 한다:
  - 제목 수정
  - 시간 수정
  - 삭제
  - 완료 체크박스
- 일정 시간이 없으면 빈 값으로 표시한다.
- `시간 미정` 같은 문구를 쓰지 않는다.

## 개인정보 규칙

- 기본값은 비공개.
- 영상 인증을 공유하기 전에 공개 대상을 확인한다.
- 사용자는 영상 인증을 삭제할 수 있다.
- 사용자는 일기를 삭제할 수 있다.
- 필요한 곳에는 차단/신고/댓글 제한 개념을 제공한다.
- 정확한 위치 정보는 기본적으로 노출하지 않는다.
- 재촉·압박성 알림 문구를 쓰지 않는다.

## 하지 말 것

- 새로운 앱 이름을 만들지 않는다.
- 두두의 이름을 바꾸지 않는다.
- 앱을 순위표(리더보드) 중심으로 만들지 않는다.
- 유료 아이템이 생산성 측면에서 우위를 주게 만들지 않는다.
- 포인트를 힘/우위로 바꾸지 않는다.
- 일정을 기본적으로 그룹 소유로 만들지 않는다.
- 일정을 기본적으로 공개 노출시키지 않는다.
- 관련 없는 게임 시스템을 추가하지 않는다.
- 고해상도의 사실적인 캐릭터 아트를 쓰지 않는다.
- 기존 브랜드 캐릭터를 모작하지 않는다.
- 죄책감·수치심·위협성 문구를 쓰지 않는다.
