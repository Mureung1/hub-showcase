# 공지 평가셋

검증2에서 모은 공지 10건을 여기에 `*.json` 으로 둔다 (일회성 테스트로 버리지 않고 회귀 테스트용으로 보관).

## 파일 형식
```json
{
  "id": "wonchon-0330",
  "raw_text": "공지 원문 전문...",
  "ground_truth": {
    "event_name": "...",
    "location": "...",
    "period": "YYYY-MM-DD ~ YYYY-MM-DD",
    "affected_lines": ["B1"],
    "affected_stops": ["..."]
  }
}
```

## 수집 대상 10건 (checklist 1주차 P0)
- 원촌육교 통제, 문평동 화재 우회
- 0시축제(PDF 첨부형 포함)
- 시간표 변경 2~3건
- 세종 1~2건, 마라톤 1~2건

> PDF 에만 정보 있는 공지가 있어서, 추출 실패 시 제목+요약+링크로 제한 (검증2 킬 조건: 10건 중 7건 미만이면 스코프 축소).
