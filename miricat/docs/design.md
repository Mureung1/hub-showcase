# 미리캣 디자인 규칙

미어캣이 접이식 의자에 앉은 사진에서 뽑은 규칙. 따뜻한 모래톤 + 유일한 쿨톤 포인트(블루).
실제 토큰은 `frontend/src/theme.css` 에 CSS 변수로 있고, 이 문서는 그 규칙을 설명한다.
색으로 정보의 무게를 구분하는 게 핵심: **경보=빨강 / 참고=앰버 / 정상=초록 / 경로·강조=블루**.

시각 미리보기: [`design-styleguide.html`](./design-styleguide.html) (브라우저로 열기)

## 색 (Color)
| 이름 | 값 | 쓰임 |
|------|-----|------|
| `--ink` | `#33261A` | 본문 글자 (짙은 흙색) |
| `--paper` | `#FBF6EE` | 페이지 배경 (모래빛) |
| `--card` | `#FFFFFF` | 카드 표면 |
| `--mist` | `#ECE1CF` | 경계선·구분선 |
| `--slate` | `#8B7863` | 보조 텍스트·캡션 |
| `--signal` / `--signal-soft` | `#E4572E` / `#FCE8DF` | **경보 (Tier1, 빨강)** |
| `--warn` / `--warn-soft` | `#C98A00` / `#FBEFD2` | **참고 알림 (Tier2, 앰버)** |
| `--route` / `--route-soft` | `#3E7CB1` / `#E9F1F8` | 지도 경로·링크·강조 (블루) |
| `--good` / `--good-soft` | `#5B8A5A` / `#E9F1E6` | 정상·완료 (초록) |
| `--fur` / `--fur-light` / `--fur-dark` | `#DCA96E` / `#F2DDB6` / `#4A3423` | 미어캣 캐릭터 털 |
| `--chat` | `#2E2823` | 디스코드 채널 배경 (다크) |

**규칙**
- 한 화면에서 강조색은 아껴 쓴다. 경보(빨강)는 진짜 영향 있을 때만.
- Tier1(도로 통제 = 확정 영향)은 빨강, Tier2(이벤트 일정 = 가능성)는 앰버. 절대 섞지 않는다.
- 파랑은 경로/링크/추천 같은 "중립 강조", 초록은 "이상 없음/통과".

## 폰트 (Type)
- 본문: **IBM Plex Sans KR** (400/500/600/700)
- 숫자·시각·코드: **IBM Plex Mono** (기간, 정류장 수, 시각 등)
- 사이즈 스케일(px): 12 / 14 / 16(기본) / 20 / 28 / 40. 제목엔 `letter-spacing: -0.02em`, `text-wrap: balance`.
- 본문 줄간격 1.55~1.6.

## 모서리 (Radius)
- 카드 `16px`(리포트/프레임은 16~18px) — 부드럽고 편안한 톤.
- 버튼·인풋 `9~12px`, 태그·알약 `100px`(full).

## 여백 (Spacing)
- 4px 배수 스케일: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64.
- 카드 내부 패딩 기본 `20~24px`. 그룹 간격은 `gap`으로.

## 그림자 (Shadow)
햇빛 아래 그림자처럼 웜톤으로. 예: `0 20px 40px -32px rgba(51,38,26,.35)`.

## 카드 스타일
- 표면 `--card` + 얇은 `--mist` 테두리 + 웜톤 그림자 + `--radius`.
- ⚠️ 가짜 브라우저 크롬(신호등 점 + URL 주소창)을 카드에 넣지 않는다 — "웹 속의 웹"처럼 어색함.
- 알림 무게 차이: 경보 embed는 왼쪽 빨간 띠, 참고는 앰버 띠.

## 캐릭터 (미어캣)
- SVG로 한 번 정의(`#miricat`, `#miricat-face`)하고 `<use>`로 재사용.
- 브랜드 핵심이라 무조건 등장. 리포트 지도에선 막히는 구간 옆에 서서 "지켜보는 중".
- 눈 깜빡임/두리번/레이더 애니메이션은 시도했다가 뺌(안 예쁨). 미어캣은 정적으로.
