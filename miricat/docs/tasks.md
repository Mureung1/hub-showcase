# 미리캣 개발 Task (Jira 스타일 백로그)

## 백로그란

해야 할 일을 전부 한 곳에 쌓아두고 우선순위를 매긴 목록. 개발 중에 "다음에 뭐 하지"를 매번 고민하지 않고 위에서부터 꺼내 쓰기 위해 필요하다. 보통 큰 기능 단위(에픽) 아래에 하루 안팎의 작업(티켓)을 두고, 각 티켓에 우선순위와 완료 조건을 붙여 관리한다. 계획은 바뀌는 게 정상이라, 밀린 티켓을 다음 스프린트로 옮기는 조정도 백로그 관리의 일부다.

아래는 미리캣의 백로그. 스프린트는 주 단위 4개(S1~S4)이고, **다음 주(S2)까지 끝낼 것**은 EPIC-2(평가셋·추출 검증)와 EPIC-3(경로 등록), 그리고 조사 그래프 한 바퀴(MIRI-13, 14, 19)다.
