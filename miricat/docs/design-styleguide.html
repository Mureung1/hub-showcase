미어캣 스타일 가이드

따뜻한 모래톤 위에 접이식 의자 천의 블루 스트라이프 하나를 포인트로 얹은 규칙 모음. 아래 모든 요소는 CSS 변수로만 제어됩니다.

색상 (Color)

주색은 미어캣 브라운, 유일한 쿨톤 포인트는 스트라이프 블루입니다.

타이포그래피 (Type Scale)

Sans 계열 · 4px 기반 사이즈 스케일. 제목은 balance 처리.

모서리 (Radius)

카드는 20px로 크게 잡아 편안한 톤을 유지합니다.

여백 (Spacing · 4px grid)
