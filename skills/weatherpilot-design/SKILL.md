# WeatherPilot Design System

WeatherPilot의 화면을 만들 때는 아래 규칙을 그대로 따른다. 지금까지 목업에서 확정한 톤이며, 임의로 색·크기·폰트를 바꾸지 않는다.

## 언제 사용하나

- WeatherPilot의 새 화면(대시보드·검토·성과·설정 등)을 만들 때
- 기존 화면에 카드/알약/타일/버튼을 추가할 때
- 톤·색·간격이 흔들리지 않게 일관성을 맞춰야 할 때

## 절대 규칙 (먼저 읽는다)

1. **외부 스타일링 라이브러리 금지** — Tailwind, styled-components, MUI 등 전부 금지. 인라인 스타일 또는 순수 CSS(토큰 변수)만 사용한다.
2. **색·간격·라운드는 반드시 토큰(CSS 변수)으로** — 하드코딩 hex를 흩뿌리지 않는다. 토큰 전체는 `references/tokens.css` 참고.
3. **시인성이 최우선** — 파란 배경 위 텍스트는 반투명 회색/연블루 금지. 반드시 **불투명 흰색(#FFFFFF) + medium 이상 굵기**.
4. **핵심 수치는 알약(pill)으로 강조** — 본문 색과 같게 두지 않는다. (아래 진단 알약 규칙)

## 색상

- 브랜드 블루: `--color-primary #4A90E2`, 그라데이션 `linear-gradient(160deg,#62A8F5,#4A90E2)`
- 배경: 앱 `#EEF3F8`, 카드 `#FFFFFF`, 보조 타일/입력 `#F4F7FA`, 구분선 `#E4EAF1`
- 텍스트: 주요 `#253449`, 보조 `#8B95A5`, 캡션 `#B0B8C4`, 블루 카드 위 `#FFFFFF`
- **강조 액센트 — 알약 전용**:
  - 매출 하락(경고): 주황 `#FF7A45` + ▼
  - 매출 상승(긍정): 초록 `#2FB37A` + ▲
- 파란 배경 위 보조 요소(뱃지 배경)는 `rgba(255,255,255,0.28)`, 구분선은 `rgba(255,255,255,0.4)`

## 타이포그래피

- 폰트: `"Poppins", -apple-system, "Segoe UI", Roboto, sans-serif`
- 크기: 캡션 12 / 라벨 14 / 본문 16 / 제목 20 / 큰수치(온도) **40px**
- 굵기: regular 400 / medium 500 / semibold 600 / bold 700
- **섹션 라벨**("오늘의 날씨", "이 가게 매출 진단")은 라벨(14px) + **bold**. 너무 키우지 않는다(본문 16px는 과함).
- 온도는 40px bold, 단위까지 **한 덩어리로 같은 크기·같은 굵기**("18°C"). 단위만 작게 만들지 않는다 — 굵기·크기가 어긋나 이상해진다.

## 라운드 · 간격 · 그림자

- 라운드: sm 8 / md 12 / lg 16(메인 카드) / xl 20(피처 카드) / pill 999
- 간격(4px 스케일): 4·8·12·16·20·24·32. 카드 패딩 기본 20(`--space-5`).
- 그림자: 흰 카드 `0 8px 24px rgba(74,144,226,.10)`, 블루 카드 `0 10px 28px rgba(74,144,226,.28)`, 리스트 셀 `0 2px 8px rgba(37,52,73,.05)`

## 컴포넌트 규칙

### 피처 카드(블루) — 현재 날씨/진단 히어로
- 배경 그라데이션, 라운드 xl(20), 흰 텍스트.
- 정보 위계(위→아래): **섹션라벨(bold) → 큰 온도(40px) + 왼쪽 날씨 아이콘(약 76px) → 소스 평균 뱃지 → (구분선) → 진단 라벨(bold) → 진단 알약**.
- 소스 평균 뱃지("기상청·OpenWeather·AccuWeather 평균")는 **날씨 정보 영역 안**(온도 아래)에 둔다. 진단 밑으로 내리지 않는다 — 무엇에 대한 근거인지 헷갈린다.

### 진단 알약 (핵심 강조 요소)
- 수치는 반드시 알약으로 감싼다. `padding:8px 16px; border-radius:pill; 흰 글씨 bold 20px`.
- 하락이면 `--down`(주황 #FF7A45 + ▼), 상승이면 `--up`(초록 #2FB37A + ▲).
- **방향 기호(▼/▲)는 텍스트 글리프로, 옆 글씨와 대등한 크기**로 키운다(폰트 여백 때문에 명목상 약 22px여야 옆 20px 글씨와 비슷하게 보임). SVG 화살표는 작아서 쓰지 않는다.

### 흰 카드 / 타일 / 토글 / 리스트 / 버튼
- 흰 카드: 배경 흰색, 라운드 lg(16), 패딩 20, 카드 그림자.
- 보조 타일: 배경 `#F4F7FA`, 라운드 md(12), 패딩 16.
- 세그먼트 토글: 트랙 `#F4F7FA` pill, **활성 탭은 불투명 블루 배경 + 흰 글씨 bold**(반투명 금지 — 안 보인다). 비활성은 진한 텍스트(`#253449`).
- 리스트 셀: 좌 아이콘 타일 + 본문 + 우측 금액. 항목 사이 `1px #E4EAF1` 구분선, 마지막 항목은 구분선 없음.
- 주 버튼: pill, 블루 배경, 흰 글씨 semibold, 블루 그림자.

## 마이크로카피 / 이모지

- **할인·프로모션 캠페인 문구에는 이모지를 적극 사용**한다(예: `☔ 🙅‍♀️ ☕ 🏃‍♂️💨 🎉✨`). 소상공인 SNS/문자 톤에 맞춘다.
- **쿠폰·프로모션 표기 앞 기호는 🎟️ 이모지**를 쓴다(추상적 SVG 아이콘 대신).
- 액션 라벨은 능동형("제안 검토하기", "이대로 발송하기"). 시스템 용어로 쓰지 않는다.
- 이모지 모양은 OS/브라우저마다 다르게 보이므로, 실제 발송 대상 기기에서 한 번 확인한다.
