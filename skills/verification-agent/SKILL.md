# Verification Agent Skill

## Overview (개요)
이 스킬은 프론트엔드, 백엔드, 데이터베이스 연동 작업이 완료된 후, 기획서의 기능 명세와 브랜드 디자인 정책(August* 스타일)을 완벽하게 만족하는지 검증하고 결함을 미리 잡아내는 역할을 정의합니다.

## When to Use (사용 시점)
- 특정 작업 단위(Issue)의 구현을 마치고 다음 작업으로 넘어가기 전.
- API 엔드포인트 연동이 완료되어 실제 데이터가 DB에 쓰이고 읽히는지 확인할 때.
- UI 구현을 마친 후 디자인 가이드라인 준수 여부를 최종 확인할 때.

## Process (수행 절차)

### 1단계: API 및 데이터베이스 검증
- **HTTP 통신 검증**: cURL, Thunder Client 또는 스크립트를 사용하여 구현된 API를 호출하고 다음 항목을 점검합니다.
  - 응답 HTTP 상태 코드 (성공 시 200/201, 에러 시 400/403/404/500 등)
  - 응답 JSON 페이로드의 key 구조가 기획 명세와 정확히 일치하는가?
- **DB 무결성 검증**: 데이터베이스(MySQL)에 직접 접속하거나 Prisma Client 쿼리를 실행하여 실제 테이블에 레코드가 의도대로 적재되었는지 확인합니다.
  - 동일 유저의 중복 투표가 차단되었는가? (데이터 유니크 제약 테스트)

### 2단계: 브랜드 디자인 시스템(August* 스타일) 검증
- **소문자 규칙 (Lowercase Rule)**:
  - 브라우저에 표시되는 모든 텍스트(제목, 버튼, 탭, 알림 메시지 등)가 대문자 없이 완벽히 `lowercase`로 쓰였는지 확인합니다.
- **직각 모서리 규격 (Sharp Corners Rule)**:
  - 알약형 모양의 Action 버튼이나 배지를 제외한 모든 카드 컴포넌트, 이미지 프레임, 인풋(Input) 상자, 상세 모달의 모서리가 `border-radius: 0`을 준수하여 날카로운 직각을 띠고 있는지 CSS를 확인합니다.
- **색상 팔레트 검증**:
  - 배경은 `#000000`(Pitch Black), 텍스트는 `#FFFFFF`, 포인트는 `#d4ff00`(Lime Green)을 정확하게 따르고 있는지 점검합니다.

### 3단계: 동적 인터랙션 및 애니메이션 검증
- **물리 스폰 스케일업**: 신규 아이템 추가 시 크기가 0에서 시작하여 0.3초간 팽창하며 나타나고 탄성(Elastic Bounce) 효과가 일어나는지 브라우저에서 관찰합니다.
- **마우스 호버**: 카드 컴포넌트에 마우스를 올렸을 때 그레이스케일이 정상 해제되며 부드럽게 스케일이 커지는지 확인합니다.
- **토스트 알림**: 동작 완료 시 하단에서 페이드업되는 알림창이 정상적으로 나타났다가 3초 후에 자연스럽게 사라지는지 확인합니다.

### 4단계: 에지 케이스(Edge Case) 및 보안 검증
- **Lock-in 데드라인 차단**: 서버 시간을 금요일 09:00 이후로 조작하거나 임시 테스트 조건(어드민 강제 락 토글) 하에서 투표를 제출했을 때, 프론트에서 투표가 잠기고 백엔드에서 `403 Forbidden`을 던지는지 확인합니다.

## Common Rationalizations (흔한 합리화)
- *"화면에 오류 메시지가 안 뜨니까 문제없이 잘 실행되었을 것이다"* ➡️ **오류**. 실제 데이터베이스(MySQL)를 직접 조회해 보기 전까지는 값이 엉뚱한 테이블 필드에 들어갔거나 무시되었을 수 있습니다.
- *"영어 로고 첫 글자만 대문자로 고치는 건 사소하니까 그냥 넘어가자"* ➡️ **오류**. August* 에디토리얼 테마의 완성도는 작은 대소문자 규정 준수에서 비롯됩니다.

## Red Flags (금지 사항)
- 실제 화면을 띄워 보거나 API에 직접 Request를 날려 보지 않고 눈대중으로만 검증을 승인하는 것.
- QA(Quality Assurance) 단계 없이 바로 PR을 올리거나 최종 완료를 사용자에게 전달하는 것.

## Verification (검증 방법)
- [ ] API 응답 상태 코드 및 반환 JSON 필드 검증 테스트 기록을 확보하였는가?
- [ ] 브라우저에서 직접 시나리오 동작을 손으로 검증하고, 변경된 DB 행(Row)을 쿼리로 확인했는가?
- [ ] August* UI 체크리스트(Lowercase, sharp corners)를 모두 확인하여 통과했는가?
