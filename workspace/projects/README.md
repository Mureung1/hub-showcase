# Projects

각 게임 프로젝트는 `workspace/projects/<project_slug>/` 아래에서 독립적으로 관리한다.

프로젝트 폴더에는 다음 항목을 둔다.

- `project_brief.md`
- `design/`
- `ideas/temporary_ideas.md`
- `approvals/approval_queue.md`
- `decisions/decision_log.md`
- `versions/version_history.md`

등록 프로젝트와 현재 기본 프로젝트는 `workspace/project_registry.md`에서 확인한다.
