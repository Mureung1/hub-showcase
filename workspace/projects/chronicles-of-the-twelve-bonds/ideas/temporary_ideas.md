#### Idea

##### 프로젝트 기본 방향

- 동양풍 시나리오를 중심으로 전개되는 TRPG를 만든다.
- 세계관은 한국·중국·일본의 문화와 신화 요소를 혼합한 독립 가상세계로 구성한다.
- 한 명의 플레이어가 플레이하며, AI가 게임 마스터 역할을 맡는다.
- 플레이어 입력은 선택지와 자연어 입력을 병행한다.
- 시나리오 진행상의 장면·구간별로 `선택지 전용` 또는 `선택지+자연어 입력` 방식을 사용한다.
- 입력 방식의 전환은 맵상의 장소가 아니라 현재 진행 중인 장면을 기준으로 한다.
- 주요 분기나 규칙상 행동 범위를 제한해야 하는 장면은 `선택지 전용`으로 구성한다.
- NPC 대화, 조사, 자유 행동 중심의 역할극 장면은 `선택지+자연어 입력`으로 구성한다.
- 개발 엔진은 Unity를 사용한다.
- 목표 플랫폼은 PC다.
- 탐험을 적당히 포함한 평균 1회차 목표 플레이 시간은 약 2시간이다.
- 메인 시나리오 위주로 진행하면 2시간보다 짧아지고, 많은 탐험과 진엔딩 조건을 노리면 더 길어질 수 있다.
- TRPG 경험이 없는 초보자도 별도 사전 지식 없이 플레이할 수 있게 구성한다.
- 프로젝트명과 AI 게임 마스터의 구체적인 진행 방식은 아직 정하지 않았다.

##### 초보자 접근성 원칙

- 고정 선택지만 사용해도 메인 시나리오를 정상적으로 진행할 수 있다.
- 자연어 입력은 플레이어가 원하는 행동을 확장하는 선택 기능으로 두고 사용을 강제하지 않는다.
- 판정, 십이지신 편성, 방향 보너스, 해금·강화 등 새로운 규칙은 처음 등장할 때 짧게 설명한다.
- AI 게임 마스터는 플레이어가 진행 방법을 묻거나 오래 머뭇거리면 현재 장면에서 가능한 행동 예시를 제시한다.
- 선택지와 판정 결과에는 필요한 정보를 명확하게 표시하고, TRPG 용어는 도움말에서 다시 확인할 수 있게 한다.

##### AI 게임 마스터 운영 규칙

- AI는 플레이어의 선택을 유도하고, 세계관을 묘사하며, 정해진 규칙에 따라 서사를 진행하는 동양 판타지 TRPG의 게임 마스터 역할을 맡는다.
- 신비롭고 장엄한 무협·동양 판타지풍 문체를 사용한다.
- 시각, 청각, 촉각 등 감각적 묘사를 활용해 장면의 몰입감을 높인다.
- 플레이어의 행동이나 대사를 AI가 대신 결정해 출력하지 않는다.
- 상황 묘사가 끝나면 플레이어의 입력을 기다리고, 해당 장면에 지정된 선택지를 명확하게 제시한다.
- `선택지 전용` 장면에서는 지정된 선택지만 받고, `선택지+자연어 입력` 장면에서는 선택지를 제시하면서 자연어 행동도 허용한다.
- AI 게임 마스터는 감각 묘사, 대사의 표현과 자연어 행동에 대한 상황 반응을 자유롭게 생성할 수 있다.
- AI 게임 마스터는 세계관의 고정 설정, Phase 결과, 보상·패널티, 카르마, 십이지신 해금·강화 조건과 엔딩 조건을 변경할 수 없다.
- 플레이어가 장면 규칙 밖의 자연어 행동을 입력하면 RAG와 현재 세션 상태 안에서 가능한 반응을 제공하되, 고정된 핵심 시나리오 결과는 유지한다.
- AI 게임 마스터는 장면 묘사와 대사를 출력할 때마다 함께 표시할 일러스트를 지정한다.
- AI 게임 마스터는 RAG에 등록된 `illustration_id`만 지정하며 존재하지 않는 ID를 임의로 만들지 않는다.
- AI 게임 마스터는 실제 이미지 데이터, 경로 또는 파일 정보를 반환하지 않는다.

##### 판정 설계 원칙

- 전투와 여정 전체에 하나의 판정 방식을 일괄 적용하지 않는다.
- 판정이 필요한 시나리오 장면이 추가될 때마다 장면의 목적과 상황에 맞는 판정 방식을 별도로 정한다.
- 판정 방식이 사용자에게 확인되지 않은 장면에는 임의의 주사위, 능력치, 난이도나 성공 공식을 확정하지 않는다.
- 새 판정 장면을 설계할 때 판정 주체, 사용 능력치 또는 자원, 주사위·계산 방식, 난이도, 보너스, 성공·실패 결과를 사용자에게 확인한다.
- 확인 전 정보는 해당 장면의 `TBD`로 유지한다.

##### 자연어 입력 예외 처리

- 현재 장면에서 허용 가능한 자연어 행동은 AI 게임 마스터가 상황에 맞는 결과를 묘사하고 정해진 규칙에 따라 진행한다.
- 실행 가능하지만 별도 규칙이나 결과가 없는 행동은 게임 상태를 변경하지 않고 상황 반응을 제공한 뒤 현재 선택지를 다시 제시한다.
- 의미가 불명확하거나 AI가 해석하지 못한 입력은 즉시 실패로 처리하지 않고 플레이어에게 다시 입력하도록 안내한다.
- 명백히 실행 불가능하거나 세계관을 벗어난 행동을 입력하면 AI 게임 마스터가 극단적인 결말을 서술하고 `GAME OVER`로 종료한다.
- 자연어 예외 처리 과정에서 고정 설정에 없는 보상, 패널티나 신규 분기를 임의로 만들지 않는다.

##### RAG 세계관 데이터

- 세계 배경
  - 특정 실존 국가를 그대로 재현하지 않는 가상세계다.
  - 한국·중국·일본의 문화, 신화와 시각 요소를 혼합한다.
  - 세 문화권 요소의 구체적인 혼합 기준과 지역별 차이는 추후 정한다.

- 십이지신당
  - 고대의 선인들이 세상의 재앙인 사흉을 봉인했던 신성한 신전이다.
  - 오랜 세월 인적이 끊겨 이끼와 먼지로 뒤덮였으며, 현재는 스산하고 기괴한 기운이 감돈다.
- 흑의인
  - 정체를 알 수 없는 검은 옷의 인물이다.
  - 십이지신당의 가장 깊은 제단에서 고대의 봉인을 풀기 위한 금지된 주술 의식을 거행한다.
- 혼돈
  - 봉인에서 풀려난 사흉 중 하나다.
  - 산처럼 거대한 덩치와 강력한 파괴력을 지녔다.
  - 지능이 낮고 움직임이 굼뜨다.
  - 발이 닿는 곳의 생명력을 빨아들이고 자연을 검게 썩히는 `오염`을 퍼뜨린다.
- 피리 속 신령
  - `인연의 피리`에 깃든 신성한 존재다.
  - 사흉의 봉인이 깨질 때 큰 타격을 입었다.
  - 근엄하지만 간절한 목소리로 플레이어에게 도움을 요청하고 길을 안내한다.
- 인연의 피리
  - 십이지신의 힘을 빌려 현현시킬 수 있는 신물이다.
  - 흑의인의 주술로 봉인이 파괴될 때 손상되었다.
  - 초반에는 혼돈의 봉인을 담당하던 원숭이(申), 닭(酉), 개(戌)의 힘만 사용할 수 있다.
  - 플레이어가 신령의 제안을 수락하는 순간 눈앞에 현현한다.
  - 이후 여정과 탐험을 통해 사용할 수 있는 십이지신의 힘을 순차적으로 복구한다.

##### AI GM용 RAG와 세션 상태 분리 1차안

- RAG에는 플레이 중 바뀌지 않는 기준 정보를 저장한다.
  - AI 게임 마스터의 역할, 문체와 행동 제한
  - 세계관, 장소, 등장인물, 괴수와 아이템 설정
  - 성별별 오프닝과 고정 시나리오 Phase
  - 장면별 입력 방식, 판정 규칙과 성공·실패 결과
  - 십이지신·사흉 방향 대응과 고정 전투 규칙
  - 사용 가능한 `illustration_id` 목록
- 세션 상태에는 플레이에 따라 달라지는 정보를 저장한다.
  - 선택 성별과 방랑도사·수련무녀 역할
  - 현재 Phase와 장면 ID
  - 흑의인 저지 시도 등 장면 선택 이력
  - 숨겨진 카르마
  - 십이지신별 해금·강화 상태
  - 아이템, 누적 정보량과 획득한 고양이 핵심 서사
  - 사흉 처치 상태와 각 정수의 현재 소유자
  - 현재 편성과 전투 상태
  - 지도 노드별 선택 가능·완료 상태
- AI 게임 마스터는 RAG에서 불러온 기준 정보와 현재 세션 상태를 함께 사용해 다음 장면을 진행한다.
- RAG나 장면 규칙에 없는 설정과 판정 결과를 임의로 확정하지 않는다.

##### AI GM 문맥 구성·RAG 검색 우선순위

1. 시스템 규칙과 금지 사항
2. 현재 장면의 고정 시나리오, 허용 선택지와 결과
3. 현재 등장인물·장소·아이템과 사용할 수 있는 일러스트 ID
4. 현재 세션 상태
5. 현재 장면과 관련된 세계관·과거 서사

- 서로 다른 정보가 충돌하면 위에서 더 높은 우선순위의 규칙을 따른다.
- 현재 장면 진행에 필요한 범위만 검색해 AI 게임 마스터 문맥에 포함한다.
- 아직 공개되지 않은 고양이 서사, 후속 장면 정보와 스포일러 일러스트 ID는 공개 조건을 충족하기 전까지 검색 결과에서 제외한다.
- 현재 장면과 관계없는 전체 RAG 데이터를 한 번에 AI 게임 마스터에게 전달하지 않는다.

##### RAG 항목 데이터 구조

- 각 RAG 항목은 다음 필드를 가진다.
  - `content_id`: RAG 항목 고유 ID
  - `content_type`: 시스템 규칙, 세계관, 등장인물, 장소, 아이템, 장면 참고 자료 등 자료 유형
  - `body`: AI 게임 마스터가 참조할 실제 내용
  - `reveal_condition`: 해당 내용을 AI 문맥에 포함할 수 있는 공개 조건
  - `related_scene_ids`: 이 항목을 참조할 수 있는 관련 씬 ID 목록
  - `illustration_ids`: 해당 자료에서 AI가 선택할 수 있는 등록 일러스트 ID 목록
- 씬 데이터의 `rag_refs`에는 현재 장면에서 조회할 `content_id` 목록을 저장한다.
- Unity는 현재 세션 상태로 `reveal_condition`을 검사하고 조건을 충족한 RAG 항목만 AI 게임 마스터 문맥에 포함한다.
- `illustration_ids`에는 실제 이미지나 경로를 넣지 않고 Unity에 등록된 ID만 저장한다.
- 플레이에 따라 바뀌는 카르마, 아이템 보유, 십이지신 성장과 진행 상태는 RAG가 아니라 세션 상태에서 관리한다.

##### 공통 ID 명명 규칙

- 데이터 연결 ID는 영문 대문자 접두사와 언더스코어를 사용한다.
- 플레이어에게 표시할 한국어 명칭과 내부 ID를 분리한다.
- 데이터 종류별 접두사는 다음과 같다.
  - 지도 노드: `NODE_`
  - 씬: `SCENE_`
  - 판정 설정: `CHECK_`
  - 결과: `OUTCOME_`
  - RAG 항목: `CONTENT_`
  - 등장인물: `CHAR_`
  - 장소: `LOC_`
  - 아이템: `ITEM_`
  - 십이지신: `ZODIAC_`
  - 사흉: `PERIL_`
  - 일러스트: `ILL_`
- 예시는 `SCENE_SHRINE_PHASE_01`, `ILL_HUNDUN_DEFAULT` 형식을 사용한다.

##### 저장·불러오기와 AI 문맥 규칙

- Unity의 세이브 데이터를 실제 게임 진행 상태의 기준으로 사용한다.
- 세이브에는 현재 Phase·장면, 선택 이력, 카르마, 십이지신 상태, 인벤토리, 수집 정보, 사흉·정수 상태와 저장 시점까지의 진행 로그를 포함한다.
- AI 서비스에 남아 있는 대화 기록 자체를 게임 저장 데이터로 사용하지 않는다.
- 세이브를 불러오면 저장 이후에 진행된 로그와 상태를 현재 플레이에서 제외한다.
- 불러오기 시 기존 AI 대화 문맥을 그대로 이어 쓰지 않고 새 문맥을 구성한다.
- 새 AI 문맥에는 저장된 세션 상태, 저장 시점까지의 로그와 현재 장면에 필요한 RAG 자료만 전달한다.
- 같은 장면을 다시 진행할 수 있지만 AI가 생성하는 세부 문장과 묘사는 이전 플레이와 달라질 수 있다.
- 과거 판정 결과는 세이브 상태와 로그로 복원하며, 동일한 난수 결과까지 재현할 필요가 있는지는 판정 시스템 설계 시 결정한다.
- 자동 저장은 장면의 판정과 보상·패널티 정산이 모두 끝난 시점에 실행한다.
- 수동 저장은 AI 응답 생성, 판정 또는 전투가 진행 중이지 않은 대기 상태에서만 허용한다.
- 자동 저장 슬롯은 1개, 플레이어가 관리하는 수동 저장 슬롯은 3개를 제공한다.
- `GAME OVER`가 발생해도 현재 자동 저장을 덮어쓰지 않는다.
- 게임 오버 화면에서는 `최근 자동 저장 불러오기`, `수동 저장 선택`, `타이틀로 이동`을 제공한다.

##### 플레이어와 도입부

- 게임 시작 시 플레이어 캐릭터의 성별을 선택한다.
- 남성을 선택하면 `방랑도사`로 시작한다.
  - 호탕하고 유쾌한 성격이다.
  - 얽매임 없이 세상을 유랑하며 술 한 잔에 바람을 벗 삼아 떠돌던 중, 묘한 기운에 이끌려 십이지신당의 문을 연다.
- 여성을 선택하면 `수련무녀`로 시작한다.
  - 조신하고 신중한 성격이다.
  - 신성한 영력의 수련과 순례를 위해 길을 걷던 중, 대지를 타고 흐르는 불길한 이치의 흐름을 추적하다 십이지신당에 도달한다.
- 선택한 성별에 따라 게임 시작 독백과 사당 진입 묘사를 다르게 적용한다.
- 성별에 따른 차이는 오프닝, 독백, 대사 톤과 같은 서사 표현에만 적용한다.
- 방랑도사와 수련무녀의 능력치, 판정 규칙, 전투 성능은 동일하게 구성한다.
- 방랑도사의 호탕하고 유쾌한 성격과 수련무녀의 조신하고 신중한 성격은 기본 서술·대사 톤으로 사용한다.
- 사전 설정된 성격은 플레이어의 선택이나 자연어 행동을 제한하지 않는다.
- 기본 성격과 다른 행동도 허용하며, AI 게임 마스터가 상황 반응이나 캐릭터 변화로 자연스럽게 서술한다.
- 동물과 관련된 카르마 선택 장면은 도입부에 몰아넣지 않고 전체 여정에 자연스럽게 분산한다.
- 선택 결과는 플레이어에게 공개되지 않는 `카르마` 수치에 누적되며, 후반 엔딩 분기에 사용된다.
- 카르마 장면은 `구한다`, `외면한다`, `조건을 건다`의 세 유형을 기본으로 구성한다.
  - 다친 새: 치료해 풀어주기 / 위험을 피하고 지나치기 / 보상이나 대가 요구하기
  - 굶주린 고양이: 먹이를 주고 안전한 곳으로 유도하기 / 바쁜 일을 이유로 지나치기 / 정보와 먹이를 교환하기
  - 뒤집어진 거북이: 원래대로 돌려주기 / 자연의 섭리라 여기고 지나치기 / 다른 이에게 떠넘기거나 대가 요구하기
- `구한다`는 카르마 증가, `외면한다`는 카르마 감소, `조건을 건다`는 조건에 따라 증감하는 구조다.

##### 사건 발생과 목표

- 흑의인 조우부터 신령과의 대화, 인연의 피리 획득까지의 오프닝 구간은 모두 `선택지 전용`으로 진행한다.
- 플레이어는 기이한 기운을 따라 십이지신당 가장 깊은 제단으로 들어간다.
- 제단 앞에서 흑의인이 금지된 주술로 사흉의 봉인을 해제하려는 현장을 목격한다.
- 플레이어의 대응과 관계없이 의식은 완성되고 봉인되어 있던 사흉 `혼돈`, `궁기`, `도올`, `도철`이 풀려난다.
- 흑의인은 사라지고 지능이 낮고 움직임이 느린 혼돈만 현장에 남으며, 나머지 사흉은 도주한다.
- 플레이어는 십이지신의 힘을 이용해 사흉을 추적하고 처치한다.
- 사흉의 정수를 노리는 검은 옷의 습격자가 여정에 개입한다.

##### Phase 1: 신당 진입과 조우

- Phase 1은 `선택지 전용`으로 진행한다.
- 흑의인이 제단 앞에서 불길한 주술을 외우고, 제단에 붉은 균열이 생기기 시작한다.
- AI 게임 마스터는 플레이어에게 다음 선택지를 제시한다.
  - 무기를 들고 흑의인을 막기 위해 뛰어든다.
  - 숨을 죽이고 상황을 지켜본다.
  - 불길한 직감을 느끼고 신전을 빠져나간다.

##### Phase 2: 봉인의 파멸

- 흑의인을 막으려 하면 마지막 주문이 먼저 완성되어 저지에 실패한다.
- 상황을 지켜보면 방해받지 않은 의식이 완성되고 제단이 갈라지며 검은 연기가 뿜어져 나온다.
- 신전에서 도망치려 하면 봉인 파괴의 충격파에 휩쓸려 정신을 잃는다.
- 세 선택 모두 별도 보상이나 패널티 없이 봉인이 파괴되는 동일한 핵심 사건을 거쳐 Phase 3으로 이어진다.
- 단, 흑의인을 저지하려 한 경우에는 Phase 4에서 신령이 플레이어의 용기를 알아보고 처음부터 우호적인 반응을 보인다.

##### Phase 3: 깨어난 재앙과 오염

- 먼지가 걷히거나 플레이어가 정신을 차리면 흑의인은 사라지고 혼돈만 남아 있다.
- 혼돈의 발치에서부터 생명력을 빼앗는 검은 오염이 빠르게 퍼진다.
- AI 게임 마스터는 플레이어에게 다음 선택지를 제시한다.
  - 무기를 고쳐 잡고 오염의 중심인 혼돈에게 접근한다.
  - 재앙을 피해 신당 밖으로 도망친다.
- 도망치면 오염이 플레이어를 집어삼켜 게임 오버가 되며, 세션을 종료하거나 Phase 3 시작점으로 돌아간다.
- 혼돈에게 접근하면 Phase 4로 이어진다.

##### Phase 4: 피리 속 신령과의 계약

- 피리 속 신령과의 대화 및 인연의 피리 획득 과정은 `선택지 전용`으로 진행한다.
- 플레이어가 혼돈에게 다가가면 아직 모습을 드러내지 않은 신령의 목소리가 머릿속에 울린다.
- 신령은 혼돈의 정체, 다른 사흉의 도주, 십이지신이 지키던 봉인의 붕괴를 설명하고 도움을 요청한다.
- 플레이어가 힘이 부족하다고 말하거나 거절하면, 신령은 인연의 피리와 십이지의 편린을 다룰 권능을 제안한다.
- 손상된 피리로는 원숭이, 닭, 개의 힘만 빌릴 수 있지만 혼돈을 상대하기에는 충분하다고 설명한다.
- 플레이어가 제안을 수락하는 순간 `인연의 피리`가 눈앞에 현현한다.
- 플레이어가 피리를 받으면 인벤토리에 `인연의 피리`가 추가되고 혼돈 보스 전투로 전환된다.

##### 전투 기본 구조

- 아래 전투 규칙은 세부 구조가 확정되지 않은 1차 아이디어다.
- 전투에 진입할 때 십이지신 12명 중 3명을 선택해 편성한다.
- 십이지신별 원소 속성과 속성 상성은 실제 사용 여부가 정해지지 않은 임시 아이디어다.
- 각 사흉과 십이지신은 대응하는 방향을 가진다.
- 사흉의 방향은 다음과 같다.
  - 동방: 도올
  - 서방: 혼돈
  - 남방: 궁기
  - 북방: 도철
- 십이지신의 방향은 다음과 같다.
  - 동방: 호랑이, 토끼, 용
  - 서방: 원숭이, 닭, 개
  - 남방: 뱀, 말, 양
  - 북방: 돼지, 쥐, 소
- 방향은 원소 속성과 별개이며, 현재는 사흉전 보너스를 중심으로 검토한다.
- 사흉의 방향과 맞는 십이지신을 편성해 해당 사흉 전투에 진입하면 방향이 일치하는 십이지신만 공격·방어 판정 보너스를 얻는다.
- 방향 보너스는 파티 전체에 일괄 적용하지 않으며, 일치하는 십이지신의 수가 많을수록 편성의 실질적인 혜택이 커진다.
- 방향 보너스는 능력치를 직접 올리는 대신 TRPG 판정에 보정치를 더하는 방식으로 적용한다.
- 방향 보너스의 구체적인 주사위·수치 보정 방식은 판정 시스템 설계 단계에서 결정한다.
- 방향 일치 규칙을 일반 여정 판정에도 적용할지는 아직 정하지 않았다.
- 특정 십이지신 조합에는 시너지가 적용된다.
- 전투 중 십이지신을 교체할 수 있다.
  - 편성된 십이지신은 체력을 공유한다.
  - 교체 시 한 턴을 소모한다.

##### 튜토리얼: 혼돈

- 혼돈전에서 기본 판정과 전투 조작을 학습한다.
- 혼돈은 덩치가 크고 공격이 느려 회피하기 쉽다.
- 봉인에서 막 풀려나 체력이 낮은 상태다.
- 튜토리얼에서는 인연의 피리로 원숭이, 닭, 개의 힘을 사용한다.
- 혼돈 처치 시 `혼돈의 정수`가 드롭되지만 검은 옷의 습격자가 훔쳐 간다.
- 이후 플레이어는 나머지 사흉의 특성을 전달받고 추적 여정을 시작한다.
- 사흉의 특성을 장소 이상 현상과 비교하는 방법은 별도 튜토리얼 정보로 설명하지 않는다.
- 플레이어는 실제 지도 노드를 선택하고 결과를 경험하면서 장소 단서 판별 방식을 익힌다.

##### 십이지신 해금과 성장

- 혼돈 튜토리얼에서는 원숭이, 닭, 개만 사용할 수 있다.
- 이후 추가 여정과 탐험을 통해 나머지 십이지신을 순차적으로 해금한다.
- 이미 해금한 십이지신도 여정과 탐험을 통해 강화할 수 있다.
- 신규 해금과 기존 십이지신 강화는 모두 탐험의 주요 성장 보상으로 사용한다.
- 대부분의 탐험에는 특정 십이지신과 관련된 요괴 사건이 등장하며, 사건을 클리어하면 관련 십이지신을 해금하거나 강화한다.
- 요괴 사건과 관련된 십이지신이 잠겨 있으면 사건 클리어 시 해당 십이지신을 해금한다.
- 관련 십이지신이 이미 해금되어 있으면 사건 클리어 시 해당 십이지신을 강화한다.
- 일부 탐험은 요괴와 조우하지 않지만 판정은 진행하며, 판정 결과에 따라 보상 또는 패널티를 적용한다.
- 사흉의 방향에 대응하는 십이지신을 확보하고 편성하는 과정이 보스전 준비 요소가 된다.

##### 핵심 플레이 루프 1차안

1. Unity가 서로 다른 이상 현상 설명이 붙은 여러 장소 노드를 지도에 표시한다.
2. 플레이어가 초반에 전달받은 사흉의 특징과 장소 설명을 비교해 이동할 지도 노드를 선택한다.
3. AI 게임 마스터가 장면을 묘사하고, 장면 유형에 따라 `선택지 전용` 또는 `선택지+자연어 입력`을 제공한다.
4. 판정이 필요한 장면이면 해당 장면에 미리 정한 규칙에 따라 십이지신을 선택하고 판정을 진행한다.
5. 판정 결과에 따라 보상·패널티를 적용하거나 요괴·사흉 전투로 전환한다.
6. 장면 완료 후 아이템, 십이지신 정보, 진엔딩 정보, 신규 십이지신 해금 또는 기존 십이지신 강화 보상을 정산한다.
7. 정산이 끝나면 자동 저장하고 지도 화면으로 돌아간다.
8. 지도에서 십이지신·인벤토리 등 필요한 메뉴를 이용한 뒤 다음 장소 노드를 선택한다.

- 사흉 추적 구간에서는 사흉의 특성과 방향 정보를 확인하고 대응하는 십이지신을 준비하는 과정이 추가된다.
- 사흉의 특징과 일치하는 장소를 선택하면 해당 사흉 조우·전투로 이어지고, 일치하지 않는 장소를 선택하면 설명과 관련된 탐험 또는 요괴 조우로 이어진다.
- 이 루프는 혼돈 튜토리얼 이후부터 최종 흑막 전투 전까지 반복한다.
- 지도 노드 선택을 초기 구현의 기본 이동 방식으로 사용한다.
- 지도에는 1차안 기준으로 한 화면에 약 10개의 장소를 표시한다.
- 지도 노드를 선택하면 장소의 이상 현상 설명을 확인하고, 이동 확인을 거쳐 해당 장면으로 진입한다.
- 별도의 정비 장면은 두지 않고 지도 화면에서 십이지신 편성·강화와 인벤토리 관리를 진행한다.

##### 평균 2시간 플레이 배분 1차안

- 오프닝과 혼돈 튜토리얼: 약 15분
- 궁기 여정·전투: 약 25분
- 도올 여정·전투: 약 25분
- 도철 여정·전투: 약 25분
- 최종 흑막 전투와 엔딩: 약 20분
- 지도 탐색, 십이지신 편성·관리와 메뉴 이용 여유: 약 10분
- 각 사흉 구간에서는 평균 2개 정도의 탐험을 진행하는 것을 기준으로 한다.
- 지도에 표시된 모든 탐험 노드를 방문하도록 강제하지 않는다.

##### 플레이 화면 UI 1차안

- 기준 화면비는 `16:9`, 기준 해상도는 `1920×1080`으로 설계한다.
- 다른 16:9 PC 해상도에서는 Unity UI 스케일링을 적용해 동일한 정보 위계와 배치를 유지한다.
- 기본 플레이 화면은 비주얼 노벨형으로 구성한다.
- 여정 목적지를 고를 때는 지도 화면으로 전환하고, 장소 노드를 선택하면 해당 장면의 비주얼 노벨 화면으로 진입한다.
- 장면 정산과 자동 저장이 끝나면 지도 화면으로 복귀하며, 지도에서 보조 메뉴에 접근할 수 있다.
- 각 장면 묘사와 대사 단위마다 AI 게임 마스터가 지정한 일러스트를 화면 상단에 표시한다.
- 화면 하단에 AI 게임 마스터의 서술·대사와 플레이어 선택지를 배치한다.
- `선택지 전용` 장면에서는 선택지만 표시한다.
- `선택지+자연어 입력` 장면에서는 선택지와 자연어 입력창을 함께 표시한다.
- 자연어 입력창은 해당 기능이 필요한 장면에서만 표시하고, 별도의 튜토리얼·안내 팝업 없이 장면 흐름 안에서 제공한다.
- 이전 진행 내용은 메인 화면에 상시 표시하지 않고, 별도의 `로그` 버튼을 눌러 확인한다.
- 로그는 별도 창이나 오버레이로 열고 닫아 현재 장면으로 돌아올 수 있게 한다.
- 로그에는 AI 게임 마스터의 장면 묘사·NPC 대사, 플레이어가 고른 선택지·자연어 입력, 판정 결과, 획득한 아이템·정보와 십이지신 해금·강화를 기록한다.
- 로그에는 숨겨진 카르마, 미공개 정보와 AI 내부 처리 내용을 표시하지 않는다.

##### 보조 메뉴 UI 1차안

- `로그`: 이전 장면의 묘사·대사, 플레이어 입력, 판정 결과와 획득 기록을 확인한다.
- `십이지신`: 십이지신별 해금·강화 상태와 현재 편성을 확인하고 관리한다.
- `인벤토리`: 획득한 보상·패널티 아이템과 효과를 확인한다.
- `정보`: 획득한 십이지신 이야기와 공개된 고양이 관련 서사를 확인한다.
- `시스템`: 자동 저장 1개와 수동 저장 3개의 저장·불러오기, 게임 설정 기능을 제공한다.
- 숨겨진 카르마와 아직 획득하지 않은 고양이 서사·스포일러 정보는 보조 메뉴에 표시하지 않는다.

##### 일러스트 ID 연동 규칙

- 모든 사용 가능 일러스트에는 Unity에서 실제 에셋과 연결할 고유한 `illustration_id`를 부여한다.
- RAG에는 AI 게임 마스터가 선택할 수 있는 `illustration_id`만 등록한다.
- AI 게임 마스터의 각 묘사·대사 응답에는 사용할 `illustration_id`만 포함한다.
- Unity는 AI가 반환한 `illustration_id`를 실제 일러스트 에셋과 대조해 화면 상단에 표시한다.
- 현재 묘사나 대사에 정확히 맞는 일러스트가 없으면 해당 캐릭터의 기본 일러스트 ID를 반환한다.
- 특정 화자가 없는 배경·상황 묘사에 정확히 맞는 일러스트가 없으면 현재 장소의 기본 일러스트 ID를 반환한다.
- 장소 기본 일러스트를 표시하는 동안에는 인물 일러스트를 표시하지 않는다.
- 스포일러가 포함된 일러스트 ID는 세션 상태의 공개 조건을 충족한 뒤에만 AI가 선택할 수 있다.
- 일러스트 선택은 화면 연출에만 사용하며 판정이나 게임 상태를 변경하지 않는다.

##### AI GM 응답 데이터 1차안

- AI 게임 마스터의 묘사·대사 응답은 Unity가 해석할 수 있는 JSON 데이터로 반환한다.
- 각 응답 단위는 다음 필드를 포함한다.
  - `speaker_id`: 현재 화자 ID. 특정 화자가 없는 배경·상황 묘사는 `narrator` 사용
  - `text`: 화면과 로그에 표시할 묘사 또는 대사 본문
  - `illustration_id`: Unity가 표시할 등록 일러스트 ID
  - `input_mode`: `choice_only` 또는 `choice_and_text`
  - `choices`: 플레이어에게 제시할 `choice_id`와 선택지 문구 목록
- Unity는 `input_mode`에 따라 자연어 입력창을 숨기거나 표시한다.
- Unity는 `speaker_id`, `text`, `illustration_id`를 사용해 화자 표시, 본문과 일러스트를 갱신한다.
- `choices`에 포함된 선택지는 현재 장면에 허용된 선택지와 일치해야 한다.
- Unity는 JSON 필수 필드, 허용된 `speaker_id`, 등록된 `illustration_id`, 현재 장면의 `choice_id`와 `input_mode`를 검증한다.
- 검증에 실패하면 화면과 게임 상태를 변경하지 않고 AI 게임 마스터에게 올바른 형식으로 한 번 자동 재요청한다.
- 자동 재요청도 실패하면 이전 화면을 유지하고 플레이어에게 `다시 시도` 버튼을 표시한다.
- AI 응답 형식 오류는 판정 실패, 패널티나 `GAME OVER`로 처리하지 않는다.

##### 여정과 사건 장면

- 여정 장면은 크게 메인 시나리오를 진행하는 `사흉 추적`과 성장·정보 수집을 위한 `탐험`으로 구분한다.
- `사흉 추적`과 `탐험`은 내부 장면 분류이며, 지도 노드에는 유형을 직접 표시하지 않는다.
- 각 지도 노드에는 `찌릿찌릿한 번개가 근처에서 계속 치고 있습니다`처럼 현장의 이상 현상과 분위기를 나타내는 설명을 붙인다.
- 플레이어는 초반에 전달받은 사흉의 특징을 기억하거나 정보 메뉴에서 확인하고 목적지 설명과 대조한다.
- 장소 설명이 사흉의 특징과 일치하면 해당 사흉과 조우한다.
- 사흉의 특징과 일치하지 않으면 장소 설명에 대응하는 일반 탐험 또는 요괴 조우 장면으로 이어진다.
- 탐험 장소는 한 번만 클리어할 수 있으며, 클리어 후 선택 가능한 지도 노드와 보상 풀에서 제거한다.
- 클리어한 탐험 장소에서는 해금·강화·아이템·정보 보상을 반복 획득할 수 없다.
- 현재 사흉을 가리키는 장소는 플레이어가 선택해 해당 사흉과 조우할 때까지 선택 가능한 지도 노드로 유지한다.
- 탐험을 마치면 남아 있는 장소와 아직 등장하지 않은 탐험 장소를 사용해 지도 노드를 갱신한다.
- 지도에는 현재 사흉과 연결된 장소 1개와 다수의 미완료 탐험 장소를 함께 표시한다.
- 한 번에 표시하는 장소는 1차안 기준 약 10개로, 사흉 장소 1개와 미완료 탐험 장소 최대 9개로 구성한다.
- 남은 탐험 장소가 9개보다 적으면 표시되는 전체 노드 수도 줄어든다.
- `혼란 조사`는 별도 유형이 아니라 탐험 장면에 포함한다.
- 모든 탐험 장면은 요괴 조우 여부와 관계없이 판정을 진행한다.
- 일반 여정의 일부 지점에는 통상 판정과 다른 특별한 진행 방식을 적용하는 방안을 검토한다.
- 일부 탐험은 신기한 장소를 발견하는 장면으로 구성하며 요괴와 조우하지 않는다.
  - 판정 성공: 보상 획득
  - 판정 실패: 패널티 적용
- 대부분의 탐험은 특정 십이지신과 관련된 요괴가 일으킨 혼란을 조사하는 장면으로 구성한다.
- 요괴 사건에서는 십이지신 1명을 선택해 판정한다.
  - 성공: 보상 획득
  - 실패: 장면 규칙에 따라 패널티 또는 전투 발생
- 요괴 사건을 클리어하면 해당 요괴와 관련된 십이지신을 해금하거나 강화한다.
- 보상은 스테이터스 상승 아이템, 패널티는 스테이터스 하락 아이템으로 구성한다.
- 아이템 설명에는 십이지신 관련 이야기와 정보가 담긴다.
- 보상 아이템과 패널티 아이템을 구분하지 않고, 획득한 모든 아이템의 정보를 진엔딩용 누적 정보량에 포함한다.
- 일반 아이템의 정보를 전부 수집할 필요는 없으며, 누적 정보량이 정해진 기준 이상이면 수량 조건을 충족한다.
- 일반 아이템 정보와 별도로 고양이에 관한 여러 개의 핵심 서사 조각을 배치한다.
- 고양이 핵심 서사에는 `쥐의 속임수로 고양이가 십이지에 들지 못한 과거`가 포함되며, 이외에도 추가 서사를 구성한다.
- 진엔딩 분기를 열려면 누적 정보량 기준을 충족하는 동시에 지정된 고양이 핵심 서사를 획득해야 한다.

##### 지도 노드 데이터 구조

- 지도 노드 정의와 현재 상태는 Unity가 관리한다.
- 각 노드는 다음 필드를 가진다.
  - `node_id`: 노드 고유 ID. 저장 데이터와 완료 상태의 기준
  - `location_name`: 지도에 표시할 장소명
  - `clue_text`: 사흉 특징과 비교할 수 있는 이상 현상 설명
  - `scene_id`: 노드 선택 후 실행할 비주얼 노벨·판정 장면 ID
  - `node_type`: `four_peril`, `yokai_exploration`, `normal_exploration` 중 하나. 플레이어에게는 표시하지 않음
  - `related_content_id`: 등장할 사흉·요괴 또는 해금·강화할 십이지신 데이터 연결 ID
  - `node_status`: `available`, `completed` 등 현재 선택·완료 상태. 세이브 데이터에 저장
- 지도에서 `node_id`를 선택하면 연결된 `scene_id`를 불러온다.
- `node_type`과 `related_content_id`에 따라 사흉전, 요괴 탐험, 일반 탐험과 보상을 결정한다.
- 장면 완료 후 `node_status`를 갱신하고 자동 저장한 뒤 지도를 다시 표시한다.
- AI 게임 마스터에게는 전체 노드 데이터가 아니라 선택된 `scene_id`, 관련 콘텐츠와 해당 장면에 필요한 RAG 정보만 전달한다.
- 지도 노드에는 `illustration_id`를 저장하지 않는다. 장면 일러스트는 AI 게임 마스터 응답의 `illustration_id`를 Unity가 표시한다.

##### 씬 데이터 구조

- `scene_id`는 장면 정의를 찾는 고유 키이며, ID 문자열 자체에 선택지·판정·결과 정보를 넣지 않는다.
- 각 씬 데이터는 다음 필드를 가진다.
  - `scene_id`: 장면 고유 ID
  - `scene_type`: 대화, 탐험 판정, 요괴 조우, 사흉전 등 장면 유형
  - `location_id`: 현재 장소와 장소 기본 일러스트 연결 ID
  - `input_mode`: `choice_only` 또는 `choice_and_text`
  - `allowed_choices`: 현재 장면에서 허용된 `choice_id`와 문구
  - `check_config_id`: 판정이 있는 경우 해당 장면의 판정 규칙 연결 ID. 판정이 없으면 사용하지 않음
  - `outcomes`: 선택·판정 결과에 따른 보상, 상태 변경과 다음 장면 정보
  - `rag_refs`: AI 게임 마스터가 현재 장면에서 참조할 등장인물·세계관·일러스트 ID 범위
- 지도에서 `node_id`를 선택하면 연결된 `scene_id`로 씬 데이터를 불러온다.
- Unity는 씬 데이터와 현재 세션 상태를 조합해 AI 게임 마스터에게 필요한 정보만 전달한다.
- 장면 처리 흐름은 `node_id 선택 → scene_id 조회 → 선택·판정 → outcomes 적용 → 다음 scene_id 또는 지도 복귀` 순서로 진행한다.

##### Outcome 데이터와 적용 순서

- `outcomes`는 플레이어의 `choice_id` 또는 Unity가 확정한 판정 결과에 연결한다.
- 각 Outcome은 필요한 경우 다음 내용을 포함한다.
  - 카르마 증감
  - 아이템 획득·제거와 정보 획득
  - 십이지신 해금·강화
  - 지도 노드 완료 상태
  - 사흉 처치 상태와 정수 소유자 변경
  - 다음 `scene_id`, 지도 복귀 또는 `GAME OVER`
- Unity가 현재 씬 데이터와 세션 상태를 기준으로 적용할 Outcome을 결정한다.
- Unity가 Outcome의 상태 변경을 먼저 반영한 뒤 확정된 결과를 AI 게임 마스터에게 전달한다.
- AI 게임 마스터는 전달받은 결과를 장면에 맞게 묘사하며, Outcome에 없는 상태 변경이나 보상을 추가할 수 없다.
- 처리 순서는 `플레이어 입력 → Unity의 Outcome 결정·상태 반영 → AI GM 결과 묘사 → 다음 장면 또는 지도`로 진행한다.

##### Check Config 데이터 구조

- `check_config_id`는 장면별 판정 규칙을 찾는 고유 키다.
- 각 Check Config는 다음 항목을 가진다.
  - 판정 주체: 플레이어 또는 선택한 십이지신
  - 선택 가능한 십이지신 목록 또는 선택 조건
  - 판정 방식: 주사위, 수치 비교 또는 해당 장면의 특수 규칙
  - 난이도
  - 방향 일치 등 적용 가능한 보정
  - 성공·실패를 구분할 결과 키
  - 각 결과 키에 연결할 Outcome
- Unity가 Check Config에 따라 판정을 실행하고 확정된 결과 키를 해당 Outcome에 전달한다.
- AI 게임 마스터는 확정된 판정 결과를 묘사하며 주사위·난이도·보정이나 결과를 임의로 변경하지 않는다.
- 새로운 판정 장면을 추가할 때마다 판정 주체, 십이지신 선택, 판정 방식, 난이도, 보정과 성공·실패 결과를 사용자에게 확인해 개별 Check Config를 작성한다.

##### 사흉 전투 진행

- 궁기
  - 사망 직전에 발악 패턴을 사용해 플레이어에게 빈사급 피해를 준다.
  - 전투 직후 검은 옷의 습격자가 `궁기의 정수`를 빼앗는다.
- 도올
  - 처치 후에도 검은 옷의 습격자가 나타나지 않는다.
  - 플레이어는 `도올의 정수`를 보유하게 되며, 궁기와 도올을 모두 처치하면 도철로 가는 선택지가 열린다.
- 도철
  - `도올의 정수`가 있어야 결계를 뚫고 진입할 수 있다.
  - 도철 처치 후 정수를 회수하려는 순간 검은 옷의 습격자가 다시 나타난다.
  - 십이지신 1명을 지정해 습격자와 정수를 두고 판정하지만 결과는 필패다.

##### 최종 전투와 엔딩

- 검은 옷의 습격자는 빼앗은 혼돈, 궁기, 도철의 정수를 흡수해 플레이어와 전투한다.
- 습격자에게 기준 이상의 피해를 주면 누적 정보량과 필수 핵심 정보 획득 여부에 따라 분기가 발생한다.
- 누적 정보량이 기준 미만이거나 필수 핵심 정보가 없는 경우
  - 별도 정체 분기 없이 전투를 계속한다.
  - 승리하면 사흉의 정수를 모두 회수하고 천계에 평화를 되찾는다.
- 누적 정보량 기준을 충족하고 필수 핵심 정보도 획득한 경우
  - 습격자의 정체가 고양이임을 알게 된다.
  - 고양이는 쥐의 속임수로 십이지가 되지 못한 원한 때문에 복수하려 했다.
  - 플레이어는 고양이의 편에 설지, 전투를 계속할지 선택한다.
- 고양이의 편에 서는 경우
  - 플레이어가 보유한 `도올의 정수`를 고양이에게 넘긴다.
  - 십이지와 전투해 승리하면 천계 멸망 엔딩으로 이어진다.
- 고양이와 전투를 계속해 승리한 경우
  - `악은 악이다. 고양이를 처단한다`를 선택하면 천계에 평화를 되찾지만, 플레이어는 이후에도 고양이를 떠올린다.
  - `한 번 더 기회를 주자`를 선택하면 숨겨진 카르마 수치에 따라 결과가 달라진다.
    - 카르마가 기준 이상이면 고양이가 플레이어를 따라와 속죄하고, 마지막에는 십이지와 같은 신이 된다.
    - 카르마가 기준 미만이면 고양이는 자신을 용서하지 못하고 플레이어가 등을 돌린 사이 스스로 목숨을 끊는다.

#### 다음 기획 재개 지점

- 사용자가 나중에 지금까지의 진행 위치를 물으면 다음 내용을 안내한다.
- 현재 기획은 초반 시나리오와 전체 시스템의 뼈대를 정하고, 실제 여정 콘텐츠를 채우기 직전까지 진행되었다.

- 우선순위는 `4방향 권역 구분 → 남부 권역 지도 → 궁기 단서 노드와 탐험 노드 → 뱀·말·양 해금·강화 사건 → 장면별 판정 확인` 순서다.
