# Project workspace override

이 문서는 프로젝트 상세 화면에서 `../MASTER.md`보다 우선한다.

## 목표

- 사용자가 30초 안에 최근 결정을 내린 이유와 근거, 관점 차이, 미결 질문과 다음 행동을 파악한다.
- 에이전트는 결과만 내놓지 않고 자료 확인·추출·근거 검증·종합 단계를 보여준다.
- 모든 주요 주장에는 근거를 확인하거나 “검토 필요”로 정정할 경로가 있다.

## 정보 구조

1. 프로젝트 제목과 최신 맥락 시각
2. Context Pulse: 원문, 관점, 미결 질문, 결정, 근거 포괄률
3. 하나의 primary CTA `새 맥락 분석`
4. Agent Step Rail: 자료 확인 → 관점·결정 추출 → 인용 검증 → 변화 종합
5. 결정 이유와 원문 근거 → 관점 차이 → 미결 질문 → 변화 서사 → 요약
6. 원문·분석 이력·공유는 보조 작업으로 단계적으로 공개

## Visual treatment

- warm paper 위 흰 문서 카드와 `#e6e6e6` hairline을 기본으로 한다.
- 프로젝트 탭은 파란 면 채우기 대신 하단 active indicator를 사용한다.
- 가져오기 composer는 `바로 붙여넣기`를 첫 선택으로 두고 TXT/JSON 파일 유형을 자동 판별한다.
- 프로젝트 저장 경계와 외부 계정 무연동 원칙은 짧은 설명으로 항상 보인다.

## 결정 원장 화면

- 분석 이력은 실제 저장된 실행만 좌측 원장에 표시한다. 공개 데모에는 과거 실행을 꾸며 넣지 않는다.
- 실행 상세의 첫 화면은 큰 핵심 결정 문장, 상태, 결정 이유, 원문 근거 CTA 순서로 읽힌다.
- 미해결 질문과 참여자별 관점은 카드 묶음 대신 hairline으로 구분한 편집형 목록으로 이어 붙인다.
- 요약, 핵심어, 에이전트 실행 과정은 접힌 보조 분석으로 낮춰 핵심 판단을 가리지 않는다.
- 데스크톱 근거 패널은 우측에 떠 있는 읽기 전용 문서로, 모바일에서는 전체 너비 modal sheet로 표시한다.
- 원장 선택 상태, 탭, CTA와 근거 연결에만 파랑을 쓰고 장식용 AI gradient나 캐릭터 이미지는 사용하지 않는다.

## 브레인 캔버스

- 저장된 분석 결과의 중심 주제, 참여자 관점, 결정, 미결 질문, 핵심어를 하나의 생각 그래프로 파생한다. 별도 DB 사본은 만들지 않는다.
- 선택한 생각과 직접 연결된 선·노드를 강조하고, 우측 상세에서 연결 이유와 전체 문장을 확인한다.
- 초기 상태에서는 모든 연결 의미를 선 위에 반복하지 않는다. 중심 주제 바깥의 생각을 선택했을 때만 해당 경로의 관계 문구를 표시한다.
- 노드 형태는 하나의 흰 문서 카드로 통일하고, 유형은 점·텍스트 라벨·위치로 구분한다. 질문·결정마다 서로 다른 말풍선이나 점선 모양을 사용하지 않는다.
- 100% 배율에서 대표 그래프 전체가 캔버스에 들어와야 하며 확대·축소는 분리된 아이콘 버튼과 현재 배율로 제공한다.
- 우측 상세의 직접 연결 생각은 카드 더미가 아닌 구분선 목록으로 제공해 현재 선택한 생각의 본문을 먼저 읽게 한다.
- 프로젝트 화면에서는 근거가 있는 생각을 기존 원문 근거 drawer로 연결한다.
- 그래프가 과밀해지면 유형별 대표 노드만 캔버스에 두고, 모든 생각과 연결은 아래 텍스트 목록에서 누락 없이 제공한다.
- 검색과 유형 필터는 시각 그래프와 텍스트 목록에 같은 조건을 적용한다.
- 색만으로 유형이나 선택 상태를 전달하지 않고 `중심 주제`, `관점`, `결정`, `질문`, `핵심어` 문구를 항상 병기한다.

## 에이전트 상태 표현

- `대기`, `진행 중`, `검증됨`, `검토 필요`, `실패`, `취소`를 텍스트와 색으로 함께 표시한다.
- 내부 사고 과정이나 프롬프트는 노출하지 않는다.
- 선택 원문 수, 검증된 근거 수, 실행 모드, 스냅숏 시각만 표시한다.
- 사용자의 정정은 기존 실행을 덮어쓰지 않고 annotation으로 남긴다.

## 반응형

- 1024px 이상에서는 이력 목록과 실행 상세를 2열로 배치한다.
- 모바일에서는 실행 목록 → 단계 → 우선 맥락 → 세부 결과 순서의 1열로 전환한다.
- 지식맵은 모바일에서 접근 가능한 목록을 먼저 제공하고 시각 그래프를 보조로 둔다.
- 640px 이하에서는 절대 좌표 그래프를 2열 생각 보드로 바꾸고, 연결 관계는 앞서 배치한 전체 목록에서 읽을 수 있게 한다.
