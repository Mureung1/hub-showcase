# Landing page override

이 문서는 공개 랜딩과 `/demo` 경로에서 `../MASTER.md`보다 우선한다.

## 목표

- 첫 화면에서 “회의 요약”이 아니라 “관점 차이·미결 질문·결정 근거를 연결하는 제품”임을 이해시킨다.
- 비로그인 평가자가 한 번의 주요 액션으로 저장되지 않는 결정론적 샘플을 체험하게 한다.
- 인증은 프로젝트를 저장하거나 공유할 때만 요청한다.

## 정보 구조

1. 문제 중심 메시지와 하나의 primary CTA `샘플 직접 체험`
2. 관점 차이 → 미결 질문 → 결정 배경을 보여주는 실제 맥락 카드
3. 기록 축적 → 맥락 분석 → 변화·공유의 3단계 흐름
4. 비영속 입력과 분석 결과
5. 개요 → 지식맵 → 온보딩 요약

## `/demo` 규칙

- 샘플 입력과 결과를 즉시 준비하고 데모 작업 영역으로 이동한다.
- “저장되지 않는 공개 데모”임을 화면과 접근성 트리에 명시한다.
- 로그인 CTA는 secondary로 유지한다.

## 금지

- 빈 대시보드 chrome을 첫 화면에 배치하지 않는다.
- AI 캐릭터, 보라·분홍 그라데이션, 근거 없는 성능 숫자를 사용하지 않는다.
- 네트워크 실패를 샘플 성공으로 대체하지 않는다.
