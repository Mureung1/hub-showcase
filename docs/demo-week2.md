# 2주차 데모 시나리오

## 데모 준비

1. Supabase Table Editor에서 `checkins` 테이블과 컬럼을 확인한다.
2. `server/.env`에 `SUPABASE_SERVICE_ROLE_KEY`를 넣는다.
3. `docs/litellm-vertex-guide.md`에 따라 LiteLLM을 실행한다.
4. 저장소 루트에서 `npm run dev`를 실행한다.
5. 브라우저에서 `http://localhost:5173`을 연다.

## 사용자 시나리오

입력 예시:

> 오늘 처음 보는 도구가 많아서 계속 막혔다. 그래도 하나씩 확인하면서 여기까지 진행했다.

1. 감정 텍스트를 입력하고 **정리하기**를 누른다.
2. 오늘의 감정, 원인, 내일의 작은 행동 카드 3개가 나타나는지 확인한다.
3. 결과 위에 `Vertex AI로 정리됨`이 표시되는지 확인한다.
4. 오늘의 감정을 `낯섦과 답답함`으로 수정한다.
5. **Supabase에 저장**을 누른다.
6. 저장 완료 안내와 최근 체크아웃 목록의 새 기록을 확인한다.
7. Supabase Table Editor에서 같은 데이터가 저장됐는지 확인한다.
8. 화면을 새로고침하고 기록이 다시 조회되는지 확인한다.

## 실패 케이스

- 빈 입력에서는 정리하기 버튼이 비활성화된다.
- 서버가 꺼져 있으면 화면에 요청 실패 안내가 표시된다.
- Supabase 키가 없으면 `.env` 확인 안내가 표시된다.
