# 디자인 컨셉

## 1. 방향 요약

인디고(#4F46E5) 포인트 컬러의 깔끔한 SaaS 대시보드 톤입니다. 본문 카드는 **가운데 정렬된 카드형 레이아웃**을 그대로 쓰되(여러 버전을 비교해본 결과 가장 반응이 좋았던 패턴), 화면 전체 구조는 **상단바 + 좌측 사이드바 앱 셸**로 감쌉니다. 앱 셸(상단바·사이드바)에만 은은한 글래스(반투명+블러) 효과를 주고, 본문 카드는 계속 완전 불투명을 유지합니다.

## 2. 핵심 키워드

- 명료함
- 근거 기반 (숫자 · 출처 표시)
- 친근한 설명체 (딱딱한 채용공고 말투 지양)
- 적당한 정보 밀도 (텍스트만 있지도, 장식만 있지도 않게)

## 3. 타깃과 톤 보정

컴공/소프트웨어 취업 준비 대학생이 타깃입니다. 세 가지 축에서 중간을 지향합니다.

- 채용공고처럼 딱딱하지 않게: "~을 요구합니다"보다 "왜 이 기술이 중요한지" 설명하듯 씁니다.
- 학습 앱처럼 과도하게 게임화하지 않게: 별점·뱃지·캐릭터 없이, 근거(공고 건수, 비율)로 신뢰를 줍니다.
- 텍스트만 있지도, 장식만 있지도 않게: 숫자 중심 요약 카드와 문단 중심 해설 카드를 함께 씁니다.

## 4. 레이아웃 패턴

1. 관심 직무 선택 → 2. 요구 역량 분석 보고서 → 3. 학습 로드맵, 3단계 흐름은 그대로입니다. 화면 구조는:

- 상단바(로고·브랜드명·현재 스텝 표시)를 화면 최상단에 고정합니다.
- 좌측 사이드바에 3단계 스텝 인디케이터를 세로로 배치합니다(현재 단계는 `--color-primary` 원, 완료 단계도 같은 색, 다음 단계는 회색 원).
- 본문(사이드바 오른쪽 영역)은 가운데 정렬된 단일 컬럼 카드입니다.
- 상단바·사이드바에만 은은한 글래스(반투명 흰색 + 블러) 효과를 주고, 본문 카드는 완전 불투명을 유지합니다.
- 강조가 필요한 곳은 옅은 그라디언트 배너 정도로 충분합니다.

## 5. 화면별 구성

### 5.1 관심 직무 선택

가운데 정렬된 카드 하나. 상단 배지("STEP 1 · 직무 선택") → 제목/설명 → 직무 입력창 → 예시 직무 버튼(아이콘+텍스트) → 전체 폭 CTA 버튼 → 하단 안내 문구.

### 5.2 요구 역량 분석 보고서

상단에 요약 카드 3개(분석 건수, 핵심 기술 수, 최다 등장 비율) → 기술 스택 빈도 막대 그래프 패널 → 인사이트 배너(왜 함께 요구되는지) → 기술별 해설 카드 3개(태그 + 설명 + 근거 리스트 + 인용구) → 이전/다음 버튼.

### 5.3 학습 로드맵

세로 타임라인(번호 원 + 연결선) 위에 단계별 카드. 각 카드는 단계 배지 + 제목 + 기간 + 설명 + 토픽 칩 + "이 순서로 추천하는 이유" 박스(옅은 인디고 배경)로 구성합니다.

## 6. 디자인 원칙

- 정보가 장식보다 우선한다 — 색과 배지는 근거를 강조할 때만 쓴다.
- 분석 결과에서 다음 행동으로 이어진다 — 각 화면 하단에 다음 단계로 가는 버튼을 명확히 둔다.
- 근거를 항상 함께 보여준다 — 숫자(건수, 비율)를 카피와 나란히 표시한다.
- 글래스 효과는 상단바·사이드바 같은 '앱 셸' 요소로 범위를 한정한다 — 본문 카드까지 번지지 않게 한다.
