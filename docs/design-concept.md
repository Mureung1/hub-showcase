# CareerSignal 디자인 컨셉

## 1. 방향 요약

CareerSignal은 인디고를 포인트 컬러로 사용하는 차분한 리서치 리포트형 SaaS 인터페이스입니다. 채용공고의 요구사항을 단순 나열하지 않고, 사용자가 지원 준비의 우선순위를 빠르게 읽을 수 있도록 숫자·구현 범위·다음 행동을 순서대로 배치합니다.

앱 셸에는 고정 상단바와 은은한 글래스 효과를 사용하고, 본문 카드는 불투명한 흰색 배경으로 유지해 읽기 편하게 만듭니다.

## 2. 핵심 원칙

- **분석에서 행동으로**: 반복 요구사항을 직무 기준선, 편차, 합격 전략, 준비 로드맵으로 연결합니다.
- **구현 범위를 보여주기**: 기술명보다 데이터 흐름·예외 처리·성능을 어느 수준까지 다뤄야 하는지 설명합니다.
- **근거 있는 정보 밀도**: 공고 건수와 비율은 짧게 보여 주고, 해석은 필요한 곳에만 둡니다.
- **절제된 시각 언어**: 인디고 강조, 흰 카드, 가벼운 그림자로 정보 위계를 만들며 장식은 최소화합니다.

## 3. 대상 사용자와 톤

대상은 채용공고를 읽어 본 적은 있지만 무엇을 먼저 준비할지 판단하기 어려운 디지털·기술 분야 취업 준비 대학생입니다. 화면 구조는 특정 기술 스택에 의존하지 않고 직무별 요구사항·증명 방식·학습 결과물을 같은 정보 위계로 표현합니다.

- 공고 문장을 그대로 반복하지 않고, 준비 기준을 설명하는 문장으로 씁니다.
- 초보자를 위한 서비스이되 과도한 게임화나 튜토리얼 문구는 사용하지 않습니다.
- 실제 데이터처럼 오해되지 않도록 프로토타입의 30건 mock 리서치 표기를 유지합니다.

## 4. 화면 구조

다섯 화면은 `직무 선택 → 통계 분석 → 채용공고 해석 → 합격 전략 → 준비 로드맵` 순서입니다.

- 모든 화면은 고정 상단바에 브랜드와 해당 단계(STEP n/5)를 둡니다. 분석 화면들에는 분석 직무와 이전 화면으로 이동하는 링크를 추가합니다.
- 직무 선택 화면은 가운데 정렬된 단일 카드에 직무 선택, 예시 직무, 분석 범위 미리보기, CTA를 배치합니다.
- 통계 분석·채용공고 해석·합격 전략·준비 로드맵은 가운데 정렬한 본문 오른쪽에 고정형 글래스 목차를 둡니다. 넓은 화면에서는 본문을 화면 중앙에 두고 목차는 그 오른쪽에 배치합니다.
- 화면 폭이 줄어들면 본문을 단일 열로 전환하고, 오른쪽 목차는 상단의 가로 스크롤 목차로 바꿉니다.
- 데스크톱에서는 90% 표시 밀도를 적용해 정보량이 많은 리포트도 답답하지 않게 읽히도록 합니다.

## 5. 화면별 정보 구성

### 5.1 직무 선택

예시 직무 버튼으로 분석의 시작점을 보여 줍니다. 아래 미리보기는 통계 분석, 채용공고 해석, 합격 전략, 준비 로드맵을 설명합니다.

### 5.2 통계 분석

리얼리티 → 기술 → 해석 → 데이터 순서의 10개 블록으로 구성합니다([기획서 9.2장](plan.md#92-채용공고-통계-분석-화면) 참고).

1. 리얼리티: KPI 지표 카드, 직무 외 요구 범위, 필수 인플레이션, 숨은 난이도
2. 기술: 기술 빈도, 함께 요구되는 기술 조합과 구현 수준, 증가·유지·감소 추이
3. 해석: 라벨 vs 현실, 기업군 성향 히트맵
4. 데이터: 요구 항목 전체표(기본 접힘)

각 블록에는 표본 수와 신뢰도를 병기하고, 요구 항목 전체표는 채용공고 해석 화면과 같은 데이터를 사용합니다.

### 5.3 채용공고 해석

전체 baseline·기업군 편차·개별 공고의 세 섹션을 항상 표시하고, 기업군 선택이 아래 두 섹션의 내용을 바꿉니다. baseline 카드는 통계 근거(등장률·필수율)를 병기하고, 편차 카드는 편차 없음 항목까지 명시합니다. 개별 공고는 원문의 모든 문장에 세 종류 주석 — 직무 공통(회색 번호+라벨), 숨은 의미(파란 하이라이트), 회사 특징(노란 하이라이트) — 을 달고, 종합 해석과 주석 종류별 해석 탭으로 보여 줍니다.

### 5.4 합격 전략

준비 현황 카드, 체크리스트 표 [요구 항목 · 근거 · 필요 산출물/활동 · 활용처 · 보유 여부], 활용처별 내용(자소서 소재, 포트폴리오 강조점, 예상 면접 질문)을 함께 배치합니다. 직무·기업군·개별 공고 범위는 체크리스트와 전략 전체를 바꾸고, 보유 체크는 준비 현황 숫자와 체크 표시만 바꿉니다. 포트폴리오·자소서·면접 전략은 체크 여부와 관계없이 유지합니다.

### 5.5 준비 로드맵

프로젝트 로드맵은 순서형 타임라인, 학습 전략은 병행형 트랙으로 배치합니다. 각 항목은 단계, 기간, 우선순위, 채워지는 체크리스트 항목, 산출물, 학습 깊이와 추천 이유를 제공합니다. 직무·기업군·개별 공고 범위가 기본 내용을 바꾸고, 체크 적용은 저장된 프로젝트·학습 후보의 완료 표시와 우선순위를 재조합합니다.

## 6. 표현 규칙

- 상단바와 오른쪽 목차만 반투명 흰색·블러 글래스를 사용합니다.
- 카드에는 불투명 흰색 배경, 얇은 테두리, 가벼운 그림자를 사용합니다.
- 버튼, 칩, 지표는 고정된 크기와 간격을 유지해 내용 변화로 레이아웃이 흔들리지 않게 합니다.
- 제목은 결론을 먼저 말하고, 보조 문장은 해당 결론을 읽는 기준을 제공합니다.
