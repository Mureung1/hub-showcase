# 디자인 컨셉

## 1. 디자인 컨셉 이름

### Signal Studio

이 프로젝트의 디자인 컨셉은 **Signal Studio**입니다.

흩어진 채용공고라는 "노이즈"에서 반복되는 요구사항이라는 "신호(Signal)"를 리서치 에이전트가 실시간으로 뽑아내고, 사용자가 그 신호를 바탕으로 커리어 준비 과정을 설계할 수 있도록 돕는 서비스의 성격을 시각적으로 표현합니다.

## 2. 핵심 키워드

- 신호(Signal)
- 실시간 분석
- 신뢰
- 명료함
- 다음 행동

## 3. 사용자에게 주고 싶은 인상

> 복잡한 채용공고를 대신 읽고, 지금 이 순간에도 분석하고 있는 믿을 수 있는 AI 커리어 어시스턴트

일반적인 보라색 AI SaaS 느낌을 피하지는 않되, 장식이 아니라 "지금 에이전트가 실제로 일하고 있다"는 실시간감을 전달하는 데 집중합니다.

### 3.1 톤 보정 기준 (타깃: 컴공/소프트웨어 취업 준비 대학생)

세 가지 축에서 중간 지점을 지향합니다.

- **채용공고처럼 딱딱하지 않게**: 실제 채용공고 문구를 그대로 나열하는 느낌(격식체, 불릿 나열)을 피하고, "이 공고들에서 반복적으로 나타난 요구사항이에요"처럼 설명해주는 듯한 문장을 씁니다. 다만 근거 수치(공고 수, 빈도)는 명확히 남깁니다.
- **학습 앱처럼 과도하게 교육적이지 않게**: 별점, 뱃지, 진행률 게이미피케이션, 캐릭터 일러스트 같은 장식은 쓰지 않습니다. "잘했어요" 식 성취 연출보다 "다음에 뭘 해야 하는지" 근거 중심으로 표현합니다.
- **정신없지도 단조롭지도 않게**: 색은 주색 1개 + 절제된 강조색으로 제한하되, 카드 크기와 텍스트 분량에 위계를 둬서(요약 카드는 작고 간결하게, 해석 카드는 크고 여유 있게) 리듬을 만듭니다. 같은 크기 카드를 반복 나열하지 않습니다.

## 4. 레퍼런스 종합

레퍼런스 4장에서 공통으로 뽑은 요소는 다음과 같습니다.

- 퍼플~인디고~블루 계열의 쿨톤 주색 (신뢰감과 테크 느낌)
- 카드 기반 위젯 레이아웃, 둥근 모서리(12~16px), 은은한 그림자
- 작은 pill/배지 태그로 상태나 카테고리 표시 (예: 완료/진행중, 중요도)
- 배경은 밝은 무채색이 기본이고, 강조 카드 1~2개만 그라디언트 + 옅은 반투명으로 떠 있는 구조
- "AI가 지금 실시간으로 일하는 중"임을 보여주는 라이브 표시와 활동 피드 (에이전트 성격과 직접 연결됨)

## 5. 디자인 방향

### 5.1 유지할 분위기

- 실시간으로 채용공고를 분석하는 에이전트라는 느낌(라이브 상태, 진행률)
- 카드형 정보 구조를 통한 명료한 근거 제시
- 전문적이지만 대학생이 부담 없이 읽을 수 있는 문장과 정보 밀도

### 5.2 피해야 할 분위기

- 화면 전체를 유리처럼 만드는 과도한 글래스모피즘 — **강조 영역 1~2곳에만 옅게 적용**하고 본문 카드는 불투명하게 유지합니다.
- 의미 없는 시스템 지표, 장식용 숫자
- 카드만 반복 나열하는 평범한 대시보드 (근거 → 해석 → 다음 행동의 흐름이 항상 보여야 함)
- 채용공고 원문처럼 딱딱한 격식체 문장과 불릿만 나열하는 서식
- 별점·뱃지·캐릭터·과도한 프로그레스바 같은 학습 앱풍 게이미피케이션 장식

### 5.3 콘텐츠 밀도와 텍스트 공간

레퍼런스 이미지들은 대부분 숫자 + 스파크라인 위주의 KPI 위젯이라 텍스트가 짧습니다. 반면 우리 서비스는 "왜 이 기술이 중요한지", "왜 이 순서로 학습해야 하는지" 같은 해석 문장을 실제로 보여줘야 하므로, 카드를 두 종류로 구분합니다.

- **요약 지표 카드**: 숫자·짧은 라벨 위주 (분석한 공고 수, 상위 키워드 빈도 막대). 작고 촘촘하게 배치 가능.
- **해석 카드**: 2~4문장 분량의 설명 텍스트를 담는 카드. 줄간격을 넉넉히(1.6~1.7) 주고 패딩을 충분히 확보해, 그리드 안에서 요약 지표 카드보다 넓은 폭을 차지하도록 배치합니다.

두 종류를 같은 그리드 안에 섞어 배치하면 크기 위계가 생겨서, 화면이 단조롭지도 정신없지도 않게 됩니다.

## 6. 레이아웃 방향

핵심 흐름은 기존과 동일합니다.

1. 관심 직무 선택
2. 요구 역량 분석 보고서 확인
3. 학습 로드맵 확인

### 6.1 기본 구조

- 왼쪽에 3단계 Progress Navigation을 배치합니다. 현재 단계는 주색(인디고/퍼플) 강조, 완료 단계는 저채도 체크 표시.
- 오른쪽에 현재 단계의 핵심 콘텐츠(카드형)를 배치합니다.
- 우측 상단 또는 사이드에 "에이전트 활동" 영역을 둡니다 — 지금 몇 개 공고를 분석했는지, 어떤 단계(수집→추출→로드맵 생성)를 지나고 있는지 실시간처럼 보여주는 작은 라이브 인디케이터 + 로그 리스트. Molar AI 레퍼런스의 "AI Agent · Live" 패턴을 참고합니다.
- 배경은 밝은 블루그레이/화이트를 기본으로 하고, 히어로 영역이나 에이전트 활동 카드 등 강조가 필요한 곳에만 그라디언트 + 옅은 반투명(backdrop blur)을 적용합니다. 전체 배경을 그라디언트로 덮지 않습니다.

## 7. 시각 요소

### 7.1 투명도 사용 원칙

- 배지, 강조 요약 카드, 에이전트 활동 패널 등 "지금 실시간으로 움직이는 정보"를 담는 요소에는 옅은 반투명(불투명도 70~85% + 약한 blur)을 허용합니다.
- 본문 텍스트가 있는 분석 카드, 로드맵 카드는 불투명하게 유지해 가독성을 지킵니다.
- 그라디언트는 화면 전체가 아니라 카드 1~2개, 혹은 히어로 배경에만 제한적으로 사용합니다.

### 7.2 색상

- Primary: 인디고/퍼플 계열 (신뢰 + 테크), 예: `#5B4FE9` 톤
- Secondary/Accent: 강조 CTA와 라이브 상태 표시용 보조색 (그린 계열 dot, 코랄/오렌지 포인트 등 소량)
- 배경: White 또는 매우 밝은 Blue-Grey
- 텍스트: 다크 네이비/차콜 계열로 대비 확보

### 7.3 타이포그래피

- 본문/제목: 가독성 높은 Sans-serif (한글 지원 서체, 예: Pretendard 계열)
- 수치, 상태 라벨, 작은 태그 등 보조 요소에 한해 Monospace 소량 사용
- 주요 제목과 설명은 자연스러운 한국어 문장으로 작성

## 8. 화면별 디자인 방향

### 8.1 관심 직무 선택 화면

가장 단순하고 여백이 넓은 화면. `직무 선택 → 분석 시작`이 명확히 보이도록 구성하고, 예시 직무 버튼은 카드형 pill 스타일로 표현합니다.

### 8.2 요구 역량 분석 보고서 화면

`근거 → 해석 → 다음 행동` 흐름이 보이도록 구성합니다. 기술별 빈도(요약 지표 카드)는 가로 막대와 수치로 표현하고, `22 / 24개 공고`처럼 근거를 함께 표시합니다. 그 옆이나 아래에는 "이 역량이 왜 중요한지"를 2~4문장으로 풀어주는 해석 카드를 넓게 배치합니다. 화면 한 편에 "에이전트가 지금 분석한 공고 수" 같은 실시간형 진행 카드를 작게 배치해 에이전트가 일하고 있다는 인상을 강화합니다.

### 8.3 학습 로드맵 화면

단계별 카드를 연결선으로 이어 순서를 시각적으로 보여주고, 각 단계는 `무엇을 → 어느 수준까지 → 왜`를 해석 카드 형태(2~4문장)로 함께 설명합니다. 단계 번호·수준 라벨(`기초/실전/심화`)은 작은 요약 지표처럼, 추천 이유 설명은 넓은 해석 카드로 구분해 배치합니다.

## 9. 디자인 원칙

### 9.1 정보가 장식보다 우선한다

시각 요소(그라디언트, 반투명, 라이브 인디케이터)는 서비스의 정보를 이해하거나 신뢰를 주는 데 도움이 될 때만 사용합니다.

### 9.2 분석 결과에서 행동으로 이어져야 한다

요구 역량 분석 보고서와 학습 로드맵이 분리된 화면처럼 보이지 않도록 근거와 추천 사이의 연결 관계를 표현합니다.

### 9.3 전문적이지만 어렵지 않아야 한다

대학생 사용자가 쉽게 이해할 수 있는 정보 구조와 문장을 유지합니다.

### 9.4 데이터에는 근거가 보여야 한다

분석 공고 수, 등장 빈도, 중요도 등 근거 정보를 함께 보여줍니다.

### 9.5 투명도는 절제해서 쓴다

옅은 반투명·블러는 "지금 살아있는 정보"를 강조할 때만 쓰고, 화면 전체를 유리처럼 만들지 않습니다.
