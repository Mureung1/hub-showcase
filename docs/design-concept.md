# CareerSignal 디자인 컨셉

## 1. 방향 요약

CareerSignal은 인디고를 포인트 컬러로 사용하는 차분한 리서치 리포트형 SaaS 인터페이스입니다. 채용공고의 요구사항을 단순 나열하지 않고, 사용자가 지원 준비의 우선순위를 빠르게 읽을 수 있도록 숫자·구현 범위·다음 행동을 순서대로 배치합니다.

앱 셸에는 고정 상단바와 은은한 글래스 효과를 사용하고, 본문 카드는 불투명한 흰색 배경으로 유지해 읽기 편하게 만듭니다.

## 2. 핵심 원칙

- **분석에서 행동으로**: 반복 요구사항을 필수 요구사항, 우대사항, 로드맵으로 연결합니다.
- **구현 범위를 보여주기**: 기술명보다 화면·데이터·실패 상태를 어느 수준까지 다뤄야 하는지 설명합니다.
- **근거 있는 정보 밀도**: 공고 건수와 비율은 짧게 보여 주고, 해설은 필요한 곳에만 둡니다.
- **절제된 시각 언어**: 인디고 강조, 흰 카드, 가벼운 그림자로 정보 위계를 만들며 장식은 최소화합니다.

## 3. 대상 사용자와 톤

대상은 채용공고를 읽어 본 적은 있지만 무엇을 먼저 준비할지 판단하기 어려운 컴퓨터·소프트웨어 분야 취업 준비 대학생입니다.

- 공고 문장을 그대로 반복하지 않고, 준비 기준을 설명하는 문장으로 씁니다.
- 초보자를 위한 서비스이되 과도한 게임화나 튜토리얼 문구는 사용하지 않습니다.
- 실제 데이터처럼 오해되지 않도록 정적 프로토타입의 24건 mock 리서치 표기를 유지합니다.

## 4. 확정된 화면 구조

세 화면은 `관심 직무 선택 → 요구사항 분석 보고서 → 학습 로드맵` 순서입니다.

- 모든 화면은 고정 상단바에 브랜드와 현재 단계를 둡니다. 보고서와 로드맵에는 분석 직무와 이전 화면으로 이동하는 링크를 추가합니다.
- 직무 선택 화면은 가운데 정렬된 단일 카드에 직무 입력, 예시 직무, 분석 범위 미리보기, CTA를 배치합니다.
- 보고서와 로드맵은 가운데 정렬한 본문 오른쪽에 고정형 글래스 목차를 둡니다. 넓은 화면에서는 본문 자체를 화면 중앙에 두고 목차는 그 오른쪽에 배치합니다.
- 화면 폭이 줄어들면 본문을 단일 열로 전환하고, 오른쪽 목차는 상단의 가로 스크롤 목차로 바꿉니다.
- 데스크톱에서는 90% 표시 밀도를 적용해 정보량이 많은 리포트도 답답하지 않게 읽히도록 합니다.

## 5. 화면별 정보 구성

### 5.1 관심 직무 선택

직무 입력과 예시 직무를 통해 분석의 시작점을 보여 줍니다. 아래 미리보기는 구현 범위 분석, 프로젝트 확인 항목, 기업군별 강조점, 다음 행동 연결을 설명합니다.

### 5.2 요구사항 분석 보고서

보고서는 다음 순서로 구성합니다.

1. 24건 mock 리서치 범위와 핵심 메시지
2. 5개 요약 지표 카드
3. React·TypeScript·REST API 등 반복되는 구현 범위 조합 카드
4. 기술 빈도와 해석
5. 먼저 맞춰야 할 필수 요구사항과 차별화할 우대사항
6. 학력·경력 조건, 기업군별 강조점, 공고 문장 확인 항목

### 5.3 학습 로드맵

세로 타임라인에 4단계 카드를 배치합니다. 각 카드는 단계, 기간, 우선순위, 구현 목표, 토픽 칩, 추천 이유를 제공합니다. 필수 흐름 완성부터 API 실패 상태, 우대사항 적용, 기업군 맞춤 소개 순서로 이어집니다.

## 6. 표현 규칙

- 상단바와 오른쪽 목차만 반투명 흰색·블러 글래스를 사용합니다.
- 카드에는 불투명 흰색 배경, 얇은 테두리, 가벼운 그림자를 사용합니다.
- 버튼, 칩, 지표는 고정된 크기와 간격을 유지해 내용 변화로 레이아웃이 흔들리지 않게 합니다.
- 제목은 결론을 먼저 말하고, 보조 문장은 해당 결론을 읽는 기준을 제공합니다.
