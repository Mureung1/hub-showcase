프로젝트 [오늘모여] 기획서

원하는 때에만 참석하는 시간 주도형 초단기간 모임 서비스

프로젝트 요약

문제 상황 (Problem)

  • 고정된 일정의 제약: 기존의 동아리나 일반 모임은 정해진 스케줄에 개인을 맞춰야 하므로, 일정이 유동적이거나 바쁜 사람들은 참석 자체가 어려움.
  • 지속 참여의 압박과 의지의 한계: 장기적인 모임은 매번 참여해야 한다는 압박감을 주어 원하는 때에만 가볍게 활동하기 힘든 반면, 완전히 혼자서 무언가를 꾸준히 활동하고 기록해 나가는 것은 의지력의 한계에 부딪힘.

해결 방안 (Solution)

  • 시간 주도형 초단기간 모임 서비스 [오늘모여]: 내가 원하는 시간대를 선택해 사람을 모으거나 개설된 시간에만 단발성으로 참여하는 유연한 활동 공간을 제공하며, 개인이 참여한 모든 활동을 체계적으로 누적 기록해 주는 지속 가능한 스케줄 기반 시스템.

핵심 기능 요약 (Core Features)

  • 단발성 초단시간 모임 시스템: 방장이 설정한 시작 시각과 진행 시간에 맞추어 원하는 스케줄에만 선착순 예약 신청 후 정시에 모여 집중하는 시스템.
  • 활동 기록 체크 및 유도 시스템: 마이페이지 대시보드를 통해 나의 활동 기록을 한눈에 체크할 수 있으며, 누적 리포트를 바탕으로 유저가 지치지 않고 꾸준하게 다음 모임에 참여할 수 있도록 동기를 유도하는 개인화 시스템 제공.

화면 구성 설명

1. 메인 홈 화면
↳ 내가 신청한 모임 대시보드 ↳ 총 진행 시간 표시 인터페이스 ↳ 당일 활동 메모장
2. 모임 구인 목록 화면
↳ 카테고리 탭 ↳ 모임 구인 글 목록
3. 모임 개설 화면
↳ 구인 정보 입력 폼 ↳ 카테고리 선택 필드 ↳ 모임 예약 시간 설정 폼
4. 실시간 모임방 화면
↳ 타이머 디스플레이 ↳ 모임 메시지 창
