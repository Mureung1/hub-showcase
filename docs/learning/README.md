이 폴더는 개발할 때마다 ChatGPT 프로젝트에 넣고 공부할 키워드를 짧게 정리하는 공간이다.

참고서처럼 길게 설명하지 않는다. 각 문서는 다음만 포함한다.

- 공부 키워드
- 왜 필요한지 한 줄
- 이 프로젝트에서 볼 코드 위치
- ChatGPT에 물어볼 질문 예시
