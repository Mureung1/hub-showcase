# XP UI CSS

## 키워드

- CSS custom properties
- absolute positioning
- z-index
- draggable window
- taskbar layout
- desktop icon layout
- bevel border
- box-shadow inset
- image-rendering: pixelated
- responsive media query
- file URL relative path

## 왜 공부하나

이 앱의 첫인상은 기능보다 XP 데스크톱처럼 보이는 UI 구조에서 나온다.
