## 왜 공부하나

코드 PR과 Wiki 문서는 제출 방식이 다르다. PR에는 docs와 public 파일이 포함되고, Wiki는 별도로 갱신한다.

## 확인할 부분

- 현재 브랜치: N019_김동민
- fork remote: origin
- 원본 저장소: upstream 또는 base repository
- Wiki는 PR에 포함되지 않음
- 정적 프로토타입은 public/prototype-static.html로 PR에 포함
- GitHub Issues는 실행 단위이고 GitHub Project는 우선순위와 상태 보드
- Project #1 필드: Priority, Week, Type, Status
