# 일일 회고

부트캠프 LMS 제출용 초안 기록. 매일 작성 후 여기에도 누적.

## 7/19(일)~7/20(월)

[오늘 잘한 일]
주말에 design-upgrade 브랜치로 화면을 통째로 갈아엎었다 — 무드 피커, 사진 첨부, 캘린더 뷰, 플립 카드, mood/image_url 컬럼까지 붙였다. 오늘은 이걸 실제로 반영하는 작업을 끝까지 갔다: Supabase 컬럼 추가, 브라우저에서 하나씩 직접 눌러보며 확인한 뒤 N114_유승혁에 머지·푸시. 주간 계획도 이슈 여덟 개로 쪼개서 등록했다.

[아쉬운 일]
화면 확인하다가 다른 사람 결과물이랑 비교하면서 내 프론트가 빈약해 보인다고 잠깐 위축됐다.

[다음에 다시 한다면?]
결과물을 남과 비교하기 전에 이번 주 체크리스트가 다 됐는지부터 본다.

## 7/21(화)

[오늘 잘한 일]
Supabase 연동이 이미 끝나 있다는 걸 코드로 다시 확인했다. 수업 자료와 녹음 대본을 먼저 읽고 화면 데이터 흐름 순서로 설계하기, 완료 기준 먼저 정하기, 구현 방법 비교하기, 이해 못한 전략은 통과시키지 않기 절차를 정리한 다음 체크인 삭제 기능 하나에 그대로 적용해봤다. 관련 파일, API 명세, 구현 방법 비교, 완료 기준, 작업 분할, 이슈 초안까지 코드 없이 설계서로 먼저 썼고, 이 절차를 다음 기능에도 반복 쓸 수 있게 스킬로 옮겨뒀다.

[아쉬운 일]
오늘 수업이 뭘 요구하는지 자료와 녹음을 먼저 확인하지 않고 짐작으로 먼저 대답했다가, 원문부터 보라는 말을 듣고 다시 확인했다.

[다음에 다시 한다면?]
설계서 승인받으면 코드부터 짜지 않고 Supabase에 의존하는 checkinService를 어떻게 테스트할지부터 정하고 TDD로 들어간다.
