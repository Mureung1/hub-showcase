# UI_GUIDE

**이 문서의 역할**: 화면 표현 규칙 — 디자인 토큰, 상태 표기, 문구, 접근성. 화면별로 무엇을 보여주고 어디로 이동하는지는 `PRD.md` 4장, 금지 문구는 `GOTCHAS.md`, 용어의 뜻은 `GLOSSARY.md`에 있다. 여기서 그것들을 다시 쓰지 않는다.

## UI 원칙

리뷰지기의 사용자는 40~60대 외식업 소상공인이다. 바쁜 영업 중 또는 마감 후 짧은 시간에 확인하므로 화면은 적게 묻고, 크게 보여주고, 다음 행동을 명확히 제시해야 한다.

## 화면 구조

공통 내비게이션은 6개 메뉴를 유지한다: **홈 · 리뷰함 · 리뷰 입력 · 분석 리포트 · 블랙컨슈머 대응 · 매장 설정**

- 리뷰 상세·답글은 홈과 리뷰함에서 들어가는 하위 화면이며 메뉴에 두지 않는다.
- 로그인·회원가입은 사이드바가 없는 단독 화면이며 6개 메뉴에 포함되지 않는다.

## 디자인 토큰

테마는 **Traditional Premium Heritage** 한 가지다.

| 토큰 | 값 | 용도 |
|---|---|---|
| Deep Burgundy | `#650B12` | 주요 버튼, 내비게이션, 핵심 상태 |
| Gold | `#B88A24` | 강조, 보조 CTA, 인사이트 |
| Ivory | `#F6F1E8` | 전체 배경 |
| Surface | `#FFFDF8` | 카드 배경 |
| Red | `#A12828` 계열 | 악성 의심, 위험 경고 |

외부 폰트와 CDN 없이 실행하는 것을 기본으로 하며, 시스템의 `Malgun Gothic`·`Georgia`·`Batang` 계열을 사용한다.

## 상태 표기

각 상태가 무엇을 뜻하는지는 `GLOSSARY.md`에 있다. 여기서는 화면에 어떻게 보일지만 정한다.

### 리뷰 유형 배지

| 유형 | 색상 방향 | 표기 |
|---|---|---|
| 칭찬 | 초록 | 배지 |
| 불만 | 앰버 | 배지 |
| 문의 | 파랑 | 배지 |
| 악성 의심 | 빨강 | 배지 + 카드 빨간 보더로 목록에서 즉시 구분 |

### 답글 상태 칩

`초안 대기` · `확인 필요` · `완료` 세 가지를 칩으로 표기한다. 색상만으로 구분하지 않고 텍스트를 항상 함께 둔다.

## 문구 규칙

- 존댓말을 기본으로 한다.
- "감성 분석", "토픽 추출" 같은 전문 용어보다 "손님 반응", "자주 나온 말"을 쓴다.
- 버튼 문구는 다음 행동이 무엇인지 그대로 드러낸다("AI 답글 확인", "대응 방법 확인", "답글 복사하기").
- 사장님이 직접 해야 하는 단계와 시스템이 안내만 하는 단계를 문구에서 구분한다.
- 법률·환불·신고 관련 문구는 단정하지 않는다. 쓸 수 있는 표현과 금지 표현은 `GOTCHAS.md`에 있다.

## 접근성 기준

- 본문은 16px 이상을 기본으로 한다.
- 버튼은 모바일에서도 손가락으로 누르기 쉬운 높이를 유지한다.
- 색상만으로 상태를 구분하지 않고 텍스트 배지를 함께 둔다.
- 위험 상태는 문구와 색상을 함께 제공한다.
- 정보 밀도를 낮게 유지하고, 한 화면에서 결정할 일을 하나로 좁힌다.
