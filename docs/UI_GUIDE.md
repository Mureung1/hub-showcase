# UI_GUIDE

## UI 원칙

리뷰지기의 사용자는 40~60대 외식업 소상공인이다. 바쁜 영업 중 또는 마감 후 짧은 시간에 확인하므로 화면은 적게 묻고, 크게 보여주고, 다음 행동을 명확히 제시해야 한다.

## 화면 구조

공통 내비게이션은 다음 6개 메뉴를 유지한다.

1. 홈
2. 리뷰함
3. 리뷰 입력
4. 분석 리포트
5. 블랙컨슈머 대응
6. 매장 설정

리뷰 상세·답글 화면은 홈과 리뷰함에서 들어가는 하위 화면이다.

## 디자인 테마

현재 PRD 기준 테마는 **Traditional Premium Heritage**이다.

| 토큰 | 값 | 용도 |
|---|---|---|
| Deep Burgundy | `#650B12` | 주요 버튼, 내비게이션, 핵심 상태 |
| Gold | `#B88A24` | 강조, 보조 CTA, 인사이트 |
| Ivory | `#F6F1E8` | 전체 배경 |
| Surface | `#FFFDF8` | 카드 배경 |
| Red | `#A12828` 계열 | 악성 의심, 위험 경고 |

외부 폰트 없이 실행하는 것을 기본으로 하며, 현재 프로토타입은 `Malgun Gothic`, `Georgia`, `Batang` 계열을 사용한다.

## 상태와 배지

### 리뷰 유형

| 유형 | 색상 방향 | UI 의미 |
|---|---|---|
| 칭찬 | 초록 | 안전한 긍정 리뷰 |
| 불만 | 앰버 | 사과와 개선 약속 필요 |
| 문의 | 파랑 | 운영 정보 기반 답변 필요 |
| 악성 의심 | 빨강 | 자동 답글 금지, 대응 센터 연결 |

### 답글 상태

- `초안 대기`: 초안 생성됨, 사장님 미확인
- `확인 필요`: 악성 의심, 분류 애매, 별점·본문 불일치
- `완료`: 사장님이 외부 플랫폼에 게시 후 완료 표시

## 주요 화면별 UI 기능

### 홈

- 오늘 처리할 리뷰 현황을 통계 카드로 보여준다.
- 악성 의심 리뷰를 가장 먼저 배치한다.
- “AI 답글 확인” 또는 “대응 방법 확인”처럼 다음 행동을 버튼으로 명확히 둔다.

### 리뷰함

- 유형 탭과 답글 상태 필터를 제공한다.
- 리뷰 카드는 플랫폼, 별점, 닉네임, 본문, 메뉴, 유형, 상태를 한눈에 보여준다.
- 악성 의심 카드는 빨간 보더로 즉시 구분한다.

### 리뷰 상세·답글

- 원본 리뷰와 AI 답글 초안을 좌우로 배치한다.
- 답글은 직접 수정 가능해야 한다.
- “답글 복사하기”가 1차 버튼이다.
- 악성 의심 리뷰에는 답글 에디터 대신 경고와 대응 매뉴얼 버튼을 보여준다.

### 리뷰 입력

- 한 건 입력과 일괄 붙여넣기를 모두 제공한다.
- 입력 중 분류 미리보기를 보여준다.
- 과거 리뷰를 붙여넣으면 분석 정확도가 올라간다는 안내를 둔다.

### 분석 리포트

- 콜드 스타트 상태를 반드시 제공한다.
- 차트는 세부 수치보다 행동 가능한 인사이트를 우선한다.

### 블랙컨슈머 대응

- 위험도와 감지 근거를 먼저 보여준다.
- 4단계 대응 매뉴얼을 위에서 아래로 수행하게 한다.
- 법적 안내 영역에는 “일반적인 정보 안내이며 법률 자문이 아닙니다” 문구를 항상 노출한다.

### 매장 설정

- 답글 톤과 운영 정보가 답글에 어떻게 반영되는지 미리보기를 제공한다.
- Phase 2 자동화 수준은 비활성 상태로만 노출한다.

## 문구 규칙

- 존댓말을 기본으로 한다.
- “감성 분석”, “토픽 추출” 같은 전문 용어보다 “손님 반응”, “자주 나온 말”을 쓴다.
- 법률, 환불, 신고 관련 문구는 단정하지 않는다.
- 사장님이 실행해야 하는 단계와 시스템이 안내만 하는 단계를 구분한다.

## 접근성 기준

- 본문은 16px 이상을 기본으로 한다.
- 버튼은 모바일에서도 손가락으로 누르기 쉬운 높이를 유지한다.
- 색상만으로 상태를 구분하지 않고 텍스트 배지를 함께 둔다.
- 위험 상태는 문구와 색상을 함께 제공한다.
