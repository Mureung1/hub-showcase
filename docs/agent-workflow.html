TeamFlow AI 개발 워크플로우

코드를 작성하는 역할과 결과를 검증하는 역할을 분리했습니다.

작동 과정

요구사항 기능과 완료 기준
→
코딩 Agent 계획과 기능 구현
→
테스트 Skill 테스트 작성 방법 안내
→
검증 Agent 요구사항과 실행 결과 확인
→
사용자 판단 승인 또는 수정

역할 구분

테스트 작성 Skill

  • 코딩 Agent가 사용합니다.
  • 테스트 수준과 작성 순서를 안내합니다.
  • 필요하면 TDD로 테스트와 기능을 작성합니다.

검증 Agent

  • 완성된 기능을 독립적으로 확인합니다.
  • 테스트·lint·build 결과를 근거로 판정합니다.
  • 문제를 발견해도 코드는 수정하지 않습니다.

TDD를 사용하는 경우

실패하는 테스트 작성 → 최소 구현 → 테스트 통과 → 전체 회귀 확인

입력 검증, 권한, API 계약처럼 기대 결과가 명확한 기능에 선택적으로 적용합니다.
