TeamFlow AI 개발 워크플로우

코드를 작성하는 역할과 결과를 검증하는 역할을 분리해, AI가 만든 기능을 다른 관점에서 다시 확인합니다.

작동 과정

요구사항 기능 범위와 직접 확인할 수 있는 완료 기준을 전달
→
코딩 Agent 기존 구조를 확인하고 계획을 세운 뒤 기능 구현
→
테스트 Skill 프로젝트에 맞는 테스트 수준·사례·실행 순서를 안내
→
검증 Agent 요구사항, 테스트 품질, 실행 결과를 독립적으로 확인
→
사용자 판단 검증 근거를 보고 승인·수정·보류 결정

역할 구분

테스트 작성 Skill

  • 코딩 Agent가 기능 개발 과정에서 사용합니다.
  • 단위·통합·컴포넌트 중 적절한 수준을 선택합니다.
  • 정상값뿐 아니라 빈 값·경계값·실패값도 확인합니다.
  • 규칙이 명확한 기능은 TDD로 개발합니다.
  • 관련 테스트부터 전체 회귀 테스트까지 실행합니다.

검증 Agent

  • 완성된 기능을 독립적으로 확인합니다.
  • 요구사항마다 코드와 실행 결과를 연결합니다.
  • 테스트 기대값과 Mock의 검증 범위도 검사합니다.
  • 테스트·lint·build 결과를 직접 확인합니다.
  • 통과·실패·확인 불가·범위 제외로 판정합니다.
  • 문제를 발견해도 코드는 수정하지 않습니다.

TDD를 사용하는 경우

실패하는 테스트 작성 → 최소 구현 → 테스트 통과 → 전체 회귀 확인

입력 검증, 권한, 계산, API 계약처럼 기대 결과가 명확한 기능에 선택적으로 적용합니다. UI 배치나 프로토타입에는 TDD를 무조건 적용하지 않습니다.

역할을 분리한 이유

작성 Agent는 구현에 집중하고, 검증 Agent는 코드를 수정하지 않은 채 근거만 보고합니다. 이를 통해 “테스트가 존재한다”와 “기능이 실제로 동작한다”를 구분합니다.
