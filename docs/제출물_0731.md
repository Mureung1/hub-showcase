## 3. 제출 양식용 설명문

### 한 줄 소개

> 날씨 데이터로 소상공인의 매출을 지키는 자율 마케팅 에이전트 — 에이전트가 마케팅을 미리 완성해 두고, 사장님은 승인만 한다.

### 문제

동네 카페·식당 매출은 날씨에 강하게 연동되지만, 1인 운영 사장님에게는 매일 날씨를 보고
전략을 짜고 홍보 문구를 쓸 시간도 전문성도 없다. 이들이 원하는 것은 더 좋은 마케팅 툴이
아니라 **"마케팅을 안 해도 되는 상태"** — 의사결정 대행이다.

### 솔루션

에이전트가 매일 아침 날씨와 그 가게의 **실매출 데이터**를 분석해 문구·쿠폰을 미리 완성해
두고, 사장님은 **승인 / 수정 / 반려** 하나만 누른다. 발송 후에는 쿠폰 코드로 캠페인이 실제
만든 매출을 실측해 되돌려준다.

### 에이전트 워크플로우

```
크론 06:30 KST (예상 하락 −20% 이상일 때만 발동 — 마케팅 남발 방지)
  → ① 날씨 앙상블 (기상청 + OpenWeatherMap 가중 병합, 한쪽 장애 시 폴백)
  → ② 매출 진단 ("이 가게는 비 오는 날 −18%" 실계산)
  → ③ LLM 제안 생성 (Groq · llama-3.3-70b)
  → ④ 가드레일 (할인율 ≤20% · 금지어 · LMS 2000byte)
  → ⑤ [사람] 사장님 검토 — 승인 / 수정 / 반려
  → ⑥ 법적 필터 **서버 강제** (수신동의자만 · (광고) 표기 · 야간 차단→예약)
  → ⑦ 발송 (Solapi 문자 + Instagram 자동 게시)
  → ⑧ 쿠폰 사용 추적 · 귀속 매출 실측
```

사람이 개입하는 지점은 ⑤뿐이다.

### 기술 스택

React + TypeScript (Vite) / Node + Express + TypeScript / Supabase (PostgreSQL),
npm workspaces 모노레포. 프론트 Vercel · 백엔드 Render 배포. 테스트 **183건** (Vitest).

### 구현 스코프 — 실연동 / 대체 / 모의

심사 시 가장 먼저 확인될 부분이라 명시한다.

| 영역 | 처리 |
|---|---|
| 날씨(기상청+OWM) · LLM(Groq) · DB · 문자(Solapi 본인 번호) · Instagram(본인 계정 게시) | ✅ **실연동** |
| POS 연동 | 🔁 수동 일매출 입력 + CSV 업로드로 **대체** |
| 080 수신거부 실회선 · 카카오 알림톡 · 타인 계정 SNS 게시(App Review 필요) | 🎭 **모의** |

- "쿠폰 실시간 추적"은 연출이며 실제로는 쿠폰 코드 기반 **누적 집계**다.
- 문자·Instagram 모두 **본인 계정/번호에만** 실동작한다.
- Instagram 실게시 검증 기록: [`@cafe_kimsajang` 게시물](https://www.instagram.com/p/DbSE6HDkmpB/) (2026-07-27)

### 차별점 3가지

1. **법을 UI가 아니라 서버가 강제한다.** 정보통신망법 요건(수신동의·(광고) 표기·야간 차단)을
   `apps/server/src/legal/filter.ts`에서 검사한다. 프론트를 우회해 API를 직접 불러도 막힌다.
2. **채널 역할을 분리했다.** 단골 문자는 1인 1코드로 **전환을 실측**하고, 공개 채널(인스타·X)은
   수신자 목록이 없어 코드를 못 주므로 **도달**을 맡는다. 못 하는 걸 하는 척하지 않는다.
3. **성과가 자율성의 근거가 된다.** 쿠폰 실측이 쌓여야 L0(제안만)→L1(승인 후 실행)→L2(완전 자율)로
   승격되는 구조. 승격 결정권은 항상 사장님에게 있고, 법적 필터는 어느 레벨에서도 우회 불가.

- "실시간 추적"이라고 말하지 않는다. 누적 집계다.

## 5. 심사자가 직접 확인하는 법

양식에 "검증 방법"란이 있으면 이걸 넣는다.

```bash
# 1. 서버 살아있는지 (첫 요청은 절전 해제로 최대 60초)
curl https://weatherpilot-server.onrender.com/health

# 2. 오늘 실제 날씨 — 기상청+OpenWeatherMap 앙상블
curl https://weatherpilot-server.onrender.com/weather/today

# 3. 오늘 생성된 제안 (진단·문구·쿠폰)
curl https://weatherpilot-server.onrender.com/proposal/today
```

`weather.sources`에 `["kma","owm"]`이 들어 있으면 두 개의 실제 예보 API를 병합한 값이다.
(`seeded: true`가 보이면 데모용 고정 날씨가 켜진 상태다.)

전체 플로우는 https://weatherpilot-web.vercel.app 에서 바로 체험할 수 있다.
