### TanStack Query와 Zustand의 책임 분리

서버 상태(TanStack Query)와 클라이언트 UI 상태(Zustand)를 분리해서 관리한다. TanStack Query는 요청
상태, 캐시, 재시도, 무효화를 컴포넌트의 UI 상태와 분리하고, Zustand는 작은 API로 전역 UI 상태를
관리하며 불필요한 구조를 줄인다. 상세 사용 기준은
[development-guide.md의 상태와 데이터 소유권](./development-guide.md#상태와-데이터-소유권)을 참고한다.
