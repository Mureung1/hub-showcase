# 사용자 정보 입력 플로우

## 목적

사용자가 입력한 주거 조건과 선호도를 이후 매물 AI 분석의 기준으로 사용한다.

## 전체 단계

### 1단계: 기본 조건

- 재학 중인 학교
  - 강원대학교
  - 경북대학교
  - 경상국립대학교
  - 부산대학교
  - 서울대학교
  - 전남대학교
  - 전북대학교
  - 제주대학교
  - 충남대학교
  - 충북대학교

- 계약 유형
  - 월세
  - 전세
  - 상관없음

- 입주 희망 시기

### 2단계: 예산

- 월 주거 예산
- 최대 보증금
- 최대 월세
- 최대 관리비
- 월 주거비 총액 기준 사용 여부

금액 단위는 만 원으로 입력한다.

### 3단계: 통학과 이동

- 주당 등교 횟수
- 귀가 시간
  - 선택 입력으로 둔다.
- 주요 이동 목적지
  - 학교
  - 직장
  - 기타

- 최대 통학 또는 통근 시간
- 선호 교통수단
  - 도보
  - 대중교통
  - 자동차
  - 자전거

### 4단계: 주거 선호

- 선호 주거 형태
  - 원룸
  - 투룸
  - 오피스텔
  - 빌라
  - 아파트
  - 상관없음

- 중요하게 생각하는 조건
  - 역세권
  - 채광
  - 방음
  - 치안
  - 편의시설
  - 주차
  - 엘리베이터
  - 반려동물 가능

- 피하고 싶은 조건
  - 반지하
  - 옥탑
  - 저층
  - 노후 건물
  - 큰길 주변
  - 유흥가 주변

### 5단계: 입력 내용 확인

- 사용자가 입력한 내용을 항목별로 요약한다.
- 이전 단계로 돌아가 수정할 수 있게 한다.
- 완료하면 매물 스크린샷 업로드 단계로 이동한다.

## 데이터 저장

현재 단계에서는 서버에 전송하지 않는다.

React state에 다음과 같은 형태로 보관한다.

```js
{
  school: "",
  contractType: "",
  moveInDate: "",
  budget: "",
  maxDeposit: "",
  maxMonthlyRent: "",
  maxMaintenanceFee: "",
  useTotalBudget: false,
  commuteDaysPerWeek: "",
  returnTime: "",
  destination: "",
  maxTravelTime: "",
  transportation: [],
  housingTypes: [],
  priorities: [],
  avoidConditions: []
}
