# TMI — 대화가 막히지 않게 돕는 AI 대화 코파일럿

> 처음 만난 사람, 어색한 직장 동료, 연인과의 대화까지.
> 상황에 맞는 질문과 다음 대화를 제안해 자연스럽게 관계를 이어주는 AI 기반 대화 가이드 서비스

## 1. 서비스 소개

대화는 관계를 시작하고 유지하는 중요한 기술이지만, 많은 사람은 다음과 같은 순간에 어려움을 느낀다.

- 처음 만난 사람에게 어떤 질문을 해야 할지 모르겠다.
- 직장 상사나 동료와 어색한 침묵이 생긴다.
- 연인과 대화가 반복되거나 갈등 상황에서 말을 꺼내기 어렵다.
- 상대방의 반응이 애매할 때 대화를 계속 이어가야 할지 판단하기 어렵다.

**TMI는 사용자의 관계와 현재 상황을 바탕으로, 지금 가장 자연스러운 질문·답변·대화 방향을 추천하는 AI 대화 코파일럿이다.**

단순히 대화 주제를 나열하는 서비스가 아니라, 사용자가 실제 대화 중 바로 활용할 수 있도록 **“다음 한마디”를 제안하는 것을 목표로 한다.**

---

## 2. 문제 정의

### 대화는 중요하지만 즉흥적으로 잘하기 어렵다

사람들은 대화가 어색해질 때 다음과 같은 행동을 반복한다.

`무슨 말을 해야 할지 고민 → 침묵 발생 → 어색함 증가 → 대화 종료`

특히 처음 만나는 자리, 직장 관계, 연인 관계에서는 말 한마디가 관계의 분위기에 큰 영향을 줄 수 있다.

하지만 기존의 대화 주제 추천 서비스는 다음 한계가 있다.

- 상황과 관계의 맥락을 충분히 반영하지 못한다.
- 질문 리스트만 제공해 실제 대화 흐름으로 연결되기 어렵다.
- 상대방의 반응에 따라 다음 행동을 제안하지 못한다.
- 갈등 상황이나 어색한 침묵처럼 민감한 순간에 활용하기 어렵다.

---

## 3. 해결 방식

TMI는 사용자가 선택한 관계, 장소, 분위기, 대화 목적을 바탕으로 AI가 맞춤형 대화 흐름을 생성한다.

사용자는 단순히 주제를 받는 것이 아니라 다음과 같은 도움을 받을 수 있다.

- 지금 꺼내기 좋은 첫 질문
- 상대방 답변에 따른 후속 질문
- 어색한 침묵을 자연스럽게 넘기는 멘트
- 너무 사적인 질문을 피하는 안전한 대화 방향
- 연인과의 감정 대화, 갈등 완화 대화 가이드
- 직장 상사·동료에게 적절한 톤의 질문 추천

---

## 4. 핵심 기능

### 4-1. 상황 기반 대화 시작 추천

사용자가 관계와 상황을 선택하면 AI가 바로 사용할 수 있는 첫 질문을 추천한다.

예시 상황

- 처음 만난 소개팅
- 새 학기 친구와 첫 대화
- 직장 상사와 점심 식사
- 어색한 팀원과 프로젝트 회의 전
- 오랜만에 만난 친구
- 연인과 데이트 중
- 연인과 다툰 뒤 화해 대화

예시 추천

> “요즘 가장 재미있게 본 콘텐츠 있어요?”
> “이번 프로젝트에서 가장 기대하는 부분은 뭐예요?”
> “오늘 데이트에서 제일 좋았던 순간은 뭐였어?”

---

### 4-2. 다음 한마디 추천

대화 중 상대방의 답변이나 현재 상황을 간단히 입력하면, AI가 자연스럽게 이어갈 다음 문장을 추천한다.

예시

```text
상대방 답변:
“요즘 회사 일이 너무 바빠서 취미를 거의 못 하고 있어요.”

추천 답변:
“많이 바쁘셨겠네요. 그래도 시간 나면 가장 먼저 다시 하고 싶은 취미가 있어요?”
```

단순 질문 추천이 아니라 공감 → 확장 질문 → 자연스러운 주제 전환까지 이어지는 흐름을 제공한다.

---

### 4-3. 대화 온도계

현재 대화 분위기를 사용자가 직접 선택하거나 AI가 입력 문맥을 기반으로 분석한다.

대화 상태 예시

- 😊 대화가 잘 이어지는 중
- 😐 조금 어색한 상태
- 🤔 상대 반응이 애매한 상태
- 😶 침묵이 길어지는 상태
- 😟 감정적으로 조심해야 하는 상태

상태에 따라 서로 다른 대화 전략을 제안한다.

예시

| 상황                | 추천 전략                                      |
| ------------------- | ---------------------------------------------- |
| 침묵이 길어질 때    | 주변 상황, 음식, 장소 등 부담 없는 주제로 전환 |
| 상대 반응이 짧을 때 | 질문 강도를 낮추고 선택형 질문 제안            |
| 대화가 잘 이어질 때 | 공통 관심사 기반으로 더 깊은 이야기 확장       |
| 갈등 상황일 때      | 해결책보다 감정 확인을 우선하는 문장 추천      |

---

### 4-4. 관계별 대화 모드

관계에 따라 적절한 말투와 질문의 깊이가 달라진다.

TMI는 관계별로 다른 대화 전략을 제공한다.

| 관계           | 대화 목표                                |
| -------------- | ---------------------------------------- |
| 처음 만난 사람 | 어색함 완화, 공통점 탐색                 |
| 친구           | 친밀도 형성, 관심사 확장                 |
| 직장 상사      | 예의 있는 소통, 업무 외 가벼운 관계 형성 |
| 직장 동료      | 협업 분위기 형성, 친밀도 조절            |
| 연인           | 감정 공유, 관계 유지, 갈등 완화          |
| 가족           | 감정 표현, 세대 차이 완화                |

---

### 4-5. 대화 미션

대화를 어려워하는 사용자가 부담 없이 연습할 수 있도록 작은 미션을 제공한다.

예시

- 오늘 처음 만난 사람에게 열린 질문 1개 하기
- 상대방 답변에 후속 질문 2번 이어가기
- 칭찬을 한 번 자연스럽게 건네기
- 연인에게 오늘의 감정을 한 문장으로 표현하기
- 직장 동료에게 업무 외 질문 한 번 하기

대화가 단순한 일회성 추천에서 끝나지 않고, 사용자의 커뮤니케이션 역량 향상으로 이어지도록 설계한다.

---

### 4-6. 대화 회고 리포트

대화가 끝난 뒤 사용자가 간단히 회고를 남기면 AI가 피드백을 제공한다.

예시 항목

- 오늘 대화는 어땠나요?
- 가장 어색했던 순간은 언제였나요?
- 상대방 반응은 어땠나요?
- 다음에는 어떤 점을 더 잘하고 싶나요?

AI 피드백 예시

> 오늘은 상대방의 답변을 기반으로 후속 질문을 잘 이어갔다.
> 다음 대화에서는 질문만 이어가기보다 본인의 경험도 함께 공유하면 더 자연스러운 대화가 될 수 있다.

## 5. 사용자 흐름

```text
상황 선택
→ 관계 선택
→ 대화 목적 선택
→ AI가 첫 질문 추천
→ 상대방 반응 입력
→ 다음 한마디 및 후속 질문 추천
→ 대화 종료 후 회고 및 피드백 제공
```

예시 플로우

```text
직장 동료와 점심
→ 아직 어색한 관계
→ 자연스럽게 친해지고 싶음
→ 첫 질문 추천
→ 상대방 답변 입력
→ 다음 질문 및 공감 멘트 추천
→ 대화 회고
```

## 6. 차별점

### 단순 질문 리스트가 아닌 대화 흐름 제공

기존 서비스가 “무슨 질문을 할까?”에 집중한다면, TMI는 다음 단계까지 지원한다.

```text
첫 질문
→ 상대방 답변
→ 공감
→ 후속 질문
→ 자연스러운 주제 확장
→ 대화 마무리
```

### 관계와 상황을 함께 고려

같은 질문이라도 상대가 친구인지, 상사인지, 연인인지에 따라 적절한 표현은 달라진다.

TMI는 관계, 장소, 대화 목적, 분위기를 함께 고려해 문장을 생성한다.

### 실제 대화 중 바로 활용 가능

복잡한 분석보다 사용자가 바로 말할 수 있는 짧고 자연스러운 문장을 제공한다.
