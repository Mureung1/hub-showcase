# 프로젝트 브리프

## 프로젝트 배경

관계형 AI는 감정과 상황을 표현하는 사용자에게 공감과 다음 단계를 제시하는 웹서비스입니다. 현대의 많은 디지털 도구는 감정을 단순히 수집하거나 분류하는 데 그치며, 사용자가 관계적 피드백을 받는 경험이 부족합니다.

## 해결하려는 문제

사용자는 자신의 상황과 감정을 표현하고 싶지만, 기존 자동화된 서비스는 공감이나 후속 질문을 제공하지 못합니다. 이로 인해 사용자는 답답함을 느끼고 대화 흐름이 끊깁니다.

## 주요 사용자

* 자신의 감정 상태를 정리하려는 사용자
* 공감형 피드백이 필요한 사용자
* 초기 상담이나 감정 정리가 필요한 사용자

## 핵심 가치

* 빠른 감정 입력과 공감 응답 제공
* 감정 기반 후속 질문으로 사용자 생각을 확장
* 대화 흐름을 자연스럽게 이어주는 경험

## 사용자가 경험할 흐름

1. 사용자가 현재 상황을 텍스트로 입력한다.
2. 사용자가 현재 감정을 선택한다.
3. 화면에서 ‘전송’ 버튼을 누른다.
4. 시스템이 입력값을 검증하고 Mock AI 응답을 생성한다.
5. 생성된 응답이 화면에 표시된다.
6. 응답이 Supabase에 저장된다.
7. 대화 화면이 최신 상태로 갱신된다.

## 핵심 사용자 시나리오

사용자는 힘든 상황을 입력하고 "불안"을 선택합니다. 시스템은 공감형 메시지를 생성하고, "그 상황에서 가장 고민되는 부분은 무엇인가요?"라는 후속 질문을 제안합니다.

## 서비스가 제공하려는 관계형 경험

* 사용자의 감정에 맞춘 공감적 응답
* 상황을 반영한 후속 질문
* 대화형 피드백으로 사용자 경험 강화
* 데이터 저장을 통한 대화 흐름 유지
