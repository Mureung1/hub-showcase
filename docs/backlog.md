# 하소AI 개발 Task 백로그

이 문서는 하소AI 프로젝트의 개발 Task를 관리하는 백로그입니다. 큰 단위로 나눈 Task에 우선순위(P0=필수, P1=중요, P2=여유 있으면)를 표시했고, 주차별로 묶어뒀습니다. 진행하면서 체크박스를 채워나갑니다.

> **우선순위 기준**
> - **P0**: 이게 없으면 서비스가 아예 성립 안 함 (반드시 완료)
> - **P1**: 핵심 가치 제안에 포함된 기능 (가능하면 완료)
> - **P2**: 있으면 좋지만 없어도 데모/제출에 지장 없음 (시간 남으면)

## 진행 원칙

- 매주 시작할 때 이번 주 P0 항목부터 순서대로 처리한다.
- P0가 예상보다 오래 걸리면 P1/P2를 다음 주로 미루거나 백로그로 내린다 (기능을 억지로 다 넣지 않는다).
- Task를 완료하면 체크박스만 채우고, 새로 발견된 할 일은 해당 주차 또는 백로그에 바로 추가한다.
