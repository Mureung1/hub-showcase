# 핵심 기능 사용자 흐름 영상 컷

서비스의 주요 기능을 사용자 행동 순서에 따라 설명하는 1920×1080 정지 이미지다.

## 결과물

- Figma: [03 · Core User Flow](https://www.figma.com/design/D2Zlcjyy5ThP80AU0YqVAx?node-id=30-20)
- PNG: `outputs/video-assets/03-core-user-flow.png`

## 사용자 흐름

1. 냉장고 관리: 재료·수량·보관 위치와 소비기한 관리
2. 조건 선택: 식사 상황과 소비기한 우선 조건 선택
3. AI 메뉴 추천: Gemini 생성 결과를 Zod와 서버 정책으로 검증
4. 레시피 확인: 재료, 대체안, 조리 순서, 영양·안전 정보 확인
5. 요리 완료: 사용한 재료를 차감하고 다음 추천에 최신 재고 반영

## 영상 적용

PNG를 7~12초 배치하고, 자막이나 강조 요소를 1번부터 5번까지 순서대로 노출한다. 웹 동작 녹화 전 전체 기능을 예고하는 장면으로 사용한다.
