# 문제 정의 / 해결 방안 영상 컷

프로젝트 소개 영상의 두 번째 장면으로 사용하는 16:9 정지 이미지다. 한 화면에서 문제와 해결 방향을 비교할 수 있도록 좌우 2단 구조로 구성했다.

## 결과물

- Figma 프레임: [02 · Problem & Solution](https://www.figma.com/design/D2Zlcjyy5ThP80AU0YqVAx?node-id=12-2)
- 최종 영상: [`n091-park-changhyun-project-introduction.mp4`](../../project-introduction-video/n091-park-changhyun-project-introduction.mp4)
- 해상도: 1920×1080
- 비율: 16:9

## 구성

- 왼쪽 `PROBLEM`: 문제 정의 항목 3개
- 가운데 화살표: 문제에서 해결로 이어지는 흐름
- 오른쪽 `SOLUTION`: 해결 방안 항목 3개
- 각 항목의 본문은 비워 두었다.
- 여섯 항목은 `Video Narrative Item / Empty Body` 공통 컴포넌트의 인스턴스다.

## 편집 방법

Figma에서 수정할 카드를 선택한 뒤 오른쪽 패널의 `Body` 속성에 문구를 입력한다. `Index` 속성으로 항목 번호도 변경할 수 있다.

본문은 한 카드당 핵심 문장 한 줄 또는 최대 두 줄을 권장한다. 문제와 해결을 같은 번호끼리 대응시키면 영상에서 별도 애니메이션 없이도 흐름을 이해하기 쉽다.

## CapCut 적용

- PNG 한 장을 5~8초 길이로 배치한다.
- 화면 전환은 기본 디졸브 또는 페이드 하나만 사용한다.
- 자막은 카드 내용을 반복하기보다 장면의 핵심 결론을 한 문장으로 요약한다.
- 필요하면 CapCut의 간단한 키프레임으로 화면을 `PROBLEM`에서 `SOLUTION` 방향으로 천천히 이동한다.
