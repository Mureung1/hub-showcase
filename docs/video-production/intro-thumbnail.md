# 영상 도입 썸네일

프로젝트 소개 영상의 첫 번째 도입 요소다. 프레젠테이션 표지처럼 프로젝트명과 영상에서 다룰 내용을 짧게 전달하며, CapCut에서 영상 시작 화면 또는 대표 썸네일로 사용한다.

## Figma

- 파일: [오늘의 냉장고 | 영상 도입 썸네일](https://www.figma.com/design/D2Zlcjyy5ThP80AU0YqVAx?node-id=2-18)
- 프레임: `01 · Intro Thumbnail · 1920×1080`
- 비율: 16:9
- 해상도: 1920×1080

## 화면 문구

- 상단 라벨: `AI AGENT CHALLENGE · PROJECT FILM`
- 제목: `오늘의 냉장고`
- 가치 문장: `냉장고 속 재료에서 오늘의 식탁까지`
- 부제목: `사용자 경험부터 AI 기술 흐름, 개발 워크플로까지`

## 디자인 기준

저장소의 `DESIGN_SKILL.md`를 기준으로 다음 규칙을 적용했다.

- 배경은 크림색 `#FFF7F1`을 사용한다.
- 핵심 비주얼은 Primary Green `#006D36`을 사용한다.
- 강조 요소는 Secondary Orange `#FF7E47`을 사용한다.
- 영문은 Plus Jakarta Sans, 한글은 폰트 스택의 폴백 역할로 Noto Sans KR을 사용한다.
- 카드 모서리는 20~40px 범위로 둥글게 처리한다.
- 그림자는 강하게 띄우지 않고 따뜻한 갈색 계열의 낮은 투명도로 사용한다.
- 음식 사진 대신 서비스의 재료 관리·메뉴 추천 구조를 추상화한 대시보드 카드를 사용한다.

## 영상 적용

- 권장 노출 시간: 3~5초
- 시작: 0.3초 페이드인
- 제목과 부제목은 동시에 보여주되, 편집 시 상단 라벨 → 제목 → 부제목 순서로 가볍게 등장시킬 수 있다.
- 다음 장면은 완성된 웹사이트 화면으로 연결한다.
