# Agent Workflow 영상 컷

`AI Agent Development Workflow` 포스터의 Agent Workflow 영역을 가로형 영상 화면으로 재구성한 1920×1080 정지 이미지다.

## 결과물

- Figma: [05 · Agent Workflow](https://www.figma.com/design/D2Zlcjyy5ThP80AU0YqVAx?node-id=39-20)
- PNG: `outputs/video-assets/05-agent-workflow.png`
- 참고 포스터: `outputs/poster-assets/ai-agent-workflow-poster-a3.png`

## 역할

- USER: 목표 설정, 실행 확인, 오류 공유, 최종 판단
- CODEX: 요구 분석, 계획, 구현, 원인 분석, 수정과 검증 지원

## 반복 흐름

`PLAN → BUILD → RUN → CHECK → FIX → VERIFY`

한 번에 완성하는 대신 실제 화면과 API 결과를 확인하고, 오류나 개선 요청이 생기면 다시 계획과 구현 단계로 돌아간다.

## 영상 적용

전체 컷을 8~12초 배치하고 다음 순서로 설명한다.

1. 사용자와 Codex의 역할 구분
2. 여섯 단계 실행 루프
3. 실패와 개선 요청이 다시 계획으로 연결되는 Feedback Loop
