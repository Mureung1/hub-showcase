# CapCut 슬라이드 + TTS 영상 제작 방법

## 권장 타임라인

다음 순서로 미디어를 배치한다.

`01 썸네일 → 02 문제/해결 → 03 핵심 기능 → 기능 시연 → 04 데이터 흐름 → 05 Agent Workflow`

프로젝트 설정은 16:9, 1920×1080, 30fps를 권장한다.

## 1. 미디어 가져오기

1. `outputs/video-assets/`의 5개 PNG와 기능 시연 영상을 CapCut으로 가져온다.
2. PNG와 시연 영상을 위의 순서대로 메인 타임라인에 배치한다.
3. 장면 사이에는 0.2~0.4초 길이의 디졸브 또는 페이드 한 종류만 사용한다.

## 2. TTS 생성

컷 하나의 대본을 한 번에 붙이지 말고, 문장이나 화면 동작 단위로 나눈다.

1. `텍스트`에서 텍스트 레이어를 추가한다.
2. 해당 컷의 대본 한 구간을 입력한다.
3. 텍스트 레이어를 선택하고 `텍스트 음성 변환`을 연다.
4. 한국어 음성 한 종류를 선택해 모든 컷에 동일하게 적용한다.
5. 음성을 생성하고 해당 PNG 또는 시연 화면 아래의 오디오 트랙에 배치한다.
6. 생성된 음성 길이에 맞춰 PNG의 표시 시간을 조절한다.

권장 설정:

- 말하기 속도: 기본값 또는 0.95~1.0배
- 음량: 모든 TTS 클립을 동일하게 유지
- 음성 스타일: 감정 표현이 강하지 않은 차분한 설명형
- 컷 종료 여백: 음성이 끝난 뒤 0.3~0.5초

TTS는 클라우드 처리를 사용하므로 생성 중에는 안정적인 인터넷 연결이 필요하다.

## 3. 기능 시연과 음성 맞추기

기능 시연은 `DEMO-01`부터 `DEMO-06`까지 각각 별도 음성으로 생성한다.

1. 화면 동작을 먼저 배치한다.
2. 해당 동작의 TTS를 아래 오디오 트랙에 놓는다.
3. 클릭은 음성보다 약 0.5초 먼저 실행한다.
4. 음성이 길면 화면을 억지로 늘리지 말고 문장을 짧게 수정한다.
5. 로딩 대기와 불필요한 마우스 이동은 잘라낸다.

## 4. 자막 생성

TTS 오디오 배치가 끝난 뒤 자동 자막을 생성한다.

1. `캡션`에서 자동 캡션을 선택한다.
2. 언어를 한국어로 설정하고 TTS 오디오를 기준으로 생성한다.
3. 다음 기술 용어를 직접 확인해 수정한다.

`React`, `Express`, `Supabase`, `Gemini`, `Zod`, `Codex`, `PLAN`, `BUILD`, `RUN`, `CHECK`, `FIX`, `VERIFY`

자막은 화면 하단 중앙에 두고 최대 두 줄까지만 사용한다.

## 5. 배경음악과 음량

- TTS를 기준 음량으로 두고 배경음악은 충분히 작게 설정한다.
- 설명이 시작될 때와 끝날 때 배경음악에 짧은 페이드 인·아웃을 적용한다.
- 음성 구간마다 음악 크기를 다르게 조절하기보다 전체에서 일정하게 유지한다.

## 6. 최종 확인과 출력

1. 전체 길이가 5분을 넘지 않는지 확인한다.
2. TTS가 끝나기 전에 화면이 전환되지 않는지 확인한다.
3. 자막의 기술 용어와 띄어쓰기를 확인한다.
4. 음성이 갑자기 커지거나 작아지는 구간이 없는지 확인한다.
5. 1920×1080, 30fps로 출력한다.

5분을 초과하면 다음 순서로 줄인다.

1. 기능 시연의 로딩 및 입력 대기 시간
2. 컷 사이 정지 구간
3. 반복되는 시연 설명
4. 데이터 흐름과 Agent Workflow의 세부 문장
