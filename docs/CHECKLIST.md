## 2.5단계 — 하이브리드 생성

> T25는 T7의 목 텍스트 UI 골격이 아니라 T26의 실제 템플릿 경로 선행 조건이다. T7은 목 텍스트로 완료할 수 있고, T26 전에는 T25 작성·검수가 끝나야 한다 — PLAN.md 주차 매핑 참고.

- [ ] **T25. 상황 카드 템플릿 72개 작성·전수 검수** — 의존: 코드 없음(SPEC 1·4장). 현재 컴포넌트의 72문구는 초안. 먼저 RESEARCH_REVIEW의 관계 지위·친밀도·화행 부담 기준으로 COMPETITIVE_VALIDATION C1~C4 대표 12문구를 source preflight하고 관계·톤·사실 hard gate를 전부 통과시킨다. 이후 72문구의 관계·모드·사실·강압·완결성 hard fail 0건, 복합 관계 양쪽 호환 72/72, 톤 블라인드 정렬 24/24, 그대로 전송 가능 58/72 이상, 자리 표시자만 채우면 전송 가능 72/72를 기록한다. 정상적인 직접 요청이 아니라 **상대 선택권을 제거하는 강압적 요청**만 hard fail이다. 모드 공유나 기준 미달 시 임의로 스키마·문구 수를 늘리지 않고 카드·taxonomy 변경을 별도 제안·승인하며 모델·사용자 비교를 열지 않는다
- [ ] **T26. 생성 경로 라우터 + 템플릿 엔진** — 의존: T3, T8, T25. SPEC 2장 라우팅 규칙(`situationId` 있음→템플릿 / 없음→AI) + 응답 `source` 필드. 템플릿 결과의 "내 상황에 더 맞추기"는 S2-b 입력으로 이동하고, 입력·제출 전에는 AI를 자동 호출하지 않음. 템플릿 경로는 API 호출 없이 즉시 응답 — T25의 실제 72개 콘텐츠가 완성돼야 목 텍스트에서 전환 가능
