# AI-Challenge: 취업비서 프로젝트 기획서

## 📌 프로젝트 개요

### 배경 & 문제정의
- 채용공고 검색의 어려움 & 귀찮음
- 정보 양극화 심각

### 핵심 목적
- **시간절약** + **개인화 지원**

### 타겟 사용자
- 신입 취준생

---

## 🎯 핵심 기능

### 1. 공고 추천 (Job Recommendation)

**입력 정보**
- 기본정보: 학교, 전공, 학점
- 기술스택: 사용 가능한 언어/프레임워크
- 선호조건: 회사규모, 근무지역, 급여, 기업문화 등

**구현방식**
- API 연동(사람인) → RAG → LLM 기반 분석

**출력**
- 적합도 점수 표시
- 추천이유 명확하게 제시

---

### 2. 자소서 작성 지원 (Resume/Cover Letter Support)

**지원 범위**
1. 초안 작성: AI가 자동으로 초안 생성
2. 첨삭: AI의 피드백 및 수정 제안
3. 기업별 맞춤 수정: 각 회사에 맞는 내용으로 커스터마이징

---

### 3. 면접 준비 (Interview Preparation)

**지원 범위**
1. 질문제시: 기업/직무별 예상 면접 질문 제공
2. 답변 아이디어 제공: 각 질문에 대한 답변 방향 제시
3. 답변 피드백(텍스트): 텍스트 기반 답변에 대한 피드백

---

### 4. 일정 관리 (Timeline Management)

**상태**: 부가 기능 (시간 있으면 추가)

**예상 기능**
- 공고 지원 현황 추적
- 면접 일정 관리
- 마감기한 알림

---

## 👥 사용자 흐름 (User Journey)

### 신입 취준생 "김준호"의 여정

1. **회원가입 & 프로필 설정**
   - 기본정보 입력: 학교, 전공, 학점
   - 기술스택 입력: 가능한 언어/프레임워크
   - 선호조건 입력: 회사규모, 지역, 급여 등

2. **맞춤 공고 추천받기**
   - AI가 프로필 분석
   - 적합도 높은 공고 5-10개 추천
   - 각 공고마다 "적합도 80%, 이유: Python 경험 + 스타트업 선호도 일치" 같은 설명 제시

3. **자소서 작성 지원**
   - 선택한 공고에 대해 "자소서 초안" 요청
   - AI가 초안 생성 → 사용자 수정 → AI 첨삭
   - 기업별로 내용 맞춤화

4. **면접 준비**
   - 해당 기업/직무의 예상 면접 질문 확인
   - 각 질문에 대해 답변 아이디어 획득
   - 텍스트 기반 피드백 받기

5. **일정 관리** (추후 추가)
   - 지원 현황, 면접 날짜 등 기록 및 알림

### 특징
- **프로필 업데이트**: 언제든 프로필 수정 가능 (새 기술스택 추가, 선호조건 변경 등)
- **다중 공고 동시 진행**: 사용자가 원하는 공고만 선택하여 자소서/면접준비 진행 가능

|------|------|------|

| **배포** | 미정 | AWS/GCP/Azure 중 검토 |

## ⚠️ 예상 리스크 & 고려사항

### 기술적 리스크

| 리스크 | 영향도 | 설명 |
|--------|--------|------|
| **API 연동** | 높음 | 사람인 API의 Rate Limit, 데이터 크기 제한 가능성 |
| **LLM 품질** | 높음 | Hugging Face 무료 API의 응답 품질 및 속도 불확실 |
| **RAG 구현** | 중간 | 예상보다 구현이 복잡할 수 있음 |
| **프론트-백엔드 연동** | 중간 | 통합 테스트에 예상보다 시간 소요 가능 |

### 데이터 관련

| 이슈 | 설명 |
|------|------|
| **공고 데이터 부족** | 사람인 API에서 충분한 공고 데이터를 제공하는지 확인 필요 |
| **학습 데이터 부족** | 기업별 면접 질문, 기업 정보 등의 학습 데이터 부족 가능 |

### 대응 전략

- 개발 중 마주치는 리스크는 **실시간으로 해결**
- Phase별 우선순위에 따라 **유연하게 일정 조정**
- 시간이 부족하면 Phase 4(일정관리)는 제외하고 Phase 1-3에 집중
