
## 🚨 문제 발생 시 확인 단계

### **1. 기술 미정 (불명확성)**
```
증상: "어떻게 구현할지 모름"
확인: CLAUDE.md, AGENTS.md에서 규칙 확인
해결: 없으면 사람이 결정 후 문서화
```

### **2. 작업 범위 불명확**
```
증상: "뭘 해야 할지 모름"
확인: checklist.md의 해당 주차 항목 재읽기
해결: 하나씩 분해해서 작업
```

### **3. 구현 오류**
```
증상: 코드 에러, 기능 미동작
확인: 설계 문서와 실제 코드 비교
해결: Claude가 해당 부분 재구현
```

### **4. 배포 실패**
```
증상: 배포 안 됨, 데이터 손실
확인: 배포 문서(PDF) + 환경 변수 확인
해결: 문서 기반으로 재설정
```

### **5. API 비용 초과**
```
증상: API 비용이 예상보다 높음
해결: Mock 데이터로 전환하거나 프롬프트 최적화
```
