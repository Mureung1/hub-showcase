# 자격증·스펙 취득 경로 플래너 — 기획서 (v1)


---

## 1. 문제 정의

**현상**: 대학생이 취업을 준비할 때, "어떤 자격증/스펙이 실제로 도움이 되는지" 판단할 근거가 마땅치 않다.

**구체적 사례**: 컴퓨터활용능력(컴활)은 취업 준비 커뮤니티나 추천 글에서 자주 언급되지만, 실제로 전산직에 취업한 사람들 사이에서는 "크게 필요하지 않았다"는 의견이 나온다. 즉 **커뮤니티에 떠도는 정보와 실제 채용 시장의 수요가 어긋나는 경우**가 흔하다.

**근본 원인**: 커뮤니티 글은 개인 경험담이라 표본이 작고, 오래된 정보가 계속 재생산되며, 작성자가 실제로 그 직무에 종사하는지 검증할 방법이 없다. 반면 실제 채용공고의 우대조건은 기업이 지금 이 순간 뭘 요구하는지 보여주는 훨씬 직접적인 신호지만, 자유 텍스트로 흩어져 있어 사람이 수백 개 공고를 일일이 읽고 취합하기 현실적으로 불가능하다.

**추가 문제**: 여러 자격증을 준비할 때, 선수조건이나 시험 일정이 서로 얽혀 있는데도 이를 고려한 순서 계획 없이 닥치는 대로 준비하게 되어 비효율이 발생한다.

**한 문장 정의**
> 실제 채용공고 데이터를 기반으로 목표 직무에 정말 필요한 자격증을 근거와 함께 걸러주고, 여러 자격증을 가장 효율적인 순서로 취득할 수 있도록 경로를 계산해주는 서비스.

---

## 2. 핵심 사용자 시나리오

**페르소나**: 본인 — 반도체 관련 직무(SK/삼성 광주전남 투자 관련) 취업을 목표로 스펙을 준비 중인 학생 개발자

**흐름**

1. 목표 직무(예: "반도체 품질관리" 또는 "전산직")를 입력한다.
2. 시스템이 워크넷·사람인 공식 API에서 해당 직무 관련 채용공고를 수집한다.
3. 공고들의 `우대조건`/`자격요건` 텍스트를 분석해서, 어떤 자격증이 얼마나 자주, 얼마나 강하게(필수 vs 우대) 언급되는지 정리된 리스트로 보여준다. 예: "산업안전기사 78% 언급, 컴활 12% 언급".
4. 커뮤니티에서 추천받았던 자격증(컴활)이 실제로는 이 직무에서 언급 빈도가 낮다는 걸 확인하고, 대신 상위에 뜬 자격증으로 계획을 조정한다.
5. 선택한 자격증들의 선수조건과 응시 일정을 반영한 최적 취득 순서를 그래프/타임라인으로 확인한다.
6. 졸업 전까지 남은 학기에 맞춰 "이번 학기엔 A, 다음 학기엔 B" 식의 구체적 계획을 받는다.

**핵심 가치**: 카더라 정보 대신 실제 수요 데이터 기반 의사결정 + 여러 스펙을 준비할 때의 순서 최적화.

## 3. 핵심 기능 (3개, 깊이 우선)

### 기능 1. 채용공고 기반 자격증 수요 분석

**무엇을 하는가**: 목표 직무의 실제 채용공고를 수집해, 자유 텍스트로 적힌 우대조건에서 자격증/스킬을 추출하고 언급 빈도·강조도를 집계한다.

**왜 핵심인가**: 이 프로젝트의 존재 이유 자체다. 커뮤니티 카더라와 실제 수요의 간극을 메우는 게 목적이므로, 이 기능 없이는 나머지가 무의미하다.

**동작 방식**: 워크넷/사람인 공식 API로 공고 수집 → 텍스트에서 자격증/스킬 명 추출 후 표준 명칭으로 정규화(표현이 제각각이라 정규화 자체가 판단 작업) → "필수"/"우대"/"있으면 좋음" 언어 강도를 문맥으로 분류 → 직무별 집계.

### 기능 2. 자격증 취득 경로 최적화

**무엇을 하는가**: 확정된 목표 자격증들의 선수조건, 응시 일정, 본인의 남은 학기를 그래프로 모델링해 최단·최적 취득 순서를 계산한다.

**왜 핵심인가**: 자격증을 뭘 딸지 알아도, 순서를 잘못 짜면 시간을 낭비하거나 일정이 꼬인다. "무엇을"과 "어떤 순서로"는 별개의 문제다.

**동작 방식**: 자격증 간 의존관계(선수조건)를 그래프로 구성 → 응시 가능 시기 제약을 반영한 일정 최적화 → 결과를 타임라인으로 시각화.

### 기능 3. 개인 진행 상황 대시보드

**무엇을 하는가**: 계획한 경로 대비 현재 진행 상황(취득 완료/준비 중/예정)을 추적하고 시각화한다.

**왜 핵심인가**: 계획은 세웠지만 실행이 안 되면 무용지물이다. 진행 상황을 눈에 보이게 해서 계획이 실제 행동으로 이어지게 한다.

**동작 방식**: 사용자가 진행 상태를 갱신하면 대시보드에 반영, 다가오는 시험 일정 기준 임박도 표시.
