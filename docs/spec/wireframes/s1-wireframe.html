S1 사용자 흐름을 완주시키는 최소 화면 3종. 저채도 로우파이 스케치로, 각 요소를 핵심 기능 F1~F4에 매핑했다. (레이아웃 검토용 — 실제 색·타이포는 다음 단계)

F1 브리핑 피드 F2 카드 요약 F3 한국어 요약 열람 F4 북마크 저장

화면 주석

①피드 — 날짜 헤더·“오늘 N편 수집”·카테고리 탭(F1) 아래로, 중요도순 카드 목록. 카드마다 중요도 배지·주제 태그·제목(영·한)·한줄 요약·🔖 저장(F2).
②상세 — 카드 클릭 시 진입. 구조화 요약(핵심 기여/방법/결과)+배경 설명, 원문 초록 토글, arXiv 원문 링크, 🔖 저장(F3·F4).
③저장 목록 — 북마크한 논문 모음. 카드를 눌러 다시 상세로 이동(F4).
↺반복 — 상세/저장에서 ← 뒤로가기로 피드 스캔을 이어가며 “다음 논문”을 확인(사용자 흐름 4→9).
