## 이번 주 전략 — "후속개선 이틀에 끊고, 배포로 넘어간다"

Phase 3 코어가 예정(7/23)보다 앞서 끝났다(7/20). 마감(7/31) 전 최대 리스크는 **배포(Phase 4)**다. 그래서 사용자가 지목한 후속개선 2건을 **월·화에 짧게** 끝내고, **수요일부터 배포에 진입**해 마감 전 버퍼를 확보한다.

1. **월·화 — 후속개선(데모 완성도 직결)**: 문자용/SNS용 문구 분리, 쿠폰 할인율 편집. 둘 다 스코프가 작고 데모에서 바로 보인다.
2. **수·목 — 배포**: FE(Vercel)·BE(Render/Railway) + 환경변수·CORS. **배포 URL에서 전 플로우 재현**이 목표.
3. **금 — 검증**: 테스트 스위트 초록불 + 법적 체크리스트 대조. 여유가 남으면 3-7 Instagram 시도(버림 1순위이므로 안 되면 버린다).

> **테스트 관련 사실**: 단위테스트는 이미 상당수 존재(`grid`·`weather`·`ensemble`·`guardrails`·`generate`·`diagnose`·`daily`·`legal/filter`·`solapi`·`coupons/tracking`·`csv`). 4-4는 "처음부터"가 아니라 **초록불 확인 + 빈 곳(campaigns 라우트·redeem 경계) 보강**이다.

- [ ] Solapi 발송이 문자용(이모지 없는) 문구 사용
- [ ] 이모지 포함 문구가 문자 경로에서 제거됨을 단위테스트로 보장
