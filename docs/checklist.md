# One-Step 개발 체크리스트

## 1주차 — 프로젝트 기반 및 핵심 화면

- [ ] 프로젝트 저장소 및 브랜치 전략 설정
- [ ] Flutter 프로젝트 초기 구성
- [ ] Firebase 프로젝트 연동
- [ ] 공통 테마, 색상, 폰트 설정
- [ ] 하단 내비게이션 구성
- [ ] 홈/캐릭터 화면 기본 레이아웃
- [ ] 퀘스트 목록 화면 기본 레이아웃
- [ ] 퀘스트 등록 화면 구성
- [ ] 사용자·퀘스트 데이터 모델 정의
- [ ] Firestore 컬렉션 구조 정의

## 2주차 — AI 도전 분해 엔진

- [ ] 큰 목표 입력 컴포넌트
- [ ] AI 분해 요청 버튼 및 로딩 상태
- [ ] LLM 프롬프트 초안 작성
- [ ] 마이크로 퀘스트 JSON 스키마 정의
- [ ] AI 응답 파싱 및 예외 처리
- [ ] 분해 결과 목록 컴포넌트
- [ ] 퀘스트 제목 수정 기능
- [ ] 퀘스트 삭제 기능
- [ ] 개별 또는 전체 재생성 기능
- [ ] 난이도 수동 변경 기능
- [ ] 분해 결과 일괄 등록 기능
- [ ] AI 응답 실패 시 템플릿 폴백
- [ ] 잘못된 응답 및 지연 상황 테스트

## 3주차 — 퀘스트 실행 및 보상 루프

- [ ] 오늘의 퀘스트 목록 조회
- [ ] 직접 퀘스트 등록 기능
- [ ] 난이도 뱃지 표시
- [ ] 예상 코인·XP 표시
- [ ] 퀘스트 완료 체크 기능
- [ ] 완료 확인 화면
- [ ] 난이도별 보상 계산 로직
- [ ] Firestore 트랜잭션 기반 코인·XP 지급
- [ ] 완료 상태 저장
- [ ] 사진 첨부 기능
- [ ] 메모 작성 기능
- [ ] 인증 첨부 시 보너스 보상 지급
- [ ] 성취 기록 저장
- [ ] 중복 완료 방지 처리
- [ ] 출석/스트릭 체크 및 연속 출석 보너스(7일) 지급
- [ ] 하루 코인 획득 상한 처리
- [ ] 동일·유사 퀘스트 반복 보상 점감(diminishing) 처리

## 4주차 — 캐릭터 성장 및 통합 검증

- [ ] 현재 레벨 및 XP 표시
- [ ] 경험치 프로그레스 바
- [ ] 캐릭터 기본 렌더링
- [ ] 레벨업 처리
- [ ] 진화 단계 변경 처리
- [ ] 코인 잔액 표시
- [ ] 상점 화면 기본 레이아웃(최소 치장 아이템 1종)
- [ ] 코인으로 치장 아이템 구매 및 적용
- [ ] 퀘스트 완료 연출
- [ ] 보상 획득 연출
- [ ] 멈춘 퀘스트 재분해 기능
- [ ] 전체 사용자 흐름 통합 테스트
- [ ] AI 분해 결과 품질 테스트
- [ ] 도전 시작률 이벤트 로그 정의
- [ ] 재분해 복귀율 이벤트 로그 정의
- [ ] 7일 리텐션 측정 항목 정의
- [ ] 오류 메시지 및 빈 화면 처리
- [ ] 최종 QA 및 버그 수정
- [ ] 데모 시나리오 작성
- [ ] 발표용 테스트 데이터 준비

## 완료 기준

- [ ] 사용자가 큰 목표를 입력하면 AI가 마이크로 퀘스트와 난이도를 생성한다.
- [ ] 사용자가 분해 결과를 수정·삭제·재생성할 수 있다.
- [ ] 확정한 결과가 퀘스트 목록에 정상 등록된다.
- [ ] 퀘스트 완료 시 난이도에 맞는 코인과 XP가 지급된다.
- [ ] 완료 결과가 캐릭터 성장에 반영된다.
- [ ] AI 실패 시에도 템플릿으로 퀘스트를 등록할 수 있다.
- [ ] 사용자가 막힌 퀘스트를 더 작게 재분해해 다시 실행할 수 있다.
