# CareerSignal 작업 체크리스트

이 문서는 완료된 정적 프로토타입 기록과 실제 제품 MVP 백로그를 분리합니다.

## 1. 정적 프로토타입 완료 기록

- [x] HTML/CSS 기반 관심 직무 선택, 분석 보고서, 학습 로드맵 3페이지 구현
- [x] 공통 상단바와 단계별 페이지 이동 구성
- [x] 가운데 정렬된 본문과 보고서·로드맵 오른쪽 글래스 목차 구성
- [x] 데스크톱 90% 표시 밀도와 반응형 단일 열 레이아웃 적용
- [x] 24건 mock 리서치 표기, 5개 지표 카드, 구현 범위 조합 카드 구성
- [x] 필수 요구사항·우대사항·기업군별 강조점·4단계 로드맵 정보 구조 구성
- [x] JavaScript 없이 정적 화면임을 범위에 반영
- [x] [Vercel 데모](https://careersignal-prototype.vercel.app/) 배포
- [x] Chrome 100% 기준 보고서 가독성과 본문·목차 정렬 확인

## 2. 정적 프로토타입 제외 범위

- [x] 사용자 입력에 따른 동적 직무 변경
- [x] mock data 조회와 빈도 집계
- [x] 분석 중·성공·오류·빈 결과 상태 처리
- [x] Verifier 검증 문구와 결과 검증
- [x] 실제 채용공고 수집, AI 분석, 로그인, DB 저장

위 항목은 프로토타입에서 의도적으로 구현하지 않았으며, 실제 제품 백로그에서 다룹니다.

## 3. 실제 제품 MVP 백로그

### 3.1 React UI

- [ ] 관심 직무 입력과 예시 직무 선택을 실제 상태로 연결한다.
- [ ] 입력, 분석 중, 완료, 지원하지 않는 직무, 오류 상태를 설계한다.
- [ ] 분석 결과를 보고서와 로드맵 화면에 렌더링한다.
- [ ] 정적 프로토타입의 정보 구조와 디자인 토큰을 React UI에 반영한다.

### 3.2 샘플 공고와 분석 규칙

- [ ] 직무별 샘플 공고 데이터 구조를 정의한다.
- [ ] 기술, 필수 요구사항, 우대사항, 업무 조건, 기업군 태그를 집계한다.
- [ ] 기술 빈도뿐 아니라 반복되는 구현 범위 조합을 계산한다.
- [ ] 필수 요구사항을 우대사항보다 먼저 반영하는 로드맵 규칙을 정의한다.
- [ ] 분석 결과가 입력 직무와 집계 데이터에 맞는지 검증하는 Verifier 규칙을 정의한다.

### 3.3 Express API

- [ ] `server/`에 분석 요청을 받을 Express API를 구현한다.
- [ ] React UI와 분석 로직의 책임을 분리한다.
- [ ] 분석 결과 응답 형식과 오류 응답을 정의한다.

### 3.4 후속 확장

- [ ] 실제 채용공고 수집과 갱신
- [ ] LLM 기반 요구사항 추출과 해설 생성
- [ ] 사용자 계정, 분석 결과, 로드맵 저장
- [ ] 사용자 역량 입력과 Gap 분석
- [ ] 여러 직무 비교와 기업군별 지원 전략 개인화

## 4. MVP 검증 시나리오

- [ ] 프론트엔드 개발자 입력 시 해당 직무의 공고 수, 구현 범위 조합, 필수·우대사항, 로드맵이 표시된다.
- [ ] 예시 직무를 누르면 입력값과 분석 결과가 함께 갱신된다.
- [ ] 지원하지 않는 직무는 대체 안내와 다음 행동을 제공한다.
- [ ] 로딩·오류·빈 결과 상태가 화면 흐름을 방해하지 않는다.
- [ ] 결과의 기술·요구사항·로드맵 항목이 입력 직무의 집계 데이터와 연결된다.
