# 아맞다 MVP 작업 체크리스트

## 문서 역할

이 문서는 아맞다 MVP 구현을 위한 작업 분해 체크리스트다. `docs/plan.md`의 확정 기능을 기준으로, AI에게 맡길 수 있는 단위의 작업으로 나누는 것을 목표로 한다.

각 항목은 개발 중 재정렬될 수 있다. 주차별 일정표가 아니라 기능과 우선순위 중심의 작업 목록이다.

## 우선순위 기준

- **P0:** MVP 핵심 경험에 반드시 필요하다.
- **P1:** 데모 완성도와 사용자 경험을 높인다.
- **P2:** 가능하면 포함하되, 없어도 핵심 경험은 유지된다.
- **확인 필요:** 멘토 확인이나 기술 검토 후 포함 여부를 결정한다.
