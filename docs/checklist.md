# 작업 체크리스트 (`docs/checklist.md`)

기획서(`docs/plan.md`)의 화면·기능·시나리오에서만 작업 단위를 도출했습니다.

> **2026-07-13 갱신**: 리더뷰 단어 인터랙션 제거 → 문장 단위 아코디언 번역으로 대체, 단어장 화면 신규 추가, 마이페이지에 AI 심리 비교 추가.

## 화면 구성 (기획서 6번 시나리오·7번 플로우차트 기준)

1. **메인 대시보드** — 오늘의 핵심 외신 3개 노출
2. **기사 상세 (리더뷰)** — 원문 파싱·렌더링 + 문장 단위 인라인 번역(아코디언) + AI 요약 + AI 인사이트 패널 + 투자 판단 버튼
3. **마이페이지** — 투자 판단 히스토리(나의 판단 vs AI 심리 비교), 클릭 시 상세뷰(요약+판단+심리)가 항상 먼저 노출, 원문은 부차 버튼으로만 연결
4. **단어장 (신규)** — AI가 자동 선별한 핵심 용어 최신순 목록, 출처(기사) 링크

---

## 화면 1. 메인 대시보드

- [ ] 오늘의 핵심 외신 3개 노출 영역
- [ ] 외신 카드 (로고 + 영문 제목 + 한 줄 번역)
- [ ] 카드 클릭 → 기사 상세(리더뷰) 이동

## 화면 2. 기사 상세 (리더뷰)

### 기능 ① 원문 리더뷰 + 문장 단위 인라인 번역 (최우선순위)

- [ ] 불필요한 요소 제거된 리더뷰 형태 원문 렌더링
- [ ] 원문 실시간 파싱
- [ ] LLM이 선별한 어려운 문장에 탭 가능 표시 (하이라이트 없이 단순 구분만, 또는 옅은 밑줄 정도)
- [ ] 문장 탭 시 **팝업이 아닌 아코디언**으로 문장 바로 아래 한글 번역 노출
- [ ] 아코디언이 원문 문장을 가리지 않고 자연스럽게 펼쳐짐, 재탭 시 접힘

> 실무 참고: "원문 실시간 파싱"은 프론트가 브라우저에서 외신을 직접 긁으면 CORS에 막히므로, [백엔드] URL을 받아 텍스트만 파싱해 반환하는 API와 [프론트] 로딩 스켈레톤 노출 + 파싱 결과 렌더링으로 나누어 작업. 상세 Task는 `docs/backlog.md` 참고.

> ⚠️ 단어 하이라이트/툴팁 UI는 이번 개편으로 리더뷰에서 완전히 제거됨 (화면 4. 단어장으로 이전).

### 기능 ② AI 문단 요약 + 종목 영향 한 줄 해설

- [ ] 문단 요약 버튼
- [ ] 문단별 3줄 불릿 요약 표시
- [ ] 기사 하단 'AI 인사이트 패널'
- [ ] "이 기사가 주가에 미치는 영향" AI 한 줄 브리핑

### 기능 ③ 완독 후 투자심리 인터랙션 + AI 심리 비교

- [ ] [매수 📈] / [관망 ➖] / [매도 📉] 버튼
- [ ] 버튼 클릭 시 `기사 URL` · `AI 요약본` · `나의 선택` · `marketSentiment` 서버 저장
- [ ] "오늘의 모의 투자 판단 완료!" 토스트 팝업
- [ ] 판단 없이 뒤로 가기/이탈 시에도 "읽기 완료"로만 처리 (판단은 미기록)

## 화면 3. 마이페이지

- [ ] 투자 판단 히스토리 등록/조회
- [ ] 나의 판단(매수/관망/매도)과 AI가 분석한 `marketSentiment`(호재/악재/중립)를 나란히 비교 표시
- [ ] 히스토리 항목 클릭 시, 저장된 요약본·나의 판단·`marketSentiment`를 보여주는 상세 화면(모달/뷰)이 항상 먼저 노출 (링크 만료 여부와 무관하게 동일 동작)
- [ ] 상세 화면 하단에 `[원문 기사 보러가기 ↗]` 버튼 — 만료 여부는 서버가 판단하지 않고, 클릭 시 브라우저가 자연스럽게 처리

## 화면 4. 단어장 (신규)

- [ ] 기사 분석 시 AI가 선별한 핵심 용어 3~5개가 사용자 액션 없이 자동 적재되는지 확인
- [ ] 단어 목록 최신순(시간 역순) 정렬
- [ ] 각 단어에 출처(기사 제목) 표기, 클릭 시 해당 기사(리더뷰)로 이동

## 화면 흐름 (기획서 7번 Mermaid 플로우차트 기준)

```
대시보드 진입 → 오늘의 핵심 외신 3개 노출 → 관심 기사 클릭
  → 리더뷰 진입 (원문 실시간 파싱 렌더링)
  → (분석 시점에 핵심 용어 3~5개 자동으로 단어장에 적재 — 리더뷰와 무관하게 백그라운드로 진행)
  → [해석 막히는 문장 발견?] 문장 탭 → 아코디언으로 번역 노출 → 독해 재개
                            넘어가기 → 독해 재개
  → [문단 요약 필요?] 버튼 클릭 → 3줄 요약 확인 → 스크롤
                      스스로 해석 → 스크롤
  → AI 인사이트 패널(종목 영향 한줄 해설 + marketSentiment) 확인
  → [나의 모의 투자 판단] 매수/관망/매도 클릭 (또는 판단 없이 이탈 → 읽기 완료만 인정)
  → 서버 전송 → 데이터 저장(URL+AI요약+내 판단+marketSentiment) → 완료 토스트
  → 마이페이지 히스토리 등록 (나의 판단 vs marketSentiment 비교 가능)
  → (재방문 시) 히스토리 클릭 → 요약+판단+marketSentiment 상세뷰 항상 노출 → [원문 보러가기] 버튼은 부차 옵션 (만료 시 브라우저가 자연스럽게 404 처리, 서버 판단 불필요)
  → (별도 시점) 단어장 화면에서 누적된 핵심 용어 복습, 출처 클릭 시 원문 기사로 복귀
```
