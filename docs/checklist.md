# 작업 분해 — 대학생 투자자를 위한 근거 검증 Agent

`plan.md`의 화면 흐름·핵심 기능을 작업 단위로 쪼갠 목록. 덩어리를 잘게 쪼갤수록 AI에게 맡기기도, 직접 검증하기도 쉬워진다.

## 1주차 — 기능 A: 종목 공부

- [ ] PostgreSQL 스키마 설계 (종목, 공시, 재무지표 테이블)
- [ ] OpenDART API 연동 (공시 목록 조회)
- [ ] 최근 사업보고서/분기보고서 파싱
- [ ] 재무지표 계산 로직 (매출, 영업이익, 부채비율, 영업현금흐름)
- [ ] 홈 화면 (종목 검색창)
- [ ] 종목 리포트 화면 (기업개요 섹션)
- [ ] 종목 리포트 화면 (최근 공시 요약 섹션)
- [ ] 종목 리포트 화면 (재무지표 변화 섹션)
- [ ] 종목 리포트 화면 (확인 포인트 섹션)
- [ ] 전문용어 자동 설명 (PER, PBR 등 문맥 풀이)
- [ ] 공시 데이터 부족 종목 처리 (KOSPI·KOSDAQ 외 검색 시 안내, 공시 부족 시 "제한된 리포트" 문구)
- [ ] 종목 리포트에 데이터 기준일 표시

## 2주차 — 기능 B: 현재가·적정가 분석

- [ ] 현재가 조회 API 연동 또는 수동 입력 폼 설계
- [ ] 현재가 분석 로직 (현재가, 적정 예상가 범위, 괴리율 계산)
- [ ] 적정 예상가 산출 규칙 (PER/PBR/ROE/성장률/변동성 기반 가중치)
- [ ] 고평가/저평가/중립 판정 로직
- [ ] 매수 가능 구간 제안 로직 (관망, 분할매수, 보류)
- [ ] 현재가 분석 화면 (현재가, 적정 예상가, 괴리율, 매수 구간)
- [ ] 현재가 분석 화면에 데이터 기준일 표시
- [ ] 현재가 분석 결과와 종목 리포트 간 연결 버튼

## 3주차 — 기능 C: 근거 검증 (프로토타입)

- [ ] LangGraph 노드 설계 (Query Parser → Claim Extractor → Evidence Verifier)
- [ ] 매수 이유 입력 화면
- [ ] Claim Extractor: 근거 유형 추출 (실적/공시/뉴스/테마/감, 다중 유형 동시 추출 지원)
- [ ] Claim Extractor: 짧고 모호한 입력("그냥 감") 처리 → 근거 없음 즉시 판정 + 후속 질문 노출
- [ ] Evidence Verifier: 공시·재무 데이터 대조 로직 (1차 검색 → 확신도 산출)
- [ ] Evidence Verifier: 근거 부족 시 재검색 반복 루프 (쿼리 재구성, 최대 3회, 검색시도로그 기록)
- [ ] 근거 검증 결과 화면 (판정: 있음/부족/없음, 다중 근거 시 유형별 판정 구분 표시, 매수 가능 여부 표시)
- [ ] 근거 검증 결과 화면 (부족한 정보 + 위험 요소 표시)
- [ ] 근거 검증 결과 화면에 데이터 기준일 표시
- [ ] 매매 전 체크리스트 생성 로직
- [ ] 체크리스트 화면
- [ ] 매수 판단 화면 (관망/분할매수/보류)

## 4주차 — 통합 + 평가

- [ ] Chroma RAG 연동 (공시 원문 청크 검색, 근거 인용)
- [ ] 임시 기기 ID 발급/저장 로직 (로그인 없이 복기 로그 구분용, MVP 한정)
- [ ] 복기 로그 저장 로직 (기기 ID, 종목, 매매 이유, 판정, 시점)
- [ ] 복기 로그 목록 화면
- [ ] 평가 지표 스크립트: 숫자 일치율 (rule-based)
- [ ] 평가 지표 스크립트: 근거 타당성 점수 (LLM judge, 골든 샘플 10~20개)
- [ ] 환각 발생률 체크 스크립트
- [ ] 전체 파이프라인 통합 테스트 (홈 → 현재가 분석 → 리포트 → 검증 → 체크리스트 → 매수 판단 → 로그)

## 5주차 — 확장 + 배포

- [ ] 누적 복기 리포트 로직 (반복 판단 패턴 집계)
- [ ] 누적 복기 리포트 화면
- [ ] 프론트엔드-백엔드 연결 (FastAPI)
- [ ] 배포 (Railway 또는 Render)
- [ ] 데모용 시나리오 3~5개 준비
- [ ] 포트폴리오 문서화 (문제정의 → 검증 결과 요약)
