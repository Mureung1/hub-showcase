# SpendMate — 개발 체크리스트

4주 로드맵을 실행 가능한 작업 단위로 쪼갠 문서. 완료한 항목은 체크(`- [x]`)로 표시하며 진행한다.

---

## 1주차 — 입력 파이프라인 구축 + PoC

### 환경 설정
- [ ] Spring Boot 프로젝트 초기 설정 (Java, Gradle/Maven)
- [ ] React 프로젝트 초기 설정
- [ ] PostgreSQL 로컬/개발 DB 세팅
- [ ] Git 브랜치 전략 확정 (기능별 브랜치, PR 흐름)

### PoC (사전 검증 — 가장 먼저)
- [ ] 네이버 클로바 OCR API 신청 및 테스트 호출
- [ ] 업스테이지 Document AI와 인식률 비교 테스트 (실제 영수증 샘플, 감열지·손글씨 포함)
- [ ] OCR 최종 후보 결정
- [ ] 네이버 쇼핑 검색 API 신청 및 테스트 호출 — 구조화된 가격 데이터(숫자) 제공 여부 확인
- [ ] 공공데이터포털 레시피 API 신청 및 테스트 호출
- [ ] Claude API 키 발급, Tool Use 최소 예제(하드코딩 Context) 동작 확인

### 입력 파이프라인
- [ ] 영수증 업로드 UI (이미지 첨부 화면)
- [ ] 업로드 이미지 → OCR API 연동
- [ ] OCR 결과 텍스트 파싱 로직 (상호명/항목/금액/날짜 추출)
- [ ] DB 스키마 설계: 영수증 원본 메타데이터 테이블 / 파싱된 지출 내역 테이블 분리
- [ ] 파싱 결과 DB 저장 확인

- [ ] 수동 입력 데이터가 DB에 영수증 기반 지출과 동일하게 저장되는지 확인

## 3주차 — 예측 + Agent + Tool 연동

### 예측 & 생존 모드
- [ ] 생활비 소진 예측 로직 (이번 달 누적 일평균 + 고정비 결합)
- [ ] 예측 신뢰성 안내 문구 (이번 달 데이터 5일 미만 시 안내)
- [ ] 월말 생존 모드 UI (남은 돈 / 남은 기간 / 오늘 쓸 수 있는 금액)
- [ ] 예산 임계치 이하 시 생존 모드 자동 전환 로직

### Context 계산
- [ ] 단기 신호 계산 (배달비 증가율, 예산 대비 지출률)
- [ ] 장기 신호 계산 (반복구매 패턴, 카테고리 구성/추세, 구독 상태, 최대 90일)
- [ ] 장기 신호 데이터 품질 단계 분기 구현 (5일 미만 / 5~13일 / 14~89일 / 90일 이상)
- [ ] 단기+장기 신호를 하나의 Context 객체로 통합

### AI Agent
- [ ] 시스템 프롬프트 작성 (Goal + Context 설명 + Tool 목록 + 출력 형식 규칙)
- [ ] Claude API tool use 연동 (Spring AI 또는 WebClient 직접 호출 중 선택)
- [ ] Recipe Tool 함수 구현 및 연동 (공공데이터포털 레시피 API 호출)
- [ ] Smart Purchase Tool 함수 구현 및 연동 (네이버 쇼핑 API 호출)
- [ ] Tool 미실행("개입 안 함") 시에도 안내 메시지가 함께 나오는지 확인
- [ ] Reasoning Summary(선택 이유) 생성 확인 — 실제 Context 값을 인용하는지 검증
- [ ] Tool 결과를 Agent가 사용자 친화적 메시지로 정리하는 2차 호출 구현
- [ ] 동일 Context 5~10회 반복 실행 → 판단 일관성 확인 (temperature 낮게 설정)
- [ ] "일부 신호는 같지만 전체 Context가 다른" 케이스로 실제 판단이 달라지는지 검증
