# CalMe 4주 작업 분해 (MVP)

## 프로젝트 개요

### MVP 범위

텍스트 또는 PDF 공지 입력 → AI 분석 → 결과 확인 및 수정 → 일정 등록 → 캘린더와 대시보드에서 확인

> 이미지와 URL 입력은 이번 MVP에서 구현하지 않으며, 향후 확장 기능으로 기획 및 구조만 설계합니다.

# 3주 차 : Mock 기반 분석 · 일정 등록

> **개발 전략**: Claude API는 4주차에 연결하고, 3주차에는 Mock 데이터로 전체 기능 흐름을 완성합니다. 
> 이를 통해 API 비용을 절감하고 안정적으로 개발할 수 있으며, 4주차에 Mock을 Claude API로 교체만 하면 됩니다.

## 월요일 - Mock 분석 엔진 및 데이터 구조 설계

### Mock 데이터 스키마 정의
- 분석 결과의 JSON 형식 정의 (Claude API와 동일한 구조)
  - 공지 제목
  - AI 요약
  - 일정 목록 (배열)
  - 각 일정: 일정명, 시작일, 종료일, 마감일, 장소, 제출물, 메모
- 날짜 형식 통일 (YYYY-MM-DD 형식)

### Mock 분석 API 구현
- 텍스트 공지용 Mock 데이터 (정상 케이스)
- PDF 공지용 Mock 데이터 (정상 케이스)
- 여러 일정 추출 시나리오 (신청 기간, 마감일, 장소, 제출물 포함)
- **예외 케이스 Mock 데이터**
  - 일정 없음 (날짜 정보 부재)
  - 일정 1개만 있는 경우
  - 일정 10개 이상 많은 경우
  - 장소/제출물 없는 경우

### 데이터베이스 구조 설계
- notices 테이블: 공지 저장
- events 테이블: 일정 저장
- notices-events 관계: 어느 공지에서 나온 일정인지 추적
- 테스트용 Mock 데이터셋 작성

### 테스트
- Mock API 응답 형식 검증
- DB 저장 로직 테스트
- 여러 케이스에 대한 Mock 데이터 준비

> **핵심**: 3주차는 Mock 데이터로 UI와 로직을 완성하고, 4주차에 Claude API로 교체하는 구조

# 4주 차 : Claude API 연동 · 캘린더 · 대시보드 · 배포

## 월요일 - Claude API 연동 및 AI 분석 고도화

> **4주차 첫 번째**: Mock을 실제 Claude API로 교체하고 분석 성능을 최적화합니다.

### Claude API 설정
- API Key 환경 변수 등록
- API 호출 구조 구현

### Claude API 프롬프트 작성
- 효과적인 분석 프롬프트 설계
- 한국어 공지 최적화
- 결과물 예제 추가 (few-shot prompting)
- JSON 형식 강제 명령어 추가

### JSON Schema 검증 강화
- 3주차 Mock 스키마와 동일한 형식 유지 (코드 변경 최소화)
- Claude API 응답 유효성 검증
- 스키마 불일치 시 오류 처리

### 실제 공지로 테스트
- 대학교 공지 사항
- 기업 공고
- 이벤트 공지
- 신청 안내
- PDF와 텍스트 모두 테스트

### Mock과 API 결과 비교 검증
- 같은 공지에 대해 Mock과 API 결과 비교
- 성능 평가 (정확도, 응답 속도)
- 개선 필요 부분 식별

### API 에러 처리 강화
- 타임아웃 처리
- 속도 제한(Rate Limit) 처리
- 일시적 오류 재시도 로직
- API 비용 모니터링

### 다양한 공지 타입 테스트
- 날짜 없는 공지
- 여러 일정이 섞인 공지
- 이미지/스캔 PDF (OCR 필요 케이스)
- 구조화되지 않은 텍스트

# Mock에서 Claude API로 전환 전략

## 핵심 원칙: 같은 JSON 스키마 유지

```
3주차 (Mock 기반)
├─ 분석 결과 JSON 스키마 정의
├─ UI/UX 완성
├─ 저장/조회 API 완성
└─ 전체 흐름 완성

              ↓ (같은 JSON 형식 유지)

4주차 (API 기반)
├─ Mock 분석 API → Claude API로 교체만 함
├─ 나머지 코드는 변경 없음
├─ 프롬프트 최적화
└─ 배포
```

## 장점

- ✅ **3주차**: 빠르고 안정적인 개발 (Mock 사용)
- ✅ **4주차**: API 교체만으로 완성 (코드 수정 최소)
- ✅ **비용 절감**: API는 1주일만 사용
- ✅ **위험 감소**: 3주차에 전체 구조 검증
