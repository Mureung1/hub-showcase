# 아맞다 2~4주차 개발 체크리스트

## 문서 역할

이 문서는 이번 주를 제외한 2주차, 3주차, 4주차의 개발 순서와 주간 완료 목표를 관리한다. 현재 구현 여부와 관계없이 계획한 기능을 모두 표시하며, 각 주차의 작업은 위에서 아래 순서로 진행한다.

- 전체 기능 범위와 세부 작업은 [제품 백로그](backlog.md)에서 관리한다.
- 파일별 구현 순서와 테스트 방법은 연결된 `docs/superpowers/plans/` 문서에서 확인한다.
- 개별 구현 상태는 백로그의 세부 체크박스를 단일 기준으로 삼는다.
- 주간 작업 목록은 연결된 백로그 범위가 모두 완료됐을 때 체크하고, 완료 기준은 해당 결과를 검증한 뒤 별도로 체크한다.
- 조건부 작업이 제외로 결정되면 체크하지 않고 항목 뒤에 `해당 없음 — 결정 사유`를 기록하며, 주차 완료를 막지 않는다.
- 우선순위는 백로그의 P0, P1, P2, 확인 필요 기준을 그대로 사용한다.

## 2주차 — 기반과 사용자 진입

### 주간 목표

다음 주까지 사용자가 Google 로그인 후 개인화 온보딩을 거쳐, 사용자별 데이터가 보호되는 앱 화면에 진입할 수 있는 기반을 완성한다.

### 작업 목록

- [ ] **[P0] 프로젝트 기반** — 앱 탭, 공통 레이아웃과 UI, 반응형 기준, 테스트 환경을 구성한다. ([백로그](backlog.md#p0-프로젝트-기반) · [구현 계획](superpowers/plans/amadda-p0-app-shell.md))
- [ ] **[P0] Supabase 인증** — Google OAuth, 로그인 전 소개와 로그인 화면, 인증 게이트, 로그아웃을 연결한다. ([백로그](backlog.md#p0-supabase-인증) · [구현 계획](superpowers/plans/amadda-auth.md))
- [ ] **[P0] 데이터 모델과 RLS** — 프로필, 카테고리, 인사이트 테이블과 사용자별 접근 정책을 적용한다. ([백로그](backlog.md#p0-데이터-모델과-rls) · [구현 계획](superpowers/plans/amadda-data-model.md))
- [ ] **[P0] 로그인 후 개인화 온보딩** — 관심 분야 선택, 초기 카테고리 생성, 완료 상태 저장과 홈 이동을 구현한다. ([백로그](backlog.md#p0-로그인-후-개인화-온보딩) · [구현 계획](superpowers/plans/amadda-onboarding.md))
- [ ] **[확인 필요] Chrome Extension 범위 결정** — 멘토 확인을 받아 MVP 포함 여부를 확정하고, 포함 시 4주차 조건부 작업으로 넘긴다. ([백로그](backlog.md#chrome-extension-범위-결정))

### 완료 기준

- [ ] 로그인 전 사용자는 보호된 앱 화면에 접근할 수 없다.
- [ ] Google 로그인 후 최초 사용자는 개인화 온보딩을 완료하고 홈으로 이동한다.
- [ ] 재방문 사용자는 온보딩을 반복하지 않고 앱으로 진입한다.
- [ ] 사용자별 데이터 테이블과 RLS 정책이 적용되고 다른 사용자의 접근이 차단된다.
- [ ] Chrome Extension의 MVP 포함 여부가 결정되어 백로그에 반영된다.

## 3주차 — 저장과 보관의 전체 흐름

### 주간 목표

사용자가 링크를 저장하고 카테고리로 분류한 뒤, 보관함에서 검색하고 수정하거나 삭제할 수 있는 핵심 관리 흐름을 완성한다.

### 작업 목록

- [ ] **[P0] 카테고리 관리** — 목록 조회, 생성, 수정, 삭제, 중복 검증과 `All`·`미분류` 시스템 필터를 구현한다. ([백로그](backlog.md#p0-카테고리) · [구현 계획](superpowers/plans/amadda-category.md))
- [ ] **[P0] 인사이트 저장** — URL 검증과 정규화, 중복 방지, 즉시 저장, 카테고리와 메모 선택 흐름을 구현한다. ([백로그](backlog.md#p0-인사이트-저장) · [구현 계획](superpowers/plans/amadda-insight-save.md))
- [ ] **[P0] 보관함·인사이트 카드·검색** — 최신순 목록, 카테고리 필터, 카드 그리드, 키워드 검색과 빈 상태를 구현한다. ([보관함 백로그](backlog.md#p0-보관함) · [카드 백로그](backlog.md#p0-인사이트-카드) · [검색 백로그](backlog.md#p0-검색) · [구현 계획](superpowers/plans/amadda-library.md))
- [ ] **[P0] 인사이트 수정과 삭제** — 제목, 메모, 카테고리 연결 수정과 확인 후 삭제 흐름을 구현한다. ([백로그](backlog.md#p0-인사이트-수정과-삭제) · [구현 계획](superpowers/plans/amadda-insight-edit.md))

### 완료 기준

- [ ] 유효한 URL을 저장하면 인사이트가 즉시 생성되고 중복 URL은 안내된다.
- [ ] 카테고리를 생성·수정·삭제할 수 있으며 삭제해도 연결된 인사이트는 유지된다.
- [ ] 보관함에서 전체·카테고리·미분류 필터와 검색을 사용할 수 있다.
- [ ] 인사이트 제목, 메모, 카테고리 연결을 수정하고 삭제할 수 있다.
- [ ] 데스크톱, 태블릿, 모바일에서 카드 목록의 기본 레이아웃이 깨지지 않는다.

## 4주차 — 꺼내보기와 데모 완성도

### 주간 목표

저장된 인사이트를 현재 상황에 맞춰 다시 찾는 `꺼내보기` 경험을 완성하고, 실패 상황과 보안·반응형 품질을 점검한 뒤 배포 가능한 데모를 준비한다.

### 작업 목록

- [ ] **[P0] 꺼내보기** — 상황 입력, 추천 상황 버튼, MiniSearch 랭킹, 최대 6개 작업팩과 최근 보관 항목을 구현한다. ([백로그](backlog.md#p0-꺼내보기) · [구현 계획](superpowers/plans/amadda-retrieve.md))
- [ ] **[P1] URL 메타데이터 수집** — 저장 후 제목, 설명, 이미지를 비동기로 수집하고 실패해도 저장 성공을 유지한다. ([백로그](backlog.md#p1-url-메타데이터-수집) · [구현 계획](superpowers/plans/amadda-metadata.md))
- [ ] **[P1] 카테고리 추천** — 도메인, 제목 키워드, 최근 사용 기록을 바탕으로 선택 가능한 추천 칩을 제공한다. ([백로그](backlog.md#p1-카테고리-추천))
- [ ] **[P1] 기존 저장물 가져오기** — Chrome 북마크 HTML을 브라우저에서 분석하고 신규·중복·오류를 확인한 뒤 원자적으로 반영하고 Undo를 제공한다. ([백로그](backlog.md#p1-기존-저장물-가져오기) · [구현 계획](superpowers/plans/2026-07-10-chrome-insight-import.md))
- [ ] **[P1] 실패 상태와 빈 상태** — 잘못된 URL, 저장 실패, 네트워크 오류, 결과 없음, 로딩 상태와 재시도를 정리한다. ([백로그](backlog.md#p1-실패-상태와-빈-상태))
- [ ] **[P1] 보안과 신뢰** — RLS, 입력 렌더링, URL 프로토콜, private IP, timeout과 응답 크기 제한을 검증한다. ([백로그](backlog.md#p1-보안과-신뢰))
- [ ] **[P1] 반응형과 사용성** — 주요 화면 크기, 하단 내비게이션, 칩 스크롤, 키보드 접근성과 focus 상태를 점검한다. ([백로그](backlog.md#p1-반응형과-사용성))
- [ ] **[확인 필요] Chrome Extension 조건부 구현** — 2주차에 MVP 포함으로 결정된 경우에만 현재 탭 저장과 웹 앱 인증 연동 범위를 구현하고, 제외로 결정되면 `해당 없음`과 사유를 기록한다. ([백로그](backlog.md#chrome-extension-mvp-포함-시-구현))
- [ ] **[P2] 마무리와 데모 준비** — 샘플 데이터, 핵심 시나리오 리허설, 문구, 배포 환경과 최종 빌드를 점검한다. ([백로그](backlog.md#p2-마무리와-데모-준비))

### 완료 기준

- [ ] 저장 후 메타데이터 수집이 비동기로 동작하며 실패가 저장 결과를 되돌리지 않는다.
- [ ] 상황 문장이나 추천 버튼으로 최대 6개의 관련 인사이트 작업팩을 확인할 수 있다.
- [ ] 추천 카테고리 후보를 확인하고 사용자가 선택해 인사이트에 연결할 수 있다.
- [ ] Chrome 북마크 파일을 선택해 가져오기 결과를 확인하고, 필요하면 사용자 수정 데이터를 보존한 채 작업 단위로 Undo할 수 있다.
- [ ] 주요 실패·빈 상태에서 원인과 다음 행동을 이해할 수 있다.
- [ ] RLS와 외부 URL 처리의 주요 보안 시나리오를 검증한다.
- [ ] 핵심 흐름이 모바일과 데스크톱에서 동작하고 키보드로 주요 기능에 접근할 수 있다.
- [ ] 저장 → 보관함 → 꺼내보기 데모를 리허설하고 배포 빌드를 통과한다.
