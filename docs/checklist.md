# 구현 체크리스트

`plan.md` 시나리오와 `images/plan.png` 화면을 기준으로, 화면 → 영역 → 세부 항목 순서로 쪼갠 작업 목록이다.

## 1. 첫 화면

### 왼쪽 영역
- [ ] 서비스 제목 문구
- [ ] 서비스 설명 문구
- [ ] 새 약속 만들기 버튼
- [ ] 기존 약속 참여하기 버튼
- [ ] 이용 관련 설명

### 오른쪽 영역
- [ ] 서비스 예시 사진(png 또는 gif)

## 2. 약속 생성 화면

### 위쪽 영역
- [ ] 약속 제목 입력칸
- [ ] 후보 날짜 선택칸 (시작일~종료일)
- [ ] 만날 가능 시간대 입력칸 (시작 시각~종료 시각)
- [ ] 응답 마감 일시 입력칸

### 아래쪽 영역
- [ ] 설정 안내 문구
- [ ] 약속 만들기 버튼

## 3. 약속 생성 완료 화면(약속 상세 화면으로 넘어간 뒤 모달으로 표시 )

### 위쪽 영역
- [ ] 생성 완료 문구
- [ ] 공유 안내 문구

### 가운데 영역
- [ ] 참여 링크 표시
- [ ] 참여 코드 표시

### 아래쪽 영역
- [ ] 링크 복사 버튼
- [ ] 공유하기 버튼

## 4. 약속 참여 화면(첫 화면에서 모달으로 표시)

### 위쪽 영역
- [ ] 화면 제목

### 가운데 영역
- [ ] 약속 링크 또는 코드 입력칸
- [ ] 이름 입력칸
- [ ] 간편 비밀번호 입력칸
- [ ] 잘못된 코드일 때 안내 문구 

### 아래쪽 영역
- [ ] 참여하기 버튼

## 5. 약속 상세 화면 (투표 현황)

### 위쪽 영역
- [ ] 약속 제목 표시
- [ ] 후보 날짜 범위 표시
- [ ] 참여 링크 표시와 복사 버튼(공유 버튼도 고려)

### 가운데 영역
- [ ] 응답 완료 인원 문구 (예: N명 중 M명 완료)
- [ ] 진행 막대
- [ ] 응답 마감 일시 표시

### 아래쪽 영역
- [ ] 약속 투표하기 버튼
- [ ] 투표 확정하기 버튼 (약속을 만든 사람에게만 표시)

## 6. 일정 입력(투표) 화면

### 위쪽 영역
- [ ] 화면 제목

### 왼쪽 영역 — 대화 입력
- [ ] 입력 안내 문구
- [ ] 대화 입력칸
- [ ] 주고받은 대화 내용 표시
- [ ] 입력 해석하기 버튼

#### 대화 이해(AI API 연동해서 구현)
- [ ] "오후", "이후" 같은 표현을 날짜·시간으로 바꿔 이해하기
- [ ] 불가능·선호·비선호 구분해서 정리하기

### 오른쪽 영역 — 시간표에서 선택하기
- [ ] 날짜별 칸 표시 (열)
- [ ] 30분 단위 시간 칸 표시 (행)
- [ ] 칸을 누르면 선택 상태로 바뀌는 표시
- [ ] 선택 상태 안내 문구 (불가능/선호/비선호 구분, 대화 기반으로 실시간 연동)

## 7. AI 해석 결과 확인 화면

### 위쪽 영역
- [ ] 정리 완료 문구

### 가운데 영역 — 정리된 조건 목록(캘린더 통해 전체적으로 표시할 수도 있음.)
- [ ] 불가능 조건 표시 (날짜·시간)
- [ ] 선호 조건 표시 (날짜·시간)
- [ ] 비선호 조건 표시 (날짜·시간)
- [ ] 항목별 수정 버튼

### 충돌 안내
- [ ] 안내 문구(실시간 연동으로 충돌 처리 가능한 경우 필요X)

### 아래쪽 영역
- [ ] 투표 완료 버튼

## 8. 투표 완료 화면

### 위쪽 영역
- [ ] 완료 표시 아이콘
- [ ] 완료 문구

### 가운데 영역
- [ ] 내가 가능하다고 답한 날짜 요약
- [ ] 내가 선호한다고 답한 시간 요약

### 아래쪽 영역
- [ ] 내 응답 수정하기 버튼

## 9. 생성자 관리 화면(3.약속 상세에서 확정 클릭시 표시 예정인 화면.)

### 위쪽 영역
- [ ] 응답 완료 인원 문구
- [ ] 진행 막대

### 가운데 영역 — 참여자 목록
- [ ] 참여자 이름 나열
- [ ] 참여자별 완료/미참여 표시

### 아래쪽 영역
- [ ] 미응답자가 있어도 마감할 수 있다는 안내 문구
- [ ] 투표 마감 버튼

## 10. 추천 결과 화면

### 위쪽 영역
- [ ] 추천 기준 안내 문구

### 추천 기준
- [ ] 참석 가능한 인원이 많은 시간 먼저 보여주기
- [ ] 선호가 많은 시간 먼저 보여주기
- [ ] 비선호가 있는 시간은 뒤로 밀기
- [ ] 최대 5개까지만 보여주기

### 추천 카드 (순위별 반복)
- [ ] 순위 표시 (1순위/2순위/3순위 …)
- [ ] 추천 날짜·시간 표시
- [ ] 선호 점수 표시
- [ ] 참석 가능 인원·비선호 인원 표시
- [ ] 이 시간으로 확정 버튼

## 11. 최종 일정 확정 화면

### 위쪽 영역
- [ ] 확정 날짜 표시
- [ ] 확정 시간 표시

### 가운데 영역
- [ ] 선정 근거 문구 (예: 전원 참석 가능, 선호 점수 등)

### 아래쪽 영역
- [ ] 결과 공유 링크 표시
- [ ] 공유 버튼
- [ ] 확정 후에는 결과만 볼 수 있다는 안내 문구
