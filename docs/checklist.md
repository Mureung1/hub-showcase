# CareerSignal 작업 체크리스트

이 문서는 정적 프로토타입의 완료 기록을 관리합니다. 실제 제품 MVP 작업은 [개발 백로그](backlog.md)에서 관리합니다.

## 1. 정적 프로토타입 완료 기록 (백엔드 · 5화면)

- [x] HTML/CSS 기반 5화면 구현 — 직무 선택 · 통계 분석 · 인재상 역산 · 합격 조건 · 준비 로드맵
- [x] 공통 상단바(STEP n/5)와 화면 간 이동 링크 구성
- [x] 가운데 정렬 본문과 오른쪽 글래스 목차(통계·역산·합격 조건·로드맵)
- [x] 데스크톱 90% 표시 밀도와 반응형 단일 열 레이아웃
- [x] 백엔드 30건 mock 표기, 5개 지표 카드, 함께 요구되는 기술 조합·빈도·시계열 추세
- [x] baseline 대비 편차·근거·신뢰도 역산 카드(전체·기업군·개별 공고)
- [x] 합격 조건 체크리스트 [요구 항목·필요 산출물/활동·활용처·보유]와 활용처별 내용
- [x] 미체크 항목과 연결된 4단계 준비 로드맵
- [x] 백엔드 로고 세트(java·spring·mysql·jpa·redis·docker·git·api), 미사용 프론트 로고 제거
- [x] JavaScript 없이 정적 화면임을 범위에 반영
- [x] 5화면 링크·앵커 흐름과 참조 에셋 정합성 검증
- [ ] origin push 후 Vercel 데모에 5화면 백엔드 반영 확인

## 2. 정적 프로토타입 제외 범위

- [x] 사용자 입력에 따른 동적 직무 변경
- [x] 샘플 데이터 조회와 빈도 집계
- [x] 분석 중·성공·오류·빈 결과 상태 처리
- [x] LLM 역산·근거 생성과 결과 자기검증
- [x] 실제 채용공고 수집, 로그인, DB 저장

위 항목은 프로토타입에서 의도적으로 구현하지 않았으며, 실제 제품 백로그에서 다룹니다.
