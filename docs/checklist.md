# 3주 MVP 완료 기준

- [ ] 매장 한 곳의 정보를 편집할 수 있다.
- [ ] 영업시간, 휴무일, 메뉴, 가격, 공지를 수정할 수 있다.
- [ ] 플랫폼별 가격 차이가 자동 계산된다.
- [ ] 카테고리 및 메뉴별 노출 플랫폼을 설정할 수 있다.
- [ ] 영구 변경과 임시 변경을 구분할 수 있다.
- [ ] 플랫폼별 적용값을 미리 확인할 수 있다.
- [ ] 사장님 최종 승인 후 업데이트가 실행된다.
- [ ] 자동 업데이트와 수동 수정 흐름이 모두 동작한다.
- [ ] 플랫폼별 성공·검토 중·실패 상태를 확인할 수 있다.
- [ ] 실패한 플랫폼만 다시 시도할 수 있다.
- [ ] 수동 수정 사이트와 복사할 내용을 제공한다.
- [ ] 외부 정보 차이를 항목별로 묶어서 확인할 수 있다.
- [ ] 수정 이력에서 원하는 항목만 되돌릴 수 있다.
