# 작업 체크리스트 (`docs/checklist.md`)

기획서(`docs/plan.md`)의 화면·기능·시나리오에서만 작업 단위를 도출했습니다.

> **2026-07-13 갱신**: 리더뷰 단어 인터랙션 제거 → 문장 단위 아코디언 번역으로 대체, 단어장 화면 신규 추가, 인사이트 노트(舊 마이페이지)에 AI 심리 비교 추가.
>
> **2026-07-15 갱신**: "마이페이지" 명칭을 "인사이트 노트"로 전면 변경. 글로벌 내비게이션(사이드바) 신설. 리더뷰에서 `insight`/`marketSentiment` 블라인드 처리 후 판단 시 바텀시트에서 공개. 투자 판단 버튼을 sticky에서 정적 배치로 변경. 인사이트 노트 히스토리를 상세뷰(모달) 방식에서 카드형 아코디언 방식으로 변경.

## 화면 구성 (기획서 6번 시나리오·7번 플로우차트 기준)

1. **글로벌 내비게이션 (사이드바, 신규)** — 상단 `[+ 오늘의 핵심 기사]` Primary 버튼, 'Menu'(대시보드/단어장) · 'History'(인사이트 노트) 그룹. 리더뷰에서는 숨김 처리, `< 뒤로 가기` 버튼으로 대체
2. **메인 대시보드** — 오늘의 핵심 외신 3개 노출
3. **기사 상세 (리더뷰)** — 원문 파싱·렌더링 + 문장 단위 인라인 번역(아코디언) + AI 3줄 요약(항상 공개) + 정적 배치 투자 판단 버튼 (`insight`/`marketSentiment`는 블라인드)
4. **바텀시트 (신규)** — 판단 버튼 클릭 시 오픈, 나의 판단 vs `marketSentiment` 비교 + `insight` 공개, 닫으면 자동 저장+토스트
5. **인사이트 노트 (舊 마이페이지)** — 히스토리 카드(나의 판단 vs marketSentiment만 심플 노출) + "AI 관점 해설 보기" 아코디언(요약+insight+원문버튼)
6. **단어장** — AI가 자동 선별한 핵심 용어 최신순 목록, 출처(기사) 링크

## 화면 1. 글로벌 내비게이션 (사이드바, 신규)

- [ ] 상단 `[+ 오늘의 핵심 기사]` Primary 액션 버튼 (대시보드로 이동 또는 새 기사 강조)
- [ ] 'Menu' 그룹: 대시보드, 단어장 링크
- [ ] 'History' 그룹: 인사이트 노트 링크
- [ ] 리더뷰(화면3) 진입 시 사이드바 숨김, 좌측 상단 `< 뒤로 가기` 버튼으로 대체

## 화면 2. 메인 대시보드

- [ ] 오늘의 핵심 외신 3개 노출 영역
- [ ] 외신 카드 (로고 + 영문 제목 + 한 줄 번역)
- [ ] 카드 클릭 → 기사 상세(리더뷰) 이동

## 화면 3. 기사 상세 (리더뷰)

### 기능 ① 원문 리더뷰 + 문장 단위 인라인 번역 (최우선순위)

- [ ] 불필요한 요소 제거된 리더뷰 형태 원문 렌더링
- [ ] 원문 실시간 파싱
- [ ] LLM이 선별한 어려운 문장에 옅은 점선 밑줄(`border-bottom: 1px dotted var(--border-subtle)`) 표시 (형광펜/파란밑줄 금지)
- [ ] 문장 탭 시 **팝업이 아닌 아코디언**으로 문장 바로 아래 한글 번역 노출, 클릭 영역은 점선이 아닌 문장 전체
- [ ] 아코디언이 원문 문장을 가리지 않고 자연스럽게 펼쳐짐, 재탭 시 접힘

> 실무 참고: "원문 실시간 파싱"은 프론트가 브라우저에서 외신을 직접 긁으면 CORS에 막히므로, [백엔드] URL을 받아 텍스트만 파싱해 반환하는 API와 [프론트] 로딩 스켈레톤 노출 + 파싱 결과 렌더링으로 나누어 작업. 상세 Task는 `docs/backlog.md` 참고.

> ⚠️ 단어 하이라이트/툴팁 UI는 이번 개편으로 리더뷰에서 완전히 제거됨 (화면 6. 단어장으로 이전).

### 기능 ② AI 문단 요약 (항상 공개)

- [ ] 문단 요약 버튼
- [ ] 문단별 3줄 불릿 요약 표시 (객관적 팩트이므로 블라인드 처리 없이 항상 공개)

> ⚠️ 기존 "AI 인사이트 패널"(종목 영향 해설 + marketSentiment)은 리더뷰에 항상 노출하던 것에서 **블라인드 처리**로 변경됨. 판단 전에는 화면에 렌더링하지 않고, 화면4 바텀시트에서만 공개.

### 기능 ③ 완독 후 투자심리 인터랙션 (정적 배치)

- [ ] [ Bullish 🐂 ] / [ Neutral ➖ ] / [ Bearish 🐻 ] 버튼 — 기사 최하단에 **정적 배치** (sticky 아님)
- [ ] 버튼 클릭 시 새 화면 이동 없이 화면4(바텀시트) 오픈
- [ ] 판단 없이 뒤로 가기/이탈 시에도 "읽기 완료"로만 처리 (판단은 미기록)

## 화면 4. 바텀시트 (신규)

- [ ] 판단 버튼 클릭 시 화면 절반을 덮는 바텀시트 오픈 (새 페이지 이동 아님)
- [ ] "나의 선택 vs 시장의 해석(AI marketSentiment)"을 중립적으로 비교 시각화
- [ ] 블라인드 처리했던 `insight`(AI 관점 해설) 공개
- [ ] 닫기/완료 액션 시 `기사 URL` · `AI 요약본` · `나의 선택` · `marketSentiment` · `insight` 서버 자동 저장
- [ ] 저장 완료 직후(바텀시트가 닫힌 뒤) "✅ 인사이트 노트에 저장되었습니다." 토스트 노출 (바텀시트와 중복되지 않게 타이밍 확인)

## 화면 5. 인사이트 노트 (舊 마이페이지)

- [ ] 투자 판단 히스토리 등록/조회
- [ ] 히스토리 카드는 나의 판단과 `marketSentiment`만 심플하게 나란히 노출 (기본 상태)
- [ ] 카드 하단 "🔽 AI 관점 해설 보기" 탭 시 아코디언으로 펼쳐짐: AI 3줄 요약 + `insight` + `[원문 기사 보러가기 ↗]` 버튼
- [ ] 원문 만료 여부는 서버가 판단하지 않고, 버튼 클릭 시 브라우저가 자연스럽게 처리 (Fallback은 아코디언 안 저장된 요약/insight로 이미 달성)

## 화면 6. 단어장

- [ ] 기사 분석 시 AI가 선별한 핵심 용어 3~5개가 사용자 액션 없이 자동 적재되는지 확인
- [ ] 단어 목록 최신순(시간 역순) 정렬
- [ ] 각 단어에 출처(기사 제목) 표기, 클릭 시 해당 기사(리더뷰)로 이동
- [ ] `{ term, definition }` 구조만 사용 (`metaphor` 필드 없음)

## 화면 흐름 (기획서 7번 Mermaid 플로우차트 기준)

```
사이드바(오늘의 핵심 기사) 진입 → 오늘의 핵심 외신 3개 노출 → 관심 기사 클릭
  → 리더뷰 진입 (사이드바 숨김, 뒤로가기로 복귀 / 원문 실시간 파싱 렌더링)
  → (분석 시점에 핵심 용어 3~5개 자동으로 단어장에 적재 — 리더뷰와 무관하게 백그라운드로 진행)
  → [해석 막히는 문장 발견?] 문장 탭(점선 힌트, 문장 전체 클릭 영역) → 아코디언으로 번역 노출 → 독해 재개
                            넘어가기 → 독해 재개
  → [문단 요약 필요?] 버튼 클릭 → 3줄 요약 확인(항상 공개) → 스크롤
                      스스로 해석 → 스크롤
  → 기사 최하단, 정적 배치된 [Bullish/Neutral/Bearish] 버튼 확인 (insight/marketSentiment는 아직 블라인드)
  → 버튼 클릭 → 바텀시트 오픈 → 나의 판단 vs marketSentiment 비교 + insight 공개
  → 바텀시트 닫기 → 서버 저장(URL+요약+판단+marketSentiment+insight) → 저장 완료 토스트
  → 인사이트 노트 히스토리 등록 (카드: 나의 판단 vs marketSentiment만 심플 노출)
  → (재방문 시) 카드의 "AI 관점 해설 보기" 탭 → 아코디언 펼침(요약+insight+원문버튼) → [원문 보러가기] 클릭 시 브라우저가 만료 여부 자연 처리
  → (별도 시점) 사이드바에서 단어장 이동, 누적된 핵심 용어 복습, 출처 클릭 시 원문 기사로 복귀
  → (판단 없이 이탈 시) 읽기 완료로만 인정, 판단 미기록
```
