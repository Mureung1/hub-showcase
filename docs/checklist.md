# 작업 체크리스트 (`docs/checklist.md`)

## 1주차 — 화면 뼈대 & 정적 UI (데이터/로직 없이 레이아웃만)

### 공통 요소
- [ ] 진행 표시줄 컴포넌트 (6단계 중 현재 위치 표시, 예: ●●●○○○)
- [ ] 상단 네비게이션 바 (뒤로가기 / 홈 아이콘)
- [ ] 하단 고정 CTA 버튼 (다음 단계 이동용)

### 화면 1. 홈 (알림 배지)
- [ ] 상단 바 (로고, 프로필 아이콘)
- [ ] "오늘의 브리핑" 메인 카드 (알림 배지 표시)
- [ ] 카드 내부 텍스트 영역 (날짜, 종목명/티커 — 더미 텍스트)
- [ ] "브리핑 열기" CTA 버튼
- [ ] 학습 스트릭 요약 영역 (더미 숫자 표시)

### 화면 2. 브리핑 진입 (헤드라인)
- [ ] 헤더 (뒤로가기 버튼 + "오늘의 브리핑" 타이틀)
- [ ] 종목 태그 배지 컴포넌트
- [ ] 기사 헤드라인 텍스트 블록
- [ ] 출처 표시 영역 (Yahoo Finance 로고/텍스트 + 발행일)
- [ ] "아래로 스크롤" 안내 컴포넌트

### 화면 3. 3줄 한글 요약
- [ ] 섹션 타이틀 ("핵심 요약")
- [ ] 요약 텍스트 블록 (3줄 불릿 레이아웃)
- [ ] 지표 하이라이트 영역 (더미 수치 표시)
- [ ] "원문 보기 →" 버튼

### 화면 4. 원문 기사 링크
- [ ] 원문 카드 (썸네일 placeholder + 제목)
- [ ] "원문 읽기" 링크 버튼
- [ ] 안내 문구 텍스트
- [ ] 뒤로가기 버튼

### 화면 5. 핵심 문장 + 표현 해설
- [ ] 섹션 타이틀 ("오늘의 핵심 문장")
- [ ] 문장 카드 컴포넌트 (영어 원문 + 한글 해석, 더미 데이터로 2~3개 배치)
- [ ] 표현 하이라이트 스타일 (밑줄/색상 강조 CSS)
- [ ] 표현 설명 아코디언 (펼침/접힘 UI만 — 내용은 더미)
- [ ] 카드 개수 인디케이터 (1/3, 2/3 등)

### 화면 6. 투자 용어 미니 설명
- [ ] 섹션 타이틀 ("오늘의 투자 개념")
- [ ] 용어 카드 컴포넌트 (용어명 + 정의, 더미 데이터)
- [ ] 맥락 설명 텍스트 영역
- [ ] "오늘 학습 마치기" 완료 버튼

---

> **1주차 완료 기준**: 화면 1→6까지 더미 데이터로 클릭해서 끝까지 넘어갈 수 있는 상태 (실제 뉴스 데이터, 개인화 로직, 복습 로직은 미포함)
