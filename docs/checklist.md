# PtoP 작업 체크리스트

## 1주차 목표

PtoP의 핵심 흐름인 "프로젝트 입력 → 분석 결과 확인 → 회고/포트폴리오 초안 확인"을 동작 프로토타입 수준으로 만든다.

## 핵심 기능 1: 프로젝트 분석 기능

- [ ] Repository URL 입력 필드 만들기
- [ ] 프로젝트 폴더 업로드 버튼 만들기
- [ ] URL 입력값이 비어 있는지 확인하기
- [ ] URL 형식이 GitHub Repository 형태인지 확인하기
- [ ] 폴더 업로드 시 파일 목록을 읽는 mock 데이터 만들기
- [ ] 분석 시작 버튼 만들기
- [ ] 분석 중 상태 표시하기
- [ ] 분석 실패 상태 표시하기
- [ ] 프로젝트 목적 mock 결과 표시하기
- [ ] 기술 스택 mock 결과 표시하기
- [ ] 핵심 기능 mock 결과 표시하기

## 핵심 기능 2: 회고/포트폴리오 초안 생성 기능

- [ ] 프로젝트 분석 결과를 회고 초안 입력값으로 연결하기
- [ ] "내가 한 일" 섹션 만들기
- [ ] "어려웠던 점" 섹션 만들기
- [ ] "해결 과정" 섹션 만들기
- [ ] "배운 점" 섹션 만들기
- [ ] 포트폴리오용 한 줄 설명 생성하기
- [ ] 생성된 초안을 사용자가 수정할 수 있게 만들기
- [ ] Markdown 미리보기 영역 만들기
- [ ] Markdown 복사 버튼 만들기

## 화면 구성 작업

- [ ] 시작 화면 정리하기
- [ ] 프로젝트 입력 화면 만들기
- [ ] 분석 진행 화면 만들기
- [ ] 분석 결과 화면 만들기
- [ ] 회고/포트폴리오 초안 화면 만들기
- [ ] Markdown 저장/복사 화면 만들기
- [ ] 모바일 화면에서도 주요 버튼과 텍스트가 잘리지 않게 조정하기

## 검증 체크리스트

- [ ] 사용자가 Repository URL을 입력하고 분석 시작 버튼을 누를 수 있는가?
- [ ] 분석 중 상태가 사용자에게 보이는가?
- [ ] 분석 결과가 프로젝트 목적, 기술 스택, 핵심 기능으로 나뉘어 보이는가?
- [ ] 회고 초안이 내가 한 일, 어려웠던 점, 해결 과정, 배운 점으로 나뉘어 보이는가?
- [ ] 사용자가 생성된 초안을 수정할 수 있는가?
- [ ] Markdown 결과를 복사할 수 있는가?
- [ ] 핵심 기능 2개가 문제 정의를 직접 해결하는가?
