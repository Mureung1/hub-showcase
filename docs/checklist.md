# 작업 체크리스트 (`docs/checklist.md`)

기획서(`docs/plan.md`)의 화면·기능·시나리오에서만 작업 단위를 도출했습니다.

## 화면 구성 (기획서 6번 시나리오·7번 플로우차트 기준)

1. **메인 대시보드** — 오늘의 핵심 외신 3개 노출
2. **기사 상세 (리더뷰)** — 원문 파싱·렌더링 + 인라인 용어 해설 + AI 요약 + AI 인사이트 패널 + 투자 판단 버튼
3. **마이페이지** — 투자 판단 히스토리, 페이월/만료 시 복기(Fallback)

---

## 화면 1. 메인 대시보드

- [ ] 오늘의 핵심 외신 3개 노출 영역
- [ ] 외신 카드 (로고 + 영문 제목 + 한 줄 번역)
- [ ] 카드 클릭 → 기사 상세(리더뷰) 이동

## 화면 2. 기사 상세 (리더뷰)

### 기능 ① 원문 리더뷰 + 전문용어 인라인 해설 (최우선순위)

- [ ] 불필요한 요소 제거된 리더뷰 형태 원문 렌더링
- [ ] 원문 실시간 파싱
- [ ] 금융 전문용어 자동 하이라이트
- [ ] 하이라이트 탭 시 팝업 툴팁 (비유 1줄 + 뜻 1줄 정책 적용, 예: 베어마켓 설명 방식)
- [ ] 팝업이 브라우저 이탈 없이 뜨고, 확인 후 독해 재개 가능

> 실무 참고: "원문 실시간 파싱"은 프론트가 브라우저에서 외신을 직접 긁으면 CORS에 막히므로, [백엔드] URL을 받아 텍스트만 파싱해 반환하는 API와 [프론트] 로딩 스켈레톤 노출 + 파싱 결과 렌더링으로 나누어 작업. 상세 Task는 `docs/backlog.md` 참고.

### 기능 ② AI 문단 요약 + 종목 영향 한 줄 해설

- [ ] 문단 요약 버튼
- [ ] 문단별 3줄 불릿 요약 표시
- [ ] 기사 하단 'AI 인사이트 패널'
- [ ] "이 기사가 주가에 미치는 영향" AI 한 줄 브리핑

### 기능 ③ 완독 후 투자심리 인터랙션

- [ ] [매수 📈] / [관망 ➖] / [매도 📉] 버튼
- [ ] 버튼 클릭 시 `기사 URL` · `AI 요약본` · `나의 선택` 서버 저장
- [ ] "오늘의 모의 투자 판단 완료!" 토스트 팝업

## 화면 3. 마이페이지

- [ ] 투자 판단 히스토리 등록/조회
- [ ] 원문 URL이 페이월에 막히거나 만료된 경우, 저장된 AI 요약본으로 판단 근거 복기 가능 (Fallback)

## 화면 흐름 (기획서 7번 Mermaid 플로우차트 기준)

```
대시보드 진입 → 오늘의 핵심 외신 3개 노출 → 관심 기사 클릭
  → 리더뷰 진입 (원문 실시간 파싱 렌더링)
  → [어려운 용어 발견?] 단어 탭 → 툴팁 팝업 → 독해 재개
                        넘어가기 → 독해 재개
  → [문단 요약 필요?] 버튼 클릭 → 3줄 요약 확인 → 스크롤
                      스스로 해석 → 스크롤
  → AI 인사이트 패널(종목 영향 한줄 해설) 확인
  → [나의 모의 투자 판단] 매수/관망/매도 클릭
  → 서버 전송 → 데이터 저장(URL+AI요약+내 판단) → 완료 토스트
  → 마이페이지 히스토리 등록
  → (재방문 시) 링크 만료/페이월 발생 → 저장된 AI 요약본으로 복기
```
