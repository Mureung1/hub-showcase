# AI 소비 코치 (SpendMate) — 핵심 시나리오 기반 구현 체크리스트

이 체크리스트는 "주차별"이 아니라 **사용자가 실제로 앱을 쓰는 흐름 순서 = 구현 순서**로 짰습니다.

---

## 핵심 시나리오 흐름 (화면 순서)

```
① 회원가입/로그인
      │
② 온보딩 — 예산 설정 + 구독 등록
      │
③ 영수증 업로드 화면
      │  (내부: OCR → 파싱 → Receipt/Expense/ReceiptItem 저장)
      │
④ 소비 요약 대시보드 (카테고리별 지출, 소진 예상일)
      │
⑤ Agent 개입 화면
      │  ├─ 개입 없음 → "소비 패턴 안정적이에요" 안내만
      │  ├─ Recipe Tool 실행 → 추천 이유 → 레시피 → 예상 절약액 → 소진 예상일
      │  └─ Smart Purchase Tool 실행 → 추천 이유 → 최저가 비교 → 예상 절약액 → 소진 예상일
      │
⑥ 월말 생존 모드 (예산 임계치 도달 시 자동 전환)
```

---
