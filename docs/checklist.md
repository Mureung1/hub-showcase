# 작업 체크리스트 (`docs/checklist.md`)

## 1주차 — 화면 뼈대 & 정적 UI (데이터/로직 없이 레이아웃만)

### 공통 요소
- [ ] 진행 표시줄 컴포넌트 (6단계 중 현재 위치 표시, 예: ●●●○○○)
- [ ] 상단 네비게이션 바 (뒤로가기 / 홈 아이콘)
- [ ] 하단 고정 CTA 버튼 (다음 단계 이동용)

### 화면 1. 홈 (알림 배지)
- [ ] 상단 바 (로고, 프로필 아이콘)
- [ ] "오늘의 브리핑" 메인 카드 (알림 배지 표시)
- [ ] 카드 내부 텍스트 영역 (날짜, 종목명/티커 — 더미 텍스트)
- [ ] "브리핑 열기" CTA 버튼
- [ ] 학습 스트릭 요약 영역 (더미 숫자 표시)

### 화면 2. 브리핑 진입 (헤드라인)
- [ ] 헤더 (뒤로가기 버튼 + "오늘의 브리핑" 타이틀)
- [ ] 종목 태그 배지 컴포넌트
- [ ] 기사 헤드라인 텍스트 블록
- [ ] 출처 표시 영역 (Yahoo Finance 로고/텍스트 + 발행일)
- [ ] "아래로 스크롤" 안내 컴포넌트

### 화면 3. 3줄 한글 요약
- [ ] 섹션 타이틀 ("핵심 요약")
- [ ] 요약 텍스트 블록 (3줄 불릿 레이아웃)
- [ ] 지표 하이라이트 영역 (더미 수치 표시)
- [ ] "원문 보기 →" 버튼

### 화면 4. 원문 기사 링크
- [ ] 원문 카드 (썸네일 placeholder + 제목)
- [ ] "원문 읽기" 링크 버튼
- [ ] 안내 문구 텍스트
- [ ] 뒤로가기 버튼

### 화면 5. 핵심 문장 + 표현 해설
- [ ] 섹션 타이틀 ("오늘의 핵심 문장")
- [ ] 문장 카드 컴포넌트 (영어 원문 + 한글 해석, 더미 데이터로 2~3개 배치)
- [ ] 표현 하이라이트 스타일 (밑줄/색상 강조 CSS)
- [ ] 표현 설명 아코디언 (펼침/접힘 UI만 — 내용은 더미)
- [ ] 카드 개수 인디케이터 (1/3, 2/3 등)

### 화면 6. 투자 용어 미니 설명
- [ ] 섹션 타이틀 ("오늘의 투자 개념")
- [ ] 용어 카드 컴포넌트 (용어명 + 정의, 더미 데이터)
- [ ] 맥락 설명 텍스트 영역
- [ ] "오늘 학습 마치기" 완료 버튼

---

> **1주차 완료 기준**: 화면 1→6까지 더미 데이터로 클릭해서 끝까지 넘어갈 수 있는 상태 (실제 뉴스 데이터, 개인화 로직, 복습 로직은 미포함)

## 2단계 — 프로토타입 (순수 HTML/CSS)

핵심 기능 A(관심종목 큐레이션), B(난이도별 조절)가 실제로 동작하는 것처럼 보이는 정적 프로토타입 제작.

### 공통

- [ ] `style.css` 기본 리셋 (margin/padding 0, box-sizing)
- [ ] 폰 프레임 스타일 (고정 너비 375px, 둥근 모서리, 그림자)
- [ ] 상단 네비게이션 바 마크업 (뒤로가기 아이콘 + 타이틀 텍스트 + 우측 아이콘)
- [ ] 진행 표시줄 바 (6칸 중 현재 위치, 배경색으로 구분)
- [ ] 하단 고정 CTA 버튼 공통 스타일 (padding, radius, hover)

### 화면 1: Home — 기능 A 결과 노출

- [ ] 상단 바 마크업 (로고 아이콘 + 프로필 아이콘)
- [ ] "오늘의 브리핑" 카드 뼈대 (배경색, radius, padding)
- [ ] 카드 내부 종목명 텍스트 (더미: "Apple Inc.")
- [ ] 카드 내부 날짜 텍스트
- [ ] 알림 배지 (빨간 점 또는 숫자, absolute 위치)
- [ ] 학습 스트릭 요약 박스 (요일별 막대 5개)
- [ ] "브리핑 열기" 버튼 → `<a href="02_entry.html">`

### 화면 2: Briefing Entry

- [ ] 종목 태그 배지 (텍스트+배경색 pill 모양)
- [ ] 기사 헤드라인 텍스트 (더미 제목)
- [ ] 출처 표시 (Yahoo Finance 텍스트 + 발행일)
- [ ] 스크롤 유도 안내 (아래 화살표 아이콘 + 텍스트)
- [ ] 하단 CTA 버튼 → `<a href="03_summary.html">`

### 화면 3: 3-Line Summary

- [ ] 섹션 타이틀 ("핵심 요약")
- [ ] 3줄 불릿 리스트 (더미 텍스트)
- [ ] "원문 보기" 버튼 → `<a href="04_link.html">`

### 화면 4: Source Link

- [ ] 원문 카드 썸네일 placeholder (회색 박스)
- [ ] 원문 제목 텍스트 (화면3과 동일 헤드라인)
- [ ] "원문 읽기" 외부 링크 (`target="_blank"`)
- [ ] 안내 문구 텍스트
- [ ] 다음 버튼 → `<a href="05_sentence.html">`

### 화면 5: Core Sentences & Expressions — 기능 B 핵심 (가장 세분화)

**문장 카드 뼈대**
- [ ] 카드 배경/테두리 스타일
- [ ] 영어 원문 텍스트
- [ ] 한글 해석 텍스트
- [ ] 표현 하이라이트 `<span>` 스타일 (배경색)

**아코디언 (5-2 인터랙션)**
- [ ] `<details><summary>` 마크업 1세트
- [ ] summary 화살표 아이콘 CSS
- [ ] 펼쳤을 때 뜻/예문 텍스트 레이아웃

**카드 전환 (5-3 인터랙션, 라디오 버튼 트릭)**
- [ ] 숨김 라디오 인풋 3개 (`#c1, #c2, #c3`)
- [ ] 카드1/카드2/카드3 div + 내용
- [ ] `:checked ~` CSS 규칙으로 카드 전환
- [ ] 인디케이터 점 3개 (현재 카드에 따라 색 변경)
- [ ] "다음 문장" 버튼 (`<label for="c2">`)

**난이도 조절 (기능 B, 별도 라디오 트릭)**
- [ ] 숨김 라디오 인풋 3개 (`#lv-basic, #lv-mid, #lv-high`)
- [ ] 초급/중급/고급용 아코디언 설명 텍스트 블록 각각
- [ ] `:checked ~` CSS로 난이도별 텍스트 전환
- [ ] 난이도 선택 토글 UI (버튼 3개, label 연동)

### 화면 6: Investment Terms

- [ ] 섹션 타이틀 ("오늘의 투자 개념")
- [ ] 용어 카드 (용어명 텍스트)
- [ ] 정의 텍스트
- [ ] 맥락 설명 텍스트
- [ ] "오늘 학습 마치기" 버튼 → `<a href="01_home.html">`

> **2단계 완료 기준**: `index.html`(화면1)부터 시작해 6개 화면을 순서대로 클릭 이동 가능, 화면5에서 카드 전환/아코디언/난이도 토글이 모두 CSS만으로 작동
