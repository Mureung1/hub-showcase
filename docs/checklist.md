# 작업 분해 체크리스트 (MVP)

> [spec/mvp-plan.md](../spec/mvp-plan.md)의 확정 기능(F1~F4 + 자동화 파이프라인)을 작업 단위로 쪼갠 목록.
>
> **원칙**: 한 항목 = AI에게 내리는 **하나의 작업 지시** = 내가 **검증할 수 있는 하나의 단위**.
> 덩어리가 크면 AI도 실패하고 나도 검증 못 한다 → **잘게 쪼갤수록 성공률이 올라간다.**

---

## 0. 준비
- [ ] 저장소 폴더 구조 잡기 (`scripts/` 수집·요약, `web/` 프론트, `data/` JSON 출력)
- [ ] `requirements.txt` 작성 (`arxiv`, `feedparser`, `google-generativeai` 등)
- [ ] Gemini API 키 발급 + 로컬 `.env`에 저장 (`.gitignore`에 `.env` 추가)

## 1주차 — 데이터 파이프라인 (Python)

### 수집 (arXiv)
- [ ] arXiv API로 `cs.CL` 카테고리 최근 논문 N편 가져오는 함수
- [ ] 대상 카테고리 `cs.AI`·`cs.LG`까지 확장
- [ ] LLM 관련 키워드로 논문 필터링
- [ ] 논문 1편에서 메타데이터 파싱 (제목·저자·날짜·초록·arXiv 링크)
- [ ] 중복 논문 제거

### 요약 (LLM)
- [ ] Gemini Flash API 호출 최소 예제 (키 연동 확인)
- [ ] 요약 프롬프트 작성 (핵심 기여 / 방법 / 결과 + 배경 설명 + 한줄 요약)
- [ ] 논문 1편 → 한국어 구조화 요약 반환 함수
- [ ] 제목 한글 번역 추가
- [ ] 여러 논문 반복 요약 (에러/재시도 처리 포함)

### 데이터 저장
- [ ] 출력 JSON 스키마 정의 (id, 제목(영/한), 저자, 날짜, 태그, 중요도, 요약, 초록, 링크)
- [ ] 중요도 값 부여 (MVP: 단순 규칙 — 예: 최신순/키워드 가중치)
- [ ] 하루치 결과를 `data/YYYY-MM-DD.json`으로 저장
- [ ] 로컬에서 파이프라인 1회 수동 실행 → JSON 내용 눈으로 검증

## 2주차 — 프론트엔드 (정적)

### 골격
- [ ] 기본 페이지 HTML/CSS 골격 (프로젝트 팔레트·타이포 적용)
- [ ] JSON 파일 로드해서 콘솔에 출력 (데이터 연결 확인)

### F1 · 오늘의 브리핑 피드
- [ ] 헤더 (날짜 + "오늘 N편 수집")
- [ ] 카테고리 탭 UI
- [ ] 카드 목록을 중요도순으로 나열
- [ ] 카테고리 탭 클릭 → 해당 태그 카드만 필터

### F2 · 논문 카드 컴포넌트
- [ ] 카드 기본 레이아웃 (제목 영·한 + 한줄 요약)
- [ ] 주제 태그 표시
- [ ] 중요도 배지 표시
- [ ] 저장(🔖) 버튼 배치

### F3 · 논문 상세 · 요약 열람
- [ ] 카드 클릭 → 상세 화면 이동
- [ ] 상세 헤더: 제목 + 메타 행 (저자 · 날짜 · 주제 태그)
- [ ] 구조화 요약 표시 (핵심 기여 / 방법 / 결과)
- [ ] 배경(맥락) 설명 표시
- [ ] 원문 초록 병기 (토글 펼치기)
- [ ] arXiv 원문 링크 버튼
- [ ] 뒤로가기로 피드 복귀

### F4 · 북마크 저장
- [ ] 저장 버튼 클릭 → 브라우저 저장(localStorage) 처리
- [ ] 저장 목록 화면 (저장한 카드 나열)
- [ ] 저장 해제 토글

## 자동화 & 배포
- [ ] GitHub Actions 워크플로 파일 작성 (`.github/workflows/`)
- [ ] cron 스케줄 지정 (매일 정해진 시각)
- [ ] API 키를 GitHub Secrets에 등록하고 워크플로에서 참조
- [ ] 파이프라인 실행 → 생성된 JSON을 저장소에 자동 커밋하는 스텝
- [ ] GitHub Pages 활성화 (배포 브랜치/폴더 설정)
- [ ] `workflow_dispatch`로 수동 트리거 → 끝까지 돌고 Pages에 반영되는지 검증

## 진행 메모
- 막히는 항목은 더 잘게 쪼갠다 (한 항목이 실패하면 그 항목이 아직 너무 크다는 신호).
- 각 항목 완료 시 "무엇을 어떻게 확인했는지" 한 줄 검증 기준을 함께 남긴다.
- MVP 범위 밖(검색·트렌드·카테고리 자동분류·공유)은 이 체크리스트에 넣지 않는다 → [spec/plan.md](../spec/plan.md) 참고.
