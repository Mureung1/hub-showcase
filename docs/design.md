# Calendar UI Design Guide

## 1. 디자인 방향

첨부 레퍼런스의 인상을 캘린더 앱에 적용한다. 핵심은 **밝고 차분한 데스크톱 생산성 도구**, **정보 밀도는 높지만 답답하지 않은 화면**, **회백색 바탕 위에 떠 있는 흰 카드**, **파란색을 절제해서 사용한 상태 강조**다.

- 전체 분위기: clean, soft, calm, professional
- 시각적 우선순위: 콘텐츠 > 일정 상태 > 탐색 요소 > 장식
- 표면은 대부분 무채색으로 유지하고 파랑은 선택, 현재 시각, 주요 버튼에만 사용한다.
- 장식적인 그라데이션이나 강한 그림자는 쓰지 않는다.
- 구분은 굵은 선보다 배경색 차이, 1px 경계선, 여백으로 만든다.

## 2. 색상

아래 값은 레퍼런스의 시각적 성격을 재현하기 위한 구현용 기준값이다.

### 기본 팔레트

| 역할 | 색상 | 용도 |
|---|---:|---|
| 앱 바깥 배경 | `#E3E8EC` | 브라우저 화면과 앱 프레임 사이 배경 |
| 사이드바 배경 | `#F1F4F6` | 좌측 탐색 영역 |
| 메인 배경 | `#FFFFFF` | 주 작업 영역 |
| 보조 표면 | `#F7F9FA` | 검색창, 비활성 셀, 보조 패널 |
| 선택 표면 | `#E5EBF0` | 선택된 메뉴, 선택 날짜 |
| 기본 경계선 | `#E7EBEE` | 카드, 셀, 입력창 |
| 강한 경계선 | `#D9E0E5` | 패널 경계, 중요한 구획 |
| 기본 텍스트 | `#171A1D` | 제목, 일정명 |
| 보조 텍스트 | `#687078` | 설명, 메타 정보 |
| 흐린 텍스트 | `#A5ADB4` | placeholder, 비활성 레이블 |
| 주요 파랑 | `#4F7FB8` | 주 버튼, 현재 시각선, 선택 상태 |
| 파랑 배경 | `#EAF2FA` | 선택 날짜나 파란 상태의 연한 배경 |

### 일정 상태색

상태색은 작은 점, 얇은 좌측선, 연한 배지에만 사용한다.

| 상태 | 전경 | 연한 배경 |
|---|---:|---:|
| 정보/예정 | `#D49B2E` | `#FFF5D9` |
| 완료 | `#54A85B` | `#E6F6E5` |
| 긴급/지연 | `#C75B61` | `#FBE7E8` |
| 일반/선택 | `#4F7FB8` | `#EAF2FA` |

### 색상 사용 규칙

- 한 화면에서 강조색이 차지하는 면적은 약 10% 이하로 유지한다.
- 본문 텍스트는 순수 검정 대신 `#171A1D`를 사용한다.
- 비활성 날짜는 흐린 텍스트와 보조 표면을 함께 사용하되 읽을 수 있어야 한다.
- 상태는 색상만으로 구분하지 않고 텍스트 또는 아이콘을 함께 제공한다.

## 3. 크기와 간격

### 기준 화면

- 데스크톱 우선 기준: `1440 × 900px`
- 앱 프레임 최대 너비: `1360px`
- 앱 프레임 최소 높이: `calc(100vh - 40px)`
- 앱 바깥 여백: `20px`
- 앱 프레임 모서리: `22px`

### 주요 영역

| 요소 | 권장 크기 |
|---|---:|
| 사이드바 | `260px` |
| 상단 헤더 | `64px` |
| 메인 콘텐츠 좌우 여백 | `24px` |
| 캘린더 툴바 | `56px` |
| 월간 요일 헤더 | `42px` |
| 월간 날짜 셀 | 최소 `112px` 높이 |
| 검색창/기본 입력 | `40px` 높이 |
| 기본 버튼 | `36px` 높이 |
| 아이콘 버튼 | `36 × 36px` |

### 간격 체계

`4px` 단위를 기반으로 한다.

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 20px;
--space-6: 24px;
--space-8: 32px;
```

- 관련 요소 내부 간격: `8–12px`
- 카드 내부 여백: `12–16px`
- 섹션 사이 간격: `24–32px`
- 아이콘과 텍스트 사이: `10–12px`

### 모서리와 그림자

| 요소 | 반경 |
|---|---:|
| 앱 프레임 | `22px` |
| 카드/팝오버 | `12px` |
| 입력창/버튼 | `8px` |
| 배지 | `999px` |

```css
--shadow-app: 0 16px 40px rgb(35 48 58 / 10%);
--shadow-popover: 0 10px 28px rgb(35 48 58 / 14%);
--shadow-card: 0 2px 8px rgb(35 48 58 / 5%);
```

기본 카드에는 그림자를 거의 쓰지 않고 `1px` 경계선을 우선한다. 팝오버와 앱 프레임에만 명확한 그림자를 적용한다.

## 4. 타이포그래피

```css
font-family:
  Inter, Pretendard, "Noto Sans KR", system-ui, -apple-system,
  BlinkMacSystemFont, "Segoe UI", sans-serif;
```

| 역할 | 크기 / 행간 | 굵기 |
|---|---|---:|
| 페이지 제목 | `22px / 1.3` | `700` |
| 월 제목 | `18px / 1.4` | `700` |
| 섹션 제목 | `16px / 1.4` | `700` |
| 기본 본문 | `14px / 1.5` | `400–500` |
| 메뉴/버튼 | `13px / 1.4` | `500–600` |
| 날짜/보조 정보 | `12px / 1.4` | `400–600` |
| 작은 배지 | `11px / 1.3` | `600` |

- 제목은 촘촘하고 선명하게, 본문은 여유 있는 행간으로 설정한다.
- 숫자와 영문이 많은 캘린더이므로 숫자 폭이 안정적인 산세리프 글꼴을 우선한다.
- 한 화면에서 글꼴 크기는 5단계 이내로 제한한다.

## 5. 레이아웃

### 전체 구조

```text
앱 프레임
├─ 사이드바 (고정 폭)
│  ├─ 브랜드
│  ├─ 검색
│  ├─ 기본 메뉴
│  ├─ 내 캘린더 목록
│  └─ 사용자 프로필
└─ 메인 영역
   ├─ 상단 헤더
   ├─ 캘린더 툴바
   └─ 월간 캘린더 그리드
```

- 앱 프레임은 화면 중앙에 둔다.
- 사이드바와 메인 영역 사이에는 `1px` 경계선을 둔다.
- 메인 영역은 `min-width: 0`과 유연한 너비를 사용한다.
- 상단 헤더와 툴바는 좌측 정렬 정보, 우측 정렬 액션의 두 그룹으로 구성한다.

### 사이드바

- 폭은 `260px`로 고정한다.
- 배경은 메인보다 한 단계 어두운 차가운 회백색이다.
- 선택 메뉴는 더 진한 회색 표면과 굵은 텍스트로 표시한다.
- 메뉴 한 줄 높이는 `40px`, 좌우 패딩은 `12px`로 한다.
- 하단 프로필은 사이드바 끝에 고정한다.
- 캘린더 목록의 색상은 `8px` 원형 점으로 표시한다.

### 상단 헤더

- 높이 `64px`, 좌우 패딩 `24px`.
- 왼쪽에는 현재 위치 또는 캘린더 이름을 둔다.
- 오른쪽에는 검색, 알림, 설정 같은 아이콘 액션과 주요 버튼을 둔다.
- 주요 버튼만 파란 배경을 사용하고 나머지는 투명 또는 흰색으로 둔다.

### 캘린더 툴바

- 왼쪽: 이전/다음 버튼, 현재 월 제목
- 오른쪽: `오늘` 버튼, 보기 전환(월/주/일), 추가 버튼
- 액션 사이 간격은 `8px`.
- 보기 전환은 하나의 분할 컨트롤처럼 묶고 선택 항목에만 연한 파랑 배경을 적용한다.

### 월간 캘린더 그리드

- 7열 그리드이며 열 너비는 동일하다.
- 요일 헤더는 높이 `42px`, 흐린 텍스트를 사용한다.
- 날짜 셀은 상단 정렬하고 `10–12px` 안쪽 여백을 둔다.
- 셀 경계는 `1px solid #E7EBEE`.
- 오늘 날짜는 파란 원형 날짜 숫자 또는 얇은 파란 테두리로 표시한다.
- 다른 달의 날짜는 보조 표면과 흐린 텍스트로 구분한다.
- 주말은 과한 붉은색 대신 약간 흐린 텍스트로만 구분한다.

### 일정 카드

- 셀 안에서는 높이 `24–28px`의 조밀한 행으로 표시한다.
- 흰색 또는 매우 연한 상태 배경, `6px` 반경을 사용한다.
- 일정명은 한 줄 말줄임 처리한다.
- 색상 점 또는 `3px` 좌측선으로 캘린더 분류를 표시한다.
- 한 셀에 일정이 많으면 최대 3개까지만 보여주고 `+ N개 더보기`를 제공한다.
- 선택 시 뜨는 상세 팝오버는 약 `300px` 폭, `16px` 패딩, `12px` 반경을 사용한다.

## 6. 반응형 규칙

### `1024px` 이하

- 사이드바를 `220px`로 축소한다.
- 메인 콘텐츠 좌우 여백을 `16px`로 줄인다.
- 중요도가 낮은 헤더 아이콘 또는 레이블을 숨긴다.
- 날짜 셀 최소 높이를 `96px`로 낮춘다.

### `768px` 이하

- 사이드바는 기본적으로 숨기고 메뉴 버튼으로 여는 오버레이 패널로 전환한다.
- 앱 바깥 여백과 프레임 모서리를 제거해 전체 화면을 사용한다.
- 툴바는 두 줄로 감쌀 수 있게 한다.
- 월간 그리드는 유지하되 일정은 색상 점과 개수 중심으로 축약한다.

### `480px` 이하

- 기본 보기를 월간 요약 또는 일간 목록으로 전환할 수 있게 한다.
- 터치 대상은 최소 `40 × 40px`를 확보한다.
- 긴 텍스트 레이블보다 아이콘과 짧은 날짜 표기를 사용한다.

## 7. 인터랙션과 상태

- hover: 배경을 한 단계 진하게 변경하며 이동이나 크기 변화는 주지 않는다.
- focus: `2px solid #4F7FB8`, `2px` 바깥 여백을 사용한다.
- active: 선택 표면 `#E5EBF0` 또는 파랑 배경 `#EAF2FA`.
- disabled: 불투명도만 낮추지 말고 텍스트와 배경을 함께 비활성 팔레트로 변경한다.
- 전환 시간은 `120–180ms`, `ease-out`.
- 캘린더에서 현재 시각을 표현할 때는 `2px` 파란 선과 작은 원점을 사용한다.


## 9. 구현 체크리스트

- [ ] 앱은 차가운 회백색 캔버스 위 중앙 프레임으로 보이는가?
- [ ] 사이드바와 메인의 명도 차이가 분명하지만 과하지 않은가?
- [ ] 파란색이 주요 액션과 현재 상태에만 쓰였는가?
- [ ] 카드 구분이 강한 그림자보다 얇은 선과 여백으로 이루어졌는가?
- [ ] 월간 그리드가 첫눈에 읽히고 일정명이 과도하게 잘리지 않는가?
- [ ] hover, focus, selected, disabled 상태가 모두 구분되는가?
- [ ] 모바일에서 탐색과 일정 확인이 키보드 및 터치로 가능한가?

이 문서는 레퍼런스의 특정 서비스 구조를 복제하는 명세가 아니라, 그 이미지의 색상·크기·레이아웃 언어를 캘린더 앱에 일관되게 적용하기 위한 디자인 기준이다.
