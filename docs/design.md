# AI-Challenge: 디자인 시스템 (Design System)

**작성일**: 2026-07-09  
**상태**: 🔄 팀 논의 중 (Design System 초안)  
**참고**: 레퍼런스 이미지 "음성진천평생교육플랫폼" 기반 도출  
**적용 상태**: 아직 미적용 — 팀 논의 후 결정 예정

---

## 📋 개요

본 디자인 시스템은 "AI-Challenge: 취업비서" 프로젝트의 시각적/상호작용 기준을 정의합니다.  
레퍼런스 이미지(공공기관형 교육 플랫폼)에서 추출한 디자인 어휘를 취업비서의 4개 핵심 기능(공고추천, 자소서 지원, 면접 준비, 일정 관리)에 재적용하는 방식으로 구성했습니다.

### 레퍼런스 이미지 분석 요약
- **색감**: 신뢰감 있는 네이비(#1e3a8a~#2c5282) + 민트/그린 포인트(#06b6d4~#10b981)
- **형태**: 둥근 모서리 카드, 큰 배경 영역 안에 콘텐츠 배치(캐러셀 패턴)
- **콘텐츠**: 일러스트 활용, 정보 밀도 높은 공공서비스 레이아웃
- **섹션 구성**: Quick Service(6개 아이콘), 프로그램 캐러셀(큰 카드), 지도+탭 결합, 후기 그리드
- **타이포그래피**: 명확한 계층 구조, 큼직한 헤딩, 친숙한 한글 웹폰트

## 🔤 타이포그래피

### 폰트 스택

```css
/* 한글 (웹폰트) */
font-family: 'Pretendard', 'Noto Sans KR', 'Segoe UI', sans-serif;

/* 영문 */
font-family: 'Inter', 'Segoe UI', sans-serif;

/* Fallback */
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

### 타이포그래피 스케일

| 용도 | 크기 | 굵기 | 행높이 | 예시 |
|------|------|------|--------|------|
| **Display (초대형)** | 48px | 700 | 1.2 | 페이지 제목, 히어로 텍스트 |
| **Heading 1** | 36px | 700 | 1.3 | 섹션 제목 |
| **Heading 2** | 28px | 600 | 1.35 | 소섹션 제목 |
| **Heading 3** | 24px | 600 | 1.4 | 카드 제목, 기능명 |
| **Body Large** | 16px | 400 | 1.5 | 본문 텍스트 |
| **Body** | 14px | 400 | 1.6 | 일반 텍스트 |
| **Body Small** | 12px | 400 | 1.5 | 보조 텍스트, 캡션 |
| **Label** | 12px | 600 | 1.4 | 라벨, 배지 텍스트 |

### 사용 예시

```markdown
# 페이지 타이틀 (Display)
## 섹션 타이틀 (Heading 1)
### 기능명/카드 제목 (Heading 3)
일반 본문은 Body 크기로 (14px, 400 weight)
보조 정보는 Body Small (12px)
```

## 🧩 컴포넌트 토큰

### 라운딩 (Border Radius)

| 이름 | 값 | 용도 |
|------|-----|------|
| **sharp** | 0px | 선형 요소 (거의 미사용) |
| **xs** | 4px | 작은 버튼, 배지, 입력창 |
| **sm** | 8px | 카드, 아이콘 박스 |
| **md** | 12px | 표준 카드, 모달 |
| **lg** | 16px | 큰 섹션 배경, 캐러셀 배경 |
| **xl** | 24px | 초대형 카드, 히어로 섹션 |
| **full** | 9999px | Pill 모양 버튼, 배지 |

### 그림자 (Shadows)

| 이름 | CSS 값 | 용도 |
|------|--------|------|
| **sm** | `0 1px 2px rgba(0,0,0,0.05)` | 카드 미세한 깊이 |
| **md** | `0 4px 6px rgba(0,0,0,0.1)` | 기본 카드, 버튼 |
| **lg** | `0 10px 15px rgba(0,0,0,0.15)` | 모달, 팝오버 |
| **xl** | `0 20px 25px rgba(0,0,0,0.2)` | 캐러셀 배경 |

## 📐 레이아웃 패턴

### 1. 히어로 섹션 (Hero Section)

**용도**: 페이지 최상단, 메인 메시지 전달  
**특징**: 큰 배경(네이비), 일러스트 또는 아이콘, 명확한 헤딩

```
┌─────────────────────────────────────┐
│  [배경: Navy #1e3a8a]               │
│                                     │
│    🎯 메인 타이틀 (Display)         │
│    부제목 (Body Large)              │
│                                     │
│    [일러스트 또는 아이콘]           │
│                                     │
│    [CTA 버튼 (Mint)]                │
└─────────────────────────────────────┘
```

**사용처**: 공고 추천 시작 페이지, 자소서 초안 생성 시작 페이지

---

### 2. Quick Service 그리드 (6개 아이콘 + 라벨)

**용도**: 주요 기능 빠른 접근  
**특징**: 2×3 또는 3×2 그리드, 아이콘 + 라벨, 호버 상태

```
┌──────┐  ┌──────┐  ┌──────┐
│ 📄   │  │ 💼   │  │ 🎤   │
│자소서 │  │공고추천│ │면접준비│
└──────┘  └──────┘  └──────┘

┌──────┐  ┌──────┐  ┌──────┐
│ 📅   │  │ ⭐   │  │ 📌   │
│일정관리 │  │북마크 │  │저장함 │
└──────┘  └──────┘  └──────┘
```

**구현**: 
- 카드 크기: 100×120px 이상
- 아이콘: 32×32px, 중앙 정렬
- 라벨: Body Small (12px)
- 호버: 배경색 → Gray 100, 보더 → Mint 500

**사용처**: 대시보드/홈 페이지, 섹션 상단 네비게이션

---

### 3. 카드 캐러셀 (Card Carousel)

**용도**: 공고 목록, 자소서 버전 관리, 면접 질문 세트  
**특징**: 큰 배경 영역, 카드 좌우 스크롤, 페이지네이션 점

```
┌─────────────────────────────────────────────┐
│  [배경: Navy #1e3a8a, border-radius: 24px] │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │ 카드 1   │  │ 카드 2   │  │ 카드 3   │ │
│  │ (화면)   │  │(숨김)    │  │(숨김)    │ │
│  └──────────┘  └──────────┘  └──────────┘ │
│                                             │
│     ◀︎  ●  ○  ○  ▶︎                      │
│                                             │
└─────────────────────────────────────────────┘
```

**구현**:
- 배경: Navy #1e3a8a, border-radius 24px, padding 24px
- 카드: 흰색, border-radius 12px, 고정 폭 (280px~400px)
- 스크롤: 좌우 화살표 버튼 또는 터치 드래그
- 페이지네이션: 검정 점(●), 회색 점(○)

**사용처**: 
- 공고 추천 결과 (카드: 회사명/직무/적합도/추천 이유)
- 자소서 버전 관리 (카드: 회사명/작성일/수정 상태)
- 면접 질문 세트 (카드: 질문/난이도/중요도)

---

### 4. 탭 + 지도/리스트 결합 섹션

**용도**: 지역별 공고 분류, 기업 정보 필터링  
**특징**: 좌측 탭 (지역/카테고리), 우측 지도/리스트

```
┌────────────────────────────────────────┐
│ 탭 선택 영역                            │
│ [서울] [경기] [인천] [지역선택]          │
│                                        │
├──────────────┬──────────────────────┤
│  필터 패널   │   지도 또는 리스트    │
│  - 회사규모  │   ▲                  │
│  - 급여      │   │ 서울 지도        │
│  - 기술스택  │   │ (경계선 표시)    │
│              │   ▼                  │
└──────────────┴──────────────────────┘
```

**구현**:
- 탭: Navy 배경, 선택 탭 → Mint 밑줄 또는 Navy 600 배경
- 필터: 체크박스, 라디오버튼, 슬라이더
- 지도: 경계선 표시, 핀 마커 (Mint 아이콘)

**사용처**: 공고 지역/산업 필터링 페이지

---

### 5. 후기/평가 카드 그리드

**용도**: 사용자 후기, 성공 사례  
**특징**: 3열 그리드 (반응형 2열/1열), 별점, 텍스트, 사용자명

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│              │  │              │  │              │
│  ⭐⭐⭐⭐⭐ │  │  ⭐⭐⭐⭐   │  │  ⭐⭐⭐     │
│              │  │              │  │              │
│ "이 서비스가  │  │ "면접 준비   │  │ "자소서 첨삭  │
│  정말 도움   │  │  정말 효과   │  │  기능이 최고" │
│  됐어요"     │  │  적이었어요" │  │ - 김준호      │
│              │  │              │  │              │
│ - 이순신     │  │ - 장보고     │  │              │
│   2026.07   │  │   2026.06   │  │              │
│              │  │              │  │              │
└──────────────┘  └──────────────┘  └──────────────┘
```

**구현**:
- 카드: border-radius 12px, padding 20px, box-shadow md
- 별점: 노란색(#fbbf24), 크기 16px
- 텍스트: Body 크기 (14px), 회색 (Gray 600)

**사용처**: 홈 페이지, 랜딩 페이지 후기 섹션

### 6. 정보 테이블 / 비교 표

**용도**: 공고 상세정보, 자소서 버전 비교, 면접 질문 난이도 표  
**특징**: 명확한 행/열 분리, 헤더는 Navy 배경, 행 호버

```
┌────────────────┬──────────────┬──────────────┐
│ 항목 (Navy)    │ 값 1         │ 값 2         │
├────────────────┼──────────────┼──────────────┤
│ 회사명         │ ABC Corp     │ XYZ Inc      │
│ 직급/직무      │ Junior Dev   │ DevOps Engr  │
│ 급여           │ 3,500~4,500  │ 4,000~5,000  │
│ 근무지역       │ 서울 강남    │ 서울 여의도  │
│ 기술스택       │ Python, Go   │ Java, Kotlin │
└────────────────┴──────────────┴──────────────┘
```

**구현**:
- 헤더 배경: Navy #1e3a8a, 텍스트 흰색
- 행 호버: Gray 50 배경
- 보더: Gray 300 (1px solid)
- 셀 패딩: 12px 16px

## 🔗 기능별 레이아웃 매핑

레퍼런스의 각 섹션을 취업비서 프로젝트의 기능과 대응시킨 적용 가이드:

| 레퍼런스 섹션 | 패턴 | 취업비서 기능 | 예상 콘텐츠 |
|---|---|---|---|
| **Quick Service** | 6개 아이콘 그리드 | 대시보드 메인 메뉴 | 공고추천, 자소서, 면접준비, 일정, 북마크, 저장함 |
| **프로그램 캐러셀** | 큰 배경 안 카드 좌우 스크롤 | 공고/자소서/면접 목록 | 공고카드(적합도+이유), 자소서버전(수정상태), 면접질문세트 |
| **지도+탭** | 탭 필터 + 지도/리스트 | 공고 지역/산업 필터 | 지역별/직무별 공고 분류 |
| **후기 카드** | 3열 그리드 (별점+텍스트) | 사용자 후기/성공사례 | "이 서비스로 3개 기업 동시 지원 성공!" |
| **정보 테이블** | 행/열 정렬된 데이터 표 | 공고 상세정보, 자소서 버전 비교 | 회사/직무/급여/지역 정보 비교 |

## 🎯 컴포넌트 사용 체크리스트

각 페이지별 권장 컴포넌트 조합:

### 📄 공고 추천 페이지
- [ ] 히어로 섹션 (페이지 진입)
- [ ] Quick Service 그리드 (필터 옵션: 회사규모/지역/급여 등)
- [ ] 카드 캐러셀 (추천 공고 목록, 적합도 점수 표시)
- [ ] 탭+지도 (지역별 분류, 선택사항)

### 📝 자소서 작성 페이지
- [ ] 히어로 섹션 (페이지 진입)
- [ ] 타이틀 + 선택한 공고 정보 표시
- [ ] 카드 캐러셀 (자소서 버전 관리: v1/v2/v3...)
- [ ] 입력 폼 (텍스트 에디터, 버튼)
- [ ] 테이블 (첨삭 이력 비교, 선택사항)

### 🎤 면접 준비 페이지
- [ ] 히어로 섹션 (페이지 진입)
- [ ] Quick Service 그리드 (질문 난이도별 필터)

## 📝 적용 시 유의사항

### 1. 기존 프로토타입과의 관계
- 현재 HTML 프로토타입(`index.html`, `prototype_*.html`)은 **보라색 그라데이션(#667eea~#764ba2)** 톤
- 본 디자인 시스템(네이비/민트)은 **별도의 목표 설정**
- **아직 프로토타입에 적용되지 않음** — 팀 논의 후 결정 예정

### 2. 레퍼런스 이미지 적용 시 주의점
- 참고는 **패턴/구조/색감 방향**
- 콘텐츠는 **취업비서 서비스에 맞게 재해석** (예: Quick Service는 공공기관의 6가지 민원 → 취업비서의 4가지 기능 + 북마크/저장함)
- 일러스트 스타일: 참고용, 최종 일러스트는 프로젝트 맥락에 맞게 제작

### 3. 구현 시 단계별 진행
1. **Phase 1 (공고 추천)**: 히어로 + 캐러셀 패턴 검증
2. **Phase 2 (자소서 지원)**: 탭/입력폼 컴포넌트 추가
3. **Phase 3 (면접 준비)**: 배지/타임라인 추가
4. **Phase 4 (일정 관리)**: 캘린더 컴포넌트 추가

### 4. 반응형 설계
- **Desktop**: 전체 레이아웃 최적화 (캐러셀, 3열 그리드)
- **Tablet**: 2열 그리드, 캐러셀 유지, 탭 수평 스크롤
- **Mobile**: 1열, 캐러셀 스와이프, 탭 축소 → 드롭다운
