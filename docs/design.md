# 디자인 시스템

## 1. 전체적인 분위기와 디자인 키워드
- 차분하고 정돈된 학습 플래너 스타일
- 깨끗한 화이트 기반 위에 파스텔 블루와 약간의 소프트 핑크를 섞은 분위기
- 깔끔한 카드형 레이아웃, 충분한 여백과 구획화된 정보 배치
- 학습 계획과 일정 관리를 직관적으로 보여주는 미니멀 플래너 느낌
- 안정감 있는 타이포그래피와 부드러운 컬러 대비

## 2. 주요 색상, 배경색, 텍스트 색상, 강조색
- 전체 배경: 매우 밝은 블루/화이트 톤
- 카드/패널 배경: 밝은 화이트, 엷은 블루 톤 배경
- 주요 텍스트: 진한 네이비/다크 블루 계열
- 보조 텍스트: 중간 그레이 블루
- 강조색: 소프트 파스텔 블루, 연한 피치/핑크
- 분홍색은 섹션 구분용 보조 색상으로만 사용하고, 개별 시험이나 항목을 구분하는 메인 강조색으로 쓰지 않음
- 구분선 및 보더: 연한 블루-그레이

## 3. 제목, 소제목, 본문의 타이포그래피
- 페이지 제목: 세리프 계열 서체로 깊이 있고 플래너 커버 같은 분위기
- 본문/버튼/메뉴: 산세리프 계열로 가독성 높고 현대적인 UI 표현
- 소제목: 본문보다 약간 큰 크기, 중간 굵기, 안정적인 계층 구조
- 본문: 읽기 쉬운 기본 크기, 적당한 줄 높이와 명확한 컬러 대비
- 상태/요약 텍스트: 작은 크기, 공간을 차지하지 않도록 세련되게 처리

## 4. 카드의 배경, 테두리, 모서리, 그림자
- 카드 배경: 대부분 흰색 또는 연한 파란색 톤의 플랫 컬러
- 테두리: 매우 얇은 라인, 연한 블루-그레이로 가벼운 구획감 부여
- 모서리: 일반 카드 8px, 작은 태그 4px, 표와 시간표 0~4px

## 5. 레이아웃 특징
- 상단 이미지 콜라주: 카드 형태보다는 플래너의 시각적 모티브로 가볍게 배치
- 왼쪽 보조 패널과 오른쪽 메인 콘텐츠로 정보 흐름 분리
- 얇은 배경 띠 형태의 섹션 제목으로 종이 플래너의 구획 느낌 전달
- 표와 일정 중심의 정보 구조로 학습 계획과 시간표를 강조
- 모바일에서는 단일 열로 전환해 한 화면에 한 섹션씩 보여줌

## 5. 추가 UI 흐름 및 네비게이션 원칙
- 여러 단계로 진행되는 화면에는 현재 단계와 전체 단계를 명시적으로 표시한다 (예: STEP 1/2 형태의 진행 표시).
- 주요 화면에는 상단 내비게이션을 둘 수 있으며, 현재 위치가 분명하게 보이도록 한다 (탭이나 강조된 텍스트 등).
- 시험 선택 카드에는 시험의 특성을 빠르게 파악할 수 있도록 직관적인 아이콘을 사용할 수 있다. 단, 아이콘은 장식적이지 않고 의미 전달에만 사용한다.
- 다음 입력 단계에서는 사용자가 앞에서 선택한 시험을 상단 요약 영역에 다시 보여준다(선택한 시험 이름·간단 정보 표시).
- 시험일 입력에는 텍스트 입력보다 날짜 선택기(Date picker)를 우선 사용한다.
- 주요 행동 버튼(예: 다음, 생성하기)은 화면마다 하나만 명확하게 강조하고, 이전(Back) 버튼은 보조 버튼으로 처리한다.
- 사용자가 ‘처음 응시’ 등 특정 옵션을 선택하면, 불필요한 입력 항목(예: 현재 점수 입력)은 숨겨서 폼을 단순화한다.

**중요한 지침**
- Google Stitch에서 참고한 화면 구조(여러 단계 표기, 상단 요약 등)는 참고하되, Stitch의 색상과 타이포그래피를 그대로 사용하지 않는다.
- 기존의 파스텔 하늘색/흰색/진한 네이비 중심 디자인은 유지한다.
- 연한 분홍색은 본문 글자색으로 사용하지 않고, 섹션 구분용 배경이나 보조 박스에만 사용한다.
- `docs/design.md` 외의 파일은 이 규칙을 추가하는 작업에서 수정하지 않는다.

## 6. 화면 여백과 요소 사이 간격
- 레이아웃 전체: 넉넉한 외부 마진과 패딩으로 숨 쉴 공간 확보
- 카드 내부: 충분한 패딩으로 내용과 경계 분리
- 섹션 간 간격: 상하 여백이 일정하고 분명히 분리
- 요소 간 간격: 라벨/텍스트, 버튼, 테이블 아이템 간 여유 있는 간격

## 7. 섹션 제목과 구분선 표현 방식
- 섹션 제목: 심플한 서체, 적당한 크기, 상단 여백 확보
- 얇은 배경 띠 형태의 섹션 제목으로 플래너 구획 느낌 강화
- 구분선: 연한 라인 또는 같은 색조의 배경 블록을 활용한 시각적 구분
- 탭이나 필터: 배경색 전환과 경계선을 통한 상태 구분

## 8. 일정, 목록, 표, 진행 상태 표현 방식
- 일정: 카드나 표 형태로 시간/과목을 일목요연하게 배치
- 목록: 체크박스와 텍스트를 좌우로 정렬한 심플한 리스트
- 표: 행과 열이 명확한 그리드, 헤더와 셀 간 적당한 패딩
- 진행 상태: 색조가 약한 배경에 텍스트 태그 형태로 표현, 완료/진행/미시작 상태를 구분

## 9. 반응형 화면에서 유지할 원칙
- 카드 기반 구조 유지: 넓은 화면에서는 2~3단 그리드, 좁은 화면에서는 단일 열 스택
- 여백과 패딩을 유지하여 정보가 빽빽해지지 않도록 함
- 주요 정보(오늘 계획, 시험 일정, 진행 상태)는 우선순위에 따라 상단 또는 앞쪽에 노출
- 타이포그래피 크기와 버튼/태그 가독성 유지

## 10. 이미지 사용 원칙
- 공부, 책, 문구류 관련 이미지 색감과 채도를 통일해 전체 분위기와 조화
- 이미지가 콘텐츠를 압도하지 않도록 낮은 대비와 연한 톤을 사용
- 배경 장식 역할로 활용하고, 정보성 콘텐츠가 우선 보이도록 배치
- 플래너 느낌을 살리는 작은 콜라주 형태를 상단에 둠

## 11. 우리 어학시험 학습 계획 서비스에 적용할 방법
- 시험 선택과 목표 입력 화면을 깔끔한 카드 형태로 구성
- 취약 영역 분석, 오늘 계획, 과제, 시간표를 각 섹션 카드로 나누어 배치
- 전체 일정과 현재 학습 상태를 한눈에 볼 수 있도록 정보 블록을 분리
- 강조 요소는 파란색/핑크 계열의 라벨과 배경으로 처리해 시선 유도
- 학습 진행률 및 상태 표시를 카드 내부 태그 형태로 구현

## 12. 피해야 할 디자인 방식
- 과도한 그래디언트나 강한 대비 색상 사용은 지양
- 학습 진행률 바를 제외한 요소에서는 그래디언트를 사용하지 않음
- 텍스트와 배경이 충분히 분리되지 않는 채도가 낮은 컬러 사용 금지
- 카드와 섹션 간 간격을 줄여서 답답해 보이게 만드는 설계 금지
- 복잡한 장식 요소, 그림자 과다 사용, 비일관적인 타이포그래피 혼합 금지

## 13. 상호작용 상태
- 선택된 항목만 선택 상태를 표시하고, 다른 시험 카드와 동일한 기본 형태를 유지함
- 같은 수준의 병렬 항목은 같은 스타일을 사용하고, 상태 차이는 텍스트 태그로만 구분함
- D-Day처럼 중요한 요약 정보는 큰 단색 블록으로 강조한다
- 동일한 정보를 화면에서 반복하지 않는다
- 상태 색상은 완료, 진행 중, 예정처럼 명확한 의미와 연결한다
- 완료 상태는 체크와 연계되어 가벼운 취소선 또는 배경 변화로 표현한다
- hover 상태는 과도한 이동 없이 가볍게 표현
- 버튼과 입력창에는 명확한 focus 표시를 둠
- disabled 상태는 낮은 대비와 흐릿한 텍스트로 구분
- 상태를 색상만으로 표현하지 않음
