- 🔵 **블루 = 학습·집중** (설문, 추천 공부법, 주 CTA)
- 🟢 **그린/민트 = 회복·루틴** (스트레스·회복 영역, 완료·저장)

## 1. 디자인 원칙

1. **차분한 집중감**: 자극적 대비 대신 연한 배경 + 부드러운 그림자로 오래 봐도 편한 화면.
2. **가독성 최우선**: 본문 16px 이상, 대비 AA 이상, 한 줄 length 제한, 색만으로 정보 전달 금지.
3. **위계로 안내**: eyebrow(맥락) → 제목(핵심) → 본문(설명) → CTA(행동)의 반복 리듬.
4. **가능성의 톤**: 카피는 단정 대신 "~할 수 있습니다", "현재 응답 기준으로는".
5. **한 화면 한 목적**: 각 단계는 하나의 결정만 요구. 정보량은 핵심부터.
6. **작은 실행 유도**: 결과의 종착점은 항상 "오늘 20~30분" 실천 카드.
7. **평가 대상 구분**: 1~5 피드백은 사용자가 아니라 추천의 현재 적합도를 평가하며, 저장 위치와 삭제 방법을 함께 안내.
8. **입력 출처 구분**: 공식 결과 직접 입력과 공식 결과 없음 경로를 시각적으로 분리하고, 탐색 코드를 공식 판정처럼 강조하지 않는다.

## 2. 컬러 토큰

의미 기반 토큰을 CSS 변수로 정의한다. 라이트가 기본, `prefers-color-scheme: dark`로 다크 대응.

```css
:root {
  /* 배경 / 표면 */
  --bg: #eef2f6;             /* 앱 배경(연 블루그레이) */
  --surface: #ffffff;        /* 카드 기본 */
  --surface-muted: #f4f7fb;  /* 보조 카드·트랙 */

  /* 파스텔 강조 카드 (학습=블루 / 회복=그린 / 보조=라벤더) */
  --tint-blue: #e7eefc;  --on-tint-blue: #2c5fd0;
  --tint-green: #e3f4ec; --on-tint-green: #1f7a54;
  --tint-lav: #ecebfb;   --on-tint-lav: #5b53c6;

  /* 브랜드 포인트 */
  --primary: #3b7dee;        /* 학습·집중, 주 CTA */
  --primary-strong: #2f66c9; /* hover/active */
  --on-primary: #ffffff;
  --accent: #2fb37a;         /* 회복·완료 */
  --accent-strong: #24936a;
  --on-accent: #ffffff;

  /* 텍스트 3단계 */
  --text-strong: #1a2230;    /* 제목 */
  --text: #4a5568;           /* 본문 */
  --text-muted: #8a93a3;     /* eyebrow·caption */

  /* 경계 / 상태 */
  --border: #e2e8f1;
  --border-soft: #eef1f6;
  --focus: #3b7dee;

  /* 그림자 */
  --shadow-sm: 0 1px 3px rgba(27, 45, 76, .06), 0 1px 2px rgba(27, 45, 76, .04);
  --shadow-md: 0 8px 24px rgba(27, 45, 76, .08);
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #10151c;
    --surface: #182029;
    --surface-muted: #1e2732;
    --tint-blue: #1b2942;  --on-tint-blue: #9dbcf6;
    --tint-green: #16311f; --on-tint-green: #74d3a4;
    --tint-lav: #24234a;   --on-tint-lav: #b6b0f5;
    --primary: #5a97f2;    --primary-strong: #78abf6; --on-primary: #0c1119;
    --accent: #43c491;     --accent-strong: #63d3a6;  --on-accent: #0c1119;
    --text-strong: #eef2f7; --text: #b3bccb; --text-muted: #7d8798;
    --border: #2a343f; --border-soft: #222b35; --focus: #5a97f2;
    --shadow-sm: 0 1px 3px rgba(0, 0, 0, .4);
    --shadow-md: 0 10px 28px rgba(0, 0, 0, .45);
  }
}
```

**사용 규칙**
- 배경은 `--bg`, 정보 블록은 `--surface` 카드. 강조 카드에만 파스텔 tint.
- 주 행동(다음/시작/결과 보기)은 `--primary`. 완료·저장·회복은 `--accent`.
- 빨강/노랑 경고색은 **위험군·오류 톤을 유발하므로 결과 표현에 쓰지 않는다**(폼 검증 안내 정도만 예외).

## 3. 타이포그래피

외부 폰트는 로드하지 않는다(추가 의존성·CSP 회피). 시스템 폰트 스택 사용.

```css
--font: -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Segoe UI",
        Roboto, "Malgun Gothic", system-ui, sans-serif;
```

| 역할 | 크기 | 굵기 | 행간 | 색 | 비고 |
| --- | --- | --- | --- | --- | --- |
| eyebrow | 13px | 700 | 1.3 | `--text-muted` 또는 tint 색 | letter-spacing .04em |
| h1 | clamp(30px, 6vw, 52px) | 800 | 1.08 | `--text-strong` | 랜딩 히어로 |
| h2 | clamp(22px, 3vw, 32px) | 800 | 1.15 | `--text-strong` | 단계 제목 |
| h3 | 18px | 700 | 1.3 | `--text-strong` | 카드 제목 |
| body | 16px | 400 | 1.6 | `--text` | 기본 본문 |
| lead | 18px | 400 | 1.6 | `--text` | 히어로 설명 |
| caption | 13px | 600 | 1.4 | `--text-muted` | 칩·보조 |

- **부분 컬러 강조**: 제목 안 핵심 단어에만 `--primary`/`--accent`를 `<strong>`으로. 문장 전체 컬러 금지.
- 반응형: 1024px 이하에서 본문 16px 유지, 제목은 clamp로 자동 축소.

## 4. 스페이싱 · 라운드 · 섀도

```css
:root {
  --space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
  --space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px;

  --r-sm: 10px;   /* 칩 내부·작은 요소 */
  --r-md: 14px;   /* 버튼·옵션 카드 */
  --r-lg: 20px;   /* 카드·패널 */
  --r-pill: 999px;/* 진행 dot·칩·pill 버튼 */
}
```

- 카드 내부 패딩: 모바일 20px, 데스크톱 24px.
- 섹션 간 간격: 24~32px. 카드 사이 간격: 12~16px.
- 그림자는 `--shadow-sm` 기본, 히어로/떠 있는 요소만 `--shadow-md`. 과한 그림자 지양.

## 5. 레이아웃

- **모바일 우선**. 콘텐츠 최대 폭 `min(720px, 100% - 32px)` 중앙 정렬(설문·결과는 읽기 편한 단일 컬럼 기준).
  넓은 화면에서 결과/루틴만 2컬럼 그리드 허용(`minmax(0,1fr)` 반복, 860px 이하 1컬럼).
- **구조 리듬**: 상단 브랜드/상태 → 진행 표시 → 카드형 단계 패널 → 하단 CTA.
- 섹션 = `eyebrow + 제목 + (본문) + 콘텐츠`. 가로스크롤 카드 리스트는 `overflow-x:auto` 컨테이너로.
- 페이지 자체는 가로 스크롤 금지. 넓은 표/카드는 자체 스크롤 박스로 감싼다.

## 6. 컴포넌트 패턴

### 버튼
- **Primary**: `background:var(--primary); color:var(--on-primary)`; radius `--r-md`; padding 12–14px 16px; min-height 46px; hover→`--primary-strong`. 주 흐름 CTA는 폭을 넓게(모바일 풀폭).
- **Accent**: 완료·저장·회복 행동. `--accent` 사용.
- **Secondary(tonal)**: `background:var(--surface-muted); color:var(--text-strong); border:1px solid var(--border)`.
- **Ghost/link**: 배경 없음, `--primary` 텍스트. "이용안내"류 보조 링크.
- `:disabled` opacity .45. `:focus-visible` → 2px `--focus` 아웃라인(offset 2px). 모든 버튼 최소 44px 탭 타깃.

### 카드
- 기본: `background:var(--surface); border:1px solid var(--border); border-radius:var(--r-lg); box-shadow:var(--shadow-sm); padding 20–24px`.
- 강조 카드: 위 tint 토큰(`--tint-*` 배경 + `--on-tint-*` 라벨). 학습=블루, 회복=그린.

### 옵션 카드 (설문 선택 · `.option-card`)
- 기본: surface + `--border`, radius `--r-md`, 좌측 정렬, min-height 54px, 굵기 600.
- 선택/hover: `border-color:var(--primary); background:var(--tint-blue); color:var(--on-tint-blue)`.
- 선택 상태는 색+테두리+(체크/굵기)로 **색만 의존하지 않게** 표시.

### 진행 표시 (`.progress`)
- pill dot 나열. 완료·현재 단계 = `--primary` 채움 + 흰 텍스트, 이후 = surface + `--border`.
- `aria-label`로 현재 단계 안내.

### 지표 막대 (`.score-row` / 결과)
- 트랙 `--surface-muted`, 채움은 블루→그린 그라데이션 또는 `--primary`.
- 라벨 + "N점"을 함께 표기. **"점수는 평가가 아니라 추천 방향 신호"** 문구를 결과 카드에 명시.
- 상위 5개만 노출(정보량 절제).

### 추천/정보 카드 (`.method`, 결과 하위 블록)
- 제목(strong) + 이유(reason) + 실행(action). "왜 추천됐는지"를 항상 함께.

### 실천 카드 (routine)
- "오늘의 상태 요약 → 20~30분 공부 루틴 → 회복 루틴 → 완료 체크 → 집중도/피로도 기록".
- 완료 체크·저장은 `--accent`.

### 칩 (`.chip` / `.answer-chip`)
- pill, tint 배경 + tint-on 텍스트, caption 크기. 선택 응답·개수 표기용.

### 툴팁 말풍선
- surface 배경 + `--shadow-sm` + 작은 꼬리. 앞에 💡 이모지. 짧은 힌트 1줄. 필수 정보는 툴팁에 숨기지 않는다.

## 8. 접근성 · 가독성 규칙

- 본문 대비 4.5:1, 큰 제목 3:1 이상. tint 배경 위 텍스트는 `--on-tint-*` 사용.
- 색만으로 상태를 전달하지 않는다(선택=테두리+굵기 병행, 신호=텍스트 병행).
- 포커스 링 항상 노출(`:focus-visible`). 탭 타깃 44px 이상.
- 이미지·아이콘에 의미가 있으면 대체 텍스트/`aria-label`.
- 다크 모드에서도 동일 위계·대비 유지.

## 9. 의도 일치 자기점검 체크리스트 (디자인 스킬)

**A. 컨셉·색상**
- [ ] 배경=연 블루그레이, 정보=화이트/파스텔 카드 구조인가
- [ ] 블루=학습, 그린/민트=회복 의미 매핑이 지켜졌는가
- [ ] 파스텔·포인트 색이 과하지 않고 차분한가(경고색 남용 없음)

**B. 크기·타이포**
- [ ] eyebrow → 굵은 제목 → 회색 본문 위계가 분명한가
- [ ] 본문 16px+ / 대비 AA / 부분 컬러 강조만 사용했는가
- [ ] 카드 라운드·여백·그림자 토큰을 일관되게 썼는가

**C. 레이아웃**
- [ ] 모바일에서 단일 컬럼으로 읽기 편한가, 가로 스크롤 없는가
- [ ] 각 화면이 하나의 목적/결정에 집중하는가
- [ ] 결과의 종착점이 "오늘 20~30분 실천 카드"로 이어지는가

**D. 표현 원칙 (필수)**
- [ ] MBTI를 고정 판정처럼 보이게 하는 시각 요소가 없는가
- [ ] 스트레스가 진단·치료·위험군처럼 보이는 요소(경고색·심각도)가 없는가
- [ ] 비교·랭킹·등급·순위·점수 우열 시각화가 없는가
- [ ] 점수 막대에 "평가가 아닌 추천 신호" 맥락이 있는가
- [ ] 추천 적합도 1~5가 사용자 등급이 아니라 추천 시스템 평가임을 명시했는가
- [ ] 피드백 저장 위치와 앱 내 삭제 경로가 안내되어 있는가
- [ ] 공식 결과 입력과 자체 탐색 신호가 혼동되지 않는가
- [ ] baseline과 MBTI 추가 결과의 차이를 효과 향상으로 단정하지 않는가

**E. 접근성**
- [ ] 색만으로 상태를 전달하지 않는가
- [ ] 포커스 링·탭 타깃(44px)·다크 모드 대비가 유지되는가
