# SpendMate 디자인 가이드

프론트엔드 프로토타입(SpendMate 모바일 앱 디자인, React + Vite, Figma Make export)에서 확정된 디자인 언어. API 응답 필드(카테고리, 금액 단위 등)를 설계하거나 백엔드에서 프론트가 그대로 쓸 값을 내려줄 때 이 문서 기준을 따른다. 프론트 프로토타입 자체를 수정할 때는 해당 프로젝트의 `spendmate-design-rules` 스킬(`.claude/skills/spendmate-design-rules/SKILL.md`)이 더 상세하니 그쪽을 우선 참고.

## 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--primary` | `#4F8EF7` | 브랜드 블루 — CTA, 활성 네비, 링크 |
| `--primary-light` | `#EBF2FF` | 프라이머리 아이콘/뱃지 배경 |
| `--mint` | `#6ED6C8` | 보조 액센트 — 프라이머리와 그라디언트로 페어링 |
| `--mint-light` | `#E8F8F6` | 라이트 민트 배경 |
| `--accent` | `#FFC857` | 웜 액센트 (경고, 하이라이트, 스트릭) |
| `--accent-light` | `#FFF8E8` | 라이트 액센트 배경 |
| `--background` | `#F7F8FA` | 화면 배경 |
| `--card` | `#FFFFFF` | 카드/서피스 배경 |
| `--foreground` | `#1A1D27` | 기본 텍스트 |
| `--muted` | `#6B7280` | 보조/라벨 텍스트 |
| `--border` | `#E8EAF0` | 헤어라인, 구분선 |
| `--radius` | `20px` | 기본 카드 radius |

**하드코딩 hex**: `#FF6B6B`은 danger/warning red (예산 초과, 삭제, 음수 추세). 항상 이 hex 그대로 사용.

폰트는 **Pretendard**, fallback `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`.

## Radius 스케일

| Radius | 용도 |
|---|---|
| `99` | 필 — 뱃지, 태그, 필터 칩, 원형 버튼, 프로그레스바 트랙 |
| `20` | 기본 카드, 시트, 히어로 카드 |
| `16` | 보조 카드, 큰 아이콘 컨테이너 |
| `14` | 아이콘 컨테이너, 작은 버튼 |
| `12` | 작은 아이콘 박스, 인라인 스탯 칩 |
| `10` | 아주 작은 요소 (컴팩트 뱃지/아이콘 박스) |
| `44` | 폰 목업 프레임 전용 (재사용 금지) |

## Shadow 스케일

| Shadow | 용도 |
|---|---|
| `0 2px 16px rgba(0,0,0,0.06)` / `0 2px 12px rgba(0,0,0,0.05–0.06)` | 기본 카드 셰도우 |
| `0 8px 32px rgba(79,142,247,0.35)` | 그라디언트 히어로 카드/프라이머리 CTA — RGB는 그라디언트 주색에 맞추고 alpha는 0.3–0.35 유지 |
| `0 -8px 40px rgba(0,0,0,0.15)` | 바텀시트/모달 |

## 타이포그래피 스케일

- **13px** — 기본 본문/라벨 (가장 많이 사용)
- **14–16px** — 보조 강조, 리스트 아이템 값, 섹션 서브헤딩
- **20–22px** — 화면 타이틀 (`fontWeight: 800`)
- **34px** — 히어로 넘버 (예: 홈 카드의 남은 예산) — 화면에서 가장 중요한 숫자 하나에만 사용

폰트 웨이트:
- `900` — 화면에서 가장 큰 숫자 (히어로 금액, 큰 타이틀)
- `800` — 화면 헤드라인, 카드 타이틀
- `700` — 강조 인라인 텍스트, 핵심 값
- `500–600` — 보조/서포팅 텍스트
- 400(regular)은 거의 안 씀 — 전체적으로 볼드 위주

## 그라디언트

항상 `135deg`, 팔레트에서 두 개 색을 짝지음:

- **브랜드/프라이머리 CTA/히어로 카드**: `linear-gradient(135deg, #4F8EF7, #6B5CF0)` (블루 → 퍼플)
- **AI/어시스턴트 관련**: `linear-gradient(135deg, #6ED6C8, #4F8EF7)` (민트 → 블루)
- **경고/주의**: `linear-gradient(135deg, #FFC857, #FF6B6B)` 또는 `#FFC857, #FF9500`
- **소프트 파스텔 배경** (아이콘/일러스트 뒤): `linear-gradient(135deg, #EBF2FF, #E8F8F6)`

의미(프라이머리 액션/AI 모먼트/경고)에 맞춰 고른다.

## 카테고리 컬러 매핑

| 카테고리 | 아이콘 컬러 | 배경 |
|---|---|---|
| 카페 | `#6F4E37` | `#FFF3E0` |
| 편의점 | `#4F8EF7` | `#EBF2FF` |
| 외식 | `#00C4B3` | `#E8F8F6` |
| 식료품 | `#FF6B6B` | `#FFF0F0` |
| 교통 | `#FFC857` | `#FFF8E8` |
| 쇼핑 | `#9B8FFF` | `#F0EFFF` |

새 카테고리 추가 시: 기존과 구분되는 새 아이콘 컬러를 고르고, 같은 hue의 저채도/고명도(약 20% tint) 배경을 생성. 기존 아이콘 컬러 재사용 금지, 자기 아이콘 컬러의 옅은 tint가 아닌 배경 금지.

> 백엔드 `Category` enum(`DELIVERY`, `CONVENIENCE_STORE`, `CAFE`, `MEAL_KIT`, `MART`, `CAMPUS_MEAL`, `SHOPPING`, `OTHER`)과 프론트 카테고리 라벨(카페/편의점/외식/식료품/교통/쇼핑)은 1:1로 이름이 맞지 않음 — API 설계 시 매핑 테이블 필요.

## 아이콘

`lucide-react`만 사용. 아이콘 → 의미 고정 매핑:

- `ChevronRight` — 더보기/이동
- `X` — 모달/시트 닫기
- `Check` — 확인/선택 상태
- `Plus` — 새 항목 추가 (센터 네비 버튼 모양이기도 함)
- `TrendingUp` / `TrendingDown` — 소비 증가/감소
- `Bell` — 알림
- `Camera` / `Image` — 영수증/사진 촬영 진입점
- `Sparkles` / `Zap` — "AI가 생성한 인사이트" 표시

## 레이아웃

- 앱 전체가 **393×852** 고정 프레임(`App.tsx`) 안에서 렌더링 — 물리 폰처럼 `borderRadius: 44`, 어두운 테두리, 큰 드롭섀도, 상단 페이크 상태바(`9:41` + 배터리).
- **하단 네비**: 5개 — 홈 / 통계 / **+** / AI 코치 / 마이페이지. 센터 `+`는 52×52 원형, 그라디언트, `marginTop: -16`으로 위로 튀어나와 프라이머리 액션임을 강조.
- **모달/바텀시트**: `position: fixed; inset: 0` 풀스크린 오버레이 + 다크 블러 백드롭, `borderRadius: '28px 28px 0 0'` 패널이 `slideUp 0.3s cubic-bezier(0.34,1.56,0.64,1)`로 하단에서 슬라이드업. 센터 모달은 쓰지 않음 — "상세로 들어가는" 플로우는 전부 이 패턴.

## 카피 & 톤

- 사용자 이름 뒤 `~님` 호칭 (예: "안녕하세요, 지민님 👋"), "사용자" 같은 무명 호칭 금지.
- 이모지는 자연스러운 지점에만 절제해서 사용 (👋 🍱 💬 ✨).
- **AI 코치 메시지 고정 구조**: [무엇이 바뀌었는지, 숫자 포함] → [구체적 대안] → [예상 절약액, 숫자 포함]을 1~2문장으로. 예: *"이번 주 배달비가 42% 증가했어요. 편의점 도시락으로 대체하면 주 12,000원 절약 가능해요!"*
- **가짜 확신도/확률 숫자 절대 금지** ("소진 확률 82%", "추천 신뢰도 95%" 등). 규칙 기반 추정치이지 보정된 확률이 아니므로, 실제로 계산 가능한 숫자(금액, 실제 소비 대비 비율, 일수)만 노출한다 — [plan.md](plan.md)의 Agent 판단 로직과 직결되는 제약.
