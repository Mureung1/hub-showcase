# 디자인 시스템

**출처**: 처음엔 참고 이미지(어두운 배경의 피트니스 브랜드 랜딩페이지 스타일, 주황 강조색, 굵은 헤드라인)에서 방향을 잡았다. 이후 Claude Design에서 핵심 화면 3개(오늘의 루틴 허브 · 통증 부위 선택 · 재편성 결과)를 실제로 만들면서 아래 값들로 구체화됐다. 원본 소스: `docs/diagrams/AI 운동 루틴 적응 코치/루틴 적응 코치.dc.html`. 화면 자체가 아직 검토 전이라 이후 바뀔 수 있다.

## 타이포그래피
- 헤드라인·숫자·라벨용 서체: **Oswald**(Google Fonts, weight 400~700), 자간 넓게(`.14em`~`.18em`). 영문/숫자 라벨엔 대문자 사용(`REFIT`, `TODAY`, `THIS WEEK`, 요일 eyebrow 텍스트 등)
- 한글 헤드라인(예: "오늘의 루틴", "하체 근력 세션"): 대문자 변환 대신 font-weight 800 + 자간 좁게(`-.01em`~`-.02em`)로 굵고 압축된 느낌을 낸다 — 한글엔 대문자 개념이 없어서 Oswald 대신 본문 서체 굵기로 대체하는 방식
- 본문/UI 서체: **Pretendard Variable**(한글 대응), 보조 텍스트는 연한 회색(`#9a9a9a`), 헤드라인보다 훨씬 작게
- 네비게이션: 중간 굵기(500~600). 활성 항목만 흰색+굵게, 나머지는 텍스트 보조색

## 컴포넌트 패턴
- **버튼(주 액션)**: 필 형태(`border-radius:100px`), accent 색 채움, 텍스트는 `#0d0d0d`(흰색 아님, 어두운 배경 대비용), font-weight 700
- **버튼(보조 액션)**: 같은 필 형태, 아웃라인만(`border:1px solid #2a2a2a`), 배경 투명, hover 시 테두리만 `#4a4a4a`로 밝아짐
- **배지**(추천/재편성됨 등): 버튼과 같은 필 형태의 축소판, accent 배경 + `#0d0d0d` 텍스트, 10~11px bold
- **리스트 행 선택 표시**: 지름 20~22px 원형 도트 — 선택 시 accent 테두리+accent 텍스트로 채움(●), 미선택 시 회색 테두리의 빈 원
- **카드(랜딩페이지용)**: 배경 이미지 + 어두운 그라디언트 오버레이, 하단에 제목·설명·원형 화살표 버튼(accent 색) — 마케팅성 카드에 한정, 앱 내부 카드는 아래 참고
- **요일 스트립(주간 뷰)**: 7칸 그리드, 각 칸은 요일·날짜·타겟부위·상태(완료/오늘/예정/휴식)를 세로로 쌓은 카드. 상태별 배경·테두리는 위 "서페이스 변형" 참고
- **세션 카드**: 헤더(타겟부위+총 운동수)/운동 목록(번호·이름·세트)/하단 액션(주 버튼+보조 버튼) 3단 구성, 각 구간은 `border-bottom`/`border-top`으로 구분
- **정보/고지 배너**: 둥근 사각형(`border-radius:12px`), `#151515` 배경, 원형 "i" 아이콘(테두리만, 텍스트 보조색) + 안내 문구
- **사이드바 네비**: 활성 항목 = 배경 `#1a1a1a`+테두리 `#2a2a2a`+좌측 강조 도트(accent), 비활성 항목 = 배경 없음(hover 시 `#151515`)
- **신체 부위 선택(바디맵)**: SVG 실루엣(`fill:#1e1e1e; stroke:#484848`) 위에 클릭 가능한 부위별 타원을 겹쳐, 선택 시 `fill: rgba(255,106,26,.85)` + `stroke:#ff6a1a`로 강조. 목록 선택과 항상 동기화(하나를 고르면 둘 다 갱신)
- **표(스케줄 등)**: 요일 라벨은 accent 배경, 나머지 셀은 어두운 표면색

## 모서리 반경(radius) 스케일
- `7px`: 로고 박스 같은 아주 작은 요소
- `9px`: 사이드바 네비 항목
- `11~12px`: 사이드바 하단 카드, 요일 카드
- `12~13px`: 리스트 행(운동/부위/후보 목록)
- `16~18px`: 세션 카드, 바디맵 패널 등 큰 카드
- `100px`: 버튼·배지 등 필 형태 전부

## 여백/레이아웃
- 섹션 전체를 어두운 배경 하나로 통일, 카드 사이 여백은 넉넉하게
- 히어로 영역은 좌(헤드라인+CTA) / 우(사진) 2단 구성
- 앱 내부 레이아웃: 좌측 고정 사이드바(`238px`, `position:sticky`) + 우측 메인(`max-width:1080px`)
