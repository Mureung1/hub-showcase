# 사이사이 (SaiSai) 디자인 가이드라인

본 문서는 '사이사이' 커뮤니티 앱의 일관된 디자인 유지를 위한 디자인 시스템 및 가이드라인입니다. (Prototype 11 기준)

## 1. 핵심 컨셉 (Core Concept)
- **Super App Style**: 대중적이고 친근하며 누구나 사용하기 쉬운 '국민 앱(Toss, 당근마켓 등)' 스타일.
- **Friendly & Soft**: 각진 모서리를 배제하고 둥글고 큼직한 곡률을 사용하여 부드러운 인상을 제공.
- **Clean & Floating**: 배경색과 카드색을 명확히 구분하고, 떠 있는 듯한(Floating) 컴포넌트를 활용해 세련된 입체감 부여.

## 2. 색상 팔레트 (Color Palette)

### 🎨 Background & Surface
- **App Background**: `#f4f3f1` (따뜻한 느낌의 오프화이트/라이트 그레이)
- **Card/Surface**: `#ffffff` (순백색, 앱 배경 위에서 명확하게 돋보이게 됨)

### 🎨 Brand & Accent Colors
- **Primary (퍼플/인디고)**: `#5c58b6` (브랜드 핵심 컬러. 활성 탭, 주요 버튼, FAB, 중요 배지 등에 사용)
- **Primary Light**: `#e8e8f8` (Primary 컬러의 배경/연한 버전)
- **Success/Resolved (그린)**: `#4f9a71` (도움 요청 '완료' 상태, 체크마크 등에 사용)
- **Success Light**: `#e6f3eb` (완료 배지 배경 등)

### 🎨 Typography Colors
- **Text Main**: `#111111` (제목, 주요 본문 등 가장 짙은 텍스트)
- **Text Sub**: `#777777` (설명, 부제목, 본문 등)
- **Text Light**: `#aaaaaa` (작은 메타데이터, 시간, 비활성 아이콘 등)

## 3. 타이포그래피 (Typography)
- **Font Family**: `Pretendard` (기본 산세리프 폰트)
- **특징**:
  - 제목(Heading)은 아주 두껍게(font-weight: 700~800) 처리하여 강렬한 대비를 줌.
  - 본문(Body)은 가독성을 고려하여 적절한 줄간격(line-height: 1.4~1.5) 유지.

## 4. UI 컴포넌트 형태 (Shapes & Shadows)

### 🟦 모서리 곡률 (Border Radius)
친근함을 극대화하기 위해 모서리를 아주 둥글게 처리합니다.
- **Main Cards**: `24px` (게시글·도움 요청·공동구매 카드)
- **Small Elements**: `12px` ~ `16px` (로고 아이콘, 작은 버튼, 배지 등)
- **Pills & Circles**: `40px` (플로팅 바), `50%` (프로필 아바타, FAB 버튼)

### ☁️ 그림자 (Box Shadow)
진하고 날카로운 그림자 대신, 아주 연하고 넓게 퍼지는 그림자를 사용합니다.
- **Cards**: `box-shadow: 0 4px 15px rgba(0, 0, 0, 0.03)`
- **Floating Nav Bar**: `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.08)`
- **FAB (Primary Button)**: `box-shadow: 0 4px 15px rgba(92, 88, 182, 0.4)` (Primary 컬러의 은은한 글로우 효과)

## 5. 핵심 컴포넌트 디자인 규칙

### 📌 Floating Bottom Navigation (하단 네비게이션)
- 화면 하단에 꽉 차지 않고 좌우 여백을 가진 **알약(Pill) 모양**으로 공중에 떠 있어야 함.
- 배경은 약간의 투명도(`rgba(255,255,255,0.9)`)와 블러(`backdrop-filter: blur(10px)`)를 적용해 뒤쪽 컨텐츠가 스크롤될 때 은은하게 비치도록 함.
- **Active 상태**: 아이콘만 있던 둥근 버튼이 길쭉하게 확장되며 텍스트 라벨이 노출되고, 배경색이 Primary(`#5c58b6`) 컬러로 칠해짐.

### 📌 Floating Action Button (FAB)
- 게시글 작성이나 도움 요청 시 사용하는 우측 하단의 둥근 버튼.
- Primary 컬러 배경에 하얀색 아이콘, Primary 컬러 톤의 그림자를 가져 확실한 클릭 유도(Call to Action)를 담당.

### 📌 Badges & Status (배지 및 상태 표시)
- 상태를 나타내는 배지는 둥근 형태(`border-radius: 12px` 이상)를 유지.
- 배경색은 폰트 색상의 아주 연한 톤(Light)을 깔고, 글자색은 진한 톤을 사용하여 명시성을 높임. (예: 완료 배지 배경 `#e6f3eb`, 글자 `#4f9a71`)

## 6. 아이콘 (Iconography)
- 둥글고 부드러운 앱 컨셉에 맞게 끝이 둥근(Rounded) 형태나 얇고 깔끔한(Outlined) 스타일의 아이콘 사용. (현재 Google Material Icons 활용 중)

## 7. Prototype 11 확정 레이아웃 규칙

### 📌 입장 후 앱 프레임
- 커뮤니티 입장 후 화면은 모바일 앱처럼 보이도록 `max-width: 480px` 중심 프레임을 유지합니다.
- 데스크톱 대시보드처럼 보이는 사이드바, 요약 카드 중심 레이아웃은 사용하지 않습니다.
- 기본 구조는 **상단 커뮤니티 라벨 + 배너 카드 + 리스트 카드 + Floating Bottom Navigation + FAB**입니다.

### 📌 상단 커뮤니티 헤더
- 입장 후 상단에서는 서비스명 `사이사이`를 반복 노출하지 않습니다.
- 첫 정보는 현재 커뮤니티명입니다.
- 형태는 `위치 표시 + 커뮤니티명`을 기본으로 합니다.
- 커뮤니티명은 화면의 메인 제목이 아니라 현재 위치 라벨입니다.
- 커뮤니티명은 탭 제목보다 작게 두고, 은은한 Primary Light 계열 underline/marker로 구분합니다.
- 우측 상단 액션 버튼은 기본적으로 두지 않습니다.

### 📌 화면 위계
- `자유게시판`, `도와주세요`, `공동구매` 세 탭의 제목이 각 화면의 메인 제목입니다.
- 커뮤니티명과 탭 제목이 같은 크기/무게로 보이지 않도록 합니다.
- 특히 `도와주세요`, `공동구매` 탭에서는 상단 커뮤니티 라벨과 화면 제목의 시각적 위계를 명확히 분리합니다.

### 📌 아이콘 사용 주의
- Material Icons는 폰트 로딩 실패 시 `home`, `location_on` 같은 아이콘 이름 텍스트가 노출될 수 있습니다.
- 헤더, 로고, 위치 표시처럼 첫인상을 결정하는 곳에는 Material Icons 의존을 피합니다.
- 위치 표시는 CSS로 만든 작은 핀 또는 텍스트 기반 표시를 우선합니다.

### 📌 문구 톤
- 기능 설명처럼 긴 문장보다 실제 이웃 앱에서 볼 법한 짧고 자연스러운 문구를 사용합니다.
- 예: `같이 사고 각자 나눠요`, `작은 일도 가까운 이웃에게`, `오늘의 동네생활`
- 백엔드, 결제, 인증처럼 아직 구현되지 않은 기능을 있는 것처럼 표현하지 않습니다.

## 8. 3주 MVP 화면 규칙

### 인증과 온보딩

- 로그인과 회원가입은 한 카드 안에서 tab 또는 text button으로 전환합니다.
- 주소 검색 결과는 도로명 주소를 첫 줄, 지번 주소와 건물명을 보조 정보로 표시합니다.
- 아파트·오피스텔을 선택했을 때만 동 번호 입력을 표시합니다.
- 자동 배정 성공 전에는 하단 탭과 앱 본문을 노출하지 않습니다.

### 도움 요청과 채팅

- 도움 요청 작성자에게만 `도움 완료`를 Primary 또는 Success action으로 표시합니다.
- 댓글 작성자별 `채팅하기`는 글쓴이 화면에만 표시합니다.
- 완료 상태에서는 입력 영역을 제거하고 `완료된 요청이라 새 메시지를 보낼 수 없어요` 안내를 표시합니다.
- 채팅 메시지는 내 메시지를 오른쪽 Primary Light, 상대 메시지를 왼쪽 Surface Soft bubble로 구분합니다.

### 공동구매

- `모집중`, `모집 종료`, `구매 확정`을 서로 다른 badge로 표시합니다.
- 목표 인원 도달 전에는 확정 버튼을 표시하지 않습니다.
- 확정 전에는 채팅 CTA를 표시하지 않고, 확정 참여자에게만 `참여자 채팅`을 표시합니다.
- 모든 공동구매 상세에 `예상 금액이며 정산은 사이사이 밖에서 진행해요`를 고정 노출합니다.
