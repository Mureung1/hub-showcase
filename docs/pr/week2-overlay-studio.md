# [N030_김병조] - 로컬 Vision 기반 사진 레이아웃 Agent 구현

## 주요 작업 리스트

- 사진 업로드 후 1인 또는 커플 인물 프레임, 수평선, 배경 가이드를 생성하는 React Studio 구현
- 투명 Overlay PNG와 `guide.json` 다운로드 기능 구현
- 분석 상태를 `모델 준비 → 인물 감지 → 배경 분석 → 가이드 생성` 단계로 표시
- 재사용 가능한 `analyzePhotoLayout()` 분석 모듈 분리
- GitHub Pages 자동 배포 설정 및 배포 완료

배포 주소: https://yf560.github.io/hub/overlay-studio/

## 내가 설명할 수 있는 부분

사진 분석 결과를 화면에 바로 묶지 않고 `guide.json` 형태로 만들었습니다. 그래서 Studio에서는 이를 미리보기와 다운로드에 사용하고, 이후 실제 포토스팟 상세나 카메라 화면에서는 같은 분석 함수를 호출해 오버레이 기능만 가져다 쓸 수 있습니다.

## 아직 이해 못 한 부분

MediaPipe가 사진 속 인물의 자세를 어떤 모델 구조와 기준으로 인식하는지, 그리고 복잡한 배경에서 더 정교한 윤곽선을 만들 때 어떤 Vision 모델을 추가해야 하는지는 더 학습이 필요합니다.

## 새로 알게 된 것

Vite 앱도 빌드 결과물은 HTML, CSS, JavaScript 정적 파일이므로 GitHub Pages에 배포할 수 있습니다. 다만 저장소의 Pages 설정에 따라 배포 브랜치와 하위 경로를 맞춰야 하며, 이번에는 기존 페이지를 보존하기 위해 `gh-pages/overlay-studio/` 경로에 배포했습니다.
