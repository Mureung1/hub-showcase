Why

팀플은 시작 단계에서 실패한다

문제

  • 서로 모르는 팀원들이 위계도 경험도 없이 첫 회의에서 계획·역할을 정해야 한다
  • 어색함과 눈치보기 속에 회의가 흐지부지
  • → 계획 없는 프로젝트, 불공정한 분담이 그대로 굳어진다

해법 — AI를 "중립적 중재자"로

  • 플래닝 에이전트: 주제·마감일·기피 날짜를 받아 역할 정의 + 마일스톤 + 태스크 생성
  • 역할 배정 에이전트: 비공개 설문 → 점수 기반 배정, 결과를 팀 단위로 설명
  • 아무도 하기 싫은 말을 AI가 대신 → 킥오프 15분 완성
