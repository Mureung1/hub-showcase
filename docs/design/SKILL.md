# Letter&Co Design Skill

빈티지 · 코티지 · 모리걸 무드의 협업/모임 조율 에이전트 "Letter&Co"를 위한 디자인 시스템입니다.
초대장(씨앗)에서 결산(수확)까지 이어지는 정원 여정을 모든 화면에서 일관되게 표현합니다.

## 핵심 철학

1. **감시하지 않는다** — 경고색(빨강)을 쓰지 않는다. 미완료·지연은 강조하지 않고, 완료만 조용히 쌓이게 보여준다.
2. **모든 추천엔 근거를 함께 보여준다** — AI가 뭔가를 제안하면 "왜"를 짧게 덧붙인다.
3. **장식은 화면당 하나씩** — 레이스, 개화 애니메이션처럼 화려한 요소는 화면마다 최대 1곳에만 써서 특별함을 유지한다.
4. **최종 결정은 언제나 사람이 한다** — 자동 확정 UI를 만들지 않는다.

## 1. 색상

기본 4색을 뼈대로 삼되, 아래 범위 안의 유사·파스텔 톤은 자유롭게 사용 가능합니다.

| 역할 | 기본 | 사용 가능 범위 |
|---|---|---|
| 배경(종이) | `#F3EFE6` | 그레이 베이지 계열 (`#EFEAD C`~`#F7F2E4`) |
| 구조/버튼(웨지우드) | `#8CA3C2` / 딥 `#4F6B8C` | 더스티 블루·세이지 블루 (`#7E9BB8`~`#9BB0C7`) |
| 강조(레몬) | `#F2D774` / 딥 `#8C6A1B` | 살구빛·크림 옐로우 파스텔 |
| 텍스트(잉크) | `#4A4438` | 고정 |

- 원색 파랑·형광 노랑·빨강 계열은 사용 금지 (무드 이탈)
- 한 화면 안에서는 계열별로 톤을 최대 2개까지만 섞기
- 경고·오류도 잉크브라운 톤(테두리+투명 배경)으로 표현, 빨강 대체 없음

## 2. 타이포그래피

- 영문 라벨(Invite, Gather 등): `Dancing Script` (필기체)
- 한글 제목: `Gowun Batang` — H1 28px / H2 20px / H3 16px, 줄간격 1.3배
- 한글 본문: `Gowun Dodum` — 14px, 줄간격 1.6배
- 캡션/코드성 라벨: `IBM Plex Mono` — 11px, 줄간격 1.4배
- Google Fonts CDN으로 로드

## 3. 여백 그리드

8px 기반. 4·8·12·16·24·32·48px만 사용, 임의 수치 금지.
- 카드 내부 패딩 16px / 섹션 간 24px / 화면 여백 20px(모바일)·40px(데스크톱)

## 4. 아이콘 · 일러스트

- 스트로크 1.4~1.6px, `stroke-linecap: round` 고정
- 기본은 선으로만, 강조 시에만 웨지우드로 부분 채움 (레몬은 아이콘 채움에 쓰지 않음)
- 곡선 제어점 각도 45~60도 유지, 내부 디테일선은 메인 스트로크의 70% 굵기
- 크기: 16px(인라인) / 24px(버튼·카드) / 40px(빈 상태) 세 단계만
- 모티프 어휘: 꽃 · 잎 · 덩굴 · 우편봉투 · 엽서 · 나뭇잎(별점 대체)

## 5. 카드 · 레이아웃

- **엽서형 카드**: 점선 테두리(1.5px, 웨지우드), 우측 상단에 8x10px 우표 자리(점선 사각형), 우하단에 옅은 접힘 그림자(opacity 0.06, 12px 이내). 화면당 최대 1개, 결과/확정처럼 "전달"하는 화면에만 사용.
- **일반 정보 카드**: 실선 테두리, 배경 `#FBF9F3`, 리스트로 반복 가능.
- 카드 간 간격 8~10px.

### 편지지 디테일 (초대장류 화면)
- 접힘 자국: 중앙 가로선(opacity 0.08)
- 디클 에지(deckle edge): 가장자리를 미세하게 불규칙한 SVG 외곽선으로
- 잉크 번짐: 모서리 1곳(opacity 0.04, 고정 위치)
- 봉투 씰: 발송 시 원형 왁스 씰 배지(그룹 이니셜/꽃 문양)
- 입력창은 밑줄 형태로 손글씨 쓰는 느낌

## 6. 레이스 장식 (Pinterest "vintage lace / cottage lace" 레퍼런스 기반)

크로셰 도일리·페이퍼 레이스 트림 특유의 스캘럽+아일릿(구멍) 질감을 벡터로 재현합니다.

- 큰 스캘럽(외곽) + 작은 스캘럽(내부, 60% 크기) 이중 레이어
- 스캘럽 사이 지름 2~3px 원형 구멍 반복
- 패턴 단위 가로 20px 고정, 카드 폭에 맞춰 자동 반복
- 색상: 배경보다 한 톤 진한 동일 계열
- 화면당 최대 1곳(보통 엽서형 카드 하단)

## 7. 컴포넌트 상태

- **버튼**: 기본(웨지우드 딥) / 강조(레몬 딥) / 비활성(연회베이지+흐린 텍스트). 클릭 시 scale 0.97, 0.1초, 그림자·색 변화 없음.
- **인풋**: 기본은 라인 컬러 테두리, 포커스 시에만 웨지우드로 전환. 레몬은 인풋에 사용 금지(경고색 오인 방지). 밑줄형(초대 문구 입력 등)은 예외.
- **칩/태그**: 배경은 항상 파스텔(레몬 페일/웨지우드 페일), 텍스트는 대응 딥 컬러.
- **체크박스**: 채워질 때 scale 0.9→1.05→1 (0.35초).

## 8. 사람(아바타)

- 사진 업로드 없음. 원형 안에 이니셜(Gowun Batang) 또는 꽃 아이콘.
- 배경은 웨지우드·레몬·연로즈 페일 톤을 멤버 순서대로 순환 배정, 테두리는 채움색의 딥 톤 1px.

## 9. 빈 상태 (Empty State)

- 64px 씨앗·봉오리 라인아트 일러스트를 중앙에
- 문구는 미래지향형: "아직 아무도 초대하지 않았어요, 첫 편지를 보내볼까요?"
- "없음"·"오류" 같은 단정적 단어 금지, 바로 아래 CTA 배치

## 10. 알림 · 토스트

- 화면 하단 중앙에서 슬라이드+페이드(0.3초), 2.5초 후 자동 소멸
- 크림 카드 + 얇은 웨지우드 테두리, 좌측에 작은 잎/체크 아이콘
- 색상으로 상태 구분 금지, 빨강 경고 없음 — 텍스트+아이콘으로만 전달

## 11. 애니메이션 계층

| 계층 | 용도 | 방식 |
|---|---|---|
| 일상 인터랙션 | 버튼·체크 | 미세한 scale 변화만 |
| 화면 전환 | 페이지 이동 | scale 0.96→1 + fade, 0.25초 |
| 스크롤 연동 | 덩굴 라인 | `stroke-dashoffset`을 스크롤 진행률에 연동 |
| 완료 지점 전용 | 확정·결산 제출 | 개화 애니메이션(꽃잎 순차 펼침, 0.6초) — 이 두 곳 외 사용 금지 |
| 로딩 | 대기 상태 | 스피너 대신 씨앗→새싹 루프(1.2초 반복) |
| 리스트 등장 | 카드 목록 | 8px 아래→위 페이드인, 항목마다 40ms 순차 딜레이 |

모든 애니메이션은 "완료를 알리는 용도"로만 사용. 대기 중 긴장감을 조성하는 연출 금지.

### 초대장 발송 애니메이션 (3단계 시퀀스)
1. **접힘** (0.3초): 카드가 종이 접히듯 접힘
2. **삽입** (0.3초): 접힌 편지가 봉투 슬릿으로 미끄러져 들어감
3. **발송** (0.4초): 봉투가 튀어오르며 우편함으로 사라지고 꽃잎 조각이 흩날림

총 ~1초. 접근성을 위해 스킵(즉시 완료) 옵션 필수 제공.

## 12. 사운드 (Howler.js)

볼륨 gain 0.15~0.25, 배경음악 없음, 사용자가 끌 수 있는 토글 필수 제공.

| 동작 | 소리 |
|---|---|
| 봉투 여닫기 | 종이 바스락 (0.2초) |
| 체크 완료 | 가볍고 짧은 딸깍음 |
| 투표 제출 | 부드러운 "톡" |
| 발송 접힘 | 사각 |
| 발송 삽입 | 스륵 |
| 발송 완료 | 톡 + 작은 종소리 |
| 확정 이미지 저장 | 도장 찍는 소리 (카메라 셔터 대체) |

## 13. 접근성

- 본문 텍스트 대비 최소 4.5:1(WCAG AA), 버튼 텍스트 최소 3:1
- 색상만으로 상태 구분 금지 — 완료 표시는 항상 아이콘+텍스트 병행
- 포커스 상태는 웨지우드 2px 아웃라인
- 모든 장식 애니메이션에 스킵/감속 옵션 제공 (`prefers-reduced-motion` 대응)

## 15. 레퍼런스 확장 디테일

Pinterest 빈티지 레이스·아르누보 레퍼런스에서 추출한 심화 디테일입니다. 15-4~15-5는 "특별한 순간"에만 제한적으로 씁니다.

### 15-1. 그레인 타이포 (Stippled Text)
- 커시브 타이틀(Dancing Script) 안에 미세한 점묘(halftone dot) 질감을 넣어 자수·레이스 특유의 촉감을 표현
- 구현: 텍스트를 `background-clip: text; color: transparent`로 만들고, SVG `feTurbulence`(baseFrequency 0.8 내외) + `feColorMatrix`로 만든 도트 패턴을 배경으로 깔기
- 적용 대상: 화면 최상단 타이틀 1곳에만 — 본문·버튼 텍스트엔 절대 사용 금지(가독성 저하)

### 15-2. 서브타이틀 트래킹 규칙
- 커시브 타이틀 바로 아래엔 항상 letter-spacing 0.15~0.2em의 스몰캡스 서브타이틀 배치 (예: "VINTAGE INSPIRED COLLECTION")
- 폰트는 IBM Plex Mono 또는 Gowun Dodum, 크기 10~11px, 색상은 ink-soft

### 15-3. 레이스 프레임 컨테이너
- 레이스를 테두리 장식이 아니라 콘텐츠를 담는 창틀(액자)로도 사용 가능 — 타원형 또는 사각형 레이스 프레임 안에 사진·아이콘·아바타를 배치
- 프레임 두께는 콘텐츠 영역의 18~22%, 스캘럽+아일릿 패턴은 6번 규칙과 동일 적용
- 용도: 그룹 대표 이미지, 확정 안내(SCR3) 상단 장식 등 화면당 1곳 한정

### 15-4. 미스트 그라디언트 배경 (특별 화면 전용)
- 블러 처리된 파스텔 색 얼룩(핑크·버터옐로우·세이지·스카이블루)이 은은하게 번지는 배경 + 그레인 오버레이
- 일반 화면 배경(종이 베이지)과 구분되는 "특별한 순간" 전용 배경 — 초대장 첫 진입(SCR0) 또는 결산 완료(SCR5) 화면에서만 1회성으로 사용
- 색은 반드시 4색 팔레트 확장 범위 안에서만 혼합, 채도 낮게 유지

### 15-5. 아르누보 코너 장식 (대안)
- 기존 라인아트 꽃 코너 장식 외에, 스크롤형 소용돌이(scroll/swirl) 코너 브래킷을 대안으로 사용 가능
- 더 격식 있는 화면(확정 안내, 결산 결과)에 적합, 일상 화면(진행 공유 등)엔 기존 꽃 코너 유지

### 15-6. 장식용 구분 글리프
- 내비게이션이나 목록 구분에 작은 꽃 글리프(❋, ✿)를 텍스트 구분자로 사용 가능 (예: "Home ❋ About ❋ Gallery")
- 색상은 wedgwood 또는 lemon-deep, 크기는 본문 텍스트의 70%

### 15-7. 라벨 언더라인 액센트
- 메타데이터형 라벨(예: "역할", "일시")에 얇은 곡선형 밑줄 장식을 추가해 손글씨 서명 같은 느낌 부여
- SVG 물결선 1px, wedgwood 컬러, 라벨 텍스트 폭에 맞춰 자동 조정

### 15-8. 팔레트 스와치 컴포넌트
- 설정·소개 화면에는 현재 사용 중인 색상 팔레트를 가로 스와치 바(사각형 4~5칸 연결)로 노출 가능
- 사용자에게 "이 프로젝트의 톤"을 직접 보여주는 용도, 기능적 UI라기보다 세계관 전달용 장식 컴포넌트

## 16. 체크리스트 (화면 제작 시 항상 확인)

- [ ] 빨강·형광색을 쓰지 않았는가
- [ ] 장식 요소(레이스, 개화 애니메이션)가 화면당 1개를 넘지 않는가
- [ ] AI 추천에 근거 문구가 붙어있는가
- [ ] 미완료 상태를 강조하지 않고 조용히 표시했는가
- [ ] 여백이 8px 그리드를 따르는가
- [ ] 최종 확정은 사람의 클릭으로 이루어지는가
