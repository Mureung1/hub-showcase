# ChaSeWar 디자인 시스템

차세워 UI의 일관성을 위한 디자인 토큰·컴포넌트 요약입니다.
**모든 값의 원본은 [`tokens.css`](./tokens.css)** 이며, 이 문서는 그 요약과 사용 규칙입니다.
컴포넌트·화면은 값을 직접 쓰지 않고 항상 `var(--토큰)`으로 참조합니다.

## 컬러
- **브랜드**: `--brand`(네이버 그린), `--brand-weak`(연한 틴트)
- **상태색**: 여유 `--ok-*` / 보통 `--warn-*` / 혼잡 `--busy-*` / 정보없음 `--none-*`
- **중립**: `--text`, `--text-muted`, `--bg`, `--surface`, `--border`

상태 판정 기준 (여유율 = 가용/총):

| 상태 | 기준 |
| -- | -- |
| 여유 | 50% 초과 |
| 보통 | 10% 초과 ~ 50% 이하 |
| 혼잡 | 10% 이하 |
| 정보없음 | 실시간 데이터 미제공 |

## 타이포그래피
- 폰트: `--font` (iOS 시스템 폰트)
- 스케일:

  | 용도 | 크기 / 굵기 |
  | -- | -- |
  | 로고 | 34 / 800 |
  | 화면·상세 제목 | 24 / 800 |
  | 강조 숫자 (상세/카드) | 30·26 / 800 (상태색) |
  | 카드·섹션 제목 | 16 / 700 |
  | 본문·값 | 15 |
  | 보조·캡션 | 13~14 (muted) |
  | 뱃지 / 운영태그 | 12·700 / 11·600 |

## 간격 · 라운드 · 그림자
- 간격: `--s1`~`--s6` (4/8/12/16/20/24). 화면 좌우 `--s5`, 카드 안쪽 `--s4`, 카드 간격 `--s3`
- 라운드: 카드 `--r-card`, 검색창·버튼 `--r-field`, 뱃지·칩 `--r-pill`
- 그림자: `--shadow` (옅게)

## 컴포넌트
검색창 · 칩 · 주차장 카드 · 상태 뱃지 · 운영 태그 · 정보 카드 · 실시간 카드 · 버튼 · 상태 화면(로딩/결과없음/검색실패).
각 컴포넌트는 위 토큰만 조합해 구성하며, 새 화면은 기존 컴포넌트를 재사용합니다.
