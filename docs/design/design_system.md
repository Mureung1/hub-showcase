# 깸 디자인 시스템

Claude Design으로 화면 목업을 만들 때 이 문서를 항상 함께 참조시킬 것.

## 색상

```
--paper: #F2F3EE        /* 배경 (오프화이트) */
--paper-raised: #FFFFFF /* 카드/입력창 배경 */
--ink: #20242C           /* 기본 텍스트 (네이비 잉크) */
--ink-soft: #5B606A      /* 보조 텍스트 */
--rule: #DBDCD4           /* 구분선, 테두리 */

--brand: #86D6BE          /* 브랜드 포인트 컬러 (민트) - 버튼, 활성 탭, 강조 요소 */

--hl-question: #F5DD5A    /* 질문 미션 (노랑) */
--hl-rebut: #FF95A8       /* 반박 미션 (핑크) */
--hl-connect: #86D6BE     /* 연결 미션 (민트, 브랜드색과 동일) */
--hl-express: #A6B4F5     /* 표현 미션 (페리윙클) */
```

브랜드 강조가 필요한 곳(온보딩 CTA 버튼, 탭바 활성 상태, 완료 표시 등)은 `--brand`(민트)를 쓴다. 미션 타입 구분이 필요한 곳은 4색 팔레트를 그대로 쓴다.

## 타이포그래피

- 폰트: 시스템 폰트 스택 (Pretendard Variable, Apple SD Gothic Neo, Malgun Gothic, sans-serif)
- 본문: 15~16px, line-height 1.6
- 헤딩/타이틀: 굵게(700~800), 자간 살짝 좁게(-0.01~-0.02em)
- 보조 텍스트(날짜, 소스명 등): 12~13px, `--ink-soft`

## 형광펜 하이라이트 스타일

텍스트 하이라이트는 `mix-blend-mode: multiply`로 반투명하게 겹쳐, 실제 형광펜으로 칠한 느낌을 낸다. 불투명한 배경색만 칠하지 않는다.

## 레이아웃 원칙 (모바일 우선)

- 기본 뷰포트: 375px 폭 기준. 데스크톱은 보조 사이즈로 추후 확장.
- 세로 스크롤만 사용, 가로 스와이프 없음.
- 하단 고정 탭바(오늘의 글 / 나의 깸): 원문 읽기, 미션 입력 화면에서는 숨김 처리.
- 주요 액션 버튼은 화면 하단 고정(sticky), 엄지로 누르기 쉬운 위치.
- 카드 컴포넌트: `--paper-raised` 배경, `--rule` 1px 테두리, 모서리 radius 12~14px.

## 톤

담백하고 절제된 톤. 종이/노트 느낌의 라이트 테마. 장식 요소를 최소화하고 텍스트 가독성을 우선한다. 형광펜 인터랙션이 유일하게 화려한 포인트이므로, 나머지 UI는 최대한 차분하게 유지한다.
