# 깸 디자인 시스템

Claude Design으로 화면 목업을 만들 때 이 문서를 항상 함께 참조시킬 것.
(`docs/design/design_reference.jpg` 참고)

## 색상

```
--paper: #F4E9D7          /* 배경 (크림/베이지) */
--paper-raised: #FFFFFF   /* 카드/섹션 배경 (화이트) */
--ink: #16301F            /* 기본 텍스트, 헤딩, 버튼 배경 (다크 그린) */
--ink-soft: #5C6459        /* 보조 텍스트 */
--rule: #E4D8C2           /* 구분선, 테두리 */

--accent-lime: #C9DB2E    /* 포인트 컬러 (스티커/스타버스트, 강조 글자) */
--accent-blue: #4C8FE8    /* 장식 블롭 컬러 */
--accent-pink: #FF95A8    /* 보조 포인트 (필요 시 사용) */
```

배경은 크림(`--paper`)과 화이트(`--paper-raised`)를 섹션 단위로 번갈아 사용한다. 헤딩·버튼·푸터처럼 강조가 필요한 곳은 다크그린(`--ink`)을 배경색으로도 쓴다. 라임(`--accent-lime`)은 가장 눈에 띄는 포인트로, 스티커형 도형이나 소수의 강조 텍스트에만 제한적으로 사용한다.

## 타이포그래피

- 폰트: 시스템 폰트 스택 (Pretendard Variable, Apple SD Gothic Neo, Malgun Gothic, sans-serif)
- 헤딩: 매우 굵게(800), 큰 사이즈, 자간 살짝 좁게(-0.01~-0.02em), `--ink` 컬러
- 본문: 14~16px, line-height 1.6, `--ink-soft`
- 보조 텍스트(라벨, 캡션 등): 12~13px, `--ink-soft`
- 통계 숫자(예: "22", "2800")처럼 임팩트가 필요한 곳은 굵게(700~800)로 크게 표시

## 장식 요소 (블롭 & 스티커)

- **블롭**: 배경에 깔리는 유기적 형태(불규칙한 둥근 얼룩 모양)의 색면. 태그/뱃지 뒤에 배치해 시선을 끄는 용도로 사용. `--accent-blue`를 주로 사용.
- **스타버스트/스티커**: 별 모양 톱니 형태의 도형. 내부에 짧은 라벨 텍스트("Future Ready", "Parent" 등)를 얹어 캐주얼한 강조 요소로 사용. `--accent-lime`을 주로 사용.
- 블롭·스타버스트는 섹션마다 1~2개 정도로 절제해서 배치하고, 본문 텍스트와 겹치지 않게 한다.

## 버튼

- 기본 버튼: `--ink`(다크그린) 배경 + 흰색 텍스트, 알약(pill) 형태, 우측에 화살표 아이콘(↗) 포함.
- 버튼 모서리는 완전히 둥글게(radius 999px 또는 height의 절반).

## 카드 & 이미지

- 사진은 모서리를 둥글게(radius 12~20px) 처리하고, 여러 장을 그리드나 겹침 구도로 배치해 생동감을 준다.
- 카드 컴포넌트: `--paper-raised` 또는 `--paper` 배경, 모서리 radius 16~24px, 그림자는 옅게(있어도 거의 안 보일 정도) 사용.
- 통계/수치 블록은 큰 숫자 + 짧은 설명 텍스트를 세로로 쌓아 구성한다.

## 레이아웃 원칙

- 기본은 데스크톱 폭(1200px 내외) 기준의 랜딩 페이지 레이아웃. 섹션을 세로로 쌓고 각 섹션은 크림/화이트 배경을 번갈아 사용한다.
- 네비게이션: 상단 고정, 좌측 로고, 중앙 메뉴, 우측 CTA 버튼.
- 히어로 섹션: 큰 헤딩 + 짧은 설명 + CTA 버튼 + 블롭/스타버스트 장식 + 하단 사진 스트립 구성.
- 푸터: `--ink`(다크그린) 배경에 흰색 텍스트, 하단에 스타버스트 장식 배치.

## 톤

밝고 친근하며 캐주얼한 톤. 크림/화이트의 편안한 배경 위에 다크그린의 안정감 있는 텍스트, 라임의 발랄한 포인트가 대비를 이룬다. 블롭과 스타버스트 같은 유기적 장식 요소로 생동감을 주되, 남발하지 않고 시선을 끌 지점에만 절제해서 배치한다.
