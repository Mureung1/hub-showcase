# Letter&Co 디자인 시스템 리파인 브리프 (Claude Design 붙여넣기용)

이 문서는 Claude Design에 이미 구축된 `Letter&Co Design System`(SKILL.md, tokens/, components/, guidelines/, ui_kits/)에
전문 프론트엔드 디자인 품질 기준(Impeccable 스타일 안티패턴 어휘)을 병합해, "AI가 만든 티"를 줄이고 완성도를 끌어올리기 위한 지시문입니다.
**이 파일을 그대로 Claude Design 프로젝트에 붙여넣고 "이 브리프에 따라 시스템을 리파인해줘"라고 요청하세요.**

---

## 0. 지금 시스템에서 이미 잘 되어 있는 것 (유지할 것)

- 4색 스켈레톤(paper/wedgwood/lemon/ink), 8px 그리드, 명확한 타입 스케일 — 토큰화가 이미 잘 되어 있음
- "화면당 장식 요소 1개" 예산 규칙 — 이건 오히려 Impeccable이 강조하는 "절제"와 정확히 같은 방향
- 빨강/형광 금지, 감시하지 않는 카피 톤 — 브랜드 원칙으로 이미 확립됨
- Postcard/Info 카드 2종 언어 분리 — 카드 남용을 막는 구조가 이미 있음

이 부분은 새로 만들지 말고 **그대로 보존**하면서, 아래 공백만 채워주세요.

## 1. 확인된 공백 — 안티패턴 금지 목록이 없다

지금 시스템은 "이렇게 해라"는 있지만 "이렇게 하지 마라"는 거의 없습니다. 아래를 `guidelines/anti-patterns.html`과 `readme.md`에 새 섹션으로 추가해주세요.

**시각/카드**
- 카드 radius 상한 12~14px (지금 10px 규칙과 충돌 없음, 명시적으로 "이 이상 쓰지 말 것"이라고 못 박기)
- 카드 안에 카드 중첩 금지 (Info/Postcard 카드 안에 또 다른 테두리 카드를 넣지 않는다)
- 두꺼운 단색 테두리 + 둥근 모서리 조합 금지 (지금 postcard의 얇은 점선 테두리와는 다른, "두껍고 튀는" 사이드 컬러 바 금지)
- 유리모피즘(blur+투명) 사용 금지 — 이미 "misted gradient는 2개 화면 전용"이라 규칙이 있지만, "그 외 화면에서 blur를 쓰지 않는다"를 명시적으로 못 박기

**타이포그래피**
- 헤딩-바디 크기 대비 최소 1.25배 규칙 추가 (지금 28/20/16/14/11px 스케일이 이미 이 조건을 만족하는지 확인하고 문서에 명시)
- 한 화면에 폰트 3종(script/heading/body) 초과 사용 금지

**레이아웃**
- 동일한 카드가 3개 이상 반복되는 "그리드형 기능 나열" 금지 — Letter&Co는 리스트/타임라인 형태를 우선하고, 카드 그리드는 place-candidate처럼 실제 비교가 필요할 때만
- 화면 전체에 동일한 간격 값만 쓰는 것 금지 — 관련 요소는 8px, 섹션 간은 24px처럼 그룹핑에 따라 간격을 다르게

**모션**
- bounce/elastic 이징 금지 — 지금 정의된 `--ease-soft` 커브를 모든 트랜지션의 기본값으로 강제

## 2. 확인된 공백 — 미해결 caveat (readme.md 자체가 이미 지적한 것)

Claude Design이 만든 readme.md 자체에 아래 caveat이 명시돼 있습니다. 이번 리파인에서 결정하고 반영해주세요.

- **대표 스크립트체 미확정**: 업로드된 14개 장식 폰트는 전부 한글 미지원. Dancing Script를 기본 스크립트체로 유지하고, 업로드 폰트 중 하나(예: Signatie/Geraldine)는 §15-1 규칙대로 "화면당 1회, 영문 라벨/스탬프 문구 전용" 포인트 사용으로 한정
- **로고/아이콘 미확정**: `Icon.jsx`는 임시 라인아이콘 세트임을 문서에 명확히 표시하고, 최소 SCR0 초대장 화면에 쓸 wax-seal 배지(이미 에셋 있음: `vintage-wax-seal-swan.png`)를 실제 브랜드 마크 후보로 반영
- **SCR4/SCR5(Bloom/Harvest) 정적 카드 상태**: 이번 스프린트 범위(SCR0~SCR2)에 맞춰 정적 상태 유지, 인터랙티브 전환은 다음 병합 때 진행

## 3. 레퍼런스 무드보드 반영 방향

공유해주신 레퍼런스 4장(girlhood 포스터, 웨딩 세이브더데이트, Andrea 스크랩북 2장)은 공통적으로 "디지털 스크랩북" 계열이에요 — 지금 Letter&Co 시스템보다 한 단계 더 촉각적이고 입체적입니다. **특정 이미지를 그대로 베끼지 말고, 아래 기법·어휘만 추출해서 우리 톤에 맞게 재해석**해주세요 (원본은 타인의 저작물이라 요소를 복제하면 안 됩니다).

**추출할 기법 (구현 스펙 포함)**

1. **도일리 풀프레임 + 프레임 이탈 로고** — 도일리가 카드 트림이 아니라 화면의 90% 가까이를 채우는 배경 프레임 역할을 하고, 로고/제목 텍스트가 그 경계를 살짝 넘어 겹치는 구도. 구현: 도일리 프레임을 세로 4:5 비율로 배치하고, 그 위에 얹는 워드마크(예: 화면 타이틀)를 프레임 상단 경계에서 8~12px 정도 위로 겹치게(overflow) 배치 — "장식이 콘텐츠를 가둔다"가 아니라 "콘텐츠가 장식을 뚫고 나온다"는 인상을 준다. SCR0 헤더 1곳에만 적용.
2. **3단 타이포 위계를 한 화면에** — 굵은 라운드 산세리프(브랜드명), 얇은 커시브(날짜/장소 같은 강조 정보), 트래킹 넓은 스몰캡스(부가 정보) 세 단을 한 화면에 겹치지 않게 배치. 구현: 각 단의 크기 비율을 대략 3 : 1.8 : 1로 두고(예: 32px / 19px / 11px), 폰트 패밀리를 서로 다르게(라운드 산세리프/Dancing Script/IBM Plex Mono) 써서 위계를 만든다 — 지금 시스템의 script/heading/mono 3종 폰트 규칙과 정확히 맞아떨어짐.
3. **십자수 도트 보더 + 모노그램 중심 배치** — 반복되는 픽셀 도트 패턴이 카드 테두리를 감싸고, 중앙에는 모노그램(이니셜)이 주변 텍스트보다 3배 가까이 크게 배치. 구현: 모노그램/이니셜 자리에는 그룹명 첫 글자나 SCR 코드("L", "SCR·0")를 커시브로 크게(48~56px), 그 위아래에 스몰캡스 라벨(11px)을 붙인다. 십자수 도트는 `vintage-floral-embroidery.png` 에셋을 스탬프 배지 테두리에 반복 타일링.
4. **카드 스택 레이어링 (오프셋 그림자)** — 카드 2~3장이 5~15px씩 대각선으로 어긋나게 겹쳐 쌓이고, 뒤로 갈수록 그림자가 옅어짐. 구현: `translate(Npx, Npx) + rotate(1~2deg)`를 카드마다 다르게, box-shadow는 앞장일수록 진하게(opacity 0.08→0.03). 봉투-발송 애니메이션(§8-3)의 카드 삽입 단계에 적용.
5. **원형 컷아웃 피크부 프레이밍** — 봉투나 카드 표면에 원형으로 뚫린 창을 내고, 그 안으로 아래 레이어의 일부만 보이게 하는 기법. 구현: `clip-path: circle()`로 원형 윈도우를 만들고 지름은 카드 폭의 30~35%. 아래 레이어는 우리 모티프(넝쿨, 봉투 실루엣)로 채워 인물/사진 요소 배제.
6. **링바인더 거터 + 섹션 컬러블로킹 (절제된 버전)** — Andrea 스크랩북의 "페이지가 넘어간다"는 은유는 살리되, 색 대비는 우리 4색 스켈레톤 안에서만. 구현: 화면 전환 시 배경색이 paper→paper-warm→paper-cool처럼 톤 안에서만 미세하게 바뀌는 것으로 "챕터가 넘어간다"는 느낌을 절제해서 재현. 링 모티프(세로로 반복되는 원)는 쓰지 않고 대신 기존 "괘선(--line)" 구분선으로 대체.
7. **필 태그 + 드롭섀도 스티커 느낌** — 콘텐츠 타입 라벨을 알약형(pill) 태그로, 옅은 컬러 보더 + 낮은 opacity의 짧은 그림자로 "종이 위에 붙인 스티커"처럼 표현. 구현: `border-radius: 999px`, `border: 1px solid`, `box-shadow: 0 2px 4px rgba(74,68,56,0.08)`. 기존 Chip 컴포넌트에 그림자 옵션만 추가하면 됨 — 새 컴포넌트 불필요.
8. **반복 서명 마크 (코너 워터마크)** — 화면 모서리에 작은 서명 스타일 이니셜이나 아이콘이 매 화면 동일한 위치에 반복 등장해 "이 시스템의 것"이라는 인장 역할. 구현: 12~14px 크기, opacity 0.5, 화면 우하단 8px 여백 고정 위치. Letter&Co 워드마크의 소문자 이니셜(예: 필기체 "L")로 대체.

**가져오지 않을 것 (Letter&Co 톤과 안 맞음)**
- 실사 오브젝트 합성(이어폰 줄, 안경, 포토부스 사진) — 우리는 사람 얼굴/개인 소지품을 다루는 화면이 아니라 벡터·라인 일러스트 기조 유지
- 원색 대비가 강한 배색(진초록+크림, 빨강 텍스트, 채도 높은 컬러블로킹) — 4색 스켈레톤과 "빨강 금지" 원칙에 위배
- 기울어진 3D 목업 프레임(폰/카드가 비스듬히 배치) — 우리 UI는 실제 작동하는 화면이라 장식용 기울임보다 정직한 정면 배치 유지
- 세로로 반복되는 링바인더 링 그래픽 — 은유는 살리되 그래픽 자체는 과도하게 장식적이라 괘선으로 대체

## 3-2. 추가 레퍼런스 — 에디토리얼 포스터 기법 (은은한 빈티지 무드)

이번에 주신 4장은 광고/포스터·인물 화보 계열이에요. 인물 사진 요소는 우리 브랜드 원칙(실사 인물 없음)과 맞지 않아서 제외하고, **레이아웃 비율·타이포·텍스처 기법만** 구현 스펙으로 뽑았습니다.

1. **브래킷 프레이밍** — 오벌/사각 프레임 위아래로 커시브 워드마크가 걸치는 구도. 상단 텍스트 40~48px, 하단 텍스트 28~34px로 크기 차등을 둬서 "감싸는" 흐름을 만든다. 적용처: SCR0 초대장 헤더, SCR5 결산 카드 상단.
2. **오벌 프레임 + 헤어라인 스트로크** — 세로 4:5 비율 타원, `border: 1px solid var(--wedgwood)`, `border-radius: 50%/60%`. 안은 사진 대신 wax-seal 배지나 아이콘 일러스트로 채운다 (인물 금지 원칙 유지).
3. **에디토리얼 크레딧 로우** — IBM Plex Mono 10~11px, letter-spacing 0.12~0.15em, 항목 사이 `·` 또는 `/` 구분자, 중앙 정렬. 예: `주최 · 날짜 · 장소`. 적용처: SCR3 확정 카드, SCR5 결산 카드 하단.
4. **미세 그리드 워터마크** — 화면의 20~30% 영역에만 opacity 4~6%짜리 옅은 격자선 텍스처. misted gradient와 경쟁하지 않도록, "장식 예산 1개" 안에서 misted gradient의 대안 텍스처로 문서화(같은 화면에 둘 다 쓰지 않는다).
5. **찢어진 종이 질감 콜라주 (한정 적용)** — 크림/베이지 사진 텍스처 배경 위에 화이트 컷아웃 실루엣을 얹는 기법. 인물 실루엣 대신 별·나뭇잎·봉투 같은 우리 모티프 컷아웃으로 대체, SCR0 진입 화면 1곳에만 한정.
6. **비대칭 콜라주 타이포 배치** — 짧은 문구(8단어 이내, 최대 3개)를 화면 여러 지점에 흩뿌리듯 배치. 온보딩·엠프티 스테이트 카피에 한정 적용.
7. **대칭 플랭킹 오너먼트** — 중심 오브젝트(봉투, 배지) 좌우에 대칭 장식을 배치하는 구도. 날개·리본 대신 우리 모티프인 넝쿨 가지로 대체 구현.

**이번 레퍼런스에서 제외할 것**
- 실사 인물/모델 사진, 얼굴 클로즈업 — 브랜드 원칙 위배
- 하트 모양으로 겹쳐지는 스크립트 오버레이 — 로맨틱 톤이 그룹 협업 툴과 안 맞음
- 플러시토이/캐릭터 스티커 — 타겟 톤보다 유아적
- 순수 광고 포스터형 레이아웃(극단적 여백 + 중앙 정렬 대형 타이포) — 우리는 기능 화면이 많아 정보 밀도가 이보다 높아야 함

## 5. 병합 후 QA 체크리스트 (직접 눈으로 확인할 것)

- [ ] 카드 radius 14px 이하인가
- [ ] 카드 안에 카드가 중첩되지 않았는가
- [ ] 화면 안에 폰트가 3종 이하인가
- [ ] misted gradient/blur가 Invite·Harvest 화면 외에는 안 쓰였는가
- [ ] 같은 톤/카드가 3개 이상 나란히 반복되지 않는가
- [ ] 트랜지션이 bounce 없이 부드럽게(ease-soft) 끝나는가
