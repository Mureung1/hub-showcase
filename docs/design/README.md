## Selected Direction

The selected direction is a combination of:

- Concept 1: Today Learning Hub
- Concept 3: Learning Workspace IDE

DevChat should open with a today-focused learning management screen, then move into a simplified VS Code-inspired learning IDE when the user starts or resumes a session.
