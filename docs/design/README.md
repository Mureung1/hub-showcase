# ICU Design

이 폴더는 ICU의 공유 제품 디자인 원칙과 Figma handoff를 관리합니다. 사용자에게 노출되는 제품명은 `ICU`이며, 화면별 동작과 상태는 `docs/features`가 담당합니다.

## 읽는 순서

1. [design-brief.md](./design-brief.md)
2. 해당 [기능 명세](../features)
3. Figma 작업이 필요할 때 [figma-handoff.md](./figma-handoff.md)

## 기능 명세

- [Today Learning Hub](../features/today-learning.md)
- [Learning Workspace IDE](../features/learning-workspace.md)
- [Git Branching Lab](../features/git-branching-lab.md)

## 선택된 방향

ICU는 앱을 열자마자 오늘 학습 목표, 학습 목록, 복습 항목, 이어하기 액션을 보여주는 학습 관리 허브로 시작합니다. 사용자가 학습을 시작하거나 이어서 진행하면 초보자도 이해하기 쉬운 IDE형 학습 워크스페이스로 이동합니다.
