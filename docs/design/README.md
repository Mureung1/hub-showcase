# ICU Design

이 폴더는 DevChat/ICU 제품 디자인 산출물을 관리합니다. 사용자에게 노출되는 제품명은 `ICU`이며, 디자인 문서에서는 Today Learning Hub와 Learning Workspace IDE 흐름을 기준으로 화면을 설명합니다.

## 선택된 방향

선택된 방향은 `Today Learning Hub + Learning Workspace IDE` 조합입니다.

ICU는 앱을 열자마자 오늘 학습 목표, 학습 목록, 복습 항목, 이어하기 액션을 보여주는 학습 관리 허브로 시작합니다. 사용자가 학습을 시작하거나 이어서 진행하면 VS Code에 익숙한 사용자가 이해하기 쉬운 IDE형 학습 워크스페이스로 이동합니다.
