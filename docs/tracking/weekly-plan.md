## 요일별 배치

### 월 07/13 — ① arXiv 수집 스크립트
- `scripts/collect.py`: arXiv API로 `cs.CL`·`cs.AI`·`cs.LG` 최근 논문 N편 fetch → LLM 키워드 필터 → 메타(제목·저자·날짜·초록·링크) 파싱 → 중복 제거.
- **DoD**: 로컬 실행 시 논문 목록이 파이썬 객체/리스트로 정상 출력.

### 화 07/14 — ② Gemini 요약 스크립트
- `scripts/summarize.py`: Gemini Flash로 **한국어 구조화 요약(기여/방법/결과) + 배경 + 한줄 요약 + 제목 번역**. 키는 `.env`.
- **DoD**: 논문 1편 → 요약 dict 반환. 에러/재시도 처리 포함.

### 수 07/15 — ③ JSON 스키마·저장 + 파이프라인 통합
- `scripts/main.py`: 수집 → 요약 → `data/YYYY-MM-DD.json` 저장. 스키마 확정(현 목 데이터와 호환), 중요도 값 부여(단순 규칙).
- **DoD**: `python scripts/main.py` 1회 실행 → 오늘자 JSON 생성, 내용 눈으로 검증.

### 목 07/16 — ④ 프론트 실데이터 연동 (+F3/F4 점검)
- `web/app.js`가 실제 생성 JSON을 읽도록 경로·스키마 정합. F3 상세·F4 북마크 동작 점검·보완.
- 로컬 미리보기는 **저장소 루트에서** `python -m http.server 8000` → `http://localhost:8000/web/` (※ `../data/` 상대경로 때문에 `cd web` 금지).
- **DoD**: 실데이터로 피드·상세·북마크 정상 동작.

### 금 07/17 — ⑤ 자동화 + ⑥ Pages 배포
- `.github/workflows/`: cron으로 파이프라인 실행 → 생성 JSON 자동 커밋. API 키는 GitHub Secrets.
- GitHub Pages 활성화(배포 브랜치·경로) → 실데이터 브리핑 서빙.
- **DoD**: `workflow_dispatch` 수동 실행 성공 + Pages에서 실데이터 브리핑 렌더 확인.
