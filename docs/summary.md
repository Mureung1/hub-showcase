## 개선해야 할 사항

**보안/인증**
- 참여자 ID가 무인증으로 노출되어 IDOR 가능(타인 응답 조회·수정, 관리자 ID로 마감까지) 
- 4자리 PIN에 rate limit/브루트포스 방어 없음
- 참여 정원 체크 count 조회 후 insert, 원자적이지 않음
- helmet, body size 제한 등 기본 보안 하드닝 전무

**기능**
- `deadline` 필드가 저장만 되고 서버 검증·응답 반영 미구현 상태
- 존재하지 않는 약속 ID에 대한 응답 코드가 API마다 제각각(404/500/200+빈값 혼재)
- `express.json()` 기본 100kb 제한이 최대 슬롯(31일×48) 페이로드(~110KB)보다 작아 413 위험
- 이름 trim 처리가 참여(join)엔 있고 생성(create)엔 없어, 공백 포함 이름은 재접속 시 다른 사람으로 인식됨
- 동명이인 참여 시 원인 파악 불가(그냥 "비밀번호 불일치"로만 안내)
