## 0. 배경 및 목표

실사용 중 발견된 지도·학식 탭의 UX 개선 요청 3건을 다룬다. 앞의 두 건은 대학 학식(충남대) 사용자가
자신이 고른 학생회관 위치를 지도에서 바로 확인하는 흐름을 다듬는 것이고, 세 번째는 주변 식당 검색
결과 개수와 '전체' 카테고리를 골랐을 때의 다양성 문제를 다룬다.

**목표**
1. 대학 학식 탭에서 "내가 고른 학생회관이 어디 있는지"를 더 눈에 띄는 위치·이름으로 보여준다.
2. 주변 식당 검색은 네이버 지역 검색의 실측 한도(쿼리당 5건)에 맞춰 결과를 5개로 제한한다.
3. '전체' 카테고리로 검색했을 때 결과가 한 계열(예: 전부 고기요리)로 쏠리지 않고 여러 요리 계열에
   분산되게 하되, **부족 영양소를 채우는 것이 항상 다양성보다 우선**하게 한다.

**성공 지표**
- 대학 학식 탭 진입 시 "학생 식당위치" 카드가 알레르기 안내보다 먼저 보이고, 건물을 바꾸면 지도가
  그 건물로 리센터되고 핀이 강조된다(이미 되던 동작 — 이름·순서만 확인).
- 주변 식당 결과가 항상 5개 이하로 나온다.
- '전체' 카테고리 검색 결과가 특정 케이스(예: 상업지구, 고깃집 밀집 지역)에서도 단일 계열로만 나오지
  않는다 — 단, 실제로 근처에 다른 계열이 없으면 있는 대로 5개를 채운다(다양성이 "결과 없음"을 만들면
  안 됨).
- 기존 특정 카테고리 선택 검색, 대표메뉴/가격/예상 섭취량/추천 이유 표시, 직업 맞춤 추천 병합은
  회귀 없이 그대로 동작한다.

## 1. 대학 학식 위치 카드 (P0)

### FR-1.1 제목 변경
- 현재 "식비 위치 보기" → "학생 식당위치"로 변경.
- 지도 중심·핀 강조는 이미 선택된 건물(`selectedBuilding`)을 반영해 동작 중 — 변경 없음.

### FR-1.2 카드 순서 변경
- 학식 탭 내 렌더 순서를 "식단 목록 → **학생 식당위치** → 알레르기 유발 식품 안내"로 변경(기존은
  "식단 목록 → 알레르기 안내 → 식당위치" 순).
- 초·중·고(K12) 급식 탭은 원래 이 카드가 없어 영향 없음(대학 학식 전용 기능).

## 2. 주변 식당 검색 개선 (P0)

### FR-2.1 결과 5개 제한
- 최종 목록(부족 영양소 기반 + 직업 맞춤 병합분 포함)을 5개로 제한(기존 8개).
- 직업 맞춤 추천에 예약된 슬롯 비율은 기존과 비슷하게 유지(8개 중 2개 예약 → 5개 중에서도 2개 예약 —
  비율을 과하게 낮추면 직업 맞춤 결과가 비결정적으로 밀려날 수 있어 그대로 둠).

### FR-2.2 '전체' 카테고리 다양화
- 사용자가 특정 카테고리(한식/중식/일식/양식/분식/아시안/카페·디저트)를 고른 경우: **현재 동작과
  완전히 동일** — 다양화 로직이 전혀 개입하지 않는다.
- '전체'를 고른 경우: 최종 5개가 가능한 한 서로 다른 요리 계열에서 나오게 한다. 단,
  1) 부족 영양소를 겨냥해 찾은 후보(예: 단백질 부족 → 고깃집 키워드로 찾은 곳)는 계열과 무관하게
     항상 결과에 먼저 자리를 확보하고,
  2) 그 다음 남은 자리를 서로 다른 계열로 채우며 한 계열이 과반을 넘지 않게 하고,
  3) 그래도 못 채우면(근처에 그 계열이 실제로 없으면) 거리순으로 채워 5개를 항상 보장한다.
- AI(Gemini) 키워드 생성 단계에서도 계열이 겹치지 않게 유도하는 지시를 추가하지만, 이건 보조 수단이고
  실제 다양성 보장은 검색 결과를 고르는 결정적 로직(코드)이 담당한다 — AI가 지시를 안 따라도 결과는
  다양해야 한다.

### FR-2.3 회귀 없음
- 대표메뉴/가격 추정/예상 영양 섭취량/추천 이유 표시 형식은 완전히 그대로 유지한다(이 PRD는 "어떤
  식당이 뽑히는가"만 바꾸고 "뽑힌 식당을 어떻게 보여주는가"는 바꾸지 않는다).
- 직업 맞춤 추천 병합, 카테고리 필터, 완화(relaxation) 폴백 등 기존 로직과 충돌 없이 동작해야 한다.

## 3. 비범위 (Out of Scope)

- 대표메뉴/가격/영양 계산 로직 변경 (기존 유지)
- K12 급식 탭에 위치 카드 신설 (요청 없음)
- 직업 맞춤 추천을 화면에 별도로 노출하는 것 (6주차 §5 결정대로 계속 비노출)
