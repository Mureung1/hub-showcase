# 통합 테스트 계획

## 목적

`frontend/src/App.jsx` 기반 관계형 AI mock UI의 핵심 흐름을 검증합니다.

## 테스트 항목

### 1. 초기 화면 렌더링
- 사이드바와 대화 영역이 정상적으로 표시되는지 확인
- AI 이름, 상태, 관찰 상태, 상황 버튼, 감정 분석 카드가 보이는지 확인
- 초기 대화 메시지 3개가 화면에 출력되는지 확인

### 2. 상황 시뮬레이션 버튼
- `평소` 버튼을 누르면 관찰 상태가 정상값(`정면`, `평소`, `보통`)으로 변하는지 확인
- `긴장` 버튼을 누르면 관찰 상태가 `회피`, `빠름`, `많음`으로 변하는지 확인
- `피곤` 버튼을 누르면 관찰 상태가 `아래`, `느림`, `적음`으로 변하는지 확인
- 버튼 선택 시 해당 버튼이 `active`로 표시되는지 확인

### 3. 메시지 입력 및 전송
- 입력창에 텍스트를 쓰면 `전송` 버튼이 활성화되는지 확인
- `Enter` 키 입력 시 메시지가 전송되는지 확인
- 전송 후 입력창이 비워지는지 확인
- 빈 입력 상태에서 전송 버튼이 비활성화되는지 확인
- AI가 `thinking` -> `speaking` -> `waiting` 상태로 순환하는지 확인

### 4. AI 반응 및 감정 분석
- `기뻐`, `성공`, `잘했어` 같은 긍정 키워드가 들어가면 긍정 응답이 나오는지 확인
- `힘들어`, `망쳤어`, `걱정돼` 같은 키워드가 들어가면 부드럽게 질문하는 응답이 나오는지 확인
- `피곤해`, `졸려`, `지쳤어` 같은 키워드가 들어가면 짧은 응답/수용형 응답이 나오는지 확인
- 상황 버튼이 `긴장`일 때 `ask_gently` 타입 분석이 적용되는지 확인
- 상황 버튼이 `피곤`일 때 `keep_brief` 타입 분석이 적용되는지 확인

### 5. 스크롤 동작
- 메시지 전송 후 새 메시지가 추가되면 화면이 자동으로 아래로 스크롤 되는지 확인

### 6. 접근성 및 상태 표시
- AI 상태 텍스트가 `aria-live` 속성으로 갱신되는지 확인
- 버튼에 `aria-pressed`가 정상 적용되는지 확인
- 화면이 너무 좁아졌을 때도 레이아웃이 깨지지 않고 세로로 정리되는지 확인

4. 키워드 메시지를 전송하여 AI 응답 패턴 확인

6. 모바일 너비로 축소 후 레이아웃 확인
