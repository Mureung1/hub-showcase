# 통합 테스트 계획

## 목적

Noa AI의 세 단계 화면 흐름, 게스트 데이터 격리, 필요할 때만 실행되는 AI 요청, 카메라
개인정보 제한과 배포 경로를 검증합니다.

## 자동 검증

```bash
npm run test:run
npm run test:analysis
npm run build
```

현재 전체 테스트 기준은 38개 파일, 112개 테스트입니다. Supabase나 배포 API를 실제로
검증할 때만 다음 명령을 별도로 실행합니다.

```bash
npm run test:supabase
npm run test:api
npm run test:e2e
```

실데이터 검증은 게스트 레코드나 AI 사용량을 만들 수 있으므로 대상 환경과 비용을 확인한
뒤 실행합니다.

## 수동 검증 시나리오

### 1. 접근 화면

- `Noa AI`가 표시되고 익명과 게스트 보관 방식의 차이가 설명됩니다.
- 익명 시작 후 기록은 현재 탭의 `sessionStorage`에만 남습니다.
- 게스트 생성 시 무작위 복구 키가 한 번 표시되며 복사할 수 있습니다.
- 잘못된 키로는 다른 게스트의 기록을 볼 수 없습니다.
- 기존 키를 입력하면 그 키에 속한 분석 기록만 복원됩니다.

### 2. 대화와 카메라

- 빈 메시지는 전송할 수 없고 입력은 500자로 제한됩니다.
- Enter는 전송, Shift+Enter는 줄바꿈으로 동작합니다.
- 익명 대화는 외부 AI API를 호출하지 않습니다.
- 게스트는 메시지를 보낼 때만 AI 요청을 한 번 보냅니다.
- 공급자 실패나 시간 초과에도 규칙 기반 응답으로 대화를 계속할 수 있습니다.
- AI 사용량 한도에 도달하면 `Noa는 자고 있어요.`가 표시됩니다.
- 카메라 권한을 요청하기 전에 기기 내 분석과 비저장 안내가 보입니다.
- 권한 거부, 얼굴 없음, 여러 얼굴, 모델 오류에서도 수동 입력을 계속 사용할 수 있습니다.
- 카메라 종료와 화면 이탈 시 모든 `MediaStreamTrack`이 종료됩니다.
- POST 데이터에 영상, 프레임, 랜드마크, 전체 blendshape, 장치 정보가 없습니다.

### 3. 감정 신호 결과

- 감정 점수의 합계가 100이며 참고값·비진단 안내가 표시됩니다.
- COBE 지구본이 자동 회전하고 포인터 드래그에 반응합니다.
- WebGL 미지원 또는 오류 시 대체 화면이 표시됩니다.
- `prefers-reduced-motion`에서는 불필요한 움직임을 줄입니다.
- 다시 대화하기로 대화 화면에 돌아갈 수 있습니다.
- 대화와 결과 화면의 처음으로 이동 기능이 접근 화면으로 돌아갑니다.

### 4. 반응형·접근성

- 좁은 화면에서도 세 화면이 동시에 나뉘지 않고 현재 단계 하나만 표시됩니다.
- 키보드만으로 주요 버튼과 입력을 사용할 수 있습니다.
- 상태 변화에는 적절한 `aria-live`, 선택 상태, 진행률 속성이 적용됩니다.
- 색상만으로 상태를 구분하지 않고 텍스트 설명을 함께 제공합니다.

### 5. 배포

- Vercel 앱의 `/api/*` 요청이 Render API로 프록시됩니다.
- Render `/health`가 서버와 DB 연결 상태를 반환합니다.
- 게스트 키가 없는 보호 API는 `401`을 반환합니다.
- 새로고침 후에도 현재 탭의 모드와 허용된 상태가 정상 복원됩니다.
- 브라우저 콘솔에 CORS, mixed-content, 정적 자산 404 오류가 없습니다.
