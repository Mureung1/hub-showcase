# 통합 테스트 계획

## 목적

기능 중심 폴더 구조로 분리된 관계형 AI mock UI의 핵심 흐름을 검증합니다.

## 테스트 항목

### 1. 초기 화면 렌더링
- 사이드바와 대화 영역이 정상적으로 표시되는지 확인
- AI 이름, 상태, 관찰 상태, 상황 버튼, 감정 분석 카드가 보이는지 확인
- 초기 대화 메시지 3개가 화면에 출력되는지 확인

### 2. 상황 시뮬레이션 버튼
- `평소` 버튼을 누르면 관찰 상태가 정상값(`정면`, `평소`, `보통`)으로 변하는지 확인
- `긴장` 버튼을 누르면 관찰 상태가 `회피`, `빠름`, `많음`으로 변하는지 확인
- `피곤` 버튼을 누르면 관찰 상태가 `아래`, `느림`, `적음`으로 변하는지 확인
- 버튼 선택 시 해당 버튼이 `active`로 표시되는지 확인

### 3. 메시지 입력 및 전송
- 상황 입력창에 텍스트를 쓰면 글자 수가 갱신되고 `분석하고 전송` 버튼이 활성화되는지 확인
- 입력은 최대 500자로 제한되는지 확인
- `Enter` 키 입력 시 메시지가 전송되는지 확인
- `Shift+Enter` 입력 시 전송하지 않고 줄바꿈 되는지 확인
- 전송 후 입력창이 비워지는지 확인
- 빈 입력 상태에서 전송 버튼이 비활성화되는지 확인
- AI가 `thinking` -> `speaking` -> `waiting` 상태로 순환하는지 확인

### 4. AI 반응 및 감정 분석
- `기뻐`, `성공`, `잘했어` 같은 긍정 키워드가 들어가면 긍정 응답이 나오는지 확인
- `힘들어`, `망쳤어`, `걱정돼` 같은 키워드가 들어가면 부드럽게 질문하는 응답이 나오는지 확인
- `피곤해`, `졸려`, `지쳤어` 같은 키워드가 들어가면 짧은 응답/수용형 응답이 나오는지 확인
- 상황 버튼이 `긴장`일 때 `ask_gently` 타입 분석이 적용되는지 확인
- 상황 버튼이 `피곤`일 때 `keep_brief` 타입 분석이 적용되는지 확인
- 얼굴 표정 또는 목소리 어조를 바꾸면 선택 버튼의 `aria-pressed` 값이 갱신되는지 확인
- 분석 결과의 감정 점수 합계가 정확히 100인지 확인
- `다시 분석하기` 버튼으로 현재 신호를 다시 분석할 수 있는지 확인

### 5. 스크롤 동작
- 메시지 전송 후 새 메시지가 추가되면 화면이 자동으로 아래로 스크롤 되는지 확인

### 6. 접근성 및 상태 표시
- AI 상태 텍스트가 `aria-live` 속성으로 갱신되는지 확인
- 버튼에 `aria-pressed`가 정상 적용되는지 확인
- 감정 점수 막대에 `progressbar`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`가 적용되는지 확인
- 결과가 감정 확정값이나 의료적 진단이 아니라는 안내가 표시되는지 확인
- 화면이 너무 좁아졌을 때도 레이아웃이 깨지지 않고 세로로 정리되는지 확인

### 7. 카메라 얼굴 표현 신호
- 자동 감지와 수동 선택을 전환할 수 있는지 확인
- 카메라 시작 전에 브라우저 내부 분석 및 비저장 안내가 보이는지 확인
- 모델 로딩과 권한 요청 상태가 표시되는지 확인
- 카메라 시작과 종료가 가능한지 확인
- 얼굴 없음, 한 명 감지, 여러 얼굴 상태가 구분되는지 확인
- 안정화된 신호와 프로토타입 유사도가 표시되는지 확인
- 권한 거부 또는 오류 후에도 수동 선택과 분석이 가능한지 확인
- 카메라 종료와 컴포넌트 해제 시 MediaStreamTrack이 종료되는지 확인
- 영상, 프레임, landmark, 전체 blendshape가 POST payload에 없는지 확인
- 제한된 요약 메타데이터가 POST와 GET에서 유지되는지 확인

## 수동 점검 순서
1. 브라우저에서 앱 실행
2. 초기 화면 구성 확인
3. 각 상황 버튼을 차례로 클릭하며 상태 변화 확인
4. 얼굴 표정과 목소리 어조 버튼을 각각 선택해 선택 상태 확인
5. 키워드 메시지를 전송하여 AI 응답 및 100% 감정 점수 확인
6. 메시지 전송 시 입력, 상태 전환, 스크롤 동작 확인
7. 결과의 판단 근거, 안내 문구, 다시 분석하기 확인
8. 모바일 너비로 축소 후 레이아웃 확인
9. 자동 감지를 선택하고 카메라를 시작한 뒤 권한 허용
10. 미소, 긴장된 표정과 가까운 신호, 얼굴 없음 상태 확인
11. 두 명이 보일 때 한 명만 보이도록 안내하는지 확인
12. 카메라를 종료하고 수동 선택으로 분석 실행
13. POST 저장 후 새로고침하여 기존 기록과 제한 메타데이터 복원 확인

## 자동 검증

```bash
npm run test:run
npm run test:analysis
npm run build
```

`test:run`은 blendshape 변환, 안정화, 입력 fallback, 서버 메타데이터 검증을 포함합니다.
`test:analysis`는 대표 시나리오별 최상위 감정, 점수 합계 100, 내림차순 정렬, 판단 근거와 mock 응답 생성을 검사합니다.

실제 카메라 권한, 웹캠 영상, 여러 얼굴과 브라우저별 성능은 수동 검증으로 구분합니다.
