## 📊 주차별 협업 패턴

```
사람의 결정
  ↓ (가이드)
Claude: 문서화 & 구조화
  ↓ (결과)
plan.md, checklist.md 완성
```

```
Claude: 기능 구현
  ↓ (매일)

  ↓ (이슈 발생)
```

```
Claude: 기능 완성 검증
  ↓

  ↓
금요일 발표 시행
```

## 🔄 실제 vs. 계획 비교

### **계획 (checklist.md)**
| 주차 | 계획 | 실제 | 차이 |
|------|------|------|------|
| 1 | 기획/설계/프로토타입 | 기획/설계/프로토타입 | ✓ 일치 |
| 2 | 기반/로그인/입력 | 기반/로그인/PDF/입력 | ✓ 일치 (+PDF 추가) |
| 3 | Mock 분석/일정 저장 | Mock 분석/저장 → API 연동 | 예상보다 빠름 (API 조기 연동) |
| 4 | Claude API/캘린더/배포 | Claude API/캘린더/배포 | ✓ 일치 |

### **주요 변경사항**
- **3주차:** API를 계획보다 빨리 연동 (예정: 4주, 실제: 3주)
- **4주차:** DB 마이그레이션 추가 (SQLite → PostgreSQL/Supabase)
