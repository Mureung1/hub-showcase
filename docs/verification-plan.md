# Claude 작업 검증 계획 (아직 방법 미정, 정식 스킬로 만들 예정)

## 배경
남이 물어봤을 때 전체 구조와 코드를 다 이해하고 있는 게 중요하다고 판단하여 결과물만 보고 넘어가는 게 아니라 디테일하게 검증하고 싶음. 스스로 혼자 검증하는 게 아니라 Claude가 검증 과정을 이끌어주는 방식(질문하며 확인시키기, 코드 같이 리뷰하기 등)을 원함.

## 검증 대상 (쌓여가는 목록)
- 오늘(260709) 슬라이드 작업의 CSS/JS: 결과물(렌더링된 화면)만 보고 넘어갔고 실제 코드는 안 봄
- `.claude/skills/`에 만든 스킬 파일들의 실제 구조와 규칙
- 위키/GitHub 관련 개념(위키가 git 저장소인 점, `_Sidebar.md`, PR이 개인 브랜치로 머지되는 구조 등)
- 앞으로 실제 개발이 시작되면 그 코드도 이 목록에 계속 추가

## 검증 방법 후보 (아직 미정)
- Claude가 코드/구조에 대해 질문하고 사용자가 답하는 방식
- 함께 코드를 줄 단위로 훑는 방식
- 사용자가 직접 다이어그램이나 말로 구조를 설명해보고 Claude가 빠진 부분을 짚어주는 방식

## 완료 기준 (초안)
남의 도움 없이 처음부터 끝까지 구조와 코드를 설명할 수 있으면 검증 완료로 본다.

## 다음 단계
방법이 정해지면 `.claude/skills/`에 정식 스킬로 만든다.
