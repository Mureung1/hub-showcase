## 1. 제품 한 줄 요약

자취 요리 초보가 **냉장고 재고를 보고 → 채우고(영수증) → 요리하고 → 다시 차감되는** 루프를 끊기지 않게 돌려주는 모바일 웹 앱. 핵심 페르소나는 23세 자취 대학생(요리 초보, 재료·채소값 지식 부족, 유통기한 놓침).

**해결하는 5가지 문제**

| 문제 | 앱의 해결 방식 |
|---|---|
| 어떤 재료로 뭘 해먹을지 모름 | 냉장고 재고 기반 레시피 추천 + 난이도 필터(초보/중급/상급) |
| 채소 평균가를 몰라 장보기가 막막 | 식자재별 평균가 정보(매일 갱신) |
| 남는 재료 소진이 어려움 | 최소 구매로 최대 요리 조합 추천(장보기 세트) |
| 냉장고에 뭐가 있는지 기억 안 남 | 나만의 냉장고 + 영수증 촬영 자동 등록 |
| 유통기한을 놓침 | 임박 알림(빨간 글자 + 푸시) + 보관법 팁 |

## 2. 페르소나

- **이름**: 김상진
- **나이**: 23살
- **소속**: 대학교 2학년 재학중 (군복학)
- **취미**: 게임(롤)

**겪는 문제점**: 자취를 시작하였는데, 요리와 담을 쌓고 살아왔던 터라 집안일은 물론 식사도 제대로 갖추지 못하고 라면이나 간장계란밥 정도의 식사만 갖추고 있음. 몇 주간 식사를 제대로 하지 못해 어느 순간부터 배달을 하거나 외식을 하는 경우가 잦아졌고, 알바를 하고 있음에도 지출을 따라가지 못하고 있는 상태. 또한 요리를 하자니 어떤 식자재를 사야 하는지, 야채값의 평균 가격대도 잘 모르고 있기에 마트에 가면 무엇을 사야 할지 막상 막막해져서 라면이나 밀키트 정도만 사고 집으로 돌아감.

## 3. 문제 정의

- 자취하는 대학생이, 요리 초보라 어떤 재료로 어떤 요리를 할 수 있는지 몰라 입문이 어려움.
  - → 쉬운 요리 추천하는 리스트 제작 (초보자 / 중급자 / 상급자별로)
- 평균적인 채소값에 대한 지식이 전무하기에 일일이 가격 비교를 위해 인터넷 검색에 불편함을 느끼고 있음.
  - → 매일마다 인터넷에서 채소값 가져와서 비교.
- 어떤 요리를 먹고 싶은데 이후 남은 재료들을 소진하기에 막막하고, 그 재료를 활용한 다른 요리를 만들려면 다시 다른 재료를 사야 하는 불편함에 채소 사는 것에 대한 걱정이 있음.
  - → 최소한의 재료 구매로 최대한 다양한 요리를 만들 수 있는 조합을 추천. / 냉장고에 채소가 남아있다면 이 채소를 사용해서 추가 구매 리스트 적용.
- 냉장고에 어떤 재료들이 정확히 있는지 기억해내기 어려움.
  - → 휴대폰으로 내 냉장고 내의 식자재를 한눈에 볼 수 있게 해줌 / 부족하면 더 사는 것을 추천하기도 하고, 영수증을 찍으면 알아서 냉장고를 자동으로 채워줌.
- 결국 남는 재료는 1인 가구라 재료 소진 속도가 느려 유통기한을 놓치는 상황에서 불편을 겪는다.
  - → 신선식품 보관법 팁 정리 (나만의 냉장고 항목의 재료를 누르면 재료별 요리에서의 주요 역할 한줄 설명과 보관법 팁이 적혀있음.)

## 4. 핵심 기능

> 필수성 기준(이게 없으면 서비스가 안 돌아가나) — 재고를 보고, 채우고, 활용하고, 다시 줄어드는 루프가 끊기지 않는 최소 단위.

### MVP 4개

1. **나만의 냉장고 (재고관리)** — 다른 모든 기능이 동작하는 기반. 실생활 단위 지원
2. **영수증 촬영 인식** — 냉장고에 재고를 채우는 유일한 입력 수단
3. **레시피 리스트 & 필터** — "재고로 뭘 해먹지"를 풀어주는 지점, 요리 초보 입문 문제의 핵심 해결책
4. **요리완료 재고차감** — 조리 후 냉장고로 재고가 다시 반영되는 연결고리

### 2차 확장

- 추천 재료 세트 (장보기 전 단계)
- 레시피 상세 & 조리모드 (단계별 안내)
- 유통기한 임박 알림 (냉장고 리스트 내 빨간 글자 표시 + 푸시 알람)
- 일주일 식단 루틴 추천 (레시피 결과가 아예 없을 때 대체 화면)
- 식자재별 가격 실시간

### 기능 구현 현황

범례: ✅ 완료 · 🟡 부분(mock/골격) · ⛔ 미구현

**MVP 4대 기능**

| # | 기능 | 상태 | 비고 |
|---|---|---|---|
| 1 | **나만의 냉장고 (재고관리)** | ✅ | 목록·추가·수정·삭제, 임박 알림 + 수량 부족 알림(`ExpiryAlerts.jsx`) 노출 |
| 2 | **영수증 촬영 인식** | ✅ | 기기 기본 카메라 앱 호출 + Naver Clova OCR 실연동(멀티파트 업로드 → BE가 프록시). Clova 크레덴셜 미설정 시에만 데모 데이터로 폴백 |
| 3 | **레시피 리스트 & 필터** | ✅ | 재고 매칭 + 난이도 필터, 결과 없을 때 식단 루틴 유도 |
| 4 | **요리완료 재고차감** | ✅ | 자동 차감 + 사용량 보정 + 냉장고 갱신, 단일 트랜잭션 |

| 유통기한 임박 알림 | ✅ | 빨간 글자·관련 레시피·**수량 부족 알림** 완성, 4주차 Day16부터 **서버 푸시(Web Push/VAPID)도 실동작**(D-2 이하 재료를 1시간 간격으로 확인해 발송) |

## 5. 사용자 시나리오

1. 냉장고에 재료가 부족하여 장을 보러 간다.
2. 장보기 전, 앱에서 추천 재료 세트를 확인한다.
   - 필터: 재료 최대활용 / 100% 완성(완성도를 낮추면 핵심 재료를 제외한 재료들을 제외해서 필요한 재료 정리) / 난이도
3. 재료를 구매하고 영수증을 촬영해 "나만의 냉장고"에 재고를 등록한다.
   - 인식 실패 또는 일부 품목만 인식 시 재촬영 요청
   - 신선식품은 구매일 기준 재료별 평균 유통기한 자동 설정(계절별 상이), 가공식품은 사용자가 선택적으로 입력
4. 냉장고 재고 기반 레시피 리스트를 필터(재료 최대활용 / 100% 완성 가능 / 초보자 난이도)로 골라 요리를 선택한다.
5. 조리 후 레시피 하단 "요리 완료" 버튼을 누르면 레시피 기준으로 재고가 자동 차감된다.
   - 실제 사용량이 다르면 레시피 옆 "사용량 수정" 버튼으로 보정 가능
   - 재료 단위는 실생활 단위 사용 (예: 파 한단/반단, 양파 한쪽/반쪽/1·4쪽)

## 7. 네비게이션 구조

**하단 탭 5개**(`BottomTabBar.jsx`) — 탭 전환 시 백스택 초기화(`tab()`)

| 탭 | 아이콘 | 진입 화면 |
|---|---|---|
| 홈 | 🏠 | `home` |
| 냉장고 | 🧊 | `fridge` |
| 레시피 | 🍳 | `recipe-list` |
| 장보기 | 🛒 | `shopping-sets` |
| 기타 | ⚙️ | `etc-menu` |

**네비게이션 방식** — react-router가 아니라 직접 만든 스택(`AppContext.jsx`): `go(id)`는 현재 화면을 쌓고 전환, `back()`은 pop, `tab(id)`은 스택을 비우고 전환. 화면은 URL이 아니라 문자열 id이며 `App.jsx`의 `SCREENS` 객체가 컴포넌트로 매핑.

**모바일 프레임** — 전체가 390px 고정 폰 프레임(`PhoneFrame.jsx`) 안에서 렌더. 디자인 톤은 톤다운 빈티지(색상·둥근 모서리·그림자 토큰, `styles.css`).

## 9. 화면별 상세 명세

### 9.1 `home` — 홈 [MVP 관문]

- **목적**: 앱을 열자마자 냉장고 상태와 지금 가능한 요리를 한눈에.
- **UI 구성**
  - 앱바: `🥬 냉장고 레시피`
  - Hero 카드 `🧊 오늘의 냉장고` + 통계 3개: **보유 재료 / 유통기한 임박 / 지금 가능한 요리** 개수
  - 배너: `🛒 냉장고 재료가 부족해요!` → 장보기 세트
  - 섹션 `유통기한 임박 재료` (전체보기 → 임박 알림) — 임박 재료 Row 리스트(빨간 D-day 뱃지)
  - 섹션 `오늘의 추천 레시피` (전체보기 → 레시피) — 보유율 높은 상위 2개 카드
- **이동**: 배너→`shopping-sets`, 임박 전체보기→`expiry-alerts`, 임박 Row→`fridge` 탭, 레시피 전체보기→`recipe-list` 탭, 레시피 카드→`recipe-detail`
- **API**: `GET /api/recipes?filter=full&pageSize=1`(가능한 요리 개수만) + `GET /api/recipes?filter=all&sort=ratio&pageSize=2`(추천 카드 2개, 보유율 상위순) — 전체 목록을 받아와 세는 대신 가벼운 요청 2개로 분리(9일차 성능 개선). 냉장고 데이터는 전역 상태 사용, 이 화면에서 재조회하지 않음.

### 9.2 `fridge` — 나만의 냉장고 [MVP]

- **목적**: 모든 기능의 기반이 되는 재고 목록.
- **UI 구성**
  - 앱바: `나만의 냉장고`
  - 상단 버튼: `📷 영수증 촬영` / `＋ 직접 추가`
  - 섹션 `유통기한 임박 🔥`(있을 때만) — 빨간 글자 + 빨간 뱃지. 신선식품뿐 아니라 **가공식품도 유통기한을 입력해 임박하면 이 섹션에 뜸**(12일차 수정 — 이전엔 가공식품이 임박해도 안 떴음)

  - 섹션 `가공식품` — 유통기한 미입력 시 회색 `—` 뱃지. 임박 항목은 위 섹션에서 이미 보여주므로 여기선 제외
- **이동**: `receipt-camera`, `add-item`, Row 탭→재료 상세 바텀시트(`IngredientSheet`)

### 9.3 `add-item` — 재료 직접 추가 [MVP]

- **목적**: 영수증 없이 재료를 수동 등록.
- **UI 구성**: 앱바 `재료 직접 추가`(뒤로가기)
  - `재료 카테고리` 칩(수평 스크롤): 채소류🧅 / 육류·가금류🥩 / 수산물·해물🦑 / 유제품·알·두부🥛 / 곡류·면류🍚 / 양념·조미료🧂 / 가공식품·기타🥫 / ✏️ 기타(직접 입력) — `GET /api/ingredients`로 받은 재료 마스터를 카테고리별로 분류
  - `재료 선택`: 고른 카테고리에 속한 재료 칩 그리드(이모지+이름), 재료마다 `getQuantityUnits()`가 정의한 서로 다른 단위 후보(예: 돼지고기는 `근`/`g`, 계란은 `알`/`개`) 노출
  - 신선식품: 단위 칩 선택 + 수량 숫자 입력. 가공식품: 자유 텍스트(`예) 1병`). "기타" 선택 시엔 재료명 텍스트 입력 + 예전 방식 자유 단위 칩(`한단/반단/한쪽/반쪽/1/4쪽/1알/g 직접입력`)
  - 구매일 (date), 유통기한 (date, 가공식품은 선택)
  - 신선식품 선택 시 안내: `💡 신선식품은 구매일 기준 평균 유통기한이 자동 입력돼요(여름철 기준·수정 가능)`
  - 하단 고정: `냉장고에 추가` 버튼
- **API**: `GET /api/ingredients`(재료 마스터 로드), `POST /api/fridge`
- **참고**: 같은 재료를 여러 번 사면 새 "구매 배치"로 쌓이지만(§5 `api.md`), 화면에는 합산된 수량으로 표시되므로 사용자 입장에서 중복으로 보이지 않는다.

### 9.4 `receipt-camera` — 영수증 촬영 [MVP]

- **OCR 연동**: BE가 Naver Clova OCR(General)을 호출해 실제 텍스트를 인식하고, 재료 마스터와 이름을 대조해 매칭한다(`backend/src/ocr/`). `CLOVA_OCR_INVOKE_URL`/`CLOVA_OCR_SECRET_KEY` 환경변수가 없으면(로컬 개발 등) 기존 데모 데이터로 조용히 폴백하지만, 크레덴셜이 있는데 호출이 실패/타임아웃되면 에러를 그대로 보여주고 재촬영을 유도한다(가짜 인식 결과를 진짜처럼 보여주지 않기 위함).

### 9.7 `recipe-list` — 레시피 목록 & 필터 [MVP]

- **목적**: "재고로 뭘 해먹지"를 풀어주는 지점.

- **정렬 드롭다운**(전체 둘러보기 탭 전용 — 내 냉장고로 요리 탭은 전부 100% 보유율이라 정렬 의미 없음): `기본순 / 추천순(보유율) / 조리시간 짧은순 / 난이도 낮은순`
- **무한 스크롤**: 목록 맨 아래 sentinel을 `IntersectionObserver`로 관찰해 화면에 들어오면 자동으로 다음 페이지를 이어붙인다. 관찰이 안 되는 환경(구형 브라우저 등)을 위해 같은 자리에 "더보기" 버튼도 항상 같이 둠(안전망) — 브라우저 렌더링 파이프라인 문제로 이 세션에선 자동 트리거 자체를 눈으로 확인하지 못해 안전망을 우선 넣음
- **아직 없는 것(기획엔 있었지만 미구현 — 다음 순서로 구현 예정)**
  - 레시피 썸네일 이미지 — API가 `image_url`을 내려주지만 카드에서 안 씀(이모지만 표시)
  - 북마크(찜) 기능
- **이동**: 카드→`recipe-detail`, 결과 없음 화면→`meal-plan-picker`
- **API**: `GET /api/recipes?filter=full|few|all&level=all|beginner|mid|expert&category=all|반찬|...&search=&page=&pageSize=&sort=default|ratio|time|level`
- **13일차에 발견해 같이 고친 버그**: "🔴 상급자" 난이도 필터가 `level=high` 값을 보냈는데 실제 계산 로직(`calculateRecipeDifficulty`)은 `'expert'`를 매겨서 필터가 항상 0건이었음. `expert`로 통일.

  - `임박 재료 구출` / `최소 지출 완성` → 바로 `shopping-list`
  - `식자재 쉐어링` / `밑반찬 쉐어링` → "몇 끼/몇 가지를 원하시나요?"(2~7) 선택 시트 → `shopping-list`
  - `일주일 식단` → "난이도를 골라주세요" 선택 시트 → `meal-plan-picker`(픽 개수: 식사 2개/반찬 1개)

- **수량 누적 산출 로직**: 단순 보유 유무가 아니라 세트 내 여러 요리의 동일 재료 필요량을 합산하여 냉장고 잔량과 비교.
- **API**: `GET /api/shopping/sets?match=&level=&pickedIds=&multiplier=&shareMealCount=`

### 9.19 `serving-size-setting` — 내 인분 설정 [새로운 기능]

- **UI 구성**: 앱바 `내 인분 설정`(뒤로)
  - 대표 식사 예시 3가지(제육볶음, 파전, 김치볶음밥)를 세로 목록으로 제시
