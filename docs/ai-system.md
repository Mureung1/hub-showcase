## 1. AI 증시 분석 기능의 역할

사용자가 현재 시황이나 관심 종목을 질문하면, AI가 시장/종목 상태 요약, 상승 근거, 하락 리스크,
가능한 시나리오, 초보자 관점의 용어 설명을 구조적으로 정리해 제공한다. 특정 종목의 매수·매도를
지시하거나 수익을 보장하지 않는다 — 사용자가 스스로 판단할 수 있도록 근거와 리스크를 비교해주는
것이 목표다. (출처: `project-overview.md` 1~2절)

## 2. 근거·리스크·시나리오 응답 형식

AI는 단순히 오를지 내릴지를 말하지 않고 항상 다음 구조로 답변한다.

```text
1. 한 줄 요약
2. 현재 시황 또는 종목 상태
3. 상승 근거
4. 하락 리스크
5. 가능한 시나리오
6. 초보자용 해석
```

예시는 [project-overview.md의 6.2 근거·리스크·시나리오 제공](./project-overview.md)을 참고한다.

## 3. 용어 설명 삽입 방식

사용자가 답변 중 모르는 용어를 만나면 별도 사전 화면으로 보내지 않고, 답변 안에서 바로 설명한다.
예시는 [project-overview.md의 6.3 답변 중 용어 바로 설명](./project-overview.md)을 참고한다. 이
기능은 향후 "④ 경제·증시 공부" 기능과 연계될 수 있다(`project-overview.md` 6.6절, TODO).

## 4. 투자 조언 관련 주의 문구

"무조건 사라", "무조건 팔아라" 같은 지시형 표현을 사용하지 않는다. AI 답변은 항상 근거와 리스크를
함께 제시해 사용자가 스스로 판단하도록 돕는 보조 역할에 머문다.
