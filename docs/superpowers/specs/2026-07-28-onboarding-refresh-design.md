# 온보딩 히어로와 기능 미리보기 개편 명세

## 목적

로그인 전 사용자가 아맞다의 핵심 가치인 `저장 → 분류 → 꺼내보기`를 현재 제품 화면과 같은 구조로 이해하도록 한다. 첫 화면에는 한 번만 재생되는 짧은 모션으로 브랜드 인상을 더하고, 두 번째 섹션은 실제 제품 구조를 압축한 전용 미니 화면으로 갱신한다.

## 범위

- 히어로 문장 `저장한 인사이트를 필요한 순간 다시 꺼내 보세요`의 강조 요소 배치와 첫 진입 모션
- `01 저장`, `02 분류`, `03 꺼내보기` 탭의 전용 미니 화면
- 기능 소개 제목과 온보딩 문서의 구현 계약
- 데스크톱, 태블릿, 모바일과 동작 줄이기 설정 대응

다음 항목은 바꾸지 않는다.

- 상단 브랜드와 로그인 행동
- 마지막 문제·의견 제안 섹션
- 로그인, 저장, 검색 등 실제 기능과 데이터 계약
- 인증 후 제품 화면의 컴포넌트

## 히어로

- 문장은 두 줄을 각각 flex 행으로 구성해 일반 문구와 강조 요소의 세로 중심을 맞춘다.
- 첫 줄은 `저장한`과 `인사이트` 사이에 단어 간격을 주고, 조사 `를`은 강조 요소 가까이에 둔다.
- 둘째 줄의 `다시`는 독립된 단어이므로 좌우에 같은 단어 간격을 둔다.
- 데스크톱에서 처음 진입할 때만 약 1초 동안 다음 순서로 재생한다.
  1. 일반 문구가 나타난다.
  2. `인사이트`가 책갈피를 꽂는 방향으로 드러난다.
  3. `다시`가 아래에서 제자리로 돌아오고 반짝임이 한 번 나타난다.
  4. `아맞다 시작하기` 행동이 나타난다.
- 반복, 스크롤 고정, 자동 재생 반복은 사용하지 않는다.
- 모바일과 `prefers-reduced-motion: reduce` 환경은 처음부터 최종 상태를 보여준다.

## 기능 소개

제목은 다음 흐름을 설명한다.

> 발견한 링크가 필요한 순간 다시 쓰이도록,
> 아맞다가 저장부터 꺼내보기까지 이어드려요.

탭은 `01 저장`, `02 분류`, `03 꺼내보기`로 표시한다. 키보드 화살표, Home, End 이동과 탭/패널 접근성 계약은 유지한다.

Hero, 기능 소개, 소통 섹션은 각각 최소 `84svh` 높이로 같은 장면 전환 리듬을 만든다. Hero 높이는 상단바를 포함해 계산하며, 콘텐츠가 더 길면 섹션 높이가 자연스럽게 늘어난다. 기능 소개 섹션의 위아래 여백은 모바일 64px, 태블릿 80px, 데스크톱 96px을 유지한다.

### 저장 미리보기

- 저장 화면의 초록색 상단 영역을 사용한다.
- `URL을 입력하면 바로 저장해요` 제목, URL 입력과 저장 행동을 먼저 보여준다.
- 저장 뒤 선택 정보가 이어지는 구조를 짧게 표현한다.

### 분류 미리보기

- 보관함의 산호색 상단 영역을 사용한다.
- `전체 인사이트`, 검색 입력과 가져오기 행동을 보여준다.
- 본문에는 카테고리, 결과 개수와 인사이트 카드를 둔다.

### 꺼내보기 미리보기

- 홈의 파란색 상단 영역을 사용한다.
- `지금 필요한 인사이트를 꺼내 보세요` 제목, 상황 입력과 꺼내보기 행동을 보여준다.
- 본문에는 고정 제안 상황과 결과 카드를 둔다.
- 실제 제품에 없는 검색 순위, AI 판단, 연결 이유는 표시하지 않는다.

## 구현 경계

- 실제 인증 후 컴포넌트를 축소 재사용하지 않고 랜딩 전용 정적 미니 화면을 유지한다.
- 색상, 간격과 형태는 `DESIGN.md`의 CSS 변수만 사용한다.
- GSAP은 히어로 첫 진입 한 곳에서만 사용하고 컴포넌트 해제 시 모든 효과를 정리한다.
- 애니메이션의 픽셀 위치를 단위 테스트하지 않는다. 문구, 탭, 미니 화면의 사용자 노출 계약만 랜딩 테스트로 검증한다.
- 시각 검증은 390px, 768px, 1280px에서 수행한다.
