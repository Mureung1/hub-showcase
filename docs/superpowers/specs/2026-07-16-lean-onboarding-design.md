# 간결한 온보딩 재구성 설계

## 목표

기존 온보딩의 White Canvas, 큰 타이포그래피, 책갈피 하이라이트 디자인은 유지하면서 불필요한 설명과 중복 섹션을 제거한다. 애니메이션 없이도 `저장한 링크가 필요한 순간 다시 나타난다`는 경험이 이해되는 정적 페이지를 먼저 만든다.

## 범위

### 유지

- 상단바의 브랜드 로고와 `저장`, `꺼내보기` 내비게이션
- Hero의 핵심 문장과 책갈피형 인라인 하이라이트
- Charcoal `서비스 경험하기` CTA
- 저장과 꺼내보기의 실제 제품 장면
- 마지막 CTA
- 기존 로그인 진입 동작

### 제거

- Hero 오른쪽 결과 예시 박스
- Hero 보조 설명과 로그인 안내
- `기억에는 온기를, 다시 찾는 과정에는 질서를.` 문구
- 문제 카드 섹션
- 장점 카드 섹션
- 저장 정책과 부가 기능을 설명하는 보조 문장
- 마지막 CTA의 설명 문단

### 이번 단계에서 제외

- GSAP timeline과 scroll pin
- 새로운 일러스트 또는 장식 이미지
- 앱 내부 저장·검색 기능 변경
- 로그인 화면 변경

## 콘텐츠 서사

```text
Hero → 저장 장면 → 꺼내보기 장면 → CTA
```

Hero는 서비스의 약속만 전달한다. 저장 장면은 링크가 저장되는 모습을, 꺼내보기 장면은 현재 상황과 연결된 저장물이 다시 나타나는 모습을 보여준다. 설명 문단 대신 실제 제품 UI의 레이블과 상태가 기능을 설명한다.

## 시각 계약

- Hero는 단일 열이며 큰 제목과 넓은 여백을 시각적 중심으로 사용한다.
- Hero의 비어 있는 공간을 별도 박스나 이미지로 채우지 않는다.
- 책갈피 하이라이트는 `링크`의 Electric Blue와 `다시`의 Amber 두 곳에만 사용한다.
- 하이라이트에서 이모지와 장식 아이콘을 제거한다.
- 초록색 대형 색면, 장식용 이모지, 별, 반짝임, 그림자를 사용하지 않는다.
- 저장과 꺼내보기 UI는 1px 경계와 기존 radius/token을 사용한다.
- 정적 페이지를 먼저 완성하고 모션은 후속 작업으로 분리한다.

## 컴포넌트 경계

- `LandingPage`는 Hero, 핵심 경험, 마지막 CTA 순서를 소유한다.
- 기존 저장 예시는 핵심 경험의 첫 장면으로 축약한다.
- 기존 `OnboardingMotionPreview`는 이번 단계에서 정적 꺼내보기 장면으로 사용하며, 추후 GSAP 적용 지점으로 유지한다.
- 문제와 장점 데이터 배열 및 해당 섹션 컴포넌트는 제거한다.

## 접근성 및 반응형

- H1의 접근 가능한 이름은 `저장한 링크를 필요한 순간 다시 꺼내보세요`를 유지한다.
- CTA는 Hero와 마지막 장면에서 키보드와 터치로 접근할 수 있다.
- 모바일은 같은 장면 순서를 단일 열로 표시한다.
- 모션 없이 모든 핵심 상태가 보인다.

## 검증 기준

- Hero에 설명 문단, 로그인 안내, 감성 문구, 오른쪽 예시 박스가 없다.
- 문제와 장점 섹션이 렌더링되지 않는다.
- 저장 장면과 꺼내보기 장면은 유지된다.
- Hero의 책갈피 하이라이트와 CTA가 유지된다.
- 모바일과 데스크톱에서 가로 넘침 없이 핵심 문장이 읽힌다.
- 기존 로그인 진입 동작과 접근 가능한 이름이 유지된다.
