# 핵심 기능 탭 온보딩 설계

## 목표

기존 White Canvas, 큰 타이포그래피, 책갈피 하이라이트 디자인을 유지하면서 제품 설명을 `저장 / 분류 / 꺼내보기` 탭으로 보강한다. 상단바의 불필요한 앵커 링크와 별도 기능 섹션은 제거하고, 하나의 제품 무대에서 세 기능을 구체적으로 보여준다.

## 최종 서사

```text
Hero → 핵심 기능 탭 → 소통
```

Hero는 제품의 약속과 로그인 진입을 담당한다. 핵심 기능 탭은 약속이 실제로 어떻게 작동하는지 보여준다. 소통 장면은 제품 설명을 반복하지 않고 버그와 개선 의견을 받는다.

## Hero

- 상단바에는 로고와 `아맞다`, 오른쪽 `로그인` 버튼만 남긴다.
- H1과 `서비스 경험하기` CTA를 유지한다.
- Electric Blue `🔖 링크`, Amber `🪄 다시` 하이라이트를 사용한다.
- 보조 설명, 로그인 안내, 결과 예시 박스는 사용하지 않는다.

## 핵심 기능 탭

섹션 제목:

```text
발견한 링크가 필요한 순간 다시 쓰이도록,
아맞다가 저장부터 꺼내보기까지 이어드려요.
```

탭은 `01 저장`, `02 분류`, `03 꺼내보기` 순서다. 처음에는 저장 탭을 선택한다. 클릭과 키보드 방향키로 탭을 바꾸며 하나의 `tabpanel`만 표시한다.

### 저장 패널

링크 URL, 저장 행동, 저장 완료 상태를 보여준다.

### 분류 패널

카테고리 필터와 카테고리에 정리된 저장물을 보여준다. 검색 입력은 포함하지 않는다.

### 꺼내보기 패널

현재 상황, 관련 저장물, 연결 단서, 원문 열기를 보여준다.

## 시각 계약

- 탭은 설명 섹션의 내비게이션이며 상단바 내비게이션이 아니다.
- 탭은 최대 720px 한 줄 그리드로 배치한다.
- 활성 탭은 Electric Blue 글자와 2px 하단선으로 구분한다.
- 비활성 탭은 Graphite 글자와 Ash 경계를 사용한다.
- 공용 제품 무대는 1px Ash 경계, 16px radius, 무그림자를 사용한다.
- 탭 패널 전환으로 전체 페이지 높이가 크게 흔들리지 않도록 공용 최소 높이를 유지한다.
- 제품 UI 안에서 Blue, Amber, Coral을 제한적으로 사용한다.
- 마지막 소통 장면은 Electric Blue 전면 배경과 Amber, Coral, Pale Blue 책갈피 도형으로 앞 장면과 구분한다.
- 소통 장면에도 그림자와 그라데이션을 사용하지 않는다.

## 컴포넌트 경계

마지막 장면은 `쓰다가 막히거나, 더 좋은 방법이 떠올랐나요?`라는 제목과 짧은 피드백 안내, `문제·의견 남기기` 링크로 구성한다. 링크는 공식 GitHub 이슈 등록 화면을 새 창으로 연다.

- `LandingPage`는 Hero, `OnboardingFeatureTabs`, 마지막 소통 장면 순서를 소유한다.
- `OnboardingFeatureTabs`는 활성 탭 상태, 키보드 이동, 세 정적 패널을 소유한다.
- 기존 `OnboardingMotionPreview`는 제거한다.
- GSAP은 이번 단계에서 사용하지 않는다.

## 접근성

- 탭 목록은 `role="tablist"`, 탭은 `role="tab"`, 제품 무대는 `role="tabpanel"`을 사용한다.
- `aria-selected`, `aria-controls`, `aria-labelledby` 관계를 연결한다.
- 선택된 탭만 `tabIndex=0`이고 나머지는 `-1`이다.
- ArrowLeft, ArrowRight, Home, End로 선택과 포커스를 함께 이동한다.
- 모든 탭, CTA, 피드백 링크는 최소 44px 터치 영역을 갖는다.

## 검증 기준

- 상단바에 `저장`, `꺼내보기` 링크가 없다.
- 승인된 섹션 제목이 표시된다.
- 세 탭이 한 줄로 표시되고 기본 탭은 저장이다.
- 각 탭 전환 시 해당 제품 장면만 표시된다.
- 키보드로 세 탭을 순환할 수 있다.
- 상단 로그인과 Hero CTA는 로그인 화면으로 이어진다.
- 마지막 피드백 링크는 공식 GitHub 이슈 등록 화면으로 이어진다.
- 모바일과 데스크톱에서 가로 넘침이 없다.
