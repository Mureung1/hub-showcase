# 저장 완료 후 선택 입력 종료 흐름 설계

## 문제

URL 저장 뒤 제목, 메모와 카테고리는 선택적으로 입력할 수 있다. 그러나 이 정보를 저장한 뒤에도 `지금은 건너뛰기`가 남아 있어, 이미 끝난 단계를 다시 건너뛰는 것처럼 보인다. 이 버튼은 저장 화면을 초기화하고 보관함으로 이동하므로 완료 상태에서는 초기화 버튼처럼 동작한다.

## 결정

- URL 저장 뒤 선택 정보를 아직 저장하지 않았다면 `지금은 건너뛰기`를 유지한다.
- 선택 정보를 저장하면 `지금은 건너뛰기`를 제거한다.
- 별도의 `보관함에서 확인하기` 또는 `다른 인사이트 저장하기` 버튼은 추가하지 않는다.
- 보관함 이동은 기존 전역 내비게이션을 사용한다.
- 선택 정보 저장 직후에는 `변경 내용 저장하기`를 비활성화한다.
- 제목, 메모나 카테고리를 다시 수정하면 저장 버튼을 활성화하고 `지금은 건너뛰기`를 다시 표시한다.
- 선택 정보 저장을 마친 사용자가 다른 화면으로 이동한 뒤 `저장` 화면에 다시 들어오면 새 URL을 저장할 수 있는 초기 화면을 보여 준다.
- 저장하지 않은 선택 정보가 남아 있다면 다른 화면을 다녀와도 입력 상태를 유지한다.

## 상태 흐름

```text
URL 저장 완료
  ├─ 선택 정보 미저장
  │    ├─ 정보 저장 → 완료 상태
  │    └─ 지금은 건너뛰기 → 보관함
  └─ 선택 정보 저장 완료
       ├─ 건너뛰기 제거
       ├─ 다시 수정 → 미저장 상태
       └─ 다른 화면을 거쳐 저장 재진입 → 새 저장 화면
```

## 검증 범위

기존 `AuthenticatedWorkspace`의 선택 정보 저장 통합 테스트 한 건을 확장한다.

- 선택 정보 저장 직후 `지금은 건너뛰기`가 사라지는지 확인한다.
- 저장 직후 변경 저장 버튼이 비활성화되는지 확인한다.
- 보관함을 확인한 뒤 저장 화면에 다시 들어오면 URL과 완료 화면이 초기화되는지 확인한다.

전역 테스트는 실행하지 않는다.
