# 오늘 학습 허브 2차 개편 (레이아웃/스타일 리프레시) 설계

## 배경

1차 개편(2026-07-25)에서 `/today`를 실데이터 기반으로 재구성했지만, 레이아웃 자체는
기존 구조(메인 컬럼 + 사이드바)를 유지한 채 섹션을 추가/치환하는 수준이었다. 사용자가
공유한 새 참고 이미지는 훨씬 밀도 높고 시각적으로 정돈된 대시보드로, 이번 라운드는
**레이아웃/스타일을 그 이미지에 맞게 다시 짜는 것**이 목표다. 새로운 추적 데이터는
만들지 않고, 지금 있는 실데이터를 이미지 스타일로 다시 배치한다.

## 범위

**다시 그리는 것:**
- 상단 히어로 영역: "오늘 목표" 카드(제목/설명/원형 진행률 게이지/N-M단계) + "이어 학습하기" 액션 카드
- 오늘 학습 큐: 번호 행 + 상태 배지 + 인라인 "계속하기" 버튼 스타일
- 최근 오답/복습: 기존 "복습과 오답" 카드를 이미지 스타일로 재구성 (날짜 스케줄링 카드는 신설하지 않음)
- 학습 목록: 기존 Git/React/Docker 3트랙 표를 아이콘 포함 스타일로 재구성
- 작업 공간 미리보기: 현재 미션의 여러 파일(코드/CSS/노트) 중 하나를 선택하는 드롭다운 추가

**이번에 만들지 않는 것:** 연속 학습일(스트릭), 복습 예정 날짜 스케줄링, 학습 통계 요약
(문제 풀이 수/정답률/코드 리뷰 수) — 추적하는 데이터가 없음.

**그대로 유지:** 캘린더 컴포넌트(내용/로직 변경 없음, 새 레이아웃 안에서 위치만 조정),
배경색·타이포그래피 등 `TodayLearningHub.module.css`의 기존 톤.

## 데이터 매핑

| 새 레이아웃 요소 | 데이터 소스 |
|---|---|
| 오늘 목표 카드 (제목/설명/원형 게이지/N-M단계) | 기존 `generatedPlan.todayMission`, `completionPercent`, `displayQueue` 기반 현재 단계 |
| 이어 학습하기 카드 | 기존 `welcomeCard`의 "학습 시작" 링크 데이터 재사용, 미니 진행률 바 추가 |
| 오늘 학습 큐 | 기존 `displayQueue`/`todayQueue` (데이터 변경 없음, 마크업만 재구성) |
| 최근 오답/복습 | 기존 `reviewMistakeItems`/`reviewSummaryItems` (데이터 변경 없음) |
| 학습 목록 | 기존 `trackRows`(Git/React/Docker) (데이터 변경 없음, 마크업에 아이콘 추가) |
| 작업 공간 미리보기 파일 드롭다운 | 기존 `createWorkspaceEditorFiles(previewActiveMission)`이 이미 여러 파일을 반환 — 지금은 `[0]`만 쓰던 것을 선택 가능하게 확장 |

## 레이아웃 구조

전체를 2컬럼 그리드로 재구성한다 (기존 "메인 컬럼(2fr) + 사이드바(1fr)" 구조 대신,
좀 더 균형 잡힌 배치):

1. **1행**: 오늘 목표 카드(넓게) + 이어 학습하기 카드(좁게)
2. **2행**: 오늘 학습 큐(좌) + 최근 오답/복습(우)
3. **3행**: 학습 목록(좌, 넓게) + 작업 공간 미리보기(우)
4. **캘린더**: 3행 아래 또는 2행 우측 하단에 기존 컴포넌트 그대로 배치 (구현 시 실제
   그리드 흐름을 보면서 가장 자연스러운 위치 확정)

## 컴포넌트 변경

- `TodayLearningHub.tsx`의 JSX 구조를 새 그리드에 맞게 재배치 — 기존 섹션들
  (`welcomeCard`, `trackStatusCard`, `upcomingCard`, `reviewCard`, `trackSection`,
  `workspacePreviewCard`, `calendarCard`)의 **데이터 로직은 그대로 두고 마크업/CSS만
  이 설계에 맞게 조정**한다. `trackStatusCard`(React 실습 현황)는 새 "오늘 목표" 카드에
  통합하거나 나란히 배치한다 — 정확한 통합 방식은 구현 중 시각적으로 확인하며 정한다.
- 작업 공간 미리보기에 파일 선택 `<select>` 추가: `createWorkspaceEditorFiles`가
  반환하는 배열에서 선택된 파일을 로컬 state로 관리.
- 새 CSS는 기존 `TodayLearningHub.module.css`의 색상 팔레트만 사용한다(1차 개편에서
  검증된 팔레트: `#07003d`, `#667085`, `#35c8f4`, `#eef5ff`, `#f8fafc`, `#eef1f5`,
  `#111827`, `#ff8a1c`, `#c24c00`, `#ffffff` 등).

## 진행 방식

이번 라운드는 서브에이전트 기반 파이프라인(브리프 작성 → 구현 → 리뷰 → 재리뷰) 없이
**현재 세션에서 직접 구현**한다. 변경 범위가 CSS/마크업 재배치 위주라 새 로직 테스트가
많지 않고, 검증은 관련 파일만 골라 돌리는 방식으로 진행한다(`npx vitest run <파일>`).
전체 스위트와 typecheck는 마지막에 한 번만 돌린다.
