# 마이페이지 모임 내역 + 신청 시 한마디 Implementation Plan (2026-07-27)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 마이페이지를 활성/내역으로 분리하고(취소·거절은 숨김), 소모임 모임장이 가입 질문을 설정해 신청자가 답변하도록 한다.

**Architecture:** 마이페이지는 **BE·DB 변경 0** — `hosted`/`joined` 응답이 이미 담고 있는 `status`·`startAt`·`endAt`으로 FE에서만 분류한다. 한마디는 `meetings.apply_question` + `meeting_participants.apply_answer` 두 컬럼을 추가하고 F1(신청)·F3(신청자 목록)·E4(수정)에 배선한다. E4는 full-replace지만 **`applyQuestion`만 예외로 "키가 없으면 기존 값 유지"**로 둔다.

**Tech Stack:** Node.js + Express + PostgreSQL(node-pg-migrate, jest + supertest), React(Vite) FE(자동 테스트 없음, lint/build).

설계 근거: `docs/superpowers/specs/2026-07-27-2단계-2일스코프-design.md` (2-1, 2-2, 3, 4항). 항목별 원설계는 `2026-07-26-개선백로그-1-2단계-design.md`의 "B. 신청 시 한마디", "2. 마이페이지 모임 내역".

- 질문이 설정된 모임은 **답변 필수**(빈 답변 400). 질문이 없으면 답변은 무시하고 `null` 저장.
- E4에서 **활성 신청자(`pending`/`confirmed`/`approved`)가 1명이라도 있으면 질문 변경 불가**(400). 같은 값을 다시 보내는 건 허용.
- 마이페이지 분류 규칙(설계 2-2 확정):
  - 내가 만든 모임 — 활성: 모임 `status ≠ cancelled` AND 종료 안 됨 / 내역: `status ≠ cancelled` AND 종료됨 / 안 보임: `status = cancelled`
  - 참여한 모임 — 활성: 내 `p.status ∈ {pending, confirmed, approved}` AND 종료 안 됨 / 내역: 내 `p.status ∈ {confirmed, approved}` AND 종료됨 / 안 보임: `p.status ∈ {cancelled, rejected}`
- pg 타입: `bigint`·`numeric`은 JS **문자열**로 온다. 새 응답 필드를 만들 때 `Number()` 정규화 확인.

// 마이페이지 목록(hosted/joined) 항목이 종료됐는지. 상세 응답과 달리 목록에는 서버가 계산한
// isPast가 없어서 여기서만 클라이언트 시계로 판단한다 — 표시 분류용이라 초 단위 오차는 무해하다.
// 기준은 서버 목록 필터(COALESCE(end_at, start_at))와 같다: 종료 일시가 있으면 그것을, 없으면 시작 일시를.
export function isScheduleEnded(item) {
  const end = item.endAt ?? item.startAt
  return end != null && new Date(end).getTime() < Date.now()
}
```

// POST /api/meetings/:id/apply — 참여 신청(F1). 성공 시 { status } 반환.
// answer는 가입 질문이 설정된 소모임에서만 필요하다. 바디를 보낼 때는 Content-Type이
// 반드시 있어야 서버의 express.json()이 파싱한다(없으면 req.body가 {}가 된다).
export function applyToMeeting(id, answer) {
  const hasAnswer = typeof answer === 'string' && answer.trim() !== ''
  return request(`/api/meetings/${encodeURIComponent(id)}/apply`, {
    method: 'POST',
    ...(hasAnswer
      ? {
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ answer: answer.trim() }),
        }
      : {}),
  })
}
```
