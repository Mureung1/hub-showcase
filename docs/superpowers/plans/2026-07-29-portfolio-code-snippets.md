# 포트폴리오 코드 스니펫 계획

> 작성일: 2026-07-29

## 목표

선택한 기술적 도전과 연결된 실제 Repository 파일에서 핵심 코드 일부를 선별해 포트폴리오 초안의 Solution 근거로 제공한다. 전체 소스나 임의로 생성한 코드는 노출하지 않고, 원문 검증을 통과한 짧은 스니펫만 화면과 PDF에 표시한다.

## 구현 방향

- Repository 분석 단계에서 이미 확보한 제한된 파일 원문 중 후보의 `filePath`와 연결되는 파일만 코드 근거로 만든다.
- 회고 저장 및 초안 생성 요청에 코드 근거를 함께 전달한다. GitHub 재조회나 별도 AI 분석 호출은 추가하지 않는다.
- 초안 AI 응답은 최대 3개 스니펫, 스니펫당 짧은 줄 수와 길이를 제한한다.
- 반환된 코드가 제공된 원문과 일치하는지 서버에서 검증하고, 일치하지 않는 스니펫은 제거한다.
- 근거가 없으면 코드를 만들지 않고 기존 텍스트 초안만 제공한다.
- 웹 초안 화면과 브라우저 PDF 출력에 파일 경로, 코드, 작성 목적, 근거 링크를 표시한다.

## 작업 순서

1. contracts에 Repository 코드 근거와 Portfolio 코드 스니펫 타입을 추가한다.
2. Repository 분석 결과에서 후보와 연결된 파일의 제한된 코드 근거를 구성한다.
3. 회고 저장 요청과 정합성 분석 프롬프트에 코드 근거를 연결하고 응답 검증을 강화한다.
4. 포트폴리오 초안 화면과 PDF 출력에 코드 스니펫 섹션을 추가한다.
5. 파서, 원문 일치 검증, API payload, 화면 유틸리티 테스트를 보강한다.
6. 타입체크, 테스트, 웹 빌드, diff 검사를 실행한다.
