## PRD — 차세워 (ChaSeWar)

서울시 공영주차장의 위치 · 요금 · 운영시간과 실시간 주차 가능 대수를 **목적지 기준으로** 제공한다.
무엇을 만들고 무엇을 만들지 않는지, 그리고 그 경계를 왜 그었는지를 적는다.

### 1. 푸는 문제

운전자는 **목적지에 도착해서야** 주차를 고민하기 시작한다. 그때 부딪히는 것이 셋이다.

- 근처에 어떤 공영주차장이 있는지 모른다
- 갔더니 만차라서 다시 다른 곳을 찾아 돈다
- 요금 · 운영시간은 주차장마다 따로 찾아야 한다

목적지 하나만 알면 이 셋이 한 화면에서 끝나야 한다.

### 2. 대상 사용자

자차로 이동하며 목적지 근처 공영주차장을 찾는 운전자. 상세한 상황은 [`user-scenario.md`](./user-scenario.md).

### 3. 범위

**만든다**

| 기능 | 설명 |
|---|---|
| 장소 키워드 검색 · 선택 | 검색어로 장소 후보를 받아 **사용자가 목적지를 확정한다** |
| 도보 거리순 주차장 목록 | 확정된 좌표 기준으로 가까운 순으로 보여준다 |
| 주차장 상세 | 요금 · 운영시간 · 주소 · 거리 |
| 실시간 주차 가능 대수 | 제공하는 주차장에 한해 현재 대수와 혼잡도 |

**만들지 않는다**

| 제외 | 이유 |
|---|---|
| 회원 · 로그인 | 즐겨찾기 · 이력이 MVP 기능에 없다. 인증이 없으면 지킬 것도 없다 |
| 지도 시각화 | 목록과 상세만으로 "어디에 자리가 있나" 에 답할 수 있다 |
| 혼잡 예측 | **원본이 스냅샷만 준다.** 과거 이력이 없어 예측의 근거가 없다 |
| 예약 · 결제 | 공공 데이터 제공 범위 밖이다 |
| 전국 확대 | 서울 데이터로 흐름을 완성한 뒤 넓힌다 |

### 4. 기능 요구사항

**검색**

- 검색어로 장소 후보를 받는다. 결과가 없으면 **오류가 아니라 "없음"** 으로 보여준다.
- 후보가 하나여도 자동으로 넘어가지 않는다. **확정은 사용자가 한다.**

**목록**

- 확정된 목적지 좌표에서 **반경 1km 안, 가까운 순 최대 10곳.**
- 도보 경로를 얻지 못하면 직선거리로 대체하되, **어느 쪽인지 표시한다.**
- 실시간을 제공하지 않는 주차장도 **목록에서 빼지 않는다.**

**상세**

- 요금 · 운영시간 · 주소 · 연락처 · 총 구획 수 · 거리.
- 실시간 제공 주차장은 현재 대수와 혼잡도를 함께 보여준다.
- 값이 없는 항목은 **없다고 표시한다.** 빈칸으로 두지 않는다.

**실시간**

| 상태 | 기준 |
|---|---|
| 만차 | 가용 0 |
| 혼잡 | 가용률 10% 이하 |
| 보통 | 10% 초과 ~ 50% 이하 |
| 여유 | 50% 초과 |
| 정보 없음 | 실시간 미제공 |

### 5. 데이터

| 데이터 | 출처 | 성격 |
|---|---|---|
| 정적 주차장 정보 | 서울 공영주차장 안내 정보 (OA-13122) | 매일 한 번 갱신 |
| 실시간 주차 대수 | 서울 시영주차장 실시간 주차대수 (OA-21709) | 스냅샷, 이력 없음 |
| 장소 검색 · 좌표 | 카카오 로컬 API | 요청할 때마다 |
| 도보 거리 | Tmap 보행자 경로 | 요청할 때마다, 실패 시 직선거리 |

스키마와 관계는 [`erd.md`](./erd.md), 응답 계약은 [`api-spec.md`](./api-spec.md).

### 6. 알려진 한계

**받아들이고 가는 것들이다.** 고칠 수 있는데 안 고친 게 아니라, 데이터가 그렇다.

- **실시간을 제공하는 주차장이 일부다.** 전체 중 소수만 실시간 대수가 있다.
- **좌표가 없는 주차장이 있다.** 지오코딩이 주소를 못 찾은 경우이고, 거리 계산에서 빠진다.
- **실시간은 과거를 남기지 않는다.** "평소 이 시간엔 여유" 같은 안내를 할 수 없다.
- **지역명을 넣으면 그 지역의 장소가 후보로 나온다.** `성수동` 같은 입력은 정확한 한 점이 아니라 근처 장소로 대체된다.
- **외부 API 한도가 있다.** 도보 경로는 무료 한도를 넘으면 직선거리로만 동작한다.

### 7. 다음 단계

MVP 이후 순서. 앞의 것이 뒤의 전제인 경우가 있어 순서를 지킨다.

1. **적재와 지오코딩을 잇는다** — 새로 들어온 주차장의 좌표가 자동으로 채워지게
2. **주소가 바뀌면 좌표를 무효화한다** — 1번이 먼저여야 주차장이 조용히 사라지지 않는다
3. 실시간 소스를 **전국 단위 API** 로 확장
4. 도보 경로 결과 캐시
