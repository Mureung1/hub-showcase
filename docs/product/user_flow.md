## 주요 사용자 흐름

### 1 URL로 레시피 저장 흐름

```text
온보딩/로그인
→ 내 레시피북
→ 레시피 추가
→ URL 입력
→ AI 정리 결과 확인
→ 내용 수정
→ 저장
→ 레시피 상세
```

#### 설명

공개 `youtube.com`, `youtu.be` 영상 URL은 제목·채널명을 조회한 뒤 공개 자막을 우선 사용해 레시피 초안을 정리한다. 자막을 얻지 못하면 Gemini 영상 분석으로 한 번 대체하며, 모든 YouTube 처리에 실패하면 사용자는 레시피 원문을 직접 입력해 계속한다.

사용자가 지원되는 일반 공개 웹페이지 또는 공개 YouTube URL을 입력하면 AI가 URL 내용을 바탕으로 레시피 초안을 정리한다.
URL이 입력된 경우 해당 URL은 출처 정보로 함께 저장된다.
공개 네이버 블로그 URL은 현재 MVP/P0 입력 범위에서 제외하며 `URL_FETCH_FAILED`와 직접 입력 안내를 표시한다.

---

### 2 직접 입력으로 레시피 저장 흐름

```text
온보딩/로그인
→ 내 레시피북
→ 레시피 추가
→ 레시피 원문 또는 메모 입력
→ AI 정리 결과 확인
→ 내용 수정
→ 저장
→ 레시피 상세
```

#### 설명

사용자가 직접 입력한 내용을 바탕으로 AI가 레시피 초안을 정리한다.
URL이 없는 경우 별도의 출처 정보는 저장하지 않는다.

---

### 3 URL과 직접 입력을 함께 사용한 레시피 저장 흐름

```text
온보딩/로그인
→ 내 레시피북
→ 레시피 추가
→ URL 입력
→ 레시피 원문 또는 추가 메모 입력
→ AI 정리 결과 확인
→ 내용 수정
→ 저장
→ 레시피 상세
```

#### 설명

URL과 직접 입력이 모두 있는 경우 AI는 두 정보를 함께 참고해 레시피 초안을 정리한다.
URL은 출처 정보로 저장되고, 직접 입력 내용은 정리 결과에 보조 정보로 반영된다.

---

### 4 내가 등록한 레시피 열람 공유 흐름

```text
내 레시피북
→ 레시피 상세
→ 열람 공유
→ 열람 링크 생성
→ 링크 복사
→ 상대방이 링크 접속
→ 열람 전용 레시피 화면
```

#### 설명

열람 공유는 상대방이 레시피를 보기만 할 수 있는 공유 방식이다.
열람자는 레시피를 수정하거나 저장하거나 다시 공유할 수 없다.

---

### 5 내가 등록한 레시피 전달 공유 흐름

```text
내 레시피북
→ 레시피 상세
→ 전달 공유
→ 전달 초대 생성
→ 전달 링크와 초대 코드 확인
→ 링크 또는 코드 공유
```

#### 설명

전달 공유를 생성하면 하나의 전달 초대가 만들어진다.
전달 초대에는 링크와 초대 코드가 함께 제공되며, 둘은 같은 초대 정보를 가리킨다.

---

### 6 전달 링크로 레시피를 받는 흐름

```text
전달 링크 접속
→ 로그인 확인
→ 전달받은 레시피 미리보기
→ 수락
→ 전해준 사람 입력
→ 관계 라벨 입력
→ 내 레시피북에 저장
→ 전달받은 레시피 상세
```

#### 설명

사용자는 전달 링크로 접속해 레시피 내용을 먼저 확인한다.
수락한 경우 전해준 사람과 관계 라벨을 입력한 뒤 자신의 레시피북에 저장한다.

---

### 7 초대 코드로 레시피를 받는 흐름

```text
내 레시피북
→ 레시피 추가
→ 전달받은 레시피가 있나요? 코드로 불러오기
→ 전달 초대 코드 입력
→ 전달받은 레시피 미리보기
→ 수락
→ 전해준 사람 입력
→ 관계 라벨 입력
→ 내 레시피북에 저장
→ 전달받은 레시피 상세
```

#### 설명

초대 코드 입력은 일반 레시피 추가 입력과 분리한다.
레시피 추가 화면에는 코드 입력창을 직접 두지 않고, 별도의 초대 코드 입력 화면 또는 모달로 이동하는 진입 문구만 제공한다.

---

### 8 전달받은 레시피 거절 흐름

```text
전달 링크 접속 또는 초대 코드 입력
→ 전달받은 레시피 미리보기
→ 거절
→ 저장하지 않고 종료
```

#### 설명

사용자가 거절한 경우 레시피는 내 레시피북에 저장되지 않는다.
MVP에서는 거절만으로 초대를 만료시키지 않고, 수락 완료 시에만 초대를 만료 처리한다.

---

### 9 전달받은 레시피 확인 흐름

```text
내 레시피북
→ 전달받은 레시피 탭
→ 레시피 카드 선택
→ 전달받은 레시피 상세
→ 내 메모 작성 또는 수정
```

#### 설명

전달받은 레시피는 원본 내용을 수정할 수 없다.
사용자는 개인 메모만 작성하거나 수정할 수 있다.

---

### 10 전달받은 레시피 제거 흐름

```text
내 레시피북
→ 전달받은 레시피 상세
→ 내 레시피북에서 제거
→ 제거 확인
→ 내 레시피북 목록
```

#### 설명

전달받은 레시피는 삭제가 아니라 내 레시피북에서 제거하는 방식으로 처리한다.
제거 후 해당 레시피는 내 목록에서 더 이상 보이지 않는다.
