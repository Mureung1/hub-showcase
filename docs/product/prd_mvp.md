# MVP PRD
## 1. 문서 목적
나만의 레시피북 MVP에서 구현할 핵심 기능, 공유 정책, 권한 규칙, 화면 흐름의 기준을 정의한다.

## 2. 서비스 개요
흩어진 레시피를 AI로 정리하고, 전해준 사람과의 관계까지 함께 보관하는 개인 레시피북 서비스

## 3. MVP 목표
- 사용자가 URL 또는 직접 입력하여 레시피를 추가할 수 있다.
- AI가 레시피를 조리하기 쉬운 형태로 정리한다.
- 사용자는 정리 결과를 확인하고 수정한 뒤 저장한다.
- 저장된 레시피는 개인 레시피북에 저장되고 다시 열람할 수 있다. 
- 개인 레시피를 공유할 수 있다.
- 레시피를 공유받을 때 전해준 사람, 전달받은 날짜, 관계 라벨이 함께 레시피북에 저장된다.
- 공유받은 레시피는 재공유할 수 없다.

## 4. MVP 포함 범위
### 포함할 기능
- Firebase Authentication 기반 Google 로그인
- 레시피 직접 입력
- URL 기반 레시피 입력
- AI 정리
- AI 정리 결과 확인
- 결과 수정 후 저장
- 내 레시피북 목록
- 레시피 상세 보기(목록 열람)
- 레시피 상세 화면 조리중 모드 토글 제공
- 열람 공유
- 전달 공유
- 관계 라벨 입력
- 내 메모 작성

### 제외할 기능(추후 구현)
- 실제 영상 자막 자동 추출
- 파일 업로드
- 친구 추가(소셜)
- 친구의 공개 레시피북 열람
- 레시피 추천 알고리즘
- 벡터 검색
- 댓글, 좋아요
- 음식 카테고리별 분류
- 목록 정렬
- 단계별 조리모드
- 타이머 기능
- 음성 조작
- 화면 꺼짐 방지

## 5. 레시피 유형 정의
### 내가 작성한 레시피
사용자가 직접 입력하여 저장한 레시피이다. 내 레시피북에 저장되며 열람 공유와 전달 공유가 가능하다. 별도의 공개 레시피 상태는 두지 않고, 열람 링크의 활성·비활성으로 접근을 제어한다.
### 외부 출처로부터 저장한 레시피
지원되는 블로그, 웹페이지와 공개 YouTube URL을 입력해서 AI가 정리한 레시피입니다. 내 레시피북에 저장되며 출처가 자동으로 저장됩니다. 열람 공유는 가능하지만 전달 공유는 불가능합니다.
### 전달받은 레시피
다른 사용자가 전달 링크 또는 초대 코드를 통해 공유한 레시피이다. 내 레시피북에 저장되지만 재공유는 불가능하다.
### 열람 중인 레시피
링크를 통해 열람만 가능한 레시피이다. 내 레시피북에 저장되지 않으며 재공유도 불가능하다.

## 6. 공유 방식 정의
### 열람 공유
- 링크가 있다면 레시피를 볼 수 있다.
- 비로그인 시에도 가능하다.
- 내 레시피에는 저장되지 않는다.
### 전달 공유
- 원 작성자가 특정 사용자에게 레시피를 전달한다.
- 받은 사용자는 자신의 레시피북에 저장할 수 있다.
- 저장 시 전해준 사람, 관계 라벨, 전달받은 날짜가 함께 저장된다.
- 전달받은 레시피는 재공유할 수 없다.

## 7. 정책 정의
본 정책은 MVP 기준의 기본 정책이며, 친구 기능, 공개 레시피북, 그룹 공유 기능이 추가될 경우 별도의 정책 문서로 분리한다.

### 레시피 권한 정책 
| 레시피 유형 | 열람 | 원본 수정 | 메모 | 열람 공유 | 전달 공유 |
|---|---:|---:|---:|---:|---:|
| 직접 작성한 레시피 (`OWNED`) | 가능 | 가능 | 가능 | 가능 | 가능 |
| 외부 출처 레시피 (`EXTERNAL`) | 가능 | 가능 | 가능 | 가능 | 불가능 |
| 전달받은 레시피 (`RECEIVED`) | 가능 | 불가능 | 가능 | 불가능 | 불가능 |
| 링크로 열람 중인 레시피 | 가능 | 불가능 | 불가능 | 불가능 | 불가능 |


### AI 정리 정책

- 공개 `youtube.com`, `youtu.be` 영상은 YouTube Data API로 제목·채널명을 조회하고 공개 또는 자동 생성 자막을 우선 사용한다. 자막 조회에 실패하면 Gemini 영상 분석을 사용하며, 모든 YouTube 처리 실패 시 사용자는 직접 입력으로 계속한다.

- AI가 정리한 결과는 자동 저장되지 않는다.
- 계량이 모호한 표현은 확인이 필요한 항목으로 표시한다.
- 사용자가 정리된 내용을 확인하고 수정한 뒤 저장한다.

### 공유 정책

레시피 공유는 목적에 따라 **열람 공유**와 **전달 공유**로 구분한다.

---

#### 열람 공유

열람 공유는 다른 사용자가 레시피를 보기만 할 수 있도록 제공하는 공유 방식이다.

1. 열람 공유 버튼을 누르면 열람 링크가 생성된다.
2. 열람 링크를 가진 사용자는 레시피 내용을 확인할 수 있다.
3. 열람 공유된 레시피는 상대방의 레시피북에 저장되지 않는다.
4. 열람자는 해당 레시피를 수정하거나 메모를 작성할 수 없다.
5. 열람자는 해당 레시피를 다시 공유할 수 없다.
6. 레시피 주인은 열람 링크를 비활성화할 수 있다.

---

#### 전달 공유

전달 공유는 다른 사용자가 레시피를 자신의 레시피북에 저장할 수 있도록 제공하는 공유 방식이다.

1. 전달 공유 버튼을 누르면 하나의 전달 초대가 생성된다.
2. 전달 초대에는 링크와 코드가 함께 제공된다.
3. 링크와 코드는 같은 초대 정보를 가리킨다.
4. 링크로 접속하거나 코드를 입력하면 동일한 전달받은 레시피 미리보기 화면으로 이동한다.
5. 수락한 사용자는 전해준 사람과 관계 라벨을 입력한 뒤 자신의 레시피북에 저장한다.
6. 저장된 레시피에는 원 저장자, 전해준 사람, 관계 라벨, 전달받은 날짜가 함께 기록된다.
7. 전달받은 레시피는 재공유할 수 없다.
8. 전달 링크와 코드는 1회 저장 후 만료된다.

### 관계 정보 저장 정책
전달 받은 레시피는 저장 시 다음 정보를 함께 가진다.

- 원 저장자
- 전해준 사람
- 전달받은 날짜
- 관계 라벨
- 재공유 가능 여부

관계 라벨과 전해준 사람은 받는 사람이 저장 시 직접 입력할 수 있다.

e.g

- 전해준 사람: 엄마
- 관계 라벨: 엄마의 레시피
- 전달 받은 날짜: 2026.07.09
- 재공유 가능 여부: 불가능
