# 나만의 레시피북 MVP 티켓

이 문서는 구현 티켓과 완료 조건의 기준이다. 티켓 ID를 지정해 다음처럼 요청할 수 있다.

```text
FE-AUTH-002 티켓 분석해줘
BE-AI-001 구현해줘
QA-CORE-001 상태 알려줘
```

## 티켓 규칙

- ID 형식은 `<영역>-<기능>-<3자리 번호>`를 사용한다.
- 영역은 `COMMON`, `FE`, `BE`, `DB`, `QA`, `OPS`를 사용한다.
- 기존 ID는 변경하거나 재사용하지 않는다. 새 티켓은 같은 영역·기능의 다음 번호를 사용한다.
- 상위 티켓은 모든 완료 조건과 검증이 끝났을 때만 `[x]`로 변경한다.
- 부분 구현은 완료된 하위 조건만 `[x]`로 표시하고 상위 티켓은 `[ ]`로 유지한다.
- 공유와 삭제·복원은 P0 핵심 흐름이 완료된 뒤 진행한다.
