## 와이어프레임

화면 구성은 **`docs/prototype/` 의 HTML** 이 원본이다. 브라우저로 바로 열어볼 수 있다.
이 문서는 그 화면들이 **어떤 흐름으로 이어지고 실제 코드의 어디에 대응하는지**를 적는다.

### 1. 화면 흐름

        [홈]  검색창
          │  검색어 입력
          ▼
        [장소 후보]  검색어에 맞는 장소 목록
          │  하나 선택 → 목적지 확정
          ▼
        [주차장 목록]  가까운 순 · 실시간 상태 표시
          │  하나 선택
          ▼
        [주차장 상세]  요금 · 운영시간 · 실시간 대수

- 뒤로 가면 한 단계씩 되돌아간다. 목록은 URL 에 좌표가 실려 있어 **새로고침해도 유지된다.**
- 목록과 상세는 각각 **로딩 · 결과없음 · 실패** 상태를 따로 가진다.

### 2. 프로토타입 ↔ 실제 화면

| 프로토타입 | 경로 | 실제 화면 |
|---|---|---|
| `index.html` | `/` | `SearchHome.jsx` |
| — | `/places` | `PlaceResults.jsx` |
| `results.html` | `/results` | `SearchResults.jsx` |
| `results-loading.html` | | `ResultStates.jsx` 의 로딩 |
| `results-empty.html` | | `ResultStates.jsx` 의 결과없음 |
| `results-error.html` | | `ResultStates.jsx` 의 실패 |
| `detail.html` | `/parking-lots/:id` | `ParkingLotDetail.jsx` |

> **장소 후보 화면은 프로토타입에 없다.**
> 검색어 하나를 우리가 임의로 해석하던 것을 사용자가 고르도록 바꾸면서 뒤에 생긴 화면이다.
> 프로토타입을 다시 그릴 때 채운다.

### 3. 화면별 구성 요소

**홈** — 로고 · 검색창 · 예시 검색어 칩

**장소 후보** — 검색창 · 결과 수 · 장소 카드 목록
장소 카드는 이름과 주소를 보여준다. **주소가 없는 장소가 있어** 그때는 이름만 나온다.

**주차장 목록** — 제목 · 검색창 · 결과 수 · 주차장 카드 목록
카드 하나에 이름 · 주소 · 거리 · 유료 여부 · 실시간 상태 뱃지가 들어간다.
실시간을 제공하지 않으면 뱃지가 **회색 "정보 없음"** 이 된다.

**주차장 상세** — 제목 · 실시간 카드 · 정보 카드(요금 · 운영시간 · 기본 정보) · 목록으로 돌아가기
실시간 카드에는 가용 대수를 크게 두고 상태색을 입힌다. 미제공이면 카드 대신 안내 문구가 나온다.

### 4. 화면을 만들 때

- 값 · 색 · 간격은 `docs/design/tokens.css` 의 토큰만 쓴다. 상세 규칙은 `chasewar-design` skill.
- 새 화면은 **기존 컴포넌트를 먼저 찾아 쓴다.** 없을 때만 만든다.
- **"값이 없다"를 어떻게 보여줄지는 화면이 정한다.** 백엔드는 없는 값을 그대로 내려준다.
