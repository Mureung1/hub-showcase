# 서비스명 미정(가칭: SeedRank) 웹 서비스 기획 정리

## 한 줄 소개
예비 창업자가 사업 아이디어를 자유롭게 등록하고, AI 구체화와 커뮤니티/기업 반응을 통해 시장성을 검증하며, 아이디어의 발전 과정과 기여 기록을 자산화하는 오픈소스형 사업화 아이디어 플랫폼.

## 핵심 콘셉트
- 커뮤니티처럼 자유롭게 아이디어를 던지는 공간
- 게임처럼 재미있는 가상 투자와 실시간 랭킹
- 구조화된 피드백을 채택해 기여자로 인정하는 오픈소스형 구조
- 공개 범위 선택으로 아이디어 공유와 보호의 균형 제공
- 최초 등록, 수정, 피드백 채택, 기업 관심을 성장 타임라인으로 기록
- 유사 아이디어를 연결해 중복을 협업 가능성으로 전환
- 기업 관심 표시를 통해 시장성 신호를 강화

## 서비스 철학
아이디어 자체보다 아이디어가 검증되고 발전해온 기록을 가치로 만든다. 이 서비스는 아이디어를 무조건 숨기거나 거래하는 플랫폼이 아니라, 공개 검증과 기여 기록을 통해 사업화 가능성을 높이는 오픈 이노베이션 플랫폼을 지향한다.

## 주요 사용자
- 아이디어 게시자: 창업을 구상하는 누구나
- 일반 사용자: 아이디어를 조회하고 좋아요, 댓글, 가상 투자로 참여
- 기여자: 채택된 피드백으로 아이디어 발전에 기여
- 기업/투자자: 기업 관심 표시, 비공개 문의, 스폰서 광고 등록

## MVP 기능
| 기능 | 설명 |
|---|---|
| 아이디어 등록 | 키워드와 배경 설명 기반 게시물 작성 |
| 공개 범위 설정 | 공개형, 반공개형, 비공개 검증형, 매칭형 공개 선택 |
| AI 아이디어 구체화 | 5가지 아이디어 후보와 기획서 초안 생성 |
| 실시간 랭킹 | 가상 투자금, 기업 관심, 좋아요, 조회수 기반 순위 |
| 구조화 피드백 | 문제 공감, 고객군, 수익 모델, 경쟁 서비스 등 유형별 피드백 |
| 기여자 기록 | 채택된 피드백을 아이디어 타임라인과 사용자 프로필에 반영 |
| 가상 투자 | 매일 제한된 포인트로 유망 아이디어에 투자 |
| 기업 관심 표시 | 기업 인증 후 공식 관심 표시 |

## 아이디어 등록 흐름
1. 키워드와 아이디어 배경 입력
2. AI가 5가지 사업 아이디어 후보 제안
3. 사용자가 하나를 선택하고 수정
4. AI가 사업 기획서와 프로토타입 이미지 생성
5. 사용자가 공개 범위와 검증 질문을 설정한 뒤 게시

## 공개와 보호의 균형
| 공개 단계 | 공개 내용 | 목적 |
|---|---|---|
| 공개형 | 제목, 요약, 문제 정의, 해결 방향, 댓글 전체 | 커뮤니티 피드백 유도 |
| 반공개형 | 제목, 요약, 문제 정의 공개 / 상세 BM 제한 공개 | 도용 불안 완화 |
| 비공개 검증형 | 게시자, AI, 승인된 멘토 또는 관리자만 열람 | 민감 아이디어 보호 |
| 매칭형 공개 | 일반 사용자는 요약, 기업/투자자는 승인 후 상세 열람 | 사업화 기회 연결 |

## 구조화 피드백 유형
- 문제 공감
- 고객군 제안
- 수익 모델 제안
- 경쟁 서비스 제보
- 실행 난이도 의견
- 기능 개선 제안

## 아이디어 성장 타임라인
- 최초 등록 시점
- 주요 수정 이력
- 채택된 피드백과 기여자
- 시장 반응 변화
- 기업 관심 또는 비공개 문의 발생 시점
- 버전 업데이트

## 랭킹 기준
1. 가상 투자금
2. 기업 관심 수
3. 좋아요 수
4. 조회수

## 수익 모델
- 일반 사용자와 게시자는 무료
- 실제 투자/제휴 연결 수수료 없음
- 기업 인증 계정과 스폰서 광고로 수익화
- 스폰서 기업만 해당 게시글 하단에 배너 광고 등록 가능

## 구현 대안
| 고난도 기능 | MVP 대안 |
|---|---|
| 실제 금전 투자 | 가상 포인트 투자 |
| 완전 실시간 랭킹 | 1~5분 주기 갱신 |
| 사업자 인증 API | 기업 이메일 인증 + 관리자 승인 |
| 광고 결제 | 관리자 승인형 광고 등록 |
| 유사 아이디어 자동 연결 | 태그/카테고리 기반 추천으로 시작 |
| 법적 소유권 보장 | 타임스탬프, 버전 기록, 기여자 기록으로 현실적 대응 |
