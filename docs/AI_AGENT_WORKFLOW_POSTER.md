# AI Agent Development Workflow 포스터

AI Agent Challenge에서 Codex와 협업해 서비스를 개발한 과정을 정리한 A3 세로형 포스터입니다.

포스터는 다음 세 영역으로 구성됩니다.

1. Development Workflow
2. Agent Workflow
3. Agent Skills & Tools

## 산출물

- [A3 인쇄용 PDF](../booth-exhibition-poster/n091-park-changhyun-ai-agent.pdf)
- [Figma 편집본](https://www.figma.com/design/xt2pNGCDtZ8o4fh4VnikTu?node-id=33-2)

PDF는 ISO A3 세로 규격인 297 x 420 mm로 제작했습니다.

## Figma에서 PDF 내보내기

1. Figma에서 포스터 전체 프레임을 선택합니다.
2. 오른쪽 패널 하단의 `Export`에서 `+`를 누릅니다.
3. 형식을 `PDF`로 선택합니다.
4. 포스터 프레임을 내보냅니다.
5. 인쇄할 때 용지 크기를 A3, 방향을 세로로 설정합니다.

Figma 편집본은 우측 상단의 `Share`에서 보기 또는 편집 권한을 설정한 뒤 링크로 공유할 수 있습니다.
