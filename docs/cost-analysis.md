# Gemini API 비용 분석 (2026-07-20 기준)

## 요금제 (OpenRouter, `google/gemini-3-flash-preview`)

`server/proxy.js`의 `MODEL` 상수(`google/gemini-3-flash-preview`)를 기준으로 [OpenRouter 모델 페이지](https://openrouter.ai/google/gemini-3-flash-preview)에서 직접 확인한 실제 가격이다.

| 구분 | 가격 (100만 토큰당) |
| --- | --- |
| 입력(prompt) | $0.50 |
| 출력(completion) | $3.00 |

이미지 입력은 별도 단가가 명시되어 있지 않고, 텍스트로 환산된 토큰 수만큼 입력 단가로 과금되는 방식이다(Gemini 계열 모델은 이미지 1장을 대략 260~1,100 토큰 내외로 환산 — 해상도에 따라 달라짐). 아래 계산은 이미지 1장당 500 토큰으로 보수적으로 가정했다.

## 사용량 로깅 추가

`server/proxy.js`의 `/api/gemini` 핸들러가 OpenRouter 응답의 `usage`(OpenAI 호환 포맷 —
`prompt_tokens`/`completion_tokens`/`total_tokens`) 값을 콘솔에 로그로 남기도록 추가했다(이미지
포함 여부도 함께 남김). 실제 서비스 사용 후 이 로그를 근거로 위 표를 실측값으로 갱신할 수 있다.

## 주의

- 위 표는 **모든 사용자가 매일 데모 시나리오와 동일하게 사용한다는 가정** 하의 상한 추정치다. 실제로는 사용자마다 빈도가 다르고, 상당수는 하루 1~2회 정도만 쓸 가능성이 높다 — 실제 평균은 이보다 낮을 것으로 예상.
- OpenRouter 가격은 수시로 바뀌므로, 정기적으로 [모델 페이지](https://openrouter.ai/google/gemini-3-flash-preview)에서 재확인할 것.
- 1,000명 규모부터는 월 $570(약 77만 원) 수준이라 무시할 수 없는 금액 — 사용자가 늘면 실측 로그 기반으로 이 문서를 갱신하고, 필요하면 캐싱(같은 사진 재분석 방지 등)이나 요금제 재검토를 고려할 것.
