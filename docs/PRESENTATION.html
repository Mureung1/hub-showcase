차별점

AI 자동 채점 챌린지

  • 배점을 미리 공개 — 예: 사당 챌린지 = 구조 30 · 학습곡선 30 · 유도 20 · 근거 20
  • 공개된 배점대로 AI가 채점 — 총점 + 항목별 점수 + 한 줄 근거
  • 추가 API 비용 0 — 채점은 기존 피드백 호출에 통합
  • 점수순 리더보드 — 마감 후 제출작을 순위로 공개
