# Development Workflow

1. Check the GitHub Project backlog and select the next P0 issue.
2. Give the requirement to the Planning Agent and confirm its task breakdown.
3. Implement and test the issue on a feature branch.
4. Give the result to the Verification Agent and resolve P0 failures.
5. Open a pull request that references the related issues.
6. Update the Project status after review or merge.

## Agent Use

- Planning Agent: `docs/agents/planning-agent.md`
- Verification Agent: `docs/agents/verification-agent.md`
