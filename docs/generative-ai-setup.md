# 생성형 AI 연결

Noa의 생성형 AI 응답은 복구 키로 인증한 게스트 대화에서만 사용합니다. 익명 대화는 서버나
외부 AI를 호출하지 않고 브라우저 안의 규칙 기반 응답만 사용합니다.

## 요청 흐름

```text
게스트 키 인증
  → 사용자 입력과 최근 메시지 최대 6개 검증
  → 서버의 고정 안전 지침과 대화 문맥 구성
  → 새 메시지를 보낼 때만 Gemini 2.5 Flash-Lite 1회 호출
  → 응답과 감정 분석 기록 저장
```

백그라운드 연결, 폴링, 반복 호출은 없습니다. 요청 시간이 8초를 넘거나 공급자 호출이
실패하면 현재 대화를 중단하지 않고 로컬 규칙 기반 응답으로 대체합니다. AI 전용 사용량
한도에 도달하면 새 생성 요청을 보내지 않고 `Noa는 자고 있어요.`를 표시합니다.

## Render 환경 변수

Render Dashboard에서 `relationship-ai-api` 서비스의 `Environment`에 다음 값을 설정합니다.

| 이름 | 값 | 공개 여부 |
| --- | --- | --- |
| `GEMINI_API_KEY` | Google AI Studio에서 발급한 키 | Secret |
| `GEMINI_MODEL` | `gemini-2.5-flash-lite` | 일반 설정 |
| `AI_RATE_LIMIT_MAX` | `10` | 일반 설정 |

`GEMINI_API_KEY`는 Render에만 저장합니다. Vercel, React 코드, `VITE_` 접두사가 붙은 환경
변수에는 넣지 않습니다. 값을 바꾼 뒤에는 Render 서비스를 다시 배포해야 적용됩니다.

## 비용과 개인정보

- 무료 등급의 실제 한도와 정책은 Google AI Studio 프로젝트 설정을 기준으로 확인합니다.
- 앱 자체 한도는 게스트별 15분 동안 기본 10회입니다.
- AI 호출은 게스트가 메시지를 전송하는 순간에만 발생합니다.
- 공급자에게는 현재 입력, 최근 텍스트 메시지 최대 6개, 계산된 감정 점수와 근거 요약만
  전송합니다.
- 카메라 영상·사진·프레임·얼굴 좌표·전체 blendshape·장치 정보는 전송하지 않습니다.
- API 키와 `.env` 파일은 Git에 커밋하지 않습니다.
