# 생성형 AI 연결

현재 웹사이트는 게스트 세션에서만 Gemini Developer API를 호출합니다. 익명
사용자는 기존 브라우저 내 규칙 기반 답변을 사용하므로 외부 생성형 AI로 대화가
전송되지 않습니다.

## 요청 흐름

```text
게스트 키 인증
→ 사용자 입력 및 최근 대화 최대 6개 검증
→ 위기 표현이면 서버의 고정 안전 응답
→ 그 외 요청만 Gemini 2.5 Flash-Lite 호출
→ 생성된 답변을 감정 분석 기록과 함께 저장
```

Gemini 요청이 실패하거나 8초를 넘으면 프런트는 기존 규칙 기반 답변을 사용합니다.
요청마다 한 번의 HTTPS 호출만 만들며 백그라운드 연결이나 반복 호출은 유지하지
않습니다.

## Render 환경변수

Render Dashboard에서 `relationship-ai-api` 서비스를 열고
`Environment`에 다음 값을 설정합니다.

| 이름 | 값 | 공개 여부 |
| --- | --- | --- |
| `GEMINI_API_KEY` | Google AI Studio에서 발급한 API 키 | Secret |
| `GEMINI_MODEL` | `gemini-2.5-flash-lite` | 일반 설정 |
| `AI_RATE_LIMIT_MAX` | `10` | 일반 설정 |

`GEMINI_API_KEY`는 Vercel이나 `VITE_` 환경변수에 넣지 않습니다. 저장 후 Render
서비스를 재배포해야 새 환경변수가 적용됩니다.

## 무료 등급 주의사항

- 무료 등급의 실제 요청 한도는 Google AI Studio의 프로젝트별 제한을 따릅니다.
- 무료 한도를 넘으면 서비스는 로컬 답변으로 자동 전환합니다.
- 무료 등급에 전송된 내용은 제공자의 제품 개선에 사용될 수 있습니다.
- 카메라 영상, 얼굴 좌표, 전체 blendshape 데이터는 전송하지 않습니다.
- 전송 대상은 입력 문장, 최근 텍스트 대화 최대 6개, 계산된 감정 점수와 근거
  요약뿐입니다.
