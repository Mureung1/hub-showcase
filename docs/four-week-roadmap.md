## 작업 분해 기준

- 한 작업은 한 번에 검증 가능한 크기로 쪼갠다.
- UI 작업과 로직 작업을 가능하면 분리한다.
- AI에게 지시할 때는 파일명보다 사용자가 확인할 동작을 중심으로 설명한다.
- 큰 기능은 체크리스트를 먼저 만든 뒤 구현한다.
