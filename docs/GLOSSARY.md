# GLOSSARY

**이 문서의 역할**: 문서와 코드가 같은 단어를 같은 뜻으로 쓰게 고정한다. 뜻만 적고 사양·수치·처리 규칙은 적지 않는다 — 그쪽은 `PRD.md`가 단일 출처다.

| 용어 | 의미 |
|---|---|
| 리뷰지기 | 소상공인 사장님의 리뷰 답글, 분석, 악성 리뷰 대응을 돕는 AI 에이전트 |
| 사장님 | 제품의 사용자. 리뷰 기능이 있는 플랫폼을 쓰는 외식업 소상공인 |
| 리뷰 | 고객이 배달 플랫폼 등에 남긴 별점과 본문 |
| 리뷰 유형 | 칭찬, 불만, 문의, 악성 의심 중 하나 |
| 칭찬 | 긍정 경험 위주이며 별도 요구사항이 없는 리뷰 |
| 불만 | 맛, 양, 배달, 포장, 서비스에 대한 구체적 부정 경험이 있는 리뷰 |
| 문의 | 영업시간, 메뉴, 배달 범위, 원산지 등 질문이 포함된 리뷰 |
| 악성 의심 | 욕설, 비하, 협박, 보상 강요, 허위 사실 정황, 반복 저격이 감지된 리뷰 |
| 복합 리뷰 | 칭찬과 불만이 함께 있는 리뷰 |
| 분류 근거 | AI가 해당 유형으로 분류한 이유를 사장님이 이해할 수 있게 쓴 한 줄 설명 |
| 답글 초안 | AI가 만든 리뷰 답글 후보. 사장님이 확인·수정 후 복사한다 |
| 답글 상태 | 초안 대기, 확인 필요, 완료 중 하나 |
| 초안 대기 | 답글 초안은 있지만 사장님이 아직 확인하지 않은 상태 |
| 확인 필요 | 악성 의심, 분류 애매, 별점·본문 불일치처럼 사장님 판단이 필요한 상태 |
| 완료 | 사장님이 외부 플랫폼에 답글을 게시하고 제품 안에서 완료로 표시한 상태 |
| 매장 프로필 | 매장명, 업종, 대표 메뉴, 답글 톤, 운영 정보, 이벤트, 금지 표현의 집합 |
| 운영 정보 | 영업시간, 휴무일, 배달 범위, 주차, 원산지 등 문의 답변에 쓰는 근거 정보 |
| 금지 표현 | 답글 초안에 들어가면 안 되는 표현. 예: 무조건, 환불 약속, 서비스 약속 |
| 콜드 스타트 | 누적 리뷰가 적어 분석 리포트를 신뢰하기 어려운 상태. 기준 건수는 PRD 2.4 |
| AI 인사이트 | 리뷰 데이터 변화에서 행동 가능한 개선 포인트를 요약한 카드 |
| 위험도 | 블랙컨슈머 대응을 위해 나누는 ① 단순 불만, ② 정당한 클레임, ③ 악성 단계 |
| 단순 불만 | 감정적 표현은 있으나 실제 경험 기반이고 별도 요구가 없는 불만 |
| 정당한 클레임 | 구체적 피해 사실과 합리적 요구가 있는 리뷰 |
| 악성 | 협박, 인신공격, 과도한 보상 요구, 허위 사실 정황, 반복 저격 등이 있는 리뷰 |
| 대응 매뉴얼 | 악성 리뷰에 대해 답글 가이드, 신고 절차, 증거 수집, 법적 대응 일반 안내를 제공하는 흐름 |
| 사례 아카이브 | 악성 의심 사건 단위 기록. 재발 확인과 증거 정리에 사용한다 |
| 매장 격리 | 리뷰·답글·프로필·사건·증거 파일을 매장 소유권 단위로 나눠, 다른 계정이 조회·수정할 수 없게 하는 것 |
| 제외 기능 | 만들지 않기로 하고 이유까지 적어 둔 기능. 목록은 PRD 7장 |
| Phase | 하네스 실행 단위(00~07). 제품 기능 구분이 아니라 개발 실행 순서다 (`HARNESS/phases/PHASE_PLAN.md`) |
