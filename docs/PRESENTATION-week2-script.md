## 슬라이드 3 — 아키텍처 (약 50초)

"연결 구조는 이렇게 세 층이에요. *(가운데 흐름도 가리키며)* 왼쪽 React 화면이 `/api`로 요청을 보내면, 가운데 Express가 받아서, 오른쪽 Supabase의 `documents` 테이블 하나에 저장합니다.

설계에서 신경 쓴 세 가지가 아래 카드인데, 하나만 짚으면 — **교체 지점을 `storage.js` 파일 하나로 몰았어요.** 원래 localStorage에 저장하던 함수들인데, 이름이랑 모양은 그대로 두고 안쪽만 서버 호출로 바꿨거든요. 그래서 화면 코드는 거의 안 건드리고 데이터 출처만 갈아끼울 수 있었습니다.

그리고 오른쪽 카드 — 이번 주 미션 중 하나가 **기능 검증 에이전트**를 만드는 거였는데, 저장이 진짜 되는지 왕복으로 확인하는 서브에이전트를 따로 만들어서 이 슬라이스를 검증했어요. 뒤에서 결과 보여드릴게요."

## 슬라이드 4 — 데모 플로우 / 라이브 데모 (약 3분)

"자, 말로만 하면 안 믿기니까 실제로 한 바퀴 돌려보겠습니다."

*(브라우저로 전환. localhost:5173, 개발자도구 Network 탭 열어둔 상태)*

> **행동 → 나타나는 것** 형식으로 진행. 슬라이드 4의 7단계와 같은 순서.

**① 작성 시작**
- *내가:* 상단 **작성하기** 클릭 → **시스템 템플릿** 선택
- *나타나는 것:* 백지가 아니라 **개요·시스템 규칙·유저 플로우…** 섹션이 미리 깔리고, 각 섹션 옆에 "이 섹션에서 다뤄야 할 것" 가이드가 뜬다
- *멘트:* "보시면 백지가 아니라 뭘 써야 할지 안내가 같이 나와요."

**② 임시저장 → 서버가 uuid 발급**
- *내가:* 개요 섹션에 한두 줄 쓰고 → **임시저장** 클릭
- *나타나는 것:* (1) 화면에 "임시저장됨 · 시각"이 뜨고 (2) **Network 탭에 `POST /api/documents` → 201**, 응답 JSON에 서버가 만든 **`id`(uuid)**가 찍힌다
- *멘트:* "지금 이 uuid를 **서버가** 만들어서 돌려준 거예요. 프론트에서 만든 임시 id가 아니라, DB에 실제 행이 생겼다는 뜻입니다." *(마이페이지 잠깐 열어 초안이 뜬 것도 보여줌)*

**③ AI 피드백**
- *내가:* 다시 에디터로 와서 **AI 피드백 받기** 클릭
- *나타나는 것:* 각 섹션 아래에 **섹션별 코멘트**가 붙는다 (지금은 모의 응답)
- *멘트:* "실제 Claude 연동은 4주차 예정이고, 지금은 자리와 흐름만 잡아둔 모의 응답이에요."

**④ 발행 → 같은 행 status flip**
- *내가:* 상단에 **대상 게임**·**시스템 유형** 태그를 채우고 → **발행** 클릭
- *나타나는 것:* 주소가 **`/archive/<uuid>`** 로 바뀌면서 상세 페이지로 이동. Network엔 **`PATCH`** 요청
- *멘트:* "발행이 초안을 지우고 새로 만드는 게 아니라, **같은 행의 상태만 draft→published로 뒤집는** 거예요. 그래서 아까 그 uuid가 주소에 그대로 있죠."
- *(선택) 반례:* "만약 태그를 안 채우고 발행하면 — *(비워서 시도)* — **에러가 나요. 이건 화면이 막는 게 아니라 DB 제약이 막는 거예요.**"

**⑤ 코멘트 → 새로고침 (핵심 증거)**
- *내가:* 상세에서 아무 섹션에 **코멘트를 하나 달고** → **F5로 새로고침**
- *나타나는 것:* 새로고침했는데 **코멘트가 그대로 남아 있다**
- *멘트:* "**이게 제일 중요한 장면이에요.** 화면 상태였으면 새로고침에 날아갔을 텐데, 남아 있다는 건 **DB에 실제로 저장됐다**는 뜻입니다."

**⑥ 목록 반영**
- *내가:* **둘러보기(아카이브)** 로 이동
- *나타나는 것:* 방금 발행한 문서가 **카드로** 떠 있다 (미리 시드해둔 데모 문서와 함께). 마이페이지엔 "받은 피드백" 수 반영
- *멘트:* "다른 화면에서도 같은 DB를 보니까 바로 나타나죠."

**⑦ DB 증거 (쐐기)**
- *내가:* 터미널에서 `curl "http://localhost:4000/api/documents?status=published"` *(또는 Supabase 대시보드 테이블 열기)*
- *나타나는 것:* 방금 만든 문서가 **JSON / 테이블 행으로** 그대로 나온다
- *멘트:* "화면을 안 거치고 서버에 직접 물어봐도 같은 데이터가 나옵니다. 여기까지가 한 바퀴예요."

*(슬라이드로 복귀, ↓)*
