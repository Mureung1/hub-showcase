### 자막을 ffmpeg 으로 굽지 않는 판단 (재확인)

이 맥의 ffmpeg `8.1.2_1` 에는 `--enable-libass`·`--enable-libfreetype` 이 없어 `subtitles`·`ass`·`drawtext` 필터가 **존재하지 않는다**. Homebrew 포뮬러의 Required deps 에도 libass 가 없어 `brew reinstall` 로는 안 생기고 소스 빌드가 필요하다.

다만 **설치하지 않는 이유는 비용이 아니라 표현력이다.** 지금 자막이 쓰는 둥근 pill·반투명 배경·`backdrop-filter: blur`·페이드는 ASS 로 재현이 안 되거나 조잡해진다. libass 의 유일한 이점(재녹화 없이 자막만 교체)은 `record.mjs` 가 남아 있어 실익이 작다. 자세한 비교는 [demo-video-script.md](../demo-video-script.md) §3.

### 비주얼 변형 — Apple 판 추가 제작

같은 큐시트·자막·타이밍으로 **CSS 만 바꿔** 한 벌 더 만들었다(`~/Downloads/hub-demo-apple.mp4`, 4:50.6). 영상의 픽셀이 전부 HTML/CSS 에서 나오기 때문에 가능한 일이다 — 스타일 교체는 mp4 편집이 아니라 CSS 수정 + 재렌더다.

**`~/Downloads/hub-demo-final.mp4`, 4:57.4** (5분까지 여유 2.6초). 웹에서 실제로 통용되는 **공부법 30개**(뽀모도로·파인만·코넬 노트·백지 복습·액티브 리콜·인터리빙·SQ3R·간격 반복 …)가 흩뿌려져 흐르다가, 필드가 물러나고 **발표자료 표지**(빈티지 에디토리얼 카드)가 떠오르는 구성이다.

## 2. Gemini 키 반영 확인

```
POST /api/mbti-chat  (consent:true, knownMbti:"INTJ")
→ {"available":true,"estimated":true,"mbti":"INTJ","confidence":"mid",
   "observedSignals":[{...focusEnergy},{...memoryStrategy},{...planningStability}]}
```

- 어제까지 `available:false` (키 없음) → 지금 정상. 규칙 폴백도 그대로 살아 있다
- 하드룰 점검: 전부 "…일 수 있음" 가능성 표현, 진단·성적예측·유형 우열 표현 없음
- **주의**: `/api/mbti-chat` 의 messages 필드는 `content` 가 아니라 **`text`** 다(`llm.js` 의 `contents` 필터가 `m.text` 를 본다). 잘못된 필드로 부르면 `contents.length === 0` 이라 0.3초 만에 `fallback:true` 가 떨어져 **키 문제로 오진하기 쉽다**

**사용자가 직접 해야 하는 것** — Supabase 대시보드 SQL Editor:

```sql
select id, anon_id, mbti, created_at from research_results order by created_at desc;
-- 2026-07-28 07:00~08:20Z 구간의 데모 건 id 를 확인한 뒤 그 id 만 삭제
```

테이블 `research_results`, 컬럼 `anon_id`·`created_at` (`backend/src/store.supabase.js`). 시간 범위로 뭉텅이 삭제는 파일럿 데이터가 섞일 수 있어 권하지 않는다.
