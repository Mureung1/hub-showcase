# 기능 스펙: 공공데이터 기반 상권 분석

## 1. 기능 구분

```text
구분: 주기능
우선순위: P0
```

LocalTwin의 핵심 기능이다. 사용자는 특정 상권 1곳을 기준으로 점포 분포, 동일 업종 경쟁 강도, 개업/폐업 흐름, 시간대별 유동 특성, 입지 점수, AI 해석 리포트를 확인한다.

## 2. 목표

```text
예비창업자 또는 소상공인이 특정 상권의 입지와 경쟁 환경을 빠르게 이해할 수 있게 한다.
```

## 3. 입력

```text
분석 대상 상권
분석 중심 위치 또는 가게 위치
분석 반경: 100m / 300m / 500m
대상 업종: 카페 또는 음식점 1개 업종부터 시작
```

## 4. 데이터 후보

실제 API 필드, 제공 방식, 이용 조건은 구현 직전에 확인한다.

| 데이터 | 사용 목적 |
| --- | --- |
| 상가업소정보 | 주변 점포, 업종 분포, 동일 업종 경쟁 강도 |
| 지방행정 인허가정보 | 개업/폐업 흐름, 영업상태, 업종 변화 |
| 생활인구/유동인구 데이터 | 시간대별 수요, 평일/주말 유동 특성 |
| 공간/용도지역 데이터 | 입지 맥락, 주거/상업 인접성 |
| 지도 API | 지도 표시, 마커, 반경 표시, 주소/좌표 변환 |

## 5. 출력

```text
상권 지도
반경 내 전체 점포 수
반경 내 동일 업종 점포 수
업종 분포
개업/폐업 추세
시간대별 유동 특성
입지 점수
AI 해석 리포트
```

## 6. 입지 점수 v0.1

v0.1은 설명 가능한 규칙 기반 점수로 시작한다.

```text
입지 점수 = 수요 점수 + 경쟁 점수 + 변화 점수 + 공간 점수 + 시간대 점수
```

| 항목 | 데이터 |
| --- | --- |
| 수요 점수 | 생활인구/유동인구, 직접 촬영 관찰값 |
| 경쟁 점수 | 동일 업종 점포 수, 업종 밀도 |
| 변화 점수 | 개업/폐업 흐름 |
| 공간 점수 | 용도지역, 상권 유형 |
| 시간대 점수 | 10시/13시/15시/18시 혼잡도 관찰값 |

## 7. 화면 요구사항

```text

반경 100m / 300m / 500m 선택
동일 업종 수 표시
업종 분포 요약
개업/폐업 추세 표시
시간대별 유동 그래프 표시
입지 분석 카드 표시
AI 해석 리포트 표시
```

## 8. v0.1 완료 기준

```text
특정 상권 1곳의 데이터를 조회할 수 있다.
카페 또는 음식점 1개 업종 기준으로 분석할 수 있다.
반경 내 동일 업종 경쟁 강도를 계산할 수 있다.
개업/폐업 흐름을 표시할 수 있다.
시간대별 유동 특성을 표시할 수 있다.
규칙 기반 입지 점수를 계산할 수 있다.
AI 해석 리포트를 생성할 수 있다.
```
