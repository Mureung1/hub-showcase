# 기능 스펙: 혼잡도 3D 기반 탐색

## 1. 기능 구분

```text
구분: 보조/추가기능
우선순위: P1
```

이 기능은 LocalTwin의 주기능이 아니다. 상권 분석 결과를 현실 공간 위에서 더 직관적으로 이해하도록 돕는 보조 기능이다.

## 2. 목표

```text
한 가게 앞 또는 한 거리 10~20m 구간을 정적 3D map으로 탐색하고,
시간대별 혼잡도 관찰값을 공간 위에서 확인한다.
```

## 3. 핵심 원칙

```text
서비스는 원본 영상을 보여주지 않는다.
서비스는 정적인 3D map을 보여준다.
3D 복원용 촬영과 시간대별 혼잡도 촬영은 분리한다.
모든 시간대 영상을 3D 학습에 섞지 않는다.
```

## 4. 입력

### A. 3D 복원용 입력

```text
사람 적은 시간 1회 촬영
가게 앞 또는 거리 10~20m
3~5분 영상 또는 충분히 겹치는 사진
```

### B. 시간대 혼잡도 입력

```text
10:00 오전 유동
13:00 점심 이후
15:00 오후 카페/체류
18:00 퇴근/저녁
```

각 시간대는 같은 위치와 같은 각도에서 1~2분 정도 촬영하거나 관찰한다.

## 5. 처리 흐름

```text
3D 복원용 촬영
→ 프레임 추출
→ 사람 영역 익명화 전처리
→ 정제 이미지 기반 3D map 생성
→ 웹 3D 뷰어 로드
→ 가게 마커 배치
→ 상권 정보 카드 연결
```

```text
시간대별 촬영/관찰
→ 사람 수 또는 혼잡도 등급 산정
→ 시간대별 관찰 데이터 저장
→ 3D 장면의 마커/카드/오버레이로 표시
```

## 6. 출력

```text
정적 3D map
가게 또는 관찰 지점 마커
상권 정보 카드
10시 / 13시 / 15시 / 18시 시간대 선택 UI
시간대별 사람 수 또는 혼잡도 등급
가게 앞 체류 여부
배달/차량 흐름 메모
```

## 7. 혼잡도 데이터 v0.1

v0.1에서는 수동 입력을 허용한다.

```text
person_count_avg
congestion_level: low / medium / high
stay_score: low / medium / high
movement_note
vehicle_delivery_note
observer_note
```

자동 탐지는 v0.2 이후 선택 확장으로 둔다.

## 8. v0.1 완료 기준

```text
한 가게 앞 또는 거리 10~20m의 정적 3D map을 웹에서 열 수 있다.
3D 장면에서 가게 마커를 클릭할 수 있다.
마커 클릭 시 상권 정보 카드가 열린다.
10시 / 13시 / 15시 / 18시 버튼 또는 탭이 있다.
각 시간대별 혼잡도 관찰값이 표시된다.
원본 영상은 서비스 화면에 노출하지 않는다.
```

## 9. 제외 범위

```text

정확한 Mesh 충돌/측정 기능
```
