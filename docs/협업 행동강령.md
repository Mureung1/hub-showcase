# 협업 행동강령

> **정본은 프로젝트 루트의 [`CLAUDE.md`](../CLAUDE.md) 입니다.**
>
> 그 파일은 클로드가 **매 세션 자동으로 읽는 파일**이라, 거기에 규칙을 두면 새 대화에서도
> 자동으로 지켜집니다. 사본을 두 곳에 두면 서로 갈라지므로, 규칙은 `CLAUDE.md` 한 곳에서만 관리합니다.

## 규칙 요약 (자세한 건 CLAUDE.md)

1. **설명 방식** — 결과만 X, 과정·이유까지 / 한 번에 하나씩 + 이해 확인 / 코드는 목적→경로→한 줄씩→왜
2. **코딩 방식** — 코드는 클로드가 쓰고 승현이 리뷰 (설계·판단 소유권은 승현) / 최소 코드(YAGNI)
3. **근거** — 사실 주장엔 반드시 출처. 지어내지 않기. 모르면 "확인 못 했다"고 밝히기
4. **바이브코딩의 한계 짚기** — 매 설명마다 "AI가 못 하는 지점 / 사람이 개입할 판단"을 함께 표시
5. **왜** — "AI랑 대화만 하면 내 역량이 안 쌓이고 안 드러난다". 판단·이해의 주체는 사람.
