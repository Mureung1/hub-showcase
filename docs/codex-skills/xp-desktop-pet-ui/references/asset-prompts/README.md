# Asset Prompt Structure

This reference mirrors the project folder:
`docs/asset-prompts`

Use it when generating or revising pixel assets. The source docs remain the project authority; this skill keeps the working rules short.

## Sections

- `00-style-guide`: shared visual language and negative prompts.
- `01-manager-sprite`: Lumi/electronic lifeform sprite rules.
- `02-room-backgrounds`: XP wallpaper and background prompts.
- `03-ui-kit`: desktop icon and XP UI kit prompts.
- `04-rewards`: reward and unlockable object prompts.
- `05-social-world`: future social exploration prompts.
- `06-pixel-tv`: future reality-pixel-TV prompts.
- `07-audio-visual-fx`: reaction, completion, and UI FX prompts.

## Core Asset Rules

- Text and UI controls are code-native.
- Background, manager, icons, rewards, and FX are image assets.
- Use transparent background for sprites/icons/rewards/FX.
- Do not generate realistic animals for Lumi.
- Do not include watermark, signature, logo, or fake UI text.
- Check assets at small sizes: 32px, 48px, 64px.
