# Manager Sprite Prompt Rules

- Lumi is a small electronic lifeform desktop pet.
- Pink/cream/mint palette is preferred.
- It must not be a cat, dog, or realistic animal.
- Replacement-character candidate: use the pink animal same-size evolution direction from `docs/asset-prompts/01-manager-sprite/pink-animal-samesize-evolution.md`.
- For that candidate, animal-like cuteness is allowed, but Stage 1-4 must keep nearly the same size, viewpoint, center, and baseline.
- Candidate evolution should add polish, ears, paws, cheek fur, paw pads, tail, or tiny accessories; it must not become taller, older, humanoid, hairy-legged, or more electronic.
- Produce transparent-background states:
  - idle waiting
  - quest running
  - happy completion
  - rebalancing
  - recovery ready
  - resting
  - window-edge hanging
  - hiding behind or peeking from a window
- Window interaction sprites should not include a baked full XP window; render the window edge, z-index layer, and clipping in the app.
- Keep silhouette readable at 64px.
