# Background Prompt Rules

- Current preferred direction: one complete background image, not awkward layer composition.
- Target asset path: `public/assets/background/background.png`.
- Composition: XP-like blue sky, clouds, green meadow, calm and readable.
- Leave open sky space for desktop icons and windows.
- No characters, UI windows, taskbar, logo, or text inside the background.
- Use `center bottom / cover` in CSS.
