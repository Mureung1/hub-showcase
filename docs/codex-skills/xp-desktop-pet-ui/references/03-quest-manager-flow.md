# Quest Manager Flow

## Onboarding

- First visit shows Profile Setup Wizard.
- After save, show the XP desktop.
- The profile wizard must not remain open after setup.
- Profile is reopened only through the desktop profile icon.

## Default Desktop

- Open only Today Quest and Manager by default.
- Notes and Profile are auxiliary windows.
- Do not show future modules by default.

## Today Quest

- The quest draft can be edited before acceptance.
- Editable fields: title, type, amount, difficulty, deadline.
- Quest types are fixed: time, quantity, action.
- Accepting the quest closes the quest draft and opens QuestRunner.exe.

## QuestRunner.exe

- Show [RUN] badge and quest title.
- Show remaining time, completion condition, EXP.
- Do not show a separate status row; it duplicates [RUN].
- Menu candidates must not duplicate visible buttons.
- Current menu candidate meanings:
  - File: export records, view today run log.
  - Quest: view quest history, view recovery suggestion history.
  - Help: app info, QuestRunner guide.

## Failure And Recovery

- Failure does not reduce EXP.
- Failure opens reason selection.
- Recovery quest is smaller and lower reward.
- Recovery edit closes the recovery window and opens only the quest window.
- Avoid opening two accept-able quest windows at once.

## Manager

- Lumi is an electronic pacemaker/desktop pet.
- Lumi grows through EXP and state changes.
- Failure state is waiting/rebalancing, not disappointment or punishment.
