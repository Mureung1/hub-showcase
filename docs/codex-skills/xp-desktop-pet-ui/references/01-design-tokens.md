# Design Tokens

## Typography

- UI font: Tahoma, Malgun Gothic, Gulim, sans-serif.
- Pixel font only for short game-like labels: manager name, level, status.
- Do not scale font size with viewport width.
- Letter spacing is 0.
- Window title: 12px, 700, white.
- Desktop icon label: 12px, white, 1px blue shadow.
- Form labels and lists: 12-13px.
- Manager dialogue: 13px, line-height 1.6, max 2 lines.

## Palette

- XP blue: #2a8bf2, #1673dd, #0a58bd, #0645a5, #003c74.
- Window surface: #ece9d8.
- Raised surface: #f8f6ee.
- Inset surface: #d6d0c4.
- Dialogue surface: #f1ede2.
- Text primary: #1f1f1f.
- Text secondary: #55514a.
- EXP/reward: #c98300.
- EXP fill: #43a54b.

## Geometry

- Window radius: 7px top, 3px bottom.
- Control radius: 2px.
- Panel radius: 4px.
- Large rounded modern cards are forbidden.
- Window body padding: 12px by default, 16px only when forms need it.
- Taskbar height: 34-36px.
- Window title height: 26-27px.

## Shadows

- Use hard XP-style shadows and bevels.
- Avoid soft modern blur shadows, glassmorphism, backdrop blur, glow.
