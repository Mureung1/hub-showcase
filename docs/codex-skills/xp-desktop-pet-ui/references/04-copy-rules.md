## Dialogue Placement

- Dialogue appears only in the manager window bottom dialogue panel.
- Do not repeat speaker name in the dialogue panel.
- Reaction bubble is empty and temporary.
- QuestRunner, failure, and recovery windows do not contain Lumi speech.

## Product Copy

- Avoid large service-name hero text in the app UI.
- Use window titles such as Manager.exe, Today Quest, QuestRunner.exe.
- Hide developer concepts from users.
