# LocalTwin 공개 데모 Runbook

이 문서는 한국어 기본 제품 경로(`/`) 발표를 위한 운영 메모다. 제출용 영어 데모(`/en`)는
별도 산출물이며, 이 runbook의 수정·복구 대상이 아니다.

## 1. 발표 전 3분 점검

1. [공개 Web](https://localtwin-product.vercel.app/)을 새 탭에서 연다.
2. [API readiness](https://localtwin-api.onrender.com/ready)가 `200`과 `"status":"ready"`를 반환하는지 확인한다.
3. Web 상단에서 `서울 상권분석 공식 데이터를 불러왔습니다.` 문구와 분기 선택기를 확인한다.
4. 연남동 골목상권 · 카페 · 직접 선택 · 300m에서 주변 점포 목록과 우측 분석 패널이 보이는지 확인한다.

Render Free 인스턴스가 idle 상태였다면 `/ready` 첫 요청에 시간이 걸릴 수 있다. 이때 Web은
지원 범위만 정적으로 보여 주고 분석 수치를 예시 값으로 바꾸지 않는다. `준비 중` 문구가
사라질 때까지 기다린 뒤 새로고침할 필요 없이 화면이 실제 API 요청을 시작하는지 확인한다.

## 2. 5분 발표 순서

| 시간 | 조작 | 전달할 메시지 | 기대 화면 |
| --- | --- | --- | --- |
| 0:00–0:40 | 홈 URL을 연다 | LocalTwin은 예비 소상공인이 상권·점포 데이터를 이해하기 쉽게 보는 도구다. | 중립 URL `/`, 분석 workspace |
| 0:40–1:30 | 연남·홍대·합정 상권을 바꾼다 | 상권 단위 데이터와 지도 표현이 함께 바뀐다. | 좌측 조건·우측 분석 패널 갱신 |
| 1:30–2:20 | 카페 업종과 100m·300m·500m 반경을 바꾼다 | 반경은 실제 주변 점포·밀도용이고, 매출·유동인구는 공식 상권 단위임을 분리한다. | 반경 원·점포 목록·동일 업종 수 갱신 |
| 2:20–3:20 | 지도에서 위치 선택 → 확정 | 원하는 위치에서 주변 경쟁을 확인할 수 있다. | 새 중심·반경과 목록 갱신 |
| 3:20–4:15 | `LocalTwin`과 `실제 지도`를 전환하고 건물 레이어를 토글한다 | 일반 basemap은 유지하고 지원 영역에만 LocalTwin 전용 표현을 겹치지 않게 추가한다. | Overlay·기본 지도 전환 |
| 4:15–5:00 | 데이터 도움말 또는 근거 보기를 연다 | 각 지표는 기간·출처·공간 기준과 함께 해석한다. | 출처·기간·용어 도움말 |

## 3. 장애별 복구

| 증상 | 확인 | 발표 중 행동 |
| --- | --- | --- |
| `분석 서버를 준비하고 있습니다`가 계속 표시 | `/ready`를 한 번 연다. | 1분 내라면 "무료 개발 서버를 깨우는 중"이라고 안내하고, 준비 뒤 자동 갱신되는 실제 데이터를 사용한다. |
| API 오류·다시 시도 버튼 | Render API 상태 또는 네트워크를 확인한다. | 오류를 빈 결과나 예시 분석으로 설명하지 않는다. `다시 시도` 후 정상 화면이 복구되면 이어 간다. 복구가 안 되면 지도·지원 범위·데이터 기준 화면까지만 시연하고 API 분석은 중단했다고 명확히 말한다. |
| 지도 타일이 늦거나 WebGL이 표시되지 않음 | 새로고침 후 브라우저 hardware acceleration을 확인한다. | `실제 지도` mode로 전환해 기본 지도를 먼저 보여 준다. 계속 실패하면 데이터 도움말·분석 근거 dialog로 전환한다. |
| 특정 점포 선택이 오래된 상태로 남음 | 분석 조건 또는 위치를 한 번 변경한다. | 이전 점포가 해제되고 최신 조건의 목록으로 바뀌는 것을 확인한 뒤 다시 선택한다. |

## 4. 발표 중 지키는 원칙

- API가 실패했을 때 정적 snapshot을 실제 조회 결과인 것처럼 보이지 않는다.
- DB URL, API key, Render·Supabase credential을 화면이나 console에 표시하지 않는다.
- `/en`은 이번 발표용 제품 흐름과 별개이므로 수정·복구 대상으로 삼지 않는다.
- 발표 전에는 실제 공개 URL을 열어 API를 한 번 깨운다. 이 절차는 데모를 더 빠르게 시작하기 위한 운영 준비이며, 제품 데이터의 출처를 바꾸지 않는다.
