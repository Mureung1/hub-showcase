# 개발 Task 백로그

> 팀플 올인원 — 4주 개발 계획
> 우선순위: 🔴 높음 / 🟡 중간 / 🟢 낮음

## 백로그란?
앞으로 할 일을 우선순위 순으로 쌓아둔 목록. 개발 중에 "다음에 뭐하지?" 하고 흔들리지 않게 하기 위함. 하나 끝내면 체크하고 다음으로. 새 할 일이 생기면 목록에 추가한다.

---

## 2주차 — 코어 기능 (태스크 관리)

- [ ] 🔴 SQLite DB 연결 및 테이블 생성 (users, teams, tasks)
- [ ] 🔴 태스크 CRUD API (조회/추가/수정/삭제)
- [ ] 🔴 React에서 태스크 목록 불러와 표시
- [ ] 🔴 태스크 추가 기능 연결
- [ ] 🔴 완료 체크 토글 + 진행률 계산
- [ ] 🟡 팀 진행도 / 내 진행도 분리 표시
- [ ] 🟡 태스크 담당자·마감일 표시

**2주차 끝 목표**: 브라우저에서 할 일을 추가하고 완료 체크하면 진행률이 바뀐다.

---

## 3주차 — 로그인 + 팀 + 회의시간 매칭

- [ ] 🔴 회원가입/로그인 API (bcrypt 해싱)
- [ ] 🔴 JWT 토큰 발급 및 검증 미들웨어
- [ ] 🔴 팀 생성 + 초대코드 자동 생성
- [ ] 🔴 초대코드로 팀 참여
- [ ] 🔴 내 팀 목록 화면
- [ ] 🔴 availability 테이블 + 가능 시간 입력 API
- [ ] 🔴 날짜 기반 격자 UI (주 단위 전환)
- [ ] 🔴 겹치는 시간 계산 + 색 농도 표시
- [ ] 🟡 모두 가능한 시간 목록 (날짜 순 정렬)
- [ ] 🟢 팀 최대 8명 제한 처리

**3주차 끝 목표**: 로그인하고 팀 만들어서, 회의 시간 맞추고 할 일 관리한다.

---

## 4주차 — 마무리 + 배포

- [ ] 🔴 배포 (Render 또는 Railway) → 실제 URL
- [ ] 🔴 빈 화면 처리 (태스크 없을 때, 팀 없을 때)
- [ ] 🟡 activity_log 기록 + 기여도 차트
- [ ] 🟡 보관(archive) 처리 — 기한 지난 팀
- [ ] 🟡 마감 임박 강조 표시
- [ ] 🟢 초대코드 재발급 기능
- [ ] 🟢 태스크 난이도 가중치 (확장 기능)

**4주차 끝 목표**: 배포된 URL로 누구나 접속해서 쓸 수 있다.
