# 사이사이 기획서

## 1. 프로젝트 개요

사이사이는 같은 건물 또는 가까운 생활권에 거주하는 사람들을 연결하는 생활 커뮤니티 서비스입니다.

사용자는 자신이 속한 커뮤니티 안에서 자유롭게 이야기를 나누고, 생활 속 도움을 요청하고, 필요한 상품을 함께 구매할 사람을 모집할 수 있습니다.

## 2. 문제 정의

가까운 곳에 살아도 이웃끼리 서로 알기 어렵고, 생활 문제를 혼자 해결해야 하는 경우가 많습니다.

특히 원룸, 오피스텔에 거주하는 대학생과 1인 가구는 다음과 같은 문제를 자주 겪습니다.

- 생활권 안에서 필요한 정보를 빠르게 공유하기 어렵다.
- 전등 교체, 벌레 처리, 택배 수령처럼 작은 도움을 요청할 곳이 마땅하지 않다.
- 생필품이나 식재료를 대량으로 사면 저렴하지만 혼자 쓰기에는 부담스럽다.
- 배달 음식이나 생활용품을 함께 구매할 사람을 찾기 어렵다.

사이사이는 가까운 생활권 사람들을 하나의 커뮤니티로 연결해 **정보 공유, 도움 요청, 공동구매**를 쉽게 할 수 있도록 합니다.


## 3. 타깃 사용자

- 대학가 근처 원룸 또는 오피스텔에 거주하는 대학생 및 1인 가구
- 가까운 이웃과 생활 정보를 나누고 싶은 사용자
- 생필품, 식재료, 배달 음식 등을 함께 구매해 비용을 줄이고 싶은 사용자
- 생활 속 작은 도움을 요청하거나 제공하고 싶은 사용자
- 같은 건물 또는 가까운 블록 안에서 커뮤니티를 만들고 싶은 사용자

## 4. 커뮤니티 단위

### 4.1 건물형 커뮤니티

건물형 커뮤니티는 한 건물, 같은 동, 또는 같은 단지 안에 충분한 사용자가 있는 주거 형태에 적용합니다.

예시는 다음과 같습니다.

- 아파트 같은 동
- 대형 오피스텔 한 동
- 기숙사 한 동
- 거주자가 충분한 원룸 건물

### 4.2 블록형 커뮤니티

블록형 커뮤니티는 한 건물의 거주 인원이 적은 원룸 밀집 지역에 적용합니다.

블록은 같은 골목, 도보 생활권, 편의점이나 학교 주변처럼 사용자가 실제로 생활을 공유할 가능성이 높은 범위로 설정합니다. 여러 원룸 건물을 하나의 블록으로 묶어 자유게시판, 도움 요청, 공동구매에 충분한 참여자가 생기도록 합니다.


## 5. 사용자 시나리오

### 시나리오 1: 자유게시판 이용

1. 사용자가 로그인한다.
2. 자신이 속한 건물 또는 생활권 블록을 선택한다.
3. 해당 커뮤니티의 자유게시판에 들어간다.
4. 생활 정보, 질문, 잡담 등 자유로운 글을 작성한다.
5. 같은 커뮤니티 사용자가 글을 확인하고 댓글을 남긴다.

### 시나리오 2: 도와주세요 게시판 이용

1. 사용자가 해결하기 어려운 생활 문제를 발견한다.
2. 도와주세요 게시판에 요청 글을 작성한다.
3. 예: 바퀴벌레 잡아주세요, 전등 교환 좀 도와주세요, 택배 좀 대신 받아주세요.
4. 같은 커뮤니티 사용자가 요청을 보고 도와주겠다고 댓글을 남긴다.
5. 작성자는 도움을 받은 뒤 글 상태를 완료로 변경한다.

### 시나리오 3: 공동구매 참여

1. 사용자가 공동구매 탭에 들어간다.
2. 상품 카드 목록에서 상품명, 가격, 모집 인원, 마감 시간을 확인한다.
3. 원하는 공동구매 상품을 선택한다.
4. 상세 페이지에서 설명, 현재 참여 인원, 분배 방식, 1인 부담 금액을 확인한다.
5. 참여 버튼을 눌러 공동구매에 참여한다.
6. 참여 인원에 따라 1인 부담 금액이 갱신된다.

### 시나리오 4: 공동구매 모집 생성

1. 사용자가 공동구매 탭에서 모집 만들기를 누른다.
2. 상품명, 상품 이미지, 총 금액, 모집 인원, 마감 시간, 분배 위치를 입력한다.
3. 공동구매 모집을 등록한다.
4. 같은 커뮤니티 사용자들이 상품 카드 형태로 모집을 확인한다.
5. 목표 인원이 모이면 모집자는 모집을 마감한다.
6. 모집자는 별도 송금 또는 오프라인 방식으로 정산하고 물건을 분배한다.

## 6. 핵심 기능

### 6.1 위치기반 커뮤니티 선택

오피스텔, 아파트, 기숙사처럼 한 건물 또는 같은 동 안에 충분한 사용자가 있는 주거 형태는 건물형 커뮤니티로 매칭합니다. 반면 원룸처럼 한 건물의 거주 인원이 적은 경우에는 주변 원룸과 생활 편의시설을 포함한 블록형 커뮤니티로 묶어 매칭합니다.
(1. 아파트/오피스텔, 2. 주택/빌라 토글을 만들어서 1번 선택 경우 건물 단위 매칭, 2번 선택 경우 블록 단위 매칭)

위치 기반 자동 매칭의 예시는 다음과 같습니다.

- 사용자가 주소나 건물명을 입력하면 가까운 건물 또는 블록을 추천한다.
- 아파트와 오피스텔은 같은 동 또는 같은 단지 단위로 매칭한다.
- 원룸 밀집 지역은 여러 건물을 하나의 블록으로 묶어 매칭한다.
- 사용자가 추천된 블록을 확인하고 최종 입장할 수 있도록 한다.

### 6.2 자유게시판

같은 커뮤니티 사람들이 자유롭게 글을 올릴 수 있는 게시판입니다.

생활 정보, 질문, 잡담, 공지성 공유 등을 작성할 수 있습니다.

### 6.3 도와주세요 게시판

생활 속 작은 도움을 요청하는 게시판입니다.

예를 들어 벌레 처리, 전등 교체, 택배 수령, 물건 이동 도움 같은 요청을 올릴 수 있습니다.

### 6.4 공동구매 탭

공동구매는 사이사이의 핵심 기능입니다.

게시판 형태가 아니라 상품 카드와 판매 페이지에 가까운 구조로 제공합니다.

공동구매 카드에는 다음 정보를 보여줍니다.

- 상품명
- 상품 이미지
- 총 금액 또는 예상 가격
- 현재 참여 인원
- 목표 모집 인원
- 마감 시간
- 1인 예상 부담 금액
- 참여 상태
- 참여 버튼

### 6.5 공동구매 상세 페이지

사용자는 공동구매 상세 페이지에서 상품 설명, 참여 인원, 마감 시간, 1인 부담 금액, 분배 방식, 픽업 위치를 확인하고 참여할 수 있습니다.

### 6.6 1인 부담 금액 계산

공동구매 총 금액을 참여 인원 수로 나누어 예상 1인 부담 금액을 보여줍니다.

### 6.7 공동구매 운영 규칙

서비스가 직접 결제나 송금을 처리하지 않습니다.

기본 운영 방식은 다음과 같습니다.

- 모집자가 상품을 구매하고 참여자에게 분배한다.
- 정산은 별도 송금 또는 오프라인 방식으로 진행한다.
- 모집자는 분배 위치와 시간을 모집 글에 명시한다.
- 목표 인원이 모이지 않으면 모집자는 모집을 마감하거나 취소할 수 있다.
- 참여자는 참여 전 상품 금액, 예상 부담 금액, 분배 방식을 확인한다.
- 참여자만 진입 가능한 페이지(채팅방)에 진입해 의견을 조율한다.

### 6.8 내 활동 확인

사용자는 자신이 작성한 글, 도움 요청 글, 참여한 공동구매를 확인할 수 있습니다.

## 7. 구현 범위

### 7.1 핵심 기능

- 로그인 및 주소 입력
- 커뮤니티 자동 매칭(사용자가 주소 입력 시 커뮤니티가 자동으로 설정 됨.)
- 공동구매 상품 카드 목록
- 공동구매 모집 생성
- 공동구매 상세 보기
- 공동구매 참여
- 공동구매 모집 마감
- 1인 부담 금액 계산
- 내 공동구매 참여 내역 확인
- 공동구매 참여자 채팅창

### 7.2 보조 기능

- 도와주세요 게시판 글 작성 및 조회
- 자유게시판 글 작성 및 조회
- 도움 요청 상태 완료 처리
- 내 게시글 및 도움 요청 내역 확인
