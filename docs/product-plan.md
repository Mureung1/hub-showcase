# 프로젝트 기획서

## Summary

이 서비스는 사용자의 장기 목표를 주간/일일 퀘스트로 바꾸고, 퀘스트 수행 결과에 따라 전자 생물 매니저와 함께 성장하는 자기계발 웹앱이다.

핵심은 단순 일정 관리가 아니라 `목표를 오늘 수행 가능한 퀘스트로 쪼개고, 성공/실패 데이터를 바탕으로 다음 퀘스트를 리밸런싱하는 성장 루프`다.

## 문제 정의

10대와 20대는 공부, 운동, 취미, 커리어 등 여러 영역에서 성장해야 하는 시기다. 하지만 자격증 취득, 체력 향상, 포트폴리오 완성처럼 의미 있는 목표는 성취까지 시간이 오래 걸린다.

사용자는 큰 목표를 세우지만, 오늘 해야 할 작은 행동으로 쪼개지 못하거나 즉각적인 보상이 없어 쉽게 흥미를 잃는다. 이 서비스는 장기 목표를 오늘 수행 가능한 퀘스트로 변환하고, 작은 성취도 전자 생물 매니저의 성장으로 되돌려 사용자가 꾸준히 시도할 수 있게 돕는다.

## 서비스 컨셉

- 사용자는 장기 목표를 입력한다.
- 전자 생물 매니저는 목표를 주간/일일 퀘스트로 나눈다.
- 사용자는 퀘스트를 수락하기 전 분량, 난이도, 제한 시간을 수정한다.
- 퀘스트를 완료하면 매니저가 경험치를 얻고 성장한다.
- 퀘스트에 실패하면 실패 이유를 바탕으로 더 작은 복구 퀘스트를 제안한다.
- 매니저는 사용자를 혼내는 AI 비서가 아니라, 사용자의 성장을 기다리고 페이스를 맞추는 전자 생물형 페이스메이커다.

## 사용자 시나리오

사용자 목표: 정보처리기사 자격증 취득

1. 사용자는 첫 접속 시 프로필 입력 마법사에서 이름, 닉네임, 목표, 하루 가능 시간, 퀘스트 크기, 매니저 말투를 입력한다.
2. 프로필 저장 후 전자 생물 매니저가 생성된다.
3. 메인 XP 데스크톱 화면에서 오늘의 퀘스트와 매니저 창이 기본으로 열린다.
4. 매니저는 장기 목표를 주간 퀘스트로 나눈다.
   - 예: 이번 주 데이터베이스 과목 1회독
5. 주간 퀘스트를 오늘의 퀘스트로 나눈다.
   - 예: 오늘 데이터베이스 개념 15분 공부
6. 사용자는 퀘스트를 수락하기 전 분량, 제한 시간, 난이도를 수정한다.
7. 퀘스트를 수락하면 `QuestRunner.exe`가 열리고 활성 퀘스트 상태가 표시된다.
8. 사용자가 완료하면 매니저가 경험치를 얻고 기록 노트에 완료 기록이 남는다.
9. 실패하면 실패 이유를 선택한다.
10. 매니저는 실패 이유를 바탕으로 더 작은 복구 퀘스트를 제안한다.

## 핵심 기능

### 1. 프로필 입력/매니저 생성

- 이름 입력
- 닉네임 입력
- 주요 목표 입력
- 하루 가능 시간 입력
- 퀘스트 크기 선택
- 매니저 말투 선택
- 전자 생물 매니저 생성

### 2. 목표 등록

- 장기 목표 입력
- 목표 카테고리 선택
- 목표 마감일 또는 희망 기간 입력
- 추상적인 목표일 경우 구체화 질문 유도

### 3. 퀘스트 생성

- 장기 목표를 주간 퀘스트로 분해
- 주간 퀘스트를 일일 퀘스트로 분해
- 퀘스트 유형 분류
  - 시간형
  - 양적형
  - 행동형

### 4. 퀘스트 수정/수락

- 제목 수정
- 분량 수정
- 난이도 수정
- 제한 시간 수정
- 예상 EXP 확인
- 수락 후 활성 퀘스트로 전환

### 5. 완료/실패 처리

- 사용자가 직접 완료 체크
- 실패 시 실패 이유 선택
- 실패한 퀘스트는 소멸 처리
- 실패는 패널티가 아니라 리밸런싱 신호로 사용

### 6. 매니저 성장

- 경험치
- 레벨
- 상태 메시지
- 완료 시 성장
- 실패 시 성장 정체 또는 기다림 상태

### 7. 복구 퀘스트

- 실패 후 더 낮은 부담의 퀘스트 제안
- 기존 퀘스트보다 분량과 보상을 낮춤
- 복구 퀘스트 성공 시 소량 보상 지급

## MVP 범위

MVP는 `목표 입력 -> 퀘스트 생성 -> 수정/수락 -> 완료/실패 -> 성장/복구` 루프가 한 번 이상 자연스럽게 동작하는 것을 목표로 한다.

### 포함

- 프로필 입력 마법사
- 전자 생물 매니저 생성
- 목표 기반 오늘의 퀘스트 초안 생성
- 퀘스트 수정/수락
- `QuestRunner.exe` 활성 퀘스트 창
- 완료/실패 처리
- 실패 이유 선택
- 복구 퀘스트 제안
- 매니저 EXP/레벨 표시
- 기록 노트

### 제외

- 알림 기능
- 실제 캘린더 연동
- 복잡한 보상 상점
- 소셜 경쟁
- 개인 LLM 연동
- 음성 입력
- 웹캠 제스처
- 현실 픽셀화 TV

## 기획 결정

### 알림 기능 제외

이 서비스는 사용자를 계속 재촉하는 앱이 아니라 사용자가 돌아오기를 기다리는 전자 생물의 정체성을 가진다. MVP에서는 알림을 제외하고, 접속했을 때 매니저가 기다리고 있었다는 반응을 보여준다.

### 실패는 리밸런싱 신호

실패는 사용자를 비난하거나 벌주는 근거가 아니다. 실패 이유는 다음 퀘스트의 크기와 난이도를 조절하는 데이터로 사용한다.

### 수락 전 수정 가능

AI나 규칙 기반 로직이 만든 퀘스트를 사용자가 그대로 받아들이게 하지 않는다. 수락 전에는 제목, 분량, 제한 시간, 난이도를 조정할 수 있어야 한다.

### 쉬운 퀘스트 반복 방지

너무 쉬운 퀘스트만 반복하면 성장 루프가 약해진다. 쉬운 퀘스트는 낮은 보상을 지급하고, 어려운 퀘스트는 더 높은 보상을 지급한다.

### 거짓 완료 처리

MVP에서는 직접 완료 체크를 기본으로 한다. 비정기 인증은 확장 기능으로 둔다.

## Acceptance Criteria

- 문제 정의가 서비스 기능과 직접 연결되어 있다.
- 사용자 시나리오가 온보딩부터 성장 루프까지 이어진다.
- 핵심 기능이 MVP와 확장 기능으로 분리되어 있다.
- 퀘스트 성공/실패/복구 흐름이 포함되어 있다.
- 전자 생물 매니저의 정체성이 단순 AI 비서와 구분된다.
- 알림 기능 제외, 실패 시 리밸런싱 중심, 수락 전 수정 가능이라는 기획 결정이 반영되어 있다.
