## 프로젝트 소개

> Mealyze(구 CJMT = Chungnam Just-eat Meal Tracker) — 음식 사진 한 장 → 내 몸 기준 부족 영양소와
> 보충 메뉴·식당을 알려주는 한국어 영양 관리 웹 서비스. (Naver Connect / Boostcamp AI Agent
> Challenge 과제로 시작)

### 문제 · 차별점 · 형태

- **문제**: 학교·주변 식당은 영양 정보가 없고, 매번 칼로리를 손으로 계산하기는 귀찮고, 지금 내
  몸에 무엇이 부족한지는 더욱 판단하기 어렵다.
- **차별점**: 단순 "사진 찍으면 칼로리 나오는" 앱을 넘어, 내 신체 기준으로 지금 무엇을 더 먹어야
  하는지를 진단하고 그걸 채울 수 있는 메뉴·주변 식당까지 이어서 추천한다.
- **형태**: 모바일 우선 웹앱 + 같은 웹을 그대로 로드하는 Android WebView 래퍼(Capacitor). 웹을
  배포하면 앱도 자동으로 갱신된다(자세한 내용: `CLAUDE.md`의 "Android app wrapper" 절).

### 화면 구조 (하단 탭 5개)

홈(촬영·분석) · 식단 · 달력 · 지도 · MY

- **홈(`/analyze`)**: 로그인·신체정보 여부와 무관하게 앱을 열면 항상 이 화면부터 시작(게스트 우선
  설계). 사진 업로드로 음식을 분석한다.
- **식단(`/meals`)**: 오늘 먹은 음식 목록 + 권장량 대비 그래프. 부족 영양소 기반 쿠팡 파트너스 광고
  캐러셀과, 로그인 계정끼리 비교하는 "오늘의 순위" 리더보드 카드가 이 탭에 있다.
- **달력(`/calendar`)**: 날짜별 영양 상태를 3단계 색상으로 표시.
- **지도(`/map`)**: 부족 영양소를 보완할 수 있는 주변 식당 추천(네이버 지역 검색 + 네이버 지도).
- **MY**: 신체정보 입력, 로그인/로그아웃, 데이터 백업(CSV) 내보내기/가져오기.

### 알고리즘 핵심

식약처 공공 DB 기반 영양 매칭 캐스케이드, BMR/TDEE 기반 권장량 계산, 광고·리더보드 점수 로직은
전용 문서 참고 — [01-알고리즘.md](01-알고리즘.md).

### 개발 히스토리 — 주요 전환점

상세 변경 이력은 루트 `CHANGELOG.md` 참고.

| 초기 | 현재 | 이유 |
|---|---|---|
| Google Gemini 직접 호출 | OpenRouter 경유 Gemini | 무료 티어 한도(하루 20회)로 503/429 빈발 → 유료 크레딧 전환으로 안정화 |
| 카카오맵 + 카카오 로컬 검색 | 네이버 지도 + 네이버 API Hub 지역 검색 | 지도·식당 검색을 네이버로 이전(카카오 코드는 롤백용으로 저장소에 남겨둠) |
| Google OAuth 로그인 | 아이디+비밀번호 로그인 | 앱(WebView)에서 임베디드 OAuth가 막히는 문제를 원천 제거 |
| 비밀번호 평문 저장(초기 데모 한정 계획) | Supabase Auth(bcrypt) | 로그인 방식을 바꾸며 실제 해시 저장으로 전환 — 더 이상 평문 저장이 아님 |
| localStorage만 사용 | 로그인 시 Supabase, 게스트는 localStorage | `dataStore.js`가 세션 여부로 저장소를 분기 |
| 프로젝트명 CJMT | Mealyze | 명칭 변경. `cjmt` 폴더명·`cjmt:` localStorage 키 접두사는 기존 게스트 데이터 호환을 위해 코드에 남아 있음 |

### 개발 과정에서 해결한 주요 이슈 (회고)

- **API 비용/한도**: 위 표 참고. 프록시에 429/503 지수 백오프(1s→2s→4s)를 적용해 안정화.
- **Gemini 인증 방식 변경**: 신형 키(`AQ.Ab...`)는 `?key=` 쿼리 대신 `x-goog-api-key` 헤더가 필요.
- **영양 과대추정**: 프롬프트 튜닝(한국 표준 1인분 앵커)만으로는 부족해, 식약처 공공 DB 연동으로
  근본적으로 해결 — 자세한 내용은 알고리즘 문서 참고.
- **CSV 왕복 버그**: 내보내기 진입점이 2개(MY 탭/달력 탭)인데 가져오기가 한 형식만 인식하던 문제.
  가져오기가 두 형식을 자동 판별하도록 고쳐 해결 — `CLAUDE.md`의 "CSV backup" 절 참고.
- **환경 이슈**: OneDrive 동기화 경로 + 한글/공백이 섞인 디렉터리명에서 일부 CLI 동작이 불안정한
  경우가 있었다(예: `git mv`가 대상 디렉터리를 미리 만들어줘야 동작).

### 남은 작업

기능 구현은 대부분 끝났고, 남은 항목은 대개 "코드가 아니라 사람이 콘솔/대시보드에서 눌러야 하는"
것들이다:

- Supabase 대시보드: Confirm email OFF(필수 — 안 하면 합성 이메일 가입이 확인 대기로 멈춤), Google
  provider 비활성화, (권장) 최소 비밀번호 길이 8
- 기존 Google OAuth 연동 계정 데이터 백업 후 삭제 — `supabase/migrations/2026-07-22_id-password-auth.sql`
- 쿠팡 파트너스 승인 후 `src/data/coupangProducts.js`의 `productName`/`price`/`imageUrl`/
  `partnersUrl`만 교체(`id`/`nutrient`는 추천 로직 키라 건드리지 말 것), 이후 `npm run check:ads`로
  무결성 재확인
- 새 Capacitor 네이티브 플러그인(`@capacitor/filesystem`, `@capacitor/share`) 반영을 위해
  `npm run app:sync` 실행 필요(안 하면 APK에서 CSV 내보내기 실패)

## 배포 전 점검 체크리스트

대조표나 일회성 데이터 정리 항목은 제외했다(필요하면 git 이력에서 해당 커밋 확인).
