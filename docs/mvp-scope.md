# MVP 구현 범위

## 포함 범위

* 사용자 상황 입력
* 감정 선택 또는 입력
* React state를 이용한 입력 관리
* Express API 요청
* 서버 입력값 검증
* 규칙 기반 Mock AI 응답
* Supabase 대화 저장
* 서버 응답 화면 표시
* 기본 로딩 상태
* 기본 오류 처리
* 기본 대화 기록 조회

## 제외 범위

* 회원가입
* 로그인
* 음성 입력과 출력
* 캐릭터 애니메이션
* 실제 생성형 AI API
* 벡터 데이터베이스
* 장기 기억
* 감정 분석 모델 학습
* 다중 사용자 기능
* 복잡한 디자인 시스템
