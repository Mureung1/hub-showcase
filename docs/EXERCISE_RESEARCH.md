# 운동 관여 부위 리서치 노트

기획서(@기획서.md)의 "컴파운드 운동 중 오버헤드프레스, 로우, 풀업, 런지의 관여 부위 교차검증" 항목을 위해 진행한 리서치 결과다. 스쿼트·데드리프트·벤치프레스를 포함해 관련 있는 변형·부위까지 넓혀서 총 33개 운동을 확인했다. 이 문서는 원자료(raw data)이며, 실제 "정적 운동 테이블"(30~50개, JSON/JS 데이터 파일)을 만드는 작업(이슈 #2)에서 이 내용을 가공해서 옮긴다.

**신뢰도 원칙**: 동료심사 연구(peer-reviewed) 또는 공식 기관 자료를 우선했고, 상업적 블로그·유튜브·AI 요약 검색 결과는 제외했다. 근거가 부족해 보수적으로(안전 우선으로) 판단한 항목은 별도 표기했다.

## 판단이 필요했던 항목 (참고)

- **원암 덤벨로우**: 신뢰할 동료심사 자료를 못 찾아 안전 우선으로 바벨로우와 동일 취급
- **레그 컬·힙쓰러스트**: 무릎 관여가 확인돼, 안전 우선으로 무릎 통증 시 배제 대상에 포함(기존 목업 데이터와 다른 결론)
- **슈러그**: 관절이 아니라 부위(목/승모근) 기준으로 분류 — 허리(요추)를 정적 부하로 취급한 것과 같은 원칙 적용
