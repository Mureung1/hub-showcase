# fiTArchive 기획서

## 1. 프로젝트 개요

fiTArchive는 사용자가 매일 입은 코디를 사진과 함께 기록하는 개인 패션 아카이브 서비스입니다.

핵심은 단순히 옷 사진을 저장하는 것이 아니라, 그날 신경 쓴 포인트와 선택 이유를 짧은 문장으로 함께 남기는 데 있습니다.

기록이 5장 이상 쌓이면 FitCheck 기능을 통해 사용자의 스타일 표현, 반복되는 취향, 자주 선택하는 분위기를 리포트 형식으로 보여줍니다.

## 2. 기획 배경

패션과 코디는 개인의 취향이 많이 반영되는 영역입니다. 같은 코디를 보더라도 사람마다 느끼는 분위기와 기준이 다르기 때문에, 코디를 단순히 좋다 또는 나쁘다로 평가하기는 어렵습니다.

하지만 매일 옷을 고르면서도 사용자는 자신이 어떤 기준으로 옷을 선택하는지, 어떤 스타일을 반복해서 입는지 잘 인식하지 못하는 경우가 많습니다.

마음에 들었던 코디가 있어도 사진첩 속에 흩어져 있거나, 그날 왜 그 옷을 선택했는지에 대한 맥락은 쉽게 사라집니다.

fiTArchive는 코디에 정답을 제시하기보다, 사용자가 직접 쌓은 기록을 통해 자신의 취향을 발견하도록 돕고자 합니다.

## 3. 문제 정의

코디는 개인 취향이 강하게 반영되는 영역이기 때문에 단순한 정답이나 점수로 평가하기 어렵습니다. 그러나 많은 사람들은 매일 옷을 입으면서도 자신이 어떤 기준으로 코디하는지, 어떤 스타일을 반복해서 선택하는지 잘 인식하지 못합니다.

또한 마음에 들었던 코디가 있어도 사진첩 속에 흩어져 있거나 따로 설명이 남아 있지 않아 나중에 다시 참고하기 어렵습니다. 사진만 저장하는 방식으로는 그날 신경 쓴 포인트나 선택 이유까지 기억하기 어렵습니다.

- 코디는 개인 취향이 강해 단순한 점수나 정답으로 평가하기 어렵습니다.
- 사용자는 매일 옷을 입지만, 자신이 어떤 기준으로 코디하는지 인식하기 어렵습니다.
- 마음에 들었던 코디를 다시 참고하고 싶어도 사진과 맥락이 흩어져 있습니다.
- 사진만 저장하면 그날 신경 쓴 포인트나 선택 이유가 남지 않습니다.
- 기록이 쌓여도 이를 바탕으로 자신의 스타일 패턴을 파악하기 어렵습니다.

## 4. 타겟 사용자

패션과 코디에 관심이 있고, 자신의 데일리룩을 기록하거나 스타일 취향을 돌아보고 싶은 대학생 및 20대 사용자를 주요 대상으로 합니다.

특히 매일 옷을 고를 때 비슷한 스타일을 반복한다고 느끼거나, 마음에 들었던 코디를 다시 참고하고 싶은 사용자를 핵심 사용자로 봅니다.

## 5. 해결 방법

fiTArchive는 사용자가 오늘 입은 코디 사진과 함께, 그날 신경 쓴 포인트나 코디의 특징을 간단한 문장으로 남기도록 합니다.

태그를 많이 붙이는 방식보다 사용자가 직접 자신의 선택 이유를 설명하는 방식에 가깝습니다.

예를 들어 사용자는 다음과 같은 문장을 남길 수 있습니다.

> 오늘은 발표가 있어서 평소보다 단정한 느낌을 주려고 셔츠와 어두운 슬랙스를 골랐다.

> 비 오는 날이라 편하게 움직일 수 있는 신발을 신었고, 전체적으로 어두운 톤으로 맞췄다.

> 상의가 포인트라서 하의와 신발은 최대한 심플하게 맞췄다.

이 문장 기록들이 쌓이면 FitCheck가 사용자의 반복되는 표현과 선택 기준을 분석해 취향 리포트로 정리합니다.

## 6. 주요 기능

### 코디 기록

오늘 입은 코디 사진과 함께 신경 쓴 포인트, 선택 이유, 전체적인 분위기, 입어본 후 느낀 만족도나 아쉬운 점을 짧은 문장으로 기록합니다.

### 코디 아카이브

기록한 코디를 카드 형태로 모아보고 날짜, 상황, 만족도, 기록 문장을 기준으로 다시 찾아볼 수 있습니다.

### FitCheck 리포트

코디 기록이 5장 이상 쌓이면 사용자의 문장 기록과 만족도 데이터를 바탕으로 반복되는 취향과 스타일 경향을 분석합니다.

## 7. FitCheck 방향

FitCheck는 사용자의 코디를 단정적으로 평가하거나 점수를 매기는 기능이 아닙니다.

사용자가 직접 남긴 기록을 기반으로 취향을 해석하고, 스타일 패턴을 리포트 형태로 보여주는 보조 기능입니다.

- 자주 등장하는 스타일 표현과 분위기
- 만족도가 높았던 코디의 공통점
- 최근 코디 기록에서 보이는 변화
- 새롭게 시도해볼 수 있는 스타일 방향

## 8. 개발 범위

초기 MVP에서는 AI가 옷을 자동으로 인식하거나 코디를 평가하는 기능은 제외합니다.

대신 사용자가 직접 입력한 사진, 문장 기록, 만족도 데이터를 기반으로 분석 리포트를 구성합니다.

## 9. 4주 개발 목표

### 1주차

React 환경 구성, 프로젝트 소개 컴포넌트, 기본 레이아웃과 코디 카드 UI 제작

### 2주차

코디 등록 폼, 이미지 업로드 UI, 문장형 코디 노트 입력 기능 구현

### 3주차

코디 목록 화면, 상세 보기, 기록 검색 및 필터 기능 구현

### 4주차

FitCheck 리포트 화면, 누적 기록 기반 스타일 분석, 발표용 데모 정리

## 10. 기대 효과

- 사용자는 마음에 들었던 코디를 사진과 맥락까지 함께 기록할 수 있습니다.
- 자신이 어떤 기준으로 옷을 선택하는지 돌아볼 수 있습니다.
- 반복되는 스타일 패턴을 발견하고 새로운 코디를 시도할 수 있습니다.
- 코디 평가가 아닌 기록 기반 분석으로 개인 취향을 존중할 수 있습니다.

## 핵심 문장

fiTArchive는 코디에 점수를 매기는 서비스가 아니라, 사용자가 직접 기록한 코디 데이터를 바탕으로 자신의 취향을 발견하도록 돕는 패션 아카이브 서비스입니다.
