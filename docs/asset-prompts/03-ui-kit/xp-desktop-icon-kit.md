# XP Desktop Icon Kit Prompt

## 목적

바탕화면 아이콘을 concept.png처럼 XP 데스크톱에 어울리는 픽셀 아이콘 세트로 통일한다.

## Prompt

Create a Windows XP inspired pixel art desktop icon set for a quest manager web app. Transparent background, 48x48 icon size, crisp pixel edges, warm beige and blue XP palette. Icons needed: profile folder, today quest clipboard, record notebook, electronic manager gem, empty recycle bin, quest runner executable, recovery quest plus symbol, reward inventory box. No text labels inside the icons, consistent lighting, consistent outline thickness, readable at small size.

## Negative Prompt

modern flat icon, lucide outline style, photorealistic, 3d glossy app icon, macOS icon, neon, text, letters, watermark, inconsistent perspective
