# XP Shell + Pixel Room Hybrid

## 목적

Windows XP풍 데스크톱 셸과 픽셀 방을 결합한 테마 후보를 만들기 위한 프롬프트다. 웹앱의 기능 패널은 XP 창처럼, 중심 월드는 작은 픽셀 방처럼 보이게 한다.

## 출력 규격

- 권장 크기: `1920x1080`
- 비율: 웹 첫 화면용 16:9
- 텍스트: 없음. 창 제목 텍스트도 넣지 말 것
- UI 컴포넌트는 나중에 React로 구현하므로 배경 느낌만 생성
