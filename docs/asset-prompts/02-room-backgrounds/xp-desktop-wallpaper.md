# XP Desktop Wallpaper Prompt

## 목적

현재 image.png를 그대로 쓰지 않고, concept.png의 Windows XP 데스크톱 감성을 따르는 새 배경을 생성한다.

## Prompt

Create a cozy Windows XP inspired pixel art desktop wallpaper for a self-growth quest web app. Bright blue sky in the upper 60%, soft puffy white pixel clouds, rolling green meadow in the lower 40%, small yellow flowers, gentle hills in the distance, warm nostalgic early-2000s mood, crisp pixel art, clean open sky area for desktop icons and app windows, no characters, no UI windows, no text, no logo, no taskbar, no dark overlay. 16:9 composition, high readability, calm and friendly.

## Negative Prompt

photorealistic, 3d, anime room, cabin interior, cyberpunk, neon, purple gradient, dark night, rain, text, icons, windows, character, watermark, logo, blurred, noisy, overly detailed, realistic grass texture

## 권장 출력

- 1920 x 1080 PNG
- React/CSS에서는 background-position: center bottom
- 정적 HTML에서는 public/assets/xp-pixel-wallpaper.png로 사용
