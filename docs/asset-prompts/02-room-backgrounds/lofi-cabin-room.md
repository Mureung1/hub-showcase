# Lofi Pixel Cabin Room

## 목적

현재 참고 이미지처럼 “고즈넉한 픽셀 오두막/방”을 웹앱의 메인 월드로 쓰기 위한 배경 프롬프트다.

## 출력 규격

- 권장 크기: `1536x1024` 또는 `1920x1080`
- 시점: isometric 또는 slightly top-down 3/4 view
- 텍스트: 없음
- 레이어 분리 권장: background, furniture, foreground props, lighting overlay

## 기본 프롬프트

```text
A cozy isometric pixel art cabin room for a self-growth web app, warm wooden floor and walls, a small desk with books and a calendar, tiny TV screen, soft blanket, low table, potted plant, window with gentle daylight, warm hanging lamp, quiet lofi atmosphere, enough empty space for UI panels around the room, no characters, no text, no logo, readable object silhouettes, hand placed pixels, warm muted palette, nostalgic indie game room, 32-bit pixel art feeling.
```
