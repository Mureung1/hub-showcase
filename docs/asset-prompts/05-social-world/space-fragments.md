# Social Quest Space Fragments

## 목적

다른 사람의 공개 퀘스트를 우주 조각처럼 탐색하는 확장 기능용 에셋 프롬프트다. MVP에서는 구현하지 않지만, 공개 퀘스트 세계관을 미리 맞춰둔다.

## 출력 규격

- 권장 크기: `1536x1024` 배경 1장
- object sheet: `1024x1024` 별도 생성
- 텍스트: 없음
- 공개 퀘스트 내용은 이미지가 아니라 앱 텍스트로 표시

## 배경 프롬프트

```text
A cozy pixel art cosmic garden background for discovering anonymous public quest fragments, not sci-fi cyberpunk. A quiet warm night sky, floating small islands, glowing paper-like fragments, tiny stars, soft nebula colors, gentle sense of exploration, calm and non-competitive, enough open space for interactive objects, no text, no logos, no watermark, hand placed pixels, muted blue, lavender, warm yellow accents.
```

## 조각 object sheet 프롬프트

```text
Create a transparent pixel art object sheet of floating quest fragments for a cozy social exploration feature. Include paper stars, small glowing stones, folded notes without text, tiny orbiting lights, soft comet chips, memory crystals, and sealed quest envelopes. Each object should be readable at small size and have a gentle glow. No text, no letters, no logo, no watermark, no aggressive sci-fi.
```

## 네거티브 프롬프트

```text
leaderboard, competition, ranking, chat bubbles with text, cyberpunk neon, spaceship battle, realistic galaxy, hard sci-fi metal, logos, watermark, unreadable tiny symbols
```
