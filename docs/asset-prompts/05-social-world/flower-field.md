# Social Quest Flower Field

## 목적

공개 퀘스트 탐색의 더 따뜻한 대안인 우주 꽃밭 콘셉트 프롬프트다.

## 출력 규격

- 배경: `1536x1024`
- 꽃 object sheet: `1024x1024`
- 텍스트 없음

## 배경 프롬프트

```text
A cozy pixel art night flower field where anonymous public quests appear as softly glowing flowers. Warm moonlight, small paths, gentle firefly-like pixels, quiet garden atmosphere, no competition, no characters, no text, no logo, enough open space for clickable flowers, hand placed pixel art, muted greens, soft blues, warm yellow glow.
```

## 꽃 object sheet 프롬프트

```text
Create a transparent pixel art object sheet of quest flowers for a cozy self-growth social feature. Include small glowing flowers, closed buds, sprouting seeds, recovery flowers, study flowers, exercise flowers, hobby flowers, career flowers, and tiny floating pollen sparkles. No text, no letters, no logo, consistent pixel style, gentle warm glow.
```

## 네거티브 프롬프트

```text
realistic botanical painting, horror forest, overgrown clutter, readable text, signboards, brand logo, competition icons, scoreboard, overly saturated fantasy magic
```
