# Generation Checklist

## 생성 전

- [ ] 에셋이 배경인지, 캐릭터인지, UI 아이콘인지 먼저 정한다.
- [ ] 결과물에 텍스트가 들어가지 않도록 지시한다.
- [ ] 투명 배경이 필요한 에셋은 transparent background를 명시한다.
- [ ] 기준 팔레트가 XP 데스크톱인지 확인한다.

## 생성 후

- [ ] 픽셀 가장자리가 선명한가?
- [ ] UI 위에 올렸을 때 글자와 충돌하지 않는가?
- [ ] 배경에 과한 디테일이 없어 창이 읽히는가?
- [ ] 캐릭터가 현실 동물처럼 보이지 않고 전자 생물처럼 보이는가?
- [ ] 보상 오브젝트는 32px, 48px, 64px에서 알아볼 수 있는가?
