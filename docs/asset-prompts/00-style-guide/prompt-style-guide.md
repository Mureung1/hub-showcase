# Prompt Style Guide

## 공통 스타일

cozy Windows XP desktop pixel art, bright blue sky, soft white clouds, rolling green meadow, early-2000s desktop nostalgia, compact beige system windows, blue title bars, crisp pixel edges, warm and calm mood, low visual noise, readable empty sky area for desktop icons and windows, no cyberpunk, no neon, no dark overlay

## 팔레트

- 하늘: 선명한 XP 블루에서 밝은 하늘색으로 내려오는 계열
- 초원: 채도 높은 초록, 노란 꽃 포인트, 어두운 틴트 금지
- 창: 베이지 본문, 파란 제목 표시줄, 흰색 제목 텍스트
- 매니저: 분홍/크림/민트 중 1~2색 중심, 과한 동물성 금지

## 구도 규칙

- 배경은 16:9 또는 4:3으로 생성한다.
- 좌측 상단과 중앙 하늘에는 창과 아이콘이 올라갈 빈 공간을 남긴다.
- 초원은 하단 35~45%에 배치한다.
- 캐릭터와 창은 별도 에셋으로 생성하고 배경에 박아 넣지 않는다.
- UI 텍스트는 이미지 생성 결과에 넣지 않는다.

## Negative Prompt

photorealistic, 3d render, cyberpunk, neon glow, dark mode, blurred background, modern glassmorphism, large rounded cards, purple gradient, anime room, realistic animal, text labels, fake UI text, watermark, signature, overly detailed clutter, low resolution, anti-aliased vector look
