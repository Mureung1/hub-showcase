# Electronic Manager Sprite Sheet Prompt

## 목적

루미는 현실 동물이 아니라 사용자를 기다리는 전자 생물형 데스크톱 펫이다.

## Prompt

Create a cute electronic lifeform desktop pet sprite sheet for a Windows XP inspired pixel art self-growth app. The character is named Lumi, a small pink and cream digital creature, not a real animal, rounded simple body, tiny antenna or pixel halo, soft expressive face, cozy and encouraging, clear silhouette at 64px. Transparent background. Include 6 states in a grid: idle waiting, quest running, happy completion, rebalancing, recovery ready, resting. Crisp pixel art, limited palette, consistent scale, no text.

## Negative Prompt

realistic animal, cat, dog, monster, human, anime girl, robot armor, cyberpunk, neon, 3d render, complex details, text, labels, UI frame, shadow baked into background, watermark
