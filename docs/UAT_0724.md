# UAT — "30초 내 승인·발송" 사용성 테스트 (7/24)

> 백로그 4-7. WeatherPilot의 핵심 가치("확인 10초로 끝나는 오늘의 매출 방어")가 실제로
> 처음 쓰는 사람에게도 성립하는지, 3명에게 과제를 주고 **검토→발송 소요 시간**과 오발송 여부를 측정한다.

## 측정 도구

- 앱을 **`?uat=1`** 로 연다(예: `https://weatherpilot-web.vercel.app/?uat=1`).
  → 발송 완료 화면에 "⏱ 검토→발송 N초"가 표시되고, 브라우저 콘솔에도 `[UAT] 검토→발송 Ns`가 찍힌다.
- 시간은 **"제안 검토하기"를 누른 순간부터 "발송/예약 완료" 화면이 뜰 때까지**를 잰다(앱이 자동 계측).

## 참가자 조건

- WeatherPilot을 **처음 보는** 사람 3명. (사장님 페르소나 — 마케팅·개발 비전문가면 더 좋음)
- 사전 설명 최소화: "동네 카페 사장님이라고 생각하고, 오늘 마케팅 제안을 확인해 보내보세요"만 안내.

## 과제 대본 (진행자가 읽어줌)

1. "지금 화면이 오늘의 대시보드예요. 오늘 날씨와 예상 매출이 보입니다."
2. "에이전트가 만들어 둔 오늘 마케팅 제안을 **검토해서, 마음에 들면 승인해 발송**해 주세요."
3. (개입 금지) 참가자가 스스로 검토 화면 → 채널 선택 → 발송까지 하도록 둔다.
4. 막히면 어디서 멈췄는지만 기록(도와주지 않는다).

## 성공 기준 (DoD)

- ✅ **완료 시간 ≤ 30초** (검토 진입 → 발송/예약 완료)
- ✅ **오발송 0** — 의도와 다른 채널/문구로 보내지 않음
- ✅ **무개입 완료** — 진행자 도움 없이 끝까지 도달
