### 회고
백엔드 API 연동 문제는 Docker로 배포하는 과정에서 발생한 문제였습니다. 로컬 환경에서는 정상적으로 동작하던 API 연동 로직이 컨테이너로 배포한 이후에는 요청이 제대로 전달되지 않아, 컨테이너 내부 네트워크 설정과 환경 변수 값이 로컬과 다르게 적용되는지를 하나씩 점검하며 원인을 좁혀나갔습니다.
-> 배포 환경과 로컬 개발 환경의 설정 차이를 미리 문서화해두고, 배포 전에 체크리스트로 확인하는 프로세스가 필요하다는 것을 느꼈습니다. 다음부터는 환경별 설정 값을 분리해서 관리하여 동일한 문제가 반복되지 않도록 개선할 계획입니다.
