# ## 주요 작업 리스트
발표 세션에서 사용할 발표자료를 준비했고, Docker로 배포하는 과정에서 발생한 백엔드 API 연동 문제를 해결했습니다. 또한 showcase.json에 내용을 추가했습니다. 그 결과로 메인 기능인 VS-* 기능들을 E2E로 검증 완료했고, 배포 과정에서 생겼던 문제도 함께 처리했습니다.

## 내가 설명할 수 있는 부분
로컬 환경에서는 정상적으로 동작하던 API 연동 로직이 Docker 컨테이너로 배포한 이후에는 요청이 제대로 전달되지 않는 문제가 있었습니다. 로컬에서 직접 실행할 때와 컨테이너 안에서 실행할 때 적용되는 네트워크 설정, 포트, 환경 변수 값이 서로 다르게 반영될 수 있다는 점을 인지하고, 이 부분을 하나씩 점검하며 원인을 좁혀나가는 과정은 설명할 수 있습니다.

## 아직 이해 못 한 부분
Docker와 배포 환경 자체에 대한 개념이 아직 완전히 잡혀 있지 않습니다. 컨테이너가 호스트와 어떤 방식으로 네트워크를 주고받는지, 배포 환경에서 환경 변수나 설정 값이 어떤 우선순위로 적용되는지에 대한 원리를 명확히 설명할 수 있는 수준은 아니라서, 이번에는 문제를 임기응변으로 해결한 감이 있고 근본 원리는 더 공부가 필요합니다.

## 새로 알게 된 것
로컬 환경과 배포(Docker) 환경은 같은 코드를 실행하더라도 네트워크나 설정 측면에서 다르게 동작할 수 있다는 것을 알게 됐습니다. 그래서 기능을 로컬에서만 확인하고 끝내는 게 아니라, 배포된 환경에서도 VS-* 기능들을 E2E로 한 번 더 검증하는 과정이 꼭 필요하다는 것을 이번 작업을 통해 체감했습니다.
