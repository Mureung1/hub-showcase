# 개발 Task & 일정 (작성 중)

챌린지 기간은 260706(월)~260731(금)이고, 주차는 월~금 기준이다. 1주차(706~710)는 기획/이 계획 문서 작성에 썼다. 실제 개발은 2주차(713 월요일)부터 시작한다.

`docs/wiki.md`에 이미 정리된 핵심 기능(8장), 기술 구현(10장), MVP 범위(12장)를 기준으로 작업을 나눴기 때문에 이미 정한 MVP/Phase 2 구분을 그대로 작업 단위로 옮겼다.

## 우선순위 (MVP 먼저, Phase 2는 시간 남으면)

MVP 안에서도 순위가 있다: A → B → **D → E(Agent가 핵심 차별화라 최우선)** → C(화면/타이머, 상대적으로 뒤로 미뤄도 되는 부분). 알파벳 순서와 실제 진행 순서가 다르니 헷갈리지 않게 아래 "일정"을 기준으로 본다.

### A. 기반 설정
- 앱을 실행할 수 있는 최소 상태로 뼈대만 먼저 만든다. 화면 UI와 비밀 키(API 키)를 안전하게 다루는 뒤편 처리를 한 프로젝트 안에서 같이 할 수 있는 도구(Next.js, React를 감싼 프레임워크)를 설치하고, 빈 화면이라도 브라우저에서 켜지게 하는 첫 단계다. 코딩 경험이 전혀 없어서 백엔드 서버를 따로 배우지 않아도 되고, 배포도 Next.js를 만든 회사(Vercel)에 깃허브 저장소만 연결하면 되는 방식이라 이걸로 정했다. Agent가 AI 모델을 호출하는 데 쓰는 도구 모음(Vercel AI SDK)도 이때 같이 연결한다
- 노션 API 연동 (Zero-Input 온보딩: 템플릿 복사 → 링크/토큰 붙여넣기)

### B. Brain Dump
- 단일 텍스트 입력창
- Agent가 문장을 25분 이내 마이크로 스텝으로 자동 분할. AI가 자유 형식 글이 아니라 미리 정한 형식(JSON)으로 답하게 강제하는 도구(`generateObject`)를 쓴다. "할 일 목록"처럼 구조가 정해진 결과가 필요할 때 쓰는 도구다

### C. One-Focus View + Full Screen Timer
- 오늘 할 일 1개만 보여주는 화면
- 타이머 상태 관리 (새로고침해도 안 끊기게, "시작한 시각"만 저장해두고 그 시각 기준으로 남은 시간을 다시 계산하는 방식)

### D. 나 지금 힘들어 (Agent 루프)
- 재조정/재분할 제안
- 반복 회피 패턴 학습, 휴식시간 20→40→60분 단계적 제안
- 여기가 "Agent가 계속 개입한다"는 차별화의 핵심이라 가장 오래 걸릴 가능성이 큼

### E. Agent 평가
- "오늘 챙겨야 할 일 10개"류 정답 세트 만들기
- 정답 중 놓친 게 없는지 보는 지표(Recall), 불필요한 제안을 줄였는지 보는 지표(Precision) 측정 스크립트

## 백로그 (지금 당장 안 해도 되는 것들, 떠오르는 대로 여기 추가)
- 2분 스타터 (Phase 2)
- 다시 시작해도 괜찮아 (Phase 2)
- 감각 강도 조절 (Phase 2)
- 같이 있어요 (Phase 2)
- 통계 화면 (Phase 2)
- 화이트노이즈 테마 (Phase 2)

## 일정 (초안, 조정 필요, 캠프 전체 기준 주차)

위키 4장·12장에 "Agent가 계속 개입한다는 차별화를 증명하는 게 핵심"이라고 이미 정리해뒀다. 그래서 화면(C)보다 Agent 루프(D)와 그 검증(E)에 먼저 힘을 싣는 순서로 짠다.

- **2주차 (260713 월~260717 금)**: A(기반 설정) + B(Brain Dump) — 앱이 켜지고, 문장을 입력하면 Agent가 쪼개주는 것까지
- **3주차 (260720 월~260724 금)**: D(나 지금 힘들어 Agent 루프) — 화면 없이 로직/API 호출 단계로라도 먼저 완성한다. 차별화의 핵심이라 가장 먼저, 가장 오래 붙는다
- **4주차 (260727 월~260731 금)**: E(Agent 평가, 반드시 함) + C(One-Focus View + Full Screen Timer, 시간 되는 만큼) + 막판 버그 수정

1주차는 기획에 썼고, 원래 개발용으로 잡았던 4주를 3주(2·3·4주차)로 압축한 거라 빠듯하다. **시간이 부족해지면 C(화면 다듬기)나 백로그를 줄이고, D·E(Agent 루프와 그 검증)는 끝까지 지킨다** — 여기가 이 프로젝트의 핵심 증명 부분이기 때문이다. 주말(711~712, 718~719, 725~726)은 이 일정에 안 넣었는데, 여유가 되면 미리 당겨서 할 예정이다.
