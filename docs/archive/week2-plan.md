# 2주차 계획

기간: 2026-07-13 ~ 2026-07-17

## 주간 목표

Agent와 함께 하루 체크아웃의 핵심 기능 하나를 FE-BE-DB까지 끝까지 연결한다.

사용자가 React 화면에서 하루 감정 텍스트를 입력하면 Express API가 요청을 받고, AI mock 결과를 만든 뒤 Supabase `checkins` 테이블에 저장한다. 저장된 기록은 다시 화면의 기록 목록에서 조회할 수 있어야 한다.

## 이번 주 최우선순위

1. Supabase 저장·조회 수직 슬라이스 완성
2. React 입력/결과/목록 화면 연결
3. 결과 수정 후 저장 흐름 구현
4. 계획 수립 Agent와 기능 검증 Agent 산출물 작성
5. 2주차 데모 시나리오 정리

AI 실제 연동은 수직 슬라이스가 동작한 뒤 붙인다. 먼저 mock 결과로 FE-BE-DB 흐름을 검증하고, 이후 LiteLLM/Vertex Gemini 호출로 교체한다.

## 이번 주 범위

- React 입력 화면
- React 결과 카드 화면
- 결과 수정 후 저장
- 기록 목록 조회
- Express `checkins` API
- Supabase `checkins` 테이블 저장·조회
- AI mock 결과 생성
- 중앙 에러 처리
- Agent 산출물 문서
- 데모 시나리오와 학습 메모

## 이번 주 제외 범위

- 로그인
- 캘린더 뷰
- 반복 패턴 분석
- 상담센터/바우처 지원 정보 안내
- 배포
- 고도화된 감정 그래프

로그인은 추후 붙인다. 이번 주에는 익명 기록으로 먼저 저장하고, 나중에 로그인과 연결할 수 있도록 `user_id` 컬럼을 비워둘 수 있게 설계한다.

## 데모 성공 기준

- 사용자가 화면에 감정 텍스트를 입력한다.
- 서버가 요청을 받아 감정·원인·내일의 작은 행동 mock 결과를 만든다.
- 사용자가 결과를 확인하고 수정할 수 있다.
- 저장 버튼을 누르면 Supabase에 기록이 저장된다.
- 저장된 기록이 화면의 목록에 다시 표시된다.
- 빈 입력, 서버 오류, DB 연결 실패 같은 실패 케이스의 기본 처리가 있다.
