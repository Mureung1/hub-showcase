# 2주차 GitHub 이슈 등록 초안

2026-07-13 ~ 2026-07-17 주간 목표는 **FE-BE-DB가 실제로 연결되는 핵심 수직 슬라이스 완성**이다.

이번 주에는 AI 실제 연동보다 Supabase 저장·조회 흐름을 먼저 완성한다. AI 결과는 처음에는 mock으로 처리하고, 저장·조회 사이클이 검증된 뒤 LiteLLM/Vertex Gemini 연동을 붙인다.

## 이번 주 완료 기준

- React 화면에서 사용자가 하루 감정 텍스트를 입력할 수 있다.
- Express API가 요청을 받아 checkin 데이터를 만든다.
- Supabase `checkins` 테이블에 데이터가 저장된다.
- 저장된 기록을 다시 조회해서 화면에 목록으로 보여준다.
- 결과 카드는 수정 후 저장할 수 있다.
- 계획 수립 Agent와 기능 검증 Agent 산출물이 문서로 남아 있다.
- 2주차 데모 시나리오와 Slack 공유용 학습 메모가 정리되어 있다.

## Supabase 간단 설명

Supabase는 프로젝트에서 사용할 수 있는 클라우드 데이터베이스 서비스다. 이번 프로젝트에서는 서버가 Supabase의 `checkins` 테이블에 하루 체크아웃 기록을 저장하고, 다시 조회한다.

이번 주에는 로그인 없이 익명 기록으로 먼저 구현한다. 나중에 로그인 기능을 붙일 수 있도록 `user_id` 컬럼은 비워둘 수 있는 값으로 설계한다.
