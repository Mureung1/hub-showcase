# 유저 스토리 — 소상공인 정부지원금 큐레이터

기획서(`docs/plan.md`)와 와이어프레임 기준으로 정리한 피처별 유저 스토리.
형식: **As a (누가) / I want (무엇을) / So that (왜)** + 인수 조건(Acceptance Criteria).

- 주 사용자(Primary Persona): **소상공인 사장님** — 업종·지역·규모는 알지만, 어떤 정부 지원금이 내게 맞는지 찾기 어려운 사람
- MVP 범위 밖 항목은 각 스토리에 `(범위 외)`로 표시

---

## Epic 1. 조건 입력 (온보딩)

### US-1.1 업종·지역·규모 입력
- **As a** 소상공인 사장님
- **I want** 내 업종, 지역(시·도/구·군), 직원 수, 연매출을 단계별로 입력하고
- **So that** 내 조건에 맞는 지원금만 추려서 볼 수 있다

**인수 조건**
- [ ] 온보딩은 4단계(업종 → 시·도 → 구·군 → 직원수+연매출)로 진행된다
- [ ] 각 단계에서 값을 고르기 전에는 "다음" 버튼이 비활성화된다
- [ ] 업종에 "기타"를 고르면 직접 입력할 수 있다
- [ ] 구·군 목록은 선택한 시·도에 따라 동적으로 바뀐다
- [ ] 입력값은 새로고침해도 유지된다(sessionStorage)

### US-1.2 입력 요약 확인
- **As a** 소상공인 사장님
- **I want** 입력을 마친 뒤 내가 고른 조건 요약을 보고
- **So that** 잘못 입력한 값이 없는지 확인하고 결과 화면으로 넘어갈 수 있다

**인수 조건**
- [ ] 완료 화면에 업종/지역/직원수/연매출이 요약 표시된다
- [ ] "맞춤 지원금 보러가기" CTA로 홈(매칭 결과)으로 이동한다
- [ ] 온보딩을 끝내지 않고 완료 화면에 직접 접근하면 첫 단계로 돌려보낸다

## Epic 2. 매칭 결과 리스트

### US-2.1 조건 매칭 리스트
- **As a** 소상공인 사장님
- **I want** 내 조건에 맞는 지원금 목록을 매칭도 순으로 보고
- **So that** 나와 가장 관련 있는 지원금부터 빠르게 확인할 수 있다

**인수 조건**
- [ ] 기본 정렬은 매칭도 순이다
- [ ] 각 카드에 지원금명, 기관, 금액, 마감(D-day), 매칭도가 보인다
- [ ] 마감 임박 정도에 따라 D-day 뱃지 색상이 다르다(urgent/soon/normal)

### US-2.2 정렬 변경
- **As a** 소상공인 사장님
- **I want** 마감임박순·지원금액순 등으로 목록을 다시 정렬하고
- **So that** 급한 마감이나 금액 큰 지원금을 우선 볼 수 있다

**인수 조건**
- [ ] 정렬 칩(전체/마감임박/지원금액/신규)으로 순서를 바꿀 수 있다
- [ ] 정렬을 바꾸면 카드 순서가 즉시 갱신된다
- [ ] 정렬 우선순위 정책: 매칭도 > 마감임박 > 지원금액

### US-2.3 결과 상태 처리
- **As a** 소상공인 사장님
- **I want** 로딩 중·오류·결과 없음 상황을 명확히 안내받고
- **So that** 화면이 왜 비어 있는지 헷갈리지 않는다

**인수 조건**
- [ ] 로딩 중에는 로딩 상태가 표시된다
- [ ] 요청 실패 시 에러 상태가 표시된다
- [ ] 조건에 맞는 결과가 없으면 빈 결과 안내가 표시된다

## Epic 3. 상세 및 외부 신청 연결

### US-3.1 지원금 상세 확인
- **As a** 소상공인 사장님
- **I want** 지원금 하나를 눌러 자격 조건·필요 서류·신청 방법을 보고
- **So that** 내가 실제로 신청 가능한지 판단할 수 있다

**인수 조건**
- [ ] 카드 클릭 시 상세 화면(`/subsidies/:id`)으로 이동한다
- [ ] 요약(금액/매칭/마감/방식), 신청 자격, 필요 서류, 신청 방법이 표시된다
- [ ] 존재하지 않는 지원금 id면 not-found 안내 + 목록 복귀 링크가 보인다

### US-3.2 외부 신청 연결
- **As a** 소상공인 사장님
- **I want** "신청하러 가기"로 해당 기관 사이트로 이동하고
- **So that** 실제 신청은 공식 기관에서 이어서 진행할 수 있다

**인수 조건**
- [ ] 하단 고정 CTA로 접수처 URL(없으면 fallback)로 새 탭 이동한다
- [ ] 서비스 내에서 신청서를 작성하지 않는다 (외부 연결만) `(범위 외: 서비스 내 신청)`

## Epic 4. 데이터 인프라 (백엔드)

### US-4.1 지원금 데이터 저장·조회
- **As a** 서비스 운영자
- **I want** 지원금 데이터를 DB(Supabase)에 저장하고 조회할 수 있고
- **So that** 매칭·상세 화면에 최신 지원금 정보를 공급할 수 있다

**인수 조건**
- [x] `subsidies` 테이블 스키마가 정의되어 있다
- [x] 서버가 환경변수로 Supabase에 연결된다
- [x] 시드/조회 스크립트로 저장·조회가 검증된다 (이슈 #3 완료)
- [ ] API(`/api/subsidies`, `/api/match`)가 DB 조회 기반으로 동작한다 `(이슈 #4/#6)`

### US-4.2 데이터 최신화 `(범위 외 / 후속)`
- **As a** 서비스 운영자
- **I want** 기업마당 등 외부 소스의 지원금 공고를 주기적으로 수집하고
- **So that** 마감된 공고 대신 최신 지원금이 노출되도록 유지할 수 있다

**인수 조건**
- [ ] 크롤러가 외부 공고를 수집해 DB에 반영한다 `(후속: crawler + GitHub Actions cron)`
