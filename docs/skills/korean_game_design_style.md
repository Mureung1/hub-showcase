# Korean Game Design Style Skill

## Purpose

한국어 게임 기획 문서의 톤과 형식을 일정하게 유지한다.

## Style

- 단정하고 실무적인 문체를 사용한다.
- 과장된 마케팅 문구보다 구현 가능한 기획 정보를 우선한다.
- 확정 정보와 제안을 구분한다.
- 긴 문단보다 짧은 설명과 bullets를 우선한다.
- 미정 정보는 `TBD`로 표기한다.
- 외래어는 이미 문서에서 쓰는 표기를 따른다.

## Avoid

- 근거 없는 세계관 확장
- 요청하지 않은 보상, 수치, 시스템 추가
- 승인된 것처럼 보이는 표현
- 모호한 "좋은 느낌", "재미있게" 같은 평가어만 있는 설명
