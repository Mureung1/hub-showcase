## 3. 복붙 원고 ① — 오버워치 전리품 상자 (챌린지 없이 발행)

**용도**: "챌린지 밖에서는 점수 대신 섹션별 강점·개선점 + 총평을 받는다"를 보여주는 예비 시연.
**경로**: 작성하기 → **시스템 역기획**

**문서 머리말**

| 항목 | 값 |
|---|---|
| 제목 | `오버워치 전리품 상자 — 확률을 감추지 않고 파는 법` |
| 대상 게임 | `오버워치` (카탈로그에서 선택) |
| 시스템 | `전리품 상자` |
| 분류 | `BM·상점` |
| 피드백 요청 | 켜기 |

### 개요

**대상 시스템**
```
오버워치 1의 전리품 상자 — 스킨·감정표현·대사 같은 외형 아이템만 담긴 랜덤 보상 상자
```

**게임 내 역할**
```
성능이 아닌 외형만 파는 수익 모델이자, 레벨업의 유일한 보상으로 장기 플레이를 지탱하는 리텐션 장치
```

**설계 의도 가설**
```
"승패와 무관하게 매 판 무언가 쌓인다"는 감각을 주되, 성능을 팔지 않아 경쟁 공정성은 건드리지 않으려 한 것으로 보인다
```

### 시스템 규칙

**핵심 규칙**
```
- 상자는 레벨업 1회당 1개, 아케이드 주간 승리 3·6·9승에서 추가로 지급된다(무과금 획득 경로가 고정 주기로 존재).
- 한 상자에는 아이템 4개가 들어가고, 그중 최소 1개는 희귀 등급 이상이 보장된다.
- 이미 가진 아이템이 나오면 아이템이 사라지지 않고 크레딧으로 환급된다.
- 크레딧으로는 원하는 아이템을 직접 구매할 수 있다 — 즉 랜덤 실패가 확정 구매의 재화로 흡수된다.
- 이벤트 기간에는 별도의 이벤트 상자가 열리고, 그 시즌 한정 아이템은 해당 기간의 풀에서만 나온다.
```

**핵심 수치·확률**
```
전설 등급 체감 확률은 상자당 약 5~8%(실측 필요, 공개 확률 표기 기준). 4개 중 1개 희귀 이상 보장은 규칙으로 확정.
```

### 유저 플로우

**흐름**
```
경기 종료 → 경험치 정산 → 레벨업 시 상자 획득 → 상자 개봉 연출(4칸 카드 뒤집기) → 중복분 크레딧 환급 →
(원하는 게 안 나오면) 크레딧 상점에서 확정 구매 → 다음 판으로 복귀
```

**이탈 지점**
```
원하는 스킨이 안 나오고 크레딧도 부족할 때. 특히 이벤트 한정 스킨은 기간이 끝나면 확정 구매 경로마저 닫혀 이탈이 커진다.
```

### 데이터 구조

**테이블 · 컬럼**
```
cosmetic_item(id, name, rarity, hero_id, event_id, credit_price)
lootbox_grant(id, user_id, source, granted_at)        -- source: levelup | arcade | event | purchase
lootbox_open(id, box_id, user_id, opened_at)
lootbox_drop(id, open_id, item_id, rarity, is_duplicate, credit_refund)
user_wallet(user_id, credits)                          -- 중복 환급이 쌓이는 곳
```

### 밸런스 · 수치

**난이도·비용 곡선**
```
초반 레벨업이 빨라 상자가 자주 열리다가, 레벨 구간이 올라갈수록 상자 간격이 길어진다. 대신 크레딧은 계속 쌓여
"랜덤이 느려질수록 확정 구매가 가까워지는" 형태로 체감 속도를 보정한다.
```

**밸런싱 의도**
```
랜덤의 기대치를 낮추되 확정 경로를 살려, 지갑을 여는 시점을 "못 참는 순간"이 아니라 "거의 다 모은 순간"으로 옮긴 것으로 보인다.
```

### 예외 처리

**경계 상황과 처리**
```
- 모든 아이템을 이미 보유한 경우: 드랍이 전부 중복 처리되어 크레딧으로만 환급된다.
- 개봉 연출 도중 접속이 끊긴 경우: 개봉은 서버에서 확정되므로 재접속 후 결과가 그대로 보관된다.
- 이벤트 종료 직후 남은 이벤트 상자: 한정 아이템 풀이 닫히므로, 개봉 시점이 아니라 지급 시점 기준으로 풀을 고정할지 정해야 한다.
- 크레딧 잔액이 가격보다 1 부족한 상태: 구매 버튼을 막을지, 부족분 안내로 유도할지가 과금 압력의 세기를 결정한다.
```

### 분석 · 개선

**설계 의도 추론**
```
"성능은 절대 팔지 않는다"는 제약 위에서 수익을 만들기 위해, 랜덤의 자극과 확정 구매의 안심을 한 사이클 안에 같이 넣은 설계로 보인다.
```

**개선 제안 + 근거**
```
- 이벤트 상자에 "기간 내 미획득 한정 아이템 1개 보장"을 넣는다. 한정 아이템의 희소성은 유지되지만,
  기간이 끝나며 아무것도 남지 않는 최악의 경험만 제거된다.
- 크레딧 환급률을 등급별로 공개한다. 확률을 감추지 않는 것이 이 BM의 강점인데, 환급 쪽은 상대적으로 덜 드러나 있다.
- 두 제안 모두 "성능을 팔지 않는다"는 원래 의도를 건드리지 않는다.
```

## 4. 복붙 원고 ② — LoL 드래곤·바론 (챌린지 제출 · 라이브 채점)

**용도**: 발표의 메인 시연. 챌린지 배점 4항목(타이머 30 / 보상 30 / 팀 유도 20 / 개선 근거 20)에 각 섹션이 정면으로 답하도록 썼다.
**경로**: 챌린지 탭 → **"리그 오브 레전드 — 드래곤·바론 오브젝트를 역기획하라" → 참가하기** (게임·시스템·분류 자동 프리필)

**문서 머리말**

| 항목 | 값 |
|---|---|
| 제목 | `드래곤·바론 — 시간표가 다섯 명을 한곳에 모으는 법` |
| 대상 게임 | `리그 오브 레전드` (프리필됨) |
| 시스템 | `정글 · 오브젝트(드래곤/바론)` (프리필됨) |
| 분류 | `진행·레벨` (프리필됨) |
| 피드백 요청 | 켜기 |

> 수치는 패치마다 조정되므로 아래 원고에는 "최근 시즌 기준·실측 필요"를 명시해 뒀다. 배점 힌트가 요구하는 태도가 그것이다.

### 개요

**대상 컨텐츠**
```
소환사의 협곡의 중립 오브젝트 — 드래곤(누적형)과 바론 내셔(단발형)
```

**게임 내 위치**
```
라인전과 한타를 잇는 중간 목표. 맵에 흩어져 있던 5명을 정해진 시각에 한곳으로 모으는 진행 장치다.
```

**대상 유저층**
```
라인전은 익숙하지만 "언제 모여야 하는지"를 아직 못 읽는 중급 이하 플레이어
```

### 컨텐츠 구조

**입장 조건**
```
별도 입장 조건 없음. 대신 스폰 시각·시야·소환사 주문 상태가 사실상의 참가 조건으로 작동한다.
```

**단계 구성**
```
드래곤: 스택 1~3(누적) → 4스택 시 드래곤 영혼(영구 효과) → 이후 장로 드래곤(강력한 한시 버프)으로 단계가 바뀐다.
바론: 단일 단계. 대신 처치 시점이 늦을수록 경기 종결력이 커진다.
```

**제한**
```
드래곤은 첫 스폰 약 5분, 처치 후 약 5분 간격으로 재등장. 바론은 경기 중반(약 20분대) 최초 등장 후 처치되면 다시 리젠된다.
정확한 수치는 패치마다 조정되므로 최근 시즌 기준 추정치이며 실측이 필요하다.
```

### 진행 플로우

**흐름**
```
스폰 1분 전 준비(시야 장악·귀환·소환사 주문 점검) → 라인 정리로 상대 발을 묶음 → 5명 집결 →
교전 또는 무혈 처치 → 보상 수령(스택 누적 또는 글로벌 버프) → 버프를 들고 다음 목표(포탑·억제기)로 전환 →
다음 스폰 시각까지 다시 흩어져 성장
```

### 보상 설계

**보상 종류·수량·조건**
```
- 드래곤(누적형): 처치할 때마다 팀 전체에 영구 스탯이 조금씩 쌓인다. 4스택이면 드래곤 영혼이 열려 판을 뒤집기 어려운 격차가 된다.
- 장로 드래곤(한시형): 짧고 강한 효과로 "지금 끝내라"는 신호를 준다.
- 바론(단발형): 팀 전체 버프가 약 3분간 유지되고, 주변 미니언이 강화돼 공성 속도가 크게 오른다.
- 공통: 처치한 팀만 보상을 받고, 마지막 타격 한 번으로 소유권이 바뀐다(스틸 가능).
```

**성장 곡선 어디에 꽂히나**
```
드래곤은 완만한 우상향(누적), 바론은 계단식 점프(단발). 두 곡선이 겹치는 25~30분 구간에서 경기 결과가 사실상 결정된다.
```

### 경제 · BM 연결

**재화 공급 · 소모**
```
직접적인 재화 공급은 없다. 대신 "시간"과 "시야 자원(와드)"을 소모시키고, 그 대가로 팀 단위 능력치를 공급한다.
소환사 주문·궁극기 같은 쿨다운 자원도 이 시간표에 맞춰 소모된다.
```

**과금(BM) 접점**
```
없다. 오브젝트 설계는 매출이 아니라 관전 가치(프로 경기의 하이라이트 구간)와 세션 길이에 기여한다.
```

### 리텐션 훅

**리텐션 장치**
```
- 시계가 곧 약속이다. "5분마다 한 번은 반드시 사건이 생긴다"는 예측 가능성이 지루한 구간을 없앤다.
- 누적 보상(스택)은 "지금 포기하면 나중이 더 어려워진다"는 압박을 만들어 중도 이탈을 늦춘다.
- 스틸 가능성은 불리한 팀에게도 끝까지 볼 이유를 남긴다 — 한 번의 스매이트로 판이 뒤집힐 수 있다.
```

### 예외 처리

**경계 상황과 처리**
```
- 인원이 부족한 상태에서 스폰: 오브젝트를 포기하고 라인 이득으로 교환하는 선택지가 열려 있어야 한다.
- 마지막 타격을 상대가 가져간 경우: 소유권이 통째로 넘어가므로, 시야가 없는 상태의 시도 자체가 위험 행동이 된다.
- 영혼 확보 직전 팀이 크게 밀린 경우: 누적 보상이 역전 불가로 굳어지지 않도록 장로 드래곤 같은 후속 변수를 남겨 둔다.
- 경기 종료 직전 리젠: 남은 시간에 의미가 없어지는 보상은 설계상 낭비다.
```

### 분석 · 개선

**설계 의도 추론**
```
개인 실력이 흩어져 발휘되는 게임에 "정해진 시각의 팀 단위 사건"을 심어, 5인 협동을 규칙으로 강제한 장치로 보인다.
누적형과 단발형을 한 맵에 같이 둔 이유는 "길게 쌓는 팀"과 "한 방에 끝내는 팀" 두 승리 경로를 모두 열어 두기 위함으로 읽힌다.
```

**개선 제안 + 근거**
```
- 드래곤 영혼 확보 직전(3스택) 구간에서 불리한 팀에게 정보 보상(스폰 30초 전 위치 신호)을 준다.
  격차 자체를 줄이지 않으므로 "누적으로 격차를 만든다"는 원래 의도를 해치지 않으면서, 일방적인 포기 이탈만 줄인다.
- 바론 버프의 미니언 강화 효과를 UI에서 더 분명히 보여준다. 지금은 버프 아이콘만 있어 초보자는
```

## 7. 자주 나올 질문 한 줄 답

- **AI 점수를 믿을 수 있나?** — 절대 평가가 아니라 참고 점수다. 배점을 미리 공개해 근거를 투명하게 하고, 사람 코멘트와 병행한다.
- **비용은?** — Gemini 무료 티어 + 유저당 하루 10회 제한(미리보기 합산). 챌린지 채점은 별도 호출이 아니라 피드백 호출에 합쳐 추가 비용 0.
- **수치가 틀리면?** — 템플릿과 AI 가이드가 "모르면 추정임을 밝히라"고 요구한다. 오늘 원고에도 "패치마다 조정·실측 필요"를 그대로 넣었다.
- **AI가 쓴 코드를 어떻게 믿었나?** — 믿지 않았다. 완료 기준을 "FE→BE→DB 왕복이 관찰될 때"로 정하고, 코드 수정 권한이 없는 검증 Agent에게 그 확인을 맡겼다([`WORKFLOW.md`](./WORKFLOW.md)).
