1. User Flow (사용자 흐름)

사용자 시나리오 6단계를 흐름으로 표현.

flowchart TD
    A["정보 입력 화면<br/>전공 · 부전공 · 학점 · 자격증 · 기타 경험"] --> B[시스템: 맞춤 공고 추천]
    B --> C[추천 공고 목록 화면]
    C --> D[사용자: 공고 선택]
    E["공고 상세 화면<br/>추천 이유 / 주요 조건 확인"]
    D --> E
    E --> F[시스템: 자소서 문항 분석]
    F --> G[시스템: 자소서 초안 생성]
    G --> H[자기소개서 초안 화면]
    H --> I[사용자: 초안 확인 및 수정]
    I --> J[최종 지원서 작성에 활용]

2. IA (화면 목록, Information Architecture)

화면주요 목적
정보 입력 화면전공, 부전공, 학점, 자격증, 그 외 경험(현장실습, 인턴, 교육) 입력
추천 공고 목록 화면추천된 공고 리스트 확인
공고 상세 화면추천 이유, 주요 조건 확인 후 자소서 생성 요청
자기소개서 초안 화면문항별 분석 결과와 생성된 초안 확인/수정
flowchart TD
    Home["① 정보 입력 화면"] --> List["② 추천 공고 목록 화면"]
    List --> Detail["③ 공고 상세 화면"]
    Detail --> Draft["④ 자기소개서 초안 화면"]
    Draft -. 다른 공고 보러 돌아가기 .-> List

3. 와이어프레임 (화면별 주요 UI 요소)

각 화면을 박스로, 화면 안의 주요 UI 요소를 노드로 표현한 대략적인 레이아웃.

flowchart TB
    subgraph S1["① 정보 입력 화면"]
        direction TB
        s1a[["전공 입력창"]]
        s1b[["부전공 입력창 (선택)"]]
        s1c[["학점 입력창"]]
        s1e[["자격증 입력창 (복수 추가 가능)"]]
        s1f[["그 외 경험 입력창 (현장실습 / 인턴 / 교육 등)"]]
        s1d(("추천받기 버튼"))
        s1a --> s1b --> s1c --> s1e --> s1f --> s1d
    end

    subgraph S2["② 추천 공고 목록 화면"]
        direction TB
        s2a[["공고 카드: 제목 / 기관 / 마감일"]]
        s2b[["공고 카드: 추천 이유 요약"]]
        s2c[["... 추가 공고 카드"]]
        s2a --> s2b --> s2c
    end

    subgraph S3["③ 공고 상세 화면"]
        direction TB
        s3a[["공고 기본 정보"]]
        s3b[["추천 이유"]]
        s3c[["주요 조건 (자격, 마감일 등)"]]
        s3d(("자소서 초안 생성 버튼"))
        s3a --> s3b --> s3c --> s3d
    end

    subgraph S4["④ 자기소개서 초안 화면"]
        direction TB
        s4a[["문항별 분석 결과"]]
        s4b[["생성된 초안 텍스트"]]
        s4c[["편집 영역"]]
        s4d(("저장 / 완료 버튼"))
        s4a --> s4b --> s4c --> s4d
    end

    S1 --> S2 --> S3 --> S4
