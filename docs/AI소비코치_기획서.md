# AI 소비 코치 — 기획서

| 항목 | 내용 |
|---|---|
| 프로젝트명 | AI 소비 코치 |
| 한 줄 소개 | 기록하는 가계부가 아니라, 소비 습관을 바꿔주는 AI 코치 — 영수증을 찍으면 자취생 특화 카테고리로 분석하고, 현재 소비 속도로 생활비가 언제 바닥나는지 예측해 알려준다 |
| 타겟 유저 | 자취/기숙사 생활 중인 대학생, 용돈·생활비를 스스로 관리해야 하는 학생 |
| 개발 기간 | 4주 |

---

## 1. 문제 정의

- 대학생·자취생은 정해진 예산 안에서 식비·생활비를 관리해야 하지만, 지출을 매번 손으로 기록하는 건 귀찮아서 며칠 지나면 흐지부지된다.
- 기존 가계부 앱(토스, 뱅크샐러드 등)은 "기록"과 "월별 리포트"까지만 도와줄 뿐, **"이대로 쓰면 이번 달 생활비가 언제 바닥나는지"**, **"지금 뭘 줄여야 하는지"**는 알려주지 않는다.
- 넷플릭스·유튜브뮤직 등 구독 서비스는 매달 똑같이 빠져나가는데, 안 쓰는 구독을 깜빡하고 계속 결제하거나 해지 방법을 몰라서 방치하는 경우가 많다.
- 국내 은행/카드 API(오픈뱅킹·마이데이터) 연동은 정식 금융 라이선스가 필요해 개인 프로젝트로는 불가능하므로, 영수증 사진 업로드 방식으로 대체한다. (인허가 불필요 + iOS/안드로이드 구분 없이 동일 동작)

**차별화 지점**: OCR이나 통계 같은 "기능"이 아니라, 여러 소비 신호를 종합 판단해 **필요할 때만 개입**하는 것 — 즉 "예측 + 선택적 개입"이라는 가치에서 경쟁 서비스와 구분된다.

## 2. 사용자 시나리오

**등장인물**: 자취 3개월 차 대학생 지민씨. 매달 생활비 40만원으로 식비·생필품을 해결해야 한다.

1. **가입 & 온보딩**: 지민씨는 앱에 가입하고 이번 달 생활비 예산(40만원)과 넷플릭스·유튜브뮤직 구독을 등록한다.
2. **일상적 사용**: 편의점에서 도시락을 사고 영수증을 찍어 업로드한다. OCR이 항목·금액·날짜를 인식하고 "편의점" 카테고리로 자동 분류한다. 오분류가 있으면 지민씨가 직접 수정한다.
3. **케이스 A — 평소와 다르지 않을 때**: 지민씨가 평소처럼 학식과 장보기 위주로 소비한 주에는, 업로드 직후 "이번 달 소비 패턴은 안정적이에요"라는 짧은 안내만 뜨고 별다른 개입은 없다.
4. **케이스 B — 신호는 같지만 상황이 다를 때**: 시험 기간이라 배달 음식이 늘었다. 아직 예산 사용률이 낮은 시점이라면 앱은 "배달비가 늘었지만 예산 상황은 여유로우니 개입하지 않는다"고 판단한다. 반면 월 중순이 지나 예산 사용률이 이미 높은 상태에서 배달비가 늘면, 앱은 이를 예산 유지 목표에 대한 위험 신호로 판단해 **레시피 추천(Recipe Tool)**을 실행하고, "최근 배달비 비중이 늘어 예산 유지가 어려워질 것 같아 이런 레시피를 추천해요"라는 이유와 함께 대체 레시피·예상 절약액을 보여준다.
5. **반복 구매 케이스**: 지민씨가 같은 생필품(예: 세제)을 반복해서 사는 패턴이 감지되면, **최저가 비교(Smart Purchase Tool)**가 실행되어 더 저렴한 구매처나 대체 상품을 제안한다.
6. **월말 생존 모드**: 예산 소진이 임박하면 화면이 자동으로 "남은 돈 / 남은 기간 / 오늘 쓸 수 있는 금액"을 보여주는 전용 모드로 전환되어, 지민씨가 월말까지 버틸 수 있도록 돕는다.
7. **주기적 확인**: 지민씨는 대시보드에서 카테고리별 소비 현황과 예산 소진 예상일을 언제든 확인하고, 구독 결제일이 다가오면 알림과 해지 방법 안내를 받는다.

## 3. 핵심 기능

### 3-1. 결정론적 분석 파이프라인 (규칙 기반, 필수)

| 기능 | 설명 |
|---|---|
| 영수증 업로드 & OCR | 영수증/주문내역 캡처 업로드 → OCR로 상호명·항목·금액·날짜 추출 |
| 자취생 특화 카테고리 분류 | 배달/편의점/카페/밀키트/마트/학식 등으로 자동 분류, 수동 보정 가능 |
| 소비 요약 대시보드 | 카테고리별·월별 지출 합계를 그래프로 시각화 |
| 생활비 소진 예측 | 이번 달 누적 일평균(변동비) + 고정비(구독)를 결합해 예산 소진 예상일 계산 |
| 구독(고정비) 등록·관리 | 정기결제 서비스 등록 → 소진 예측에 확정값으로 반영 |
| 월말 생존 모드 | 예산 임계치 이하 시 "남은 돈/기간/오늘 쓸 금액" 전용 화면 자동 노출 |
| 소비 Context 계산 | 단기 신호(배달비 증가율, 예산 소진 위험도)와 장기 신호(반복구매, 카테고리 추세, 구독 상태)를 하나의 Context로 생성해 Agent에 전달 |
| 수동 지출 입력 | 계좌이체·현금·더치페이 등 영수증이 없는 지출을 직접 입력. 자취생 지출 중 상당수가 여기 해당해 빠지면 예측·Context 정확도가 크게 떨어지므로 필수 기능으로 포함, F6 예측·F8 Context 계산에 동일하게 반영 |

### 3-2. AI 소비 코치 Agent (핵심 차별 기능, 필수)

- **Goal**: 사용자가 예산 안에서 지속 가능하게, 더 경제적으로 소비하도록 돕는다.
- 소비 Context를 Goal에 비추어 종합 해석해, 다음 중 하나를 스스로 판단한다.
  1. 개입 불필요 → Tool 호출 없이 안내 메시지만 제공
  2. **Recipe Tool** 실행 — 배달·외식을 대체할 절약 레시피 추천
  3. **Smart Purchase Tool** 실행 — 최저가 비교 및 대체 구매 제안
- 하나의 신호만으로 판단하지 않으며, 같은 신호라도 전체 상황(예산 사용률 등)이 다르면 다른 결정을 내린다.
- Tool 실행 결과를 그대로 노출하지 않고, **추천 이유 → Tool 결과 → 예상 절약 효과 → 예산 소진 예상일** 순서로 사용자 친화적 메시지로 정리해 전달한다.

### 3-3. 선택 기능 (시간 남으면)

카테고리별 예산 목표 설정, 구독 결제 예정 알림 + 해지 가이드, 주간 리포트 알림.

## 4. 이 서비스를 이용함으로써 얻는 이득

- **기록 부담 해소**: 영수증만 찍으면 항목·금액·카테고리가 자동 정리되어, 손으로 가계부를 적다가 며칠 만에 흐지부지되는 문제를 없앤다.
- **돈 떨어지기 전에 미리 안다**: "이대로 쓰면 언제 바닥나는지"를 미리 알려줘서, 월말에 갑자기 잔액이 없어 당황하는 상황을 예방한다.
- **실제로 아낀다**: 막연히 "줄이세요"가 아니라 대체 레시피·최저가 비교 같은 구체적인 행동 대안을 제시해, 실행 가능한 절약으로 이어진다.
- **새는 돈을 막는다**: 안 쓰는 구독을 인지하고 해지까지 안내받아, 매달 자동으로 빠져나가던 불필요한 고정비를 줄인다.
- **선택 스트레스 감소**: 예산이 빠듯한 시기에도 "오늘 쓸 수 있는 돈"이 명확해져, 매번 지출을 결정할 때마다 느끼던 불안을 줄인다.
- **자취생 현실에 맞는 조언**: 범용 카테고리가 아니라 배달/편의점/밀키트 등 실제 자취 소비 패턴에 맞춘 코칭을 받는다.
