# Project Plan

## 프로젝트명
AI 기반 졸업 플래닝 웹 서비스

## 프로젝트 목표
복잡한 졸업요건을 한눈에 확인하고,
학생이 원하는 학기별 수강 계획을 쉽게 세울 수 있도록 지원하는 웹 서비스를 개발한다.

## 주요 기능
- 졸업요건 시각화
- 학점 현황 대시보드
- 과목 검색 및 수강 계획 추가
- 학기별 로드맵 구성
- AI 기반 과목 추천 및 졸업 가능 여부 분석

## MVP
- Mock Data 기반 졸업요건 표시
- 학점 진행률 확인
- 수강 계획 추가/삭제
- 졸업 충족 여부 표시

## 기술 스택
- React
- JavaScript
- CSS

## 6. 4주 개발 계획

### 1주차: 요구사항 정리 및 데이터 구조 설계

목표:

- 졸업요건 구조 정의
- 과목 데이터 구조 설계
- 사용자 이수 내역 구조 설계
- 주요 화면 와이어프레임 작성

주요 작업:

- 컴퓨터학 졸업요건 분석
- 졸업요건 항목 분류
- 과목, 학점, 영역, 필수 여부 데이터 모델 설계
- 대시보드 화면 설계
- 수강 바구니 화면 설계

산출물:

- 졸업요건 데이터 모델
- 과목 데이터 모델
- 주요 화면 설계안

### 2주차: 졸업요건 계산 로직 및 대시보드 구현

목표:

- 사용자의 이수 내역을 기반으로 졸업요건 충족 여부 계산
- 대시보드에서 결과 표시

주요 작업:

- 이수 과목 입력 기능 구현
- 전공/교양/총 학점 계산 로직 구현
- 필수 과목 이수 여부 판단
- 부족 학점 계산
- 졸업요건 충족 현황 대시보드 구현

산출물:

- 졸업요건 계산 기능
- 기본 대시보드

### 3주차: 수강 바구니 및 미래 학기 시뮬레이션 구현

목표:

- 사용자가 수강 예정 과목을 추가하고 졸업요건 변화를 확인할 수 있도록 구현

주요 작업:

- 과목 검색 및 선택 기능 구현
- 수강 바구니 추가/삭제 기능 구현
- 바구니 반영 후 졸업요건 재계산
- 미래 학기별 과목 계획 기능 구현
- 졸업 가능 여부 시뮬레이션 구현

산출물:

- 수강 바구니 기능
- 미래 학기 시뮬레이션 기능

### 4주차: AI 추천 기능 및 최종 개선

목표:

- 부족 요건을 기반으로 AI가 수강 계획을 추천
- MVP 완성도 향상

주요 작업:

- AI 추천 프롬프트 설계
- 부족 요건 기반 추천 로직 구현
- 학기별 수강 계획 추천 기능 구현
- UI 개선
- 테스트 및 오류 수정
- GitHub Wiki 문서 최종 정리

산출물:

- AI 기반 수강 계획 추천 기능
- MVP 최종 버전
- 프로젝트 문서

- GitHub

## 향후 계획
- 학교 API 연동
- AI 추천 기능 고도화
- 실제 학사 데이터 기반 졸업 시뮬레이션 구현
