# Project Plan

## 프로젝트명
AI 기반 졸업 플래닝 웹 서비스

## 프로젝트 목표
복잡한 졸업요건을 한눈에 확인하고,
학생이 원하는 학기별 수강 계획을 쉽게 세울 수 있도록 지원하는 웹 서비스를 개발한다.

## 주요 기능
- 졸업요건 시각화
- 학점 현황 대시보드
- 과목 검색 및 수강 계획 추가
- 학기별 로드맵 구성
- AI 기반 과목 추천 및 졸업 가능 여부 분석

## MVP
- Mock Data 기반 졸업요건 표시
- 학점 진행률 확인
- 수강 계획 추가/삭제
- 졸업 충족 여부 표시

## 기술 스택
- React
- JavaScript
- CSS
- GitHub

## 향후 계획
- 학교 API 연동
- AI 추천 기능 고도화
- 실제 학사 데이터 기반 졸업 시뮬레이션 구현
