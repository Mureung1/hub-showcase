# 화면 구조(UI) — 탑히어

> 프로토타입: [`prototype/index.html`](../../prototype/index.html) — 아래 화면 구성을 순수 HTML/CSS로 구현한 클릭 가능한 시안. 브라우저로 직접 열어 확인할 수 있다.

처음 진입할 때부터 **화면 전환 없이 "좌측 조건 패널 + 우측 지도"** 한 화면으로 구성된다. 페이지가 바뀌는 게 아니라, 사용자의 입력에 따라 같은 화면 안에서 좌측 패널과 우측 지도의 내용이 단계적으로 채워지는 방식(SPA형)이다. [기획서](기획서.md)의 사용자 시나리오(2장) 1~5단계는 이 한 화면이 거치는 상태 변화에 대응한다.

우측 지도는 실제 지도(도로·행정동 경계가 보이는 지도 타일) 위에 추천 지역을 폴리곤 색칠로 강조하는 방식이며, 아래 참고 이미지가 그 느낌의 기준이다.

![alt text](../../public/region-select.png)

## 상태 1 — 학교 검색 (진입 직후)

시나리오 1단계에 대응. 좌측 패널에는 학교 검색창만 보이고, 우측 지도는 아직 특정 지역으로 좁혀지지 않은 기본 화면이다.

```
┌───────────────────┬──────────────────────────────────────┐
│ 탑히어              │                                        │
│                    │                                        │
│ 🔍 학교 이름을        │                                        │
│    검색하세요         │              (기본 지도 화면)             │
│  ├ 건국대학교         │                                        │
│  ├ 세종대학교  ← 자동완성│                                        │
│  └ 한양대학교         │                                        │
│                    │                                        │
└───────────────────┴──────────────────────────────────────┘
```

- 검색창에 입력하면 학교명 자동완성 목록이 뜬다.
- 학교를 선택하면 화면 전환 없이 곧바로 **상태 2**로 바뀐다. 우측 지도는 선택한 학교 위치로 자동 이동·확대되고, 학교 위치에 마커가 표시된다.

## 상태 2 — 조건 입력

시나리오 2단계에 대응. 학교를 고르고 나면 좌측 패널 상단이 검색창 대신 선택한 학교 이름으로 바뀌고, 그 아래 예산·통학 허용시간 같은 조건 입력 필드가 나타난다. 이 시점에는 아직 가중치 슬라이더나 추천 결과가 보이지 않는다.

```
┌───────────────────┬──────────────────────────────────────┐
│ 건국대학교 ▾         │                                        │
│                    │              🏠(학교 마커로 지도 이동)      │
│ 월세 상한(만원)       │                                        │
│  [    60    ]      │                                        │
│                    │                                        │
│ 통학 허용시간(분)      │                                        │
│  [    20    ]      │                                        │
│                    │                                        │
│   [ 확인 ]          │                                        │
└───────────────────┴──────────────────────────────────────┘
```

- 월세 상한, 통학 허용시간은 슬라이더가 아니라 사용자가 값을 직접 입력하는 필드다.
- "확인"을 누르면 화면 전환 없이 **상태 3**으로 바뀐다.

## 상태 3 — 가중치 슬라이더 + 지도 폴리곤 + TOP5 (핵심 화면)

시나리오 3~4단계에 대응. 확인을 누른 순간부터 좌측 패널의 학교 이름 아래에 통학·월세·치안·편의시설·교통 5개 항목의 **가중치 슬라이더**가 나타나고, 그 아래에는 TOP5 지역이 참고 이미지 속 카드와 같은 형태로 나열된다. 동시에 우측 지도에는 추천 지역의 경계가 폴리곤으로 강조되고 TOP5 지역에는 마커가 찍힌다. 슬라이더를 움직이면 좌측 카드와 우측 지도가 실시간으로 함께 다시 계산된다.

```
┌───────────────────┬──────────────────────────────────────┐
│ 건국대학교 ▾         │                🏠(학교)                │
│                    │        ╱▔▔▔▔╲                        │
│ 통학 중요도          │       │ 자양동  ╲___                   │
│ ▓▓▓▓▓▓░░░░         │       │ (폴리곤 강조) ╲                  │
│                    │        ╲______╱                       │
│ 월세 중요도          │                    ╱▔▔╲                │
│ ▓▓▓▓▓▓▓░░░         │                   │화양동│               │
│                    │                    ╲__╱                │
│ 치안 중요도          │                                        │
│ ▓▓▓▓▓░░░░░         │   진할수록 점수 높음 · ★ = TOP5 마커       │
│                    │                                        │
│ 편의시설 중요도       │                                        │
│ ▓▓▓▓░░░░░░         │                                        │
│                    │                                        │
│ 교통 중요도          │                                        │
│ ▓▓▓▓▓▓░░░░         │                                        │
│                    │                                        │
│ ── TOP5 지역 ──     │                                        │
│ ① 자양동   91점      │                                        │
│   통학지수 · 월세지수 · 편의시설 │                                │
│ ② 화양동   87점      │                                        │
│   통학지수 · 월세지수 · 편의시설 │                                │
│ ③ 군자동   82점      │                                        │
│ ④ 성수동   76점      │                                        │
│ ⑤ 중곡동   71점      │                                        │
└───────────────────┴──────────────────────────────────────┘
```

- 슬라이더 5종(통학·월세·치안·편의시설·교통 중요도)은 조작 즉시 좌측 TOP5 카드와 우측 지도 폴리곤·마커에 반영된다(디바운스 없이 실시간).
- 우측 지도는 행정동 경계를 실제 지도 위에 폴리곤으로 색칠하는 방식이며, 점수 상위 5개 지역에는 별도 마커가 표시된다.
- 좌측 TOP5 카드 또는 지도 위 마커를 클릭하면 해당 지역의 **상세 드로어**가 열린다.

## 상세 드로어 — 근거 수치 + 외부 연결

시나리오 4~5단계에 대응. 화면을 벗어나지 않고 우측에서 드로어(패널)가 슬라이드 인되는 방식으로, 지도의 맥락을 유지한 채 근거를 확인할 수 있게 한다.

```
                              ┌───────────────────────────┐
                              │ 자양동            ✕ 닫기    │
                              │ 종합점수 91 · 전체 1위       │
                              │                             │
                              │ 통학시간     22분            │
                              │ 예상 월세    58만원           │
                              │ 치안 점수    80 / 100        │
                              │ 편의시설 점수 78 / 100        │
                              │ 교통 점수    85 / 100        │
                              │                             │
                              │ "통학은 조금 늘어나지만       │
                              │  월세·교통에서 앞선다"        │
                              │                             │
                              │ ┌─────────────────────────┐ │
                              │ │ 네이버 부동산에서 보기 ↗   │ │
                              │ └─────────────────────────┘ │
                              └───────────────────────────┘
```

- 상단에 지역명과 종합 순위, 중단에 항목별 근거 수치, 하단에 한 줄 코멘트를 배치해 "왜 이 지역이 상위인지"를 한 화면에서 설명한다.
- "네이버 부동산에서 보기" 버튼은 새 탭으로 네이버 부동산(해당 지역 매물 검색 결과)을 연다. 탑히어의 책임은 여기까지이며, 이후 매물 비교·계약 문의는 외부 플랫폼에서 진행된다.

## 상태 전환 흐름 요약

```
상태 1: 학교 검색
      │ 학교 선택 (화면 전환 없음, 지도만 이동)
      ▼
상태 2: 조건 입력 (월세 상한 · 통학 허용시간 직접 입력)
      │ "확인"
      ▼
상태 3: 가중치 슬라이더 + 지도 폴리곤 + TOP5 (좌우 실시간 연동)
      │ 카드 또는 지도 마커 클릭
      ▼
상세 드로어(근거 수치)
      │ "네이버 부동산에서 보기"
      ▼
   외부 플랫폼(새 탭)
```
