# 3주차 — 주간 계획 (2026-07-20 ~ 2026-07-24)

> [기획서.md](기획서.md), [backlog.md](backlog.md) 기준. 이슈 등록·개발은 이 문서를 보고 직접 진행한다.

## 1. 진도 점검

**결론: 화면-서버-DB 수직 슬라이스(vertical slice)가 아직 완성되지 않았다.**

- **프론트**: `chat-demo`, `log-viewer` 화면 UI는 완성. 하지만 `src/api/chat.js`, `src/api/logs.js`는 실제 백엔드를 호출하지 않고 `setTimeout` + 하드코딩된 목업 데이터로만 동작한다 (코드 주석에도 "목업 구현. 백엔드 준비되면 교체"라고 명시돼 있음).
- **백엔드**: `server/`에는 `server/src/data/schema.sql`(DB 스키마)과 `db.js`만 있고, `app.js`·`routes/`·`providers/`·`services/`는 전혀 없다. `server/package.json` 의존성에 express조차 설치돼 있지 않다.
- 즉 요청이 화면 → 백엔드 API → DB 저장 → 응답까지 한 바퀴 도는 경로가 전혀 연결돼 있지 않다.

**따라서 이번 주의 최소 목표는 화면-서버-DB가 한 바퀴 도는 수직 슬라이스 완성이다.**

## 2. 이번 주 목표

전화번호/이메일이 포함된 프롬프트를 입력하면 마스킹되고, 기업 기밀 키워드가 포함된 프롬프트는 차단되는 시나리오가 화면→서버→DB→화면까지 실제로 동작하는 것. (auth까지 반영한다)

인증을 수직 슬라이스 뒤로 미루지 않고 월요일부터 바로 붙이도록 한다.
