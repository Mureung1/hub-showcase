# StockMate Agent 진행 기록

> StockMate Agent MVP를 기획하고 화면 설계를 구체화하는 과정에서의 작업 기록입니다.

---

## 2026-07-09

### 오늘 시도한 작업

오늘은 StockMate Agent의 화면 설계를 실제 구현 단계에서 반복 적용할 수 있도록 **디자인 스킬과 화면 구성 규칙**을 정리해보려 했습니다.

특히 대시보드와 오늘의 브리핑 화면에서 다음 기준을 잡으려고 했습니다.

- 재고 상태를 한눈에 구분할 수 있는 색상과 태그 규칙
- 오늘 먼저 확인해야 할 상품을 강조하는 우선순위 카드 구조
- 셀러가 숫자만 보는 것이 아니라 “왜 지금 확인해야 하는지” 이해할 수 있는 문장형 브리핑 톤
- 자동 발주가 아니라 사용자가 최종 판단하는 흐름을 유지하는 버튼과 화면 구조

### 아직 정리 중인 부분

오늘 안에 디자인 스킬을 완성된 문서로 확정하지는 못했습니다.

대시보드 화면은 정보가 많아질수록 표와 상태 태그가 복잡해질 수 있고, 오늘의 브리핑 화면은 카드가 너무 설명 위주로 보이면 사용자가 빠르게 판단하기 어려울 수 있다고 판단했습니다. 그래서 화면을 바로 확정하기보다, 다음 작업에서 재사용할 수 있는 디자인 기준을 조금 더 정리한 뒤 구현에 반영하려고 합니다.

### 다음 작업 방향

- 대시보드의 상태 태그 색상과 우선순위 기준을 더 단순하게 정리
- 오늘의 브리핑 카드에서 상품명, 위험 사유, 추천 발주 수량이 먼저 보이도록 정보 순서 조정
- 화면 설계 이미지와 프로토타입의 스타일을 맞춰 실제 React 구현 기준으로 정리
- 디자인 스킬 초안을 바탕으로 공통 UI 컴포넌트 구조 설계
