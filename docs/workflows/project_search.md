# Project Search Workflow

## Purpose

확정 문서, 아이디어, 승인 큐, 결정 로그, 버전 기록에서 근거 있는 답변을 만든다.

## Search Order

1. `workspace/design/`
2. `workspace/decisions/decision_log.md`
3. `workspace/versions/version_history.md`
4. `workspace/approvals/approval_queue.md`
5. `workspace/ideas/temporary_ideas.md`

## Steps

1. 질문의 핵심 키워드, 대상 문서 타입, 시점을 파악한다.
2. 관련 파일을 검색한다.
3. 확정 문서와 미승인 아이디어를 구분한다.
4. 답변에 파일 경로와 근거를 포함한다.
5. 근거가 부족하면 추정하지 말고 부족한 점을 말한다.

## Safety Rule

검색 요청은 문서 수정 요청이 아니다. 사용자가 별도로 변경을 요청하지 않으면 파일을 수정하지 않는다.
