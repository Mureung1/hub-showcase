## 2. 자막 작성 규칙

음성이 없으므로 **읽을 시간 확보가 전부**다.

- 한 줄 **최대 30자**, **최대 2줄** (30자를 넘으면 한 줄이 화면 밖으로 밀린다)
- 한 자막 **최소 노출 2.5초**. 2줄이면 **3.5초 이상**
- 자막 사이 간격 최소 0.1초 (붙으면 편집기에서 겹침 경고가 난다)
- **화면에 이미 크게 쓰인 문구를 자막으로 반복하지 않는다** — 화면이 말하지 않는 것만 자막으로
- 숫자·영문 고유명사는 그대로(`storedCount`, `INTJ`, `503`)

## 3. 녹화 전 체크리스트

**워밍업 (필수, 녹화 5분 전)**

```bash
curl -m 90 https://hub-backend-kymx.onrender.com/api/health && curl -sI https://hub-theta-brown.vercel.app | head -1
```

Render 무료 티어는 15분 미사용 시 슬립하고, 2026-07-28 실측 콜드스타트는 **15.4초**다. 워밍업하지 않으면 그 15초가 그대로 영상에 찍힌다. 응답의 `storedCount` **시작값을 적어둔다** — C 블록에서 "늘었다"를 보여주려면 시작값을 알아야 한다.

**브라우저**

- 시크릿 창, 창 크기 **1280×800**, 확대 **100%**
- 북마크바 숨김(`⇧⌘B`), 확장 프로그램 아이콘 정리
- `/api/health` 탭을 **미리 열어둔다**(C 블록용)
- localStorage가 빈 상태에서 시작 — 랜딩에 `이전 결과 이어보기` 버튼이 **안 떠야** 한다

**macOS**

- 방해금지 모드 ON (알림 배너가 찍히면 재촬영)
- Dock 자동 숨김
- `⇧⌘5` → 옵션에서 **마우스 클릭 표시 ON**

**절대 화면에 넣지 않는 것**

- Render 대시보드 **Environment 탭** (Supabase `service_role` 키가 노출된다) — Render는 **Logs 탭만** 사용
- Supabase 대시보드의 API 키 영역
- `.env` 파일 내용, 터미널의 환경변수 출력

## 4. 자막 금칙어 (하드룰)

아래 표현이 자막이나 화면에 들어가면 안 된다.

| 금칙 | 이유 |
|---|---|
| "MBTI로 당신의 공부법이 결정됩니다" 류 단정 | MBTI를 고정 판단 도구로 쓰지 않는다 |
| 성적·등급 예측 표현 | 하드룰 |
| "정확도 92%" 같은 수치 | 검증되지 않은 정확도 주장 금지 |
| "스트레스를 진단합니다" | 정신건강 진단 아님 |
| "AI가 분석해서 맞춰줍니다" | 추천은 규칙 기반이다. 사실과 다르다 |

반대로 **반드시 화면에 잡혀야 하는 것**: 결과 화면의 *"공식 MBTI 평가 결과가 아닙니다"* 고지. 하드룰을 지키고 있다는 시각적 증거다.

## 5. 편집·내보내기

1. QuickTime Player(또는 `⇧⌘5`)로 녹화 → `.mov`
2. CapCut에서 `.mov` 열기 → 자막 → 로컬 자막 가져오기 → [`subtitles/demo.srt`](./subtitles/demo.srt)
3. 녹화 실제 타이밍에 맞춰 자막 위치 조정(대본은 계획값이라 몇 초씩 밀린다)
4. **총 길이가 5:00 미만인지 확인** ← 제출 요구사항
5. 1080p mp4로 내보내기

> 이 맥에는 `ffmpeg`이 없어서 자막 번인 자동화 대신 CapCut 경로를 쓴다. 설치돼 있는 도구: CapCut · iMovie · QuickTime Player.

업로드와 `showcase/showcase.json`의 `demoVideoUrl` 추가는 **영상 확정 후 별도로** 한다. 스키마상 `demoVideoUrl`은 `^$|^https://` 패턴이라 로컬 파일 경로는 넣을 수 없다.
