## 2. 자막 작성 규칙

음성이 없으므로 **읽을 시간 확보가 전부**다.

- 한 줄 **최대 30자**, **최대 2줄**

- 자막 사이 간격 최소 0.1초
- 읽기 속도 **초당 9자 이하**
- **화면에 이미 크게 쓰인 문구를 자막으로 반복하지 않는다**
- 숫자·영문 고유명사는 그대로(`storedCount`, `INTJ`, `503`)

`scratchpad/demo/check-srt.mjs`가 위 규칙과 §4 금칙어를 한 번에 검사한다. SRT를 고치면 반드시 돌린다.

## 3. 자막을 ffmpeg 으로 굽지 않는 이유

**브라우저가 자막을 그리고, 그 프레임을 그대로 인코딩한다.**

이 맥의 ffmpeg 은 `8.1.2_1` (Homebrew) 이고 빌드 옵션에 `--enable-libass`·`--enable-libfreetype` 이 없다. 그래서 `subtitles`·`ass`·`drawtext` **필터가 아예 존재하지 않는다**(옵션이 꺼진 게 아니라 컴파일이 안 됐다). 현재 Homebrew ffmpeg 포뮬러의 Required deps 에도 libass 가 없어 `brew reinstall` 로는 생기지 않고 소스 빌드가 필요하다.

다만 **설치하지 않는 이유는 비용이 아니라 표현력이 후퇴하기 때문**이다.

| | ASS / libass | 브라우저 CSS (현재) |
|---|---|---|
| 배경 박스 | 사각형만 (`BorderStyle=3`) | **둥근 pill** |
| 반투명 + 배경 블러 | 불가 | `backdrop-filter: blur(4px)` |
| 페이드 인/아웃 | `\fad` 태그, 거칠다 | `transition: opacity .22s` |
| 한글 폰트 | fontconfig 가 잡아야 함 | 시스템 폰트 그대로 |

libass 가 주는 유일한 이점은 **화면과 자막의 분리**(재녹화 없이 자막만 교체)인데, `record.mjs` 가 남아 있어 재녹화가 스크립트 한 번이라 실익이 작다.

> 참고: 소프트 자막(켜고 끄는 트랙)은 libass 없이도 된다 — `mov_text`·`srt` **인코더**는 이 빌드에 있다.

## 5. 제작 방법 — 완전 자동 녹화

사람이 화면을 조작하지 않는다. macOS 화면 기록 권한이 필요 없고, 몇 번을 다시 찍어도 결과가 같다.

```
headless Chrome ─ CDP 로 배포된 앱 조작 ─ Page.startScreencast 프레임 수집 ─ ffmpeg concat → mp4
        ↑                                          ↑
   대본(SRT) 시각이 그대로 타임라인          자막·가짜 커서를 페이지에 주입해 프레임에 굽는다
```

스크립트는 스크래치패드에 있고 커밋하지 않는다(`scratchpad/demo/`).

| 파일 | 역할 |
|---|---|
| `record.mjs` | SRT 큐 시각을 타임라인으로 삼아 클릭·스크롤을 배치. 자막과 화면이 어긋날 수 없다 |
| `overlay.mjs` | 자막 + 가짜 마우스 커서를 페이지에 주입. CDP 는 이벤트만 주입하고 커서를 그리지 않는다 |
| `slides.html` | 15씬 덱. 터미널·아키텍처·Agent 워크플로우는 브라우저로 찍을 수 없어 슬라이드로 만든다 |
| `cdp.mjs` | Node 24 전역 `WebSocket` 기반 최소 CDP 클라이언트(패키지 설치 없음) |
| `encode.sh` | 실제 프레임 타임스탬프로 concat → CFR 30fps mp4 |
| `check-srt.mjs` | 자막 규칙 + 금칙어 검사 |
| `check-slides.mjs` | 15씬이 1280×720 에서 넘치거나 자막 영역을 침범하지 않는지 |
| `smoke.mjs` | 앱 흐름 셀렉터 전수 확인. **서버 저장은 누르지 않는다**(DB 오염 방지) |

### 스크립트가 스스로 확인하는 것 (25개 체크)

**자동 녹화는 "클릭이 성공했는지"를 스크립트가 확인해야 한다.** 요소를 못 찾아도 조용히 지나가면 영상을 다 찍은 뒤에야 알게 된다(2026-07-28 교훈). 각 클릭 성공 여부에 더해:

- 4축 카드 안에 `공식 MBTI 평가 결과가 아닙니다` 고지가 있는지
- `.trust-observed` 카드와 `.basis-chip` 이 렌더됐는지 → **LLM 실호출 성공의 증거**
- `/api/health` 응답에 `storedCount` 가 있는지
- 종료 후 `localStorage['hub-anon-id']` 와 `storedCount` 변화 → `last-run.json`

### 알아둘 것

- **React 제어 컴포넌트에 값을 넣을 때** `.value` 직접 대입은 무시된다. native setter + `input` 이벤트가 필요하다:
  ```js
  const set = Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype, 'value').set;
  set.call(ta, text); ta.dispatchEvent(new Event('input', { bubbles: true }));
  ```
- **Chrome JSON 뷰어의 `pretty print 적용` 토글**은 `display:none` 으로 감춰도 남는다. 응답 텍스트만 뽑아 `document.body` 를 통째로 다시 그린다.
- **AI 근거 카드의 제목은 `h3` 가 아니라 `span.trust-step-tag`** 다. 컨테이너 `.trust-observed` 로 잡는다.
- **녹화 전 워밍업 필수** — Render 무료 티어 콜드스타트 실측 15.4초. `record.mjs` 가 `/api/health` 와 `/api/mbti-chat` 을 먼저 찔러 둔다.

### ⚠ 녹화는 연구 데이터에 실제 레코드를 남긴다

큐 21에서 **실제로 `서버에 익명 저장`을 누른다.** 그래야 `storedCount` 증가가 진짜 증거가 된다. 대신:

- `record.mjs` 가 종료 직후 `anonId` 를 로그와 `last-run.json` 에 남긴다
- 영상 확정 후 `DELETE /api/results?anonId=…` 로 즉시 지운다
- **프로필을 지우기 전에 반드시 `anonId` 를 확보**한다 — 2026-07-28 2차 녹화분은 이걸 놓쳐 API 로 못 지우고 Supabase 대시보드에서 직접 지워야 한다

## 5-1. 비주얼 변형 두 가지

큐시트·자막·타이밍은 **완전히 동일**하고 `slides.html`·`overlay.mjs` 의 CSS 만 다르다. 영상의 픽셀은 전부 HTML/CSS 에서 나오므로, 스타일 교체는 mp4 를 손대는 게 아니라 CSS 를 바꾸고 다시 렌더하는 일이다(스크립트 한 번, 약 5분).

| | 빈티지 에디토리얼 | Apple |
|---|---|---|
| 파일 | `~/Downloads/hub-demo.mp4` | `~/Downloads/hub-demo-apple.mp4` |
| 배경 | 크림 `#f2ede1` 단일 | `#f5f5f7` ↔ `#000000` 이분법 |
| 악센트 | 잉크블루 `#3d5a99` + 레드·골드 | **Apple Blue 하나만** (`#0071e3` / `#2997ff`) |
| 헤드라인 | weight 800, 40px | **weight 600**, 54px (히어로 62px) |
| 씬 리듬 | 없음(전부 라이트) | light → dark → light(앱) → dark → light → dark → light |
| 앱 화면(0:54–3:08) | 동일 — 배포된 실제 앱이라 손대지 않는다 | |

**Apple 판 디자인 토큰** (`slides.html` `:root`)

```
--light:#f5f5f7  --dark:#000  --ink:#1d1d1f  --ink-2:#6e6e73  --ink-3:#86868b
--on-dark:#f5f5f7  --on-dark-2:#86868b  --blue:#0071e3  --blue-d:#2997ff
--shadow: 3px 5px 30px rgba(0,0,0,.22)   ← 섀도우는 이 한 가지만
--pill: 980px   --card: 18px
letter-spacing: 헤드라인 -0.374px / 본문 -0.28px,  line-height 1.09~1.19
```

> **폰트**: `system-ui` 를 쓴다. macOS 에서 `system-ui` 는 라틴 SF Pro Display/Text + 한글 Apple SD Gothic Neo 로 해석되는 **Apple 정품 페어링**이다. `"SF Pro Display"` 는 웹 콘텐츠에서 패밀리명으로 접근할 수 없고(측정으로 확인), Pretendard 는 이 맥에 설치돼 있지 않다. 웹폰트로 Pretendard 를 불러오면 한글이 오히려 Apple 에서 멀어지고 녹화 중 로드 타이밍 리스크가 생긴다.

> **남는 이질감**: 영상의 46%(0:54–3:08)는 배포된 실제 앱 화면이고, 그 앱의 확정 디자인은 빈티지 에디토리얼(크림·블루잉크)이다. 슬라이드를 Apple 로 바꾸면 이 구간과 톤이 갈린다. 앱을 고치지 않는 한 없앨 수 없는 차이라, 씬 리듬에서 앱 구간을 "light" 로 취급해 충격을 줄였다.
