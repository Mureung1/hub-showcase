grep▌

텍스트에서 패턴과 일치하는 줄을 검색한다

설명

Global Regular Expression Print의 약자. 파일이나 다른 명령어의 출력에서 특정 문자열/정규표현식과 일치하는 줄만 걸러서 보여준다.

주요 옵션

  • -i대소문자를 구분하지 않고 검색
  • -r디렉터리 내 모든 파일을 재귀적으로 검색
  • -n일치한 줄의 줄 번호를 함께 표시
  • -v패턴과 일치하지 않는 줄만 표시(반전 검색)

터미널 예시

grep "TODO" main.js

main.js에서 TODO가 포함된 줄 찾기

grep -rn "error" ./logs

logs 디렉터리 하위 모든 파일에서 error 검색, 줄 번호 표시

동작 설명 — 목록에서 명령어 카드를 클릭했을 때 이동하는 상세 화면(기획서 4장 "명령어 상세 보기"). 설명 + 주요 옵션 + 터미널 실행 예시 3단 구조로 고정되며, chmod처럼 개념 설명이 더 필요한 명령어는 옵션 표가 확장되는 식으로 같은 레이아웃을 재사용한다.
