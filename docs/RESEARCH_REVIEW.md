# 문헌 기반 제품·검수 근거

> 상태: 2026-07-12 범위의 집중 문헌 검토 완료. 체계적 문헌고찰이나 사용자 검증 결과가 아니다.
>
> 목적: 인터뷰가 어려운 현재에는 동료심사 연구로 답냥이의 설계·콘텐츠·AI 평가 기준을 보강하고, 실제 사용자만 답할 수 있는 가설은 분리해 남긴다.
>
> 적용 범위: T25 콘텐츠 검수, T20 실 provider 품질 진행 전 무참여자 벤치마크, T21 AI 품질 평가, T22 짧은 사람 대상 과업 검증. provider 비종속 T18·T30 백엔드 기반 구현은 이 판정과 분리한다.

## 1. 먼저 내린 결론

문헌은 제한된 글쓰기 과업에서 AI가 시간과 평균 품질을 개선할 수 있다는 점을 지지한다. 동시에 AI 추천은 표현의 감정 방향과 상대의 인상을 바꿀 수 있다. AI가 텍스트를 제공한 조건과 자기선택한 AI-primary 작성은 낮은 ownership·책임감과 연관됐고, 전적 언어도구 의존으로 알려진 사과는 진정성이 낮게 평가됐다. 이는 단조로운 사용량 효과나 모든 AI 문구의 인과효과를 뜻하지 않는다. 따라서 답냥이의 경쟁력은 “AI가 더 잘 써준다”가 아니라 **프롬프트로 맥락을 설명하는 부담을 관계·상황 선택으로 줄이면서, 사용자가 사실과 최종 표현을 통제하게 하는가**로 검증해야 한다.

| 구분 | 이 문서에서의 의미 | 예시 |
| --- | --- | --- |
| 직접 근거 | 해당 연구의 표본·과업 안에서 관찰된 결과 | 업무 글쓰기 시간 감소, 실제 사용된 추천문의 감정이 대화 언어를 움직임, AI 제공·AI-primary 조건과 낮은 ownership의 연관 |
| 제품 추론 | 직접 근거와 답냥이 설계 사이의 간접 적용. 별도 검증 필요 | 관계·상황 카드는 프롬프트 부담을 줄일 수 있음, 사용자 선택은 agency 손실을 완화할 수 있음 |
| 미검증 가설 | 문헌이나 현재 저장소로 답할 수 없는 사용자·시장 결과 | ChatGPT·Gemini 대신 선택, 30% 시간 단축, 실제 재사용·관계 개선 |

문헌은 아래 설계의 답냥이 내 효과를 직접 증명하지 않는다. 다만 선행 연구가 알려준 효율·agency·관계 위험을 줄이기 위해 유지할 **제품 가설과 검증 방향**은 다음과 같다.

- 관계·상황을 선택지로 외부화해 빈 프롬프트 작성 부담을 줄인다.
- 완성문은 자동 전송하지 않고, 세 후보를 같은 무게로 보여준 뒤 사용자가 선택·복사하고 실제 전송 전에 수정할 수 있게 한다.
- 세 후보는 같은 사실과 의도를 유지하고 직접성·완화 방식만 달라야 한다.
- 속도만 보지 않고 사실 충실성·관계 적합성·후수정량·“내가 실제로 할 말 같다”를 함께 본다.
- 공손성을 종결어미 하나로 판단하지 않고 관계 지위·친밀도·화행 부담·매체를 함께 검수한다.
- LLM 평가는 관찰 가능한 항목의 보조 수단으로만 쓰고, 주관적인 관계 적합성·진정성은 한국어 맥락을 아는 사람의 블라인드 평가를 우선한다.

아직 증명되지 않은 주장은 다음과 같다.

- 대학생이 같은 상황에서 ChatGPT·Gemini보다 답냥이를 먼저 선택한다.
- 답냥이가 범용 AI보다 최종 전송 문구까지 30% 이상 빠르다.
- 세 후보가 한국어 관계 메시지의 보편적인 최적 개수다.
- 답냥이 문구가 관계 결과를 개선하거나 실제 전송·재사용을 늘린다.
- 현재 네 관계 묶음이 한국 대학생의 메시지 상황을 가장 잘 설명한다.

## 2. 검토 방법과 증거 수준

2026-07-12까지 확인 가능한 저널·학회 원문, DOI, KCI 색인을 우선했다. AI 글쓰기 효과, AI 매개 관계 커뮤니케이션, 어려운 대화, 구조화 추천 UI, 한국어 공손성의 다섯 질문을 대상으로 한 **집중 검토**이며, 데이터베이스 전수검색·중복 선별·메타분석을 수행한 체계적 문헌고찰은 아니다.

| 코드 | 증거 수준 | 이번 문서에서의 사용 |
| --- | --- | --- |
| P1 | 동료심사 무작위배정 실험 또는 식별 전략을 명시한 대규모 현장 준실험. 사전등록 여부는 각 행에 별도 표기 | 제한된 맥락의 효과 방향과 측정 항목 근거 |
| P2 | 동료심사 자기선택·관찰·질적 HCI·언어 연구 | 인과효과가 아닌 설계 위험, 검수 기준, 맥락 변수의 근거 |
| W | 워크숍·preprint·관점 글 | 가설 후보만 허용. 이번 결정 gate의 핵심 근거에서는 제외 |
| O | 공식 제품 문서 | 현재 경쟁 제품의 기능 확인만 허용. 사용자 효과 근거로 사용 금지 |

표본·효과·연구 맥락이 답냥이와 다르면 결과를 직접 일반화하지 않는다. 공개 초록에 표본이 없는 국내 연구는 “미기재”로 표시하며 추정하지 않는다.

## 4. 현재 관계 taxonomy에 대한 문헌 판정

현재 네 분류는 MVP 탐색 범위를 줄이기 위한 **제품 가설**이다. 문헌에서 그대로 도출된 관계 분류로 표현하지 않는다. 이번 작업에서는 화면 구조와 분류를 바꾸지 않고, 복합 카드의 양쪽 하위 관계를 모두 통과하도록 T25 검수를 강화한다.

| 현재 분류 | 문헌이 지지하는 범위 | 남은 위험과 현재 결정 |
| --- | --- | --- |
| 팀플·조모임 | 단체 대화의 공식성 전환과 요청 부담 원리만 간접 지지 | 대학 팀플 고유 범주 근거는 없음. 팀원·조장 어느 쪽에도 강압적이지 않은지 검수 |
| 교수님·조교님 | 교수 요청 이메일의 위계·고부담 근거는 비교적 강함 | 교수와 조교를 같은 호칭으로 묶는 근거 없음. `교수님` 하드코딩 0건, 양쪽 호칭과 매체 중립성을 검수 |
| 선배·동기 | 지위와 친밀도가 전략을 바꾼다는 원리 지지 | 상위자와 동등자를 같은 문구로 묶는 직접 근거 없음. 선배에게 무례하지 않고 동기에게 과잉 격식이 아닌지 모두 검사 |
| 친구·연인 | 친밀도가 공손 전략에 영향을 준다는 원리 지지 | 친구와 연인의 동일 범주 근거 없음. 친밀감 강요·관계 단정·입력 없는 약속을 금지 |

분류 변경은 제품 구조 변경이므로 별도 제안·승인을 거친다. T25에서 한 문구로 두 하위 관계를 안전하게 포괄할 수 없으면 문구를 억지로 일반화하지 않고 해당 카드·taxonomy 조정안을 먼저 제안한다.

## 5. 문헌과 제품 계약을 검수 기준으로 연결한 항목

아래 기준의 출처를 섞어 표현하지 않는다. 문헌은 관계·화행·매체를 살필 이유를 제공하고, 사실 추가 금지와 출력 완결성은 기존 답냥이 계약·안전 판단에서 나온다. T25의 정확한 합격선은 `SPEC.md` 4장이 정본이다.

### 문헌이 보강한 맥락 검수

- 복합 관계의 지위·친밀도가 다르므로 교수/조교, 선배/동기, 친구/연인 양쪽에서 각각 읽는다.
- 공손성을 종결어미 하나로 판단하지 않고 호칭·직접성·완화·화행 부담을 함께 본다.
- 사과는 관계뿐 아니라 실제 책임·상대 영향·심각도를 구분한다.
- 교수 이메일 연구를 조교 메신저에 직접 일반화하지 않고, 매체가 없으면 짧은 인사–용건–감사의 중립형을 쓴다.
- 이모티콘·`ㅋㅋ/ㅎㅎ/ㅠㅠ`와 높은 격식은 관계·매체에 따라 선택적으로만 쓰며 공손성의 자동 기준으로 삼지 않는다.

### 기존 제품 계약·안전 hard fail

- 입력에 없는 날짜·기한·사유·책임·향후 약속·상대 동의 추가
- 상대 선택권을 제거하는 강압적 요청 또는 거절을 수락처럼 흐리는 핵심 화행 오류
- 사과에서 실제 책임을 입력 없이 확정하거나 보상·재발 방지를 약속
- 톤별로 사실·요구·약속이 달라지는 후보 세트
- 복합 관계 한쪽에만 맞는 호칭·높임·친밀도 단정

### 콘텐츠 품질 불합격

- 관계·매체에 맞지 않는 과잉 격식·자기비하·빈 칭찬
- 친구·팀플 기본안에 친근 표지를 필수처럼 고정
- 세 안이 어미만 바뀌거나 서로 지나치게 유사해 실질적인 비교가 안 됨

### T21 AI 평가

- 시드와 겹치지 않는 holdout에서 관계 적합·완결성·사실 충실성·톤·전송 가능성을 사람 평가자 2명이 독립 채점한다.
- `입력에 없는 사실`, `필수 요청 포함`, `출력 형식`처럼 관찰 가능한 항목만 자동 검사의 주 대상으로 둔다.
- LLM-as-judge는 인간 평가 합의 뒤 보조 분석에만 사용하며, 진정성·공감·상대 의도 추론의 단독 판정자로 쓰지 않는다.
- 합격 모델 중 가장 빠르고 저렴한 모델을 고르는 기존 원칙을 유지하되, 평균 품질만으로 관계 hard fail을 상쇄하지 않는다.

### T22 짧은 사람 대상 과업

긴 행동 인터뷰는 필수가 아니다. 카드는 각 참여자의 평소 ChatGPT·Gemini와 비교하고, 실 AI는 답냥이 직접입력 경로 단독 사용성으로 분리해 가상 과업을 수행하게 한다. 아래 최소 신호만 기록한다.

- `E2E_TTF`, 작성 글자 수, 생성 턴, 최종 수정률
- 사실·관계 hard fail과 블라인드 전송 가능성
- 5점 척도의 `이 문구는 내가 실제로 할 말 같다`
- 다음 같은 상황에서 먼저 고를 도구와 그 이유
- 카드가 받은 원문을 읽지 않는다는 경계와 AI provider 전송 이해

“내 말 같다”는 첫 파일럿에서 탐색 지표로 기록하며 결과를 본 뒤 소급해 합격선을 만들지 않는다. 실제 전송·상대 반응·재사용은 별도 후속 관찰 전까지 미검증으로 남긴다.
