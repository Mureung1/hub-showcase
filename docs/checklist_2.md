# 스펙핏(SpecFit) 작업 분해 체크리스트

>
> `demo_10.html`은 디자인/화면 흐름/갭 분석 로직 검증용 정적 목업이다. 실제 구현 스택(React+Express+SQLite)이 아니지만, 이미 검증된 UX 패턴(포커스 유지, 이어하기 배너, 인사이트 팝업 분기, 탭/정렬, 상세 모달 문장 등)은 그대로 포팅한다.

## 확정 사항 (plan_3.md + CLAUDE.md 반영, 임의 변경 금지)
- 타겟: **재학 중인 대학생** — "지금 지원 가능한 공고 추천"이 아니라 "재학 중 준비 로드맵" 제공이 목적. 카피에 즉시성/조급함 강조 금지.
- 데이터: **워크넷 API 사용 안 함(개인 신청 불가로 최종 기각)**. JOB-ALIO CSV(실제 862건: 회사명/제목/등록일/마감일/상태) + 규칙 기반 합성 스펙 필드(학력/경력/자격증/전공/외국어/컴퓨터활용능력). 합성 데이터임을 문서/발표/UI 어디서든 명시.
- 갭 분석 판정: 학력·경력·자격증·전공·외국어 **5개 항목 AND 조건**. 컴퓨터활용능력은 참고용 우대 항목 — 판정에 절대 포함 금지.
- 보완 우선순위: **항목 1개 보완 시나리오만**. 2개 이상 항목이 동시 미충족인 공고는 카운트에서 제외. 여러 항목 조합 시나리오 금지.
- 매칭 점수화: **단순 개수 기반**, 가중치 부여 금지.
- 필터: **직종 + 고용형태(`is_intern` 여부만)**. 근무지역/급여 필터는 데이터 자체가 없어 완전 제외.
- 4단계 보완 인사이트 팝업: 로딩 직후 자동 노출, 3가지 분기(보완하면 늘어남 / 이미 전부 충족 / 대상 공고 0건).
- 새로고침해도 상태 유지(localStorage). "홈"(상태 보존 + 이어하기 배너)과 "초기화"(완전 리셋)는 다른 동작 — 반드시 체감 가능하게 구현.
- "기타" 직종 26% 비중, 근무지역/급여 필드 없음은 **한계로 그대로 둔다** — 임의 개선 작업 시작 금지.
- 기술 스택 변경 금지: Backend는 Express, DB는 SQLite로 확정.
