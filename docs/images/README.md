# 초기 UI 목업 스크린샷

Beacon 초기 설계 단계에서 만든 핵심 화면 목업의 보존용 이미지다.
자가완결형 HTML 목업 소스는 단일 앱 구조로 정리하면서 삭제했으며, 현재 UI 구현의 단일 원천은
[`docs/design.md`](../design.md)와 [`src/index.css`](../../src/index.css)다.

| 파일 | 화면 |
|------|------|
| `discord-alert.png` | Discord 조건 충족 알림 |
| `ai-review.png` | AI 복기 결과 |
| `journal.png` | 초기 저널·차트 화면 |

이 이미지는 설계 이력 참고용이며 현재 앱과 시각적 차이가 있을 수 있다.
