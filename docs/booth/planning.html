L0 · 제안만

현재 구현 L1 · 승인 후 실행

원탭 승인 시 채널 발송·쿠폰 발급·효과 추적까지 자율 수행.

설계됨 L2 · 완전 자율

사전 설정 범위 안에서 자율 발송. 사장님은 성과 리포트만 확인.

↑ 승격 조건은 쿠폰 사용률·승인율 실측치 — 그리고 승격 버튼을 누르는 사람은 언제나 사장님이다. 어느 레벨에서도 법적 필터는 우회되지 않는다.

차별점비슷한 도구가 잘 안 하는 세 가지

01 — 규제 대응 법을 UI가 아니라
서버가 강제한다

수신동의·(광고) 표기·야간 차단을 발송 API에서 검사한다. 화면을 우회해 API를 직접 불러도 막힌다.

apps/server/src/legal/filter.ts
02 — 측정 설계 채널마다 맡는
역할을 분리했다

단골 문자는 1인 1코드로 전환을 실측하고, 수신자 목록이 없는 공개 채널은 도달을 맡는다. 못 하는 걸 하는 척하지 않는다.

coupons · issueCouponsFor()
03 — 자율성 근거 성과가 쌓여야
권한이 올라간다

쿠폰 실측이 L0→L1→L2 승격의 유일한 근거다. 신뢰를 말로 요구하지 않고 숫자로 번다.

coupons/tracking.ts
