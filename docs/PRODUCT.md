# Product

## 해결하려는 문제

개인 카페를 이용하는 손님은 여러 매장의 스탬프와 쿠폰을 한곳에서 확인하기 어렵습니다. 카페 사장님은 매장 화면에서 손님을 빠르게 확인하고 스탬프를 적립할 수 있어야 합니다.

이 프로젝트는 손님용 모바일 웹과 사장님용 넓은 화면 웹으로 카페별 스탬프 현황과 보상 흐름을 보여주는 MVP를 목표로 합니다. 현재 개발 목표는 일반 공개 서비스가 아니라, 카페 1곳에서 사장님 1명과 손님 1~2명이 실제 배포 URL과 Supabase 데이터로 며칠간 사용해볼 수 있는 파일럿 MVP입니다.

## 주요 사용자

- 손님: 여러 카페의 스탬프, 쿠폰, 알림을 확인하는 사용자
- 사장님: 담당 카페에서 손님을 조회하고 스탬프를 적립하는 사용자

## 핵심 사용자 흐름

기획 문서 기준 핵심 흐름은 다음과 같습니다.

1. 손님과 사장님이 각자의 고정 계정으로 로그인합니다.
2. 손님은 담당 파일럿 카페를 포함한 카페별 스탬프 현황과 보상을 확인합니다.
3. 손님은 자신의 회원번호와 `cafe-stamp:<회원번호>` 형식의 QR을 확인합니다.
4. 사장님은 고객 회원번호를 직접 입력하거나, 매장 QR·바코드 스캐너가 입력창에 넣어준 값을 사용해 고객을 조회합니다.
5. 사장님은 담당 카페에서 스탬프 1개를 적립합니다.
6. 목표 달성 시 쿠폰이 자동 발행되고 알림이 생성됩니다.
7. 손님은 새로고침 후 변경된 스탬프, 쿠폰, 알림을 확인합니다.

현재 코드에서는 이 흐름이 실제 인증이나 데이터 저장 없이 정적 데모 화면으로만 표현되어 있습니다.

## 현재 MVP 범위

기획 문서에서 확인되는 MVP 범위는 다음과 같습니다.

- 손님 역할과 사장님 역할
- 손님용 모바일 중심 화면
- 사장님용 넓은 화면
- 카페별 스탬프 현황
- 카페별 보상 표시
- 쿠폰과 알림 확인
- 회원번호 기반 고객 조회와 스탬프 적립
- 손님용 회원번호 QR 표시
- 사장님용 회원번호 입력창 자동 포커스와 스캐너 입력 후 Enter 조회

## 이번 프로젝트에서 다루지 않을 범위

기획 문서에서 제외된 범위는 다음과 같습니다.

- 브라우저 카메라 기반 QR 스캔
- POS나 스캐너 장비 설정 같은 매장 인프라 연동
- 결제와 POS 연동
- 문자, 메신저, 이메일, 브라우저 푸시 알림
- 위치 기반 탐색과 카페 검색
- 쿠폰 사용, 승인, 만료 처리
- 카페 등록, 운영 통계, 관리자 화면
- 여러 카페를 관리하는 사장님
- 실제 회원가입, 비밀번호 찾기, 소셜 로그인
- 부정 적립 방지와 네이티브 앱

외부 QR·바코드 스캐너는 별도 SDK나 POS 연동 없이 키보드처럼 입력되는 장비를 기준으로 합니다. 앱은 입력창 포커스, 접두어 파싱, Enter 조회만 지원하며 스캐너 장비 구매나 설정은 MVP 범위에 포함하지 않습니다.

## 아직 결정되지 않은 사항

- 실제 Supabase 프로젝트와 환경변수
- 인증 계정과 파일럿 데이터의 최종 값
- 데이터베이스 마이그레이션 구조
- 테스트 도구와 테스트 범위
- 배포 방식과 운영 URL
- 현재 정적 데모 화면을 어떤 순서로 실제 데이터 화면으로 전환할지
