🤖 Claude 프롬프트

→ 정확도 ↑

📋 JSON 검증

API 응답이 항상 올바른 형식 아님

→ 검증 로직 추가

📅 날짜 형식

→ 정규화 함수 작성

→ 명확한 기준 수립
