CalMe

AI 기반 대학생 일정 관리 서비스

4주 개발 여정 & 최종 성과

https://calme-frontend.vercel.app

문제 & 솔루션

❌ 문제점

여러 공지사항, 공모전, 팀플 등 다양한 채널에서 공지를 확인하면서 중요한 마감일을 놓침

✅ 솔루션

공지 업로드 → AI 자동 분석 → 일정 추출 → 캘린더 등록

서비스 흐름

📄 공지 입력 (텍스트/PDF)
↓
🤖 Claude AI 분석
(마감일, 제출물, 장소 자동 추출)
↓
✏️ 사용자가 결과 수정
↓
💾 일정 저장 & 중복 감지
↓
📅 캘린더에 자동 등록

기술 스택

Frontend

React + Vite → Vercel 배포

Backend

Node.js + Express → Render 배포

Database

PostgreSQL (Supabase)

AI

Claude API (claude-opus-4-8)

핵심 기능 & 문제해결

  • AI 분석: Claude API로 마감일·제출물·장소 자동 추출
  • 사용자 수정: AI 결과를 직접 수정 가능
  • 중복 감지: 같은 일정 등록 방지
  • PDF 처리: 실제 텍스트 추출 (pdf-parse 라이브러리)
  • 배포: SQLite → PostgreSQL 마이그레이션 (데이터 영속성)

4주 개발 과정

Week 1
기획 & 설계 (사용자 시나리오, 아키텍처, UI)
Week 2
기반 구축 (로그인, PDF 입력, Mock 분석)
Week 3
Claude API 통합 & 저장 기능 (수정 UI, 중복 감지)
Week 4
배포 & 마이그레이션 (PostgreSQL, 프로덕션 배포)

기술 성취

Full-Stack 배포 (Vercel-Render-Supabase)
Claude AI 프로덕션 환경에서 실제 사용
PDF 파일에서 실제 텍스트 추출 구현
데이터 영속성 보장 (PostgreSQL 마이그레이션)
안정적인 API 통신 (JWT 인증)
