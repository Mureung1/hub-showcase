CalMe

공지에서 일정을 자동으로 추출해주는
AI 기반 대학생 일정 관리 서비스

4주간의 개발 여정과 기술 성과

https://calme-frontend.vercel.app

문제 & 솔루션

❌ 문제

여러 공지(학교, 공모전, 팀플)에서 마감일을 놓침

✅ 솔루션

공지 업로드 → AI 분석 → 일정 추출 → 저장

서비스 흐름 상세

1️⃣ 로그인 (JWT) → 2️⃣ 공지 입력 (텍스트/PDF)
3️⃣ Claude AI 분석 (마감일, 제출물, 장소)
4️⃣ 사용자 수정 (각 필드 직접 수정)
5️⃣ 중복 감지 (user + name + date)
6️⃣ 저장 (DB) → 7️⃣ 캘린더 확인

+ Claude API (AI 분석)

Claude API 활용

프롬프트 엔지니어링

시스템: "대학교 공지 분석 전문가,
일정명/마감일/제출물 추출, JSON 반환"

JSON Schema (응답 형식)

{ "events": [{ "name": "일정명", "deadline": "YYYY-MM-DD", "deliverables": ["제출물"], "location": "장소" }] }

효과: 정확한 형식으로 일정 추출

핵심 기능 (1)

1️⃣ AI 공지 분석

  • Claude API (claude-opus-4-8) 실제 사용
  • 프롬프트 최적화로 정확도 향상

2️⃣ PDF 텍스트 추출

  • pdf-parse 라이브러리로 실제 추출
  • Multer 파일 처리 (10MB 제한)
  • 스캔 PDF 감지 (OCR 필요 시 경고)

3️⃣ 사용자 수정 & 저장

  • 각 필드 직접 수정 가능
  • DB에 저장 (events 테이블)

핵심 기능 (2)

4️⃣ 중복 감지 로직

같은 사용자 + 일정명 + 날짜
→ 중복 경고 팝업
→ 강제 등록 선택 가능

5️⃣ 데이터 검증

  • JSON Schema 검증 (형식 확인)
  • 재시도 로직 (API 타임아웃 시)
  • 날짜 정규화 (다양한 형식 → YYYY-MM-DD)

4주 개발 과정

Week 1
기획·설계: 시나리오, 아키텍처, UI
Week 2
기반 구축: JWT 인증, PDF 입력, Mock 분석
Week 3
핵심 Claude API 통합, 수정 UI, 저장, 중복 감지
Week 4
배포 SQLite→PostgreSQL, 프로덕션 배포

배포 & 마이그레이션

SQLite → PostgreSQL 이유

  • 데이터 영속성: SQLite는 파일 기반 (손실 위험)
  • 확장성: PostgreSQL은 동시성 처리 우수
  • 백업: Supabase 자동 백업 & 복구

배포 플랫폼

Frontend

Vercel (정적 파일)

Backend

Render (Node.js)

Database

Supabase (PostgreSQL)

연결

Vercel Rewrite
