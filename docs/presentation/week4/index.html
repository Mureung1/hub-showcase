CalMe
AI 기반 대학생 일정 관리 서비스

공지사항과 안내문에서 일정을 자동으로 추출하고 캘린더에 등록해주는 서비스

🎯 문제 정의 & 솔루션

❌ 문제점

대학생들은 학교 공지, 공모전, 팀플 등 여러 곳에서 오는 공지를 일일이 확인해야 하며, 이 과정에서 중요한 마감일을 놓치는 불편함을 겪습니다.

✅ 솔루션

공지를 업로드하면 AI가 자동으로 분석하여 일정을 추출하고, 사용자가 수정 후 캘린더에 등록할 수 있습니다.

⭐ 핵심 기능

🤖

AI 자동 분석

Claude AI가 공지 내용을 분석하여 일정명, 마감일, 제출물 등 정보를 자동 추출

✏️

수정 & 확인

AI 분석 결과를 사용자가 직접 검토하고 수정할 수 있는 편집 인터페이스

📅

자동 등록

수정된 일정을 캘린더에 자동으로 등록하고 대시보드에서 한눈에 확인

🛠 기술 스택

React
Express.js
SQLite
Claude API

주요 기술

  • JWT 인증 & bcrypt 암호화
  • PDF 텍스트 추출 (pdf-parse)
  • Claude API (claude-opus-4-8) 프롬프트 엔지니어링
  • JSON Schema 검증
  • 중복 감지 로직

📈 개발 진행 현황

1주차

기획 & 설계

사용자 시나리오, 기술 아키텍처, UI 프로토타입 완성

2주차

기반 구축

로그인/회원가입, 텍스트/PDF 입력 기능, Mock 분석 결과 표시 완료

3주차

AI 통합 & 저장 기능

Claude API 실제 연결, 결과 수정 UI, 일정 저장, 중복 감지 시스템 완성

4주차

완성 & 배포

캘린더 구현, 대시보드 개선, 통합 테스트, 배포 준비

✨ 주요 특징

🎯 실제 AI 분석: Mock 데이터가 아닌 Claude API를 통한 실제 공지 분석

🔍 중복 감지: 같은 사용자의 중복 일정 등록을 방지하는 안전장치

📊 사용자 격리: JWT 인증을 통한 안전한 사용자 데이터 관리

📸 주요 화면

분석 결과 수정 UI
저장된 일정 대시보드
중복 감지 경고

🚀 프로젝트 완성도

CalMe는 4주간의 집중 개발을 통해 다음을 달성했습니다:

  • ✅ AI 기반 자동 분석 기능 (Mock → 실제 Claude API 전환)
  • ✅ 사용자 중심의 수정 & 저장 기능
  • ✅ 견고한 데이터 검증 및 중복 감지 시스템
  • ✅ 안전한 인증 & 암호화
  • ✅ 완전한 서비스 흐름 (입력 → 분석 → 수정 → 저장 → 확인)
