# 바로진료 3주차 주간 계획

기간: 2026년 7월 20일 월요일 ~ 7월 24일 금요일

## 이번 주 목표

1. 신규 병원 관리자 인증 흐름을 복구하고 입점 진행 화면까지 연결합니다.
2. 미도착 자동 만료 작업을 Express와 PostgreSQL로 완성합니다.
3. 원격 환자와 병원 관리자의 핵심 수직 슬라이스를 실제 화면·서버·DB로 검증합니다.
4. 목요일까지 개발을 마치고 금요일에는 문서, 이슈와 발표 자료를 정리합니다.

## 현재 진도 점검

| 구분 | 판정 | 근거 |
|---|---|---|
| 환자 원격 웨이팅 수직 슬라이스 | 완성 | React 요청이 Express와 Supabase DB를 거쳐 화면에 반영됨 |
| seed 병원 관리자 대기열 관리 | 완성 | 승인된 테스트 관리자 계정으로 통합 대기열 API와 화면이 연결됨 |
| 신규 병원 관리자 가입 흐름 | 보완 필요 | 인증 Redirect와 병원 소속이 없는 계정의 화면 전환이 필요함 |
| 자동 미도착 처리 | 보완 필요 | 판정 로직은 있으나 1분 실행기와 advisory lock이 필요함 |

이번 주에는 기능 범위를 넓히기보다 신규 병원 관리자 흐름과 자동 만료를 먼저 완성합니다.

## 이번 주 제외

- 직원 상세 영역의 알림 발송 이력 UI
- 네트워크 실패와 재시도 UI
- 병원 검색·필터와 `내 주변` 영역
- 병원 상세 신청과 플랫폼 관리자 최종 승인
- 병원 운영 설정 화면

제외 항목은 P1 백로그에 유지하고 이번 주 P0 수직 슬라이스 검증이 끝난 뒤 진행합니다.

## 목요일 개발 완료 기준

- 신규 병원 관리자 인증 링크가 관리자 웹으로 돌아옵니다.
- 승인된 병원 소속이 없는 관리자는 대기열 대신 입점 진행 화면을 봅니다.
- 원격 환자 등록부터 직원 도착·호출까지 실제 데이터로 확인할 수 있습니다.
- 미도착 환자의 마지막 이동과 20분 만료 자동 취소가 중복 없이 실행됩니다.
- 전체 품질 검사 명령이 통과합니다.

## 금요일 정리 완료 기준

- 체크리스트, Task, GitHub Issues와 Project 상태가 실제 구현과 일치합니다.
- 완료·미완료 범위와 다음 작업이 문서에 남습니다.
- 발표 자료와 데모 순서가 이번 주 구현 상태를 반영합니다.
