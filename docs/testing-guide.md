# 테스트 가이드

## 1. 테스트 전략

사용자 동작과 실패 경로를 기준으로 변경 위험도에 맞는 테스트를 작성한다. 모든 코드에 동일한 깊이의
테스트를 강제하지 않고, 위험도가 높은 로직(금융 데이터 계산, 실시간 데이터 처리, AI 응답 파싱 등)에
우선 투자한다. (출처: `AGENTS.md`/`README.md`의 작업 방식)

## 2. 사용 도구

Vitest, Testing Library (`frontend/package.json` 기준). 테스트는 jsdom 환경에서 실행된다
(`frontend/vite.config.ts`).

```bash
pnpm test        # 1회 실행
pnpm test:watch  # 감시 모드
```
