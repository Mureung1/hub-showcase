The Challenge

AI 협업에서 발생하는 컨텍스트 단절

다중 에이전트 환경 및 작업 인수인계 시 발생하는 정보 왜곡 현상

Drift

1. 컨텍스트 유실 (Context Drift)

여러 에이전트가 교대하며 작업할 때, 이전 에이전트가 어떤 의사결정을 내렸고 어떤 코드를 의존했는지 히스토리가 소실되어 작업의 일관성이 깨집니다.

Silo

2. 정보 고립화 (Context Silo)

각각의 에이전트가 수집한 코드베이스 분석 리포트가 공유되지 않아 동일한 리소스 분석 연산을 중복 수행하며 자원을 낭비합니다.

Architecture

Modu Brain 컨텍스트 동기화 모델

실시간 수집 파이프라인과 공유 생각 그래프(Thought Graph)의 결합

1. Context Parser

로컬 워크스페이스의 코드 변경 사항과 Git 커밋, 이슈를 지속적으로 추적하여 핵심 컨텍스트 객체를 생성합니다.

2. Agent Telemetry

백그라운드로 동작하는 에이전트들의 모든 실행 결과와 프롬프트 토큰 사용량, 탐색 트리 경로를 통합 로깅합니다.

3. Decision Tracker

핵심 아키텍처 결정 의도(ADR)를 구조화된 마크다운 문서로 작성하여 로컬 데이터베이스와 실시간 매핑합니다.

Key Capabilities

주요 화면 및 핵심 기능 데모

사용자와 에이전트가 함께 확인하는 통합 브레인 대시보드

분석 소스 자동 파싱

외부 사이트 링크나 로컬 소스코드를 등록하면 실시간 파이프라인이 즉각 가동되어 컨텍스트를 동기화합니다.

의사결정 보관소 (ADR)

어떤 코드 블록이 왜 변경되었고 어떤 종속성을 예방했는지 실시간 타임라인으로 기록하여 공유합니다.

품질 게이트 통합

ESLint, TypeScript Typecheck, Vitest, Supabase 로컬 마이그레이션 적합성 검증까지 원버튼으로 일괄 검증합니다.

Masterclass Milestone

D02 (07-15) 마스터클래스 실습 성과

React 컴포넌트 리팩토링, 자가 진단 퀴즈 및 데이터 모델 설계

Refactoring

Props & Callback 책임 분리

대형 페이지 컴포넌트를 LessonCard, NoteItem, SchemaTable 등 재사용 가능한 구조로 분리하고, 단방향 데이터 흐름을 명확하게 제어했습니다.

Schema Design

Supabase ERD 및 뷰어 탑재

실습 메모와 퀴즈 이력을 영구 보존할 lessons, user_notes, quiz_responses 테이블 구조와 RLS 정책을 명세화하고, UI에서 볼 수 있는 뷰어를 탑재했습니다.

Future Roadmap

Modu Brain 개발 로드맵

보안 인증 강화 및 다중 협업 환경으로의 단계적 확장
