INTRODUCING MODU BRAIN

회의 기록 맥락 정렬 및 의사결정 추적 도구

카카오톡, Teams, Notion에 흩어진 기록에서 '사람별 관점 차이', '열린 질문', '결정 근거'를 찾아 팀의 일치된 행동을 이끌어냅니다.

발표자

N031 김서준

The Challenge

팀 회의 시 맥락이 불일치하는 이유

흩어진 대화록과 명확하지 않은 목표로 인해 회의 후 '뭘 해야 할지 모르는' 혼선

Leak

1. 흩어진 대화 속 맥락 누수

카톡방 의견 충돌, 노션의 긴 줄글 회의록, 개인 메모에 산재된 기록들 속에서 서로의 진짜 의도와 최종 근거를 모으기 어렵습니다.

Confusion

2. 회의 종료 후 액션 플랜의 부재

치열하게 논의했음에도 최종 결정사항과 미결된 질문들이 한 곳에 정리되지 않아, 다음 미팅 때 똑같은 질문과 공백을 다시 마주합니다.

How it Works

회의록 한 장으로 팀 맥락 정렬하기

Modu Brain이 흩어진 회의 텍스트에서 명확한 결론과 행동 지침을 구조화하는 흐름

1. 기록 축적 및 통합

카카오톡 텍스트 추출물, 팀즈 회의록, 단순 복사한 텍스트 등을 계정 연동이나 복잡한 셋업 없이 안전하게 붙여넣어 정리합니다.

2. 맥락 분석 & 구조화

팀원별 서로 다른 의견의 충돌 지점(관점), 추가 논의가 필요한 의문(열린 질문), 합의에 이른 근거(결정 배경)를 명확히 분류합니다.

3. 다음 단계 가시화

회의 이후 '오늘 손코딩/수행할 메모'와 같이 무엇을 해야 할지 즉각적인 행동 지침(Action Item)으로 시각화합니다.

Key Capabilities

모두의 브레인 주요 기능

팀원들 간의 시각차를 좁히고 명확한 진행 상황을 추적하는 기능셋

사람별 관점 비교 (Perspectives)

회의 참여자 간에 의견이 갈리는 쟁점(예: 근거 공개 여부 vs 시연 속도 우선)을 대조 표 형식으로 비교 제공합니다.

열린 질문 (Open Questions)

합의되지 않고 미결된 의문 사항을 목록화하여 다음 회의 시 집중 논의하고 결론을 도출하도록 강제합니다.

결정 근거 (Decision Log)

최종 의사결정이 내려진 배경(ADR)을 기록하고, 연동 데이터베이스 설계를 바로 확인하여 혼선을 방지합니다.

Demo Flow

화면 · 서버 · DB 연결 흐름 한 바퀴

사용자 입력부터 데이터 저장까지 전체 파이프라인 시연 요약

🖥️ 화면 (Frontend)

React 19 화면이 회의록 입력과 결과 탭, 지식맵 상호작용을 상태로 관리하고 분석 API를 호출합니다.

React + TypeScript + Vite

⚙️ 서버 (API)

Node.js API가 입력을 검증하고, 로컬 또는 선택형 OpenAI 분석 결과의 근거 인용문을 다시 확인합니다.

source snapshot → analysis → evidence validation

🗄️ DB (Supabase)

Supabase PostgreSQL에 프로젝트·원문·분석 실행·공유 링크를 저장하고 RLS로 사용자별 접근을 분리합니다.

Row Level Security: auth.uid() = owner_id

Development Status

현재 구현한 핵심 기능과 검증

기획부터 공개 데모, 근거 검증, 배포 확인까지 연결한 현재 상태

근거 기반 분석

결정·관점·질문을 원문과 연결

회의록을 분석해 결정 이유, 참여자 관점, 미결 질문을 구조화하고 결과별 실제 원문 인용문을 다시 확인하도록 만들었습니다.

배포·품질 확인

공개 데모와 서비스 상태 점검

Render 정식 서비스와 Vercel 공개 데모를 분리하고, health endpoint·Playwright·접근성 검사로 주요 흐름을 확인했습니다.

Current Service

공개 데모와 다음 개선 방향

지금 바로 확인할 수 있는 서비스 흐름과 후속 고도화 영역

공개 데모

로그인 없이 핵심 흐름 확인: 회의록 입력, 구조화 분석, 지식맵, 근거 각주를 공개 데모에서 바로 체험할 수 있습니다.

안전한 저장

로그인 사용자의 프로젝트 보관: Supabase Auth와 RLS를 바탕으로 프로젝트·원문·분석 이력을 사용자별로 저장합니다.

후속 개선

연결과 협업의 확장: 외부 기록 가져오기, 팀 공동 편집, 실제 LLM 품질 평가를 단계적으로 고도화합니다.
