문제

초보자는 번역기를 써도 낯선 금융 영어 문장 구조를 이해하기 어렵고, 하루에 쏟아지는 외신 중 무엇이 주가에 실질적 영향을 주는지 선별할 기준이 없어 쉽게 지치고 포기한다.

타겟

해외주식 · 영문뉴스 모두 처음인 완전 초보자

스코프

증권사 매매 연동은 스코프 밖 — 모의 투자 판단 훈련 도구

"번역기 없이 원문을 완독하고, 스스로 판단한 뒤 AI 해석과 비교하며 배우는 모의투자 학습 도구"

Agents & Skills

전담 Agent 2개 + Skill 2개

AGENT2026-07-13

feature-slice

  • 요구사항 → 하루 단위 Task + 최우선/P0/P1 우선순위
  • plan.md / api-spec.md 선확인, 스코프 크리프 경계
  • 읽기 전용 — 계획만 세우고 코드는 건드리지 않음
AGENT2026-07-17

feature-verify

  • "구현했다" ≠ "검증됐다" — checklist 체크박스는 불신
  • 코드 + 실행 중인 서버로 PASS/FAIL 판정
  • 근거는 항상 파일경로:줄번호로 남김
SKILL2026-07-09

design

  • 색상/타이포/컴포넌트/인터랙션 규칙 단일 소스
  • 과거 회귀(JS 금지, :focus/:checked/<details>만)를 규칙화
SKILL2026-07-23

testing

  • Vitest describe/it 구조 (정상/빈값/경계값/실패케이스)
  • it.each, vi.spyOn + afterEach 컨벤션
