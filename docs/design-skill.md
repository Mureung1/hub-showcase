# Pick My Clothes Design Skill

## 프로젝트 컨셉

"나의 코디 다이어리"

사용자가 매일의 코디를 일기처럼 기록하고 AI와 함께 코디를 추천받는 감성적인 웹 서비스를 목표로 한다.

# UI 스타일

- 노트 배경 사용
- 스프링 노트 장식 유지
- 둥근 카드(Radius 24px 이상)
- 둥근 버튼 사용
- 파스텔 핑크 중심 디자인
- Soft Shadow 적용
- 귀여운 일러스트 활용
- 여백을 충분히 사용하여 답답하지 않게 구성

---

# 컴포넌트 규칙

Button

- Radius 999px
- Hover Animation
- 그림자 적용

Card

- Rounded
- Soft Shadow
- Padding 20~32px

Input

- Radius 적용
- 연한 회색 Border
- Hover 시 핑크 Border

---

# 아이콘 스타일

- 단순한 라인 아이콘 사용
- 너무 화려한 아이콘 사용 금지

---

# 이미지 스타일

- 실제 의류 이미지
- 스티커 느낌
- 다이어리에 붙인 사진 같은 분위기

---

# 애니메이션

- 버튼 Hover
- 카드 Hover
- Fade In
- Scale 효과

과한 애니메이션은 사용하지 않는다.

# 디자인 체크리스트

□ 핑크 감성이 유지되는가?

□ 노트 컨셉이 유지되는가?

□ 모든 버튼 디자인이 통일되어 있는가?

□ 둥근 스타일이 유지되는가?

□ 사용자가 직관적으로 사용할 수 있는가?

□ 화면 간 디자인 일관성이 있는가?

# 디자인 피드백 규칙

디자인을 수정할 때마다 아래 내용을 확인한다.

1. 기존 디자인 시스템과 통일되는가?

2. 사용성이 좋아졌는가?

3. 너무 복잡하지 않은가?

4. 감성적인 분위기가 유지되는가?

5. "나의 코디 다이어리" 컨셉과 맞는가?
