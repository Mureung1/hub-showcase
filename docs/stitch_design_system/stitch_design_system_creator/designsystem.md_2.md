# 오늘모여 — 디자인 시스템

와이어프레임(`오늘모여 홈 와이어프레임.dc.html`)에서 실제로 사용된 스타일 규칙을 정리한 문서. 새 화면이나 컴포넌트를 만들 때 아래 토큰과 패턴을 그대로 재사용할 것.

## 1. 컨셉

손그림 느낌의 "잉크 스케치" 스타일. 크림색 배경 + 진한 잉크색 굵은 선 + 오프셋 하드 섀도우(블러 없음)로 종이에 펜으로 그린 듯한 톤을 낸다. 포인트 컬러는 캠프파이어를 연상하는 오렌지.

## 2. 타이포그래피

- 폰트: **Jua** (Google Fonts) — 둥글둥글한 한글 손글씨체. `font-family:'Jua',sans-serif` 하나만 사용, 별도 세리프/산세리프 페어링 없음.
- 굵기 대비는 폰트 굵기 대신 **font-size + font-weight:700(제목) / 400(본문)** 조합으로 준다.
- 크기 스케일: 제목 19–20px · 서브헤딩 12–13px(회색) · 본문/버튼 라벨 13–16px · 캡션 11–12px.
- 줄간격은 본문 설명문에서 `line-height:1.5~1.6`.

## 3. 스페이싱 · 라운드 · 섀도우

- **테두리**: 항상 굵은 두께(2px 또는 2.5px). 얇은 1px 테두리는 쓰지 않는다 (스케치 굵은 선 느낌 유지).
- **라운드**: 버튼은 프로퍼티로 pill(`999px`) 또는 rect(`10px`) 중 선택. 카드/모달은 `10–16px`, 아이콘 버튼은 `10px`.
- **섀도우(시그니처)**: 블러 없는 오프셋 섀도우(색은 테두리와 동일 계열, 불투명도 높게). 카드는 `6px 6px 0`, 모달/팝업은 `8px 8px 0`, 소형 카드는 `3–4px 3–4px 0`. 절대 `box-shadow`에 blur 값을 넣지 않는다.
- **간격**: 폼 필드 사이 `gap:12–14px`, 버튼 그룹 `gap:10–14px`, 칩/태그 `gap:8px`.

## 4. 레이아웃

- 기준 캔버스: **PC 16:9, 1440×810px**. 전체 화면 하나에 앱이 담기고, 나머지 기능은 그 위에 뜨는 모달/팝업으로 처리한다 (별도 페이지 전환 없음).
- 구조: 중앙 정렬된 메인 화면(로고/일러스트 + 주요 액션 버튼 3개) + 우상단 고정 아이콘(마이페이지, 메모장) + 액션 클릭 시 화면 중앙에 뜨는 모달 창.

## 5. 컴포넌트 패턴

### 버튼 (Neutral / Active)
- Neutral: 배경색, 굵은 테두리, 기본 텍스트색
- Active(선택됨): 포인트 컬러로 배경/테두리 채우고 흰 텍스트
- 패딩 `14px 26px`, 라운드는 위 pill/rect 규칙 따름.
- 버튼 라벨은 줄바꿈 금지(`white-space:nowrap`).

### 아이콘 버튼 (우상단 유틸리티)
- `42×42px`, `border-radius:10px`, 굵은 테두리, 배경은 메인 배경색과 동일.
- 내부 아이콘은 SVG 대신 `<span>` 굵은 선으로 직접 구성 (햄버거 3줄, 메모 사각형+줄 등) — 이모지 사용하지 않음.
- 알림 뱃지: 우상단에 `12px` 원, 포인트 컬러 배경 + 배경색과 동일한 테두리.
- 클릭 시 바로 아래에 팝오버(마이페이지 메뉴) 또는 중앙 모달(메모장)이 뜬다.

### 모달 / 창 (Window)
가장 많이 재사용되는 패턴. 모임 생성, 모임 목록, 내 모임, 메모장, 상세정보 모두 동일 구조:
- 오버레이: `position:absolute; inset:0`, 반투명 딤 처리.
- 창 본체: 배경색 + 굵은 테두리 + 라운드 `14–16px` + 오프셋 하드 섀도우.
- 헤더: 좌측 제목(`font-weight:700; font-size:19px`) + 우측 `28×28px` 닫기 버튼(`✕`, 테두리 있는 정사각형).
- 폭은 내용에 따라 340–780px. 목록형(모임 목록)은 좌측에 카테고리 사이드바(170px)를 붙인 2-컬럼 구조.

### 드롭다운 선택 피커 (시작 시각 / 진행시간 / 인원)
텍스트 직접 입력 대신 **클릭 → 목록에서 선택** 방식만 사용:
- 트리거: `padding:10px 14px`, 굵은 테두리, `border-radius:8px` + 현재 값 + `▾`
- 목록: 트리거 바로 아래 `position:absolute`, 동일 스타일의 카드, 오프셋 섀도우, `max-height` + 스크롤.
- 한 번에 하나의 피커만 열림(다른 피커 열면 이전 것 닫힘).
- 시간대는 시/분을 **분리된 두 피커**로 제공, 분 단위는 10분 단위(00/10/…/50).

### 태그 / 카테고리 칩
- 선택 안 됨: 굵은 테두리 + 투명 배경 + 기본 텍스트색
- 선택됨: 진한 배경 + 배경색 텍스트로 반전 (카테고리 필터와 통일된 반전 방식)
- `border-radius:999px`, `padding:7px 16px`, 가로로 `flex-wrap`.

### 리스트 행 (모임 목록 / 신청한 모임 / 메모 목록)
- 각 행: 굵은 테두리 + `border-radius:10px; padding:12–14px`, hover 없음(대신 클릭 시 상세/선택 상태로 전환).
- 선택 가능한 행(내 모임)은 선택 시 테두리를 포인트 컬러로 바꾸고 옅은 포인트 컬러 배경을 깐다.
- 메모 목록은 **날짜(고정폭 좌측 컬럼) + 제목** 2열 구성, 구분선은 `1.5px dashed`.
- 리스트 안에서 항목 클릭 → 같은 창 안에 상세 오버레이(설명/정보)가 뜨는 패턴(모임 목록 상세, 내 모임 정보창).

### 상태 표시 (타이머 · 입장 가능)
- 대기 중: 옅은 보조색 텍스트, `font-family:ui-monospace,monospace`로 카운트다운 표기.
- 입장 가능: 포인트 컬러 + `font-weight:700` + "지금 입장 가능" 텍스트.
- 선택된 항목에서만 하단에 신청취소/입장하기 버튼이 **활성화**(비활성 시 `opacity` 낮추고 `pointer-events:none`, 점선 테두리).

## 6. 인터랙션 규칙

- 라디오형 3버튼(모임 생성/목록/내 모임)은 **상호 배타적** 토글: 하나를 열면 나머지 버튼은 사라지고 해당 창만 보인다. 같은 버튼 다시 클릭 시 원래 화면으로 복귀.
- 모달 안에서 리스트 항목 클릭 시 이벤트 전파를 막아(`stopPropagation`) "신청" 등 행 내부 버튼과 충돌하지 않게 한다.
- 메모장: 목록 / 작성 / 상세 3개 뷰가 서로 배타적으로 전환(작성 열면 목록 숨김, 상세는 "← 목록으로"로 복귀).
- 모든 폼 입력은 자유 텍스트가 필요한 제목/설명 정도만 `<input>`/`<textarea>`, 나머지(시간, 인원, 태그)는 전부 선택형 UI.

## 7. 조정 가능 항목(Tweaks)

- **accentColor**: 포인트 컬러 (여러 컬러 옵션 중 선택)
- **buttonShape**: 버튼 라운드 pill / rect
- **defaultPanel**: 최초 진입 시 열려 있는 창
- **showMemoBadge**: 메모 아이콘 알림 뱃지 표시 여부
