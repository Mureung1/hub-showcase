# 개인 카페 스탬프 통합 서비스 기획

## 1. 서비스 개요

개인 카페 스탬프 통합 서비스는 손님이 여러 개인 카페의 스탬프를 하나의 웹 서비스에서 관리할 수 있도록 돕는 무료 MVP 서비스이다.

손님은 웹 브라우저에서 테스트 로그인으로 서비스를 시작하고, 결제 시 본인 웹 화면의 적립용 QR 코드를 카페 직원에게 제시한다. 카페 직원은 매장용 웹 화면에서 해당 QR 코드를 스캔해 손님의 카페별 스탬프를 즉시 적립한다. 카페별 스탬프 조건을 채우면 웹 서비스 안에서 쿠폰이 자동으로 발급된다.

초기 버전은 결제나 POS 연동 없이, 웹 브라우저만으로 손님 QR 제시와 매장 QR 스캔 기반 디지털 스탬프 경험을 빠르게 검증하는 데 집중한다.

## 2. 문제 정의

개인 카페의 스탬프 제도는 단골을 만들기 좋은 방식이지만, 종이 쿠폰 중심으로 운영될 때 다음과 같은 불편이 생긴다.

- 손님이 종이 쿠폰을 잃어버리거나 집에 두고 와서 적립 기회를 놓친다.
- 여러 카페의 쿠폰을 지갑이나 가방에 따로 보관해야 해서 관리가 번거롭다.
- 카페마다 스탬프 조건과 혜택이 달라 현재 얼마나 모았는지 한눈에 알기 어렵다.
- 사장님이나 직원은 종이 쿠폰을 계속 제작하고 관리해야 한다.
- 네이티브 앱 설치가 필요한 서비스는 과제 조건과 초기 접근성 측면에서 부담이 될 수 있다.

이 서비스는 종이 쿠폰 분실과 미소지 문제를 가장 중요한 문제로 보고, 개인 카페의 스탬프를 웹 기반 QR 제시/스캔 경험으로 바꾸는 것을 목표로 한다.

## 3. 주요 사용자

### 카페 손님

- 여러 개인 카페를 방문하며 스탬프를 모으는 사용자
- 종이 쿠폰을 자주 잃어버리거나 챙기기 번거로운 사용자
- 웹에서 카페별 적립 현황과 발급된 쿠폰을 한눈에 보고 싶은 사용자

### 카페 사장님/직원

- 종이 쿠폰 대신 간단한 웹 기반 디지털 스탬프를 운영하고 싶은 개인 카페 운영자
- 손님이 제시한 QR을 웹 화면에서 스캔해 적립을 처리하는 사용자
- 복잡한 POS 연동 없이 가볍게 재방문 유도 기능을 도입하고 싶은 사용자

## 4. 사용자 시나리오

### 손님 시나리오

1. 손님은 모바일 브라우저에서 웹 서비스에 접속한다.
2. 손님은 테스트 로그인으로 손님 모드에 진입한다.
3. 손님은 결제 시 웹 화면 상단의 QR 버튼을 눌러 본인 적립용 QR을 크게 표시한다.
4. 카페 직원은 매장용 웹 화면에서 손님의 QR 코드를 스캔한다.
5. 웹 서비스는 스캔된 손님 계정에 해당 카페의 스탬프를 즉시 적립한다.
6. 해당 카페가 손님의 목록에 없다면 첫 적립과 함께 자동으로 추가된다.
7. 손님은 웹에서 카페별 스탬프 개수와 보상 조건을 확인한다.
8. 스탬프가 카페의 보상 조건을 충족하면 쿠폰이 자동으로 발급된다.
9. 손님은 발급된 쿠폰 목록을 웹에서 확인하고, MVP에서는 간단한 사용 완료 버튼으로 상태를 바꾼다.

### 사장님/직원 시나리오

1. 직원은 웹 서비스에 접속해 직원 모드로 테스트 로그인한다.
2. 직원은 테스트 카페를 선택하거나 고정된 테스트 카페로 진입한다.
3. 직원은 매장용 QR 스캔 화면을 연다.
4. 손님이 결제 시 본인 웹 화면의 QR 코드를 제시하면 직원이 해당 QR을 스캔한다.
5. 스캔이 완료되면 손님의 해당 카페 스탬프가 즉시 적립된다.
6. 적립 결과 화면에서 성공/실패 상태를 확인한다.

## 5. 핵심 기능

- 테스트 로그인: 손님 모드와 직원 모드를 빠르게 전환해 MVP 흐름을 검증한다.
- 손님 QR 제시: 손님은 웹 화면의 본인 적립용 QR 코드를 결제 시 매장에 제시한다.
- 매장 웹 QR 스캔: 카페 직원은 브라우저 카메라를 사용해 손님의 QR 코드를 스캔한다.
- 카페 자동 추가: 손님이 처음 방문한 카페도 첫 적립과 함께 내 스탬프 목록에 추가된다.
- 카페별 스탬프 카드: 손님은 카페마다 다른 스탬프 현황을 확인한다.
- 카페별 자유 보상 규칙: 카페마다 필요한 스탬프 개수와 보상 내용을 설정할 수 있다.
- 자동 쿠폰 발급: 손님이 보상 조건을 채우면 쿠폰이 자동으로 생성된다.
- 쿠폰 사용 처리: MVP에서는 쿠폰 사용을 단순 버튼으로 처리한다.

## 6. 부가 기능

- 적립 내역: 손님이 언제 어느 카페에서 스탬프를 적립했는지 확인한다.
- 쿠폰 목록: 손님이 발급된 쿠폰을 카페별로 확인한다.
- 테스트 카페 데이터: 개발용 카페와 보상 규칙을 미리 준비해 흐름을 빠르게 확인한다.
- 반응형 화면: 손님은 모바일 화면, 직원은 모바일 또는 데스크톱 화면에서 사용할 수 있게 한다.
- 기본 상태 화면: 빈 스탬프 목록, 빈 쿠폰 목록, 적립 성공, 적립 실패 상태를 제공한다.

## 7. 이번 프로젝트에서 구현하지 않을 기능

- 결제/POS 연동: 실제 결제 데이터나 포스기와 연결해 자동 적립하는 기능은 구현하지 않는다.
- 지도 기반 탐색: 주변 카페를 지도에서 찾거나 추천하는 기능은 구현하지 않는다.
- 카페 검색: 카페명이나 지역으로 카페를 검색해 추가하는 기능은 구현하지 않는다.
- 쿠폰 실제 사용 승인: 직원이 쿠폰 사용을 승인하는 운영 흐름은 구현하지 않는다.
- 부정 적립 방지: QR 공유, 반복 제시, 위치 검증, 이상 패턴 탐지 등은 이번 버전에서 구현하지 않는다.
- 네이티브 모바일 앱: Android/iOS 앱 설치형 구현은 하지 않는다.
- 카카오 로그인 필수 구현: 카카오 로그인은 나중에 넣을 수도 있고 제외할 수도 있는 선택 기능으로 둔다.
- 유료 구독과 광고: 초기 MVP는 무료 사용을 전제로 하며, 수익화 기능은 구현하지 않는다.

## MVP 방향

이번 프로젝트의 목표는 완성형 운영 시스템을 만드는 것이 아니라, 개인 카페 스탬프를 웹으로 통합 관리하는 핵심 경험이 실제 사용자에게 가치 있는지 검증하는 것이다.

따라서 초기 구현은 다음 흐름을 가장 중요하게 다룬다.

1. 테스트 로그인
2. 손님 QR 표시
3. 직원용 웹 QR 스캔
4. 스탬프 즉시 적립
5. 손님의 카페별 스탬프 카드 확인
6. 조건 충족 시 쿠폰 자동 발급
7. 쿠폰 사용 완료 상태 처리
