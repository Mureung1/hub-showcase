# 프로젝트 백로그 및 개발 스케줄 (Project Backlog & Schedule)

## 📌 제품 백로그(Product Backlog)란?
- **무엇인가요?** 우리가 만들어야 할 제품(ShortsGen)에 필요한 모든 기능, 버그 수정, 기술적 개선 사항들을 우선순위대로 나열해 둔 '작업 목록(Task List)'입니다.
- **왜 필요한가요?** 개발 중에 새로운 아이디어나 문제점들이 계속 쏟아질 때, 목표가 흔들리지 않고 "지금 당장 가장 중요한 일(우선순위)"에 집중할 수 있도록 돕는 나침반 역할을 합니다.
- **어떻게 생겼나요?** 대개 큰 덩어리의 '에픽(Epic)'에서 작고 구체적인 '태스크(Task)'로 쪼개진 형태를 띱니다. 
- **어떻게 관리하나요?** 구글 시트, 노션(Notion), 혹은 Github Projects 같은 툴을 이용해 관리하며, 우선순위가 높은 일일수록 위로 올리고 상세히 적습니다.
