## 2주차 (~7/19)

- [ ] P0 테스트: 원촌육교 공지 넣고 B1 경로에서 걸리는지
- [ ] P1 Planner 노드: 경로 보고 어느 소스 볼지 결정 — 밀리면 소스 고정 매핑으로 시작
- [ ] P1 매칭 4층 (좌표 거리 + 기간 겹침)
- [ ] P1 그래프 전체 Langfuse 트레이싱 + 확인한 소스/시각 기록
- [ ] P1 APScheduler로 하루 1회 돌리기 — 밀리면 데모는 수동 트리거로
