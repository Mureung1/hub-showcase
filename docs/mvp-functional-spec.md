# MVP 기능 명세

## Summary

MVP는 `Windows XP 데스크톱 앱`처럼 보이는 React 웹앱이다. 설명형 랜딩 페이지가 아니라, 사용자가 작은 데스크톱 프로그램 안에서 목표를 퀘스트로 실행하는 느낌을 주는 것이 핵심이다.

## 구현 범위

- XP풍 파란 하늘/초원 배경
- 바탕화면 아이콘
- 시작 버튼과 작업표시줄
- XP풍 창 프레임
- 창 닫기
- 작업표시줄 열린 창 목록 표시
- 창 제목 표시줄 드래그 이동
- Profile Setup Wizard
- 오늘의 퀘스트 창
- QuestRunner.exe 창
- 매니저 창
- 기록 노트 창
- 내 프로필 창

## 창 시스템

- 열린 창 목록은 배열 상태로 관리한다.
- 작업표시줄은 열린 창 목록을 기준으로 렌더링한다.
- 창을 클릭하면 해당 창이 활성화되고 가장 위로 올라온다.
- 닫기 버튼을 누르면 열린 창 목록에서 제거된다.
- 바탕화면 아이콘이나 작업표시줄 버튼을 누르면 해당 창이 다시 열린다.
- 제목 표시줄을 드래그하면 창 위치가 변경된다.

## Profile Setup Wizard

- localStorage에 프로필이 없으면 첫 화면으로 표시한다.
- 입력 항목:
  - 이름
  - 닉네임
  - 주요 목표
  - 목표 카테고리
  - 목표 기간
  - 하루 가능 시간
  - 퀘스트 크기
  - 매니저 말투
- 저장 후 XP 데스크톱으로 이동한다.
- 이후에는 내 프로필 아이콘으로만 다시 접근한다.

## XP Desktop

- 기본 열린 창은 오늘의 퀘스트와 매니저다.
- 바탕화면 아이콘:
  - 오늘의 퀘스트
  - 매니저
  - 내 프로필
  - 기록 노트
  - 휴지통
- 작업표시줄:
  - 시작 버튼
  - 열린 창 목록
  - 현재 시간
  - 매니저 레벨

## 오늘의 퀘스트

- 목표 기반으로 생성된 퀘스트 초안을 보여준다.
- 사용자는 수락 전 다음 항목을 수정할 수 있다.
  - 제목
  - 유형
  - 분량
  - 난이도
  - 제한 시간
- 난이도와 분량에 따라 예상 EXP를 계산한다.
- 수락하면 오늘의 퀘스트 편집 창은 닫히고 QuestRunner.exe가 열린다.

## QuestRunner.exe

- 수락한 퀘스트를 별도 실행 프로그램처럼 보여준다.
- 표시 항목:
  - 퀘스트 제목
  - 상태
  - 남은 시간
  - 보상 EXP
  - 완료 버튼
  - 실패 처리 버튼
- 완료 시:
  - EXP 증가
  - 매니저 상태 변경
  - 기록 노트에 완료 기록 추가
- 실패 시:
  - 실패 이유 선택 UI 표시
  - EXP 감소 없음
  - 복구 퀘스트 제안으로 연결

## 실패/복구 흐름

- 실패 이유:
  - 시간이 부족했다
  - 목표가 너무 컸다
  - 집중이 안 됐다
  - 컨디션이 좋지 않았다
  - 까먹었다
- 실패 후 매니저는 사용자를 비난하지 않는다.
- 실패는 다음 퀘스트 크기를 조정하기 위한 신호로 사용한다.
- 복구 퀘스트는 기존 퀘스트보다 작은 분량과 낮은 보상을 가진다.

## 매니저 창 표현

- 루미의 대사는 매니저 창 하단의 고정 대화 패널에만 표시한다.
- QuestRunner.exe, 실패 이유, 복구 퀘스트 창에는 루미의 대사를 표시하지 않는다.
- 매니저 상태는 픽셀 상태 아이콘과 짧은 라벨로 표현한다.
- 완료처럼 감정이 큰 순간에는 내용 없는 반응 말풍선을 잠깐 표시할 수 있다.
- 실제 멘트는 말풍선이 아니라 하단 대화 패널에서 갱신한다.
## 제거해야 할 UI

- 큰 프로젝트명/소개 문구
- 랜딩 페이지형 히어로 섹션
- 테마 스위처
- 로파이 오두막 테마
- 확장 모듈 바
- 개인 LLM, 음성 입력, 웹캠 제스처, 우주 탐색, 현실 픽셀화 TV 설명
- Reward Layer, Social Layer, Input Layer, Asset Pipeline 같은 개발자용 레이어명

## Acceptance Criteria

- 첫 접속 시 Profile Setup Wizard가 먼저 뜬다.
- 프로필 저장 후 XP 데스크톱으로 이동한다.
- 새로고침 후 저장된 프로필이 있으면 온보딩이 다시 뜨지 않는다.
- 기본 열린 창은 오늘의 퀘스트와 매니저 2개다.
- 바탕화면 아이콘으로 보조 창을 열 수 있다.
- 창 닫기 버튼으로 창을 닫을 수 있다.
- 작업표시줄에 열린 창 목록이 표시된다.
- 창 제목 표시줄을 드래그해 이동할 수 있다.
- 퀘스트 수정 -> 수락 -> QuestRunner.exe 실행 흐름이 이어진다.
- 완료 시 EXP가 증가하고 기록 노트에 남는다.
- 실패 처리 -> 실패 이유 선택 -> 복구 퀘스트 제안이 이어진다.
- 화면에 미구현 확장 기능이나 개발자용 레이어명이 보이지 않는다.
