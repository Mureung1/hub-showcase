# 기능 체크리스트 (Spec)

기능(Feat) 단위로 지금 어디까지 왔는지 체크리스트로 관리하는 문서다. 각 Feat은 아래 흐름을 따른다.

```
Feat-N → GitHub Issue 등록 → 설계 → 개발 → PR(dev 브랜치) → 내가 승인하고 머지 → 이슈 닫기
```

멘토 피드백에서 받은 "작게 작업 나누기" 흐름을 그대로 따른 것이다. Feat 하나가 이 흐름을 다 통과해서 이슈가 닫히면 아래 체크박스를 `[x]`로 바꾼다.
