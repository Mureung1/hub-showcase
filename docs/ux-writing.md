# 아맞다 UX Writing 계약

## 목적

아맞다는 사용자가 저장한 인사이트를 필요한 순간 다시 꺼내 쓰도록 돕는다. 제품 문구는 사용자가 현재 상황과 다음 행동을 바로 이해하게 해야 한다.

## 기준 우선순위

문구 기준이 충돌하면 다음 순서로 판단한다.

1. 기능·보안·개인정보·법적 의미를 정확하게 유지한다.
2. 아맞다 도메인 언어와 제품 원칙을 따른다.
3. 앱인토스 UX 라이팅 원칙을 적용한다.
4. 화면 공간과 접근성 맥락에 맞게 길이와 표현을 조정한다.

## 제품 목소리

- 설명, 상태, 질문, 오류는 해요체로 쓴다.
- 능동형, 긍정형, 캐주얼한 경어와 동사 중심 표현을 우선한다.
- 띄어쓰기는 `해 주세요`, `돼요`를 사용한다.
- 완전한 본문, 설명, live region 문장은 마침표로 끝낸다. 제목, 버튼, 라벨에는 마침표를 쓰지 않는다.

## 용어

| 의미               | 사용할 말 | 사용 기준                                                  |
| ------------------ | --------- | ---------------------------------------------------------- |
| 저장한 대상        | 인사이트  | 저장된 대상을 링크라고 부르지 않는다.                      |
| 대화 속 주소       | 링크      | 주소를 자연어로 가리킬 때 사용한다.                        |
| 입력·검증 대상     | URL       | `링크 URL`, `원문 URL`처럼 뜻이 겹치는 표현을 쓰지 않는다. |
| 저장 장소          | 보관함    | 저장 행동 자체를 보관함이라고 부르지 않는다.               |
| 정리 기준          | 카테고리  | 사용자 UI에서 분류와 섞지 않는다.                          |
| 외부 자료 이전     | 가져오기  | 내부 이관 용어를 쓰지 않는다.                              |
| 현재 상황으로 발견 | 꺼내보기  | 기능 이름은 붙여 쓴다.                                     |
| 단서로 직접 찾기   | 검색      | 꺼내보기와 목적을 섞지 않는다.                             |
| 가져오기 취소 복구 | 되돌리기  | 삭제·복구 범위를 함께 설명한다.                            |

`원문 열기`는 외부 페이지를 여는 행동으로 허용한다. 다만 주소 이름에는 `원문 URL`, `링크 URL`을 사용하지 않는다.

## 역할별 규칙

- 버튼은 누르면 얻는 결과가 드러나게 쓴다.
- 일반 다이얼로그의 왼쪽 행동은 `닫기`로 쓴다.
- 실제로 Notion 연결을 중단하는 행동은 `Notion 연결 그만두기`로 쓴다.
- 선택 입력은 라벨 뒤에 `(선택)`을 붙인다.
- 오류는 발생한 일, 보존된 내용, 다음 행동 순서로 쓴다.

## 상태 기본형

표에서 마침표 없이 적은 예시는 상태 제목 또는 접근 가능한 이름이다. 같은 문구를 본문이나 live region의 완전한 문장으로 사용할 때는 마침표를 붙인다.

| 상태         | 기본 문구                                                                           |
| ------------ | ----------------------------------------------------------------------------------- |
| 진행         | 가져올 내용을 확인하고 있어요                                                       |
| 성공         | 인사이트 3개를 보관함에 추가했어요                                                  |
| 오류         | 가져올 내용을 확인하지 못했어요. 입력한 링크는 그대로 두었어요. 다시 시도해 주세요. |
| 초기 빈 상태 | 첫 인사이트를 저장하면 여기에서 다시 찾을 수 있어요                                 |
| 결과 없음    | 이 검색어로 찾은 인사이트가 없어요. 검색어를 줄이거나 다른 단서를 입력해 보세요.    |
| 확인         | 이 가져오기를 되돌릴까요? 이 작업에서 새로 만든 인사이트만 삭제해요.                |

## 접근성

- 보이는 문구와 접근 이름은 같은 의미를 전달한다.
- 진행과 성공은 기존 live region에서 완전한 문장으로 알린다.
- 오류는 기존 alert와 입력 설명의 연결을 유지한다.
- 같은 상태를 보이는 문구와 live region에서 중복으로 읽지 않게 한다.

## 적용 범위

웹, Android 공유, Chrome 확장과 보조기술 문구에 적용한다.

내부 로그, 개발자 예외, 코드 주석, 테스트 설명, 픽스처, 사용자 입력, 외부 서비스가 소유한 문구는 적용 대상에서 제외한다.
