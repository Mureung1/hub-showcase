**온보딩→매칭→상세→외부 신청 이동 전체 흐름을 PR마다 수동으로 재현·확인할 수 있는 체크리스트
문서를 만든다.**

## 현재 상태 (전환 전)

- `npm test`(vitest)는 컴포넌트/라우트 단위 테스트만 커버 — 화면 간 흐름 전체를 잇는 E2E 테스트는 없음
- 각 이슈 계획 문서(`docs/week3/*.md`, `docs/week4/*.md`)에 그 이슈 범위의 수동 검증만 개별 기록돼
  있고, 전체 사용자 플로우를 한 번에 확인하는 공통 체크리스트는 없음
- `docs/plan.md`의 화면 흐름(조건 입력 → 매칭 리스트 → 상세 → 외부 이동)이 사실상의 E2E 대상 시나리오

## 범위

### 포함 (이번 이슈)
- `docs/week4/e2e-checklist.md`(체크리스트 본문, 살아있는 문서) 작성
- 골든 패스: 온보딩 4스텝 완료 → 매칭 리스트(정렬 3종) → 상세 → 외부 URL 이동
- 주요 엣지 케이스: 온보딩 필수값 미입력 시 진행 차단, 매칭 결과 0건, 상세 존재하지 않는 id(404),
  `POST /api/match` 잘못된 입력(400)
- Playwright 등 자동화 E2E 도입 여부는 이번엔 판단만 하고 실제 도입은 제외(아래 리스크 표)

### 제외 (다음으로)

  확인되면 별도 이슈
- 크롤러 파이프라인 E2E(이미 `docs/week3/verification.md` 형식으로 별도 커버)
