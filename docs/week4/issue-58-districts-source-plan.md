## 목표 (한 줄)

**시·도(REGIONS)/구·군(DISTRICTS) 데이터를 정적 TS 파일로 계속 유지할지, 외부 API/공공데이터로
전환할지 결정하고 문서로 남긴다.**

## 현재 상태 (전환 전)

- `shared/src/regions.ts`의 `REGIONS`(시·도 17개 — 전남광주 통합 반영)와 `src/data/regions.ts`의
  `DISTRICTS`(시·도별 구·군 목록, 85줄 하드코딩 `Record<string, string[]>`)가 유일한 지역 데이터 소스
- 두 파일 다 사람이 직접 작성·갱신 — 2023 군위군 대구 편입, 2026 전남광주 통합 등 행정구역 변경을
  발견할 때마다 수동으로 고쳐왔음(파일 상단 주석에 기준 시점 명시)
- 온보딩 Step2/3(`Step2Region.tsx`)에서 이 두 데이터로 지역 선택 UI 구성, 크롤러도 같은 `REGIONS`
  표기를 공유해서 매칭 시 문자열 일치에 사용(#43)
- 외부 API로 바꿀 필요가 생긴 구체적 장애나 버그는 아직 없음 — CONTEXT.md에 "미정 사항"으로만 남아있던 항목
