# 핵심 기능 세부 정리

기능 개요는 [`service-mvp.md`](service-mvp.md)를 참고.

## 오늘의 깸: 세부 처리 방식

- 미션은 특정 문장이 아니라 글 전체를 대상으로 한다. 원문은 앱 안에 저장·표시하지 않으므로(저작권·서비스 방향), 사용자는 원문 링크로 이동해 읽고 돌아온 뒤 미션을 받는다.
- 미션 유형은 질문·반박·연결·표현 중 하나가 서버에서 제시되며, 사용자는 원하면 다른 유형으로 바꿀 수 있다.
- 빈 답변과 "네", "ㅇㅇ" 같은 명시적인 무성의 답변은 완료 처리하지 않고 재작성을 안내한다. 임의의 최소 글자 수나 AI 판정은 사용하지 않는다.
- 완료된 답변만 저장하며 작성 중인 미션은 저장하지 않는다.
- 같은 글에 다시 답변하는 것은 허용하고, 각 답변을 별도의 사고 기록으로 남긴다.

## 오늘의 글 추천: 세부 정리

### 콘텐츠 수집 방식

콘텐츠는 사전에 검증해 등록한 외부 RSS 소스에서 수집하며 크롤링은 사용하지 않는다. MVP에서는 다중 소스 CLI를 운영자가 수동 실행한다. 자동 스케줄러, 실행 이력과 실패 알림은 현재 MVP 범위에 포함하지 않는다. 구체적인 수집 계약은 [`content-pipeline.md`](../engineering/content-pipeline.md)를 기준으로 한다.

### 콘텐츠 종류

MVP 추천 대상은 DB의 `source_type`과 `content_type` 계약을 따르며, 실제로 검증된 무료 원문과 등록된 소스만 사용한다. 특정 매체나 수집 방식의 후보 목록은 현재 제공 범위로 간주하지 않는다. 구체적인 콘텐츠 정책은 [`content-strategy.md`](../engineering/content-strategy.md)를 기준으로 한다.

### 콘텐츠 분류

소스 유형과 관심사 태그를 관심사 매칭에 사용한다. 소스를 등록할 때 관심사를 지정하고, 수집된 글은 그 관계를 기반으로 콘텐츠 관심사 태그를 저장한다.

### 콘텐츠 품질관리

자동 추천은 원문 접근 가능 여부, 소스 신뢰도, 콘텐츠 품질과 관심사 일치를 확인한 후보만 사용한다. 유료·접근 불가·품질 기준 미달 콘텐츠는 기본 추천에서 제외한다.

### 추천 로직

사용자 관심사와 일치하는 후보 중 품질, 최신성, 소스 신뢰도와 반복 보정을 반영해 최대 3개를 추천한다. 이미 미션을 완료한 글은 추천에서 제외한다. 추천 후보가 없으면 다른 관심사의 글이나 영어 선택 소스를 자동으로 섞지 않고 빈 상태를 안내한다. 클릭 수 인기글, 협업 필터링, 날짜별 고정 배정과 미완료 글 자동 재제시는 MVP에서 사용하지 않는다.

## 나의 깸: 현재 MVP

사용자가 남긴 질문, 반박, 연결, 표현 기록은 `Asia/Seoul` 기준 월별 캘린더에서 날짜를 선택해 확인한다. 선택한 날짜 안에서는 기록을 최신순으로 보여주고, 같은 콘텐츠에 여러 번 남긴 기록도 각각 표시한다. MVP에서는 페이지네이션과 무한 스크롤을 사용하지 않는다.

## 후속 후보

다음 기능은 현재 MVP에서 제외하며, 사용자 검증 후 별도로 결정한다.

- 특정 미션 유형을 2주 동안 선택하지 않았을 때 예시를 보여주는 팝업
- 사용자당 최대 3개의 작성 중 미션 저장과 LIFO 복원
- 클릭 수 기반 인기글과 사용자 프로필 기반 협업 필터링
- 이전 사고 기록을 추천에 반영하거나 다른 미션으로 다시 제시하는 기능
- 과거 기록을 파고들거나 확장·재구성·반론을 제시하는 AI 재사고 질문

AI 재사고 질문을 도입한다면 AI 생성임을 명시하고, 실존하는 타인의 의견처럼 위장하지 않는다.
