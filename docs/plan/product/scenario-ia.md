# 사용자 시나리오 및 화면 구조

## 사용자 시나리오

앱에 처음 접속하면 익명 Auth 세션을 만들고 관심사 1~3개를 선택한다. 이후 관심사에 맞는 글을 최대 3개 확인하고, 글 하나를 선택해 외부 원문을 읽은 뒤 앱으로 돌아온다. 글 전체를 기준으로 추천된 사고 미션 하나를 수행하거나 다른 유형으로 바꾸고, 생각을 입력해 완료된 사고 기록으로 저장한다. 나의 깸에서는 월별 캘린더에서 날짜를 선택해 이전 기록을 확인한다. 다음 접속부터는 관심사 설정을 건너뛰고 오늘의 글 화면으로 진입한다.

## 화면 흐름(IA)

앱 접속 시 관심사 설정 이력을 확인한다. 이력이 없으면 관심사 설정 화면을 거쳐 오늘의 글 화면으로 이동하고, 있으면 바로 오늘의 글 화면으로 이동한다. 사용자는 오늘의 글 화면에서 글 소개를 확인하고 외부 원문으로 이동한다. 앱으로 돌아온 뒤 미션 화면에서 질문·반박·연결·표현 중 하나를 수행해 기록을 저장한다. 오늘의 글과 나의 깸은 하단 탭으로 이동하며, 나의 깸에서는 월을 이동하고 날짜를 선택해 해당 날짜의 기록을 확인한다.

브라우저·모바일 시스템 뒤로가기와 URL 직접 진입은 현재 MVP IA에 포함하지 않으며 별도 후속 요구사항으로 다룬다.
