# "깸" 프로토타이핑 기록

> **문서 상태:** 완료된 과거 계획의 기록이다. 현재 제품 요구사항이나 React 구현의 기준 문서가 아니다.

## 목적

초기 화면 흐름과 디자인 시스템을 브라우저에서 검토하고, 이후 React 구현에 참고할 수 있는 프로토타입을 만드는 것이 목적이었다.

## 당시 계획

- 모바일 375px 폭을 기준으로 온보딩, 오늘의 깸, 글 읽기, 미션, 미션 완료, 나의 깸 화면을 구성한다.
- 헤더·본문·하단 영역과 카드, 버튼, 탭바 등 공통 컴포넌트를 먼저 정의한다.
- 당시 목업에 있던 문장 하이라이트 전후 상태와 하이라이트 인용 미션도 화면 흐름에 포함한다.

이 계획은 여러 정적 HTML 페이지를 만드는 방식으로 시작했으나, 최종 산출물은 화면 간 이동과 상태 변화를 확인할 수 있는 단일 인터랙티브 HTML로 완성되었다.

## 실제 산출물

- [`docs/prototype/final_prototype.html`](../../prototype/final_prototype.html)

프로토타입은 빌드 대상이 아닌 디자인 참고 자료다. 당시 검토하던 화면, 문구, 데이터와 이후 폐기된 흐름이 포함될 수 있다.

## 현재 기준과의 경계

- 현재 제품 범위와 화면 흐름은 [`docs/plan/product/`](../product/) 문서를 기준으로 한다.
- 현재 기술 계약과 구현 방식은 [`docs/plan/engineering/`](../engineering/) 문서와 `frontend/` 구현을 기준으로 한다.
- 현재 미션은 글 전체를 읽은 뒤 수행하며, 사용자가 문장을 선택하거나 하이라이트하지 않는다.
- 프로토타입의 색감과 레이아웃은 참고할 수 있지만, 프로토타입 자체를 기능 요구사항이나 구현 완료 기준으로 사용하지 않는다.
