# 오늘모여 — 서비스 기획서

## 1. 문제 상황

- **고정된 일정의 제약**: 기존 동아리나 일반 모임은 정해진 스케줄에 개인이 맞춰야 하므로, 일정이 유동적이거나 바쁜 사람은 참석 자체가 어려움.
- **지속 참여의 압박과 의지의 한계**: 장기적인 모임은 매번 참여해야 한다는 압박감을 주어 원하는 때에만 가볍게 활동하기 힘든 반면, 완전히 혼자서 무언가를 꾸준히 활동하고 기록해 나가는 것은 의지력의 한계에 부딪힘.

## 2. 해결 방안

- **시간 주도형 초단기 모임 시스템**: 내가 원하는 시간대를 선택해 사람을 모으거나, 개설된 시간에만 단발성으로 참여하는 유연한 활동 공간을 제공. 방장이 설정한 시작 시각과 진행 시간에 맞추어 원하는 스케줄에만 선착순으로 예약 신청 후, 정시에 모여 집중하는 시스템.
- **활동 기록 체크 및 유도 시스템**: 마이페이지 대시보드를 통해 나의 활동 기록을 한눈에 체크할 수 있으며, 누적 리포트를 바탕으로 유저가 지치지 않고 꾸준하게 다음 모임에 참여할 수 있도록 동기를 유도하는 개인화 시스템 제공.

## 3. 사용자 시나리오

1. **모임 탐색 및 신청**: 메인 홈 화면에서 원하는 시간대의 모임 구인 글을 탐색하고 참가 신청
2. **모임 참가**: 신청한 모임의 대기 상태를 확인하고, 설정 시간이 되면 [입장하기] 버튼으로 방에 입장
3. **모임 진행**: 설정된 시간 동안 참여자들과 함께 주제에 맞는 활동을 수행
4. **활동 기록**: 모임이 종료되면 메인 페이지로 이동하여 그날 활동한 기록에 대해 메모하고 기록

## 4. 구성 페이지

**페이지 구현 방식**: 메인 홈 화면 내 하위 화면(모임 구인 목록 / 내 모임 대시보드 / 모임 개설 / 활동 기록)은 SPA의 조건부 렌더링 방식으로 구성한다. 실시간 모임방 화면(Room)만 별도의 페이지로 분리해 제작한다.

- **메인 홈 화면** (조건부 렌더링으로 하위 화면 전환)
  - 모임 구인 목록 화면
  - 내 모임 대시보드
  - 모임 개설 화면
  - 활동 기록
- **실시간 모임방 화면** (별도 페이지)

## 5. 페이지별 기능

### 메인 홈 화면
- 내가 신청한 모임 현황을 한눈에 확인
- 총 누적 진행 시간 확인
- 당일 활동 기록 열람 및 작성 화면으로 이동
- 모임 구인 목록 / 모임 개설 화면으로 이동

### 모임 구인 목록 화면
- 카테고리별 모임 구인 글 탐색
- 모임 구인 글 목록 확인
- 목록 새로고침을 통한 최신 구인 글 동기화
- 원하는 모임에 참가 신청

### 내 모임 대시보드
- 신청 완료한 모임 정보 확인
- 모임 시작까지 남은 시간 확인
- 설정 시간 도달 시 [입장하기]를 통해 모임방 입장

### 모임 개설 화면
- 모임 제목 및 상세 설명 입력
- 카테고리 선택
- 모임 예약 시간(시작 시각 / 진행 시간) 설정
- 모임 개설 완료

### 활동 기록
- 지난 활동 기록 목록 열람
- 당일 활동에 대한 메모 작성

### 실시간 모임방 화면
- 참여자들과 실시간으로 대화
- 모임 진행 시간을 타이머로 확인
- 모임 종료 후 메인 화면으로 복귀
