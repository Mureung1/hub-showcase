# 사용자 시나리오 및 화면 구조

## 사용자 시나리오

앱 접속 후, 관심사 기반으로 큐레이션된 오늘의 글 1~3개를 확인한다. 글 1개를 선택해 원문 링크로 이동해 읽고 앱으로 돌아온다. 글 전체를 기준으로 오늘의 사고 미션 1개가 제시된다. 한 줄 생각을 입력한다. 입력 내용이 사고 log 카드로 저장된다. 나의 깸에서 이전 기록을 다시 확인한다. 다음 접속 시, 이전 사고 log를 반영한 새로운 글을 추천받는다.

## 화면 흐름(IA)

앱 접속 시 관심사 설정 이력이 있는지 확인한다. 없으면(최초 접속) 관심사 설정 화면(태그 선택)으로 이동한 뒤 오늘의 글 화면으로 넘어가고, 있으면 바로 오늘의 글 화면에서 원문(외부 링크)으로 이동해 읽고 돌아오면, 오늘의 사고 미션 화면(질문/반박/연결/표현 중 1개)으로 이동한다. 여기서 한 줄 기록을 입력하면 사고 log 카드로 저장되고, 다음 날 접속 시 다시 오늘의 글 화면으로 돌아간다. 오늘의 글 화면과 히스토리 화면(나의 깸)은 하단 탭으로 상호 이동 가능하다.
