# 오늘모여 — 2주 개발 계획

핵심 시나리오(모임 탐색 → 신청 → 참가 → 진행)를 1주차에 완성하고, 2주차에 모임 개설·활동 기록·마무리 배포까지 진행한다.

---

## 1주차. 기반 구축 및 핵심 시나리오

### 1단계. 기획 및 설계 (완료)

| 작업 | 상태 |
|---|---|
| `CONTEXT.md` 작성 — 프로젝트 개요, 기술 스택, 컨벤션 정의 | 완료 |
| 디자인 시스템 정의 — `prompts/designsystem.md` | 완료 |
| 개발 계획 문서 수립 — `docs/roadmap.md` | 완료 |
| UI 프로토타입 제작 (`index.html` / `room.html`) | 완료 |

이 단계가 끝나면: 기획서·디자인 시스템·개발 계획이 준비되고 화면 구조가 프로토타입으로 확인 가능하다.

## 2주차 최종 목표

- 개발 환경(FE/BE/DB)이 갖춰져 있다.
- 모임을 탐색하고 신청할 수 있다.
- 신청한 모임에 정시 입장해 실시간으로 대화할 수 있다.
- 새 모임을 개설할 수 있다.
- 활동 기록을 남기고 누적 시간을 볼 수 있다.
- 전체 흐름을 시연할 수 있다.
