# 깸 디자인 시스템

Claude Design으로 화면 목업을 만들 때 이 문서를 항상 함께 참조시킬 것.
(색상/타이포/장식/버튼/카드/레이아웃 톤은 `docs/design/reference.jpg`의 전체 분위기 참고, 컴포넌트 구조는 `docs/design/reference.jpg`·`docs/design/reference2.jpg` 참고)

## 색상

```
--paper: #F4E9D7          /* 배경 (크림/베이지) */
--paper-raised: #FFFFFF   /* 카드/섹션 배경 (화이트) */
--ink: #16301F            /* 기본 텍스트, 헤딩, 버튼 배경 (다크 그린) */
--ink-soft: #5C6459        /* 보조 텍스트 */
--rule: #E4D8C2           /* 구분선, 테두리 */

--accent-lime: #C9DB2E    /* 포인트 컬러 (스티커/스타버스트, 강조 글자) */
--accent-blue: #4C8FE8    /* 장식 블롭 컬러 */
--accent-pink: #FF95A8    /* 보조 포인트 (필요 시 사용) */
```

배경은 크림(`--paper`)과 화이트(`--paper-raised`)를 섹션 단위로 번갈아 사용한다. 헤딩·버튼·푸터처럼 강조가 필요한 곳은 다크그린(`--ink`)을 배경색으로도 쓴다. 라임(`--accent-lime`)은 가장 눈에 띄는 포인트로, 스티커형 도형이나 소수의 강조 텍스트에만 제한적으로 사용한다.

## 타이포그래피

- 폰트: 시스템 폰트 스택 (Pretendard Variable, Apple SD Gothic Neo, Malgun Gothic, sans-serif)
- 헤딩: 매우 굵게(800), 큰 사이즈, 자간 살짝 좁게(-0.01~-0.02em), `--ink` 컬러
- 본문: 14~16px, line-height 1.6, `--ink-soft`
- 보조 텍스트(라벨, 캡션 등): 12~13px, `--ink-soft`
- 통계 숫자(예: "22", "2800")처럼 임팩트가 필요한 곳은 굵게(700~800)로 크게 표시

## 장식 요소 (블롭 & 스티커)

- **블롭**: 배경에 깔리는 유기적 형태(불규칙한 둥근 얼룩 모양)의 색면. 태그/뱃지 뒤에 배치해 시선을 끄는 용도로 사용. `--accent-blue`를 주로 사용.
- **스타버스트/스티커**: 별 모양 톱니 형태의 도형. 내부에 짧은 라벨 텍스트("Future Ready", "Parent" 등)를 얹어 캐주얼한 강조 요소로 사용. `--accent-lime`을 주로 사용.
- 블롭·스타버스트는 섹션마다 1~2개 정도로 절제해서 배치하고, 본문 텍스트와 겹치지 않게 한다.

## 버튼

- 기본 버튼: `--ink`(다크그린) 배경 + 흰색 텍스트, 알약(pill) 형태, 우측에 화살표 아이콘(↗) 포함.
- 버튼 모서리는 완전히 둥글게(radius 999px 또는 height의 절반).

## 카드 & 이미지

- 사진은 모서리를 둥글게(radius 12~20px) 처리하고, 여러 장을 그리드나 겹침 구도로 배치해 생동감을 준다.
- 카드 컴포넌트: `--paper-raised` 또는 `--paper` 배경, 모서리 radius 16~24px, 그림자는 옅게(있어도 거의 안 보일 정도) 사용.
- 통계/수치 블록은 큰 숫자 + 짧은 설명 텍스트를 세로로 쌓아 구성한다.

## 컴포넌트

`reference.jpg`(온보딩/홈 화면)와 `reference2.jpg`(상세 콘텐츠 화면)의 구조를 참고하되, 색상은 위 팔레트(`--paper`, `--ink`, `--accent-lime`, `--accent-blue`, `--accent-pink`)를 그대로 적용한다.

### 마스코트 캐릭터

- 단순한 기하 도형(사각형/오각형/원 등) 몸통 + 얇은 선(stick) 팔다리 + 점 2개와 곡선으로만 이루어진 표정의 캐릭터를 온보딩, 완료 화면 등 감정 전달이 필요한 지점에 배치한다.
- 몸통 색은 `--accent-lime` 또는 `--accent-blue`를 사용하고, 선/눈코입은 `--ink`로 그린다.
- 장식 요소(블롭·스타버스트)와 마찬가지로 화면당 1개만 배치해 포인트로 남긴다.

### 카드 스택 (겹침 리스트)

- 여러 항목을 완전히 분리된 카드로 나열하지 않고, 아래 카드가 위 카드 뒤로 살짝 겹쳐 보이도록 배치해 리듬감을 준다.
- 각 카드는 배경색을 다르게 써서(`--accent-lime`, `--accent-pink`, `--accent-blue` 순환) 구분하고, 카드 안에 작은 마스코트 아이콘 + 제목 + 보조 정보(소요시간, 빈도 등)를 좌우로 배치한다.
- 카드 모서리 radius는 카드 규칙(16~24px)을 따른다.

### 날짜/탭 셀렉터

- 가로로 나열된 알약형 셀 목록(요일, 탭 등)으로, 선택된 셀만 `--ink` 배경 + 흰색 텍스트로 채우고 나머지는 `--paper-raised` 배경 + `--ink-soft` 텍스트로 둔다.
- 셀 사이 간격은 좁게, 셀 자체는 완전히 둥근 모서리(pill)로 처리한다.

### 하단 플로팅 내비게이션

- 화면 하단에 배경과 분리된 알약형 바를 띄우고(좌우 여백 확보, 화면 폭에 꽉 채우지 않음), 내부에 아이콘 2~4개(+ 필요 시 프로필 이미지)를 균등 배치한다.
- 배경은 `--paper-raised`, 활성 아이콘만 `--ink` 배경의 원형 뱃지로 강조한다.

### 상세 콘텐츠 카드 & 페이지네이션

- 원문/미션처럼 하나의 콘텐츠에 집중해야 하는 화면은, 화면 상단 배경(그라데이션 대신 `--paper` 또는 `--ink` 단색)과 그 위에 얹힌 화이트(`--paper-raised`) 카드 하나로 구성한다.
- 카드 안은 라벨(작게, `--ink-soft`) → 핵심 콘텐츠(크게, 굵게) → 보조 설명 순으로 세로 배치한다.
- 여러 항목을 순차로 넘기는 화면에는 카드 하단에 "이전 / 현재 위치 (예: 3/7) / 다음" 페이지네이션을 얇게 배치한다.

### 하단 고정 액션 영역

- 화면 하단에 버튼 1~2개를 고정 배치한다. 버튼이 2개일 때는 보조 액션(아웃라인, `--paper-raised` 배경 + `--ink` 테두리/텍스트)과 주요 액션(`--ink` 배경 채움, 아이콘 포함)을 좌우로 나눈다.
- 텍스트 입력이 필요한 화면은 버튼 대신 하단 고정 입력바(placeholder 텍스트 + 우측 짧은 액션 버튼)로 대체할 수 있다. 입력바 배경은 `--paper-raised`, 액션 버튼은 `--accent-lime` 배경 + `--ink` 텍스트로 강조한다.

## 레이아웃 원칙

- 기본은 데스크톱 폭(1200px 내외) 기준의 랜딩 페이지 레이아웃. 섹션을 세로로 쌓고 각 섹션은 크림/화이트 배경을 번갈아 사용한다.
- 네비게이션: 상단 고정, 좌측 로고, 중앙 메뉴, 우측 CTA 버튼.
- 히어로 섹션: 큰 헤딩 + 짧은 설명 + CTA 버튼 + 블롭/스타버스트 장식 + 하단 사진 스트립 구성.
- 푸터: `--ink`(다크그린) 배경에 흰색 텍스트, 하단에 스타버스트 장식 배치.

## 톤

밝고 친근하며 캐주얼한 톤. 크림/화이트의 편안한 배경 위에 다크그린의 안정감 있는 텍스트, 라임의 발랄한 포인트가 대비를 이룬다. 블롭과 스타버스트 같은 유기적 장식 요소로 생동감을 주되, 남발하지 않고 시선을 끌 지점에만 절제해서 배치한다.
