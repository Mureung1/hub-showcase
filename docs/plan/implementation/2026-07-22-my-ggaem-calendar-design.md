# 나의 깸 캘린더 화면 설계

## 목적

사용자가 월별 캘린더에서 사고 기록이 있는 날짜를 확인하고, 날짜를 선택해 그날 작성한 미션 기록을 다시 본다. 같은 콘텐츠에 여러 번 기록한 경우에도 각각 별도 카드로 표시한다.

## 화면 구조

나의 깸 화면은 다음 순서로 구성한다.

1. 화면 제목
2. 이전 달·다음 달 이동이 가능한 월별 캘린더
3. 선택 날짜 안내
4. 선택 날짜의 미션 기록 카드 목록
5. 오늘의 깸과 나의 깸을 오가는 하단 탭

날짜 셀 전체를 버튼으로 만든다. 기록이 있는 날짜에는 해당 날짜의 첫 미션 유형 색상으로 스탬프를 표시한다. 스탬프를 누르는 동작도 날짜 셀 선택과 같다.

## 날짜 선택

- 최초 진입 시 현재 월과 오늘 날짜를 선택한다.
- 이전 달이나 다음 달로 이동하면 기존에 선택한 일자와 같은 일자를 자동 선택한다.
- 이동한 달에 같은 일자가 없으면 그 달의 마지막 날을 선택한다.
- 기록이 없는 날짜도 선택할 수 있다.
- 선택한 날짜의 기록은 캘린더 하단에 `createdAt desc`, `id desc` 순서로 표시한다.

## 스탬프 기준

월별 캘린더 API는 기록 날짜별로 다음 값을 반환한다.

```json
{
  "date": "2026-07-21",
  "recordCount": 3,
  "firstMissionType": "connection"
}
```

`firstMissionType`은 `Asia/Seoul` 기준 해당 날짜에 생성된 기록 중 `createdAt asc`, 같은 시각이면 `id asc`인 첫 기록의 미션 유형이다.

스탬프는 다음 기능색을 사용한다.

- `question`: 질문
- `rebuttal`: 반박
- `connection`: 연결
- `expression`: 표현

한 날짜에 여러 유형의 기록이 있어도 스탬프는 최초 미션 유형 하나만 표시한다. `recordCount`는 스탬프의 접근 가능한 설명과 기록 개수 표시에 사용한다.

## API 연결

화면 진입 시 다음 요청을 보낸다.

```text
GET /api/mission-records/calendar?month=YYYY-MM
GET /api/mission-records?date=YYYY-MM-DD
```

- 월 이동 시 새 월의 캘린더와 자동 선택된 날짜의 기록을 조회한다.
- 같은 월에서 날짜만 변경하면 날짜별 기록만 다시 조회한다.
- 날짜와 월 문자열은 프론트에서도 `Asia/Seoul` 기준으로 만든다.

월별 캘린더 응답은 날짜, 기록 개수, 첫 미션 유형을 포함한다. 날짜별 기록 응답은 기존 평면 배열 계약을 유지한다.

## 기록 카드

각 기록 카드는 다음 정보를 표시한다.

- article 제목
- 출처와 관심사 태그
- 미션 유형
- 미션 문구
- 사용자 답변
- 작성 시각
- 원문 다시 보기 상태

같은 article의 기록도 합치지 않고 각각 별도 카드로 표시한다.

`urlStatus`가 `active`면 원문을 새 탭으로 연다. `broken`, `removed`, `paywalled`이면 기록은 유지하되 원문 버튼을 비활성화하고 상태 안내를 표시한다.

## 화면 상태

캘린더와 날짜별 기록은 상태를 분리한다.

- 캘린더 로딩: 월별 스탬프를 불러오는 상태 표시
- 캘린더 에러: 월별 조회 실패 안내와 재시도 제공
- 월 빈 상태: 캘린더는 유지하고 해당 월에 기록이 없다는 안내 표시
- 기록 로딩: 선택 날짜의 기록을 불러오는 상태 표시
- 기록 에러: 날짜별 조회 실패 안내와 재시도 제공
- 날짜 빈 상태: 선택 날짜에 기록이 없다는 안내 표시

실패한 요청만 다시 시도하며, 다른 영역의 정상 데이터를 지우지 않는다.

## 상태 소유

나의 깸 화면 컨테이너가 표시 월과 선택 날짜를 소유한다. 캘린더와 기록 목록은 전달받은 데이터와 콜백을 렌더링한다. 현재 요구사항에 필요한 화면 상태만 두고 별도 전역 상태나 범용 캘린더 계층은 만들지 않는다.

하단 탭 전환은 기존 App의 로컬 화면 전환 구조를 확장한다. 라우터 라이브러리는 추가하지 않는다.

## 테스트 범위

- 오늘 날짜 기본 선택
- 월 이동 시 같은 일자 선택
- 존재하지 않는 일자는 해당 월 마지막 날로 보정
- 날짜 셀 클릭과 키보드 선택
- `firstMissionType`별 스탬프 표시
- 날짜 선택 후 하단 기록 목록 변경
- 같은 article의 여러 기록을 별도 카드로 표시
- 월별·날짜별 로딩, 에러, 빈 상태와 재시도
- 원문 상태별 링크 또는 비활성 버튼
- 하단 탭 전환
- 320px와 375px 화면에서 오버플로우 없음

## 의도적으로 제외하는 범위

- 페이지네이션과 무한 스크롤
- 여러 미션 유형을 한 날짜에 동시에 표시하는 스탬프
- 콘텐츠별 기록 그룹과 생각 변화 비교
- 주간·월간 통계와 연속 기록 계산
- 범용 캘린더 라이브러리와 새 라우터 의존성
