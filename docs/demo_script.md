# 데모 스크립트 (하소AI · AI Agent Challenge 2026)

배포 주소로 직접 리허설한 내용을 바탕으로 작성. 시연 직전 체크리스트부터 순서대로 따라가면 된다.

---

## 시연 직전 체크리스트 (필수)

- [ ] **백엔드 미리 깨우기**: Render 무료 티어는 idle 상태면 첫 요청에 15~50초 걸린다. 시연 5분 전에 `https://haso-ai-backend.onrender.com/health` 를 한 번 호출해서 미리 깨워둔다.
- [ ] `https://hub-five-delta.vercel.app` 접속해서 "맥락 엔진"이 "자동 감지 완료"로 뜨는지 확인 (날씨/공휴일 정상 로드).
- [ ] 발표 네트워크가 느릴 수 있으니, 모바일 핫스팟 등 백업 회선 준비.

---

## 1. 문제 & 사용자 (30초)

> "SNS 홍보를 매일 직접 해야 하는 소상공인 사장님들은, 정형화된 홍보 글보다 사장님의 솔직한 뒷이야기에 소비자가 더 반응한다는 걸 알면서도, 그걸 매일 글로 옮길 시간과 에너지가 없습니다. 하소AI는 사장님이 오늘 있었던 '하소연'을 그냥 편하게 적으면, 감정 온도에 맞는 SNS 콘텐츠로 바꿔줍니다."

- **문제**: 반복되는 콘텐츠 제작의 심리적 부담, 정형화된 홍보글의 낮은 반응
- **사용자**: SNS 홍보를 직접 하는 소상공인 사장님, 매장 운영을 돕는 직원

---

## 2. 핵심 기능 시연 순서 (2~3분)

| 순서 | 화면 조작 | 보여줄 포인트 |
|---|---|---|
| 1 | (이미 등록돼 있으면 생략) 업장 정보 등록 모달에서 업종·이름 입력 후 저장 | 한 번만 등록하면 생성마다 자동 반영됨 |
| 2 | 하소연 입력창에 실제 사연 입력 (예시 칩 중 "환불 요청 속상해요" 클릭 가능) | 150자 제한 + 예시 칩으로 빠른 시작 |
| 3 | 발행 채널을 "인스타그램"으로 선택 | 플랫폼별 글자수/톤이 다름을 설명 |
| 4 | 맥락 엔진 확인 — "맑음, XX°C", 공휴일 여부가 자동으로 떠 있는 상태 그대로 둠 | 날씨·공휴일·큐레이션 키워드가 자동으로 콘텐츠에 녹아든다는 것을 강조 |
| 5 | 감정 온도 슬라이더를 0→50→80으로 움직여 톤 설명 문구가 바뀌는 것 보여줌 (감성 일기 / 균형 유머 / 매운 풍자) | 온도 하나로 문체가 극단적으로 바뀌는 게 핵심 차별점 |
| 6 | "콘텐츠 생성하기" 클릭 → "AI가 콘텐츠를 쓰고 있어요" 로딩 (약 30~40초 소요) | 이 대기 시간엔 다음 talking point(3. Agent 협업 설명)로 자연스럽게 넘어간다 |
| 7 | 생성된 글, 해시태그, ❤️/💬/🔗 미리보기 확인 → "복사하기" 클릭 | 바로 SNS에 붙여넣을 수 있는 완성형 콘텐츠임을 강조 |
| 8 | (시간 되면) "AI 이미지 생성" 클릭해서 GPT Image 결과까지 보여줌 | 글+이미지가 한 세트로 나온다는 것 |

> 생성에 30~40초가 걸리므로, 6번 클릭 직후 바로 3번(Agent 협업 설명) talking point로 넘어가서 대기 시간을 자연스럽게 채운다.

## 3. Agent와 협업한 방식 설명 (1분)

> "문제 정의, 감정 온도 컨셉, 핵심 기능은 제가 직접 정했고, ChatGPT로 프롬프트 초안을 검증했습니다. 실제 개발은 Claude Code와 함께했는데, 특히 배포 후 문제가 생겼을 때 — '증상 설명 → 관련 코드 탐색 → 배포 주소에 실제 API 호출로 재현 → 원인 확인 → 수정 → 커밋·재배포'를 반복하는 방식으로 작업했습니다. 오늘 아침에도 이 방식으로 공휴일 API가 배포 환경에서 계속 타임아웃 나던 버그를 찾아서 고쳤습니다."

- 자세한 단계별 표는 [agent_collaboration.md](./agent_collaboration.md) 참고 (필요하면 발표 화면에 띄워서 보여줘도 됨)
- 강조 포인트: **의사결정(문제 정의·컨셉·기술스택)은 사람, 재현·진단·구현은 Claude Code**라는 역할 분담

## 리허설 메모

- 실제로 "환불 요청 속상해요" + 온도 80 + 인스타그램으로 끝까지 생성해봤고, 정상적으로 텍스트+해시태그가 나오는 것 확인함 (2026-07-30 기준).
- 생성 버튼을 누른 직후 페이지가 멈춘 것처럼 보일 수 있는데, 실제로 40초 정도 걸리는 정상 동작이니 시연 중 당황하지 않아도 됨.
- 백엔드가 완전히 식어 있으면(발표 시작 전 한동안 미접속) 첫 로딩에서 맥락 엔진이 "불러오는 중..."에 오래 머무를 수 있음 → 체크리스트의 "백엔드 미리 깨우기"가 중요.
