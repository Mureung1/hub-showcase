# 최종 데모 시연 시나리오 및 대본

본 문서는 실제 제출된 데모 영상(Scholar-sync AI.mp4)의 타임라인과 자막 대본을 기록한 스크립트임.

## 1. 서비스 개요
* **문제:** 매일 쏟아지는 방대한 학술 DB 속에서 내 연구 주제와 일치하는 핵심 논문을 찾고 요약하는 데 극심한 인지적 피로가 발생함.
* **타겟 사용자:** 문헌 조사가 필수적인 대학원생, 연구원 및 최신 동향을 파악하려는 엔지니어.

## 2. 시연 씬(Scene) 구성 및 자막 대본

* **[Scene 1] 서비스 소개 및 컨텍스트 세팅 (0:00 ~ 0:25)**
  * **액션:** 메인 화면 진입 -> 전공 및 관심 키워드 확인 -> 큐레이션 질문('Diffusion LLM') 세부 입력.
  * **자막 1:** "Scholar-sync AI는 내 관심사에 맞추어 논문을 추천해주는 서비스입니다."
  * **자막 2:** "우선 사용자는 전공, 관심 키워드, 학술 채널 입력 등을 통해 AI 에이전트에게 배경 컨텍스트를 제공합니다."
  * **자막 3:** "이후 큐레이션 질문을 세부적으로 입력할 수 있는 칸에 원하는 논문을 더 자세히 묘사할 수 있습니다."

* **[Scene 2] 2-Phase RAG 큐레이션 구동 및 아키텍처 설명 (0:26 ~ 0:56)**
  * **액션:** '큐레이션 시작' 클릭 -> 분석 프로그레스 바 진행 및 대기.
  * **자막 1:** "두 컴포넌트의 입력이 완료되면, 에이전트가 2-Phase RAG 기반의 큐레이션을 진행합니다."
  * **자막 2:** "Phase 1: Semantic Scholar API를 이용, 키워드를 기반으로 대량의 논문을 실시간 검색합니다."
  * **자막 3:** "Phase 2: 검색된 논문들을 Gemini 컨텍스트에 주입하여 연관성 점수를 매기고 3줄 요약을 생성합니다."
  * **자막 4:** "연관성 점수는 Originality, Validity, Generalizability(OVG)를 기준으로 산출하며,"
  * **자막 5:** "3줄 요약은 논문의 초록(Abstract)을 배경 / 방법론 / 결과 및 수치로 요약해 전달합니다."

* **[Scene 3] 결과 확인 및 로그인 연동 (0:57 ~ 1:23)**
  * **액션:** 큐레이션 완료 후 상위 5개 논문 리스트 스크롤 -> '내 서재 보관' 클릭 -> 로그인 필요 알림 -> 구글 소셜 로그인 진행.
  * **자막 1:** "검색이 완료되면 연관성 점수 상위 5개의 논문 및 요약을 확인할 수 있습니다."
  * **자막 2:** "관심 논문을 저장할 수도 있지만, 해당 기능에는 로그인이 필요합니다."

* **[Scene 4] 다국어 UI 지원 및 영문 큐레이션 재실행 (1:24 ~ 2:13)**
  * **액션:** 상단 'KO / EN' 언어 토글 클릭(UI 영문 전환) -> 영문 쿼리 입력 후 큐레이션 재실행 -> 영문 요약 결과 확인 -> 'Save Paper' 클릭하여 정상 보관.
  * **자막 1:** "Scholar-sync AI 서비스 UI는 영어로도 제공됩니다."
  * **자막 2:** "다시 새로운 논문의 큐레이션을 시도해보겠습니다."
  * **자막 3:** "사용자가 설정한 언어 설정에 따라 요약 언어도 변경됨을 확인할 수 있습니다."

* **[Scene 5] 내 서재 아카이빙 및 DB 연동 확인 (2:14 ~ 2:54)**
  * **액션:** 우측 하단 미니 서재 및 상단 'My Library' 탭 이동 -> 논문 삭제(Remove) 시연 -> 'View Paper' 클릭하여 Semantic Scholar 원문 새 탭 열기.
  * **자막 1:** "서재에 저장된 논문들은 우측 하단의 간단 메뉴나 My Library 페이지에서 확인하실 수 있습니다."
  * **자막 2:** "삭제나 원문 확인도 잘 동작함을 확인하실 수 있습니다."
  * **자막 3:** "논문은 고유 id - 유저 id의 쌍으로 이루어져 Supabase DB에서 관리됩니다."
  * **자막 4:** "이로서 Scholar-sync AI의 데모를 마치겠습니다. 시청해주셔서 감사합니다."
