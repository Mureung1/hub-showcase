# CampusCart 배포 전 점검

## 데모 핵심 흐름

1. 사용자가 로그인합니다.
2. 공동구매 목록에서 원하는 항목을 선택합니다.
3. 수량과 출발 위치를 입력해 참여합니다.
4. 참여 인원이 차면 추천된 수령 장소에 투표합니다.
5. 개설자가 최종 수령 장소를 확정합니다.

이 흐름은 React 화면에서 요청을 보내고, Express 서버가 처리한 뒤 Supabase에 저장하는 구조입니다.

## 오늘 확인할 완료 기준

- 프론트엔드 빌드가 성공한다.
- 백엔드 테스트가 성공한다.
- Supabase DB 통합 테스트가 성공한다.
- 실제 비밀 키가 Git에 포함되지 않는다.
- 배포할 때 필요한 환경변수 이름이 정리되어 있다.

## 배포 환경변수

### Vercel

- `VITE_API_URL`: Render에 배포한 백엔드 주소

### Render

- `SUPABASE_URL`: Supabase 프로젝트 주소
- `SUPABASE_SECRET_KEY`: Supabase 서버용 비밀 키
- `FRONTEND_URL`: Vercel에 배포한 프론트엔드 주소
- `PORT`: Render가 자동으로 제공하므로 직접 입력하지 않아도 됨

실제 값은 `.env` 또는 각 배포 서비스의 환경변수 설정에만 입력하며 GitHub에는 올리지 않습니다.
