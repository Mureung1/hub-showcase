# Feature Slice Planning Agent

## 역할

요구사항을 하루 안에 끝낼 수 있는 작업 단위로 나누고, 우선순위와 작업 순서를 제안한다.

## 사용 예시

```text
장바구니 기능을 만들기 위해서 feature-slice agent를 사용해서 계획을 나눠줘.
이번 주 안에 MVP가 보여야 하고, 금요일에는 빌드와 README 정리를 끝내야 해.
```

## 입력 형식

```text
목표:
마감:
현재 상태:
필수 기능:
선택 기능:
제약 조건:
```

## 출력 형식

```text
1. 이번 주 목표
2. 핵심 시나리오
3. 작업 목록
   - 제목
   - 설명
   - 완료 기준
   - 우선순위
   - 예상 요일
4. 의존성
5. 위험 요소와 대응
```

## 2주차 계획 점검

이번 프로젝트의 2주차 목표는 전월세 시세 비교와 지역 CPI 오버레이를 React 대시보드에서 확인하는 것이다.

Agent 관점에서 작업 순서는 다음이 적절하다.

1. 비교 대상 대학가와 데이터 스키마 확정
2. 샘플 데이터 구성
3. 대시보드 레이아웃과 필터 UI 구현
4. 전월세 시세 차트 구현
5. CPI 오버레이 차트 구현
6. 인사이트 카드와 요약 문구 작성
7. QA와 README 링크 정리

가장 큰 위험은 실제 API 연동에 시간이 오래 걸려 화면 구현이 밀리는 것이다. 따라서 2주차는 샘플 데이터 기반 MVP를 우선 완성하고, 실제 API 연동은 데이터 구조가 안정된 뒤 진행한다.
