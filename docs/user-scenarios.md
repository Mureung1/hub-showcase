# 사용자 시나리오 (User Scenarios)

> `ai-briefing-service` 기획 문서. 문제 정의(정보를 놓침 + 따라잡는 시간 비용)를 바탕으로, MVP 범위에 얽매이지 않고 넓은 범위에서 도출한 사용자 시나리오. 이후 UI/UX 화면 설계의 근거로 사용한다.
>
> **용어** — 각 시나리오의 **"사용 기능"** = 그 상황을 수행할 때 화면에서 실제로 쓰이는 기능 목록.

## 페르소나
**한지우** — LLM 응용을 다루는 연구자 겸 개발자. arXiv·SNS·뉴스의 정보량에 압도됨. 가장 큰 고통 = ① 중요한 걸 놓침 ② 따라잡는 시간 비용.

---

## S1. 아침 데일리 브리핑 — "밤새 뭐 나왔지?"
- **트리거**: 매일 아침 업무 시작, 커피 한 잔 하며 5분.
- **목표(JTBD)**: 밤새 나온 논문 중 중요한 것을 짧은 시간에 놓치지 않고 훑기.
- **화면 구성 (오늘의 브리핑 피드)**:
  - 상단: 날짜 헤더 + "오늘 N편 수집" + 카테고리 탭(전체/추론/에이전트/…).
  - 본문: 논문 카드 목록. 카드 = 제목(영문+한글 병기) · **한줄 요약** · 주제 태그 · **중요도 배지** · 저장(북마크) 버튼.
  - 정렬: 기본 중요도순(향후: 인용·화제성 기반).
- **동작 흐름**: 접속 → 피드 스캔 → 관심 카드 2~3개 클릭 → 한국어 요약 패널 확인 → 나중에 볼 것 저장.
- **사용 기능**: 데일리 피드, 카드 한줄 요약, 중요도 정렬, 저장(북마크).
- **핵심 가치**: 놓치지 않기.

## S2. 주제 검색 — "RAG 최신 동향만 모아줘"
- **트리거**: 새 프로젝트/과제 착수로 특정 기술을 조사해야 함.
- **목표(JTBD)**: 특정 키워드·주제의 최신 논문을 빠르게 찾아 비교.
- **화면 구성 (검색 결과 페이지)**:
  - 상단: 검색창(키워드 입력) — 예 `retrieval augmented generation`.
  - 좌측: 필터 사이드바 — **기간**(최근 1주/1개월/직접), **카테고리(주제 태그)**, **추가 키워드**.
  - 본문: 결과 목록(매치 하이라이트) + 각 항목 요약 미리보기.
  - 상세 하단: **"이 논문과 관련된 논문"** 추천.
- **동작 흐름**: 키워드 입력 → 결과 목록 → 필터로 좁히기 → 요약 비교 → 관련 논문 추천 타고 확장.
- **사용 기능**: 검색, 필터(기간/카테고리/키워드), 요약 미리보기, 관련 논문 추천.
- **핵심 가치**: 필요할 때 탐색.

## S3. 카테고리 브라우징 & 트렌드 — "요즘 뜨는 주제는?"
- **트리거**: 주간 회고, 분야 큰 그림 파악, 무엇을 공부할지 결정.
- **목표(JTBD)**: 분야별 흐름과 **급부상 주제** 인지 (나무가 아닌 "숲" 보기).
- **화면 구성 (주간 트렌드 대시보드)** — 개별 논문이 아닌 **집계·시각화** 화면:
  1. **주제별 논문 수** (막대/영역 차트): 이번 주 '에이전트' 42편, '추론' 38편, '멀티모달' 25편… → 어떤 주제가 활발한지.
  2. **급상승 키워드** (전주 대비 증가율): 예 `test-time compute ↑210%`, `MoE ↑90%` → "요즘 뜨는" 포착.
  3. **주간 하이라이트**: 그 주 가장 화제가 된 논문 3~5편 카드.
- **카테고리 드릴다운** (넓게 → 세부로 좁혀 보기):
  ```
  [전체 트렌드 대시보드]      ← 모든 카테고리 개요
     │  '에이전트' 카테고리 클릭
     ▼
  [에이전트 카테고리 페이지]   ← 그 주제 논문만 필터 + 미니 트렌드
     │  특정 논문 클릭
     ▼
  [논문 상세 보기]            ← S4로 연결
  ```
- **참고**: 여기서 "카테고리"는 arXiv 원분류(cs.CL 등)가 아니라 **LLM이 논문 내용을 보고 자동으로 붙인 주제 태그**(추론·에이전트·멀티모달·효율화·안전성 등). 기획서의 "카테고리 자동 분류"(향후 확장)가 생성.
- **사용 기능**: 카테고리 자동 분류, 트렌드 집계·시각화, 드릴다운, 주간 요약.
- **핵심 가치**: 트렌드 파악.

## S4. 심층 탐구 + 스크랩 + 공유 — "제대로 읽고 팀에 공유"
- **트리거**: 중요 논문 발견, 깊이 이해 및 지식화 필요.
- **목표(JTBD)**: 요약으로 판단한 뒤 원문까지 파고들고, 저장·공유.
- **화면 구성 (논문 상세 페이지)**:
  - 헤더: 제목 · 저자 · 날짜 · 주제 태그 · **arXiv/PDF 원문 링크**.
  - 본문: **구조화 요약** — 핵심 기여 / 방법 / 결과 / **배경(맥락) 설명** + **원문 초록 병기(토글)** 로 검증 가능.
  - 액션바: **북마크 · 메모 · 공유**.
- **동작 흐름**: 상세 진입 → 구조화 요약으로 판단 → 원문(arXiv/PDF) 이동해 정독 → 북마크+메모로 지식화 → 팀에 링크 공유 또는 주간 다이제스트 구독.
- **사용 기능**: 상세 보기, 배경 설명, 원문 링크, 북마크·메모, 공유/구독.
- **핵심 가치**: 깊이 있는 이해 + 지식 축적.

| 시나리오 | 핵심 가치 | 사용 기능 |
|---|---|---|
| S1 데일리 브리핑 | 놓치지 않기 | 피드, 카드 요약, 중요도 정렬, 저장 |
| S2 주제 검색 | 필요할 때 탐색 | 검색, 필터, 요약 미리보기, 관련 추천 |
| S3 카테고리·트렌드 | 트렌드 파악 | 자동 분류, 트렌드 시각화, 드릴다운, 주간 요약 |
| S4 심층·공유 | 깊이·지식화 | 상세, 배경설명, 원문 링크, 북마크/메모, 공유 |
