2주차 데모

교재는 멈춰있고,
개념은 단계마다 바뀐다.

전공별 시각화 학습 플랫폼은 정해진 규칙에 따라 상태가 단계마다 바뀌는 절차형 지식과, 직접 조작해봐야 감이 오는 조작형 지식을 코드·시각화와 동기화해 눈으로 재생하고 손으로 확인하는 학습 도구입니다. 특정 학과가 아니라 개념의 성격에 반응하도록 설계해, 컴퓨터공학과 화학을 시작으로 다른 전공까지 확장 가능합니다.

문제의식. 자료구조·알고리즘·분자구조처럼 단계마다 상태가 순차적으로 변화하는 개념은, 교재의 정적인 텍스트와 그림만으로는 각 단계에서 값이 실제로 어떻게 바뀌는지 확인할 수 없어 직관적으로 이해하고 오래 기억하기 어렵습니다.

핵심 기능은 두 갈래

학습 개념도 두 갈래로 나뉩니다 — 지켜봐야 이해되는 것과, 직접 조작해야 감이 오는 것. 두 엔진은 각각의 갈래에 대응하며, 특정 전공이 아니라 개념의 성격에 반응하도록 설계했습니다.

기능 A

코드-시각화 동기화 재생

정해진 규칙에 따라 상태가 한 단계씩 바뀌는 절차를 자동 재생하며, 코드(또는 반응식) 하이라이트와 시각화를 동기화합니다. 재생 · 한 단계 · 처음부터 · 속도 조절, 같은 컨트롤로 정렬이든 화학 반응이든 "왜 이 상태가 됐는지"를 눈으로 따라갑니다.

정렬 · 트리 · 유기화학 반응 멘토
기능 B

사용자 조작형 인터랙티브 시뮬레이터

값을 직접 입력하고 조작해서 결과를 즉시 확인하며 체득합니다. 정해진 절차를 지켜보는 게 아니라, 조작 가능한 대상을 자유롭게 건드려보며 규칙을 스스로 발견하는 방식입니다.

스택 · 큐 · 덱
차별화 기능

화면 상태를 정확히 아는 AI Q&A

시각화 도구 자체는 이미 여러 서비스가 제공합니다. 차별점은 "시각화가 있다"가 아니라, 기능 A가 매 단계마다 만들어내는 판단 과정 설명을 그대로 재활용해, 지금 화면에 정확히 무엇이 일어나는지 아는 AI에게 바로 물어볼 수 있다는 것입니다.

tree-binary.tsx · AI Q&A
왜 오른쪽으로 가야 해?
지금 40과(와) 30을(를) 비교하고 있어요 — 40 ≥ 30이므로 오른쪽 자식으로 이동합니다.
context = step.description · 범용 챗봇이 흉내낼 수 없는, 그 순간의 정확한 판단 근거

Gemini API 키는 클라이언트에 노출하지 않고 Express 백엔드가 대신 호출합니다. API 장애 시에도 안내 문구만 표시될 뿐, 시각화 자체(기능 A/B)는 100% 독립적으로 정상 동작합니다.

실제 구현 범위

컴퓨터공학과 5개 + 화학과 2개, 총 7개 화면이 실제로 동작합니다.

정렬 스택 큐 덱 트리 일반화학 · 분자 뷰어 유기화학 · 반응 멘토
컴퓨터공학과정렬 4종, 스택·큐·덱, 이진/완전/편향 트리 화학과SMILES 2D/3D 분자 뷰어, SN2·마르코니코프·에스테르화·E2 반응 메커니즘
2주차 성과

로그인 → 홈 → 시각화 → AI Q&A → 답변

하나의 기능을 끝까지 완성한다는 목표로, 화면·서버·DB가 실제로 한 바퀴 도는 것까지 확인했습니다.

로그인 / 회원가입
Supabase Auth 실제 연동. 아이디+비밀번호만 사용하고, 로그인은 선택 — 안 해도 시각화는 자유롭게 이용 가능합니다.
AI Q&A 실 연동
mock이 아닌 Gemini API 실제 연동. 지금 화면에 뭐가 떠 있는지(예: "50을 루트로 삽입 중")를 함께 전달해 답합니다.
DB 저장 / 조회
질문·답변이 Supabase qna_logs 테이블에 저장되고, 새로고침해도 대화 기록이 그대로 다시 로드됩니다.
전 페이지 적용
정렬 · 스택/큐/덱 · 트리 · 일반화학 · 유기화학, 7개 화면 전부에서 AI Q&A를 쓸 수 있습니다.
위치 고정 + 드래그
AI Q&A 창은 어느 페이지든 항상 우측 하단에서 시작하고, 마우스로 원하는 곳에 옮겨둘 수 있습니다.

아키텍처

브라우저가 Supabase와 직접 통신하고, Gemini 호출만 Express가 대신합니다.

데모 시연 순서

01
앱 접속 — 로그인 없이 홈페이지가 바로 보임헤더 우측 "로그인" 클릭 → 회원가입 → 자동으로 홈페이지 이동
02
홈페이지에서 트리 메뉴 클릭 → 트리 시각화 화면 진입
03
편향트리 선택 → 한 단계 버튼으로 삽입 과정 진행
04
AI Q&A 열어보기 클릭 → 우측 하단에 패널 등장
05
"지금 화면에서 뭘 하고 있어?" 질문 → 현재 스텝 설명을 반영한 Gemini 답변
06
새로고침 → 방금 나눈 대화가 그대로 재로드 (저장 → 조회 확인)
07
(선택) 정렬 · 화학 페이지로 이동 → 각 화면에 맞는 컨텍스트로 AI Q&A 동작
08
로그아웃 클릭 → "로그인" 링크로 전환 확인
로그인부터 AI 답변, DB 저장까지 — 실제로 도는 하나의 완성된 기능 흐름을 보여드립니다.
