# 대학생 자취방 의사결정 도우미 (가칭)

## 프로젝트 소개

대학생이 계약하려는 자취방을 AI가 다양한 관점에서 분석하여, 보다 합리적인 의사결정을 할 수 있도록 돕는 웹서비스입니다.

기존 부동산 플랫폼은 **매물을 찾는 것**에 집중되어 있지만, 이 프로젝트는 **계약해도 괜찮은 매물인지 판단하는 것**에 초점을 맞춥니다.

---

# 문제 정의

대학생은 자취를 처음 시작하는 경우가 많아 부동산 계약 경험이 부족합니다. 이로 인해 정보의 비대칭성으로 다양한 문제가 발생합니다.

* 시세 대비 가격이 적절한지 판단하기 어렵다.
* 관리비가 적정한 수준인지 알기 어렵다.
* 계약 시 어떤 조항을 확인해야 하는지 모른다.
* 온라인 매물이 실제 존재하는 매물인지 판단하기 어렵다.
* 월세 외에도 통학시간, 교통비 등 숨겨진 비용을 고려하기 어렵다.

> **즉, 매물을 찾는 것보다 '이 매물을 계약해도 되는가'를 판단하는 것이 더 어려운 문제입니다.**

---

# 해결 방법

사용자가 자신의 정보와 검토 중인 매물 정보를 입력하면 AI가 여러 관점에서 매물을 분석하고 의사결정을 지원합니다.

분석 항목은 다음과 같습니다.

* 시세 대비 가격 적정성 분석
* 관리비 적정성 검토
* 허위매물 가능성 분석
* 통학시간 및 교통비 분석
* 생활 편의성 분석
* 계약 전 반드시 확인해야 할 체크리스트 제공
* AI 종합 의견 제공

통학시간과 이동 거리 분석은 카카오 지도 API를 사용한다. 서버 환경변수 `KAKAO_REST_API_KEY`가 설정되어 있으면 매물 주소와 학교 좌표를 기준으로 도보/대중교통 이동 정보를 계산하고, API 키가 없거나 주소 좌표를 찾지 못하면 AI 분석은 계속 진행하되 지도 기반 계산은 생략한다.
