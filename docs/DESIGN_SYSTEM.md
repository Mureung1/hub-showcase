# 자취방 청결관리사 · 디자인 시스템

핵심 기능 화면(체크인·프로브 → 가설 카드 → AI 재검증 → 세션 종료)을 일관되게 개발하기 위한 단일 기준. 개발 Agent와 사람 모두 이 문서를 기준으로 UI를 만든다.

## 1. 컨셉

> "청소 직후의 물기 있는 타일" — 차가운 청록으로 청결·신뢰를 말하고, 앰버·코랄로 이상 신호를 짚는다.

이 앱은 "게으른 자취생"을 위한 것이므로, 화면은 **한 번에 한 가지 판단만** 요구한다. 정보를 쌓아 보여주지 않고, 탭 한 번으로 다음으로 넘어가게 한다.

## 2. 컬러 — 의미 단위로 쓴다

raw hex를 직접 쓰지 말고 아래 의미 매핑을 따른다. (값은 `tokens.css` / `tokens.js`)

| 의미 | 토큰 | 언제 쓰나 |
|---|---|---|
| 브랜드 액션 | `mint` / `mint-deep`(hover) | 기본 버튼, 활성 상태 |
| 양호·괜찮음 | `mint` + `mint-wash` | 프로브 "괜찮음", 양호 pill |
| 이상 신호·가정 | `amber` + `amber-wash` | 침묵 알림 🔔, "가정하고 진행" 점선 박스 |
| 문제·이의제기 | `alarm` + `alarm-wash` | 프로브 "문제 있음", AI 재검증 이의 박스 |
| 텍스트 | `ink`(제목) / `ink-soft`(보조) | 전 화면 공통 |
| 배경 | `paper`(앱) / `tile`(카드) | 레이아웃 |

**규칙:** 한 화면에서 강조색(민트/앰버/코랄)은 **한 가지 역할당 하나만.** 앰버와 코랄을 같은 화면에서 남발하면 "무엇이 급한지" 신호가 죽는다.

## 3. 타이포

| 역할 | 크기/굵기 | 용도 |
|---|---|---|
| Display | 23 / 800 | 화면 제목 ("같이 원인을 찾아봐요") |
| Title | 15 / 700 | 카드 제목 (가설명) |
| Body | 14 / 400 | 본문·대화 |
| Caption | 12 / 600 | 라벨·버튼·pill |
| Eyebrow | 11 / uppercase / letter-spacing .14em | 화면 상단 분류 ("문제 발생 · 턴제 진단") |

Eyebrow는 항상 민트색이며 앞에 짧은 민트 바(`—`)를 둔다. 이게 "지금 어느 단계인지"를 알려주는 시그니처 요소다.

## 4. 컴포넌트 스펙

핵심 4개 컴포넌트. 개발 시 이 규칙대로 만든다.

### ProbeCard (프로브)
- 배경: `mint-wash`→흰색 그라데이션, 테두리 `mint`
- 응답 버튼 3개(👍/👀/🔧)는 **동일 너비**, 탭 시 각각 mint/amber/alarm wash로 반응
- 질문은 1줄, 그 아래 회색 보조설명 1줄. 그 이상 길어지면 안 됨(1탭 원칙)

### HypothesisCard (가설 카드)
- 흰 배경, `radius-md`, `shadow-card`
- 상단: 좌측 "가설 N · 가장 유력"(민트), 우측 confidence 표시
- **confidence는 숫자가 아니라 "유력/보통" 질적 라벨 + 짧은 바로 표현** (틀린 확신 방지 — 기획서 6장 리스크 반영)
- 하단 버튼 3개: 완료(민트 hover) / 해당없음(중립) / 사진확인(앰버 hover)

### AssumeBox ("가정하고 진행")
- `amber-wash` 배경 + **점선** 테두리 `amber` → "확정 아님, 가정"임을 시각적으로 구분
- 실선 카드(가설)와 반드시 다르게 보여야 함

### DisputeBox (AI 재검증 이의)
- `alarm-wash` 배경, 테두리 `alarm`
- 상단 "⚠ 이의 제기" 태그, 어긋난 근거를 `alarm`색 볼드로 강조
- 톤은 비난이 아니라 조력 — "~하면 재발이 줄어요" 식 (기획서 열린질문: 재검증 강도)

## 5. 간격·모양

- 간격은 4px 그리드(`space-1~6`)만 사용
- 카드 radius `16`, 시트·프로브 `20`, 버튼 `11`
- 그림자는 카드용/플로팅용 2종만

## 6. 접근성 (품질 바닥)

- 키보드 포커스 항상 보이게
- `prefers-reduced-motion` 존중 (토큰에 반영됨)
- 탭 타깃 최소 44px
- 강조색만으로 의미 전달하지 않기 (아이콘·텍스트 병행 — 색약 대응)

## 7. Export 사용법

- **CSS 프로젝트**: `tokens.css` import → `var(--color-mint)` 사용
- **React 프로젝트**: `import tokens, { semantic } from './tokens'` → `tokens.color.mint`
- 두 파일의 값은 **항상 동일**해야 함. 색을 바꾸려면 둘 다 고친다(추후 빌드 스크립트로 자동화 가능).
