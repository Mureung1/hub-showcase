# ADR 0003. 커뮤니티 요약 방식의 그래프 검색을 기본 경로에서 제외한다

## 맥락

그래프 기반 검색에는 두 가지 접근이 있다. 하나는 자유 추출로 그래프를 만들고 군집을 탐지해 군집별 요약을 생성하는 방식이고, 다른 하나는 노드와 엣지 유형을 고정한 온톨로지로 추출을 제한하는 방식이다.

커뮤니티 요약 방식의 산출물은 집단의 주제 요약이다.

## 결정

기본 검색 경로는 온톨로지 고정 방식을 사용한다. 커뮤니티 요약 방식은 기본 경로에 포함하지 않는다.

- 노드와 엣지 유형은 `ontology_versions`에 등록한 목록으로 제한한다.
- 등록되지 않은 유형과 허용되지 않은 연결은 폐기한다.
- 그래프 탐색은 다단계 관계 조회에만 사용한다.

## 고려한 선택지

| 선택지 | 결과 |
| --- | --- |
| 커뮤니티 요약 | 집단 주제 요약을 생성한다. 전처리 비용과 조회 지연이 크고 인덱스가 초선형으로 증가한다 |
| 온톨로지 고정 | 관계 유형이 명확하고 조회가 결정적이다. 유형 확장에 버전 발행이 필요하다 |
| 자유 추출 후 사후 정규화 | 노드가 폭발하고 정규화 품질을 검증하기 어렵다 |

## 선택 이유

집단의 주제 요약은 통계 분석 에이전트가 이미 생성한다. 같은 질문에 두 산출물이 존재하면 값이 어긋날 때 판정 기준이 없다. 통계는 전수 집계라 재계산으로 검증할 수 있고 요약은 생성 결과라 검증이 어렵다. 검증 가능한 쪽을 남긴다.

CareerSignal의 노드와 관계 유형은 이미 명확하다. 요구, 역량, 표준, 증명 산출물, 활용처, 학습 자료, 체크리스트의 연결이 도메인에서 정해져 있다. 유형 제약으로 잘못된 엣지를 차단할 수 있고, 추천에서 근거로 이어지는 경로를 결정적으로 조회할 수 있다.

## 결과와 제약

- 새 관계 유형이 필요하면 온톨로지 버전을 발행한다.
- 군집 수준의 서술은 통계 지표와 해석 주장이 담당한다.
- 커뮤니티 요약 방식은 비교 평가의 대상으로 남긴다.
