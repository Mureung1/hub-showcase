# ADR

ADR(Architecture Decision Record)은 되돌리기 어렵거나 이후 작업에 영향을 주는 기술·제품 결정을 기록한다.

## 작성 기준

ADR은 다음 경우에 작성한다.

- 생산용 기술 스택을 정할 때
- DB, 배포, 인증, LLM 공급자처럼 교체 비용이 큰 결정을 할 때
- MVP 범위와 Phase 2 범위를 바꾸는 결정을 할 때
- 플랫폼 자동 수집·자동 게시처럼 리스크가 큰 기능을 도입할 때

## 형식

```text
# ADR-0000 — 제목

상태: 제안됨 | 채택됨 | 대체됨
날짜: YYYY-MM-DD

## 맥락
왜 결정이 필요한가.

## 결정
무엇을 선택했는가.

## 결과
좋아지는 점, 감수해야 하는 점, 후속 작업.

## 대안
검토했지만 선택하지 않은 안.
```
