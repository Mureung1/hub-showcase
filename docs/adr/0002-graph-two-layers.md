# ADR 0002. 지식 그래프를 의미 층과 계보 층으로 나눈다

## 맥락

그래프는 두 종류의 질문에 답한다. 하나는 직무 지식이 어떻게 연결되는지이고, 다른 하나는 특정 산출물이 어떤 자료에서 만들어졌는지다.

두 질문을 한 층에 담으면 원문 표현과 정규화된 개념이 같은 그래프에 섞인다. 표현이 다른 동일 개념이 별개 노드로 남아 관계 탐색의 결과가 중복된다.

## 결정

그래프를 두 논리 층으로 나누고 `graph_layer` 속성으로 구분한다.

- Semantic Knowledge Graph는 정규화가 끝난 도메인 관계만 담는다.
- Provenance Lineage Graph는 산출물의 생성 경로를 담는다.
- 원문 표현에서 차원으로 이어지는 정규화는 계보이므로 Provenance 층에 기록한다.
- 노드와 엣지 유형은 `ontology_versions`에 등록한 목록으로 제한한다.

## 고려한 선택지

| 선택지 | 결과 |
| --- | --- |
| 단일 그래프 | 원문 표현과 정규화 개념이 섞여 탐색 결과가 중복된다 |
| 그래프와 관계형 테이블로 분리 | 계보 조회가 두 저장 방식을 오가며 경로 추적이 끊긴다 |
| 두 논리 층 | 탐색은 의미 층에서, 근거 추적은 계보 층에서 수행하고 두 층을 연결해 전체 경로를 얻는다 |

## 선택 이유

의미 탐색은 정규화된 개념 위에서 수행해야 결과가 중복되지 않는다. 근거 추적은 정규화 이전의 원문 표현까지 내려가야 원문 문장에 도달한다. 두 요구가 상충하므로 층을 나눈다.

로드맵 항목에서 공고 원문까지의 경로는 두 층을 잇는 계보 경로다.

## 결과와 제약

- 노드와 엣지 유형이 두 층으로 나뉘어 등록 대상이 늘어난다.
- 전체 근거 경로 조회는 두 층을 연결해야 한다.
- `graph_paths`는 캐시이며 진실의 원천은 `knowledge_edges`다.
- 경로 캐시 키에 분류체계, 지식, 분석, 그래프 정책 버전을 포함한다.
