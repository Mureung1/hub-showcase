# ADR 0004. 자료 계층과 허용 용도를 검증 단계에서 강제한다

## 맥락

자료 계층은 품질의 단일 순서가 아니라 허용 용도의 구분이다. 외부 전문가 자료는 준비 방법과 면접 관점에 유용하지만 기업의 요구 빈도 근거로 사용하면 통계가 왜곡된다.

문서에만 정책을 기술하면 실행 중 위반을 발견할 수 없다.

## 결정

허용 용도를 데이터로 저장하고 검증 단계에서 자동으로 검사한다.

- `source_assessments.allowed_uses`가 자료별 허용 용도를 담는다.
- 검증의 자료 정책 검사가 허용되지 않은 용도의 근거를 차단한다.
- 위반한 주장은 낮은 신뢰도로 유지하지 않고 폐기한다.
- 검사 결과는 `reason_code`와 함께 기록한다.

## 고려한 선택지

| 선택지 | 결과 |
| --- | --- |
| 문서 규칙만 유지 | 위반을 사람이 표본 점검으로만 발견한다 |
| 프롬프트에 제약 서술 | 생성 결과가 제약을 지키는지 보장할 수 없다 |
| 데이터와 검증으로 강제 | 위반이 실행 중에 차단되고 기록이 남는다 |

## 선택 이유

진로 조언은 사용자가 실제 학습 계획으로 옮기는 정보다. 근거의 출처가 잘못된 결과의 비용이 크다. 정책을 데이터로 저장하고 검사로 강제하면 규모가 커져도 일관성이 유지된다.

## 결과와 제약

- 자료 평가가 없는 스냅샷은 근거로 사용할 수 없다.
- 평가 기준 변경은 새 `assessment_version`으로 다시 평가한다.
- 회사 공식 자료의 근거는 요구 차원에 직접 연결하지 않고 분석 주장의 지지 근거로 연결한다.
