# ADR 0009. 제3자 자료의 편입을 신뢰도 점수로 판정한다

## 맥락

준비 전략과 준비 로드맵의 근거는 제3자 자료에서 온다. 편입 기준을 작성자와 전문성 확인에 두면 공개 자료의 상당수가 걸러진다. 국내 공개 자료는 작성자와 경력을 페이지에 드러내지 않는 것이 많다.

확인하지 못한 자료를 E 계층에 두면 허용 용도가 없어 저장해도 사용하지 못한다. 근거가 모이지 않으면 준비 전략과 로드맵 화면에 표시할 내용이 없다.

`source_assessments.reliability_score`는 스키마에 있으나 채워지지 않는다.

## 결정

D 계층의 편입을 출처 확인이 아니라 내용 판정으로 결정한다.

- 편입 판정의 기준은 내용이 직무 요구와 이어지는지와 주장이 검증 가능한 형태인지다.
- 판정 결과를 `source_assessments.reliability_score`에 0과 1 사이 값으로 기록한다.
- 작성자와 게시일은 확인되면 기록하고 확인되지 않아도 편입을 막지 않는다.
- E 계층은 원문을 확인할 수 없거나 내용이 직무 요구와 이어지지 않는 자료에 남는다.
- 통계 집계의 경계는 바뀌지 않는다. D 계층은 통계에 들어가지 않는다.

## 고려한 선택지

| 선택지 | 결과 |
| --- | --- |
| 작성자 확인을 유지 | 근거 표본이 모이지 않아 준비 전략과 로드맵이 비어 있다 |
| 계층 구분을 폐기 | 제3자 자료가 통계에 섞여 기업의 요구 빈도 주장이 무너진다 |
| 내용 판정과 신뢰도 기록 | 근거가 늘고 신뢰도가 낮은 근거를 노출 단계에서 거른다 |

## 선택 이유

출처 확인은 신뢰의 대리 지표다. 내용 판정과 신뢰도 기록이 같은 목적을 더 넓은 자료에서 달성한다.

통계 경계를 유지하면 제3자 자료가 늘어도 기업 요구의 집계는 채용공고 원문에서만 나온다. 넓히는 범위와 지키는 범위가 분리된다.

## 결과와 제약

- 신뢰도가 기록되지 않은 D 계층 자료는 근거로 사용하지 않는다.
- 신뢰도 판정 기준이 바뀌면 새 `assessment_version`으로 다시 평가한다.
- 근거 함의 검증과 교차 모델 표본 감사가 구현되기 전까지 신뢰도 점수가 잘못된 조언을 막는 유일한 수단이다.
- 신뢰도는 자료 단위의 값이며 개별 주장의 신뢰도와 다르다. 주장의 신뢰도는 [에이전트 설계](../agent-design.md)의 신뢰도 정책을 따른다.
