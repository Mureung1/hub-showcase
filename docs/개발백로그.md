# 개발 백로그

- 문서 상태: 2주차 개발 착수 전 초안
- 최종 수정일: 2026-07-10
- 참고: [서비스 기획서](../서비스%20기획서.md) §9 기능 도입 순서

## 백로그란

앞으로 해야 할 작업을 우선순위 순으로 정리해 둔 목록이다. 스프린트를 시작하기 전에 "무엇을, 언제, 왜" 할지 미리 정해두면 개발 중간에 범위가 흔들리지 않는다. 진행하면서 계속 갱신하는 살아있는 문서이며, 완료된 항목은 상태를 바꾸고 새로 발견된 작업은 우선순위를 매겨 추가한다.

## 우선순위 기준

| 등급 | 의미 |
|---|---|
| P0 | 기반 작업. 이게 없으면 다른 작업도 진행할 수 없음(백엔드, DB, 인증 등) |
| P1 | 이번 4주 스프린트 안에 반드시 끝내야 하는 핵심 기능 |
| P2 | 여유가 있으면 진행, 없으면 다음 스프린트로 미룸 |

## Task 목록

### P0 — 기반 작업

| # | Task | 설명 | 현재 상태 |
|---|---|---|---|
| 1 | 백엔드 구현 (API) | React 프론트와 통신할 REST API 서버 기본 구조 (Express) | 미착수 — 지금은 프론트 mock 데이터만 있음 |
| 2 | DB화 | 일정/카테고리/친구/게시물/반응 스키마 설계 및 실제 DB 연결 | 미착수 |
| 3 | 회원가입·로그인 (인증) | 실제 사용자 계정 개념 도입, 세션/토큰 인증 | 미착수 — 지금은 사용자가 1명(mock)뿐이라 "친구" 개념 자체가 성립 안 함 |
| 4 | 인증 영상 업로드·저장 | 프론트에서 찍은 영상을 서버/스토리지에 실제 저장 | 미착수 — 지금은 브라우저 메모리 blob URL이라 새로고침하면 사라짐 |
| 5 | 인증 영상 코멘트 기능 | 인증 피드에 댓글 작성·조회 | 미착수 — 눈빛 반응만 있고 댓글은 없음 |

### P1 — 이번 스프린트 핵심 기능

| # | Task | 설명 | 현재 상태 |
|---|---|---|---|
| 6 | 친구 및 그룹 관리 | 친구 추가/삭제/검색, 절친·스터디·가족·커플 그룹 생성·편집 | 미착수 — 지금은 친구 3명이 데이터에 고정 |
| 7 | 친구 마이홈 방문 | 친구의 두두·마이홈을 방문해서 구경/반응 | 미착수 — 친구 캘린더 열람은 있지만 마이홈 방문은 없음 |
| 8 | 프로필 고도화 | 프로필 실제 편집(이름/소개/사진), 달성 기록 실데이터 연동 | 미착수 — 지금 마이페이지는 정적 mock |
| 9 | 두두 행동 및 일기 알고리즘 | 완료한 활동 데이터를 기반으로 두두의 상태·행동, 오늘의 일기 문장을 실제로 생성 | 미착수 — 지금은 마이홈 기분·말풍선 문구가 고정 텍스트 |

### P2 — 여유 있으면

| # | Task | 설명 |
|---|---|---|
| 10 | 푸시 알림 | 일정 임박, 친구 반응·댓글 알림 |
| 11 | 일정 추억 장면 | 친구와 함께한 일정 완료 시 캐릭터 단체 장면 자동 생성 |
| 12 | 위시 리스트 룰렛 | 친구와 하고 싶은 일을 등록하고 두두가 무작위로 다음 활동 선정 |
| 13 | 집중 동행 | 친구와 같은 시간에 집중 타이머 동시 진행 |

### 기타 (기능 외 필요 작업)

| # | Task | 설명 |
|---|---|---|

## 4주 스프린트 일정 (2주차~5주차)

| 주차 | 목표 | Task |
|---|---|---|
| 2주차 | 백엔드/DB 기반 세팅 | 1(백엔드 구현), 2(DB화) — **다음 주까지: API 서버 기동 + 스키마 설계 완료, 일정 CRUD API 최소 1개 동작 확인** |
| 3주차 | 인증 + 영상 저장 | 3(회원가입·로그인), 4(영상 업로드·저장) — 프론트 mock 데이터를 실제 API 연동으로 교체 시작 |
| 4주차 | 소셜 기능 붙이기 | 5(인증 영상 코멘트), 6(친구·그룹 관리), 7(마이홈 방문) |
| 5주차 | 두두 알고리즘·프로필 마무리 + 정리 | 8(프로필 고도화), 9(두두 행동·일기 알고리즘), 15(배포), 16(에러/로딩 처리) — 버퍼 겸 발표 준비, 여유 있으면 10(푸시 알림)도 시도 |

P2 항목(10~14)은 5주차까지 여유가 있을 때만 진행하고, 못 하면 다음 스프린트 백로그로 이월한다.
