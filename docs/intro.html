하루 체크아웃

정리되지 않은 감정을 날것 그대로 입력하면, AI가 감정·원인·다음 행동으로 구조화해주는 대학생용 하루 체크아웃 도구

1문제 정의

대학생의 정신건강 위기

학업과 취업 준비로 정신적 어려움을 겪는 대학생은 늘고 있으나 도움 통로는 제한적입니다.

  • 상담 이용에 대한 심리적 부담(낙인)도 여전함
  • 학업·팀플·취업 준비가 겹치며 매일 스트레스가 쌓이지만, 하루 끝에 이를 정리할 방법이 마땅치 않음
  • 힘든 날일수록 기록이나 상담 같은 행동은 오히려 부담스러워 건너뛰게 됨

기존 도움 통로의 한계

  • 교내 학생상담센터: 무료지만 인력 부족으로 대기 수개월 (일부 대학 대기 ~5개월, 상담사 1인당 학생 2,000~5,000명 / 적정 비율은 500명당 1명)
  • 공공 지원(심리상담 바우처, 청년 마음건강 지원사업): 존재하지만 의뢰서 발급 등 절차가 복잡해 학생이 스스로 찾아 이용하기 어려움

그 결과 많은 학생이 AI 챗봇에 고민을 털어놓지만, 일반 챗봇은 과도하게 동조(sycophancy)하고 대화가 휘발되어 자기 상태를 축적적으로 파악하기 어렵습니다.

3타 서비스와의 차별점

구분 감정일기 앱 일반 AI 챗봇 하루 체크아웃
AI의 역할 없음 (단순 기록) 조언·공감·대화 위주 조언·진단·위로 금지, 정리만 (출력 형식 고정)
동조 편향 해당 없음 사용자에게 과도하게 동조(sycophancy)하는 경향 고정된 출력 형식으로 동조 편향 차단
기록의 지속성 기록은 쌓이지만 패턴 분석 없음 대화가 휘발되어 자기 상태를 축적적으로 파악하기 어려움 기록 누적 → 반복 감정/상황 패턴 표시
실제 지원 연결 없음 없음 반복 신호 시 교내 상담센터·심리상담 바우처 안내 연결
