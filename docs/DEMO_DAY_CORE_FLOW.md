# 데모데이 핵심 사용자 흐름

## 공통 메시지

### 문제

자취생은 냉장고에 재료가 있어도 무엇을 만들지 결정하기 어렵고, 소비기한이
가까운 재료를 놓치기 쉽다.

### 해결

`있는대로`는 보유 재료와 소비기한, 오늘의 조리 상황을 바탕으로 지금 만들 수
있는 1인분 메뉴를 추천한다.

### 한 문장 가치

**냉장고 속 재료를 확인하는 순간부터 오늘의 메뉴와 조리 순서까지 한 흐름으로
연결한다.**

## 데모의 핵심 사용자

- 혼자 식사를 준비하는 자취생
- 냉장고에 재료는 있지만 메뉴 결정을 미루는 사람
- 소비기한이 가까운 재료를 먼저 쓰고 싶은 사람
- 추가 장보기와 복잡한 조리를 줄이고 싶은 사람

## 60초 핵심 흐름

1. **냉장고 확인**
   보유 재료와 수량, 보관 방식, 소비기한을 한눈에 확인한다.
2. **오늘의 조건 선택**
   `소비기한부터 챙길래요`를 선택해 임박 재료를 우선한다.
3. **AI 메뉴 추천**
   Gemini가 서버에서 검증 가능한 구조로 레시피를 생성하고, 정책 검증을 통과한
   메뉴만 보여준다.
4. **레시피 선택**
   `소고기 채소 볶음밥 · 15분 · 쉬움 · 부족한 재료 없음`처럼 바로 판단할 수
   있는 정보를 확인한다.
5. **상세 확인과 요리**
   보유·선택 재료, 대체 재료, 조리 순서, 정성적 영양 구성, 안전 주의사항을
   확인한다.

## 발표 자료 구성

기존 7장 초안을 유지하되, 각 장의 역할을 다음처럼 고정한다.

1. **보유 재료 기반 레시피 추천** — 서비스와 핵심 가치
2. **재료는 있지만 메뉴 결정은 어렵다** — 문제와 대상 사용자
3. **보유 재료를 검증된 AI 추천으로 연결한다** — React, Express, Supabase,
   Gemini 데이터 흐름
4. **냉장고 상태를 먼저 이해한다** — 재료 조회·등록 화면
5. **오늘의 상황에 맞는 한 끼를 고른다** — 조건 선택과 추천 결과
6. **추천 이유부터 조리 안전까지 확인한다** — 레시피 상세
7. **공개 환경에서 핵심 흐름을 완성했다** — 배포 URL, 테스트 111개 통과,
   남은 공개 CRUD·장애 대응 검증

현재 `todays-fridge-demo-day-v2.pptx`의 7번 슬라이드는 배포를 다음 단계로
표현하므로, 최종본에서는 실제 배포 완료 결과로 교체한다.

## 포스터 초안

### 제목

**냉장고 속 재료를 오늘의 메뉴로**

### 부제

보유 재료와 소비기한을 바탕으로 지금 만들 수 있는 1인분 레시피를 추천합니다.

### A1 세로 레이아웃

1. 상단 20%: 제목, 부제, 서비스 대표 화면
2. 중단 30%: 문제 → 해결 → 사용자 가치
3. 중단 30%: 냉장고 확인 → 조건 선택 → AI 추천 → 상세 확인 4단계 화면
4. 하단 15%: React → Express → Supabase·Gemini 기술 흐름
5. 하단 5%: 공개 서비스 QR 코드, 팀 정보, `테스트 111개 통과`

### 포스터용 짧은 문구

- **재료를 다시 입력하지 않아도** 냉장고 상태를 불러옵니다.
- **소비기한과 오늘의 상황을 반영해** 선택지를 줄입니다.
- **AI 응답을 서버에서 검증해** 실제로 보여줄 레시피만 남깁니다.
- **재료·순서·대체안·주의사항까지** 한 화면에서 확인합니다.

## 60~90초 데모 영상 대본

| 구간 | 화면 | 내레이션 |
|---|---|---|
| 0~10초 | 냉장고 재료 목록 | 냉장고에 재료는 있지만 오늘 무엇을 만들지는 늘 고민입니다. |
| 10~25초 | 임박 재료와 오늘의 메뉴 이동 | 있는대로는 보유 재료와 소비기한을 읽고, 먼저 사용할 재료를 알려줍니다. |
| 25~45초 | `소비기한부터 챙길래요` 선택과 추천 | 오늘의 상황을 고르면 Gemini가 메뉴를 만들고, 서버가 재료와 응답 구조를 검증합니다. |
| 45~65초 | 소고기 채소 볶음밥 카드와 상세 | 지금은 15분 안에 만들 수 있고 부족한 재료가 없는 소고기 채소 볶음밥을 추천했습니다. |
| 65~80초 | 조리 순서·대체 재료·안전 안내 | 사용 재료, 대체안, 조리 순서와 안전 주의사항까지 바로 확인할 수 있습니다. |
| 80~90초 | 서비스 URL·QR | 냉장고 속 재료가 오늘의 한 끼가 되는 흐름을 공개 환경에서 완성했습니다. |
