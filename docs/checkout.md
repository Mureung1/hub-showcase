## Phase 1️⃣: 프로필 설정 + 공고 추천 (MVP)

**목표**: 사용자 프로필 입력 → 맞춤 공고 추천 기능 완성  
**예상 완료**: 2026-07-20

### 1-1. 프론트엔드: 프로필 입력 페이지
- [ ] 프로필 설정 폼 UI 구현
  - [ ] 기본정보 입력 (학교, 전공, 학점)
  - [ ] 기술스택 입력 (사용 가능한 언어/프레임워크 선택)
  - [ ] 선호조건 입력 (회사규모, 근무지역, 급여, 기업문화)
  - [ ] 저장 버튼 및 유효성 검증
- [ ] 프로필 수정 페이지 (이미 입력한 정보 수정)

### 1-2. 백엔드: 프로필 저장 API
- [ ] POST `/api/profile` - 프로필 생성/업데이트
  - [ ] 데이터베이스에 저장
  - [ ] 입력값 검증 및 에러 처리
- [ ] GET `/api/profile` - 사용자 프로필 조회
  - [ ] 저장된 프로필 반환

### 1-3. 사람인 API 연동 & 공고 수집
- [ ] 사람인 API에서 채용공고 데이터 수집
  - [ ] API 호출 최적화 (Rate Limit 처리)
  - [ ] 공고 데이터 정규화 (회사명, 직무, 지역, 급여 등)
- [ ] 수집한 공고를 데이터베이스에 저장
  - [ ] 주기적 업데이트 로직 (예: 하루 1-2회)

### 1-4. RAG + LLM 기반 공고 분석 & 추천
- [ ] 사용자 프로필과 공고 정보를 비교하여 적합도 점수 계산
  - [ ] 기술스택 매칭 점수
  - [ ] 기업문화/조건 매칭 점수
  - [ ] 전체 적합도 종합 점수 (0~100)
- [ ] LLM을 활용한 추천 이유 생성
  - [ ] 예: "Python 경험 + 스타트업 선호도 일치 → 적합도 80%"
- [ ] RAG 구현 (선택사항, 현재 미정)
  - [ ] 필요시 나중에 추가

### 1-5. 백엔드: 공고 추천 API
- [ ] GET `/api/recommendations` - 맞춤 공고 추천 목록 반환
  - [ ] 사용자 프로필 기반 필터링
  - [ ] 적합도 상위 5-10개 반환
  - [ ] 각 공고별 추천 이유 포함

### 1-6. 프론트엔드: 추천 공고 UI
- [ ] 추천 공고 목록 페이지
  - [ ] 각 공고의 적합도 점수 표시
  - [ ] 추천 이유 명확하게 표시
  - [ ] 공고 상세 정보 보기
- [ ] 공고별 북마크/저장 기능

### 1-7. 통합 테스트 (Phase 1)
- [ ] 프로필 입력 → API 저장 → 조회 확인
- [ ] 사람인 API 데이터 수집 동작 확인
- [ ] 프로필 기반 공고 추천 결과 정확도 확인
- [ ] 프론트-백엔드 연동 테스트
