## 🚀 **현재 기술 스택**

### 백엔드
- **Framework:** Express.js + TypeScript
- **Database:** PostgreSQL + Prisma
- **외부 API:** GitHub API v3
- **인증:** Supabase JWT
- **LLM:** Ollama (llama3.1:8b)

### 프론트엔드
- **Framework:** React 18 + TypeScript
- **빌드:** Vite
- **상태 관리:** Zustand + React Hooks
- **UI:** Tailwind + shadcn/ui
- **폼:** React Hook Form + Zod

### 데이터베이스
- **사용자 데이터:** users, user_profiles, user_github_stars
- **공고 데이터:** raw_postings, postings, eligibility
- **GitHub 데이터:** github_repos
- **기타:** scraps, calendar_events, push_subscriptions
