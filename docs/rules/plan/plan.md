# 로그인 - 간편 참여 및 재접속 기능 기획

1. 관리자와 참여자는 동일한 약속 링크를 통해 서비스에 접속한다.
2. 관리자와 참여자 모두 별도의 회원가입 없이 본인의 이름과 숫자 4자리 간편 비밀번호를 입력한다.
3. 입력한 이름과 비밀번호를 기준으로 사용자를 구분하며, 약속 생성자는 관리자로 식별한다.
4. 관리자는 참여 현황 확인, 참여 기록 삭제, 약속 수정 및 투표 마감 기능을 사용할 수 있다.
5. 참여자는 자신의 일정 응답을 입력하고 기존 응답을 조회하거나 수정할 수 있다.
6. 이름은 약속별로 중복을 허용하지 않으며, 앞뒤 공백을 제거한 후 중복 여부를 확인한다.
7. 처음 등록된 이름이면 신규 참여자로 생성하고 일정 입력 화면으로 이동한다.
8. 기존 이름과 비밀번호가 일치하면 해당 사용자의 기존 화면과 응답 정보를 불러온다.
9. 내부 데이터는 이름이 아닌 별도의 사용자 ID를 기준으로 관리하며, 관리자와 참여자 역할을 함께 저장한다.
10. 입력 화면에 다음 안내를 표시한다: “처음 참여할 때 입력한 이름과 비밀번호로 나중에 다시 접속해 응답을 수정할 수 있어요. 비밀번호를 잊으면 기존 응답을 찾을 수 없으니 기억해 주세요.”
11. 이름 중복 시 다음 안내를 표시한다: “이미 사용 중인 이름이에요. 동명이인이라면 구분할 수 있는 별명을 사용해 주세요. 예: 민수(개발), 민수2”
12. 비밀번호가 일치하지 않으면 비밀번호를 다시 입력하도록 안내한다.
13. 관리자가 비밀번호를 잊은 경우에는 관리자 기록을 삭제할 수 없으므로, 약속을 새로 생성하도록 안내한다.

# 선호 시간 투표 기획

1. 일정 입력은 ‘가능한 시간 선택’과 ‘선호 시간 선택’의 2단계로 구성한다.
2. 첫 번째 단계에서 참여자는 자신이 참석할 수 있는 날짜와 시간대를 모두 선택한다.
3. 선택하지 않은 날짜와 시간대는 참석이 불가능한 시간으로 처리한다.
4. 가능한 시간 선택을 완료하면 “특별히 더 선호하는 시간대가 있으신가요?”라는 안내를 표시한다.
5. 두 번째 단계에서는 앞에서 선택한 가능한 시간 중 특별히 선호하는 시간만 추가로 표시할 수 있다.
6. 선호 시간이 없는 참여자는 ‘건너뛰기’를 선택해 바로 입력을 완료할 수 있다.
7. 안내 문구로 “가능한 시간 중 특히 원하는 시간만 선택해 주세요”를 함께 제공한다.
8. ‘선호’로 선택한 시간은 참석 가능한 시간에서 특별히 선호하는 시간대로 처리된다.
9. 각 시간대의 가능 인원은 해당 시간대를 가능한 시간으로 선택한 전체 인원으로 계산한다.
10. 선호 점수는 해당 시간대를 선호로 표시한 참여자 1명당 1점으로 계산한다.
11. 가능 인원이 가장 많은 시간대를 우선 추천한다.
12. 가능 인원이 같으면 선호 점수가 높은 시간대를 우선 추천한다.
13. 추천 결과 화면에서 히트맵에 날짜를 클릭시 가능 인원, 선호 인원 등 추천의 근거를 보여준다.
