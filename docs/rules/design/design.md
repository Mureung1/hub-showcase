## 8. 일정 입력
- 처음 가능한 시간 선택 시 연한 파란 색상으로 표시된다.
- 다음 화면에서는 그 가능한 시간들 중에서 선호하는 시간을 선택 가능하도록 하는데, 이때 선택 시 이전보다 진한 파란 색상으로 표시된다.

### 날짜/시간 선택 UX 스펙

#### 레이아웃
- 상단: 날짜 헤더 (예: `7/13(월)  7/14(화)  7/15(수)  7/16(목)`)를 한 화면에 여러 개 동시에 노출
- 헤더 양옆에 좌우 화살표(‹ ›) 배치 — 화살표를 눌러 날짜 범위를 페이지 단위로 넘김 (7일씩 이동)
- 그리드 왼쪽: 시간 라벨 (30분 단위, 예: 09:00 / 09:30 / 10:00 …)
- 그리드 본문: 시간(행) × 날짜(열) 교차 셀. 각 셀이 하나의 "날짜+시간" 슬롯을 의미

#### 선택 동작
1. **날짜 넘기기**: 좌우 화살표 클릭/탭으로 날짜 구간 전환. 날짜 자체를 탭해서 선택하지 않음 — 날짜는 항상 "지금 보이는 범위"이고, 실제 선택은 그리드 셀 드래그로 이루어짐.
2. **시간 선택 (드래그)**: 그리드 셀 위에서 시작점을 누르고 끌면 시작 셀부터 끝 셀까지 사각형 범위가 파란색으로 채워지며 선택됨. 행(시간)과 열(날짜) 양방향으로 드래그 가능 — 한 날짜 안에서 여러 시간을 잇거나, 여러 날짜에 걸쳐 선택할 수 있음.
3. **꾹 눌러야 드래그 시작 (Long-press to drag)**:
   - 그리드는 세로 스크롤이 되는 영역이므로, 일반 스와이프(스크롤)와 선택 드래그가 충돌하지 않도록 구분이 필요함.
   - 셀을 짧게 터치해 바로 손가락을 움직이면 **화면 스크롤**로 인식. (이때 스크롤로 이동하는 것은 시간축 스크롤 뿐임. 날짜는 1에서 언급하였듯 클릭 탭으로만 이동 가능.)
   - 셀을 **일정 시간(예: 300~400ms) 이상 꾹 누르고 있으면** 그리드가 "선택 모드"로 전환되고, 이 상태에서 손가락을 움직여야 **드래그 선택**이 시작됨 (짧은 진동 피드백이나 셀 하이라이트로 모드 전환을 알려주면 좋음).
   - 꾹 누르는 동안 손가락을 떼지 않고 그대로 움직이면 지나간 셀들이 순서대로 범위에 포함됨.
   - 손을 떼면 선택이 확정되고, 하단 요약 영역에 `날짜 · 시작시간 ~ 종료시간` 형태로 표시됨.
4. **탭(짧게 누르고 즉시 뗌)**: 셀 하나만 선택한 것으로 처리 (범위의 시작=끝).
5. 드래그 하는 도중일 때 기존에 드래그 된 영역을 만나면, 무시함(선택된 상태로 유지.)
