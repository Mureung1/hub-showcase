## 작업 내용

`docs/rules/subTasks.md`의 화면4(약속 생성완료 모달)·화면5(관리자 대시보드)·화면6(참여자 대시보드)를 다루는 묶음. 세 화면 모두 "참여 링크 복사"와 "참여 현황 표시"라는 요소를 공유하므로 `CopyLinkBox`/`ProgressBar` 공용 컴포넌트를 이 묶음에서 먼저 만들고 세 곳에서 재사용한다.

## 확정된 설계 결정

- `CopyLinkBox`: 링크를 드래그 복사하기 쉬운 박스 + 복사 버튼, `navigator.clipboard.writeText`로 자동 복사 + 복사완료 안내(토스트 또는 인라인).
- `ProgressBar`: `completed`/`total` 기반 막대바 + 퍼센트 표시, 기존 텍스트("N명 중 N명 완료")와 병기.
- 관리자 대시보드 하단 "참여자별 응답 상태" 목록에 필요한 데이터(참여자 이름 + 개별 완료 여부)가 현재 API에 없을 가능성이 있음 — 5번 묶음에서 조기 확인 후 필요하면 BE를 소폭 확장한다.

- [ ] 2. `ProgressBar` 공용 컴포넌트

- [ ] 5. 관리자 대시보드 — 참여자별 응답상태 목록(+ 필요 시 BE 확장)
- [ ] 6. 참여자 대시보드 — 공용 컴포넌트 재사용 + "내 응답 상태"
- [ ] 7. 통합 확인

## 우선순위

- 관리자 대시보드(4~5번)를 먼저 완성한 뒤 참여자 대시보드(6번)에서 그 패턴을 재사용
- BE 확장 필요 여부(참여자별 완료 여부·완료일시)를 5·6번 진행 중 최대한 일찍 판단해 뒤 작업이 밀리지 않게 한다

## 작업 순서

아래 순서대로 진행한다. 각 묶음이 끝날 때마다 수동으로 확인한 뒤 다음 묶음으로 넘어간다.

### 1. 공용 컴포넌트
1. `client/src/components/CopyLinkBox.tsx`/`.css` 신설 — 링크 박스 + "복사" 버튼, 클릭 시 `navigator.clipboard.writeText` 호출, 복사완료 안내 표시
2. `client/src/components/ProgressBar.tsx`/`.css` 신설 — `completed`/`total` props로 막대바 + 퍼센트 렌더링

이 묶음이 끝나면: 임시로 아무 화면에 두 컴포넌트를 붙여 독립적으로 정상 렌더링되는지 확인한다.

### 2. 약속 생성완료 모달
3. `AppointmentPage.tsx`의 생성완료 `Modal` 내부 링크 표시를 `CopyLinkBox`로 교체
4. 모달 아이콘/문구 등 시각적 다듬기(1주차 UIUX-1에서 만든 트랜지션 재사용)

이 묶음이 끝나면: 약속을 새로 만들었을 때 뜨는 모달에서 복사 버튼 클릭 시 실제로 클립보드에 링크가 복사되고 완료 안내가 뜨는지 확인한다.

### 3. 관리자 대시보드
5. `AdminDashboard.tsx` 상단에 약속 제목 + 기한(날짜/시간 범위) 표시 — `GET /:id` 응답의 `title`/`dateStart`~`timeEnd` 활용
6. 참여 현황에 `ProgressBar` 추가(기존 텍스트와 병기)
7. `CopyLinkBox` 적용
8. "투표 마감하기" 버튼을 빨간색으로 변경(기존 "약속 투표하기" 버튼은 파란색 유지)
9. 참여자별 응답 상태(이름 + 완료 여부) 표시에 필요한 데이터가 현재 API에 있는지 확인 — 없으면 `server/src/routes/results.ts` 또는 별도 라우트에 참여자 목록 + 완료 여부 응답을 추가(BE 확장), FE에서 목록 렌더링

이 묶음이 끝나면: 관리자 대시보드에서 제목/기한/막대바/링크복사/빨간 마감버튼/참여자별 상태 목록이 모두 실제 데이터로 보이는지 확인한다.

### 4. 참여자 대시보드
10. `ParticipantDashboard.tsx`에 3번 묶음 패턴(제목/기한, `ProgressBar`, `CopyLinkBox`) 재사용 적용 — 마감 버튼은 넣지 않음
11. 하단을 "내 응답 상태"(완료 배지, 입력 완료일시, "응답을 수정하고 싶다면 다시 접속해주세요" 안내)로 교체 — 완료일시 데이터가 현재 응답 조회 API에 없다면 `server/src/routes/responses.ts`의 GET 응답에 `created_at` 등을 추가(BE 확장)

이 묶음이 끝나면: 참여자 계정으로 들어갔을 때 대시보드 하단에 내 응답 상태가 올바르게 뜨는지 확인한다.

### 5. 통합 확인
12. 관리자/참여자 두 계정으로 전체 워크스루 — 생성완료 모달 → 대시보드 진입 → 복사/참여현황/마감버튼(관리자만)/응답상태 확인
