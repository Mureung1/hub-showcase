## 작업 내용

`docs/rules/subTasks.md`의 화면10(투표 마감 확인 모달)·화면11(최종 결과 화면)을 개선하고, 화면12(전체 공통 마무리 워크스루)로 이번 UI/UX 고도화 4개 묶음 전체를 점검한다. 시간이 남으면 `subTasks.md`의 "추가 개선 제안" 항목도 이어서 진행한다.

## 완료 기준

- [ ] 1. 투표 마감 확인 모달 개선
- [ ] 2. 최종 결과 화면 — 7일 페이지네이션 적용
- [ ] 3. 전체 공통 마무리 워크스루
- [ ] 4. 추가 개선 제안 착수(시간 여유 시)

## 우선순위

- 1·2번(마감모달, 결과화면)이 핵심, 3번(마무리 워크스루)까지가 이번 UI/UX 고도화의 필수 범위
- 4번(추가 개선)은 `subTasks.md`에 명시된 대로 "시간 보고" 진행하는 후순위 항목

## 작업 순서

아래 순서대로 진행한다. 각 묶음이 끝날 때마다 수동으로 확인한 뒤 다음 묶음으로 넘어간다.

### 1. 투표 마감 확인 모달
1. 상단에 경고 아이콘(빨간/주황 원형 배지, 느낌표) 추가
2. "투표를 마감할까요?" 제목 + 참여 현황을 `ProgressBar`(2주차 UIUX-2에서 만든 컴포넌트)로 표시
3. "마감 후에는 참여자가 더 이상 응답을 수정할 수 없습니다" 안내 문구
4. "마감할게요"(빨간 버튼)/"취소" 버튼 스타일 정리

이 묶음이 끝나면: 마감 확인 모달에서 실제 참여 현황이 막대바로 정확히 표시되고, 마감 버튼 클릭이 실제 마감 처리까지 이어지는지 확인한다.

### 2. 최종 결과 화면
5. `ResultHeatmap.tsx`/`ResultPage.tsx`에 `subTask3.md`에서 만든 7일 페이지네이션 패턴을 재사용 — 히트맵도 화살표로 7일씩 이동
6. 페이지 이동 시 색상 등급(순위 기반)이 페이지와 무관하게 전체 데이터 기준으로 정확히 유지되는지 확인(등급 계산은 전체 슬롯 기준, 렌더링만 페이지 단위로 필터링)

이 묶음이 끝나면: 결과 화면에서 날짜를 넘겨도 히트맵 색상이 일관되게 보이는지 확인한다.

### 3. 전체 공통 마무리
7. 화면1~11 전체를 순서대로 워크스루하며 `ScreenHint` 안내문구와 전환 트랜지션이 빠짐없이 적용됐는지 점검
8. 빠진 부분 보완

이 묶음이 끝나면: 홈부터 결과 화면까지 전체 플로우를 한 번에 수동으로 훑어 UI/UX 고도화 항목 12개가 모두 반영됐는지 확인한다.

### 4. 추가 개선 제안(시간 여유 시, `docs/rules/subTasks.md` "추가 개선 제안" 섹션 참고)
9. 공용 Toast/Snackbar 컴포넌트로 정리(2주차 UIUX-2에서 `CopyLinkBox`용으로 일부 만들었다면 범용화)
10. 폼 제출 버튼 로딩/비활성 상태 추가(중복 제출 방지)
11. 빈 상태(empty state) UI(참여자 0명, 결과 데이터 없음)
12. 색약 접근성 보완(아이콘/패턴 등 보조 표시)
13. 아이콘 버튼(복사, 화살표 등)에 `aria-label` 추가
14. 잘못된 `:id` 접근 시 에러 화면 UI 개선
15. 참여 정원 초과(409) 안내 문구 스타일링
