# 기획안

## 문제 정의
대학생이 여러 공지와 안내문을 확인하는 과정에서 중요한 일정과 마감일을 놓치는 불편을 겪는다.



## 사용자 시나리오
1. 사용자가 CalMe 웹사이트를 실행한다.
2. 사용자가 '일정 등록' 버튼을 클릭한다.
3. 사용자가 학교 공지, 공모전, 대외활동, 팀플 일정이 담긴 URL 또는 PDF를 업로드한다.
4. AI가 업로드된 공지를 분석하여 마감일, 신청 기간, 제출물, 일정 등 핵심 정보를 추출한다.
5. 사용자는 AI가 추출한 정보를 확인하고 '캘린더에 등록' 버튼을 누른다.
6. 일정이 앱 내 캘린더에 자동으로 등록된다.
7. 사용자가 캘린더에서 등록된 일정을 클릭하면 세부 정보와 원본 공지 요약을 확인할 수 있다.
8. 마감일이 있는 일정은 잠금화면 위젯에 D-30, D-7, D-1 등으로 표시되어 사용자가 쉽게 확인할 수 있다.


## 핵심기능 (2개)
- AI 공지 분석 및 일정 자동 추출
- AI 기반 캘린더 자동 등록

## 화면 흐름 (기획 시각화)
```mermaid
flowchart TD
    A([웹사이트 접속]) --> B{로그인 여부}

    B -->|로그인 안 됨| C[로그인 / 회원가입]
    C --> D[메인 대시보드]

    B -->|로그인 됨| D[메인 대시보드]

    D --> E[일정 등록 버튼 클릭]

    E --> F{공지 등록 방식 선택}

    F -->|URL| G[URL 입력]
    F -->|PDF| H[PDF 업로드]
    F -->|이미지| I[JPG / PNG 업로드]

    G --> J[AI가 공지 분석]
    H --> J
    I --> J

    J --> K{날짜 정보 발견 여부}

    K -->|없음| L[날짜를 찾을 수 없습니다 팝업]
    L --> M{직접 입력할까요?}
    M -->|아니오| D
    M -->|예| N[사용자가 날짜 직접 입력]

    K -->|있음| O[AI 요약 및 일정 자동 추출]

    N --> O

    O --> P[추출 결과 미리보기<br/>일정명 / 날짜 / 분류 / 요약 / 원본 공지]

    P --> Q{수정이 필요한가?}

    Q -->|예| R[사용자가 일정 정보 수정<br/>날짜 / 시간 / 분류 / 메모]
    R --> S[등록할 일정 선택]

    Q -->|아니오| S[등록할 일정 선택]

    S --> T{중복 일정 여부}

    T -->|중복 의심| U[비슷한 일정이 이미 있습니다 팝업]
    U --> V{그래도 등록할까요?}
    V -->|아니오| D
    V -->|예| W[캘린더 자동 등록]

    T -->|중복 아님| W[캘린더 자동 등록]

    W --> X[메인 대시보드 업데이트]

    X --> Y{마감 임박 일정 존재 여부}

    Y -->|있음| Z[마감 임박 카드 표시<br/>D-1 / D-3 / D-7]
    Y -->|없음| AA[등록된 마감 일정이 없습니다 표시]

    X --> AB[캘린더에서 일정 확인]

    AB --> AC[일정 클릭]
    AC --> AD[상세 정보 확인<br/>AI 요약 / 메모 / 원본 공지]

    AD --> AE[일정 수정 / 삭제 가능]
```
