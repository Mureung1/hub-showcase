# PlaceSync 기획서

## 문제 정의

온라인 플랫폼에 매장 정보를 등록한 사장님들은 실제 매장의 영업시간, 휴무일, 메뉴와 가격이 변경될 때마다 각 플랫폼의 정보를 일일이 확인하고 수정해야 하며, 이 과정이 번거롭고 실수로 수정하지 못한 정보가 잘못된 정보로 남는 불편을 겪습니다.

## 사용자 시나리오

1. 사장님이 매장의 영업시간, 휴무일, 메뉴 또는 가격을 변경하려고 합니다.
2. 사장님이 서비스에 접속하면 각 플랫폼에 현재 등록된 매장 정보가 한 화면에 표시됩니다.
3. 사장님은 변경할 정보와 고객에게 안내할 공지 내용을 한 번만 입력하고, 수정된 내용을 확인합니다.
4. AI Agent가 입력한 내용을 플랫폼별 형식과 가격 정책에 맞게 변환해 미리보기를 제공합니다.
5. 사장님이 최종 승인하면 자동 업데이트가 가능한 플랫폼에는 정보를 직접 반영합니다.
6. 자동 업데이트가 불가능한 플랫폼에는 수정 사이트 링크와 복사할 수 있는 수정 내용을 제공합니다.
7. 업데이트가 끝나면 플랫폼별로 전송 완료, 검토 중, 반영 완료, 실패 상태를 확인합니다.
8. 실패한 플랫폼은 다시 시도하고, 계속 실패하면 해당 플랫폼의 수정 화면으로 이동해 수동으로 반영합니다.

## 핵심 기능 (2개)

### 1. 매장 정보 통합 편집 및 플랫폼별 적용값 생성

사장님이 영업시간, 휴무일, 메뉴, 가격, 공지 내용을 한 번만 입력하면 AI Agent가 각 플랫폼에 적용할 값을 자동으로 생성합니다.

- 영구 변경과 임시 변경 구분
- 임시 변경의 시작일, 종료일, 적용 시간 설정
- 플랫폼별 가격 차이 자동 적용
- 메뉴 카테고리별 노출 플랫폼 설정
- 특정 메뉴의 개별 가격 및 노출 예외 설정
- 플랫폼별 반영 내용 미리보기
- 사장님의 최종 승인 후 업데이트 실행

### 2. 플랫폼별 정보 반영 및 결과 확인

사장님이 승인한 정보를 각 플랫폼에 반영하고, 플랫폼별 처리 상태와 실패 원인을 확인할 수 있도록 합니다.

- 자동 업데이트가 가능한 플랫폼에 정보 직접 반영
- 자동 업데이트가 불가능한 플랫폼에 수정 사이트 링크 제공
- 수정할 내용을 복사할 수 있는 기능 제공
- 전송 완료, 검토 중, 반영 완료, 실패 상태 표시
- 실패한 플랫폼만 재시도
- 외부 플랫폼에서 따로 수정된 정보 감지
- 가격, 메뉴, 영업시간·휴무일별로 묶은 불일치 알림 제공

## 화면 흐름

![PlaceSync 사용자 흐름](./user-flow.png)

화면 흐름은 다음과 같습니다.

> 대시보드에서 현재 정보 확인  
> → 통합 편집 화면에서 정보 수정  
> → 플랫폼별 적용값 미리보기  
> → 사장님 최종 승인  
> → 각 플랫폼에 업데이트  
> → 플랫폼별 반영 결과 확인  
> → 실패 시 재시도 또는 수동 수정
