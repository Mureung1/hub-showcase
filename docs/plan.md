# 기획서 — FirstPR

> 사용자의 GitHub 활동과 선호 조건을 분석해, 첫 오픈소스 기여에 적합한 레포지토리와 이슈를 추천하는 서비스

## 1. 문제 정의
- 최근 AI 기술의 발전으로 오픈소스에 기여하고자 하는 개발자가 늘어나고 있다.
- 하지만 정작 어떤 프로젝트/이슈에 기여해야 할지 막막해하는 사람이 많다.
- 따라서 사용자의 기술 성향, 실력, 요구사항에 맞는 레포지토리 및 이슈를 추천해줄 필요가 있다.

## 2. 타겟 사용자 / 페르소나
- 주요 사용자: 오픈소스에 기여하고자 하는 모든 개발자

### 페르소나 예시
- 이름: 홍길동
- 나이: 20~30대
- 기술 스택: JavaScript/Python/Java, 실무 1~2년차 주니어 개발자 및 개발자 지망생
- 상황: 평소 오픈소스를 자주 사용하다 보니 자신도 기여해보고 싶다는 생각이 듦
- 고민: "기여해볼만한 오픈소스가 뭘까?", 관심 있는 레포를 찾아도 이슈 목록을 보면 난이도가 가늠이 안 되고 너무 어려워 보여서 선뜻 시작하지 못함
- 니즈: 내 기술 스택과 실력 수준에 맞는 레포/이슈를 추천받아 부담 없이 첫 기여를 시작하고 싶음

## 3. 사용자 시나리오
### 입력 정보
1. GitHub ID — 사용자의 기존 활동/기술 스택 분석용
2. 선호 조건 — 기여해보고 싶은 언어, 난이도, 주제 등

### 흐름
1. 사용자가 서비스에 접속한다.
2. GitHub ID를 입력한다.
3. 기여해보고 싶은 언어, 난이도, 주제 등 선호 조건을 입력한다.
4. 시스템이 GitHub 활동 이력(기술 스택, 실력 수준)과 선호 조건을 함께 분석한다.
5. 사용자에게 맞는 레포지토리 및 이슈 목록을 추천한다.
6. 사용자가 추천 목록 중 관심 있는 레포/이슈를 선택해 상세 정보를 확인한다.
7. 사용자가 실제로 해당 레포에 첫 기여를 시작한다.

## 4. 핵심 기능
1. 사용자 GitHub 및 입력에 따라 GitHub에서 오픈소스 레포 및 이슈 분석
2. 사용자에게 추천 레포, 이슈 제공 및 간단한 정보 제공

### 세부 기능
- **GitHub 프로필 분석**: 입력한 GitHub ID의 활동 이력(사용 언어, 커밋/PR 이력, 기존 오픈소스 참여 여부 등)을 분석해 기술 성향과 실력 수준을 파악
- **선호 조건 입력**: 기여하고 싶은 언어, 난이도, 주제(관심 분야)를 선택/입력
- **레포/이슈 추천**: 프로필 분석 결과와 선호 조건을 조합해 적합한 레포지토리 및 이슈 목록을 추천
- **추천 상세 보기**: 추천된 레포/이슈의 상세 정보(설명, 난이도, 필요 기술, 이슈 링크 등) 제공
- **추천 결과 재조회/필터링**: 조건을 바꿔 다시 추천받거나 결과를 필터링

## 5. 화면 흐름
1. **랜딩 페이지** — 서비스 소개 및 시작하기 버튼
2. **GitHub ID 입력 화면** — GitHub ID 입력 및 연동
3. **선호 조건 입력 화면** — 언어/난이도/주제 선택
4. **분석 중 화면(로딩)** — 프로필 분석 및 추천 계산 진행 상태 표시
5. **추천 결과 목록 화면** — 추천 레포/이슈 리스트 (필터/재조회 가능)
6. **추천 상세 화면** — 선택한 레포/이슈의 상세 정보 및 외부 링크(GitHub 이동)

흐름: 랜딩 → GitHub ID 입력 → 선호 조건 입력 → 분석 중 → 추천 결과 목록 → 추천 상세(→ GitHub으로 이동)

## 6. 비기능 요구사항 / 기술적 고려사항
- **GitHub API 제약**: 비인증 요청은 시간당 60회로 제한됨 → 인증 토큰 사용 및 결과 캐싱으로 rate limit 대응
- **응답 속도**: 프로필 분석·추천 계산에 시간이 걸릴 수 있으므로 로딩 상태를 명확히 표시하고, 필요 시 비동기 처리
- **개인정보/보안**: 공개된 GitHub 활동 정보만 사용하며, 별도 개인정보는 수집하지 않음
- **추천 품질**: 초기에는 규칙 기반(언어·라벨·난이도 매칭)으로 시작하고, 데이터가 쌓이면 고도화

## 7. MVP 범위 및 향후 계획
### MVP 범위 (우선 구현)
- GitHub ID + 선호 조건 입력
- 프로필 분석 및 규칙 기반 레포/이슈 추천
- 추천 목록 및 상세 보기

### 향후 확장 (이후)
- 추천 결과 재조회/필터링 고도화
- 추천 정확도 개선(활동 이력 기반 스코어링, 개인화) — 매니페스트(`package.json` 등) 기반 실사용 라이브러리 매칭 타당성 검증 완료, 구현은 보류(참고: [decisions.md](decisions.md) 2026-07-27)
- 기여 이력 추적 및 북마크 등 부가 기능
