# 스펙핏(SpecFit) 기획서

## 문제 정의
취업 준비 중인 대학생이 관심 공고에 지원할지 말지 고민할 때 자신의 스펙이 부족한지 충분한지 판단할 기준이 없어 막막함을 겪는다.

## 사용자 시나리오
1. 관심 있는 직종/지역/고용형태를 필터링해 채용공고 목록을 본다
2. 자신의 스펙(학력, 경력, 자격증, 전공, 외국어 등)을 입력한다
3. 필터링된 공고 중 현재 스펙으로 지원 가능한 비율을 도넛 차트로 확인한다
4. 부족한 역량 랭킹(막대 그래프)을 보고 어떤 항목을 보완하면 지원 가능 공고가 얼마나 늘어나는지 확인한다
5. 개별 공고를 클릭해 항목별 충족/미충족 체크리스트를 본다

## 핵심 기능
서비스 파이프라인은 아래 4개 기능으로 구성되지만 기존 취업 플랫폼과 스펙핏을 구분 짓는 **차별화 핵심은 ③④번**이다.

- ① 스펙 입력 — 학력, 경력, 자격증/면허, 전공, 외국어 성적, 컴퓨터활용능력 등
- ② 조건 필터링 — 직종, 근무지역, 고용형태, 희망 급여 등
- **③ 갭 분석 엔진 (핵심★)** — 사용자 스펙과 공고 요구사항을 대조해 지원 가능 비율을 계산하고, 항목별 보완 시 늘어나는 지원 가능 공고 수를 시뮬레이션
- **④ 시각화 결과 화면 (핵심★)** — 지원 가능 비율(도넛 차트), 부족 역량 랭킹(막대 그래프), 개별 공고 충족/미충족 체크리스트

> 기존 플랫폼은 "공고 추천"에 그치지만 스펙핏은 ③갭 분석 + ④시각화를 통해 "자기 진단 + 액션 플랜"을 제공한다는 점이 정체성이다.

## 화면 흐름

```mermaid
flowchart LR
    A[필터/목록 화면<br/>공고 리스트 확인] --> B[스펙 입력 화면<br/>학력·경력·자격 입력]
    B --> C[결과 화면<br/>갭 분석 시각화]
    C --> D[공고 상세 화면<br/>충족/미충족 체크]
    D -- 뒤로 --> C
```

### 결과 화면 구성 (와이어프레임 메모)
- 좌측: 지원 가능 공고 비율 — 도넛 차트 (예: 60%, 18/30건)
- 우측: 부족 역량 랭킹 — 항목별 보완 시 증가하는 공고 수 막대 그래프 (예: 컴퓨터활용능력 +9건, 외국어 성적 +6건, 관련 자격증 +3건)
- 하단: 공고 리스트 — 공고별 지원 가능/미충족 사유 태그
