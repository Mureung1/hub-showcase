# 프로젝트 기획서

## 1. 프로젝트명

나만의 공부 사용설명서

## 2. 프로젝트 개요

MBTI와 공부 습관·스트레스 반응 설문을 바탕으로 사용자의 공부 선호와 학습 패턴을 정리하고, 오늘 바로 실천할 수 있는 공부 루틴과 회복 루틴을 추천하는 웹 서비스입니다.

이 프로젝트에서 MBTI는 사람을 고정적으로 판단하거나 분류하기 위한 도구가 아닙니다. 사용자의 공부 선호를 이해하기 위한 초기 참고 지표로만 활용하며, 실제 추천은 공부 습관 설문과 스트레스 반응 설문을 함께 반영합니다.

스트레스 관련 기능은 진단이나 치료 목적이 아니라, 사용자가 학습 중 피로를 인식하고 가볍게 회복할 수 있는 루틴을 제안하는 데 목적이 있습니다.

## 3. 문제 정의

많은 학습자는 공부 계획을 세우지만 꾸준히 이어가지 못합니다. 또한 유명한 공부법이나 타인의 루틴을 그대로 따라 하다가 오히려 집중력이 떨어지거나 부담을 느끼기도 합니다.

사용자에게 필요한 것은 단순히 더 긴 공부 시간이 아니라, 자신의 성향과 생활 패턴에 맞는 지속 가능한 학습 방식입니다.

## 4. 목표

- 사용자가 자신의 공부 선호와 부담 요인을 이해하도록 돕기
- 오늘 바로 실행할 수 있는 짧고 구체적인 공부 루틴 제공
- 학습 후 집중도와 피로도를 기록해 스스로 점검할 수 있게 하기
- 성향 분석과 맞춤 루틴 추천 중심의 MVP 구현

## 5. 주요 사용자

- 공부 계획은 세우지만 꾸준히 유지하기 어려운 학습자
- 자신에게 맞는 공부법을 찾고 싶은 학생
- 학습 중 스트레스나 피로를 자주 느끼는 사용자
- 긴 계획보다 바로 실행 가능한 짧은 루틴이 필요한 사용자

## 6. 사용자 시나리오

1. 사용자는 MBTI를 선택하거나 간단한 성향 정보를 입력합니다.
2. 공부 습관 설문에 답해 집중 시간, 선호 환경, 계획 방식 등을 입력합니다.
3. 스트레스 반응 설문에 답해 학습 중 부담을 느끼는 상황을 입력합니다.
4. 서비스는 입력값을 바탕으로 공부 성향 지표를 요약합니다.
5. 사용자는 추천 공부법 TOP 3와 피해야 할 공부 방식을 확인합니다.
6. 사용자는 오늘의 20분 공부 루틴과 스트레스 회복 루틴을 확인합니다.
7. 공부 후 완료 여부, 집중도, 피로도를 기록합니다.

## 7. 핵심 기능

### 7.1 MBTI 선택 또는 간단 성향 입력

- MBTI 유형을 직접 선택
- MBTI를 모르는 사용자를 위한 간단 입력 흐름 제공
- 결과는 고정된 성격 판단이 아니라 공부 선호 참고값으로 활용

### 7.2 공부 습관 설문

- 선호 공부 시간대
- 평균 집중 가능 시간
- 혼자 공부와 함께 공부 선호
- 계획형과 즉흥형 경향
- 복습 방식과 문제 풀이 선호

### 7.3 스트레스 반응 설문

- 학습 중 부담을 느끼는 상황
- 집중 저하 시 나타나는 반응
- 휴식과 회복 선호 방식
- 진단이나 치료가 아닌 회복 루틴 추천용 참고값으로 활용

### 7.4 공부 성향 분석

- 입력값을 바탕으로 사용자의 공부 성향 지표 요약
- 강점과 주의할 점을 함께 제공
- 단정적인 표현보다 가능성과 추천 중심의 문장 사용

### 7.5 맞춤 루틴 추천

- 추천 공부법 TOP 3
- 피해야 할 공부 방식
- 오늘의 20분 공부 루틴
- 스트레스 회복 루틴

### 7.6 학습 후 기록

- 완료 여부
- 집중도
- 피로도
- 간단 메모
- localStorage 기반 저장

## 8. MVP 범위

MVP는 성향 분석과 맞춤 루틴 추천에 집중합니다.

- MBTI 기반 초기 공부 선호 참고
- 공부 습관 설문
- 스트레스 반응 설문
- 공부 성향 요약
- 추천 공부법 TOP 3
- 피해야 할 공부 방식
- 오늘의 20분 공부 루틴
- 스트레스 회복 루틴
- 학습 후 간단 기록

## 9. 제외 범위

- 회원가입
- 커뮤니티
- 친구 비교
- 성적 예측
- 정신건강 진단
- 결제

## 10. 표현 원칙

- MBTI를 사람을 고정적으로 판단하는 도구처럼 표현하지 않습니다.
- 스트레스 기능을 진단이나 치료처럼 표현하지 않습니다.
- 사용자를 단정하지 않고, 선택 가능한 추천과 참고 정보로 안내합니다.
- 학습량을 무리하게 늘리는 방향보다 지속 가능한 실천을 우선합니다.
