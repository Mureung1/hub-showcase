# 하소AI 프로젝트 기획서

> 하소연이 콘텐츠가 되는, 하소AI 프로젝트
> Turning Your Struggles into Viral Stories

---

## 1. 문제 정의: 소상공인이 겪는 고립과 피로

### 심각한 디지털 번아웃
사장님들의 70%는 일과 삶의 분리에 어려움을 겪으며, 매일 반복되는 마케팅 콘텐츠 제작에 큰 심리적 부담을 느낍니다.

### organic engagement의 하락
단순한 홍보성 게시물은 더 이상 노출되지 않습니다. 소비자들은 사장님의 '진솔한 뒷이야기'에만 반응하기 시작했습니다.

---

## 2. 솔루션: 투명성과 유머의 시너지

- **진정성 있는 스토리텔링**: 사장님이 오늘 겪은 황당하고 슬픈 사건을 유머러스하게 승화시켜, 팔로워들과 정서적 유대감을 형성합니다.
- **맥락 기반 콘텐츠 보강**: 날씨, 공휴일/기념일 등 그날의 현장감을 더하는 정보를 자동으로 결합하여, 사장님의 하루가 더 생생한 이야기로 완성되도록 돕습니다.

---

## 3. 핵심 기능

### 감정 온도 조절 시스템
사용자가 설정한 '감정 온도'에 따라 AI의 문체(Tone & Manner)가 극단적으로 변화합니다.
- 🔥 **80도 이상**: 매운맛 풍자와 시원한 사이다 일기
- 🌧️ **30도 이하**: 담백하고 감성적인 철학적 일기

### 콘텐츠 맥락 엔진
사장님의 하소연에 현장감을 더하기 위해, 안정성이 검증된 소스부터 순차적으로 결합하는 계층 구조로 설계합니다.

| 요소 | 설명 |
|---|---|
| 큐레이션 키워드 DB | 직접 선별/갱신하는 시즌·밈 키워드 리스트 (JSON 형태로 관리, 주 단위 업데이트) — 항상 동작하는 기본 소스 |
| 공휴일·기념일 API | 공공데이터포털 제공 공식 API로 오늘이 어떤 날인지(공휴일, 기념일, 절기 등) 자동 확인 |
| 날씨 API | 기상청 공식 API로 오늘의 날씨 정보를 자동 반영 |

→ 사람이 큐레이션한 안전한 키워드를 기본으로 삼고, 그 위에 공식 API로 날짜·날씨 맥락을 자동으로 더해 콘텐츠를 구성합니다. 두 API 모두 공공데이터포털/기상청이 제공하는 공식 서비스라 안정성이 높고, 별도 인증 절차나 비용 없이 사용할 수 있습니다.

### AI 비주얼 생성
GPT Image 1.5 기반의 고퀄리티 이미지 생성을 통해, 사장님의 일기가 한 편의 영화처럼 시각화됩니다. 단순한 사진이 아닌, 사장님의 감정 선을 표현하는 '예술적인 비주얼'을 4주 안에 구현합니다.

---

## 4. 사용자 경험 여정 (UX Flow)

1. **하소연 입력** — 오늘 있었던 일을 텍스트로 입력
2. **온도 조절** — 현재 내 기분의 온도를 조절하여 톤앤매너 결정
3. **콘텐츠 생성** — 맥락 정보가 반영된 글과 이미지를 AI가 자동 생성
4. **다운로드 / 복사** — 마음에 드는 결과물을 이미지 파일로 다운로드하거나 텍스트를 복사하여 직접 SNS에 게시

---

## 5. 기술 스택 및 아키텍처

| 구분 | 기술 / API | 역할 |
|---|---|---|
| Frontend | React / Figma | 감정 조절 인터페이스 및 대시보드 |
| Backend | FastAPI (Python) | 데이터 가공 및 API 오케스트레이션 |
| Text AI | OpenAI GPT-4o | 맥락 정보 결합 및 텍스트 생성 |
| Image AI | GPT Image 1.5 | 프롬프트 기반 SNS 전용 이미지 생성 |
| Data 관리 | 큐레이션 키워드 DB (JSON) | 시즌/밈 키워드 수동 관리 및 주 단위 갱신 |
| Data API | 공공데이터포털 특일정보 API | 공휴일/기념일/절기 정보 조회 |
| Data API | 기상청 API | 날씨 정보 조회 |

---

## 6. 기대 효과

- 사장님의 진솔한 이야기가 담긴 콘텐츠는 기존의 정형화된 홍보글보다 소비자와의 정서적 유대감 형성에 유리할 것으로 기대됩니다.
- 날씨·기념일 등 현장감 있는 맥락 정보를 결합한 콘텐츠는, 단순 홍보글보다 공감과 몰입도 측면에서 더 높은 반응을 이끌어낼 것으로 예상됩니다.
- 반복적인 콘텐츠 제작 부담을 줄여, 사장님이 본업에 집중할 수 있는 환경을 제공합니다.
- 큐레이션 DB와 공식 API(날씨, 공휴일/기념일)만으로 구성해, 별도 비용이나 인증 부담 없이 안정적으로 운영할 수 있습니다.
