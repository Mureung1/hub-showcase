# MVP 기획 문서 안내

아맞다의 제품 기획은 GitHub 위키에서 관리한다.

- [제품 개요](https://github.com/ppre1ude/hub/wiki/%EC%A0%9C%ED%92%88-%EA%B0%9C%EC%9A%94): 해결하려는 문제, 사용자와 제품 가치
- [현재 MVP](https://github.com/ppre1ude/hub/wiki/%ED%98%84%EC%9E%AC-MVP): 제품 가설, 핵심 흐름과 범위
- [제품 원칙과 결정](https://github.com/ppre1ude/hub/wiki/%EC%A0%9C%ED%92%88-%EC%9B%90%EC%B9%99%EA%B3%BC-%EA%B2%B0%EC%A0%95): 제품을 설계하고 범위를 판단하는 기준
- [제품 학습](https://github.com/ppre1ude/hub/wiki/%EC%A0%9C%ED%92%88-%ED%95%99%EC%8A%B5): 사용자 근거에서 얻은 학습과 남은 질문

현재 작업 상태와 실행 순서는 [아맞다! 프로젝트](https://github.com/users/ppre1ude/projects/3), 기능별 사용자 결과와 완료 기준은 [GitHub 이슈](https://github.com/ppre1ude/hub/issues)를 따른다.

코드와 함께 바뀌어야 하는 계약은 저장소에서 관리한다.

- 제품 언어와 현재 제약: [작업 컨텍스트](../CONTEXT.md)
- 검색 점수, 정렬과 테스트 기준: [검색 구현 계약](retrieve.md)
- 화면과 컴포넌트 규칙: [디자인 시스템](../DESIGN.md)
- 코드 구조와 저장 경계: [개발 아키텍처](development-architecture.md)

이 파일은 기존 링크를 유지하기 위한 안내 문서다. `docs/superpowers/plans`와 `docs/superpowers/specs`는 별도 요청이 있을 때까지 보존한다.
