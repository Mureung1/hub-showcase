# 대학생 맞춤형 공고 추천 및 자기소개서 작성 Agent

대학생의 관심 분야와 경험을 바탕으로 신입 공채, 인턴십, 공모전, 대외활동 공고를 추천하고, 선택한 공고에 맞는 자기소개서 초안을 작성해주는 Agent 서비스

## 문제 정의

대학생들은 신입 공채, 인턴십, 공모전, 대외활동에 지원할 때 자신에게 맞는 공고를 고르고, 자기소개서 문항에 맞게 자신의 경험을 정리해 작성하는 데 어려움을 겪는다.

## 사용자 시나리오

1. 사용자는 서비스에 접속해 대학교, 학년, 전공, 복수전공(선택), 부전공(선택), 취득학점, 평균평점, 자격증, 그 외 경험(현장실습, 인턴, 교육 등)을 입력한다.
2. 서비스는 입력된 정보를 바탕으로 사용자에게 적합한 신입 공채, 인턴십, 공모전, 대외활동 공고를 추천한다.
3. 사용자는 각 공고의 추천 이유와 주요 조건을 확인하고 지원할 공고를 선택한다.
4. 서비스는 선택한 공고의 자기소개서 문항을 분석한다.
5. 서비스는 사용자의 경험을 반영해 자기소개서 초안을 작성해 보여준다.
6. 사용자는 생성된 초안을 확인하고 수정해 최종 지원서 작성에 활용한다.

## 핵심 기능

1. 사용자 정보 기반 맞춤 공고 추천
2. 공고별 자기소개서 초안 생성
