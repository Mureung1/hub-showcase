# 구현 완료 후 자동 코드리뷰

`backend/`, `frontend/` 등 실제 동작 코드를 새로 작성하거나 수정하는 작업을 완료하면, 사용자가 "코드리뷰해줘"라고 요청하기를 기다리지 않고 바로 `implementation-code-reviewer` 서브에이전트로 1차 리뷰를 실행한다.

## 적용 대상

- production 코드(`backend/app/`, `frontend/src/` 등)를 새로 만들거나 수정한 작업
- 위 코드에 대한 테스트를 함께 작성한 작업

## 적용하지 않는 대상

- `docs/` 문서만 수정한 작업
- 코드 변경 없이 질문에 답하거나 조사만 한 작업
- 설정 파일(`.claude/`, `package.json` 등)만 바꾼 작업
- 사용자가 리뷰를 명시적으로 원하지 않는다고 밝힌 작업

## 실행 방식

- `AGENTS.md`의 "AI 협업 운영 방식" 표에 정의된 "구현 1차 리뷰" 단계를 그대로 따른다.
- `implementation-code-reviewer` 서브에이전트(`.claude/agents/implementation-code-reviewer.md`)를 호출한다.
- 변경 파일 목록과 구현 요약, 리뷰 시 확인해야 할 요구사항을 프롬프트에 구체적으로 포함한다.
- 리뷰 실행 여부를 사용자에게 먼저 묻지 않는다. 실행 후 결과와 반영 여부를 보고한다.
- 리뷰에서 P0/P1이 발견되면 수정하고 관련 검증을 다시 실행한 뒤 결과를 보고한다.
