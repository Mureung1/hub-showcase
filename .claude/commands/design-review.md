## 다음만 답한다
1. 빠진 조건이나 엣지 케이스가 있는가
2. MVP에 과한 복잡도가 있는가 (오버엔지니어링)
3. 도메인 값이 실제 DB 제약과 어긋나는가
4. 보안·데이터 신뢰성 리스크가 있는가
   - user_id를 요청 본문에서 받고 있지 않은가 (토큰에서만 뽑아야 한다)
   - 숨겨야 할 데이터를 프론트에서만 거르고 있지 않은가 (백엔드에서 걸러야 한다)
   - RLS가 필요한 곳에 secret 키를 쓰고 있지 않은가
5. 완료 기준에 "실패해야 정상인 케이스"가 있는가
6. 구현 전에 반드시 확정해야 할 항목은 무엇인가

- 파일을 수정하지 않는다.
