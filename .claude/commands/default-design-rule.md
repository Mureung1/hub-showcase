UI 작업을 시작하기 전에 반드시 `docs/design.md`를 읽어라.

읽은 뒤 아래 항목을 확인하고 작업에 적용한다:
- 색상: `docs/design.md`의 Color Palette 기준만 사용
- 타이포그래피: Font Family, 크기, 굵기 기준 준수
- 간격: Spacing 기준 (4px 단위)
- 라운딩: Border Radius 기준
- 그림자: Shadows 기준
- 레이아웃: Layout 구조 기준

기준에 없는 값이 필요하면 사용자에게 먼저 확인한다.
