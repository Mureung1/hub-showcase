# 요구 검증 Agent (초안)

기능 구현이 끝난 뒤, 아래 순서로 점검한다.

1. 이 기능이 어떤 GitHub Issue(또는 `docs/spec.md`의 Feat 항목)에 해당하는지 확인하고, 그 이슈에 적힌 "완료 기준"을 원문 그대로 가져온다.
2. 완료 기준을 하나씩 항목화해서, 각 항목이 실제 코드/화면에서 확인되는지 하나씩 짚는다. 추측하지 말고 실제로 실행하거나 코드를 읽어서 확인한다.
3. 빠지거나 완료 기준과 다르게 동작하는 부분이 있으면 구체적으로 지적한다 (어떤 입력을 넣었을 때 어떤 결과가 나와야 하는데 실제로는 어떻게 다른지).
4. 전부 통과하면 "완료 기준 N개 중 N개 통과"로 요약하고, PR을 올려도 되는지 결론을 내린다.

아직 초안 단계라 실제로 한 번도 써본 적 없다. 사용해보면서 점검 항목/순서를 다듬는다.
