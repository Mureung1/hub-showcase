이 스킬은 사용자가 세션 내내 반복해서 요청한 규칙 하나를 고정해둔 것이다: **판단이 갈리는 지점에서는 스스로 결정하지 말고 먼저 질문한다.** CLAUDE.md의 "작업 방식" 항목과 같은 내용이며, 이 스킬은 그 규칙을 언제·어떻게 적용할지 조금 더 구체적으로 풀어둔 버전이다.

## 언제 질문하나

다음 중 하나에 해당하면, 실제 작업(파일 수정·리서치 반영·커밋 등)에 들어가기 전에 먼저 질문한다.

- 여러 타당한 선택지가 있고 정답이 하나로 정해지지 않을 때 (예: 라이브러리 선택, 우선순위 라벨 체계, 문서를 나눌지 합칠지)
- 리서치 범위를 스스로 좁히거나 넓혀야 할 때 (예: "운동 변형을 다 포함할지, 관절이 다른 것만 포함할지")
- 기존에 확정된 내용(기획서.md, CLAUDE.md, design.md 등)과 다르게 해석될 여지가 있을 때
- 사용자 지시를 문자 그대로 따르면 앞뒤가 안 맞거나 이미 정해둔 것과 충돌할 때

## 언제 질문하지 않나 (질문 남발 방지)

- 이미 이 세션이나 문서에서 확정된 내용을 그대로 적용하는 경우
- 정답이 하나뿐인 기계적 작업 (오탈자 수정, 이미 정해진 값 그대로 파일에 반영 등)
- 사용자가 이미 구체적으로 "이렇게 해줘"라고 지시한 경우

## 질문하는 방법

- 선택지를 2~4개로 좁혀서 제시하고, 근거와 함께 추천안을 먼저 놓는다 — 다만 최종 선택은 사용자가 하게 둔다.
- 판단 지점이 여러 개 동시에 있으면 한 번에 모아서 질문한다. 한 개씩 여러 턴에 걸쳐 나눠 묻지 않는다.

## 완료 후

질문에 대한 답을 받은 뒤에만 실제 작업을 진행한다. 답변받은 내용과 다르게 임의로 확장하거나 축소하지 않는다.
