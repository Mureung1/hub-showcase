> **재사용 방법**: 화면/컴포넌트 작업을 시킬 때 "우리 디자인 Skill 적용해서 만들어줘"라고 말하면 이 문서의 규칙을 따라 작업한다. 아래 "확정된 규칙"만 강제 규칙이고, "추후 결정" 항목은 지금 prototype.html의 값을 그대로 베끼지 말고 별도로 논의해서 정할 것.

## 색상 — 기본 (일반 화면)

| 변수         | 값        | 용도                     |
| ------------ | --------- | ------------------------ |
| `--bg`       | `#f7f5f1` | 배경, 웜 오프화이트      |
| `--panel-bg` | `#ffffff` | 카드/패널                |
| `--ink`      | `#1e2a3a` | 기본 텍스트, 다크 네이비 |
| `--ink-soft` | `#4b5a6b` | 보조 텍스트              |
| `--line`     | `#e1dcd2` | 구분선/보더              |
| `--coral`    | `#e8694f` | 포인트 컬러, CTA·강조    |

## 색상 — 개입 팝업 전용

**일반 화면의 배경·버튼에는 절대 쓰지 않는다.** 평소엔 조용하다가 팝업이 뜰 때 대비되는 효과를 내기 위한 색이다.

- 팝업 배경: `#0F2A3A` 고정. 오버레이 딤도 레벨과 무관하게 항상 동일.
- 레벨이 오를 때 바뀌는 건 포인트 컬러(배지·버튼·강조 테두리) 하나뿐:
  - Lv1 `#8FBDB6` (민트)
  - Lv2 `#209EBB` (블루)
  - Lv3 `#FFB701` (옐로우)
  - Lv4 `#E8362E` (레드)
- Lv1·Lv3처럼 밝은 포인트 컬러 위에는 흰 글자 대신 다크 네이비(`#0F2A3A`) 글자를 써서 대비를 확보한다.
- 압력 게이지 등 레벨 진행을 시각화하는 요소는 이 4색 그라데이션(민트→블루→옐로우→레드)을 그대로 재사용한다.

## 레이아웃

- 카드 radius: `14px`
- 일반 버튼 radius: `9px`
- 랜딩 CTA 같은 pill 버튼: `999px`
- 카드: 화이트 배경 + 1px 보더(`--line`), 패딩 `18~20px`
- 컨텐츠 최대 폭: `900px` 중앙 정렬 (랜딩 히어로 섹션만 예외로 `720px`)

## 타이포

- 헤딩: `800` weight, 다크 네이비
- 본문: `--ink-soft`, `14px` 내외
- 폰트: Pretendard 우선, 시스템 폰트 폴백

## 원칙

다크 네이비(`#0F2A3A`)와 Lv1~4 포인트 컬러는 **"개입 팝업" 전용**이며, 랜딩페이지나 일반 화면의 배경·버튼에는 절대 쓰지 않는다.

## 추후 결정 (아직 규칙 아님)

아래 항목은 prototype.html에 있던 스타일을 그대로 쓰고 있을 뿐, 레퍼런스 검토를 거쳐 확정된 게 아니다. 지금 코드의 값을 그대로 규칙으로 못박지 말 것 — 별도로 논의 후 이 문서에 반영한다.

- 홈 화면 통계 카드(진행 중/완료/스트릭) 스타일
- 할일 카드의 라벨 칩(유형/마감/회피이유) 색상·형태
- 보조 버튼(`btn-secondary`, `btn-ghost`) 톤
- 폼 인풋 스타일 (할일 등록 화면)
- 빈 상태(empty state) 디자인

### 확인 필요 — 아이콘 시스템 불일치

prototype.html은 이모지를 아이콘으로 쓰고 있는데, `CLAUDE.md`의 컨벤션은 "손으로 그린 인라인 SVG(24x24, stroke 기반, `aria-hidden`/`focusable="false"`)"로 되어 있어 서로 다르다. 어느 쪽을 따를지 확인 필요.
