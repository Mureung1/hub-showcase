> **재사용 방법**: 화면/컴포넌트 작업을 시킬 때 "우리 디자인 Skill 적용해서 만들어줘"라고 말하면 이 문서의 규칙을 따라 작업한다. 아래 "확정된 규칙"만 강제 규칙이고, "추후 결정" 항목은 지금 prototype.html의 값을 그대로 베끼지 말고 별도로 논의해서 정할 것.

## 색상 — 기본 (일반 화면: 랜딩/홈/등록/히스토리)

| 변수         | 값        | 용도                            |
| ------------ | --------- | ------------------------------- |
| `--bg`       | `#f4f5f7` | 배경, 쿨 그레이                 |
| `--panel-bg` | `#ffffff` | 카드/패널                       |
| `--ink`      | `#1e2430` | 기본 텍스트, 다크 네이비        |
| `--ink-soft` | `#656d7a` | 보조 텍스트                     |
| `--line`     | `#dde1e6` | 구분선/보더                     |
| `--accent`   | `#4c5fd5` | 포인트 컬러, CTA·주요 버튼·강조 |

`--coral`(`#e8694f`)은 일반 화면에서 더 이상 쓰지 않는다 — 팝업 전용으로 용도를 좁혔다 (아래 참고). CTA를 코랄로 두면 팝업 Lv4 레드와 색 계열이 겹쳐서 "위급함" 신호가 새어나가는 문제가 있어 인디고(`--accent`)로 교체했다.

## 색상 — 개입 팝업 전용

**일반 화면의 배경·버튼에는 절대 쓰지 않는다.** 평소엔 조용하다가 팝업이 뜰 때 대비되는 효과를 내기 위한 색이다.

- 팝업 배경: `#0F2A3A` 고정. 오버레이 딤도 레벨과 무관하게 항상 동일.
- 레벨이 오를 때 바뀌는 건 배지·버튼·강조 테두리 하나뿐:
  - Lv1 `#8FBDB6` (민트)
  - Lv2 `#209EBB` (블루)
  - Lv3 `#FFB701` (옐로우)
  - Lv4 `#E8362E` (레드)
- **텍스트 대비 규칙(코드 기준 확정)**: Lv1·Lv3처럼 밝은 포인트 컬러 위에는 다크 네이비(`#0F2A3A`, `var(--notif-bg)`) 글자를 쓴다. **Lv2·Lv4처럼 어두운 포인트 컬러 위에는 흰 글자(`#fff`)**를 쓴다. (`.lv-chip`/`.btn-notif-primary` 기본값이 흰 글자이며, Lv1·Lv3 클래스에서만 다크 네이비로 오버라이드하는 구조.)
- **코랄(`#e8694f`)은 팝업 안에서만, "레벨이 아직 안 붙은 기본 액션"에 쓴다**: 레벨 0(시작 대기) 상태의 "지금 시작하기" 버튼, 그리고 Lv2의 자유 텍스트 "보내기" 버튼(레벨색인 "지금 시작하기"와 구분되도록 별도 클래스 `btn-notif-accent`로 분리). 즉 코랄 = "이 액션은 특정 레벨의 escalation이 아니다"라는 의미로 쓴다.
- 팝업 안의 잔소리봇 아바타 아이콘 배경은 코랄이 아니라 `--avatar-bg`(`#5b6472`, 쿨그레이)를 쓴다 — 장식용 아이콘이라 브랜드 액션 색과는 분리한다. _(코드에는 아직 변수화 안 되어 있고 하드코딩 상태 — CSS에 `--avatar-bg` 변수를 추가하고 이 값을 참조하도록 정리 필요.)_

### 홈 화면 압력 게이지 전용 (팝업 색과 별개)

홈 화면의 압력 게이지(진행바)는 팝업 Lv 색이 아니라 별도 그라데이션을 쓴다 — 시각적으로 이 조합이 더 자연스럽다는 판단.

| 변수       | 값        |
| ---------- | --------- |
| `--gauge1` | `#4a6fa5` |
| `--gauge2` | `#6b5b95` |
| `--gauge3` | `#c24e5b` |
| `--gauge4` | `#d9822b` |

## 레이아웃

- 카드 radius: `14px`
- 일반 버튼 radius: `9px`
- 랜딩 CTA 같은 pill 버튼: `999px`
- 카드: 화이트 배경 + 1px 보더(`--line`), 패딩 `18~20px`
- 컨텐츠 최대 폭: `900px` 중앙 정렬
- **폼 화면(할일 등록)**: `640px` 폭으로 좁혀서 중앙 정렬. 헤더(제목+설명)는 좌우 분산이 아니라 세로로 쌓는다. 폼 카드는 패딩 `32~36px`, 은은한 그림자(`0 1px 3px rgba(30,42,58,.05)`) 사용.
- **개입 팝업**: 최대 폭 `540px`, radius `22px`, 패딩 `30px`. Lv2/Lv3처럼 질문·텍스트가 들어가는 레벨도 답답해 보이지 않도록 넉넉하게 잡는다.
- **랜딩 히어로(`.landing-hero`)**: 최대 폭 `820px`, 타이틀(`.landing-title`) `60px`/`900` weight, 서브카피 `18px`. 기능 소개는 큰 카드 대신 히어로 하단에 작은 라벨("핵심 기능")+헤드라인(`22px`)+알약형 태그 2개로 압축한다.

## 타이포

- 헤딩: 기본 `800` weight, 다크 네이비.
- **예외 — 랜딩 히어로 타이틀(`.landing-title`)만 `900` weight, `60px`를 쓴다.** 다른 화면의 헤딩을 더 크게 키워야 할 때는 weight `800`을 유지하고 font-size만 조정한다. (히어로만 유일하게 900이며, 나머지 헤딩까지 900으로 확장하지 않는다.)
- 본문: `--ink-soft`, `14px` 내외
- 폰트: Pretendard 우선, 시스템 폰트 폴백

## 아이콘

- 손그림 stroke 기반 인라인 SVG(24x24 viewBox, `aria-hidden="true"`, `focusable="false"`)를 기본으로 한다. 아이콘 라이브러리는 쓰지 않는다.
- 적용된 곳: 랜딩 기능 태그(번개=첫 행동, 타겟=맞춤 개입), "완료" 상태 칩의 체크 아이콘.
- 순수 장식성 이모지(🎉 등)는 제거하고, 굳이 아이콘이 없어도 되는 곳(피드백 버튼 "도움됐음"/"귀찮았음", "지금 확인하기")은 텍스트만 쓴다.
- 스트릭(🔥)은 예외로 유지 — 홈 통계 카드와 완료 팝업 모두에서 이미 일관되게 쓰이고 있어서 빼면 오히려 통일성이 깨진다.

## 원칙

- 다크 네이비(`#0F2A3A`)와 Lv1~4 포인트 컬러는 **"개입 팝업" 전용**이며, 랜딩페이지나 일반 화면의 배경·버튼에는 절대 쓰지 않는다.
- 일반 화면의 강조가 필요한 곳(마감 D-day 등)에 팝업 Lv 색을 빌려 쓰지 않는다 — 무채색(굵기로 강조) 또는 `--accent`를 쓴다.

## 추후 결정 (아직 규칙 아님)

- 홈 화면 통계 카드(진행 중/완료/스트릭) 스타일 — 아직 방향 미정
- 보조 버튼(`btn-secondary`, `btn-ghost`) 톤 — 새 할일 등록/지금 확인하기 색, 상단 네비바 탭 스타일 포함, 구체적 피드백 없어 보류 중
- 랜딩 히어로 캐릭터 일러스트 — 지금은 로고 아이콘(🤖 이모지)뿐. 나중에 실제 캐릭터 일러스트가 생기면 히어로를 2단 레이아웃(텍스트 좌 / 캐릭터 우, 크게)으로 바꿀 예정. 이때 팝업 안 레벨별 표정(🙂😐😟🔥)과 같은 캐릭터의 다른 표정처럼 보이게 디자인할 것.
- 아바타 배경(`#5b6472`)의 CSS 변수화 (`--avatar-bg`) — 값 자체는 확정, 코드 정리만 남음.

### 미해결 — 작업 전 확인 필수: 아이콘 시스템 일부만 정리됨

랜딩 기능 태그와 "완료" 칩은 SVG로 정리했지만, 잔소리봇 마스코트(🤖), 레벨별 표정(🙂😐😟🔥), 캘린더(📅), 말풍선(💬) 등은 아직 이모지 그대로다.

**이 아이콘들을 새로 만들거나 수정하는 작업이 오면, SVG로 전환할지 이모지를 유지할지 임의로 판단하지 말고 반드시 먼저 사용자에게 확인한다.** 캐릭터 일러스트 방향이 정해지기 전까지는 전면 SVG 전환을 진행하지 않는다 — 지금 일부만 바꾸면 마스코트 표정과 아이콘 스타일이 서로 안 맞을 수 있기 때문이다.
