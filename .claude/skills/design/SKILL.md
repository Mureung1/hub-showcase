# 디자인 규칙 적용 스킬

이 스킬은 `docs/skills/design.md`에 정의된 CSS 변수와 스타일 규칙을 그대로 가져와
실제 UI(컴포넌트, 페이지, 스타일시트 등)를 만들 때 적용한다. 코드가 규칙을 지키는지
검증만 하는 것이 아니라, 처음부터 규칙에 맞게 작성하는 것이 목적이다.

## 절차

1. **기준 문서 읽기**
   `docs/skills/design.md`를 읽어 현재 확정된 CSS 변수 전체
   (색상/폰트/모서리/여백/카드/모션)와 `사용 규칙`, `Do / Don't` 항목을 파악한다.

2. **하드코딩 대신 변수 사용**
   요청받은 UI를 만들 때 색상 hex, px 값 등을 직접 쓰지 않고 `design.md`의 CSS 변수
   (`--color-*`, `--font-*`, `--radius-*`, `--space-*`, `--card-*`, `--duration-*` 등)를
   그대로 사용한다.

3. **변수 블록 재사용/삽입**
   - 대상 파일이나 프로젝트에 이미 `:root` 변수 블록이 있다면 그것을 재사용한다.
   - 없다면 필요한 변수를 `:root`에 포함시켜 새로 만든다.
   - 임의로 새로운 색상/간격 값을 추가하지 않는다. 필요한 값이 `design.md`에 없다면
     가장 가까운 기존 토큰을 사용하거나 사용자에게 확인한다.

4. **Do / Don't 준수**
   - 텍스트 색상 위계(`text-strong → primary → secondary → tertiary → muted → disabled`)를
     용도에 맞게 구분해서 쓴다.
   - 주색은 CTA/핵심 강조에만 선명하게 쓰고, 넓은 면을 채우거나 장식용 그라디언트로 쓰지 않는다.
   - 카드는 테두리보다 그림자와 배경 대비로 구분하고, 카드 안에 카드를 중첩하지 않는다.
   - 버튼 높이는 최소 44px(`--button-height-sm`) 이상 확보한다.
   - 모션은 transform/opacity 위주로, `--duration-base` + `--ease-out`을 기본값으로 쓴다.

5. **결과 요약**
   작업이 끝나면 어떤 CSS 변수를 사용해 색상/타이포그래피/모서리/여백/카드 스타일을
   구성했는지 간단히 요약해서 알려준다.
