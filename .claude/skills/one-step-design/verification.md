# One-Step 디자인 완료 검증 기준

> 이 파일은 `one-step-design` Skill의 참고 문서다. 진입점은 `SKILL.md`.
> 화면/컴포넌트 구현 후 아래 항목을 점검한다. 하나라도 미충족이면 수정한다. 값·컴포넌트 근거는 `tokens.md`·`components.md`·`screens.md` 참고.

- [ ] 색상은 정의된 디자인 토큰을 사용한다.
- [ ] 임의의 HEX 색상을 화면 파일에 직접 작성하지 않는다.
- [ ] 노랑은 코인, 보상, 스트릭 이외의 용도로 사용하지 않는다.
- [ ] AI 및 정보 요소에는 블루 계열을 사용한다.
- [ ] 성장, 완료, 주요 행동에는 그린 계열을 사용한다.
- [ ] 카드와 컴포넌트의 라운드 규칙이 일관된다.
- [ ] 검은색 중심의 강한 그림자를 사용하지 않는다.
- [ ] 간격은 8px 베이스라인과 정의된 토큰을 따른다.
- [ ] 타이포그래피는 정의된 스타일과 Sora 폰트를 따른다.
- [ ] 정상, 로딩, 빈 상태, 오류 상태가 고려되었다.
- [ ] 버튼과 터치 요소의 터치 영역이 충분하다.
- [ ] 텍스트와 배경의 대비가 확보되었다.
- [ ] 기존 공통 컴포넌트와 토큰을 우선 재사용했다.
- [ ] 디자인 구현 때문에 비즈니스 로직을 임의로 변경하지 않았다.
- [ ] `flutter analyze`에서 새 오류가 발생하지 않는다.
