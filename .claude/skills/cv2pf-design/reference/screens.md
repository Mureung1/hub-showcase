# CV2PF 화면별 의도 (스티치 시안 대조표)

검수 시 실제 화면과 나란히 놓고 볼 “의도”. 각 시안 이미지는 저장소에 있다.

> 공통 셸: 상단 앱바(좌 `CV2PF` 워드마크 · 중 “도움말/가이드” · 우 “임시 저장” + 아바타) +
> 좌측 세로 사이드바 “프로젝트 흐름 · N단계 / 총 4단계” + 넓은 콘텐츠. 상단에 얇은 진행바.

## ① CV 업로드
- 시안: `cv-to-portfolio/stitch_designs/1._cv_kr/screen.png`
- 좌 카드 **“이력서 업로드”**: 파일 선택(.md/.txt, 최대 5MB) + 마크다운 입력 영역(휴지통).
- 우 카드 **“실시간 미리보기”**: 파싱 결과(기본정보·전문요약·경력 N개 감지)를 즉시 표시.
- 하단: `취소`(고스트) · `다음: 디자인 선택 →`(파랑). 내용 없으면 다음 비활성.

## ② 디자인 테마 선택
- 시안: `cv-to-portfolio/stitch_designs/2._kr/screen.png`
- 좌: 테마 카드 목록(미니 스와치 + 이름 + 한 줄 설명, 기본값에 “추천” 배지).
- 우: 선택 테마의 **DESIGN.md** 다크 코드 뷰어(문법 하이라이트, 신호등 점).
- 하단: `← 이전`(고스트) · `다음: 포트폴리오 생성 →`(**초록** — 다음이 생성 흐름의 전환).

## ③ 생성 중
- 시안: `cv-to-portfolio/stitch_designs/3._kr/screen.png`
- 좌: 단계 리스트(구조 분석 ✓ → 토큰 추출 ✓ → 콘텐츠 주입 ◌활성 → HTML 조립 ⏾대기).
- 우: **시스템 로그** 다크 터미널(`> … [OK]` 순차 출력).
- 카피가 “결정적 렌더러 · API 키 불필요”를 명시(안전성 신뢰).

## ④ 완성(결과)
- 시안: `cv-to-portfolio/stitch_designs/4._kr/screen.png`
- 상단: 초록 체크 원 + **“포트폴리오가 완성되었습니다!”** display 헤드라인.
- 카드: **라이브 미리보기 ↔ HTML 코드** 탭, 브라우저 크롬으로 감싼 iframe, “데스크톱 뷰” 토글.
- 하단 CTA: **`HTML 파일 다운로드`(초록)** · `코드 복사`(고스트) · `+ 새 프로젝트 시작`(고스트).

## 현재 구현과의 차이 (2026-07-09 기준, 열린 항목)
- 현 앱은 **상단 알약 스텝퍼 + 중앙 단일 컬럼**. 시안은 **좌측 세로 사이드바 셸 + 상단 앱바**.
  → 셸 레이아웃 전환은 2주차 개발 항목(불일치, 미해결).
- 토큰(색·폰트·반경)은 1차 정렬 완료 — `docs/design-review-2026-07-09.md` 참조.
