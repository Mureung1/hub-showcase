# CV2PF 디자인 시스템 — 상세 참조

SKILL.md의 빠른 참조를 넘어, 값을 정할 때 여는 문서. 출처: `stitch_designs/professional_career_engine/DESIGN.md` + 스티치 시안 4종.

## 1. 브랜드 & 톤

- 성격: **Professionalism · Efficiency · Empowerment**. 스트레스 받는 포트폴리오 제작을
  “통제된 진행감(controlled progress)”의 경험으로 바꾼다.
- 미학: **Corporate Modern** — 명료함·실용성 우선, 그러나 프리미엄하고 정돈된 느낌.
- 콘텐츠 우선(Content-First): UI는 물러나고 사용자의 이력이 주인공.

## 2. 색상

주색은 **Corporate Blue `#2563EB`**(신뢰·안정), 보조는 **Success Green `#059669`**(“생성”/
완료 보상). 중립은 Slate 스케일(차갑고 현대적).

| 역할 | HEX | 사용 |
| --- | --- | --- |
| primary | `#2563EB` | 버튼·활성 스텝·링크·진행바 |
| primary-strong | `#004AC6` | hover/강조 |
| primary-soft | `#EFF4FF` | 활성/선택 배경 틴트 |
| success | `#059669` | **생성·다운로드(전환)에만** |
| success-soft | `#ECFDF5` | 완료 배경 틴트 |
| ink | `#0F172A` | 본문 텍스트 |
| muted | `#64748B` | 보조 텍스트·메타·라벨 |
| line | `#E2E8F0` | 테두리·구분선 |
| surface | `#FFFFFF` | 카드 |
| background | `#F8FAFC` | 작업 영역 |
| error | `#B91C1C` / bg `#FEF2F2` | 에러 텍스트/배경 |

- **접근성:** 텍스트·인터랙티브 색 조합은 WCAG AA. ink/background 대비 ≈ 15.6:1.

## 3. 타이포그래피

- 서체: **Inter**(화면 최적, 큰 x-height) 단일. 한글은 Pretendard→시스템 폴백.
- 위계(권장 스케일):

| 역할 | 크기/행간 | 굵기 | 비고 |
| --- | --- | --- | --- |
| display | 48 / 56 | 700 | 완성 화면 헤드라인 |
| headline-lg | 32 / 40 | 600 | 화면 제목 (letter-spacing -0.01em) |
| headline-md | 24 / 32 | 600 | 카드 제목 |
| body-lg | 18 / 28 | 400 | 리드 문단 |
| body-md | 16 / 24 | 400 | 본문 |
| label-md | 14 / 20 | 500 | 라벨 |
| label-sm | 12 / 16 | 600 | 메타·배지(대문자 자주) |

- 본문 행간은 넉넉히(1.5×) — 검토/편집 피로 감소.

## 4. 간격 · 그리드

- 4px 베이스. xs 4 · sm 8 · md 16 · lg 24 · xl 32 · xxl 48.
- 데스크톱 12컬럼 고정 그리드, 뷰포트 중앙 정렬. gutter 24px.
- 컨테이너 최대폭 ~1200px(도구), 생성물 읽기폭은 별도.

## 5. 반경

- 8px(버튼·입력·작은 카드) · 12–16px(큰 섹션/워크스페이스) · 24px(디자인 선택 “오브젝트” 카드)
  · 999px(칩/배지). 도구 UI 버튼을 999px 알약으로 만들지 말 것(현재 코드의 개선 포인트).

## 6. 엘리베이션

- **L0 배경:** 평평한 작업 영역.
- **L1 카드:** 흰 배경 + 1px `#E2E8F0` + `y2 blur4 rgba(0,0,0,.05)`.
- **L2 hover:** `y4 blur12 rgba(0,0,0,.08)` — 살짝 떠오름.
- **L3 모달/팝오버:** 더 강한 대비 그림자.

## 7. 컴포넌트 규격

### 버튼
- Primary: 파란 채움, 흰 텍스트, 8px, 포커스 링 2px offset.
- Success: 초록 채움 — **“생성”/“다운로드/내보내기”에만**.
- Ghost: 중립 테두리, hover 전까지 채움 없음 — 보조(뒤로 등).

### 스텝퍼 (4단계)
- Active: 파란 원 + 흰 번호, 굵은 라벨.
- Completed: 초록 원 + 흰 체크, 중립 라벨.
- Pending: 회색 테두리 원 + 회색 번호, 흐린 라벨.
- 좁은 화면: “N / 4단계” + 진행바로 축약.

### 입력 필드
- 흰 배경, 8px, 1px 회색 테두리. Active: 파란 테두리 + 3px 소프트 블루 글로우.
- Error: 빨간 테두리 + 바로 아래 도움말 텍스트.

### 디자인 선택 카드
- 큰 썸네일. Selected: 3px 파란 테두리 + 우상단 체크 배지, 반경 24px.

### DESIGN.md 뷰어 (화면 ②)
- 다크 코드 패널(터미널풍) + 문법 하이라이트, 우상단 신호등 점 3개. 선택 테마의 원문 표시.

### 생성 로그 터미널 (화면 ③)
- 다크 패널에 `> … [OK]` 라인이 순차 출력. 진행 단계(분석→토큰→레이아웃→조립)와 병치.

### 결과 미리보기 프레임 (화면 ④)
- 브라우저 크롬(신호등+주소창)으로 감싼 iframe. “라이브 미리보기 ↔ HTML 코드” 탭.

## 8. 반응형

- 데스크톱: 좌우 분할(입력 좌 · 미리보기 우) + 좌측 사이드바 4단계.
- 태블릿: 세로 스택 + “미리보기 보기” 토글.
- 모바일: 단일 컬럼, 하단 고정 내비로 주요 액션.
