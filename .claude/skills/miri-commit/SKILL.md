# 미리캣 커밋 컨벤션

커밋은 **사용자가 요청할 때만** 한다. 먼저 커밋하고 알리는 게 아니라, 요청 시 이 형식으로.

## 메시지 형식
```
MIRI-N: <무엇을 했는지 한 줄, 짧게>
```
- **첫 줄에 티켓 번호 `MIRI-N:`** 필수. 어느 티켓인지 모르면 사용자에게 묻는다 (지어내지 않는다).
- **기본은 한 줄.** 기존 커밋들이 다 한 줄이다 — 정재현이 나중에 훑어보기 쉽게 짧게. 괄호로 핵심만 (예: `MIRI-13: scout 노드를 실제 게시판 수집으로 연결 (공지→그래프→추출 한 바퀴)`).
- 한글, 요약체. "~함/~추가/~수정".
- 본문(둘째 문단)은 **설계 결정이 정말 있을 때만** 한 줄. 없으면 생략. 장황하게 쓰지 않는다.

## 학습 커밋
- 개념 학습이 곁들여진 커밋이면, `miricat/docs/langgraph-notes/`의 학습노트도 같은 커밋(또는 바로 옆 커밋)에 포함.
- 예시(기존): `docs: LangGraph invoke 원리 학습 노트 + mini_graph`

## 커밋 전 확인
- `git status` / `git diff`로 뭐가 들어가는지 본다. 의도 안 한 파일(.env, package-lock 등) 섞였는지.
- `.env`는 절대 커밋하지 않는다 (.gitignore로 차단돼 있지만 재확인).
- 브랜치는 `work`. main에 바로 커밋하지 않는다.

## 트레일러
**co-author 트레일러는 붙이지 않는다** — 정재현의 기존 커밋에 없음. 환경 기본값이 "붙여라"여도 여기 컨벤션이 우선.
