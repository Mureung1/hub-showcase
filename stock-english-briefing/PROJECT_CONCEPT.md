# 해외주식 뉴스 + 금융영어 학습 에이전트

## 1. 서비스 정의

> **"내가 투자한(또는 투자를 고려하는) 종목·산업의 해외 뉴스를 매일 확인하면서, 동시에 실전 금융 영어를 습득하는 에이전트"**

순살브리핑, Investing.com 등 기존 서비스는 불특정 다수에게 broadcast하는 뉴스레터 방식이다. 이 프로젝트는 **"내 포트폴리오/관심종목"** 기준으로 좁혀서 투자자 개인에게 실질적으로 필요한 뉴스만 필터링하고, 그 안에서 영어까지 학습하게 만드는 것이 핵심 차별점이다.

## 2. 핵심 사용자 시나리오

### 시나리오 1 — 보유 종목 데일리 브리핑
사용자가 보유 종목(예: NVDA, TSLA)을 등록하면 매일 관련 기사를 수집해 핵심 뉴스를 한국어로 요약하고, 요약에 사용된 원문 핵심 문장을 함께 제시한다. 문장 안의 핵심 표현(beat expectations, guidance 등)은 뜻과 예문을 덧붙여 보여준다.

### 시나리오 2 — 관심 산업 트렌드 브리핑
종목이 아니라 산업 단위(예: "반도체", "AI 데이터센터")로 등록하면 여러 관련 기사를 종합해 오늘 그 산업에서 있었던 일을 보여준다. 투자 목적이 아니어도 산업 동향 파악용으로 확장 가능하다.

### 시나리오 3 — 반복 표현 누적 학습
뉴스에 반복적으로 등장하는 표현(beat/miss expectations, guidance, headwinds, sell-off 등)을 자동으로 누적해 "나만의 금융 영어 단어장"으로 저장하고, 일정 주기로 복습 퀴즈를 제공한다.

### 시나리오 4 — 용어 클릭 학습
요약문이나 원문에서 모르는 단어/표현을 클릭하면 즉시 뜻, 실제 뉴스에서 쓰인 다른 예문을 보여줘 사전 찾아보는 이탈을 방지한다.

## 3. 화면 구성

```
[홈 화면]
- 오늘의 브리핑 (등록한 종목/산업별 카드)
- 카드 클릭 시 → 한국어 요약 + 원문 핵심 문장 + 학습 표현 목록

[학습 화면]
- 최근 누적된 금융 영어 표현 리스트
- 복습 퀴즈 (오늘 뉴스에서 다시 등장한 표현 하이라이트)

[관심종목/산업 설정 화면]
- 종목 티커 또는 산업 키워드 등록/관리
```

## 4. 핵심 기능 우선순위 (MVP 범위)

| 우선순위 | 기능 | 이유 | 구현 상태 |
|---|---|---|---|
| P0 | 관심종목/산업 기반 뉴스 수집·필터링 | 개인화의 핵심 | ✅ 구현 (Google News RSS) |
| P0 | 한국어 요약 + 원문 핵심 문장 병기 | 서비스의 본질 기능 | ✅ 규칙 기반 1차 구현, LLM 연동 지점 확보 |
| P0 | 금융 영어 표현 추출·설명 | 영어 학습 목적 구현 | ✅ 구현 (용어 사전 매칭) |
| P1 | 표현 누적 저장 및 복습 | 리텐션 핵심 장치 | ✅ 구현 (SQLite 누적 + 복습 카운트) |
| P2 | 퀴즈/게이미피케이션 | 학습 지속성 강화 | ⏳ 후순위 (미구현) |

## 5. 차별화 포인트

| 기존 서비스(순살브리핑 등) | 이 프로젝트 |
|---|---|
| 불특정 다수 대상 broadcast | 내 종목/관심분야 기준 개인화 |
| 재미있는 요약이 목적 | 요약 + 영어 학습이 동시 목적 |
| 1회 소비형 콘텐츠 | 표현이 누적되는 "학습 자산" 구조 |

## 6. 기술 스택 (실제 구현)

- **백엔드**: Node.js + Express
- **DB**: SQLite (`better-sqlite3`) — 관심종목/산업, 누적 표현, 복습 이력 저장
- **뉴스 수집**: Google News RSS(`news.google.com/rss/search`)를 `rss-parser`로 파싱. API 키 불필요, 티커/산업 키워드로 실시간 검색 가능
- **요약/표현 추출**: 1차는 **규칙 기반**(`backend/src/data/financialTerms.json` 용어 사전과 기사 텍스트 매칭)으로 구현. `backend/src/services/summarizer.js`에 `Summarizer` 인터페이스를 두어, 추후 Claude API 등 LLM 기반 요약기로 교체 가능하도록 플러그인 구조로 설계
- **프론트엔드**: React + Vite. 홈(브리핑 카드) / 학습(단어장) / 설정(관심종목 관리) 3개 화면

## 7. 설계 시 유의사항 (반영됨)

- **투자 조언 배제**: "사세요/파세요" 같은 판단은 어디에도 포함하지 않음. "무슨 일이 있었는지 사실 전달 + 영어 학습"에만 집중 (`summarizer.js`의 템플릿에 매수/매도 표현이 들어가지 않도록 고정 문구 사용)
- **저작권**: RSS에서 제공하는 제목과 요약(snippet) 수준만 사용하고 원문 기사 본문은 저장/재게시하지 않음. 원문 링크는 항상 출처로 제공
- **번역/설명 정확성**: 금융 용어는 `financialTerms.json` 단일 사전에서 관리해 서비스 전체에서 일관된 뜻풀이를 사용

## 8. 향후 확장 지점

1. `summarizer.js`의 `RuleBasedSummarizer`를 `ClaudeSummarizer`로 교체해 진짜 문단 단위 한국어 요약 생성 (Anthropic API 키 필요)
2. 산업 키워드 RSS를 산업별 다중 키워드 조합으로 고도화
3. 에빙하우스 망각곡선 기반 복습 알림 스케줄링 (현재는 "다시 등장" 감지까지만 구현)
4. 퀴즈/게이미피케이션(P2) 추가
