# 작업 분해

## 1단계: 기본 화면 만들기

- [ ]  글자와 버튼이 들어갈 기본 파일 세팅 (`index.html`, `style.css`, `app.js`)
- [ ]  내 몸 상태(증상)를 체크할 수 있는 설문지 화면 만들기
- [ ]  몸 상태에 따른 추천 성분과 과다복용 경고를 보여줄 결과 화면 만들기
- [ ]  중소기업 제품 정보와 스마트스토어 링크 버튼이 들어간 추천 카드 만들기

## 2단계: 기능 작동시키기 (계산 및 연결)

- [ ]  설문 결과를 분석해서 필요한 영양소 성분을 골라주는 기능 만들기
- [ ]  복용 중인 영양제들의 성분을 다 더해서 하루 기준치 초과 여부 알려주는 경고 로직 만들기
- [ ]  추천 성분에 맞는 중소기업 제품을 매칭해서 연결해주는 기능 만들기

## 3단계: 화면 연결하고 다듬기

- [ ]  버튼을 클릭했을 때 화면이 자연스럽게 넘어가도록 연결하기
- [ ]  글씨 크기와 정렬, 색상을 보기 좋게 정리하기
