# 연간결산 보고서 자동화 — 세무조정 엔진 (Python)

> 이 프로젝트의 **실제 산출물**(트랙 A). 종이 연간결산 보고서를 코드로 재현해 검증하고,
> 그 엔진으로 세무사 전달용 초안을 만든다. 전체 계획은 [`PLAN.md`](PLAN.md), 흐름 데모는 [`demo/`](demo/).

## 왜 Python인가

기술 스택 조사([`notes/기술스택-결정.md`](notes/기술스택-결정.md)) 결과, 세무 계산의 정확성 급소는
**금액을 부동소수로 다루는 것**이었다. Python `decimal.Decimal`은 이 오차를 언어 차원에서
원천 차단한다 — 모든 금액을 `Decimal`로 다루고 원 단위로 명시적 절사/반올림해 확정한다.
(사용자가 직접 코드를 읽을 수 있다는 점도 결정 요인.)

## 실행

```bash
python --version                              # 3.11 이상
python -m unittest discover -s tests          # 엔진 검증 27개
python -m taxengine.cli.reproduce             # 예시 템플릿으로 재현 시연
python -m taxengine.cli.reproduce --dir data/private/fy2025   # 실제 종이책 데이터로
```

설치할 것 없음 — 표준 라이브러리(`decimal`, `csv`, `unittest`)만 사용, 의존성 0개.
Windows에서 한글 출력이 깨지면 `PYTHONIOENCODING=utf-8`을 앞에 붙인다.

## 검증 철학

테스트 기댓값은 **세법이 정한 외부 정답**이다(상각률표 별표4, 세율표 §55). 순환논증이 아니다.

- **검증한다**: 교과서 예제(1억·5년 정률 = 45,100,000), 내부 정합성(대차평형), 법적 제약(건물에 정률 주입 시 무시), 통합 재현
- **음성 케이스도 검증**: 대차가 안 맞거나 기초누계가 취득가를 넘으면 검증기가 잡는다 (항상 초록이 아님)
