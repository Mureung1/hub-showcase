# 연간결산 보고서 자동화 — 세무조정 엔진

> 이 프로젝트의 **실제 산출물**(트랙 A). 종이 연간결산 보고서를 코드로 재현해 검증하고,
> 그 엔진으로 세무사 전달용 초안을 만든다. 전체 계획은 [`PLAN.md`](PLAN.md), 흐름 데모는 [`demo/`](demo/).

## 실행

```bash
npm test                                   # 엔진 검증 27개 (node --test)
npm run reproduce                          # 예시 템플릿으로 재현 시연
npm run reproduce -- --dir data/private/fy2025   # 실제 종이책 데이터로
```

빌드 스텝 없음 — Node 20+ 순수 ESM. 의존성 0개.

## 지금까지 된 것 (2026-07-16)

**종이책 CSV → 무결성 검증 → 감가상각 시부인 → 세무조정 집계 → 별지3 세액 → 정답지 대조**
전 과정이 끝까지 돌고, 예시 기준 **차감납부세액이 정답지와 원단위 일치**한다(재현 성공).

```
  [1] 입력 무결성 검증      대차평형 · 당기순이익 연결 · 자산대장 정합성
  [2] 감가상각 시부인       자산별 상각범위액 vs 회사계상액 (§5)
  [3] 소득금액조정합계표    개별 조정 + 감가부인 자동 합산
  [4] 별지3 세액조정계산서  당기순이익 → 과세표준 → 세율 → 차감납부세액
  [5] 종이책 정답지 대조    엔진값 vs 실제값, 항목별 채점
```

## 검증 철학

테스트 기댓값은 **세법이 정한 외부 정답**이다(상각률표 별표4, 세율표 §55). 내가 지어낸 게 아니라 순환논증이 아니다.

- **검증한다**: 교과서 예제(1억·5년 정률 = 45,100,000), 내부 정합성(대차평형), 법적 제약(건물에 정률 주입 시 무시), 통합 재현
- **음성 케이스도 검증**: 대차가 안 맞거나 기초누계가 취득가를 넘으면 검증기가 잡는다 (항상 초록이 아님)
