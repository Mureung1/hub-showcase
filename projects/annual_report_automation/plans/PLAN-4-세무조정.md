## 1. 이 단계의 위치

> ⚠️ 2026-07-16 팩트체크로 **재평가됨.** 이전 버전은 "세무사랑Pro가 이미 자동화해서 차별점이 약하다"고 적었으나,
> 조사 결과 **과장**이었다. 근거: [`../notes/팩트체크-자동화-현황.md`](../notes/팩트체크-자동화-현황.md) §3

**강점 1: 지금 당장 시작할 수 있고, 채점도 완벽하다.**
종이책 안에 이 단계의 **입력(재무제표·자산명세)과 출력(조정명세서·별지3 세액)이 둘 다** 들어 있다. 통장도 인증서도 필요 없다. 차감납부세액 원단위까지 채점된다.

**강점 2: 생각보다 비어 있다.** [검증됨]

| 증거 | 내용 |
|---|---|
| **더존비즈온 2025.2** | "AI로 법인세 신고 — **반나절 걸리던 세무조정을 3분 만에**" |
| **WEHAGO T 2025.3.1** | "AI 법인 세무조정" 출시. 기존: **"수임기업별 3시간 이상"**, "고연차 직원만 가능" |

→ 이미 자동화됐다면 업계 최대 벤더 두 곳이 2025년에 이걸 신제품으로 팔 이유가 없다. **기존 상용 프로그램을 쓰면서도 반나절~3시간이 걸렸다**는 업계 자백이다. 그리고 AI 버전조차 세무사에게 **"검토만 하세요"**라고 한다 — 우리 설계와 같은 "초안 + 사람 검토" 구조.

**자동화의 경계**: 서식 채우기·반복 계산(부가세·감가상각·최저한세)·"간편조정"은 자동. **판단 항목은 빈 곳** — 접대비 한도초과 판단, 임원상여·퇴직금 한도, **소득처분(귀속자 판정)**, **부당행위계산부인**, 이월결손금 활용 전략.

**강점 3: 일반 법인용 제품이 시장에 없다.** [검증됨]
세무사랑Pro는 뉴젠솔루션 공식 페이지 원문이 **"세무회계사무소용"**. KcLep·경리나라는 **법인조정 모듈 자체가 없고**, 이카운트는 "국세청에서 무료로 받으라"고 안내한다. 자비스도 세무조정료를 별도 청구한다(결국 세무사가 수행).

**⚠️ 단, 법적 장벽**: 외부조정 의무(시행령 **§97조의2**) 대상이면 조정반 소속 세무사만 조정계산서를 작성할 수 있다. 자기조정 가능 법인은 사실상 **매출 3억 미만 + 감면 없음 + 준비금 없음**인 극소형뿐. → 우리 법인이 대상인지 확인 필요 (`../PLAN.md` §8 Q1)

**이 단계의 가치 정리:**
1. **절세 시나리오 엔진의 토대** — 세액을 계산할 수 있어야 시나리오를 비교한다. **상용도 이건 안 해준다**
2. **1·2·3단계 자동화의 최종 채점기** — 분개가 맞았는지의 궁극적 증명은 "세액이 맞게 나왔는가"다
3. **판단 항목이라는 빈 곳** + **일반 법인용 시장의 공백**
4. **가장 먼저 검증되는 성과** — 통장 확보를 기다리는 동안 병렬 진행 가능

## 3. 모듈 구성

각 모듈은 research.md의 예제 수치로 **단위테스트를 먼저 작성**한다 (`node --test`). 이건 mock이 아니라 세법이 정한 외부 정답이다.

| # | 모듈 | 핵심 로직 |
|---|---|---|
| 4-A | 감가상각 시부인 | `회사계상액 – 상각범위액` → (+)부인액 손금불산입(유보) / (–)시인부족액은 전기이월부인액 한도 내 추인. **자산별 계산, 통산 금지.** 즉시상각의제, 승용차 5년 정액 강제 |
| 4-B | 기업업무추진비 | ① 적격증빙 검증(건당 3만원 초과) ② 한도 = 기본(중소 3,600만)×월수/12 + 수입금액×적용률(0.3/0.2/0.03%). 소규모 임대법인 50% 축소 |
| 4-C | 업무용승용차 | 전용보험 미가입 시 전액 부인 → 운행기록부 유무(비율 vs 1,500만) → 감가상각비 800만 한도 → 초과분 상여 처분 |
| 4-D | 세금과공과 판정 | 계정 적요·거래처 키워드 규칙표로 손금/불산입 판정 (자동화 최적) |
| 4-E | 선급비용 | 미경과분 손금불산입(유보) + 전기분 손금산입(△유보) 추인 |
| 4-F | 임대보증금 간주익금 | 부동산임대업 주업 + 차입금 과다 법인 해당 시 |
| 4-G | 원천납부세액 | 이자 원천징수영수증 집계 → 기납부세액 |
| 4-H | **유보 관리** | 조정 → 소득처분 꼬리표 → 자본금과적립금(을) 기초·증감·기말 자동 생성. **연도 간 연속성 검증** |
| 4-I | 조정 집계 | 소득금액조정합계표 (좌: 익금산입·손금불산입 / 우: 손금산입·익금불산입). ⚠️ 기부금 한도초과는 여기 안 넣고 별지3에서 직접 가감 |
| 4-J | **세액 계산 (별지3)** | 당기순이익 → ±조정 → ±기부금 → 각사업연도소득 → 이월결손금(중소 100%/일반 80%) → 과세표준 → 세율 → 최저한세 → 공제감면 → 가산세 → 기납부 → **차감납부세액** |
| 4-K | 지방소득세 | 과세표준 공유 + 독립세율(0.9/1.9/2.1/2.4%). 다지자체면 안분 |
| 4-L | 집계 서식 | 별지1 표지, 감가상각 합계표, 공제감면 합계표 — 하위 서식 완성 시 자동 |

**세율 선택**: 사업연도 개시일 기준 자동 분기. `~2025 개시: 9/19/21/24%` / `2026.1.1~ 개시: 10/20/22/25%` (research.md §7)

## 7. 5단계 확장 — 절세 시나리오 엔진 (원안 전면 구현)

이 엔진이 완성되면 그 위에 얹는다. **이건 상용 프로그램이 안 해주는 영역이라, 4단계의 진짜 차별점이다.**

| # | 담당 | 작업 |
|---|---|---|
| 5-1 | [클로드] | **결정 변수 공간 정의** (`보고서-준비물-워크플로우.md` §1-E): 임의상각 수준(0~상각범위액), 신규 취득자산 상각방법·내용연수(±25%), 결산조정 계상 여부, 배당 규모, 세액공제 당기/이월 |
| 5-2 | [클로드] | **법적 제약을 코드로 강제**: 건축물=정액법만, 기존 자산 방법 변경 불가(계속적용), 최저한세 자동 적용 → 불법 조합은 생성 자체가 불가능 |
| 5-3 | [클로드] | 적법 조합 열거 → 4단계 엔진으로 전 조합 계산 → **세액 비교표** (조합별 세액·차이·근거 조문) |
| 5-4 | [클로드] | 다년 관점 경고: **과세이연형**(올해 덜 내면 내년에 더 냄 — 유보로 이월)과 **절대 절감형**을 구분 표기 |
| 5-5 | **[사용자]** | 비교표 해석 → 세무사와 논의할 후보 선정 |

**포지셔닝**: "추천"이 아니라 **"적법 조합 비교표 + 근거 조문"**. 최종 판단은 세무사 — 세무대리 업역 리스크 회피.

## 8. 다른 단계와의 연결

- 입력(재무제표) ← 3단계 / 회사계상 상각비 ← 2단계 / 증빙유형 태그 ← 1단계 (R2)
- 출력(세액) → 2단계 법인세비용으로 역류 (순환 루프)
- **재현 산출물 = 내년의 전기 이월 DB**: 유보 잔액·이월결손금·부인액 누계가 그대로 다음 해 입력이 된다
