# 2단계 계획 — 결산 자동화 (결산수정분개 → 시산표)

> 작성일: 2026-07-15 · 상위 문서: `../PLAN.md` · 계산 원리: `../notes/세무조정계산서-결산보고서-research.md` §4-2, §5

---

## 1. 이 단계가 하는 일

1단계의 전표는 "실제로 돈이 오간 거래"만 담고 있다. 결산은 여기에 **돈이 안 오갔지만 회계적으로 인식해야 하는 것**을 얹어 장부를 마감하는 작업이다.

```
수정전시산표
   ↓ 결산수정분개
     ① 감가상각비 계상        (자산이 닳은 만큼 비용)
     ② 선급비용 정리          (보험료 중 내년 몫을 자산으로)
     ③ 미수수익·미지급비용     (발생했지만 아직 안 받은/안 낸 것)
     ④ 선수수익               (미리 받은 임대료)
     ⑤ 대손충당금 설정        ← 결산조정 항목 (계상해야만 손금)
     ⑥ 재고 실사 반영         (임대업이면 보통 해당 없음)
     ⑦ 법인세비용 계상        ← ⚠️ 4단계와 순환 (아래 §4)
   ↓
수정후시산표 → 3단계로
```

---

## 2. 입력 / 출력 / 정답지

**입력**
| 자료 | 출처 | 비고 |
|---|---|---|
| 1단계 전표 (수정전시산표) | 1단계 산출물 | |
| **자산대장** | 종이책의 유형자산감가상각비명세서 | 자산별 취득가·취득일·상각방법·내용연수·기초 누계액 |
| 기간비용 계약 정보 | 보험증권·임대차계약서 | 지급일·대상기간 (선급비용 안분용) |
| 4단계 세액 계산 결과 | 4단계 엔진 | 법인세비용 계상용 — 순환 |

**출력**: 결산수정분개 + 합계잔액시산표

**정답지**: 종이책의 **합계잔액시산표** (전 계정 차변합계/차변잔액/대변잔액/대변합계)

> 시산표는 계정 하나하나가 다 찍혀 있어서 채점 해상도가 재무제표보다 높다. 1단계 분개 AI의 채점에도 재무제표보다 시산표가 더 좋은 정답지다.

---

## 3. 핵심 로직

**① 감가상각** (research.md §5 — 이 프로젝트에서 로직이 가장 두꺼운 부분)
- 정액법: `취득가액 × 정액법 상각률` / 정률법: `미상각잔액 × 정률법 상각률`
- 상각률표(별표4), 기준내용연수표(별표5·6) 내장
- 신규 취득 연도 월할 (1개월 미만은 1개월)
- 업무용승용차: **5년 정액법 강제**
- ⚠️ 회계상 계상액과 세법상 상각범위액은 **다른 개념**이다. 2단계는 "회사가 장부에 얼마를 적을 것인가"(회계), 4단계는 "세법이 얼마까지 인정하는가"(시부인). 여기서 계상한 금액이 4단계 시부인의 입력이 된다.

**② 선급비용 안분**: `지급액 × 미경과일수 / 총일수`

**③ 대차평형 검증**: 차변총계 = 대변총계. 단, research.md §4-2의 지적대로 이건 전기(轉記) 오류만 잡고 **분개 자체의 오류(계정 착오)는 못 잡는다.** 계정 착오는 정답지 대조로만 잡힌다.

---

## 4. ⚠️ 순환 참조 — 이 단계의 유일한 구조적 난점

```
법인세비용을 계상해야 → 당기순이익이 확정되고
당기순이익이 확정돼야 → 4단계 세무조정으로 세액이 나오고
세액이 나와야      → 법인세비용을 계상할 수 있다
```

실무에서는 **반복 계산(iteration)**으로 푼다. 설계:
1. 법인세비용 0으로 두고 시산표 → 3단계 재무제표 → 4단계 세액 계산
2. 나온 세액을 법인세비용으로 계상 → 시산표 재생성 → 재계산
3. 세액이 수렴할 때까지 반복 (보통 2~3회면 수렴)

> 이 순환 때문에 2·3·4단계는 **한 번에 쭉 흐르는 파이프라인이 아니라 수렴 루프**로 설계해야 한다. 아키텍처를 짤 때 처음부터 반영할 것.

## 6. 완료 기준

- 감가상각 엔진이 research.md §5 교과서 예제와 원단위 일치 (외부 정답이 있는 검증 — mock이 아님)
- 생성된 시산표가 종이책 합계잔액시산표와 계정별로 일치, 또는 차이가 전부 설명됨
- 법인세비용 수렴 루프가 2~3회 내에 안정적으로 수렴

## 7. 리스크

| # | 리스크 | 대응 |
|---|---|---|
| R1 | 자산대장의 **기초 누계액·전기 상각방법 신고 내역**이 종이책에 안 나올 수 있음 | 종이책 감가상각명세서에 기초누계액은 통상 있음. 없으면 전기 신고서 확인 필요 (세무사무소 요청) |
| R2 | 대손충당금 등 **결산조정 항목은 "선택"** — 세무사가 실제로 얼마를 설정했는지는 종이책 결과에서 역산해야 함 | 이건 비결정론 항목. 재현 시에는 종이책 값을 그대로 입력하고, 5단계 절세 시나리오에서 변수로 승격 |
| R3 | 순환 참조 미수렴 (진동) | 수렴 조건·최대 반복 횟수 명시. 세액은 단조 함수라 실무상 수렴함 |
| R4 | 회계상 상각액 ≠ 세법상 상각범위액을 코드에서 혼동 | 2단계(회계 계상)와 4단계(세법 시부인)를 별도 모듈로 완전히 분리. 같은 함수 재사용 금지 |

## 8. 다음 단계와의 연결

- 출력(수정후시산표) → **3단계** 재무제표 생성의 입력
- 감가상각 회사계상액 → **4단계** 시부인의 입력 (`회사계상액 – 상각범위액 = 부인액/시인부족액`)
- 자산대장은 **4단계와 공유**하는 마스터 데이터 — 한 곳에서 관리
