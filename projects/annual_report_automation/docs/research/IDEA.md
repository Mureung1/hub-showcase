# 기본적 아이디어
지금 내가 원하는 것은 연간결산 보고서 (세무조정 보고서 + 결산보고서 notes\연간결산_보고서_내용들.md 이 문서에 적혀있는 내용들을 인간의 힘이 아닌 ai 혹은 코드를 통해 작성하여 각각의 것들을 제작한 후 최종적으로 모아 연간 결산 보고서 ) 제작을 자동화를 하고 싶음. 

# 세부 아이디어

## feature 1 자동화에 관하여

- 연간결산 보고서의 내용을 크게 결정론적인 자료와 비결정론적인 자료로 나누자. 

  - 결정론적 자료란
    - 홈택스에서 발급하여서 세무사의 세법을 활용하는 기술적 영역이 아닌 홈택스에서 발급 신청을 한다면 어떠한 사람이 발급을 해도 항상 같은 결과가 나오는 내역들 

  - 비결정론적 자료란
    - 세법 혹은 회계상의 방법 (예를 들어 감가상각을 정액법을 쓸 경우 혹은 정률법? 내지는 다른 방법)에 따라 결론이 다른게 나오는 문서를 의미한다. 

- 자료의 구조에 따라 자동화 방식에 차이가 생긴다.
  
  - 결정론적 자료의 경우

    - 홈택스를 통해서 발급해야하는 경우

    - 그렇지 않은 경우 

  - 비결정론적 자료의 경우
    
    - 방법론에 따라 자동화를 다르게 진행한다. 
    
    - 방법
    
      - 실제 세무 회계상 계산의 공식이 어떻게 진행되는지 파악한다. 
    
      - 각각의 방법에 따라 다르게 계산 코드를 작성한다. 

- 합법적인 선에서 절세를 할 수 있는 방법을 검토한다. 

- 예상 파이프라인 **확정되지 않음** 
  1. 홈택스 혹은 은행 을 통해 결정론적 자료를 수집한다.
  2. 수집한 자료를 비결정론적 자료의 산출을 위해 입력한다.
  3. 비결정론적 자료의 경우 경우에 따라 결과가 다르게 나오기 떄문에 경우의 수를 계산한다. 
  4. 모든 경우의 수를 계산 한 후 각각의 경우의 수를 병렬로 계산한다.
  5. 사용자가 원하는 방향 (세금을 줄이고 싶다. 즉 절세 (합법적))을 바탕으로 결론을 도출한다. 
  6. 최종 양식에 맞게 문서형태로 산출 한다.
