## 0. 한 장 요약 — 전체 생산 라인

보고서의 모든 항목은 아래 5단계 생산 라인 중 **어느 단계의 산출물인가**로 분류된다.
핵심 통찰: **지금 갖고 계신 종이 보고서는 3~5단계의 산출물만 담고 있고, 1~2단계의 재료(전표·증빙)는 담고 있지 않다.**

```
[0단계: 원천자료 수집]     통장내역, 증빙(세금계산서·카드·현금영수증), 계약서, 급여대장,
                           홈택스 발급자료, 은행 발급서류, 전기(작년) 신고서
        ↓
[1단계: 장부 기록]         전표 입력 → 총계정원장 / 계정별원장
        ↓                  (재료: 0단계 전부 / 도구: 회계프로그램)
[2단계: 결산]              결산수정분개(감가상각·선급비용·미지급 정리) → 합계잔액시산표 확정
        ↓
[3단계: 결산보고서 출력]   재무상태표, 손익계산서, 이잉처계산서, 계정별 명세서 전부
        ↓                  (재료: 확정된 장부. 추가 재료 없음 — 장부의 '조회 결과'다)
[4단계: 세무조정]          개별 조정명세서 → 소득금액조정합계표 → 별지3 세액계산 → 별지1
        ↓                  (재료: 3단계 산출물 + 전기 신고서 + 법령 파라미터 + 방법 선택)
[5단계: 신고·납부]         홈택스 전자신고 / 위택스 신고 / 은행 납부
                           (부산물: 접수증, 납부서·영수증 — ★재료가 필요 없는 항목들)
```

- **"준비물이 필요 없는" 항목** = 5단계의 부산물(접수증·납부서류)과, 다른 서식이 다 만들어지면 자동으로 채워지는 집계 서식(별지1, 합계표류).
- **"준비물이 가장 많이 필요한" 항목** = 1단계(장부)를 거쳐야 하는 모든 것. 장부가 없으면 3단계 이후는 전부 생산 불가.
- 재현 검증 관점: 종이 보고서에는 **4단계의 입력(재무제표·자산명세)과 출력(세액)이 둘 다 들어 있으므로, 4단계는 종이 보고서만으로 재현·검증 가능**하다. 반면 1~2단계는 전표가 없어 재현 불가 — 내년 실사용 때만 필요하다.

## 1. 준비물(원천자료) 카탈로그 — 어디서 무엇을 가져오는가

세무사무소가 법인 결산 때 실제로 수집하는 자료 목록 기준 (웹 리서치로 검증).

### A. 회사 내부에서만 나오는 것 (남이 대신 못 구함)

| 준비물 | 형태 | 쓰이는 곳 |
|---|---|---|
| 1년치 거래 증빙·전표 기록 | 회계프로그램 or 수기 | 장부 전체의 뿌리 |
| 법인 통장 거래내역 (전 계좌) | 은행 사이트에서 엑셀 다운로드 | 전표 입력, 보통예금 명세서, 매출·비용 대사 |
| 급여대장·원천징수 자료 | 내부 or 세무사무소 | 인건비 전표, 예수금 명세서 |
| 임대차계약서 (임대인 지위) | 계약서 원본 | 임대보증금 명세서, 간주익금 계산, 매출(임대료) 검증 |
| 차량 운행기록부 | 내부 기록 (양식 있음) | 업무용승용차 명세서 — 미작성 시 연 1,500만원 한도로 불리 |
| 주주명부·주식 변동 서류 (주총/이사회 의사록, 양수도계약) | 내부 | 주식등변동상황명세서 |
| 배당·이익처분 결의 내용 | 주총 의사록 | 이익잉여금처분계산서 |
| 재고 실사 결과 | 내부 (임대업이면 보통 해당 없음) | 결산수정분개 |

### B. 홈택스에서 발급·조회 가능한 것 (IDEA.md의 "결정론적 자료"에 해당)

수집 경로 3가지: ① 법인 인증서로 직접 로그인 ② 세무대리인 수임동의 후 세무사무소가 조회 ③ 신고 후 My홈택스에서 재출력.

| 준비물 | 홈택스 메뉴 | 쓰이는 곳 |
|---|---|---|
| 전자세금계산서 매출·매입 집계/상세 | 조회/발급 → 전자세금계산서 | 매출·매입 전표, 수입금액조정 |
| 사업용(법인)카드 매입내역 | 조회 → 사업용신용카드 | 비용 전표, 기업업무추진비 적격증빙 판정 |
| 현금영수증 매출·매입 내역 | 조회 → 현금영수증 | 전표, 적격증빙 |
| 부가가치세 신고내역 (과세표준) | My홈택스 → 신고내역 | **조정후수입금액명세서의 부가세 대사** |
| 원천세 신고내역·지급명세서 | My홈택스 | 인건비 검증, 원천납부세액 대사 |
| 법인세 중간예납 납부내역 | My홈택스 → 납부내역 | 별지3 기납부세액, 선납세금명세서 |
| **전기 법인세 신고서 전체** | My홈택스 → 세금신고 내역 | §1-D 전기 이월 데이터의 원천 |
| 표준재무제표증명 (전기분) | 즉시발급 증명 | 전기 재무제표 확인 대체재 |

⚠️ 제약: 법인 자료는 **법인 명의 인증서**(또는 수임동의된 세무대리인 권한)가 필요. 현재 개인 금융인증서만 확보된 상태라 ①은 막혀 있음 — fincert-spike에서 확인된 블로커와 동일.

### C. 제3자 기관에서 발급받는 것

| 준비물 | 발급처 | 쓰이는 곳 |
|---|---|---|
| 잔액증명서 (기말 기준, 전 계좌) | 은행 | 보통예금·단기금융상품 명세서 대사 |
| 대출 잔액·이자상환 내역 | 은행 | 단기차입금 명세서, 이자비용 검증 |
| 예금이자 원천징수영수증 | 은행 | **원천납부세액명세서**, 이자수익 전표 |
| 업무전용자동차보험 증권 | 보험사 | 승용차 명세서 — 미가입 시 전액 손금불산입 |
| 리스/렌트 계약서·납입내역 | 리스사 | 승용차 감가상각비 상당액 계산 |

| 기부금 영수증 | 기부처 | 기부금 조정 (별지3 직접 가감) |

### D. 전기(작년) 신고서에서 이월되는 것 — 연도 간 연속성 데이터

**올해 재현 작업이 그대로 내년 신고의 D 데이터가 된다**는 점에서 이 프로젝트의 재현 검증은 실사용의 선행 투자다.

| 준비물 | 어느 서식에서 | 쓰이는 곳 |
|---|---|---|
| 전기 재무상태표 (기말잔액) | 전기 결산보고서 | 당기 기초잔액 (BS 연속성) |
| 유보 잔액 명세 | 전기 자본금과적립금조정명세서(을) | 당기 (을)표 기초, 추인 조정 |
| 이월결손금 발생·공제 명세 | 전기 (갑)표 하단 | 별지3 이월결손금 공제 |
| 세액공제 이월잔액 | 전기 세액공제조정명세서(3) | 당기 공제·이월 계산 |
| 감가상각 부인액 누계·상각방법·내용연수 신고 내역 | 전기 별지20 계열 | 당기 시부인 (전기이월부인액 추인) |
| 전기 미처분이익잉여금 | 전기 이잉처계산서 | 당기 이잉처계산서 첫 줄 |

### E. 사람의 판단·선택이 들어가는 것 (IDEA.md의 "비결정론적" 지점의 실체)

| 선택 | 자유도 | 비고 |
|---|---|---|
| 감가상각 방법 | **기취득 자산은 이미 고정** (계속적용 원칙, 변경은 세무서장 승인) | 신규 취득 자산만 선택 가능. 건축물은 정액법 강제 |
| 내용연수 | 신규 취득 연도에만 기준연수 ±25% 신고 가능 | 이후 고정 |
| 임의상각 수준 | 0 ~ 상각범위액 사이 자유 | 당기 손금 조절의 실질적 레버 |
| 결산조정 항목 계상 여부 | 대손충당금 등 — 장부에 적어야 인정 | 결산 마감 전에만 조절 가능 |
| 이익처분(배당) 규모 | 상법 한도 내 자유 | 이잉처계산서 |
| 세액공제 당기공제/이월 | 대부분 순서 법정 — 자유도 낮음 | |
| 성실신고확인 | 선택이 아니라 **세무사 판단·서명** 영역 | 자동화 불가, 초안 지원만 가능 |

### F. 법령 파라미터 (코드에 상수/테이블로 내장할 것)

세율표(2026 개시 사업연도부터 10/20/22/25%), 상각률표(별표4), 기준내용연수표(별표5·6), 기업업무추진비 한도식, 승용차 한도(800만/1,500만, 소규모 임대법인은 절반), 최저한세율, 이월결손금 공제한도, 간주익금 이자율(기획재정부령 정기예금이자율 — 매년 고시 확인 필요).

## 2. 항목별 매트릭스 — 각 문서는 무엇으로 만들어지는가

범례 — 생산 단계: ⓪원천 ①장부 ②결산 ③결산보고서 ④세무조정 ⑤신고부산물
준비물 등급: **[무]** 재료 불필요(자동 집계·부산물) / **[장]** 확정 장부만 있으면 기계 생성 / **[장+파]** 장부+파라미터·외부자료 / **[전기]** 전기 신고서 필요 / **[판단]** 사람 판단·서명 개입

### 2-2. 세무조정계산서 쪽 (④단계 — 재료는 "③ 산출물 + 전기 + 파라미터 + 판단")

| 항목 | 등급 | 준비물 | 생성 과정 |

## 3. 실무 워크플로우 재구성 — 세무사무소는 실제로 이렇게 만든다

웹 리서치로 확인된 실제 순서 (12월말 법인 기준):

1. **[연중]** 수임동의 상태로 홈택스 자료(세금계산서·카드·현금영수증) 자동 수집 + 회사가 보내주는 통장내역으로 **매월 기장** (1단계를 연중 분산 처리).
2. **[1월]** 부가세 확정신고 → 이 시점에 연 매출이 사실상 확정.
3. **[2월]** 회사에 결산자료 요청: 통장 기말잔액, 잔액증명서, 대출내역, 이자 원천징수영수증, 보험증권, 운행기록부, 기부금영수증, 재고 실사 등 (§1-A·C 목록).
4. **[2~3월]** 결산수정분개(감가상각·선급·미지급) → 시산표 확정 → **재무제표 확정** (②→③).
5. **[3월]** 세무조정 프로그램(세무사랑Pro 등)에 장부를 넘겨 §2-2 서식 자동 생성 + 조정 판단 → 별지3 세액 확정 (④).
6. **[3월 말]** 홈택스 전자신고 + 납부, **[4월]** 위택스 지방소득세 신고 (⑤). 성실신고확인대상은 4월 말까지.
7. 접수증·납부서를 묶어 **연간결산 보고서 책자**로 제본해 회사에 전달 ← 지금 갖고 계신 그 문서.

## 4. 이 프로젝트에 주는 결론

1. **재현 검증(1차 목표)에는 0~2단계 재료가 필요 없다.** 종이 보고서 안에 4단계의 입력(재무제표, 자산명세, 조정합계표)과 출력(세액)이 다 있으므로, ④ 세무조정 엔진은 지금 바로 만들고 검증할 수 있다.
2. **내년 실사용에는 1단계(장부)가 최대 병목이다.** 전표를 만들 원천자료(A·B·C)를 연중 수집해야 하며, 특히 홈택스 B자료는 법인 인증서 문제를 풀어야 한다 (아버지 명의 법인 인증서 발급 협조 또는 세무사무소 경유).
3. **전기 데이터(D)는 올해 재현 작업의 부산물로 자동 확보된다.** 작년 보고서를 구조화 입력하는 순간, 내년 신고의 기초잔액·유보·이월액 데이터베이스가 생긴다.
4. **자동화 불가 항목이 명확해졌다**: 성실신고확인서 계열(세무사 서명), 접수증·납부서(신고 부산물). 이 둘을 빼면 나머지 전부가 코드 생성 대상이다.
5. **판단(E) 지점이 곧 절세 시나리오의 변수 공간이다**: 임의상각 수준, 신규자산 상각방법·내용연수, 결산조정 계상, 배당 규모 — IDEA.md의 "경우의 수 계산"은 이 변수들의 조합 열거로 구현하면 된다.
