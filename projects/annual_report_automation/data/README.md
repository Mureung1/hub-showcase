# data/ — 입력 데이터 규칙

> ⚠️ **`private/`는 git에 절대 올라가지 않는다** (`data/.gitignore`로 차단). 실제 법인 자료는 여기에만 둔다.

## 폴더 구조

```
data/
├── templates/   ← 빈 입력 템플릿 (CSV). git 추적 O — 구조만 담김
├── private/     ← 실제 종이책 데이터를 채운 것. git 추적 X
│   └── fy2025/  ← 사업연도별 폴더
└── README.md    ← 이 파일
```

## 입력 방법

1. `templates/`의 CSV를 `private/fy2025/`로 복사한다.
2. 종이 보고서를 보며 값을 채운다 (엑셀로 열어 입력 가능).
3. `npm run reproduce -- --dir data/private/fy2025` 로 검증·재현한다.

## ★ 마스킹 규칙 (입력 단계에서 반드시 적용)

식별 정보는 **입력하는 순간부터** 코드로 치환한다. 원본 식별자는 아예 파일에 넣지 않는다.

| 원본 | 입력값 | 이유 |
|---|---|---|
| 주민등록번호 | **입력 안 함** (필요 시 생년만) | 재현·세액 계산에 불필요 |
| 사람 이름 | 역할코드 — `대표A`, `주주B`, `임원C` | |
| 거래처명 | 코드 — `거래처01`, `임차인A` | |
| 계좌번호 | `은행명+뒤4자리` — `국민1234` | |
| **금액·날짜** | **그대로** | 계산에 필요, 그 자체로는 식별 불가 |

주식등변동상황명세서·성실신고 명세서처럼 주민번호 밀도가 높은 서식은 **이 프로젝트의 재현 대상에서 제외**한다 (세액 계산과 무관, 개인정보 위험만 큼).

## 사업연도 폴더 예시

```
private/fy2025/
├── company.csv          법인 프로필 (사업연도·중소기업 여부·특례 스위치)
├── balance_sheet.csv    재무상태표
├── income_statement.csv 손익계산서
├── assets.csv           자산대장 (감가상각 계산의 마스터)
├── adjustments.csv      세무조정 재료 (개별 명세서에서 온 조정 항목)
└── answer.csv           정답지 — 종이책의 별지3 세액 (대조용)
```
