# 계정과목 카탈로그 — 재무제표 전체 과목 + 어느 CSV에 적는가

> 한국 일반기업회계기준 재무상태표·손익계산서의 표준 계정과목을 트리 구조로 정리한 것.
> 종이책을 CSV에 옮길 때 "이 숫자를 어디에 적지?"를 없애기 위한 참고표.
> **없는 과목은 안 적으면 됩니다** — 엔진은 있는 줄만 더하고 없는 줄은 0으로 칩니다.

---

## 큰 그림 — 어느 CSV에 무엇을 적나

| CSV 파일 | 무엇 | 종이책 출처 |
|---|---|---|
| `balance_sheet.csv` | 재무상태표 (자산·부채·자본) | 재무상태표 |
| `income_statement.csv` | 손익계산서 (수익·비용) | 손익계산서 |
| `assets.csv` | 자산대장 (감가상각 계산용, 유형자산만) | 유형자산감가상각비명세서 |
| `adjustments.csv` | 세무조정 (개별 명세서에서 온 가감) | 소득금액조정합계표 |
| `company.csv` | 법인 프로필 + 별지3 입력값 | 별지1 표지·중소기업검토표 등 |
| `answer.csv` | 정답지 (채점용) | 별지3 세액조정계산서 |

> `balance_sheet.csv`의 유형자산과 `assets.csv`는 **같은 자산을 다른 관점에서** 봅니다.
> BS는 "기말 잔액(취득가·누계액)", assets는 "감가상각을 어떻게 계산하는가(방법·연수)". 둘 다 적습니다.

## 1. 재무상태표 — `balance_sheet.csv`

`[구분]`은 계산에 쓰는 값(자산 / 자산차감 / 부채 / 자본), `[대분류·중분류]`는 사람이 보기 위한 트리.

### 자산

```
자산
├─ 유동자산 (1년 내 현금화)
│  ├─ 당좌자산
│  │   현금 · 보통예금 · 정기예금 · 매출채권 · 대손충당금[자산차감]
│  │   미수금 · 미수수익 · 선급금 · 선급비용 · 선납세금 · 단기대여금
│  └─ 재고자산
│      상품 · 제품 · 원재료 · 재공품
└─ 비유동자산 (1년 넘게 보유)
   ├─ 투자자산
   │   장기금융상품 · 투자부동산 · 장기대여금
   ├─ 유형자산  ← assets.csv에도 적는 것들
   │   토지 · 건물 · 감가상각누계액(건물)[자산차감]
   │   구축물 · 기계장치 · 감가상각누계액(기계)[자산차감]
   │   차량운반구 · 감가상각누계액(차량)[자산차감]
   │   비품 · 감가상각누계액(비품)[자산차감] · 건설중인자산
   ├─ 무형자산
   │   영업권 · 개발비 · 소프트웨어 · 특허권 · 상표권
   └─ 기타비유동자산
       임차보증금 · 기타보증금(지급)
```

### 부채

```
부채
├─ 유동부채 (1년 내 갚음)
│   매입채무 · 미지급금 · 미지급비용 · 예수금 · 선수금 · 선수수익
│   단기차입금 · 유동성장기부채 · 미지급세금(미지급법인세)
└─ 비유동부채
    장기차입금 · 임대보증금 · 퇴직급여충당부채 · 사채
```

### 자본

```
자본
├─ 자본금            자본금
├─ 자본잉여금        주식발행초과금 · 감자차익
├─ 자본조정          자기주식 · 주식할인발행차금
├─ 기타포괄손익누계액 매도가능증권평가손익 등
└─ 이익잉여금        이익준비금 · 임의적립금 · 미처분이익잉여금
```

**★ 자산차감 항목** (구분을 `자산차감`으로): 대손충당금, 감가상각누계액, 재고자산평가충당금 — 자산을 깎는 항목이라 양수로 적되 구분만 다릅니다.

**검증 규칙**: (자산 합계 − 자산차감 합계) = (부채 합계 + 자본 합계). 안 맞으면 입력 오타.

## 2. 손익계산서 — `income_statement.csv`

`[구분]`은 수익 / 비용. 당기순이익 = 수익 합계 − 비용 합계 (법인세비용 포함).

```
매출액          임대료수입 · 상품매출 · 제품매출               [수익]
(−) 매출원가    상품매출원가 · 제품매출원가                    [비용]
─────────────────────  = 매출총이익
(−) 판매비와관리비                                            [비용]
    급여 · 상여금 · 퇴직급여 · 복리후생비 · 여비교통비
    기업업무추진비(구 접대비) · 통신비 · 수도광열비 · 세금과공과
    감가상각비 · 임차료 · 수선비 · 보험료 · 차량유지비
    지급수수료 · 광고선전비 · 대손상각비 · 소모품비 · 도서인쇄비
─────────────────────  = 영업이익
(+) 영업외수익  이자수익 · 배당금수익 · 유형자산처분이익 · 잡이익   [수익]
(−) 영업외비용  이자비용 · 기부금 · 유형자산처분손실 · 잡손실       [비용]
─────────────────────  = 법인세차감전순이익
(−) 법인세비용                                                [비용]
─────────────────────  = 당기순이익  ← 별지3의 첫 줄
```

> **임대법인이면** 보통: 매출=임대료수입 / 판관비=급여·감가상각비·세금과공과·기업업무추진비·차량유지비·보험료 / 영업외=이자수익·이자비용 / 법인세비용. 나머지는 비워두면 됩니다.

## 3. 자산대장 — `assets.csv`

BS의 **유형자산만** 감가상각 계산용으로 다시 적습니다. 자산 1개당 1줄.

| 열 | 뜻 |
|---|---|
| 명 | 자산 이름 (건물·승용차·비품…) |
| 구분 | 건축물 / 차량운반구 / 비품 / 기계장치 (기준내용연수·방법고정이 갈림) |
| 취득일 / 취득가 | 언제 / 얼마에 샀나 |
| 기초누계 | 작년까지 쌓인 감가상각 누계액 (첫 해면 0) |
| 회사계상액 | 올해 장부에 실제로 적은 감가상각비 |
| 방법 / 내용연수 | 정액·정률 / 몇 년 (건축물=정액40, 승용차=정액5 강제) |
| 전기이월부인액 | 자본금과적립금(을)표의 누적 유보 (첫 해면 0) |
| 업무용승용차 | true/false |

## 4. 세무조정 — `adjustments.csv`

소득금액조정합계표의 가감 항목. 조정 1개당 1줄. **구분**: 익금산입·손금불산입(가산) / 손금산입·익금불산입(차감).

임대법인 흔한 것: 법인세비용(손금불산입), 세금과공과 중 과태료(손금불산입), 기업업무추진비 증빙불비·한도초과(손금불산입), 업무용승용차 업무외·한도초과(손금불산입), 선급비용(손금불산입→다음해 손금산입 추인), 임대보증금 간주익금(익금산입).

⚠️ **감가상각 부인액과 기부금 한도초과는 여기 넣지 마세요** — 각각 assets.csv·company.csv에서 처리됩니다.

## 참고

- 계정과목명은 회사·회계프로그램마다 조금씩 다릅니다. 종이책에 적힌 이름을 그대로 쓰되, 위 표준명과 뜻이 같으면 됩니다.
- 여기 없는 특수 과목이 있으면 그대로 한 줄 추가하고 [구분]만 맞추면 엔진이 처리합니다.
- 세법상 계산 원리는 `notes/세무조정계산서-결산보고서-research.md` 참고.
