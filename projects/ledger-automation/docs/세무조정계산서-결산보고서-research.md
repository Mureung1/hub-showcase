## 1. 큰 그림

법인 하나가 1년 결산을 마치고 세금 신고를 끝내면 산출물이 두 덩어리 나온다. IDEA.MD의 두 목록이 정확히 이 두 덩어리다.

```
[회계 장부]                          [세무 신고]
 전표 입력                            결산보고서(재무제표)를 출발점으로
   ↓                                   ↓
 총계정원장 → 합계잔액시산표          세무조정 (익금/손금 조정)
   ↓                                   ↓
 결산수정분개                         세무조정계산서 (수십 개 명세서 묶음)
   ↓                                   ↓
 결산보고서                           홈택스 전자신고 (법인세)
  = 재무상태표, 손익계산서,           위택스 전자신고 (법인지방소득세)
    이익잉여금처분계산서,               ↓
    각종 계정별 명세서                납부서 출력 → 은행 납부 → 영수증
```

- **결산보고서** = 기업회계기준(일반기업회계기준 또는 K-IFRS)에 따라 만든 **회계 산출물**. 회계프로그램(더존 Smart A 등)이 만든다.
- **세무조정계산서** = 회계상 당기순이익을 **법인세법상 소득**으로 변환하는 과정을 증빙하는 **세무 산출물**. 세무조정 프로그램(세무사랑Pro, WEHAGO T 등)이 만든다.

### 신고 기한과 무신고 간주 규정 (법인세법 §60)

- 법인세: **사업연도 종료일이 속하는 달의 말일부터 3개월 이내** (12월말 법인 → 3/31). 성실신고확인대상 법인은 **4개월**(→ 4/30).
- 법인지방소득세: **사업연도 종료일이 속하는 달의 말일부터 4개월 이내** (12월말 법인 → 4/30). 위택스로 별도 신고.
- ⚠️ **재무상태표·(포괄)손익계산서·이익잉여금처분계산서(또는 결손금처리계산서)·세무조정계산서** 이 4가지를 첨부하지 않으면 **신고 자체를 무신고로 본다**(법인세법 §60⑤). 결산보고서와 세무조정계산서가 "있으면 좋은 서류"가 아니라 신고의 성립요건이라는 뜻.

### 법인세 계산 구조 (별지 제3호 서식이 이 구조 그대로다)

```
    결산서상 당기순이익                ← 손익계산서에서 옴
(+) 익금산입 · 손금불산입             ┐
(–) 손금산입 · 익금불산입             ┘ 소득금액조정합계표에서 옴
(±) 기부금 한도초과액/한도초과 이월분 손금산입   ← 기부금은 합계표에 안 넣고 별지3에서 직접 조정
 = 각 사업연도 소득금액
(–) 이월결손금                        ← 15년 내 발생분(2020.1.1 이후 개시 사업연도 발생분 기준,
                                        2009~2019 발생분은 10년). 공제한도: 일반법인 소득의 80%, 중소기업 100%
(–) 비과세소득
(–) 소득공제
 = 과세표준
(×) 세율                              ← 아래 세율표
 = 산출세액 (+ 토지등 양도소득 법인세, 미환류소득 법인세)
(–) 공제·감면세액                     ← 최저한세(조특법 §132) 적용 후. 공제감면합계표에서 옴
(+) 가산세
(–) 기납부세액                        ← 중간예납 + 원천납부(원천납부세액명세서) + 수시부과
 = 차감 납부할 세액                   ← 1천만원 초과 시 분납 가능(1개월, 중소기업 2개월)
```

### 법인세율 (웹 검증 완료 — §7 참고)

| 과세표준 | 2023~2025 개시 사업연도 | **2026.1.1 이후 개시 사업연도** |
|---|---|---|
| 2억원 이하 | 9% | **10%** |
| 2억 초과 ~ 200억 | 19% | **20%** |
| 200억 초과 ~ 3,000억 | 21% | **22%** |
| 3,000억 초과 | 24% | **25%** |

- 2025년 세제개편(예산부수법안 국회 통과)으로 전 구간 1%p 인상 확정 — 2022년 인하분의 환원.
- **법인지방소득세**는 같은 과세표준에 법인세율의 1/10 수준 독립세율(0.9/1.9/2.1/2.4%)로 별도 과세. 법인세율 인상에 연동한 지방세법 개정(1.0/2.0/2.2/2.5%) 여부는 실제 신고 시점에 지방세법 §103조의20 확인 필요.

## 2. 세무조정의 원리

회계이익 ≠ 과세소득인 이유: 기업회계는 **발생주의·수익비용대응**으로 "경영성과"를 재고, 세법은 **권리의무확정주의·조세정책 목적**으로 "담세력"을 잰다. 이 차이를 항목별로 가감하는 것이 세무조정이다.

### 조정의 4유형

| 유형 | 방향 | 예 |
|---|---|---|
| 익금산입 | 소득 ↑ | 임대보증금 간주익금, 특수관계인 저가양도 부당행위계산부인 |
| 손금불산입 | 소득 ↑ | 기업업무추진비 한도초과, 감가상각 부인액, 벌금·과태료, 법인세 |
| 손금산입 | 소득 ↓ | 전기 유보 추인(선급비용 등), 국고보조금 일시상각충당금 |
| 익금불산입 | 소득 ↓ | 수입배당금 익금불산입, 전기 익금 유보 추인 |

### 결산조정 vs 신고조정

- **결산조정 항목**: 장부에 비용으로 계상해야만 손금 인정. 감가상각비(원칙), 대손충당금, 재고자산 평가손 등. → "장부에 안 적으면 세법도 안 준다."
- **신고조정 항목**: 장부 계상과 무관하게 세무조정으로 처리(의무 또는 선택). 퇴직연금충당금, 업무용승용차 감가상각(강제), 국고보조금 압축기장 등.

### 소득처분 — 조정마다 반드시 따라붙는 꼬리표

| 처분 | 의미 | 사후관리 |
|---|---|---|
| **유보 / △유보** | 회계·세무 차이가 **회사 안에** 남아 있음(자산·부채의 세무상 가액 ≠ 장부가액) | **자본금과적립금조정명세서(을)** 에 누적 관리, 차이 해소 시 반대조정(추인) |
| 배당·상여·기타소득 | 사외유출 — 귀속자(주주/임직원/제3자)에게 소득세 과세 | 소득자료 통보, 원천징수 |
| 기타사외유출 | 사외유출이지만 귀속자 추적 불필요(벌금, 기업업무추진비 한도초과 등) | 없음 |
| 기타(잉여금) | 자본 항목 간 이동 | 없음 |

유보의 누적 잔액이 곧 "세무상 자기자본과 회계상 자기자본의 차이"이고, 이것을 기록하는 장부가 자본금과적립금조정명세서(을)다. **세무조정의 절반은 이 유보 관리**라고 봐도 된다.

## 3. 세무조정계산서 서식별 해설

IDEA.MD 목록 순서. 각 항목: **무엇인가 → 계산 원리/작성 요령 → 데이터가 어디서 오는가**.

### 3-1. 법인세 과세표준 및 세액 신고서 (별지 제1호)

- 신고서 묶음 전체의 **표지**. 법인 기본정보(사업자번호, 법인구분, 업종코드), 재무상태표 요약(자산/부채/자본 총계), 최종 세액(산출→공제감면→가산세→기납부→차감납부), 세무대리인·조정자 정보, 첨부서류 체크리스트.
- 모든 하위 서식이 완성된 뒤 **맨 마지막에 채워지는 집계 서식**. 전자신고 시 이 서식 데이터가 접수 원장이 된다.

### 3-2. 법인세 과세표준 및 세액조정계산서 (별지 제3호)

- §1의 "법인세 계산 구조"를 그대로 옮긴 **세액 계산의 본체**. ① 각사업연도소득 계산(당기순이익 ± 조정) ② 과세표준 계산(이월결손금·비과세·소득공제 차감) ③ 산출세액 ④ 납부할 세액(공제감면·가산세·기납부) 4단 구성.
- 입력원: 손익계산서(당기순이익), 소득금액조정합계표(조정 합계), 자본금과적립금조정명세서(갑)(이월결손금 잔액), 공제감면합계표, 원천납부세액명세서.

### 3-3. 공제감면세액 및 추가납부세액 합계표 (별지 제8호 계열)

- 조특법·법인세법상 **모든 세액감면(면제)과 세액공제를 한 장에 집계**하는 표. (갑)에 감면·공제 종류별 코드와 금액, 최저한세 적용 대상/제외 구분.
- **최저한세**(조특법 §132): 감면 후 세액이 [감면 전 과세표준 × 최저한세율(중소기업 7%, 일반 10~17%)]에 미달하면 그만큼 감면을 배제. 배제 순서도 법정되어 있어 계산 로직이 꽤 복잡하다.
- "추가납부세액" = 과거에 공제·감면받았다가 사후관리 요건(투자자산 처분 등)을 어겨 도로 뱉어내는 세액 + 이자상당가산액.

### 3-4. 세액공제조정명세서(3)

- 각 세액공제(통합투자세액공제, 연구인력개발비 세액공제, 고용 관련 공제 등)의 **당기 발생액 → 최저한세 배제 → 당기 공제액 → 이월액**을 공제 종류별로 관리하는 명세서. 세액공제는 10년(일부 상이) 이월공제가 가능해서 이월잔액 관리가 핵심.
- 데이터 흐름: 개별 공제 계산서(예: 연구인력개발비 명세서) → 이 서식 → 공제감면합계표(3-3) → 세액조정계산서(3-2).

### 3-5. 원천납부세액명세서 (별지 제10호)

- 법인이 지급**받은** 이자소득 등에서 금융기관이 원천징수해간 법인세(이자소득 14%, 비영업대금이익 25%)의 건별 명세. 원천징수의무자(은행) 사업자번호, 지급일, 이자금액, 세액.
- 여기 집계액이 **기납부세액**으로 산출세액에서 차감된다. 데이터 원천: 결산보고서의 이자수익 계정 + 은행 원천징수영수증. (홈택스 지급명세서 자료와 대사 가능)

### 3-6. 성실신고 확인비용 세액공제 신청서 (조특법 §126의6)

- 성실신고확인(3-21)에 든 수수료의 **60%를 세액공제**(법인 한도 **150만원**, 개인 120만원) 신청하는 서식. 예: 수수료 300만원 → 300×60%=180만 → 한도 걸려 150만원 공제.

### 3-7. 소득금액조정합계표 + 과목별 소득금액조정명세서 (별지 제15호)

- **모든 세무조정의 총집계표.** 왼쪽에 익금산입·손금불산입(과목/금액/소득처분), 오른쪽에 손금산입·익금불산입. 개별 조정명세서(감가상각, 기업업무추진비, 선급비용, 세금과공과, 승용차…)에서 나온 조정이 전부 여기로 모인 뒤 별지 제3호로 넘어간다.
- 예외: **기부금 한도초과액은 이 표에 넣지 않고** 별지 제3호에서 직접 가감한다(기부금 한도가 "각사업연도소득"을 기준으로 순환 계산되기 때문).
- "과목별 소득금액조정명세서"는 합계표 각 줄의 계산 근거(어느 계정, 어떤 사유, 어떤 법조문)를 쓰는 부속 명세다.

### 3-8. 수입금액조정명세서 (별지 제16호) / 조정후 수입금액명세서 (별지 제17호)

- **수입금액조정명세서**: 손익계산서상 매출액에서 출발해 세법상 익금 귀속시기 차이를 조정. 가산 항목 예: 작업진행률 기준 익금(장기도급공사), 위탁매출 누락분, 부산물 매각대. 차감 항목 예: 중소기업 장기할부판매의 회수기일도래기준 선택분. → "조정 후 수입금액" 확정.
- **조정후 수입금액명세서**: 그 수입금액을 **업종코드별·품목별로 분해**하고, **부가가치세 신고 과세표준과의 차액을 소명**하는 표. 차액 원인 코드(고정자산 매각대, 간주공급, 간주임대료 등)까지 기재.
- 국세청이 "부가세 신고 매출 vs 법인세 신고 매출"을 자동 대사하는 핵심 검증 서식. 조정 후 수입금액은 기업업무추진비 한도(3-10) 계산에도 들어간다.

### 3-9. 감가상각비조정명세서 합계표 / 유형자산감가상각비 조정명세서(정액법) (별지 제20호 계열)

- 별지 제20호서식(1) = 정률법용, **(2) = 정액법용**, 합계표는 자산 그룹별(건축물/기계장치/기타) 총괄.
- 자산(또는 자산군)별로 **상각범위액을 계산해 회사 계상액과 비교(시부인)** 하는 서식. IDEA.MD에 "(정액법)"이 붙은 이유는 해당 법인이 정액법 신고 자산(건축물 등)을 보유했기 때문. 계산 원리 전체는 **§5에서 상세히**.

### 3-10. 기업업무추진비 조정명세서 (별지 제23호 계열, 갑·을)

- 구 "접대비". **2024.1.1부터 법률상 명칭이 기업업무추진비로 변경**(웹 검증).
- 2단계 검증:
  1. **적격증빙 검증(을)**: 건당 3만원 초과(경조사비 20만원 초과) 지출 중 신용카드·세금계산서 등 적격증빙 없는 분 → 전액 손금불산입(기타사외유출).
  2. **한도 검증(갑)**: 한도 = ① 기본한도 1,200만원(**중소기업 3,600만원**) × 월수/12 + ② 수입금액 × 적용률(100억 이하 0.3%, 100억~500억 0.2%, 500억 초과 0.03%; 특수관계인 거래 수입금액분은 산출액의 10%만) + ③ 문화 기업업무추진비 추가한도(일반한도의 20%) 등. 한도초과액 손금불산입(기타사외유출).
- 부동산임대업 주업 + 상시근로자 5인 미만 + 지배주주 지분 50% 초과인 소규모 법인은 **한도가 50%로 축소**.
- 데이터 원천: 장부의 기업업무추진비 계정 전표 + 증빙 유형 태그.

### 3-11. 업무용승용차 관련비용 명세서 (별지 제29호)

- 대상: 개별소비세 과세 대상 승용차(경차·9인승 이상·화물·영업용 제외). 차량 1대당 1줄씩 관련비용(감가상각비, 유류비, 보험료, 수선비, 자동차세, 통행료…)과 업무사용비율을 기재.
- 손금 인정 로직(법인세법 §27의2, 웹 검증):
  1. **업무전용자동차보험 미가입 → 전액 손금불산입** (법인 필수). 취득가 8천만원 이상 법인차는 연두색 전용번호판 미부착 시에도 전액 부인(2024.1.1~).
  2. **운행기록부 작성 시**: 관련비용 × 업무사용비율만 손금. **미작성 시**: 연 **1,500만원**까지만(월할).
  3. 업무사용분 중 **감가상각비는 연 800만원 한도**, 초과분은 유보로 이월. 임차차량은 "감가상각비 상당액"(리스: 리스료 – 보험료·자동차세·수선유지비, 렌트: 렌트료×70%)으로 동일 적용. **처분손실도 연 800만원 한도.**
  4. 한도초과·업무외사용분 중 사용자 귀속분은 **상여 처분**(소득세 과세).
  - 3-10과 같은 소규모 부동산임대 법인은 한도 절반(800→400만, 1,500→500만).
- 감가상각 방법도 특칙: **2016.1.1 이후 취득분은 내용연수 5년 정액법 강제 + 강제 신고조정**(§5-6 참고).

### 3-12. 주요계정명세서 (갑·을)

- 매출채권·매입채무·재고자산·가지급금 등 **주요 계정과목의 상세 내역**(거래처별 잔액 등)을 적는 부속서류. 세무조정 프로그램이 계정별원장에서 자동 생성한다. 법정 필수라기보다 국세청 신고 안내상 표준 부속서류.

### 3-13. 자본금과 적립금 조정명세서 (별지 제50호, 갑·을)

- **(을): 유보소득 관리대장.** 과목별로 [기초잔액 → 당기 감소 → 당기 증가 → 기말잔액]. 소득금액조정합계표에서 유보/△유보로 처분된 조정이 자동 전기된다. 전기 기말잔액 = 당기 기초잔액이어야 하므로 **연도 간 연속성 검증이 되는 서식** — 세무조사 때 가장 먼저 보는 표 중 하나.
- **(갑): 세무상 자기자본 계산서.** 재무상태표상 자본 + (을)표 유보 잔액 ± 손익미계상 법인세 = 세무상 자기자본. 하단에 **이월결손금 발생·공제 명세**(발생 사업연도별, 기한 내/기한 경과 구분)를 관리 — 별지 제3호의 이월결손금 공제액이 여기서 나온다.

### 3-14. 세금과공과금 명세서

- 세금과공과 계정 전표를 전부 나열하고 **손금 여부를 판정**하는 명세.
  - 손금불산입: 법인세·법인지방소득세, 가산세·강제징수비, 벌금·과료·과태료, 공제받은 부가세 매입세액, 폐수배출부담금 등 → 각각 소득처분(대부분 기타사외유출).
  - 손금 인정: 재산세, 자동차세, 인지세, 면허세, 교통유발부담금, 상공회의소 회비 등.
- 규칙 기반 자동 판정이 가장 쉬운 서식(계정 적요/거래처 키워드 매칭).

### 3-15. 선급비용 명세서

- 보험료·이자·임차료처럼 기간에 걸치는 지출 중 **당기말 현재 기간 미경과분**을 계산하는 표. [지급액 × 미경과일수/총일수] = 선급비용.
- 회사가 전액 당기 비용 처리했다면: 미경과분 **손금불산입(유보)** → 다음 기 **손금산입(△유보) 추인**. 전형적인 "자동 반복 유보" 항목이라 자동화 대상 1순위.

### 3-16. 중소기업 등 기준검토표

- 그 법인이 세법상 **중소기업인지 판정하는 체크리스트**(조특법 시행령 §2). 판정 결과가 세율 특례는 아니지만 기업업무추진비 기본한도(3,600만), 최저한세율(7%), 각종 감면(중소기업특별세액감면 등), 이월결손금 100% 공제, 분납 2개월 등 **수십 개 조항의 적용 스위치**가 된다.
- 4대 요건: ① 업종(소비성서비스업 아님) ② 규모(중소기업기본법 시행령 별표1의 업종별 평균매출액 기준 이내) ③ 독립성(자산 5천억 이상 법인이 30% 이상 지배하면 탈락, 관계기업 합산) ④ 졸업 기준(자산총액 5천억 이상 등) 미해당. 요건 상실 시 유예기간 부여(최근 개정으로 3년→5년 확대 — 적용 시점 확인 필요).

### 3-17. 주식등 변동상황명세서 (별지 제54호)

- 사업연도 중 **주주·지분율 변동**(매매·증자·감자·상속·증여)이 있으면 제출. 주주별 인적사항(주민번호!), 기초/기말 보유 주식 수, 변동 사유.
- 미제출·부실기재 시 **가산세 = 미제출 주식 액면금액의 1%**(웹 검증). 국세청이 **과점주주 간주취득세, 증여 추정, 명의신탁** 등을 잡아내는 원천 데이터라 개인정보 민감도가 최상급.

### 3-18. 표준재무상태표 / 합계 표준재무상태표 / 표준손익계산서 (별지 제3호의2·3 계열)

- 회사 계정과목을 **국세청 표준 계정과목 코드 체계로 변환**해 제출하는 재무제표. 전자신고 필수 첨부. 회사마다 제각각인 계정과목명을 국세청이 전산 분석(신고성실도 분석, 업종 평균 비교)할 수 있게 표준화하는 장치.
- "합계" 표준재무상태표: 수익사업/비수익사업 구분이 있는 법인 등이 합산본을 함께 내는 것.
- 이것이 접수되어야 나중에 **표준재무제표증명**(§6)을 발급받을 수 있다.

### 3-19. 이익잉여금처분(결손금처리)계산서

- [전기이월 미처분이익잉여금 + 당기순이익 ± 회계변경 누적효과] = 처분전 이익잉여금 → **이익준비금 적립(상법 §458: 금전배당액의 1/10 이상, 자본금의 ½ 한도) → 배당 → 임의적립금** → 차기이월.
- K-IFRS·일반기업회계기준에서는 주석/자본변동표로 밀려났지만 **법인세법 §60이 여전히 필수 첨부서류로 요구**(미첨부 시 무신고 간주)해서 세무 신고용으로는 반드시 만든다.

### 3-20. 전산조직운용명세서

- 장부와 증빙을 **전산(ERP·회계프로그램)으로 작성·보존**하는 법인이 사용 시스템 현황(하드웨어, 소프트웨어명, 처리 업무 범위)을 신고하는 서식. 국세기본법상 장부 전산보존 요건과 연결.

### 3-21. 성실신고확인서 + 주요항목 명세서 + 특이사항 기술서 + 사업자 확인사항 (법인세법 §60의2)

- **대상 법인**(웹 검증): ① 부동산임대업 주업이거나 이자·배당·부동산임대소득이 수입금액의 50% 이상 + ② 상시근로자 5인 미만 + ③ 지배주주 및 특수관계자 지분 50% 초과 — **3요건 동시 충족** 소규모 법인, 또는 성실신고확인대상 개인사업자가 **법인전환 후 3년 이내**인 법인.
- 세무사(확인자)가 장부 전체를 검증하고 서명하는 제도. "주요항목 명세서"가 IDEA.MD 메모대로 분량·개인정보의 최대 지점: 수입금액 검토, 가공인건비 여부, 배우자·가족 인건비, 차량 사적사용, **3만원 초과 적격증빙 없는 매입 명세(1-13)**, 특수관계인 거래 등을 항목별로 소명.
- 제출 시: 신고기한 1개월 연장 + 확인비용 60% 세액공제(3-6). 미제출 시: **가산세 = Max(산출세액×5%, 수입금액×0.02%)** + 세무조사 선정 사유.

### 3-22. 법인지방소득세 신고서 / 세액조정계산서(갑·을) (지방세법 시행규칙)

- 2014년부터 **독립세**: 법인세 과세표준을 그대로 쓰되 세율(법인세율의 1/10 수준)·신고·납부를 지자체에 별도로 한다. 국세 공제감면은 원칙적으로 적용되지 않음.
- 사업장이 여러 지자체에 있으면 **종업원 수 ½ + 건축물 연면적 ½ 가중치로 안분**해 지자체별로 나눠 낸다(안분명세서 첨부).
- 신고 채널이 홈택스가 아니라 **위택스(wetax.go.kr)**. 납부서 겸 영수증(별지 제43호의8)·접수증이 결산보고서 묶음에 들어있는 이유는 신고 완료의 증빙으로 함께 철하기 때문.

## 4. 결산보고서 구성요소 해설

### 4-1. 3대 재무제표

| 문서 | 내용 | 원리 |
|---|---|---|
| **재무상태표** | 결산일 시점의 자산 = 부채 + 자본 | 유동성 배열법(유동→비유동). 세무조정의 출발점이자 표준재무상태표의 원본 |
| **손익계산서** | 매출액 – 매출원가 = 매출총이익 – 판관비 = **영업이익** ± 영업외손익 = 법인세차감전순이익 – 법인세비용 = **당기순이익** | 당기순이익이 별지 제3호 첫 줄로 들어간다 |
| **이익잉여금처분계산서** | §3-19 참고 | 상법상 배당 절차 + 법인세법상 필수 첨부 |

### 4-2. 합계잔액시산표

- 총계정원장 전 계정의 [차변합계/차변잔액/계정과목/대변잔액/대변합계]를 한 표로. **대차평균의 원리**(모든 분개는 차=대)에 의해 차변총계 = 대변총계가 맞으면 전기(轉記) 오류가 없다는 1차 검증. 분개 자체의 오류(계정 착오, 이중분개)는 못 잡는다는 한계도 전공 포인트.
- 결산 실무: 수정전시산표 → 결산수정분개(감가상각, 대손 설정, 미수·미지급·선급·선수 정리, 재고 실사 반영, 법인세비용 계상) → 수정후시산표 → 재무제표.

## 5. 감가상각 완전 정리

### 5-1. 개념

감가상각 = 유·무형자산의 취득원가를 **내용연수에 걸쳐 체계적·합리적으로 비용 배분**하는 절차(원가 배분이지 평가가 아님 — K-IFRS 1016호). 세법 관점에서는 **손금 귀속시기 문제**: 언젠가는 전액 손금이 되지만, 언제 얼마씩이냐를 법이 통제한다.

핵심 용어:
- **감가상각대상금액** = 취득원가 – 잔존가치 (세법은 잔존가치 0 원칙)
- **상각범위액** = 세법이 허용하는 그 사업연도의 최대 손금 (세법 용어)
- **시부인** = 회사 계상액과 상각범위액의 비교 판정

### 5-2. 회계상 감가상각 방법 전체 (공식 + 공통 예제)

공통 예제: 취득원가 10,000,000원, 잔존가치 1,000,000원, 내용연수 5년, 총예정생산량 9,000단위.

**① 정액법 (straight-line)** — 매기 균등 배분

```
연 상각비 = (취득원가 – 잔존가치) ÷ 내용연수
         = (10,000,000 – 1,000,000) ÷ 5 = 1,800,000원/년 (5년 내내 동일)
```

**② 정률법 (declining balance)** — 기초 장부금액에 일정률. 초기에 크고 점점 감소(가속상각)

```
연 상각비 = 기초 장부금액(= 취득원가 – 감가상각누계액) × 상각률 r
r = 1 – (잔존가치/취득원가)^(1/n)          ← 잔존가치가 0이면 r이 정의 불가 → 세법은 5% 의제(§5-4)
r = 1 – (0.1)^(1/5) = 0.36904…  ≈ 36.9%

1년차: 10,000,000 × 0.369 = 3,690,000
2년차: (10,000,000 – 3,690,000) × 0.369 = 2,328,390
3년차: 3,982,000 × 0.369 ≈ 1,469,000 … (매년 체감, 5년차 말 잔액 ≈ 잔존가치)
```

**③ 이중체감법 (double declining balance)** — 정률법의 실무 간편형. 상각률을 정액법률의 2배로 고정

```
r = 2/n = 2/5 = 40%
1년차: 10,000,000 × 0.4 = 4,000,000
2년차: 6,000,000 × 0.4 = 2,400,000
3년차: 3,600,000 × 0.4 = 1,440,000
4년차: 2,160,000 × 0.4 = 864,000
5년차: 잔존가치 1,000,000만 남기고 296,000 (마지막 해는 끼워맞춤)
```

**④ 연수합계법 (sum-of-years'-digits)** — 감가상각대상금액에 체감 분수를 곱함

```
연 상각비 = (취득원가 – 잔존가치) × 잔여내용연수 / 내용연수의 합계
내용연수 합계 = n(n+1)/2 = 5×6/2 = 15
1년차: 9,000,000 × 5/15 = 3,000,000
2년차: 9,000,000 × 4/15 = 2,400,000
3년차: 9,000,000 × 3/15 = 1,800,000
4년차: 9,000,000 × 2/15 = 1,200,000
5년차: 9,000,000 × 1/15 =   600,000   (합계 정확히 9,000,000 — 끼워맞춤 불필요)
```

**⑤ 생산량비례법 (units-of-production)** — 시간이 아니라 사용량 기준

```
연 상각비 = (취득원가 – 잔존가치) × 당기 실제 생산량 / 총예정생산량
당기 2,000단위 생산 시: 9,000,000 × 2,000/9,000 = 2,000,000
(변형: 작업시간비례법 — 생산량 대신 가동시간)
```

분류 방법(전공 시험 단골): 정액법·연수합계법·생산량비례법은 **(취득원가–잔존가치)** 기준, 정률법·이중체감법은 **장부금액(취득원가–누계액)** 기준. K-IFRS는 "자산의 미래경제적효익 소비 형태를 반영"하는 방법이면 무엇이든 허용하고 매기 재검토를 요구한다.

### 5-3. 세법(법인세법)상 허용 방법 — 자산 종류별로 강제된다

회계와 달리 세법은 자산별로 **선택 가능한 방법과 무신고 시 법정방법**을 못 박는다(법인세법 시행령 §26):

| 자산 | 선택 가능 | 신고 안 하면(법정) |
|---|---|---|
| **건축물, 무형자산**(아래 예외 제외) | **정액법만** | 정액법 |
| 건축물 외 유형자산 (기계장치, 차량, 비품 등) | 정률법 또는 정액법 | **정률법** |
| 광업권, 폐기물매립시설 | 생산량비례법 또는 정액법 | 생산량비례법 |
| 광업용 유형자산 | 생산량비례법·정률법·정액법 | 생산량비례법 |
| 개발비 | 20년 이내 신고 내용연수 균등상각 | 5년 균등 |
| 사용수익기부자산 | 사용수익기간 균등 | 좌동 |
| 주파수이용권·공항/항만시설관리권 | 사용기간 균등 | 좌동 |

- 상각방법은 최초 신고 후 **계속 적용**이 원칙, 변경은 관할세무서장 **승인** 필요(합병, 사업 인수 등 법정 사유).
- **연수합계법·이중체감법은 세법상 인정 안 됨** → K-IFRS로 연수합계법을 쓰는 회사는 매년 세무조정으로 차이를 유보 관리해야 한다.

### 5-4. 세법상 계산 요소

**잔존가액**: 원칙 **0**. 단 정률법은 상각률 산정 시 취득가액의 **5%로 의제**(0이면 r 계산 불능이므로), 그 5%는 미상각잔액이 취득가액의 5% 이하가 되는 사업연도의 상각범위액에 가산해 소진. 상각 완료 자산은 **비망가액 1,000원**을 남기고(처분 시 손금), 나머지 전액 손금 가능.

**내용연수**(법인세법 시행규칙 §15, 별표): 자산별 **기준내용연수**의 **±25% 범위**에서 영업개시(취득) 사업연도 신고기한까지 신고. 무신고 시 기준내용연수.

| 별표 | 대상 | 대표값 (기준내용연수, 괄호는 신고 가능 범위) |
|---|---|---|
| 별표2 | 시험연구용 자산 | 3년, 5년 |
| 별표3 | 무형자산 | 영업권·상표권·디자인권·실용신안권 5년 / 특허권 7년 / 어업권 등 10년 / 광업권 등 20년 / 댐사용권 50년 |
| 별표4 | **상각률표** (아래) | — |
| 별표5 | 건축물 등 구조·자산별 | 차량운반구·공구·기구·비품 **5년(4~6)** / 선박·항공기 12년(9~15) / 목조·연와조 등 건물 20년(15~25) / 철골·철근콘크리트조 **40년(30~50)** |
| 별표6 | 업종별 기계장치 | 제조업 다수 8년(6~10) 등 업종코드별 |

**상각률표(별표4) 발췌** — 정액법률 = 1/n, 정률법률 = 1 – 0.05^(1/n):

| 내용연수 | 정액법 | 정률법 |
|---|---|---|
| 4년 | 0.250 | 0.528 |
| 5년 | 0.200 | **0.451** |
| 6년 | 0.166 | 0.394 |
| 8년 | 0.125 | 0.313 |
| 10년 | 0.100 | 0.259 |
| 20년 | 0.050 | 0.140 |
| 40년 | 0.025 | — (건축물은 정액법만) |

**세법 공식** (회계 공식과 미묘하게 다름 — 잔존가치를 안 뺀다):

```
정액법 상각범위액 = 취득가액(자본적지출 포함) × 정액법 상각률
정률법 상각범위액 = 미상각잔액(취득가액 – 기왕 손금산입 상각누계) × 정률법 상각률
생산량비례법     = 취득가액 × 당기 채굴량 / 총채굴예정량
신규 취득 연도    = 상각범위액 × 사용 월수/12 (월할, 1개월 미만은 1개월)
```

**예제 — 기계장치 1억원, 내용연수 5년, 세법 기준:**

| 연도 | 정액법(0.200) | 정률법(0.451) — 미상각잔액 기준 |
|---|---|---|
| 1년차 | 20,000,000 | 100,000,000×0.451 = **45,100,000** |
| 2년차 | 20,000,000 | 54,900,000×0.451 = 24,759,900 |
| 3년차 | 20,000,000 | 30,140,100×0.451 = 13,593,185 |
| 4년차 | 20,000,000 | 16,546,915×0.451 = 7,462,659 |
| 5년차 | 19,999,000 (비망 1,000원) | 잔액 9,084,256이 취득가 5%(500만) 판정 로직에 걸려 **9,083,256 전액**(비망 1,000원 제외) |

정률법이 1년차에 2.25배를 상각하는 것이 보인다 — 초기 절세(과세이연) 효과 때문에 무신고 법정방법임에도 실무에서 그대로 쓰는 경우가 많다.

### 5-5. 시부인 계산 — 감가상각 세무조정의 본체 (별지 제20호가 하는 일)

세법상 감가상각은 **임의상각**: 결산에 비용으로 계상한 금액을 한도(상각범위액) 내에서만 인정.

```
회사계상 상각비 – 상각범위액 = (+) 상각부인액 → 손금불산입(유보)
                              (–) 시인부족액 → 원칙 소멸(그냥 손해).
                                              단, 전기 이월 상각부인액이 있으면
                                              시인부족액 한도 내에서 손금추인(△유보)
```

- **자산별 계산** — 자산 간 통산 금지(A자산 부인액과 B자산 부족액 상계 불가).
- **감가상각의제**: 법인세를 면제·감면받는 사업연도에는 상각 안 해도 한 것으로 의제 → 이후 상각범위액이 줄어든다(감면기간에 상각을 미뤄 감면 후 손금을 키우는 조작 방지).
- **즉시상각의제**: 자산 취득가액이나 자본적지출을 그냥 비용 처리하면, 그 금액을 "감가상각비로 계상한 것"으로 보아 시부인에 합산. 예외(비용 처리 즉시 인정):
  - 거래단위별 **취득가액 100만원 이하** 소액자산(고유업무상 대량 보유·사업 개시/확장용 제외)
  - 금액 불문: 전화기(휴대폰 포함), 개인용 컴퓨터(주변기기 포함), 어구, 영화필름, 공구, 가구, 시계·시험기기, 간판 등
  - **소액수선비**: 개별자산당 600만원 미만, 또는 전기말 장부가액의 5% 미만, 또는 3년 미만 주기의 주기적 수선
  - 시설 개체·기술 낙후로 **폐기** 시 비망가액 1,000원 남기고 손금
- **자본적지출 vs 수익적지출**: 내용연수 연장·가치 증가(개조, 엘리베이터 설치, 냉난방 설치)는 자본적지출 → 취득가액에 가산해 상각. 원상회복·능률유지(도색, 유리 교체, 소모품)는 수익적지출 → 당기 비용.

### 5-6. 특례들

- **업무용승용차**(2016.1.1 이후 취득): **5년 정액법 강제 + 미달 계상해도 강제 신고조정으로 손금산입** — 유일하게 임의상각이 아닌 강제상각. 그 위에 §3-11의 800만원 한도가 다시 씌워진다.
- **K-IFRS 도입 법인 특례**(법인세법 §23②): IFRS 전환으로 상각비가 줄어든 경우 종전 방식 기준 상각비까지 신고조정 손금 허용.
- **가속상각 특례**(조특법, 한시): 중소·중견기업 설비투자에 내용연수 50~75% 단축 허용 — 일몰이 자주 바뀌므로 적용 연도의 조특법 확인 필요.
- **중고자산 수정내용연수**: 기준내용연수의 50% 이상 경과한 중고자산 취득 시 [기준내용연수×50% ~ 기준내용연수] 범위에서 선택 신고 가능.

## 6. 발급·작성 경로 총정리

### 6-1. 누가 만드는가

| 문서 | 작성 주체 | 근거/조건 |
|---|---|---|
| 결산보고서 | 회사 경리팀 or 기장대리 세무사무소 | 회계프로그램에서 결산 후 출력 |
| 세무조정계산서 (**자기조정**) | 회사 스스로 | 외부조정 의무 대상이 아닐 때만 |
| 세무조정계산서 (**외부조정**) | **조정반 소속 세무사·회계사만** | 직전 수입금액 70억 이상, 외감법인, 조특법 감면 적용 법인 등은 외부조정 **의무**(법인세법 시행령 §97의3, 조정반은 지방국세청장 지정) |
| 성실신고확인서 | 세무사 등 (기장 세무사와 동일인 가능, 개인은 불가 규정과 다름) | §3-21 대상 법인 |

### 6-2. 작성 도구

- **세무조정(세무사무소 표준)**: 더존 세무사랑Pro / WEHAGO T, 한국세무사회 프로그램 등 — 장부(계정별원장)를 읽어 §3의 서식 대부분을 자동 생성 + 전자신고 파일(.101 등) 생성.
- **회계 결산**: 더존 Smart A/iCUBE, 경리나라, 이카운트 등.
- **직접 작성**: 홈택스 [세금신고→법인세]에서 서식을 화면 입력으로 직접 채울 수도 있음(초소규모 법인용, 실무에서는 드묾).

### 6-3. 제출 채널

- 법인세 + 세무조정계산서 + 표준재무제표: **홈택스** 전자신고 (신고 후 납부서 출력 → 은행/가상계좌/카드 납부).
- 법인지방소득세: **위택스**(wetax.go.kr) — 홈택스 신고 자료 연계 후 안분·신고·납부.
- 재무제표 부속서류(외감법인 등): 전자신고에 다 안 실리는 부속명세는 신고기한 후 10일 내 서면 제출 대상이 있음.

### 6-4. 사후 발급 경로 (이미 신고된 것을 나중에 받는 법) — 자동화 관점에서 중요

| 원하는 것 | 경로 |
|---|---|
| 신고서 원본 전체 (세무조정계산서 포함) | 홈택스 로그인 → **My홈택스 → 세금신고 내역** → 해당 신고 건 [보기/출력]. 또는 작성한 세무대리인에게 PDF 요청(실무 최다) |
| 신고서 접수증 | 같은 메뉴에서 접수증 재출력 |
| **표준재무제표증명** (금융기관 제출용) | 홈택스 → **국세증명·사업자등록·세금관련 신청/신고 → 즉시발급 증명** → 표준재무제표증명. 정부24, 무인민원발급기도 가능. ⚠️ 법인세 신고가 전산 처리된 뒤(신고 후 수 주)부터 발급 가능 |
| 납부서/영수증 | 홈택스 [납부 내역] 재출력, 위택스 [납부확인서] |
| 법인 등기·주주 관련 | 주식등변동상황명세서는 신고 내역에서, 등기부는 인터넷등기소(별개) |
| 외감법인 감사보고서 | DART(dart.fss.or.kr) 공시 — 로그인 불필요, 크롤링 최용이 |

## 8. 자동화 관점 시사점 (IDEA.MD 8번과의 연결)

서식별 자동화 난이도를 데이터 소스 기준으로 나누면:

1. **장부만 있으면 기계적으로 생성 가능 (규칙 기반, 난이도 하)** — 합계잔액시산표, 계정별 명세서 전부(보통예금~기타보증금), 세금과공과금명세서(키워드 판정), 선급비용명세서(날짜 안분), 표준재무제표(계정과목 매핑 테이블), 주요계정명세서.
2. **장부 + 고정 파라미터(자산대장, 세율표)로 계산 가능 (난이도 중)** — 감가상각 시부인(§5 로직 그대로 구현 가능), 기업업무추진비 한도, 업무용승용차 명세서(운행기록 데이터 필요), 수입금액조정(부가세 신고자료 대사), 원천납부세액(이자 원천징수영수증).
3. **연도 간 상태(유보·이월액) 연속성 관리 필요 (난이도 중상)** — 자본금과적립금조정명세서(을)·(갑), 세액공제 이월관리, 이월결손금 — 전기 신고 데이터를 DB로 보유해야 함.
4. **전문가 판단·서명이 법적으로 요구됨 (자동화 불가 영역)** — 외부조정 대상 법인의 조정계산서(조정반 세무사 서명), 성실신고확인서(확인자 책임). → 에이전트는 "초안 생성 + 검토 지원" 포지셔닝이 현실적.

또한 §3-17, §3-21 메모대로 **주민등록번호·거래처 정보 등 개인정보 밀도가 매우 높은 서식**(주식등변동상황명세서, 성실신고 주요항목 명세서)이 섞여 있으므로, 자동화 파이프라인 설계 시 이 서식들은 처리·저장 정책을 분리해야 한다.
