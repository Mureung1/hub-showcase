# 📄 PRD (Product Requirement Document)

# AI Portfolio Agent

---

# 1. 프로젝트 개요

## 1.1 프로젝트명

**AI Portfolio Agent**

---

## 1.2 프로젝트 소개

AI Portfolio Agent는 개발자의 GitHub 프로젝트, 이력서, 프로젝트 문서(README, docs, Wiki 등), 그리고 채용공고(Job Description)를 종합적으로 분석하여 기업 맞춤형 포트폴리오를 자동 생성하는 AI Agent 기반 웹 서비스이다.

기존 생성형 AI는 문장을 잘 작성하는 데 초점을 맞추고 있지만, 실제 취업에서는 가장 중요한 것이 **지원자의 실제 경험을 기반으로 한 설득력 있는 포트폴리오**이다.

본 프로젝트는 텍스트 생성이 아닌 **Evidence 기반 분석**을 핵심 가치로 삼는다.

AI는 사용자의 프로젝트를 먼저 이해하고, 해당 프로젝트가 채용공고와 어떻게 연결되는지를 판단한 후 가장 적합한 형태의 포트폴리오를 생성한다.

---

# 2. 문제 정의 (Problem Statement)

현재 취업 준비 과정에는 다음과 같은 문제가 존재한다.

### 문제 1

기업마다 요구하는 기술 스택과 역량이 다르다.

동일한 포트폴리오를 제출하면 서류 합격률이 낮아질 수 있다.

---

### 문제 2

지원자는 기업마다 포트폴리오를 수정해야 한다.

프로젝트 소개

기술 스택

강조 포인트

성과

구성 순서

등을 반복적으로 수정해야 하므로 많은 시간이 소요된다.

---

### 문제 3

기존 AI 도구는 실제 프로젝트를 충분히 이해하지 못한다.

사용자의 입력에만 의존하기 때문에

* 존재하지 않는 경험 생성
* 프로젝트와 맞지 않는 설명
* AI 특유의 문체
* 부정확한 기술 설명

등의 문제가 발생한다.

---

### 문제 4

GitHub에는 코드뿐 아니라 다양한 프로젝트 정보가 존재한다.

예를 들어

* README
* docs
* Wiki
* 프로젝트 구조
* 설정 파일

등이 존재하지만 대부분의 AI 서비스는 이를 충분히 활용하지 못한다.

---

# 3. 프로젝트 목표 (Goals)

본 프로젝트의 목표는 다음과 같다.

### Goal 1

사용자의 실제 프로젝트를 최대한 정확하게 이해한다.

---

### Goal 2

채용공고와 가장 적합한 프로젝트를 자동으로 선정한다.

---

### Goal 3

모든 결과는 실제 프로젝트를 근거로 생성한다.

---

### Goal 4

사용자가 별도의 수정 없이 제출 가능한 수준의 포트폴리오를 생성한다.

---

### Goal 5

포트폴리오 생성 시간을 기존 수작업 대비 90% 이상 단축한다.

---

# 10. 성공 지표 (Success Metrics)

프로젝트의 성공 여부는 다음 기준으로 판단한다.

### 기능적 목표

* GitHub 프로젝트를 정상적으로 분석할 수 있다.
* JD를 정상적으로 분석할 수 있다.
* 프로젝트와 JD를 매칭할 수 있다.
* 포트폴리오를 자동 생성할 수 있다.
* PDF로 다운로드할 수 있다.

### 사용자 경험 목표

* 사용자는 5분 이내에 맞춤형 포트폴리오를 생성할 수 있다.
* 기존 수작업 대비 포트폴리오 작성 시간을 크게 단축할 수 있다.
* 생성된 포트폴리오는 사용자가 최소한의 수정만으로 제출 가능한 수준을 목표로 한다.

# 12. 제품 비전 (Product Vision)

AI Portfolio Agent는 포트폴리오를 작성하는 도구가 이상의 개발자의 프로젝트를 이해하고 기업과의 연결고리를 찾아주는 AI Agent를 목표로 한다.

장기적으로는 개인의 프로젝트, 경험, 기술 역량을 종합적으로 분석하여 취업 준비 전 과정을 지원하는 AI Career Platform으로 발전시키는 것을 비전으로 한다.
