# S1 고양이 조력자 에셋

관계 선택(S1) 카드의 오른쪽 원형 미디어 슬롯에 넣을 고양이 일러스트입니다.

권장 파일명:

- `groupwork-cat.png` — 팀플냥
- `professor-cat.png` — 교수냥
- `senior-cat.png` — 선배냥
- `friend-cat.png` — 연인냥

권장 규격은 정사각형 PNG 또는 WebP, 최소 240×240px입니다. 카드에서 원형으로 잘리므로 얼굴·상체가 중앙에 오도록 배치합니다. 파일을 추가한 뒤 `src/domain/message.ts`의 각 `assetPath`에 `/cats/<파일명>`을 지정하면 됩니다.
