# 기업·채용 공고 예시 5개

> 확인일: 2026-07-24  
> 용도: CV2PF의 지원 기업·채용 공고 선택 데모 데이터  
> 주의: 채용 공고는 변경되거나 마감될 수 있다. 아래 내용은 원문을 복사한 것이 아니라
> 포트폴리오 생성에 필요한 업무·역량·강조점을 요약한 것이다.

## 선정 기준

- 기업이 직접 운영하는 채용 페이지 또는 기업의 공식 채용 플랫폼 게시물일 것
- 프론트엔드 직무여서 같은 샘플 CV로 비교 시연할 수 있을 것
- 기업과 제품의 성격, 인재상, 기술 요구가 서로 달라 맞춤 생성의 차이를 설명할 수 있을 것
- 공고 원문 링크와 확인일을 사용자에게 공개할 수 있을 것

## 한눈에 비교

| 기업 | 예시 포지션 | 핵심 맥락 | 포트폴리오 강조점 |
| --- | --- | --- | --- |
| 토스 | Frontend Developer | 자율적인 제품 조직, 금융 경험 개선 | 문제 발견, 제품 임팩트, 주도적 출시 |
| LINE Pay | Frontend Engineer | 결제·리워드·커머스, 대규모 트래픽 | 복잡한 흐름의 UI, 품질, 직군 간 협업 |
| Coupang Play | Staff Front-end Engineer (CX) | 멀티 플랫폼 스트리밍 경험 | 성능, 멀티 디바이스, 재사용 컴포넌트 |
| CLO Virtual Fashion | Frontend Developer | 디지털 패션 자산 협업 플랫폼 | 시스템 설계, 성능, 글로벌 협업 |
| QANDA | Frontend Engineer | 교육 검색·웹 경험 | 문제 정의, TDD, 모니터링과 개선 |

## 1. 토스

- 공고: [Frontend Developer](https://toss.im/career/job-detail?job_id=4770557003)
- 제품·조직 맥락: 작은 제품 조직이 높은 자율성과 책임을 바탕으로 금융 경험을 빠르게 개선한다.
- 주요 기술: React, TypeScript, Next.js, SPA, WebView
- 인재상 요약: 문제를 먼저 발견하고, 학습하며, 제품 임팩트까지 책임지는 사람
- 생성 시 강조: 문제를 발견한 이유, 의사결정 근거, 사용자 경험이나 성능이 달라진 결과

## 2. LINE Pay

- 공고: [LINE Pay Frontend Engineer](https://careers.linecorp.com/ko/jobs/3005/)
- 제품·조직 맥락: 결제·리워드·커머스의 대규모 트래픽을 안정적으로 처리한다.
- 주요 기술: React, Next.js, TypeScript, Git, HTTP, Database
- 인재상 요약: 실험과 코드 리뷰를 통해 품질을 높이고 여러 직군과 협업하는 사람
- 생성 시 강조: 복잡한 비즈니스 흐름을 단순화한 UI, 테스트·리뷰, 백엔드·디자인 협업

## 3. Coupang Play

- 공고: [Staff Front-end Engineer (CX)](https://www.coupang.jobs/en/jobs/7956824/staff-front-end-engineer-cx-coupang-play/?gh_jid=7956824)
- 제품·조직 맥락: PC, 스마트 TV, WebView를 아우르는 스트리밍 고객 경험을 만든다.
- 주요 기술: TypeScript, React, Next.js, SSR, A/B Test, WebView
- 인재상 요약: 고객 관점에서 성능을 측정하고 실험하며 멀티 플랫폼 문제를 해결하는 사람
- 생성 시 강조: Core Web Vitals, 접근성, 멀티 디바이스, 재사용 컴포넌트

## 4. CLO Virtual Fashion

- 공고: [Frontend Developer](https://jobs.lever.co/clovirtualfashion/57810e0b-dc08-4c8b-bfc5-c2dc4fb5d3ae)
- 제품·조직 맥락: 전 세계 팀이 디지털 패션 자산을 관리하고 협업하는 CLO-SET을 만든다.
- 주요 기술: React, TypeScript, REST API, Vite, 상태 관리
- 인재상 요약: 문제를 먼저 찾고 시스템 관점으로 설계하며 글로벌 환경에서 협업하는 사람
- 생성 시 강조: 복잡한 도메인의 구조화, 프론트엔드 설계, 빌드·렌더링 성능, 디자인 시스템

## 5. QANDA

- 공고: [Frontend Engineer](https://jobs.lever.co/mathpresso/3041f15a-fb50-4b6d-85df-d624b8ac1b20)
- 제품·조직 맥락: 누구나 좋은 교육 기회를 얻도록 대규모 검색과 웹 경험을 개선한다.
- 주요 기술: React, Next.js, TypeScript, Vitest, Playwright, MSW
- 인재상 요약: 사용자 문제를 명확히 정의하고 테스트와 학습으로 품질을 개선하는 사람
- 생성 시 강조: TDD·통합 테스트, 디자인 시스템, 트래픽·오류 관찰, 교육 사용자 임팩트

## 데이터 사용 원칙

1. 공고 정보는 사용자가 지원 방향을 비교하는 참고 자료로만 사용한다.
2. 생성 결과에는 CV에 존재하는 경험과 수치만 사용한다.
3. JD 문장을 그대로 복사하지 않고, CV의 실제 근거를 직무 관점에서 재배치한다.
4. 공고 확인일과 원문 링크를 함께 제공해 사용자가 최신 내용을 다시 확인하게 한다.
