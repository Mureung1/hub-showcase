## 1. 문제 정의

**한 줄:** 이력서 "내용"은 있는데, 그것을 보여줄 "포트폴리오 사이트"로 만드는 일이 여전히 번거롭다.

- 취준·이직 중인 개발자/디자이너는 경력·프로젝트(CV)는 정리돼 있지만, 이를 웹 포트폴리오로 바꾸려면 **디자인·퍼블리싱·배포**라는 별도 노동이 필요하다.
- 기존 방법의 한계
  - **직접 코딩** — 자유롭지만 시간·기술 부담이 크다.
  - **템플릿 빌더(노션·링크트리 등)** — 빠르지만 디자인이 획일적이고, 결과물을 내 파일(HTML)로 소유·수정하기 어렵다.
  - **범용 AI에 통째로 요청** — 결과가 매번 달라 재현·비교가 어렵고 디자인 방향을 통제하기 힘들다.
- **우리가 푸는 문제:** 내용(CV)과 디자인(DESIGN.md)을 **분리**해, 사용자는 *내용은 올리기만, 디자인은 고르기만* 하면 **완성된 독립 실행형 포트폴리오 HTML**을 즉시 얻는다.
  - → 결과는 **파일로 소유·배포** 가능하고, 디자인 선택은 **재현·비교** 가능하다.

## 2. 사용자 시나리오

**주 사용자:** 취준/이직 중인 주니어~미들 **개발자**, **프로덕트 디자이너** (마크다운으로 이력을 정리할 수 있는 사람).

### 해피 패스 (핵심 흐름)
1. **업로드** — CV(마크다운)를 붙여넣거나 `.md/.txt` 파일로 올린다. → 화면에서 *이름·직함·연락처·스킬·경력·프로젝트·학력*으로 파싱된 결과를 즉시 확인한다.
2. **디자인 선택** — 5개 `DESIGN.md` 테마 카드를 훑고, 각 테마 설명(팔레트·타이포·레이아웃·"이럴 때 좋아요")을 읽고 하나를 고른다.
3. **생성** — "이 디자인으로 생성"을 누르면 선택한 디자인으로 포트폴리오가 조립된다.
4. **전달** — 미리보기로 확인하고 `이름_portfolio.html`로 다운로드한다. (또는 HTML 코드를 복사해 직접 손본다.)

### 부가 시나리오
- **비교** — 같은 CV로 여러 테마를 바꿔가며 생성해 고른다.
- **수정 후 재생성** — CV 내용을 고쳐 다시 만든다.
- **직접 편집** — 받은 HTML을 열어 세부를 다듬은 뒤 원하는 곳에 배포한다.

## 3. 핵심 기능 (핵심 먼저, 서브는 뒤로)

### 3.1 CV 파싱 — *가장 핵심*
- **입력:** 마크다운 이력서(형식 자유) · **출력:** `{ 이름, 직함, 연락처[], 요약, 스킬[], 경력[], 프로젝트[], 학력[] }`
- **제약:** 사람마다 형식이 달라 **관대하게(휴리스틱)** 파싱하고, 실패해도 **원문은 항상 보존**한다.

### 3.2 디자인 테마 시스템
- 각 테마 = 사람이 읽는 **`DESIGN.md`**(선택 근거) + 생성기가 쓰는 **디자인 토큰**(색·폰트·레이아웃·헤더 스타일).
- 현재 5종: **Minimal Clean(기본)** · Terminal Dark · Creative Gradient · Editorial Serif · Pro Sidebar.

### 3.3 생성 엔진
- **입력:** 파싱된 CV + 디자인 토큰 · **출력:** **독립 실행형 HTML 1개**(인라인 CSS, 외부 의존 없음).
- 레이아웃 4종(single-column / timeline / two-column / sidebar) 지원, 사용자 입력은 이스케이프.

### 3.4 결과 전달
- 미리보기(iframe) ↔ HTML 코드 탭 · 파일 다운로드 · 코드 복사 · 새로 만들기.

### 서브 기능 (후순위)
- 샘플 CV 제공, 실 LLM 생성 경로(`generateWithAI.js` seam), (향후) PDF/DOCX 업로드, 원클릭 배포.

## 5. 향후 로드맵
- `generateWithAI.js` seam → 백엔드를 붙여 **실제 LLM(예: Claude API)로 자유도 높은 생성** (API 키는 서버에서만).
- PDF/DOCX 파싱 파이프라인.
- GitHub Pages / Vercel 원클릭 배포.
