수직 슬라이스 완성

저장 요청이 DB 행이 되고, 조회한 HTML이 다시 화면을 바꿉니다.

03

User Journey

사용자 행동 하나가 네 단계로 이어집니다

1

결과 생성

CV와 디자인을 선택해 독립 HTML 포트폴리오를 만듭니다.

2

현재 결과 저장

React가 HTML과 메타데이터를 Express API로 보냅니다.

3

목록 즉시 갱신

Supabase insert 응답을 받아 최근 기록 state를 갱신합니다.

4

DB 결과 다시 보기

저장 기록을 조회해 iframe 미리보기를 실제 HTML로 바꿉니다.

04

Architecture

저장 요청이 DB를 거쳐 화면 갱신으로 돌아옵니다

1
React가 저장 요청

생성된 HTML과 제목·테마를 POST /api/portfolios로 보냅니다.

2
Express가 검증·중계

요청 본문을 검사하고 Supabase REST API 호출을 담당합니다.

3
Supabase가 영구 저장

portfolios 테이블에 HTML과 메타데이터를 insert합니다.

4
응답으로 화면 갱신

201 응답과 조회 결과로 React state, 목록, iframe을 바꿉니다.

🔒 Supabase secret key는 Express 환경변수에만 두고 브라우저에는 노출하지 않습니다.

05

Actual Product Demo

실제 페이지에서 저장하고 다시 불러옵니다

2

Supabase의 저장 기록을 불러와 미리보기를 교체합니다.
