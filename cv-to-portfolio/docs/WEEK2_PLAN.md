## 주간 목표

금요일까지 같은 CV와 DESIGN.md로 **결정적 렌더러와 Claude AI 결과를 비교**하고,
AI가 실패해도 결정적 렌더러로 완성본을 제공하며, 새 클론에서도 테스트와 실행을 재현한다.

## 금요일 데모 시나리오

1. 샘플 CV와 테마를 선택한다.
2. 결정적 결과와 AI 결과를 나란히 비교한다.
3. 서버 중단 또는 키 미설정 상황에서 자동 폴백과 안내 메시지를 확인한다.
4. 선택한 결과 HTML을 다운로드한다.
5. `npm test`와 `npm run build` 성공을 확인한다.

## Feature Slice Agent 점검

프로젝트의 [`feature-slice`](../../.claude/skills/feature-slice/SKILL.md) Agent로 초안을
점검했다.

| 관점 | 사람이 작성한 백로그 | Agent 점검·조정 |
| --- | --- | --- |
| 목표 범위 | Must-Finish 5개 | 5개 모두 유지, 누락 없음 |
| 우선순위 | P0 3개, P1 1개, P2 1개 | 주당 P0 최대 3개 원칙에 적합 |
| 순서 | 주차 목록 중심 | 외부 연동 → UI 연결 → 실패 복구 → 테스트 → 재현성으로 고정 |
| 작업 크기 | M/S 표기 | 하루 단위 점검이 가능하도록 요일과 선행 이슈 추가 |
| 완료 기준 | 금요일 데모 중심 | HTTP 코드·명령·화면·빌드 등 관찰 가능한 조건으로 구체화 |
| 위험 관리 | 폴백 포함 | 폴백을 독립 P0로 유지해 외부 API 실패 위험을 격리 |

결론적으로 원안의 범위는 적절했다. Agent 점검으로 **작업 간 의존성, 일일 종료점,
검증 방법, 컷 기준**을 명확히 했다.
