# 디자인 리뷰 — CV2PF 앱 셸 (2026-07-09)

> `cv2pf-design` 스킬(`.claude/skills/cv2pf-design`)의 **디자인 리뷰 워크플로**로 현재 앱
> 셸(`client/src/index.css` · `client/src/**`)이 스티치 시안(의도)과 맞는지 검수한 기록.
> 검수 대상은 **CV2PF 도구 UI**(생성물 6개 테마 아님).

## 방법

스킬의 6단계(의도 로드 → 토큰 대조 → 레이아웃 대조 → 컴포넌트 대조 → 체크리스트 → 판정)를
그대로 돌렸다. 판정은 `PASS / 개선 / 불일치`.

## 이번에 고친 것 (토큰 1차 정렬)

`client/src/index.css` 의 `:root` 를 스킬 토큰과 일치시켰다.

- 인디고 `#4F46E5` → **Corporate Blue `#2563EB`**, `--brand-strong #004AC6`, `--brand-soft #EFF4FF`
- 성공색 `#16A34A` → **`#059669`**(+`--ok-soft #ECFDF5`)
- 반경 단일 `14px` → **`--radius-sm 8px` / `--radius 12px` / `--radius-lg 16px`**
- 본문 폰트 → **`--font-sans`(Inter 우선 + Pretendard/시스템 폴백)**
- 버튼: 반경 토큰화(8px), `:focus-visible` 링, 전환용 `.btn.success` 변형 추가

## 남은 불일치 (2주차 개발 항목)

- **셸 레이아웃 전환**: 상단 알약 스텝퍼 → **좌측 세로 4단계 사이드바 + 상단 앱바(CV2PF
  워드마크·도움말·임시저장·아바타)**. 컴포넌트 재배치가 필요해 토큰 정렬과 분리했다.
- **전환 CTA에 초록 적용**: “다음: 포트폴리오 생성”/“HTML 다운로드” 버튼에 `.btn.success`
  실제 적용(현재는 변형만 준비).
- **DESIGN.md 뷰어 / 생성 로그 터미널**의 다크 코드 패널 스타일 정식화.
