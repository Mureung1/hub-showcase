# Terminal Dark

터미널 창을 열어둔 것 같은 다크 테마입니다. 모노스페이스 heading과 네온 초록 accent로 "코드가 곧 이력서"인 개발자의 감성을 그대로 옮겼습니다.

## 팔레트
- 배경 `#0A0E14` — 거의 검정에 가까운 짙은 네이비 블랙, 터미널 배경 그 자체
- 표면(카드) `#121820` — 배경보다 한 톤 밝은 패널, 코드 블록처럼 살짝 떠 보임
- 본문 `#D6E0EA` — 차분한 오프화이트, 배경 대비 14.5:1로 눈이 편함
- 보조 텍스트 `#8A97A6` — 주석(comment) 같은 회청색, 대비 6.5:1로 또렷함
- accent `#3BE38B` — 네온 그린. 프롬프트 커서와 성공 로그의 색, 링크·강조·타임라인 점에
- accent2 `#4FD6E0` — 시안. 키워드·태그·보조 강조용
- 경계선 `#243040` — 은은한 청록빛 hairline

## 타이포그래피
- Heading: JetBrains Mono — 코드 폰트로 이름·섹션 제목을 찍어 "터미널 출력" 느낌
- Body: Inter — 본문은 가독성 높은 산세리프로 균형을 잡음
- 모노 heading + 산세리프 body 조합이 감성과 실용을 동시에 챙깁니다

## 레이아웃
- timeline 레이아웃 — 경력·프로젝트를 커밋 로그처럼 세로 타임라인으로 흐르게
- split 헤더 — 좌측 이름/직함, 우측 연락처·GitHub 링크를 나눠 배치해 CLI 헤더처럼 정돈

## 성격
차갑고 정밀하며 자신감 있는 톤. 과한 장식 없이 콘텐츠와 코드로 말합니다.

## 이럴 때 좋아요
- GitHub·기술 블로그·CLI 도구 경험을 전면에 내세우고 싶은 개발자
- 스타트업·인프라·오픈소스 포지션 지원자
- "디자인보다 실력"이라는 인상을 주고 싶을 때
