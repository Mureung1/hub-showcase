# 2단계 · 도구 선택 (select_tool)

> 이 파일은 런타임에 로드되는 자산이다. 코드에 프롬프트를 박지 않는다.
> 바꿀 때는 [CHANGELOG.md](./CHANGELOG.md)에 무엇을·왜·결과를 남긴다.

**목적** 초록으로 충분한지, 본문까지 읽을지 결정한다. **에이전트의 도구 선택이 실제로 일어나는 유일한 지점.**
**입력** `title`, `abstract`
**출력**
```json
{"need_fulltext": true, "reason": "한 문장"}
```
**fallback** `{"need_fulltext": false}` → **비용이 싼 쪽으로.** 판단이 안 될 때 본문을 받으면 돈과 시간이 샌다.

## 프롬프트
```text
아래 논문을 요약할 때, 초록만으로 '기여·방법·결과'를 정확히 쓸 수 있는가?
아니면 본문까지 읽어야 하는가?

본문이 필요한 경우:
- 새 방법을 제안하는데 초록에 구조·수식·알고리즘 설명이 없다
- 결과를 언급하는데 실험 설정(데이터셋·베이스라인·지표)이 없다

초록으로 충분한 경우:
- 서베이·포지션 페이퍼처럼 초록이 곧 요지인 경우
- 초록에 방법과 수치가 이미 다 있는 경우

반드시 아래 JSON만 출력하라.
{"need_fulltext": true 또는 false, "reason":"한 문장"}

제목: {title}
초록: {abstract}
```
