# Design Skill

## Project

Pick My Clothes - My Style Diary

AI가 오늘의 코디를 추천해 주고, 사용자가 코디를 다이어리처럼 기록하고 저장할 수 있는 감성적인 웹 서비스

---

# Design Goal

전체적인 분위기는 '나의 코디 다이어리'를 컨셉으로 한다.

단순한 쇼핑몰 느낌이 아니라, 사용자가 자신의 하루를 기록하는 감성적인 공간처럼 느껴질 수 있도록 디자인한다.

사용자가 편안하게 사용할 수 있는 따뜻한 분위기를 제공하며, AI가 추천해 주는 코디를 하나의 일기처럼 받아들이도록 구성한다.

# UI Style

전체 UI는 실제 다이어리를 펼쳐놓은 느낌을 준다.

화면을 여러 개의 카드(Card)로 구성하여 내용을 자연스럽게 구분한다.

모든 버튼은 둥근 모서리를 사용하여 부드러운 이미지를 유지한다.

과도한 그림자 대신 은은한 Shadow를 사용한다.

여백을 충분히 사용하여 답답하지 않은 레이아웃을 만든다.

# Illustration Style

- 실제 의류 사진 또는 감성적인 일러스트 사용
- AI 추천 결과를 카드 형태로 표현
- 스티커나 메모지 같은 요소를 활용하여 다이어리 감성을 강화

---

# UX Principles

- 사용자는 최소한의 입력만으로 추천을 받을 수 있어야 한다.
- 버튼과 기능은 직관적으로 이해할 수 있어야 한다.
- 추천 결과는 읽기 쉽고 감성적인 문장으로 표현한다.
- 사용자가 자신의 코디를 저장하고 다시 확인하는 과정이 자연스러워야 한다.

---

# AI Prompt Rules

디자인을 생성할 때 아래 원칙을 유지한다.

- "My Style Diary" 컨셉 유지
- 노트 또는 다이어리 느낌 유지
- 파스텔 핑크 중심의 컬러 사용
- 카드 형태의 UI 사용
- 라운드 디자인 적용
- 과도한 애니메이션 사용 금지
- 감성적이고 따뜻한 분위기 유지
- 모바일과 PC 모두 고려한 반응형 디자인
- 깔끔하고 여백이 충분한 레이아웃 유지
