# Pick My Clothes — 프로젝트 기획서

> 네이버 커넥트 재단 AI Agent 서비스 개인 프로젝트

---

## 1. 문제 정의 (Problem)

### 핵심 문제

> **"약속에 나가기 전, 무엇을 입을지 고민하다가 약속에 늦은 적이 있다."**

### 문제가 발생하는 이유

| 원인 | 설명 |
|------|------|
| **선택 과부하** | 옷장에 옷은 많지만, 상황에 맞는 조합을 떠올리기 어렵다 |
| **상황-옷 매칭 부재** | 회의, 데이트, 친구 모임 등 상황마다 적합한 스타일이 다르지만, 기준 없이 고민한다 |
| **날씨·장소 미반영** | 날씨와 장소를 고려하지 않아 부적절한 코디를 고르거나, 다시 갈아입느라 시간을 낭비한다 |
| **시간 압박** | 출발 직전에 결정해야 해서 고민 시간이 길어지고, 결과적으로 지각한다 |

### 이 서비스가 푸는 문제

사용자의 **옷장(보유 의류)**과 **오늘의 상황(장소·상황·날씨)**을 AI Agent가 분석해, **빠르게 입을 코디를 추천**한다.

"무엇을 입을지" 고민하는 시간을 줄여 **지각을 방지**하고, 상황에 맞는 스타일을 제안한다.

### 타겟 사용자

- 약속·외출 전 옷 고민으로 자주 시간을 쓰는 20대
- 옷은 많지만 코디 감각에 자신 없는 사람
- 출근·모임·데이트 등 상황별로 다른 스타일이 필요한 사람

## 2. 사용자 시나리오 (User Scenario)

### 시나리오 A — 오늘 나갈 때: 내 옷장 기반 코디 추천 (메인 플로우)

```
[고민] → [서비스 접속] → [상황 입력] → [옷장 확인] → [AI 코디 추천] → [코디 결정]
```

| 단계 | 사용자 행동 | 시스템 반응 |
|------|------------|------------|
| 1 | 약속 전 "뭐 입지?" 고민 | — |
| 2 | Pick My Clothes AI Agent 접속 | 홈 화면, 오늘 날씨 간단 표시 |
| 3 | **장소·상황·날씨** 입력 (또는 프리셋 선택) | 예: "강남 / 친구들과 브런치 / 맑음 22°C" |
| 4 | (최초 1회) 옷장에 옷 사진 업로드 | AI가 카테고리·색상·스타일 자동 태깅 |
| 5 | "코디 추천" 요청 | AI가 **내 옷장**에서 2~3개 코디 제안 |
| 6 | 추천 코디 확인 후 선택 | "이 코디로 결정" → 출발 |

**상황 프리셋 예시 (간편 선택)**

- 회의 / 출근
- 친구들과 놀기
- 데이트
- 운동 / 등산
- 격식 있는 행사

---

### 시나리오 B — 미래 코디 계획: 새 옷 포함 추천

```
[미래 약속 계획] → [상황 입력] → [새로운 옷] 버튼 → [AI 코디 + 구매 링크] → [쇼핑 or 저장]
```

| 단계 | 사용자 행동 | 시스템 반응 |
|------|------------|------------|
| 1 | 다음 주 데이트 코디를 미리 정하고 싶음 | — |
| 2 | 장소·상황·날씨 입력 | — |
| 3 | **"새로운 옷"** 버튼 클릭 | 옷장에 없는 아이템 포함 코디 추천 모드 |
| 4 | 추천 코디 확인 | 기존 옷 + **구매 필요 아이템** 표시 |
| 5 | 구매 링크 클릭 | 쇼핑몰/브랜드 페이지로 이동 |
| 6 | (선택) 코디 저장 | "다음 주 데이트 코디"로 저장 |

---

### 시나리오 C — 대화형 코디 피드백 (AI Agent)

> 사용자가 이미 정한 코디(또는 일부)에 대해 **대화로 질문**하면, AI Agent가 어울리는 아이템을 추천하고 **내 옷장 사진을 리마인드**하거나 **구매 링크**를 함께 제공한다.

```
[코디 일부 결정] → [Agent에게 질문] → [AI 피드백 + 추천] → [옷장 리마인드 or 쇼핑 링크] → [최종 결정]
```

| 단계 | 사용자 행동 | 시스템(AI Agent) 반응 |
|------|------------|----------------------|
| 1 | 오늘 입을 옷 중 일부는 정했지만, 나머지가 고민됨 | — |
| 2 | Agent 채팅에 상황·고민 입력 | 예: *"오늘 블라우스에 치마 입을 건데, 신발을 뭐 신을지 모르겠어"* |
| 3 | — | Agent가 **이미 정한 아이템(블라우스+치마)**을 파악하고, 어울리는 신발 스타일 제안 |
| 4 | — | **내 옷장**에 해당 스타일 신발이 있으면 → 업로드해 둔 사진과 함께 리마인드 |
| 5 | — | 옷장에 없으면 → **"새로운 옷"** 모드로 메리제인 등 추천 + **쇼핑 링크** 제공 |
| 6 | 추천 확인 후 선택 | "이 신발로 할게" → 코디 완성 |

#### 대화 예시

**사용자**
> 오늘 블라우스에 치마 입을 건데, 신발을 뭐 신을지 모르겠어.

**AI Agent**
> 블라우스와 치마 조합이면 **메리제인 구두**나 **로퍼**가 잘 어울릴 것 같아요.  
> 깔끔하고 여성스러운 느낌을 살리기 좋아요.
>
> 📷 **내 옷장에서 찾은 신발**
> - 베이지 메리제인 (업로드 사진) — 블라우스 톤과 잘 맞아요
> - 블랙 로퍼 (업로드 사진) — 치마와 클래식한 조합이에요
>
> 옷장에 마음에 드는 게 없다면, 아래 아이템도 추천드려요.  
> 🛒 [메리제인 구두 — ○○몰](링크) | [로퍼 — △△몰](링크)

**사용자**
> 베이지 메리제인으로 할게!

**AI Agent**
> 좋아요! 블라우스 + 치마 + 베이지 메리제인으로 코디가 완성됐어요. 오늘 코디 저장할까요?

#### 시나리오 A·B·C 관계

| 시나리오 | 트리거 | Agent 역할 |
|----------|--------|-------------|
| **A** (오늘 나갈 때) | 상황 입력 → "코디 추천" | 처음부터 전체 코디 제안 |
| **B** (미래 계획) | "새로운 옷" 버튼 | 옷장 + 구매 아이템 포함 코디 |
| **C** (대화형 피드백) | 채팅으로 부분 고민 질문 | **이미 정한 코디** 기준으로 부족한 아이템만 추천 + 옷장 리마인드/링크 |

## 3. 핵심 기능 (Core Features)

> 서브 기능보다 **핵심 기능**을 먼저 정의합니다.

### 3-1. 상황 기반 코디 추천 (Core #1)

**설명:** 사용자가 입력한 장소·상황·날씨를 AI Agent가 이해하고, 그에 맞는 코디를 추천한다.

| 항목 | 내용 |
|------|------|
| 입력 | 장소, 상황(목적), 날씨(온도·강수 등) |
| 출력 | 2~3개 코디 조합 + 각 코디 선택 이유 |
| AI 역할 | 상황 → 스타일 규칙 매핑 (회의→포멀, 친구 모임→캐주얼 등) |

**예시**

- 입력: "강남 / 회의 / 흐림 18°C"
- 출력: "블라우스 + 슬랙스 + 가디건" + "격식 있는 자리에 적합하고, 흐린 날씨에 가디건으로 체온 조절"

---

### 3-2. 내 옷장 기반 추천 (Core #2)

**설명:** 사용자가 업로드한 **실제 보유 의류**만 사용해 코디를 구성한다.

| 항목 | 내용 |
|------|------|
| 입력 | 옷 사진 (업로드) |
| 처리 | AI가 카테고리(상의/하의/아우터 등), 색상, 스타일 태깅 |
| 출력 | **내 옷장에 있는 옷**으로만 구성된 코디 |

**핵심 가치:** "없는 옷"이 아닌 "내가 가진 옷"으로 추천 → **바로 입을 수 있음**

---

### 3-3. AI Agent 대화형 추천 (Core #3)

**설명:** 단순 버튼 클릭이 아니라, Agent가 상황을 묻고 맥락을 이해한 뒤 추천한다.

| 항목 | 내용 |
|------|------|
| Agent 역할 | 상황 질문, 옷장 분석, 코디 생성, 이유 설명 |
| 사용자 경험 | "오늘 뭐 입을까?" → Agent가 장소/상황 확인 → 추천 |

---

### 3-4. 새 옷 포함 코디 + 구매 링크 (Core #4)

**설명:** 미래 코디 계획 시, 옷장에 없는 아이템을 포함한 코디를 추천하고 구매 링크를 제공한다.

| 항목 | 내용 |
|------|------|
| 트리거 | "새로운 옷" 버튼 |
| 출력 | 기존 옷 + **추가 구매 아이템** + 쇼핑 링크 |
| 사용 시점 | 미래 약속 코디 미리 계획할 때 |

---

### 3-5. 대화형 코디 피드백 Agent (Core #5)

**한 줄 정의:** 사용자가 자연어로 코디 고민을 말하면, Agent가 **이미 정한 옷 + 부족한 아이템**을 이해하고 추천·리마인드·구매 링크까지 제공한다.

#### 5-1. 자연어 코디 고민 이해 (Intent & Context Parsing)

| 항목 | 내용 |
|------|------|
| **역할** | 사용자 발화에서 "이미 정한 것"과 "고민하는 것"을 구분 |
| **입력 예** | "블라우스에 치마 입을 건데 신발 뭐 신을지 모르겠어" |
| **파싱 결과** | 확정: 상의(블라우스), 하의(치마) / 미정: 신발 |
| **추가 맥락** | (선택) 장소, 날씨, 상황 — 대화 중 Agent가 짧게 확인 가능 |

**핵심 가치:** 폼 입력 없이 **말하듯** 질문해도 Agent가 코디 맥락을 파악한다.

#### 5-2. 부분 코디 기반 보완 아이템 추천 (Partial Outfit Completion)

| 항목 | 내용 |
|------|------|
| **역할** | 확정된 아이템 조합에 어울리는 **미정 아이템**만 추천 |
| **입력** | 확정 코디(블라우스+치마) + 미정 카테고리(신발) |
| **출력** | 2~3개 스타일 옵션 + 각각 선택 이유 |
| **추천 예** | "메리제인 구두", "로퍼", "스트랩 힐" |

**핵심 가치:** 전체 코디를 다시 짜지 않고, **딱 고민하는 한 가지**에만 답한다.

#### 5-3. 내 옷장 리마인드 (Wardrobe Match & Remind)

| 항목 | 내용 |
|------|------|
| **역할** | 추천한 스타일과 **사용자 옷장**을 매칭해, 이미 가진 아이템을 사진과 함께 보여줌 |
| **입력** | 추천 스타일(메리제인) + 사용자 업로드 옷장 DB |
| **출력** | 매칭된 옷 사진 + "베이지 메리제인 — 블라우스 톤과 잘 맞아요" |
| **조건** | 옷장에 해당 카테고리·스타일이 있을 때만 표시 |

**핵심 가치:** "그 신발 있었지!" — **구매 없이** 바로 코디를 완성할 수 있다.

#### 5-4. 옷장 미보유 시 쇼핑 링크 제공 (Shop Link Fallback)

| 항목 | 내용 |
|------|------|
| **역할** | 옷장에 맞는 아이템이 없으면, 추천 아이템의 **구매 링크** 제공 |
| **트리거** | 5-3에서 매칭 결과 0건, 또는 사용자가 "옷장에 없어"라고 말할 때 |
| **출력** | 추천 아이템명 + 쇼핑몰/브랜드 링크 1~2개 |
| **연계** | 시나리오 B "새로운 옷" 기능과 동일한 링크·상품 로직 공유 |

**핵심 가치:** 옷장에 없어도 **다음 행동(구매)**까지 이어진다.

#### 5-5. 대화형 피드백 응답 (Conversational Response)

| 항목 | 내용 |
|------|------|
| **역할** | 추천 결과를 **대화 톤**으로 설명하고, 후속 질문·확정을 유도 |
| **응답 구성** | ① 스타일 추천 + 이유 ② 옷장 리마인드(있을 때) ③ 쇼핑 링크(없을 때) ④ 확인 질문 |
| **후속 예** | "베이지 메리제인으로 할게" → "코디 완성! 저장할까요?" |

**핵심 가치:** 단순 검색 결과가 아니라 **Agent와 대화하며** 코디를 확정하는 경험.

#### 기능 간 관계

```
[사용자 자연어 입력]
        ↓
   5-1 맥락 파악 (뭐 입을지 / 뭐가 고민인지)
        ↓
   5-2 보완 아이템 추천 (신발·가방·아우터 등)
        ↓
   ┌──── 5-3 옷장에 있음? ────→ 사진 리마인드
   │
   └──── 없음 ─────────────→ 5-4 쇼핑 링크
        ↓
   5-5 대화형 응답 + 후속 대화
```

#### 다른 핵심 기능과의 연계

| 연계 대상 | 관계 |
|-----------|------|
| **3-2 내 옷장 기반 추천** | 5-3 리마인드의 데이터 소스 (업로드·태깅된 옷장) |
| **3-4 새 옷 + 구매 링크** | 5-4 쇼핑 링크 로직 공유 |
| **3-1 상황 기반 추천** | 대화 중 장소·날씨·상황 반영 시 참조 |
| **3-3 AI Agent 대화형 추천** | 동일 Agent UX — 시나리오 A는 "전체 추천", C는 "부분 피드백" |

## 5. 성공 지표

| 지표 | 목표 |
