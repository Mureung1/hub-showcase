# FitCheck Design System Specification (`DESIGN.md`)

이 문서는 트레이너용 회원 관리 플랫폼 'FitCheck'의 UI/UX 일관성을 위한 디자인 시스템 명세서입니다. 개발 에이전트는 본 프레임워크와 컴포넌트 배치 규칙을 엄격히 준수하여 프론트엔드 코드를 작성해야 합니다.

---

## 1. 글로벌 테마 및 디자인 토큰 (Design Tokens)

### 1.1 색상 체계 (Color Palette)

본 플랫폼은 깊은 다크 모드(Deep Dark Mode)를 기반으로 하며, 핵심 액션 및 상태 구분을 위해 제한된 포인트 컬러를 사용합니다.

| Token Name              | Hex Code  | Usage                                            |
| :---------------------- | :-------- | :----------------------------------------------- |
| `--color-bg-base`       | `#111111` | 애플리케이션 전체 가장 바깥쪽 배경색             |
| `--color-bg-sidebar`    | `#222222` | 좌측 네비게이션 사이드바 배경색                  |
| `--color-bg-card`       | `#2D2D2D` | 대시보드 위젯, 콘텐츠 카드, 입력 영역 배경색     |
| `--color-brand-primary` | `#E50914` | 로고 심볼(FT), 대시보드 활성화 메뉴 강조색 (Red) |
| `--color-text-main`     | `#FFFFFF` | 헤더, 메인 타이틀, 강조 데이터 텍스트            |
| `--color-text-muted`    | `#999999` | 가이드라인 설명글, 비활성 메뉴, 플레이스홀더     |
| `--color-border`        | `#3A3A3A` | 카드 테두리 및 구분선                            |

### 1.2 신호등 / 상태 컬러 토큰 (Status Colors)

대시보드 상단 및 커뮤니케이션용 핵심 상태 색상 세트입니다.

- `--color-status-red`: `#FF3B30` (주의 필요 / 회원수 알림)
- `--color-status-yellow`: `#FFCC00` (원격 필요 / 피드백 대기)
- `--color-status-green`: `#34C759` (정상 관리)
- `--color-status-purple`: `#AF52DE` (피드백 대기중 / 기타 상태)

### 1.3 타이포그래피 및 레이아웃 규칙 (Layout & Typography)

- **사이드바 너비:** 전체 화면의 고정 가로폭 레이아웃을 유지합니다.
- **기본 서체:** Sans-serif 계열 (시스템 다크모드 최적화 폰트)
- **둥글기 값 (Border Radius):** - 기본 카드 및 위젯 박스: `8px`
  - 상태 알림 원형 배지 및 검색바: `완전 원형(Full-rounded / 9999px)` 또는 `4px`
- **그리드 간격 (Gap):** 메인 캔버스의 모든 대시보드 카드 간격은 고정 16px(`--spacing-md`) 또는 24px(`--spacing-lg`)의 Flex/Grid Gap을 적용합니다.

## 2. 화면별 핵심 레이아웃 및 컴포넌트 규칙

### 2.1 공통 레이아웃 구조 (App Shell)

- **Left Sidebar:** 서비스 로고(`FT`), 메뉴 목록(대시보드, 회원관리, 루틴 관리, 식단 피드백, 성장 리포트) 배치. 활성화된 메뉴는 배경 `--color-brand-primary`로 강조.
- **Top Bar:** 중앙에 긴 타원형의 `회원 이름, 운동 검색 ...` 바가 위치하며, 우측 끝에 트레이너 프로필(`김 트레이너`) 배치.

### 2.2 [대시보드] 화면 (Dashboard)

- **상단 스태츠 라인:** 4개의 가로형 상태 카드(Red, Yellow, Green, Purple 원형 배지와 설명 포함) 배치.
- **중단 그리드:** 좌측에 넓은 `신호등 소통 대시보드` 영역, 우측에 좁은 `빠른 루틴 입력` 영역이 2분할 뷰로 배치.
- **하단 그리드:** 가로 전체를 차지하는 `식단 피드백 타임라인` 위젯 영역 배치.

### 2.3 [루틴 관리] 화면 (Routine Management)

- **상단 서브 타이틀:** "회원별 운동 루틴을 분석하고 편집하여 가이드를 전송해보세요." 문구 노출.
- **회원 선택 토글:** 상단에 가로로 길게 배치되는 회원 필터 및 선택 영역.
- **중앙 2분할 레이아웃:**
  - **좌측 섹션 (넓음):** `선택한 회원의 루틴` 상세 관리 그리드. 상단에 `루틴 복사, 중량 추가, 세트 추가, 랩 추가 등의 버튼` 그룹이 한 줄로 배치됨.
  - **우측 섹션 (좁음):** 3단 적층 구조 (`AI를 통한 회원별 루틴 추천` -> `가이드 미리보기` -> `가이드 전송 이력`).

### 2.4 [식단 피드백] 화면 (Diet Feedback)

- **상단 네비게이션:** "오늘, 어제, 이번 주, 달별 선택 버튼"이 좌측에 배치되어 선택 시 날짜별 정렬 기능 작동. 우측 끝에 `회원 선택 토글` 배치.
- **메인 뷰:** 가로가 넓은 단일 통 카드로 `기간별 회원들이 업로드한 식단` 리스트/그리드가 표시되는 영역.

### 2.5 [성장 리포트] 화면 (Growth Report)

- **상단 스태츠 요약:** 4개의 주요 지표 카드가 대형 넘버와 함께 가로 배열.
  1. 총 운동 횟수 (예: `17회` / 8주간의 운동)
  2. 식단 준수율 (예: `17%` / 최근 4주 기준)
  3. 최근 중량 (예: `65kg` / 스쿼트)
  4. 이번 주 변화 (예: `-2kg` / 지난 주 대비, 감소치는 Red 계열 강조 가능)
- **하단 그리드 배분:**
  - 좌측(넓음): `분석된 성장 리포트 그래프` 영역.
  - 우측(좁음): `식단 업로드 현황` 요약 위젯.
  - 최하단 가로 전체: `최근 달성한 기록` 타임라인/보드 영역.

## 3. 개발 에이전트 행동 지침 (Agent Constraints)

1. **컬러 적용 제한:** 소스 코드 작성 시 임의의 회색이나 원색을 하드코딩하지 마세요. 배경은 반드시 `--color-bg-base`와 `--color-bg-card` 구분을 지키고, 텍스트는 주 텍스트(`--color-text-main`)와 부 텍스트(`--color-text-muted`)의 계층을 엄격히 분리하세요.
2. **반응형 대시보드 컴포넌트:** 지정된 위젯 영역(예: 신호등 소통 대시보드, 빠른 루틴 입력)은 Flexbox 또는 CSS Grid를 사용하여 화면 크기에 맞게 내부 콘텐츠가 유연하게 채워지도록 컴포넌트 스켈레톤을 구성하세요.
3. **버튼 스타일 일관성:** 루틴 관리의 상단 버튼 그룹처럼 여러 버튼이 나열될 때는 디자인 토큰에 정의된 둥글기 값과 여백을 균일하게 설정하여 시각적 파편화를 방지하세요.
