# 관계형 AI 기능 계획 Agent

## 목적

관계형 AI 프로젝트의 핵심 수직 슬라이스를 GitHub Issue로 분해하여 일주일 내에 완성할 수 있도록 작업을 계획합니다.

## 핵심 사용자 시나리오

사용자가 자신의 상황과 감정을 입력하면 관계형 AI가 공감형 반응이나 추가 질문을 제공하는 웹서비스 사용자 경험:

1. 사용자가 React 화면에서 상황(텍스트)과 감정(선택)을 입력
2. '제출' 버튼을 클릭
3. Express 서버가 입력을 검증하고 Mock AI가 응답 생성
4. Supabase에 사용자 입력과 AI 응답이 저장됨
5. React 화면에 AI 응답이 표시되고 대화 화면이 갱신됨

## 핵심 수직 슬라이스 완료 기준

- [ ] 상황 입력 필드와 감정 선택 UI 완성
- [ ] Mock AI 응답이 화면에 표시됨
- [ ] Express 서버가 입력을 검증하고 Mock 응답 생성
- [ ] Supabase에 대화 저장 및 조회 가능
- [ ] React와 Express, Express와 Supabase 연결 완료
- [ ] 오류 및 로딩 상태 처리
- [ ] 전체 프로세스 E2E 테스트 완료

## 기술 스택

- **Frontend**: React (useState)
- **Backend**: Express
- **Database**: Supabase (@supabase/supabase-js)
- **통신**: fetch API
- **Mock AI**: 규칙 기반 응답 생성

## 영역별 분류

- **Planning**: 요구사항 정의 및 계획 수립
- **Agent**: 자동화 에이전트 개발
- **Frontend**: React 컴포넌트 및 상태 관리
- **Backend**: Express 서버 및 API 라우트
- **Database**: Supabase 데이터베이스 설정
- **Integration**: Frontend-Backend-Database 연결
- **Test**: 기능 테스트 및 E2E 검증
- **Docs**: 문서화 및 README 업데이트

## 우선순위 가이드

**P0 (필수)**
- 수직 슬라이스 구현에 반드시 필요한 작업
- 다른 작업의 선행 작업인 경우
- 예: API 라우트, DB 스키마, 연결 통합

**P1 (중요)**
- 사용자 경험 개선
- 추가 UI 요소 또는 화면 개선
- 예: 에러 처리, UI 컴포넌트 보완

**P2 (추가)**
- 향후 개선 사항
- 현재 범위에서 제외된 기능
- Backlog로 이동
