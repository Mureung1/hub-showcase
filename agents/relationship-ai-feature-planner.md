# 관계형 AI 기능 계획 Agent

관계형 AI의 기능 요구사항을 GitHub Issue 단위로 분해하는 계획 수립 Agent 문서입니다.

## Agent 규칙

* 작업 하나는 최대 25분
* 하루 최대 작업 시간은 180분
* 토요일과 일요일에는 작업을 배치하지 않음
* 우선순위 P0, P1, P2 지정
* 구현 방법 작성
* 사용할 라이브러리 작성
* 확인 가능한 완료 기준 작성
* 실행 순서 작성
* 선행 작업 작성
* React → Express → Supabase → React 수직 슬라이스 우선
* 범위를 벗어난 기능은 Backlog로 이동
