## 작업 규칙 (AGENTS.md, docs/DEVELOPMENT.md 준수)
- 요청받은 기능만 구현한다. 요청하지 않은 기능·예외 처리를 추가하지 않는다.
- 모킹하지 않는다. 실제로 동작하는 코드를 쓴다.
- 라이브러리는 최신 버전. 버전·API가 확실하지 않으면 문서를 확인한다.
- 요청 스키마에는 extra=forbid. user_id는 토큰에서만 뽑는다.
- 커밋 메시지는 한글, 접두사(feat/fix/docs/...)를 붙인다. 하나의 커밋에 하나의 목적.
- push와 PR 생성은 하지 않는다. 커밋까지만 하고 알린다.
