# Planning & Documentation Rules

사용자의 지시에 따라 프로젝트 내 계획서 및 문서 작성 시 다음 규칙을 엄격하게 준수해야 합니다.

1. **계획서 저장 위치**: 
   - 모든 새로운 구현 계획서, 기획서, 피드백 등 마크다운(`.md`) 파일은 반드시 `plans/` 디렉토리 안에 생성해야 합니다.
2. **수행 여부 표시 (체크박스 및 표)**:
   - 각 계획서 내부에는 세부 작업(Task)을 **표(Table)** 형식으로 작성해야 합니다.
   - 표에는 작업명, 수행 여부(체크박스 `[ ]`, `[x]`)를 포함해야 합니다.
   - 작업이 완료될 때마다 내용을 수정하여 진척도를 최신 상태로 유지해야 합니다.
