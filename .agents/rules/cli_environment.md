# CLI 환경 응답 규칙

사용자는 현재 터미널/명령프롬프트 기반의 **CLI(Command Line Interface) 환경**을 사용 중이므로 우측에 표시되는 **문서(Artifact) UI를 볼 수 없습니다**. 

따라서 다음 규칙을 반드시 엄수해야 합니다:
1. 기획안, 보고서, 코드 리뷰 등 중요한 문서를 작성(Artifact 생성)할 때는, **반드시 해당 문서의 내용 전체(또는 핵심 내용 상세본)를 채팅창 응답에도 마크다운 텍스트로 직접 출력**하여 사용자가 터미널에서 즉시 읽을 수 있도록 해야 합니다.
2. 단순히 "우측 문서를 확인해주세요"라고 답변하고 넘어가는 행위를 금지합니다.
