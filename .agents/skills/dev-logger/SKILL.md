# Dev Logger (개발 일지 작성) 스킬

이 스킬은 사용자의 명시적 요청이 있을 때, 프로젝트의 구체적인 개발 계획과 완료 내역을 히스토리 문서로 남기기 위해 활성화됩니다.

## 📝 작동 원리 및 가이드라인

1. **타겟 파일 확인**
   - 워크스페이스 최상단에 있는 `dev_log.md` 파일을 수정 대상으로 삼습니다. 파일이 없다면 새로 생성합니다.

2. **날짜 포맷 작성**
   - 오늘 날짜를 `## YYYY-MM-DD` 형식의 헤딩으로 추가합니다. 
   - 이미 오늘 날짜의 헤딩이 존재한다면, 그 아래에 내용을 이어서(Append) 누적 기록합니다.

3. **기록할 내용 구성**
   - 사용자와 논의했던 세부 구현 계획, 방금 코딩을 마친 주요 기능, 버그 수정 내역 등을 알기 쉽게 요약합니다.
   - 각 항목은 `### [기능명] (상태: 계획중/완료/보류)` 형태로 적습니다.
   - 세부 내용에는 **목표**, **작업 내역**, **수정/생성된 파일명**을 포함시켜 나중에 어떤 파일이 왜 수정되었는지 추적하기 쉽게 만듭니다.

4. **완료 보고**
   - 도구를 사용해 파일에 쓰기를 마친 후, 사용자에게 "요청하신 내역을 dev_log.md 파일에 저장 완료했습니다"라고 간결하게 보고합니다.

## 🛠️ 사용해야 할 도구
- `write_to_file`: 파일이 없을 때 새로 생성.
- `replace_file_content` 또는 `multi_replace_file_content`: 기존 파일에 내용을 추가(Append)할 때 사용. (새 날짜 헤딩을 추가하거나 기존 날짜 헤딩 아래에 항목을 끼워 넣음)
