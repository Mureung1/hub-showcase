# 아침 브리핑 스킬 지침

이 스킬은 사용자가 아침 업무를 시작하며 브리핑을 요구할 때 활성화됩니다.

## 1. 분석 및 보고 작성 기준
에이전트는 브리핑 작성 전 반드시 다음 문서들을 확인해야 합니다:
1. `.agents/rules/project_instruction.md` (요일별 전체 일정표)
2. `walkthrough.md` 또는 어제 대화 기록 (어제 완료한 작업 내역)
3. `detailed_tasks.md` 및 `checklist.md` (오늘 구현해야 할 구체적인 스펙)

## 2. 보고 포맷 양식
다음과 같은 포맷으로 읽기 쉽고 활기차게 브리핑을 작성하여 **채팅창에 출력**합니다:

### ☀️ 굿모닝! [오늘 요일] 아침 브리핑입니다.

#### 🏆 1) 어제([어제 요일]) 완료한 작업 요약
* 어제 진행했던 핵심 작업(예: 스키마 구축, API 연동 등)을 3줄 이내로 요약합니다.
* 어제의 작업이 오늘 작업에 어떤 긍정적인 영향을 미치는지 덧붙여 격려합니다.

#### 🎯 2) 오늘([오늘 요일])의 목표와 세부 태스크
* `project_instruction.md`에 명시된 오늘의 공식 Task를 적습니다.
* 해당 Task를 달성하기 위해 오늘 구체적으로 구현해야 할 기능들(`checklist.md` 기준)을 체크리스트 형태로 나열합니다.

#### 💡 3) 오늘의 핵심 포인트 및 조언
* 오늘 작업에서 주의해야 할 점(예: 상태 관리, 폼 검증, CSS 레이아웃 등)이나 참고하면 좋을 팁을 짧게 조언합니다.

마지막에는 "자, 오늘 작업을 바로 시작할까요?" 라는 활기찬 멘트로 마무리합니다.
