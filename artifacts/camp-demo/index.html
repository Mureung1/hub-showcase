기술 부록 A1 · Runtime Harness

Agent 실행을 하나의 계약으로
시작하고, 관찰하고, 기록합니다

이 화면은 학생용 UI가 아니라 Server·kernel·SSE·history 경계를 반복 검증하는 개발자용 진단 표면입니다.

정상 실행started → output_delta → completed
경계 상태부분 출력 취소 · 재현 가능한 실패 · terminal 보존
진단 이력완료 뒤 history 기록 · 재시작 뒤 recovery
실행 경로Inspector → Express API → AgentRuntimeKernel → Adapter

Runtime Harness ≠ 제품 Chat UI·diagnostic history ≠ 확인된 학기 정보·Fake demo ≠ live provider
