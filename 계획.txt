1주차 — 앱 완성 (거의 끝난 상태): 데이터 소스를 네이버 블로그 검색 API(공식·무료, 앱 등록만 하면 됨)로 교체. "경쟁사 이름 + 후기"로 검색해 실제 텍스트를 받아 Gemini로 분석. 기획서의 Collect→Analyze→Synthesize→Report 워크플로우가 그대로 유지되고, "약관 위반인 크롤링 대신 공식 API를 선택했다"는 의사결정 자체가 면접 스토리가 됩니다.
2주차 — 컨테이너화: FastAPI, React(Nginx), MySQL을 각각 Dockerfile로 만들고 docker-compose.yml로 한 번에 띄우기. 환경변수/시크릿 분리(.env), DB 볼륨 관리 포함. 데브옵스 포트폴리오의 최소 요건입니다.
3주차 — CI/CD + 클라우드 배포: GitHub Actions로 푸시하면 자동 빌드→테스트→배포되는 파이프라인 구성. 배포처는 네이버 클라우드 플랫폼(NCP) 을 강력 추천합니다. 네이버 부트캠프라는 맥락과 정확히 맞고, NCP는 신규 가입 크레딧이 있어 학생 프로젝트 규모면 무료 범위에서 운영 가능합니다(정확한 크레딧 조건은 가입 시점에 확인 필요).
4주차 — 운영 요소 + 문서화: 기획서에 이미 있는 "DB 캐싱으로 API 비용 절감" 구현(같은 가게 재조회 시 LLM 호출 생략), 간단한 모니터링(헬스체크 엔드포인트 + Uptime 알림, 여유되면 Grafana), 아키텍처 다이어그램과 README 작성.
이렇게 하면 최종 산출물이 "AI 서비스를 만들고 → 컨테이너화하고 → CI/CD로 NCP에 배포해 실제 운영한" 프로젝트가 돼서, AI 부트캠프 과제 요건과 클라우드/데브옵스 취업 포트폴리오를 하나로 해결합니다. 주제를 새로 정하는 것보다 이미 돌아가는 걸 심화하는 쪽이 한 달 안에 "제대로 작동하는 것"을 만들 확률도 훨씬 높습니다.
