WEEK 1–2

어학시험 서비스의 흐름을 만들고, 실제 저장까지 연결했습니다

1주차

서비스 흐름 만들기

  • 어학시험 준비의 막막함을 문제로 정리
  • 사용자 이용 흐름 설계
  • 주요 화면 UI 프로토타입 제작

시험 선택부터 학습 계획까지의 전체 흐름을 화면으로 만들었습니다.

2주차

실제 데이터 연결하기

  • Express 서버와 Supabase 연결
  • 입력한 정보를 DB에 저장
  • 저장한 정보를 다시 조회해 화면에 표시
  • 검증 Agent로 기능 점검

화면에서 입력한 값이 실제로 저장되고 다시 표시되도록 연결했습니다.

1주차에는 어학시험 학습 서비스의 흐름을 만들고,
2주차에는 그 흐름이 실제로 작동하도록 연결했습니다.
