📋 정본 사용 규칙

  • 클래스명 재사용: 4개 페이지가 여기서 정한 Tailwind 클래스 조합을 그대로 복사해서 사용

  • Topbar & Sidebar: DOM 구조와 클래스명을 4페이지에서 100% 동일하게 유지해야 React 전환 시 컴포넌트 추출이 용이함
