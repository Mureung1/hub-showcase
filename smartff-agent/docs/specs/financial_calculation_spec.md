## 핵심 계산식

### 1. 매출액
```
매출액 = SUM(판매금액)
출처: sales 파일의 조회기간 판매액
자료형: INT (단위: 원)
```

### 2. 평균원가율 (카테고리별)
```
평균원가 = waste 파일의 폐기된 상품들 평균 원가
평균판매가 = 카테고리 전체 판매액 ÷ 판매수량
평균원가율 = 평균원가 ÷ 평균판매가
```

### 3. 추정 매출원가
```
추정 매출원가 = 판매액 × 평균원가율
참고: 카테고리 평균 원가율 기반 추정치
```

### 4. 마진액 (추정)
```
마진액 = 판매액 - 추정 매출원가
표기: "추정 마진액"
단위: 원
```

### 5. 마진율 (추정)
```
마진율 = 마진액 ÷ 판매액 × 100%
표기: "추정 마진율"
단위: %
```

### 6. 폐기손실
```
폐기손실 = SUM(폐기금액)
출처: waste 파일
단위: 원
```

### 7. 폐기율
```
폐기율 = 폐기손실 ÷ 판매액 × 100%
단위: %
```

### 8. 순이익 (추정)
```
순이익 = 마진액 - 폐기손실
표기: "추정 순이익"
주의: 운영비 미포함, 세금 미포함
단위: 원
```

### 9. 순이익율 (추정)
```
순이익율 = 순이익 ÷ 판매액 × 100%
단위: %
```

| `waste_*.xlsx` | 상품코드, 상품명, **원가**, 폐기수량, 폐기금액 | 원가율 산출, 폐기손실 계산 | ✅ 신뢰도 높음 |
| `inventory_*.xlsx` | 상품코드, 정가, 재고 | 참고용 (가격 검증) | ⚠️ 사용 제외 |

### 주요 발견

#### 1. SALES vs WASTE 상품 일치율
```
1월~6월 평균: 50.1% (상품명 기준)
- 공통 상품: 475개 (50.1%)
- SALES에만: 473개 (49.9%) ← 폐기 기록 없음
- WASTE에만: 75개 ← 판매 기록 없음

카테고리별:
- 주먹밥: 64.2% (가장 안정적)
- 햄버거샌드위치: 49.0%
- 김밥: 44.8%
- 도시락: 36.6% (가장 낮음)

⚠️ 결론: 개별 상품 매칭 불가능 → 카테고리 평균 원가율 방식 필수
```

#### 2. WASTE vs INVENTORY 상품코드 매칭 (정수 기준)
```
1월~6월 평균: 67.3%
- 1월~4월: 낮음 (13~97%)
- 5월~6월: 높음 (100%)

⚠️ 결론: Inventory 파일에 원가 정보 없음 → WASTE 파일만 사용
```

#### 3. SALES vs INVENTORY 판매가 비교 (VAT 검증)
```
SALES × 1.10 vs INVENTORY 정가

1월 데이터:
- 김밥: 60% 일치 (평균차이 82원)
- 도시락: 79% 일치 (평균차이 26원)
- 주먹밥: 100% 일치 (평균차이 6원)
- 햄버거샌드위치: 83% 일치 (평균차이 31원)

결론:
- SALES 가격: 세전 가격 (Tax-Excluded)
- INVENTORY 정가: 세후 가격 (세전 × 1.10)
- 가격 차이: VAT(10%) + 할인/프로모션
```

## 계산 로직 (최종 구현 방식)

### 1단계: 폐기 이력 기반 원가율 산출

```
폐기 기록이 있는 상품들에서:
  - 각 상품의 원가(unit_cost) 수집
  - 평균원가 = SUM(원가) ÷ 상품 수
  
카테고리 전체 데이터에서:
  - 평균판매가 = 총판매액 ÷ 총판매수량
  
카테고리 평균원가율:
  - 원가율 = 평균원가 ÷ 평균판매가
```

### 2단계: 재무 지표 계산

```
FOR 각 카테고리:
  추정 매출원가 = 판매액 × 원가율
  마진액 = 판매액 - 추정 매출원가
  마진율 = 마진액 ÷ 판매액 × 100%
  
  폐기손실 = SUM(폐기금액)
  폐기율 = 폐기손실 ÷ 판매액 × 100%
  
  순이익 = 마진액 - 폐기손실
  순이익율 = 순이익 ÷ 판매액 × 100%
```

### 3단계: 데이터 집계

```
- 월별 카테고리별 계산
- 월별 전체 합계
- 6개월 평균
```

## 가정 및 한계

### 가정

1. **폐기 이력 = 대표성**
   - "폐기된 상품들의 원가가 그 카테고리 전체를 대표한다"
   - 폐기 이력이 없는 상품도 동일 원가율 적용

2. **원가 변동 없음**
   - WASTE 파일의 원가 = 해당 월의 모든 상품에 적용
   - 실제로는 시간에 따라 원가가 변할 수 있음

3. **세금/할인 미포함**
   - 순이익은 부가세, 인건비, 로열티 미포함
   - 실제 수익과는 다를 수 있음

### 한계

| 한계 | 설명 | 영향 |
|------|------|------|
| 표본 편향 | 폐기 기록 상품이 적으면 원가율 왜곡 | 도시락(37%) 위험 |
| 계절성 | 6월 폐기율 급증으로 신뢰도 감소 | 실시간 모니터링 필요 |
| 가격 변동성 | SALES에 할인/프로모션 포함 | 정확한 원가율 계산 어려움 |
| 데이터 완성도 | 일부 월/카테고리 파일 누락 가능 | 검증 필수 |

### 개선 방안

- **우선순위 1**: 상품별 원가 마스터 데이터 확보
- **우선순위 2**: 6월 폐기 급증 원인 분석
- **우선순위 3**: 일일/주별 정밀도 증가 (현재는 월별)

## Financial 페이지 표기

### 표기 규칙

```
마진액 (추정)
- 산출 방식: 판매액 × 평균원가율
- 신뢰도: 중간 (카테고리 평균 기반)
- 비고: 개별 상품 원가 미지정

순이익 (추정)
- 산출 방식: 마진액 - 폐기손실
- 신뢰도: 중간 (추정 마진액 포함)
- 비고: 운영비, 세금 미포함
```
