### 각 항목별 구현 가능 여부 및 데이터 상태

#### 1. 기간 필터링 ✅ 즉시 가능
```
필요 데이터: ✅ 1월~6월 월별 데이터 (완전)
구현 방식:
  - Dropdown: "2026년 7월" 선택
  - Range: "2026-01-01 ~ 2026-06-30"
  - 또는 Tab: 1월 | 2월 | 3월 | 4월 | 5월 | 6월
```

#### 2. 월간 비교 ✅ 즉시 가능
```
필요 데이터: ✅ 1월~6월 각 월별 지표
구현 방식:
  - 좌측: 현재월 마진율, 우측: 전월 마진율 (Side-by-side)
  - 또는 라인차트: 6개월 추이 (마진율, 폐기율, 순이익율)
  - Change Badge: "↑ +2.3%" / "↓ -1.2%"
```

#### 3. 카테고리 드릴다운 ✅ 즉시 가능
```
필요 데이터: ✅ 상품명, 판매액, 폐기액 (완전)
구현 방식:
  - Financial 페이지에 "카테고리별 상세" 탭 추가
  - 선택된 카테고리의 상품 리스트 (판매수량, 판매액, 마진액, 폐기손실)
  - 상품별 마진율, 폐기율 계산
```

#### 4. 주별 분석 ⚠️ 6월만 가능
```
필요 데이터: ✅ weekly_waste, weekday_sales (6월만)
           ❌ 1월~5월 주별 데이터 없음
구현 방식:
  - 6월 데이터만 "주별 탭" 활성화
  - 1월~5월은 "월별 데이터만 가용" 안내 표시
  - 향후: 7월부터 모든 월이 주별 데이터 보유
```

#### 5. Rule Engine 확장 ✅ 즉시 가능
```
필요 데이터: ✅ 현재 계산 지표 모두 활용 가능
V1 규칙 (현재):
  - IF 판매↑ AND 폐기율<5% → 발주확대 검토
  - IF 판매↓ AND 폐기율↑ → 발주축소 검토
  - IF 마진율 낮음 → 수익성 검토

추가 가능 규칙:
  - IF 카테고리별 순이익 기여도 높음 → 확대 추천
  - IF 폐기율 > 평균 + 2σ → 재고관리 검토
  - IF 마진율 변화 급락 → 가격 검토
  - IF 발주량 증가했는데 폐기 감소 → 발주 전략 성공
  - IF 특정 상품 폐기율만 높음 → 상품별 수요 조사
```

#### 6. 발주 데이터 통합 ✅ 데이터 있음
```
필요 데이터: ✅ orders_*.xlsx (6월, 날짜별)
           ⚠️ 1월~5월 발주 데이터는 아직 미분석
구현 방식:
  - 발주량(units) × 발주가 = 발주금액
  - 발주금액 vs 매출액 비교 (발주 과다/과소 판단)
  - 발주량 vs 폐기량 상관관계 (높은 상관 = 발주전략 미흡)
  - 발주 변화율 vs 판매 변화율 (반응성 분석)
```

## 데이터 가용성 정리

### ✅ 지금 바로 가능 (P0/P1에 포함)

```
✅ 월별 분석 (1월~6월)
   - 판매액, 마진액, 폐기손실, 순이익
   - 카테고리별 지표
   - 기간 필터링, 월간 비교

✅ 상품별 분석 
   - 상품명, 판매수량, 판매액
   - 폐기수량, 폐기금액
   - 상품별 마진율, 폐기율

✅ Rule Engine 규칙
   - 판매 추세 기반 발주 제안
   - 폐기율 기반 재고 조정
   - 마진율 기반 가격 검토
```

### ⚠️ 부분적으로 가능 (6월만)

```
⚠️ 주별 분석 (6월 데이터만)
   - weekly_waste, weekday_sales 보유
   - 1월~5월: 월별만 가능
   - 7월부터: 모든 월이 주별 데이터 보유

⚠️ 시간대별 분석 (6월 데이터만)
   - hourly_sales 보유
   - 1월~5월: 데이터 없음
```

### ❌ 불가능 (데이터 부재)

```
❌ 일별 분석
   - 일별 raw 데이터 없음

❌ 전년대비 (YoY)
   - 2025년 데이터가 없음
   - 2026년 6개월만 보유
```
