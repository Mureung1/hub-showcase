## 페이지 개요

### 목적
**"왜 이런 일이 일어났는가?"** 질문에 답변

### 핵심 기능
- 카테고리별 판매 패턴 분석
- 요일별/시간대별 판매 분석
- 판매 추세 & 폐기 추세 비교
- 카테고리별 AI 인사이트 제공

---

## 최종 검증된 디자인 요소

### ✅ 반영 완료 항목

1. **AI 인사이트 가독성**
   - 텍스트 길이: 2줄 이내 (최적화됨)
   - 카테고리별 맞춤형 인사이트 제공

2. **폐기 추세 경고 강화**
   - 정상 상태: 초록색 라인, 초록 그라디언트 배경
   - 경고 상태(폐기 증가): 빨강색 라인, 연한 빨강 배경 틴트 (#FEF2F2)
   - Dashboard 위험 신호 카드와 동일한 시각 언어

3. **바 차트 최고값 강조**
   - 최고값: 진한 파랑 (#2563EB)
   - 2위: 연한 파랑 (#93C5FD)
   - 기타: 라이트 그레이 (#EFF2F7)

4. **라인 차트 설계**
   - 그라디언트 언더레이 포함
   - 포인트 마커로 인터랙션 준비
   - 추세 텍스트 색상 (긍정: 초록, 경고: 빨강)

### ✅ 숫자 라벨 정책
- **제외**: "150천원" 같은 수치 라벨 불필요
- **이유**: 편의점 FF 매출 100,000 미만이므로 바의 상대적 높이로 충분
- **현재 상태**: 최고값만 텍스트로 표시 (예: "최고 판매 요일 · 토요일")

## 카테고리별 데이터 정의

### 도시락 (정상 상태)
- 판매 추세: +18% (파랑)
- 폐기 추세: 안정적 (초록)
- 최고 판매 요일: 토요일
- 최고 판매 시간: 12시 (점심)

### 삼각김밥 (경고 상태)
- 판매 추세: -12% (빨강)
- 폐기 추세: 2주 연속 증가 (빨강)
- 최고 판매 요일: 월요일
- 최고 판매 시간: 09시 (아침)
- **시각화**: 차트 배경 연한 빨강 틴트, 라인 빨강색

### 김밥 (안정 상태)
- 판매 추세: +5% (파랑)
- 폐기 추세: 안정적 (초록)

### 샌드위치 (보통 상태)
- 판매 추세: +2% (파랑)
- 폐기 추세: 보통 (회색)

## Design System 준수

✅ **아이콘 레일 사이드바**: Dashboard와 동일  
✅ **헤더 레이아웃**: Dashboard와 동일  
✅ **배지 시스템**: 3-variant pill (AI 정서이트, 위험 신호, AI 추천)  
✅ **컬러 팔레트**: 
- Primary: #2563EB / #1D4ED8 / #EFF6FF
- Danger: #DC2626 / #FEF2F2 / #FECACA
- Success: #15803D

✅ **타이포그래피**: Manrope, 기존 규칙 동일  
✅ **차트 규칙**: 흰 배경, 얇은 그리드선, 3D 금지
