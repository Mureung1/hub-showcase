# FitCheck Trainer Web

트레이너용 웹 서비스입니다. Vite + React + TypeScript로 구성되어 있습니다.

## 스크립트

| 명령어 | 설명 |
|--------|------|
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` | oxlint 실행 |

## 개발 서버

```bash
npm install
npm run dev
```

http://localhost:5173 에서 확인할 수 있습니다.
