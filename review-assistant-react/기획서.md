# 🍊 리뷰 답변 도우미 — 기획서

## 0. 프로젝트 개요
| 항목 | 내용 |
|---|---|
| 서비스명 | 리뷰 답변 도우미 |
| 대상 사용자 | 매일 손님 리뷰에 답변을 다는 소상공인(카페, 식당 등) |
| 문제 정의 | 리뷰마다 톤을 고민하고 직접 답변을 쓰는 데 시간이 많이 든다. 반복되는 불만(대기시간, 친절도 등)을 놓치기 쉽다. |
| 핵심 가치 | 리뷰를 붙여넣기만 하면 (1) 감정/키워드 분석, (2) 답변 초안 3종, (3) 반복 문제 감지·개선 제안까지 한 번에 제공 |
| 현재 구현 범위 | 외부 API 없이 브라우저 내 키워드 규칙 기반 분석 (React + Vite) |

---

## 0-1. 프로토타입

- 순수 HTML/CSS/JS로 제작한 핵심 기능 프로토타입: [index.html](../index.html)
- 외부 API 없이 브라우저 내 키워드 규칙으로 감정 분석·답변 생성이 동작하며, 아래 "핵심 기능" 목록과 1:1로 대응합니다.
- 동료 피드백 반영 이력은 이 섹션에 계속 업데이트합니다. (현재: 초안, 피드백 대기 중)

## 1. 사용자 관점 동작 시나리오

### 1-1. 메인 플로우
| 단계 | 사용자 행동 | 화면 반응 |
|---|---|---|
| 1 | 랜딩 페이지 진입 | Hero 섹션에서 서비스 한 줄 소개 확인 ("손님 리뷰, 이제 고민하지 말고 답변하세요") |
| 2 | "지금 시작하기" 또는 "사용법" 클릭 | 해당 섹션으로 스크롤 이동 |
| 3 | 리뷰 텍스트를 줄바꿈으로 구분해 붙여넣기 | textarea에 입력, placeholder 예시로 입력 형식 안내 |
| 4 | "분석 시작" 버튼 클릭 | 버튼 비활성화 + "분석 중..." 표시, 상태 메시지 노출 |
| 5 | 분석 완료 (약 0.5초) | 리뷰별 카드가 리스트로 렌더링 |
| 6 | 결과 카드 확인 | 감정 태그(긍정/부정/중립 색상), 키워드 태그, (부정일 경우) 개선 제안, 답변 초안 3종(정중함/친근함/간결함) 표시 |
| 7 | 마음에 드는 답변의 "복사하기" 클릭 | 클립보드 복사 + 버튼이 "복사됨 ✓"로 1.5초간 변경 |
| 8 | (반복 시) 같은 키워드의 부정 리뷰가 누적 2건 이상 | 상단에 "⚠️ 반복되는 문제 감지" 패널 자동 노출, 키워드별 개선 제안 표시 |
| 9 | 필요 시 "누적 기록 초기화" 클릭 | 누적 히스토리·반복 문제 패널 초기화 (현재 결과는 유지) |

### 1-2. 예외 시나리오
| 상황 | 처리 |
|---|---|
| 입력 없이 "분석 시작" 클릭 | "리뷰를 먼저 입력해주세요." 에러 메시지 |
| 공백/줄바꿈만 입력 | "유효한 리뷰가 없어요." 에러 메시지 |
| 리뷰 15개 초과 입력 | "한 번에 최대 15개까지 분석할 수 있어요." 에러 메시지, 분석 미실행 |
| 클립보드 복사 실패 (권한 등) | "복사에 실패했어요. 직접 선택해서 복사해주세요." 에러 메시지 |

```
┌─────────────────────────────────────────┐

├─────────────────────────────────────────┤

│   손님 리뷰, 이제 고민하지 말고 답변하세요        │
│   (부제) 감정분석·반복문제감지·개선제안 한 번에    │

│   ① 리뷰 붙여넣기 → ② 분석 시작 → ③ 답변 복사   │

│  ┌───────────────────────────────────┐  │

│      - 리셋 버튼                          │
│      - 키워드별: 발생건수 + 개선제안           │
```

### 2-2. 상태별 화면 분기
| 상태 | 노출 요소 |
|---|---|
| 초기 (results === null) | 입력 카드만 표시 |
| 로딩 중 | 입력 카드 + 상태 메시지("분석 중이에요...") |
| 에러 | 입력 카드 + 에러 박스 |
| 결과 있음 (0건) | "분석 결과가 없어요." 빈 상태 문구 |
| 결과 있음 (1건 이상) | 리뷰 카드 리스트 |
| 반복 문제 감지됨 | 결과 리스트 위에 경고 패널 추가 노출 |

### 2-3. 감정별 색상 규칙
| 감정 | 색상 |
|---|---|
| 긍정 | 초록 |
| 부정 | 빨강 |
| 중립 | 회색 |

## 3. 핵심 기능 (우선순위 순)

### ① 리뷰 일괄 입력 & 파싱 — [핵심]
- 여러 리뷰를 줄바꿈으로 구분해 한 번에 입력
- 빈 줄 제거, 최대 15개 제한
- 입력값 검증 실패 시 명확한 에러 메시지

### ② 감정 분석 (긍정/부정/중립) — [핵심]
- 키워드 매칭 기반 규칙 엔진 (POSITIVE_WORDS / NEGATIVE_WORDS)
- "불친절"처럼 부정 접두사(불/안/못)가 붙은 경우 긍정 오탐 방지 처리
- 매칭 점수 비교로 최종 감정 판정

### ③ 핵심 키워드 추출 — [핵심]
- 맛/친절도/대기시간/가격/청결도/분위기 6개 카테고리
- 리뷰당 최대 3개 키워드, 매칭 없으면 "일반"

### ④ 답변 초안 3종 생성 — [핵심]
- 감정×키워드 조합으로 정중함/친근함/간결함 3가지 톤 생성
- 리뷰별로 즉시 확인·비교 가능

### ⑤ 답변 클립보드 복사 — [핵심]
- 버튼 클릭 시 즉시 복사, 1.5초간 "복사됨 ✓" 피드백
- 실패 시 에러 안내

### ⑥ 반복 문제 감지 & 개선 제안 — [핵심]
- 세션 누적 히스토리 기준, 동일 키워드의 부정 리뷰가 2건 이상이면 자동 노출
- 키워드별 구체적 개선 제안 문구 제공 (예: 대기시간 → "피크타임 인력 배치 조정")
- "누적 기록 초기화"로 리셋 가능

### ⑦ 에러/예외 처리 — [핵심]
- 빈 입력, 15개 초과, 클립보드 실패 3가지 케이스 커버

> 서브 기능(파일 업로드, 통계 대시보드, 톤 커스터마이징, 실제 AI API 연동 등)은 위 핵심 기능이 안정된 뒤 논의할 "향후 개선 아이디어"로 별도 관리합니다.
