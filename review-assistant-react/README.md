# 🍊 리뷰 답변 도우미 (React)

소상공인이 손님 리뷰를 붙여넣으면, AI가 감정을 분석하고 답변 초안 여러 개를 추천해주는 웹 도구의 React + Vite 버전입니다.

## 프로젝트 배경
소상공인은 매일 여러 건의 리뷰에 답변을 달아야 하지만, 매번 톤을 고민하고 직접 작성하는 데 시간이 많이 듭니다. 이 도구는 리뷰를 붙여넣기만 하면 감정 분류, 키워드 추출, 답변 초안 3종을 한 번에 받아볼 수 있도록 만들었습니다.

## 주요 기능
- 리뷰 텍스트 여러 개를 줄바꿈으로 구분해 한 번에 입력
- 리뷰별 감정 분석 (긍정 / 부정 / 중립)
- 리뷰별 핵심 키워드 추출 (예: 맛, 친절도, 대기시간 등)
- 답변 초안 3종 생성 (정중함 / 친근함 / 간결함)
- 답변 클립보드 복사 기능
- 감정별 색상 태그 UI (긍정=초록, 부정=빨강, 중립=회색)
- 빈 입력, API 오류 등에 대한 에러 처리

## 파일 구성
```
review-assistant-react/
├── public/
│   └── favicon.svg
├── src/
│   ├── App.jsx      # 리뷰 분석 UI + 로직 (React 컴포넌트)
│   ├── App.css      # 스타일
│   ├── main.jsx     # React 진입점
│   └── index.css    # 전역 리셋
├── index.html        # Vite 진입 HTML
├── package.json       # React/Vite 의존성 정의
├── vite.config.js
├── .gitignore
└── README.md
```

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 안내된 주소(기본 http://localhost:5173)로 접속하면 UI를 확인할 수 있습니다.

> ℹ️ **참고**: 이 버전은 외부 API 호출 없이 브라우저 안에서 키워드 기반 규칙으로 감정 분석과 답변 초안을 생성합니다. API 키나 서버 없이 바로 동작하지만, 실제 AI 분석만큼 정교하지는 않습니다.

## 향후 개선 아이디어
- 백엔드를 추가해 Claude API 키를 안전하게 관리하고 실제 AI 분석으로 교체
- 리뷰 파일 업로드(CSV) 지원
- 답변 톤 커스터마이징 (가게별 말투 가이드라인 입력)
- 기간별 감정 추이 통계 대시보드
