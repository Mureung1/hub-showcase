# 🍊 리뷰 매니저 AI (React)

소상공인이 손님 리뷰를 붙여넣으면 감정 분석·키워드 추출·반복 문제 감지·답변 초안 3종을 제공하고, 리뷰마다 AI 점수를 매겨 총 분석·월별 통계까지 보여주는 웹 도구의 프론트엔드(React + Vite)입니다. (구 "리뷰 답변 도우미")

## 프로젝트 배경
소상공인은 매일 여러 건의 리뷰에 답변을 달아야 하지만, 매번 톤을 고민하고 직접 작성하는 데 시간이 많이 듭니다. 반복되는 불만을 놓치기 쉽고, 어떤 리뷰부터 먼저 챙겨야 할지 판단하기도 어렵습니다. 이 도구는 리뷰를 붙여넣기만 하면 감정 분류·키워드 추출·AI 관심도 점수·답변 초안 3종을 한 번에 받아보고, 쌓인 리뷰를 총 분석·월별 통계로 확인할 수 있도록 만들었습니다.

## 주요 기능
- 리뷰 텍스트 여러 개를 줄바꿈으로 구분해 한 번에 입력 (최대 15개)
- 리뷰별 감정 분석 (긍정 / 부정 / 중립)
- 리뷰별 핵심 키워드 추출 (맛 / 친절도 / 대기시간 / 가격 / 청결도 / 분위기)
- 리뷰마다 AI 관심도 점수(0~100) — 어떤 리뷰부터 챙겨야 할지 판단하는 기준
- 답변 초안 3종 생성 (정중함 / 친근함 / 간결함) + 클립보드 복사
- 세션 누적 기준 반복 문제 감지 (같은 키워드의 부정 리뷰 2건 이상 시 배너 노출)
- 리뷰 총 분석 · 월별 통계 대시보드
- 감정별 색상 태그 UI (긍정=초록, 부정=빨강, 중립=회색)
- 빈 입력, 개수 초과, API 오류 등에 대한 에러 처리

## 화면 구성 (React Router)
| 경로 | 화면 |
|---|---|
| `/` | 랜딩 — 서비스 소개, 반복 문제 감지 데모, 차별점 |
| `/app` | 도구 — 리뷰 입력·분석·답변 복사 (핵심 화면) |
| `/guide` | 사용법 — 예시 결과, FAQ |
| `/dashboard` | 총 분석 — 누적 리뷰 총계, 감정 분포, 월별 통계 |

## 파일 구성
```
review-assistant-react/
├── public/
│   └── favicon.svg
├── design/                 # 디자인 핸드오프 원본 (design-build 스킬 참고)
├── src/
│   ├── pages/               # 화면 단위 컴포넌트 (LandingPage, ToolPage, GuidePage, DashboardPage)
│   ├── components/          # 여러 화면에서 공유하는 컴포넌트 (ExampleResultCard 등)
│   ├── hooks/                # 커스텀 훅 (useInView, useCountUp)
│   ├── lib/                  # sessionId 관리, 백엔드 API 클라이언트
│   ├── App.jsx               # 라우터 설정
│   ├── App.css               # 스타일
│   ├── design-tokens.css     # 디자인 시스템 토큰 (색상/radius/shadow)
│   ├── main.jsx               # React 진입점
│   └── index.css              # 전역 리셋
├── index.html                 # Vite 진입 HTML
├── package.json                # React/Vite 의존성 정의
├── vite.config.js
├── .gitignore
└── README.md
```

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 안내된 주소(기본 http://localhost:5173)로 접속하면 UI를 확인할 수 있습니다.

> ℹ️ **참고**: 분석 로직은 백엔드(`review-assistant-server`, 기본 http://localhost:4000)를 호출합니다. 프론트엔드만 켜져 있으면 분석 요청이 실패하니, 함께 `review-assistant-server`도 실행해야 합니다. 백엔드는 현재 규칙 기반으로 분석하며(외부 AI API 미연동), 실제 AI 분석 교체는 3주차 예정입니다.

## 향후 개선 아이디어
- 백엔드 분석 로직을 Claude API 기반 실제 AI 분석으로 교체 (AI 관심도 점수 산정 고도화 포함)
- 리뷰 파일 업로드(CSV) 지원
- 답변 톤 커스터마이징 (가게별 말투 가이드라인 입력)
