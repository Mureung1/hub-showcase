# AI 논문 브리핑 서비스 — MVP 기획 문서

> `ai-briefing-service`의 첫 MVP 기획서. 전체 기획서([plan.md](./plan.md))와 사용자 시나리오([user-scenarios.md](./user-scenarios.md)) 중 **S1(아침 데일리 브리핑) 하나에 집중**해, 1~2주 내 동작하는 최소 제품을 정의한다.

---

## 1. 문제 정의 · 문제 상황

### 문제 상황
최신 AI(특히 LLM) 분야는 arXiv 논문·뉴스의 **생산 속도와 양이 개인이 따라잡을 수 있는 한계를 넘어섰다.** 매일 수십 편의 논문이 쏟아지지만, 대부분 영문 원문이라 훑는 데 시간이 오래 걸린다.

그 결과 연구자·개발자는 두 가지 고통을 겪는다.
- **① 놓침** — 중요한 논문·발표를 그냥 지나친다.
- **② 시간 비용** — "무엇이 중요한지 선별하고 파악하는 것" 자체에 매일 큰 시간이 든다.

### 문제 정의
> **흩어지고 쏟아지는 최신 AI 논문을, 매일 짧은 시간에 놓치지 않고 파악할 방법이 없다.**

### 해결 방향
최신 AI(LLM) 논문을 **자동 수집 → LLM 한국어 요약 → 매일 브리핑**으로 정리해, 사용자가 웹에서 **5분 안에** 오늘의 핵심 동향을 훑게 한다.

- **주 사용자**: AI 연구자·개발자 (전문 용어 유지, 깊이 있는 요약 + 배경 설명)
- **핵심 가치**: 놓치지 않기(Curation) + 짧은 시간에 파악(시간 절약)

## 2. 사용자 시나리오 (S1) · 사용자 흐름

### S1. 아침 데일리 브리핑 — "밤새 뭐 나왔지?"
- **페르소나**: 한지우 — LLM 응용을 다루는 연구자 겸 개발자.
- **트리거**: 매일 아침 업무 시작, 커피 한 잔 하며 5분.
- **목표(JTBD)**: 밤새 나온 논문 중 중요한 것을 짧은 시간에 놓치지 않고 훑기.
- **핵심 가치**: 놓치지 않기.

### 사용자 흐름 — 아침 데일리 브리핑 (MVP)

```
1. 사용자: 아침에 서비스 접속 (☕ 업무 시작 전)
   ↓
2. 시스템: '오늘의 브리핑' 피드 자동 로드
   - 날짜 헤더 표시 (2026-07-07)
   - "오늘 32편 수집" 카운트 표시
   - 카테고리 탭 노출 (전체 / 추론 / 에이전트 / 멀티모달 …)
   ↓
3. 시스템: 논문 카드 목록을 '중요도순'으로 정렬해 표시
   각 카드에 다음 요소를 담아 렌더링
   ┌─────────────────────────────────────────┐
   │ [🔥 중요]  #추론  #test-time            │
   │ Scaling Test-Time Compute…              │
   │ (테스트 타임 연산을 늘려 추론 성능…)      │
   │ 한줄 요약: 추론 단계 연산량을 키워…       │
   │                                  [🔖 저장]│
   └─────────────────────────────────────────┘
   ↓
4. 사용자: 카드 목록 훑어보기 (스캔)
   (제목·한줄 요약·주제 태그·중요도 배지를 빠르게 스캔)
   ↓
5. 판단: 관심 가는 논문이 있는가?
   ├─ 아니오 → 사용자: 카테고리 탭 전환 / 스크롤로 계속 탐색
   │            ↺ 4번(스캔)으로 돌아감
   └─ 예 ↓
   ↓
6. 사용자: 관심 카드 클릭
   ↓
7. 시스템: 한국어 요약 패널 표시
   - 구조화 요약 (핵심 기여 / 방법 / 결과)
   - 배경(맥락) 설명
   - 원문 초록 병기 (토글) — 검증용
   - arXiv 원문 링크
   ↓
8. 판단: 나중에 다시 볼 논문인가?
   ├─ 예 → 사용자: "🔖 저장(북마크)" 클릭
   │        시스템: 저장 목록에 추가
   └─ 아니오 ↓
   ↓
9. 판단: 더 볼 논문이 있는가?
   ├─ 예 → ↺ 4번(피드 스캔)으로 돌아가 다음 논문 확인
   └─ 아니오 ↓
   ↓
10. 완료! 🎉 5분 내 오늘의 AI 동향 파악 끝
```

## 3. 핵심 기능

MVP는 위 S1 흐름을 완주시키는 데 필요한 **최소 화면·기능**만 담는다.

| # | 기능 | 설명 | 흐름 단계 |
|---|------|------|-----------|
| F1 | **오늘의 브리핑 피드** | 날짜 헤더 · "오늘 N편 수집" · 카테고리 탭 · 논문 카드 목록(중요도순 정렬) | 2·3 |
| F2 | **논문 카드 요약** | 카드에 제목(영·한 병기) · 한줄 요약 · 주제 태그 · 중요도 배지 표시 | 3·4 |
| F3 | **한국어 요약 열람** | 카드 클릭 시 구조화 요약(기여/방법/결과) + 배경 설명 + 원문 초록 병기(토글) + arXiv 원문 링크 | 6·7 |
| F4 | **북마크 저장** | 관심 논문을 저장 목록에 추가 | 8 |

### 뒤에서 이를 뒷받침하는 파이프라인 (자동화)
- **수집**: 매일 GitHub Actions cron이 arXiv API(`cs.CL`/`cs.AI`/`cs.LG`)에서 최신 논문 fetch, LLM 키워드로 LLM 관련 논문 선별.
- **요약**: Gemini Flash(무료 티어)로 한국어 구조화 요약 생성, 원문 초록 병기.
- **저장·서빙**: 결과를 JSON/정적 파일로 생성해 저장소에 커밋 → GitHub Pages가 정적 서빙. **서버 0대, 비용 0원.**

### MVP 범위 밖 (향후 확장)
검색·필터, 카테고리 자동 분류(주제 태그 고도화), 트렌드 대시보드, 관련 논문 추천, 메모·공유, 주간 요약, 로그인·개인화, 디자인 고도화 — 모두 후속 단계로 미룬다. (전체 목록은 [plan.md](./plan.md) 참고)

## 4. 화면 설계 (와이어프레임)

S1 흐름을 완주시키는 최소 화면 3종. 아래 스케치로 레이아웃을 개괄하고, 실물(인터랙티브·라이트/다크·모바일 대응)은 **[s1-wireframe.html](./wireframes/s1-wireframe.html)** 에서 확인한다.

### ① 오늘의 브리핑 피드 · F1·F2
```
┌──────────────────────────────────────────┐
│ 2026·07·07 오늘의 브리핑            32편  │
│ [전체] 추론  에이전트  멀티모달  효율화    │  ← 카테고리 탭 (F1)
├──────────────────────────────────────────┤
│ ┌────────────────────────────────────┐   │
│ │ 🔥중요  #추론 #test-time       🔖 │   │  ← 카드 (F2)
│ │ Scaling Test-Time Compute…         │   │     제목(영·한)
│ │ (테스트 타임 연산을 늘려…)          │   │     한줄 요약
│ └────────────────────────────────────┘   │
│ ┌────────────────────────────────────┐   │
│ │ 🔥중요  #에이전트              🔖 │   │
│ │ Multi-Agent Planning with Tool Use │   │
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

### ② 논문 상세 · 요약 열람 · F3·F4
```
┌──────────────────────────────────────────┐
│ ← 오늘의 브리핑                            │
│ Scaling Test-Time Compute for Reasoning   │
│ 저자 외 4인 · 2026-07-06 · #추론          │
├──────────────────────────────────────────┤
│ ▚ 핵심 기여  ▬▬▬▬▬▬▬▬▬                    │  ← 구조화 요약 (F3)
│ ▚ 방법       ▬▬▬▬▬▬                       │
│ ▚ 결과       ▬▬▬▬▬                        │
│ ▚ 배경·맥락  ▬▬▬▬▬▬▬                      │
│ ▸ 원문 초록(English) 펼치기                │  ← 검증용 토글
│ [ ↗ arXiv 원문 ]        [ 🔖 저장 ]        │  ← 원문 링크 / 저장 (F4)
└──────────────────────────────────────────┘
```

### ③ 저장 목록 · F4
```
┌──────────────────────────────────────────┐
│ 🔖 저장한 논문                       3편  │
│ · Scaling Test-Time Compute…    #추론  🔖 │
│ · Multi-Agent Planning…       #에이전트 🔖 │
│ · (효율화 논문)                 #효율화 🔖 │
└──────────────────────────────────────────┘
```
