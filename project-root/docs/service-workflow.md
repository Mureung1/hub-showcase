# Campus Scheduler — 서비스 워크플로우

시간표를 추천받아 확정하고, 다른 학생과 공유하기까지의 전체 흐름입니다.

## 진입 경로

| 대상 | 시작 화면 | 설명 |
|---|---|---|
| 신입생 | 선배 시간표부터 둘러보기 | 전공필수/전공선택/교양이 어떻게 배치돼 있는지 참고용으로 확인 |
| 재학생 | 바로 내 조건으로 추천받기 | 학년·학과·공강요일 등 조건을 입력해 추천 시간표부터 확인 |

두 경로 모두 아래 흐름으로 이어집니다.

## 전체 흐름

1. **로그인 / 회원가입** — `Supabase Auth`
   이메일·비밀번호로 계정을 인증합니다.

2. **조건 입력** — `PreferenceScreen`
   학년·학과·공강요일·목표학점(12/15/18/21)·오전수업 피하기·팀플 선호를 고르고, 이미 들은 과목을 체크합니다(선수과목 확인용).

3. **AI 조건 해석** *(선택)* — `Gemini API`
   자유 텍스트로 조건을 적으면, AI가 위 카테고리 폼과 같은 4개 필드로 해석해 자동으로 반영합니다.

4. **추천 시간표 확인** — `RecommendResultScreen`
   전공필수 강제 포함, 선수과목 체크, 동시수강 세트를 반영한 상위 3개 추천안 중 하나를 고릅니다.

5. **시간표 확정** — `CalendarScreen`
   요일×시각 캘린더로 최종 확인 후 내 계정에 저장합니다.

6. **시간표 공유** — `POST /api/timetables/share`
   확정한 시간표를 "선배 시간표" 목록에 공개합니다.

7. **열람 & 추천(좋아요)** — `HomeScreen`
   다른 사용자가 홈 화면에서 이 시간표를 보고 추천(좋아요)을 남깁니다.

> **루프:** 7번에서 남긴 추천 수는 곧바로 2번(홈 화면)에 반영돼서, 시간표를 공유한 사람도 자기 화면에서 늘어난 추천 수를 바로 확인할 수 있습니다.
