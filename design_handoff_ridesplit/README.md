# Handoff: RideSplit — 대학생 택시 동승 매칭 앱

## Overview
대학교 학생들이 같은 방향(학교 거점 ↔ 시내 주요 거점)으로 이동할 때 택시 동승 상대를 찾아 비용을 나눠 낼 수 있게 해주는 서비스의 핵심 화면 프로토타입입니다. 매칭 알고리즘(같은 방향·비슷한 시간대 후보 노출)과 동행 신청→합류→출발 확정 플로우, 두 가지 핵심 기능을 중심으로 5개 화면을 구현했습니다.

## About the Design Files
이 폴더의 `RideSplit-Prototype.dc.html`은 **디자인 레퍼런스로 만든 HTML 프로토타입**입니다 — 실제 프로덕션에 그대로 복사해 넣을 코드가 아닙니다. 개발자는 이 HTML이 보여주는 화면 구성·색상·타이포그래피·인터랙션을 참고해, 프로젝트의 실제 스택(React + Vite, Express, Supabase — `CLAUDE.md`/`docs/plan.md` 참고)에 맞는 컴포넌트로 다시 구현해야 합니다. `ios-frame.jsx`는 프로토타입에서 iPhone 목업 프레임을 그리기 위한 장식용 셸일 뿐이며, 실제 앱 UI와는 무관하니 그대로 가져오지 마세요.

## Fidelity
**High-fidelity.** 색상, 타이포그래피, 간격, 컴포넌트 형태는 최종안에 가깝습니다. 개발자는 아래 디자인 토큰과 화면별 명세를 기준으로 픽셀 단위로 재현하면 됩니다.

## Screens / Views

### 1. 로그인 (Login)
- **목적**: 학교 이메일로 로그인 시작
- **레이아웃**: 세로 중앙 정렬, 좌우 패딩 28px. 위에서부터: 브랜드 로고(64×64, radius 20px) → 타이틀(22px/800) → 서브카피(13px, secondary 색) → 흰 카드(이메일 표시 + `.ac.kr 인증` 배지) → primary 버튼(pill, full width) → 안내 문구(11px)
- **카피**: "학교 이메일로 로그인" / "대학교 학생만 이용할 수 있는 택시 동승 매칭 서비스예요" / 이메일 예시 `jieun@univ.ac.kr` + 우측 `.ac.kr 인증` 배지 / 버튼 "인증 메일 받기"

### 2. 출발/도착 등록 (홈)
- **목적**: 이동 방향, 거점, 희망 시간을 등록해 매칭 후보를 조회
- **레이아웃**: 상단 뒤로가기 → 타이틀/서브카피 → "이동 방향" 세그먼트(2개, 나란히 flex:1) → "출발" 칩 그룹(선택된 방향에 따라 학교 거점 2개 또는 시내 거점 7개) → "목적지" 칩 그룹(반대쪽 목록) → "희망 출발 시간" 칩 3개 → "도착 소요시간" 칩 3개 → 동성 매칭 필터 토글(카드+스위치) → primary 버튼
- **핵심 로직**: "이동 방향" 토글로 학교→거점 / 거점→학교를 뒤집으면 출발·목적지 칩 목록이 서로 바뀜(학교 쪽은 항상 정문/북문, 반대쪽은 시내 거점 7개: 대구역·동대구역·동성로·대구공항·서부정류장·반월당·기타)
- **칩 상태**: 선택됨 = primary 배경 + 흰 텍스트, 미선택 = 흰 배경 + 옅은 테두리

### 3. 매칭 후보 리스트
- **목적**: 같은 방향·비슷한 시간대 학생들이 만든 "방(room)"을 보고 신청
- **정렬**: 출발 시간이 빠른 순
- **카드 구성**(후보 1명당): 아바타(40px 원, 이니셜) + 이름 + 평점(`★4.8`) + 단과대·성별 한 줄 + 목적지·출발시간·시간차이(`21:25 출발 · 5분 차이`) + 인원 배지(`n/4`, 1명이면 회색, 2명 이상이면 red tint) + 우측 상태 버튼
- **버튼 상태**: `신청`(outline) → 누르면 즉시 그 방에 합류하고 채팅방(4번 화면)으로 바로 이동 / 이미 다른 방에 합류했다면 `참여 불가`(disabled) / 정원 4명 다 찼으면 `정원 마감`(disabled) / 내가 합류한 방은 `채팅방 보기`(초록, 클릭 시 채팅방 재진입)
- **필터**: 동성 매칭 필터가 켜지면 이성 후보는 목록에서 제외

### 4. 그룹 채팅방
- **목적**: 합류한 방의 멤버들과 조율하고, 정원 미달 시 전원 동의로 출발을 확정
- **레이아웃**: 아바타 겹침 표시 + 인원 배지(`n/4명 모임`, 정원 차면 초록, 아니면 red tint) → 타이틀("동행자를 모으는 중이에요" / 정원 충족·동의 후 "그룹이 확정됐어요") → 채팅 말풍선(내 말풍선은 primary 배경, 상대는 연한 회갈색) → **정원 미달 시**: red-tint 카드에 "정원이 다 차지 않았어요" 안내 + "동의하고 출발 확정" 버튼 노출, 이 버튼을 눌러야 아래 비용 카드·탑승 확인 버튼이 나타남 → 예상 요금 카드(테두리 primary, 1인당 금액 강조) → "탑승 확인" 버튼(정원 충족 또는 동의 완료 시에만 활성화)
- **비용 계산**: 총 요금 12,000원을 실제 방 인원수로 나눠 100원 단위 반올림 표시

### 5. 완료 및 평가
- **목적**: 동행자별 별점 평가 + 개별 노쇼 신고
- **레이아웃**: 동행자별 카드 — 이름(14px/700) → 한 줄에 별점 5개(좌)와 "노쇼 신고하기" 체크박스(우, `justify-content: space-between`으로 멀리 이격) → 하단 "완료" 버튼

## Interactions & Behavior
- 전체 네비게이션은 단계(step 0~4) 기반 상태 머신. 각 화면 상단 진행 도트(5개, 활성 도트만 넓어짐)로 현재 단계 표시.
- 칩/토글/버튼은 클릭 즉시 상태 반영(비동기 대기 없음) — 신청 = 즉시 합류 + 즉시 화면 전환.
- 하나의 방에만 합류 가능(다른 방 신청 버튼은 자동 비활성화).
- 완료 화면에서 "완료" 클릭 시 전체 상태 초기화(합류 해제, 별점/노쇼 초기화) 후 로그인 화면으로 복귀.
- 호버 상태는 별도로 정의하지 않음(모바일 우선 프로토타입) — 개발 시 버튼에 표준 프레스/호버 다크닝(배경색 8~10% 어둡게) 추가 권장.

## State Management
- `direction`: `from_school` | `to_school`
- `schoolGate`: `정문` | `북문`, `cityPoint`: 7개 거점 중 하나
- `time`, `arrival`: 칩 선택값
- `genderOnly`: boolean (동성 매칭 필터)
- `candidates[]`: 각 `{id, name, college, gender, rating, dest, time, groupCount}` — `groupCount`는 그 방의 현재 인원(최대 4)
- `joinedId`: 내가 합류한 candidate id (없으면 null)
- `confirmed`: 정원 미달 상태에서 "동의하고 출발 확정"을 눌렀는지
- `ratings`: 멤버 id → 1~5점, `noshow`: 멤버 id → boolean
- 데이터 fetching은 없음(전부 클라이언트 mock) — 실제 구현 시 매칭 후보 조회 API, 방 합류 API, 실시간 인원 갱신(웹소켓/폴링), 채팅 메시지 API로 대체 필요 (`docs/plan.md`, `docs/checklist.md` 참고)

### Typography
- 폰트: `Pretendard`, fallback `-apple-system, system-ui, sans-serif` (한글 최적화)
- 화면 타이틀: 20–22px / 800
- 본문: 13–15px / 400–700
- 캡션/라벨: 11–12px / 600–700

### Radius
- 버튼/칩/배지: `999px` (pill)
- 카드: `14–16px`
- 로고 사각형: `8px`(소형) / `20px`(대형)

### Spacing
- 화면 좌우 패딩: `20px` (로그인만 `28px`)
- 섹션 간 간격: `18–20px`
- 칩 gap: `8px`, 리스트 카드 간 gap: `10px`

### Shadow
- 별도 그림자 거의 없음 — 카드는 얇은 테두리로 구분(그림자 대신 border 사용). 필요 시 `0 1px 3px rgba(36,21,18,0.06)` 정도의 아주 옅은 그림자 권장.

## Assets
- 브랜드 로고: 별도 이미지 없음. 겹친 두 원(사람 아이콘 은유) + 우측 하단 `₩` 코인 배지를 조합한 인라인 SVG로 표현(합승 + 절약 컨셉). 정확한 마크업은 `RideSplit-Prototype.dc.html`의 `logoStyle`/`bigLogoStyle` 부분 참고.
