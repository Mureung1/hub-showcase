## 회계장부 자동화 agent — MVP 구현계획 확정 (IDEA.MD 8번)

- 리서치 문서: [세무조정계산서-결산보고서-research.md](세무조정계산서-결산보고서-research.md) — 결정론적/비결정론적 서식 분류(§8)가 이번 슬라이스의 근거
- **구현계획 전문: [회계장부-자동화-구현계획.md](회계장부-자동화-구현계획.md)**

요약:
- 새 모듈 `ledger-automation/` — Node.js(ESM) + Express + 바닐라 JS UI + exceljs (의존성 2개)
- 흐름: 전표 직접 입력(웹 UI) → 총계정원장 집계 → **합계잔액시산표 + 재무상태표 + 손익계산서** → Excel 다운로드
- 금액은 원 단위 정수(KRW 무소수점), 계정과목은 더존식 3자리 코드 ~20개(소규모 서비스업 가상 법인)
- 마감분개 생략(단일 회계기간): 검증 항등식 `총자산 = 총부채 + 자본(원장) + 당기순이익`

| Step | 내용 | 완료 기준 |
|---|---|---|
| 1 | 스캐폴드 + 계정 마스터 + 전표 검증 | 차대불일치/미등록코드/비정수 거부 테스트 |
| 2 | 저장소(atomic write) + 원장 집계 + 샘플 시드 | Σ차변=Σ대변 |
| 3 | 합계잔액시산표 | 차변총계=대변총계 |
| 4 | 손익계산서 + 재무상태표 | 자산=부채+자본+당기순이익 |
| 5 | Express REST API | fetch 통합테스트 |
| 6 | Excel 렌더러 + 다운로드 | 라운드트립(재파싱) 검증 |
| 7 | 전표 입력 UI | 수동 E2E 체크리스트 |

머메이드 활용해서 데이터 흐름을 시각화해줘. states 랑 컴포넌트 나눠서 한다.
