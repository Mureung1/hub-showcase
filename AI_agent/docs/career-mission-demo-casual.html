Career Mission AI

취업 준비생이 스펙을 입력하고, AI 분석과 맞춤 미션을 거쳐 포트폴리오까지 정리하는 서비스입니다.

React + Vite Express Prisma PostgreSQL JWT
Problem

문제점

목표 직무에 맞게 준비하고 있는지 확인하기 어렵고, 결과물을 포트폴리오로 연결하는 과정도 혼자 하기 어렵습니다.

역량 판단

현재 준비 상태가 목표 직무 기준으로 어느 정도인지 알기 어렵습니다.

실무 경험

공부한 내용을 어떤 결과물로 만들어야 할지 애매합니다.

피드백

혼자 만든 결과물을 어떻게 보완해야 하는지 확인하기 어렵습니다.

정리

수행 경험을 자기소개서나 면접에서 말할 수 있게 구조화해야 합니다.

Service Flow

핵심 흐름

단순히 분석 결과만 보여주는 것이 아니라, 실제로 할 미션을 추천하고 결과물을 취업 준비 자료로 남기는 흐름입니다.

스펙 등록 AI 분석 미션 추천 피드백 포트폴리오
01
회원가입과 로그인

사용자 계정과 인증 상태를 만들고 보호 페이지 접근을 제어합니다.

02
스펙과 목표 직무 등록

전공, 학점, 경험, 기술, 목표 직무를 분석 기준 데이터로 저장합니다.

03
미션 수행과 제출

추천 미션을 수행하고 링크, 설명, 파일 UI로 결과물을 제출합니다.

04
피드백과 포트폴리오

제출 결과물을 평가하고 프로젝트 경험 형태로 다시 정리합니다.

Home

홈 화면

  • 서비스 첫 화면
    AI 커리어 매니저의 핵심 가치와 사용 흐름을 바로 보여줍니다.
  • 상단 메뉴
    스펙 등록, AI 분석, 미션, 피드백, 포트폴리오로 이동할 수 있습니다.
  • 로그인 상태 반영
    로그인 후에는 내 정보와 로그아웃 버튼으로 바뀌도록 구성했습니다.
Account

회원가입 화면

  • 기본 정보 입력
    이름, 아이디, 이메일, 학교, 전공, 비밀번호를 입력합니다.
  • 학교와 학과 검색
    입력 폼과 검색 버튼을 분리해 확장 가능한 구조로 만들었습니다.
  • 다음 단계 연결
    회원가입 후 로그인과 이메일 인증 흐름으로 이어집니다.
Verification

이메일 인증과 로그인

  • 이메일 인증
    회원가입 후 인증 토큰을 만들고 SMTP 메일 발송 흐름을 구성했습니다.
  • JWT 인증
    로그인 성공 시 토큰을 발급하고 보호 API 요청에 사용합니다.
  • 보호 페이지
    로그인하지 않은 사용자는 스펙 등록, 분석, 미션 화면에 바로 접근할 수 없습니다.
My Page

마이페이지

  • 커리어 현황 확인
    회원 상태, 등록한 스펙, 목표 직무, 최근 AI 분석 결과를 한 화면에서 확인합니다.
  • DB 저장 구조
    사용자 정보와 스펙, 분석 결과가 백엔드 API와 DB에 연결됩니다.
  • 다음 행동 버튼
    스펙 수정과 AI 분석 보기로 핵심 흐름에 다시 진입할 수 있습니다.
Spec Register

스펙 등록

  • 목표 직무 입력
    분석 기준이 되는 목표 직무를 먼저 등록합니다.
  • 핵심 스펙 저장
    학년, 학점, 자격증, 어학 점수, 프로젝트 경험, 대외활동, 보유 기술을 입력합니다.
  • 분석 화면 연결
    저장 후 AI 분석 화면으로 이동해 준비도와 부족한 역량을 확인합니다.
AI Analysis

AI 분석

  • 준비도 점수
    목표 직무와 등록한 스펙을 기준으로 현재 준비도를 보여줍니다.
  • 강점과 보완점
    사용자가 이미 가진 강점과 부족한 역량을 나눠서 확인합니다.
  • 추천 준비 방향
    다음에 무엇을 보완해야 하는지 우선순위 형태로 정리합니다.
Mission

추천 미션

  • 목표 직무 기반 추천
    전공, 목표 직무, 보유 기술을 기준으로 미션을 추천합니다.
  • 결과물이 남는 과제
    단순 학습이 아니라 포트폴리오로 연결할 수 있는 과제로 구성했습니다.
  • 카드형 정보
    난이도, 기간, 필요한 역량, 제출 결과물을 한눈에 볼 수 있습니다.
Mission Detail

미션 상세와 진행 체크

  • 수행 가이드
    선택한 미션을 어떻게 진행할지 단계별 안내를 제공합니다.
  • 체크리스트 상태
    체크 항목에 따라 pending, in_progress, completed 상태를 계산합니다.
  • 제출 화면 연결
    수행 후 결과물 업로드와 피드백 화면으로 이어집니다.
Submission

결과물 제출

  • 미션 결과 선택
    수행한 미션을 선택하고 제출할 결과물을 연결합니다.
  • 링크와 설명 입력
    GitHub, Notion, 블로그, 배포 링크와 수행 설명을 함께 작성할 수 있습니다.
  • 파일 제출 UI
    PDF, 이미지, 텍스트/코드 파일 제출 흐름을 준비했습니다.
Feedback

AI 피드백

  • 최신 제출물 기준
    사용자가 제출한 결과물을 기준으로 평가를 생성합니다.
  • 수정 방향 제공
    잘한 점, 개선할 점, 수정 제안, 포트폴리오 반영 포인트를 나눠 보여줍니다.
  • fallback 처리
    OpenAI API가 없거나 실패해도 기본 피드백으로 흐름이 끊기지 않게 했습니다.
Portfolio

포트폴리오 정리

  • 프로젝트 경험화
    미션 결과물을 문제 정의, 접근 방식, 결과, 배운 점으로 재구성합니다.
  • 면접과 자기소개서 연결
    수행 과정을 말로 설명할 수 있는 형태로 정리합니다.
  • 자동 생성 확장
    피드백 결과를 바탕으로 포트폴리오 초안을 더 정교하게 만들 수 있습니다.
Backend

백엔드

  • Express API
    인증, 스펙, 분석, 미션, 제출, 피드백, 포트폴리오 API를 구성했습니다.
  • Prisma + PostgreSQL
    User, UserSpec, AnalysisResult, Mission, UserMission 모델을 설계했습니다.
  • 외부 연동 준비
    OpenAI, SMTP, CareerNet, Q-Net API 호출 구조와 fallback을 준비했습니다.

인증

회원가입, 로그인, 이메일 인증, JWT 보호 API

미션

추천 미션 조회, 체크리스트 진행 상태 저장

산출물

결과물 제출, AI 피드백, 포트폴리오 초안

Validation

검증한 부분

  • 프론트 검증
    lint와 build로 화면 코드가 깨지지 않는지 확인했습니다.
  • 백엔드 테스트
    서비스 로직 테스트와 미션 진행 상태 통합 테스트를 작성했습니다.
  • TDD 적용
    미션 체크리스트 상태 계산은 테스트를 먼저 만들고 구현했습니다.
검증 명령
