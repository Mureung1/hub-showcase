마이페이지 DB 저장까지 구현한 데모 발표

React Express JWT Prisma + DB SMTP
안녕하세요. Career Mission AI 프로젝트 발표를 시작하겠습니다. 이 서비스는 사용자의 스펙과 목표 직무를 바탕으로 부족한 역량을 분석하고, 실무형 미션으로 연결하는 서비스입니다.
Problem

취업 준비는 정보보다 실행이 어렵습니다

스펙을 쌓아도 목표 직무 기준으로 무엇이 부족한지 알기 어렵고, 보완 활동을 포트폴리오로 남기기도 쉽지 않습니다.

진단

현재 스펙을 기준에 따라 분석

미션

부족한 역량을 실무형 과제로 전환

포트폴리오

수행 결과와 피드백을 자산화

그래서 단순히 분석 결과만 보여주는 것이 아니라, 사용자가 바로 실행할 수 있는 미션과 포트폴리오 흐름까지 연결하는 것을 목표로 했습니다.
3 Step

스펙 등록 → AI 분석 → 추천 미션

Register Screen

회원가입 화면

  • 기본 계정 정보 입력
    이름, 아이디, 이메일, 학교, 전공, 비밀번호를 입력합니다.
  • 백엔드 회원가입 API 연결
    입력값은 /api/auth/register로 전달됩니다.
  • 이메일 인증 시작
    가입 후 인증 메일 발송 흐름으로 이어집니다.
회원가입 화면은 사용자의 기본 정보를 입력받고, 백엔드 API로 전달하는 첫 진입점입니다. 이후 이메일 인증이 완료되어야 정상적으로 로그인할 수 있습니다.
Email Verification

이메일 인증

DB 저장 토큰 생성 SMTP 발송 링크 클릭 인증 완료

로그인 차단

이메일 인증 전 사용자는 로그인할 수 없습니다.

환경 변수 보호

SMTP 설정은 백엔드 .env에서만 관리합니다.

회원가입 후 백엔드는 인증 토큰을 만들고 SMTP를 통해 메일을 발송합니다. 사용자가 인증 버튼을 누르면 이메일 인증 완료 상태로 변경됩니다.
Auth Guard

로그인과 보호 페이지

  • 인증된 사용자만 로그인
    이메일 인증 상태를 확인해 로그인 가능 여부를 판단합니다.
  • JWT 토큰 발급
    로그인 성공 시 토큰을 발급하고 보호 API 요청에 사용합니다.
  • ProtectedRoute 적용
    미로그인 사용자의 보호 페이지 접근을 프론트에서도 차단합니다.
백엔드에서는 JWT를 검증하고, 프론트에서는 ProtectedRoute로 화면 접근을 제어합니다. 화면과 API 양쪽에서 보호가 이루어지는 구조입니다.
2중 보호

프론트 라우팅 제어 + 백엔드 JWT 검증

My Page

마이페이지 DB 저장 개선

  • 프로필 수정 API 추가
    PATCH /api/auth/me로 이름, 이메일, 학교, 전공을 수정합니다.
  • 브라우저 저장에서 DB 저장으로 개선
    수정값이 실제 DB에 반영됩니다.
  • 백엔드 검증
    중복 이메일과 잘못된 입력값을 서버에서 검증합니다.
기존에는 수정값이 브라우저 세션에만 반영됐지만, 이제는 DB에 저장되도록 개선했습니다. 그래서 재로그인 후에도 사용자의 최신 프로필을 유지할 수 있습니다.

목표 직무 기반

제출 결과물 명확화

GitHub 저장소, 배포 URL, 구현 과정 요약처럼 결과물을 정의합니다.

분석 결과가 실제 행동으로 이어지도록 미션을 추천합니다. 사용자는 미션 시작 버튼을 눌러 수행 화면으로 이동할 수 있습니다.
Mission Detail

미션 상세와 진행 체크

  • 수행 가이드 제공
    미션을 어떻게 진행할지 단계별 안내를 보여줍니다.
  • 체크리스트 기반 진행률
    사용자가 수행 단계를 체크하며 진행 상황을 확인합니다.
  • 결과물 업로드로 연결
    미션 완료 후 결과물 제출과 AI 피드백으로 이어집니다.
미션 상세 화면에서는 수행 가이드와 체크리스트를 제공합니다. 다음 단계에서는 이 진행 상태를 API와 DB에 저장하도록 확장할 예정입니다.
Architecture

프론트 - 백엔드 - DB 구조

React 화면 authService.js Express API Prisma DB
프론트는 API 함수만 호출하고, 입력 검증과 DB 접근, 이메일 인증, JWT 검증은 백엔드에서 처리합니다. 민감한 설정과 외부 API 키는 프론트에 노출하지 않습니다.

Frontend

Backend

Database

User, Spec, Analysis 결과 저장

External

SMTP, OpenAI API, 환경 변수 관리
