# Deployment

## Render Backend

Create a Render Blueprint from the repository and use `render.yaml`.

- Service root: `AI_agent/backend`
- Build command: `npm ci && npm run db:generate`
- Pre-deploy command: `npx prisma migrate deploy`
- Start command: `npm start`
- Health check: `/api/health`

Set these environment variables in Render:

```env
FRONTEND_ORIGIN=https://your-vercel-domain.vercel.app
DATABASE_URL=postgresql://...
OPENAI_API_KEY=...
CAREER_NET_API_KEY=...
PUBLIC_DATA_API_KEY=...
SMTP_HOST=smtp.gmail.com
SMTP_USER=...
SMTP_PASS=...
SMTP_FROM="Career Mission AI <...>"
RESEND_API_KEY=...
RESEND_FROM="Career Mission AI <onboarding@resend.dev>"
```

`JWT_SECRET` is generated by the Blueprint. If you create the service manually, add a long random value.

Render Free web services block outbound SMTP ports. Use `RESEND_API_KEY` and `RESEND_FROM` for production email on the free plan.

## Vercel Frontend

Import the same repository into Vercel and configure the project as a monorepo app.

- Root Directory: `AI_agent/frontend`
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

Set these environment variables in Vercel:

```env
VITE_API_BASE_URL=https://your-render-service.onrender.com
VITE_GITHUB_URL=https://github.com/samingming
VITE_DISCORD_URL=https://discord.com/users/your-id
VITE_CONTACT_EMAIL=your-email@example.com
```

After Vercel gives you the production URL, update Render `FRONTEND_ORIGIN` to that exact URL and redeploy the backend.
