# 한끼바꿈 디자인 시스템 (v3 · Warm Paper 확정)

부산대 앞 대학가에서 학생의 디지털 재능과 사장님의 식사권을 물물교환하는 서비스.
주 사용자는 **50대 사장님**과 **20대 대학생** — 모든 디자인 판단의 기준은 "사장님도 헤매지 않는가".

룩의 정체성 한 줄: **따뜻한 종이색 바탕 + 아주 절제된 페리윙클 블루 포인트 + 애플 이모지가 컬러 포인트.**
동네 상생 서비스의 온기(웜 그레이·크림)와 플랫폼의 신뢰(블루)를 결합한 조합이다.
진한 색을 넓게 칠하거나, 중성색을 차가운 회색으로 되돌리는 순간 이 룩은 깨진다.

## 1. 디자인 토큰 (v3 확정 — 값 그대로 사용, 임의 색 추가 금지)

```css
:root{
  /* 주색 — 포인트 전용 */
  --primary:#5B6CF5;        /* 강조 문구, 배지 글자, 숫자, 아이콘 */
  --primary-soft:#EAEDFB;   /* 배지·칩·버튼 배경 (넓은 면은 항상 이걸로) */
  --primary-deep:#4354D8;   /* 눌림 상태 등 꼭 필요할 때만 */

  /* 배경 — 따뜻한 종이 톤 (차가운 라벤더그레이 금지) */
  --bg-page:#F6F3EC;        /* 페이지 배경: 종이색 */
  --bg-card:#FFFEFB;        /* 카드: 크림 기 도는 흰색 (#FFFFFF 순백 금지) */
  --bg-section:#F5F1E8;     /* 카드 안 안내 박스, 아바타, 비활성 요소 */

  /* 글자 — 웜 그레이 (푸른 기 도는 쿨그레이 금지) */
  --ink:#2B2620;            /* 제목 (완전 검정 금지) */
  --body:#5A544B;           /* 본문 */
  --muted:#A39A8C;          /* 보조·메타·영문 캡션 */
  --line:#EDE7DB;           /* 구분선 — 최후의 수단으로만 */

  /* 보상(식사권) — 시그니처 */
  --ticket-bg:#FFF3D6;      /* 연크림 노랑 */
  --ticket-ink:#8A6A1B;

  /* 상태 */
  --ok-soft:#E9F4EA;  --ok:#3E9A64;     /* 사용 가능·완료 배지 */
  --hot-soft:#FDEEE9; --hot:#E85D3D;    /* 핫딜 태그·"필수" 표시 (글자에만) */

  /* 반경 */
  --r-card:20px;   /* 카드 */
  --r-inner:14px;  /* 카드 안 요소(버튼·입력창·티켓) */
  --r-pill:999px;  /* 배지·칩·태그 = 전부 알약형 */

  /* 그림자 — 테두리 대신. 반드시 갈색 기운 (남색 그림자 금지) */
  --shadow-card:0 8px 24px rgba(88,68,32,.07);
  --shadow-float:0 18px 44px rgba(88,68,32,.12);
}
```

## 2. 타이포그래피

```css
font-family:"Pretendard","Apple SD Gothic Neo","Noto Sans KR",sans-serif;
```

- 제목: 1.4~1.6rem · 굵기 800 · `letter-spacing:-0.02em` · 행간 1.35 — 제목 안 핵심 구절만 `--primary` 색으로 강조
- 제목 아래 짧은 영문 캡션(`--muted`, .8rem) 병기 가능
- 본문: .9~.95rem · 500 · 행간 1.7 / 메타·캡션: .74~.82rem
- 12px 미만 금지 (50대 사용자 기준), 웹폰트 CDN 로드 금지 — 시스템 폰트 스택만

## 3. 색 운용 규칙 (이 룩의 본체 — 양보 불가)

1. **주색 원색(`--primary`)은 좁게만**: 강조 문구·숫자·배지 글자·아이콘. 버튼 배경·패널 등 넓은 면은 반드시 `--primary-soft`. 진한 채움 버튼은 화면당 1개 이하
2. **중성색은 반드시 웜 톤**: 배경·글자·그림자 어디에도 푸른 기 도는 회색을 쓰지 않는다. 화면 온도는 주색이 아니라 중성색이 결정한다
3. **카드는 테두리 없이 그림자로**: 크림 흰 카드 + `--shadow-card`(갈색 기운). 1px 보더 금지
4. **강조는 배경칠이 아니라 글자색으로**: 중요한 문구 = `--primary` 색 텍스트
5. **여백이 구분선을 대체**: 섹션 구분은 선 대신 큰 여백(40px+)과 `--bg-section` 톤 변화로
6. **이모지 = 아이콘**: 별도 아이콘 세트 금지. 기본 유니코드 이모지(🍚 🎟️ 💡 🍽️ 🤝)를 아이콘 자리에 사용 — 애플 기기에서 애플 이모티콘으로 렌더링되며, 절제된 화면의 컬러 포인트 역할. 한 화면에 7~8개 이내로 절제

## 4. 시그니처 컴포넌트: 식권 티켓

보상(식사권)이 등장하는 **모든 지점**(피드·상세·완료·지갑)에 사용. 절취선 + 펀치 구멍이 핵심.
상태별 색: 사용 가능 = `--ticket-bg` 연노랑 / **사용 완료·비활성 = `--bg-section` dim** (초록 아님 — 초록은 상태 배지 전용)

```css
.ticket{display:flex;align-items:center;background:var(--ticket-bg);border-radius:var(--r-inner);position:relative}
.ticket .stub{flex:0 0 86px;text-align:center;padding:14px 6px;
  border-right:2px dashed rgba(138,106,27,.3);font-weight:800;font-size:1.35rem;color:var(--ticket-ink)}
.ticket .body{flex:1;padding:12px 16px;font-size:.84rem;font-weight:600;color:var(--ticket-ink)}
.ticket::before,.ticket::after{content:"";position:absolute;width:14px;height:14px;border-radius:50%;
  background:var(--bg-card);top:50%;transform:translateY(-50%)}  /* 구멍 색 = 티켓이 놓인 배경색과 일치 */
.ticket::before{left:79px} .ticket::after{right:-7px}
.ticket.dim{background:var(--bg-section)} .ticket.dim .stub,.ticket.dim .body{color:var(--muted)}
```

## 5. 핵심 컴포넌트 규격

- **버튼**: `--primary-soft` 배경 + `--primary` 글자, 최소 높이 48px, radius 14px, 굵기 700. :active 시 #DEE2F8
- **배지·칩·태그**: 전부 알약형(999px), soft 배경 + 진한 글자 조합만 — 사용가능(`--ok-soft`/`--ok`), 핫딜(`--hot-soft`/`--hot`), 일반(`--primary-soft`/`--primary`), 비활성(`--bg-section`/`--muted`)
- **진행 스텝바**: `요청등록 → 매칭 → 완료대기 → 완료·지급` 4단계 고정. 완료 단계 `--primary`, 현재 단계 `--hot` 테두리, 최종 지급 `--ok`
- **카드**: `--bg-card` · radius 20px · 패딩 24px · `--shadow-card` · 카드 간 간격 20px
- **아바타**: 44px 원, `--bg-section` 배경 + 이모지
- **온기 문장**: 화면당 1줄, 하단에 서비스 의도를 상기시키는 카피 (예: "🤝 이 식사권들은 헬퍼님의 재능으로 만들어졌어요"). 과용 금지 — 화면당 최대 1개

## 6. UI 원칙 (양보 불가)

1. **큰 글씨 · 큰 버튼 · 낮은 단계 수** — 핵심 행동까지 탭 2번 이내
2. **상태값이 채팅을 대체** — 거래 화면엔 스텝바/상태 배지 필수, 채팅 UI 금지
3. **AI는 초안까지만** — AI 생성물엔 "AI가 만든 초안" 표시 + 사용자 확인 버튼 필수, 자동 게시 금지
4. **보상은 항상 티켓** — 식사권을 일반 텍스트·₩ 금액으로 표기 금지 (현금 없는 플랫폼)
5. **지역은 프리셋 드롭다운** — 활성 `부산대 앞` / 비활성(오픈 예정) `경북대 앞` `경상국립대 앞`. 지도·GPS UI 금지

## 7. 마이크로카피 톤

- 부드러운 존댓말 "~해요"체: "두 사람 모두 확인하면 식사권이 지급돼요"
- 호칭: **사장님 / 헬퍼(님)** — "판매자/구매자", "의뢰인/작업자" 금지
- 규칙 안내는 이유와 함께: "예시가 있으면 다툼이 확 줄어요. 그래서 필수예요."
- 필수 필드는 `--hot` 색 "필수", 선택은 `--muted` "선택"

## 8. 하지 말 것

- 외부 UI 라이브러리(부트스트랩, MUI 등) 금지 — 위 토큰으로 직접 스타일링
- 팔레트 외 색 추가, 색 의미 매핑 변경 금지 (노랑=보상, 초록=완료 배지, 주황빨강=긴급 글자)
- 차가운 중성색(쿨그레이 배경·글자·남색 그림자) 금지 — v2 클린 팔레트로 회귀 금지
- 진한 색을 넓은 면에 채우기 금지 (그라데이션 히어로 카드 포함)
- 카드 1px 테두리, 12px 미만 텍스트, 화면당 3개 이상 주요 버튼 금지
- 채팅 UI · 지도 UI · 결제 UI · ₩ 표기 · 다크모드 금지
