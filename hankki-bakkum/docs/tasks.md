# 한끼바꿈 개발 Task 백로그

> **백로그란?** 해야 할 일을 전부 한곳에 모아둔 목록. 매주 여기서 이번 주 할 일을 골라 진행하고, 새로 생기는 작업도 여기에 먼저 쌓아둔다.
> **우선순위**: P0 필수(없으면 서비스가 안 됨) · P1 중요(있어야 완성도가 산다) · P2 여유되면
> **관리 방법**: 완료 시 `[ ]` → `[x]`로 바꾸고 커밋. 혼자 진행하는 프로젝트라 **P0만 지켜도 4주 완주 성공**, P1·P2는 여유에 따라 조정.
> **진행 현황 (7/17 기준)**: 1~2주차 P0 완료 — 가입→로그인→요청 등록→피드 노출 시나리오 통과, 2주차 데모 발표 완료.
