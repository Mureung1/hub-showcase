# 시험 벼락치기 스케줄러 — 기획서 (v2)

> 검증된 수면과학 모델을 이용해, 시험기간 대학생의 벼락치기 수면·카페인 스케줄을 최적화하는 도구

---

## 0. 개요

시험 날짜·남은 공부량·평소 수면 패턴·카페인 섭취 상태를 입력하면, 검증된 생물수학 모델(Two-Process Model + 카페인 상호작용 모델)로 "시험 시작 시각에 각성도가 최고가 되는" 수면·카페인 스케줄을 계산해주는 웹 도구. 시험이 여러 개 겹치는 시험기간 전체를 한 번에 고려해 스케줄을 짜준다는 점이 핵심 차별점이다.

> 🔗 **[클릭해서 프로토타입 바로 보기](https://dodeho.github.io/hub/)** — 홈 → 정보 입력 → 처리 중 → 결과 → 스케줄 조정 5개 화면을 실제로 눌러볼 수 있는 HTML/CSS 목업

## 1. 문제정의

**상황**
시험기간이 되면 대학생 대부분은 벼락치기를 하게 되고, 이 과정에서 수면과 카페인 섭취를 순전히 감과 스트레스에 의존해서 조절한다. (스트레스로 매운 음식·결식 반복, 카페인 과다 섭취, 수면 부족 → 위염 발생, 정작 시험 당일엔 컨디션 저하로 죽만 먹는 경험)

**핵심 문제**
1. 학생들은 "언제 자고, 언제 일어나고, 카페인을 언제 얼마나 섭취해야 시험 시작 시각에 각성도가 최고가 되는지"에 대한 과학적 근거 없이 직관에만 의존하고 있다.
2. 그 결과 오히려 역효과(수면 부족 누적, 위장 장애, 시험 당일 컨디션 저하)가 발생한다.
3. 시험 기간에는 시험이 하루가 아니라 일주일 내내 연달아 겹치는 경우가 많은데, 학생들은 "오늘 밤"만 생각하지 시험기간 전체의 컨디션 배분은 고려하지 못한다.
4. 이건 일부 학생의 특수한 상황이 아니라, 시험이 있는 대학생이라면 학기마다 반복적으로 겪는 보편적이고 확실한 문제다.

**기존 해결책의 한계**
- 카페인 계산기 앱(LastSip, Caffly, caff.ai 등): "오늘 밤 잘 자기 위한" 목적이라, 마감에 맞춰 각성도를 끌어올리는 시나리오를 다루지 않음
- RISE 같은 생체리듬 앱: 장기적으로 좋은 수면 습관을 유지하는 게 목적이라, 시험이라는 단기 마감·필요 학습량을 입력받아 스케줄을 역산해주지 않음
- 두 부류 모두 시험이 하나가 아니라 여러 개 연속으로 겹치는 "시험 주간" 전체를 놓고 컨디션을 배분하는 기능은 없음
- 즉, **"시험 일정(들) + 남은 공부량"이라는 구체적 제약 조건을 입력하면 과학적으로 검증된 모델로 최적 스케줄을 계산해주는 도구는 존재하지 않는다.**

## 2. 사용자 시나리오

생명과학과 3학년 민지는 이번 주에 시험이 세 개다: 월요일 9시 세포생물학, 수요일 14시 유전학, 금요일 10시 생화학. 평소엔 밤 12시에 자서 아침 7시에 일어난다. 오늘 아침에는 스트레스 때문에 이미 아이스 아메리카노를 한 잔 마셨다.

1. 앱을 열고 "시작하기"를 누른다.
2. 정보 입력 화면에서 캘린더 UI로 세 시험의 일시와 각 시험별 남은 공부 시간을 입력한다. 평소 수면 패턴, 오늘 이미 마신 카페인(아메리카노 톨, 오전 9시), 카페인 민감도, 나이·성별·건강상태, 최소 수면시간을 차례로 입력한다.
3. "계산하기"를 누르면 처리 중 화면에서 Two-Process Model + 카페인 상호작용 모델이 세 시험 일정을 한꺼번에 고려해 계산을 진행한다.
4. 결과 화면에서 오늘부터 금요일 시험까지 며칠에 걸친 예측 각성도 그래프와, 날짜별 "몇 시 취침 → 몇 시 기상 → 몇 시 카페인 몇 mg" 추천 스케줄을 확인한다. 만약 추천된 카페인 총량이 안전 섭취 한도에 걸리면 경고 문구가 함께 표시된다.
5. 추천안이 본인 상황과 안 맞으면(예: 그 시간에 잘 수 없음) 스케줄 조정 화면에서 취침·기상·카페인 조건을 슬라이더로 직접 조정하고 재계산한다.
6. 최종 스케줄을 저장하면 로그인 없이 브라우저에 기록이 남아, 다음에 다시 열어도 이어서 확인할 수 있다.

## 3. 핵심 기능

### 기능 1. 정보 입력 → 검증된 계산 엔진

캘린더·폼 UI로 시험 일정(복수 가능), 평소 수면 패턴, 오늘까지 섭취한 카페인, 카페인 민감도, 나이/건강 상태, 최소 수면시간을 입력받는다. 시험장까지 이동시간은 계산에 넣지 않고, "기상 후 준비·이동에 필요한 시간만큼 목표 각성 시각을 조절해보세요" 같은 안내 문구로 사용자가 스스로 감안하도록 한다(2026-07-15 결정 — 사용자마다 편차가 커서 직접 판단이 더 정확함). 자연어 텍스트박스는 "빠른 입력을 위한 보조 기능"으로만 제공하며(입력값을 폼에 미리 채워주는 용도), 없어도 서비스 이용에 지장이 없는 스트레치 목표로 둔다.

계산은 AI가 임의로 만들어내지 않고, 아래 두 논문에 발표된 검증된 생물수학 모델을 그대로 구현해 사용한다.

- Borbély, A.A. (1982). *A Two Process Model of Sleep Regulation*. Human Neurobiology, 1, 195-204. — 수면압(Process S)과 일주기리듬(Process C)의 상호작용으로 각성도를 예측하는 원형 모델
- Vital-Lopez, F.G., Doty, T.J., & Reifman, J. (2024). *When to sleep and consume caffeine to boost alertness*. SLEEP, 47(10), zsae133. — 위 모델에 카페인의 아데노신 수용체 경쟁적 억제 효과를 결합해, 원하는 시각에 각성도를 최대화하는 수면·카페인 스케줄을 계산하는 통합 모델(UMP)

여러 후보 수면·카페인 스케줄을 이 모델에 대입해 비교하고, **입력된 모든 시험 시각의 예측 각성도를 함께 고려해** 가장 좋은 조합을 추천한다. (상세 알고리즘은 6장 참고)

### 기능 2. 그래프(시간축) + 시각화

며칠에 걸친 시간대별 예측 각성도를 그래프로 표시하고, 추천 수면·공부·카페인 스케줄을 타임라인 형태로 함께 보여준다. 각 시험 시각은 그래프/타임라인 위에 마커로 표시된다. 사용자가 스케줄 조정 화면에서 조건을 바꾸면 그래프와 타임라인이 즉시 갱신된다.

### 기능 3. 안전 섭취 한도 체크

나이·건강 상태를 바탕으로 개인별 일일 카페인 한도를 계산하고, 오늘 이미 마신 카페인을 차감해 "추가로 마셔도 되는 양"을 추적한다. 추천 스케줄이나 사용자가 직접 조정한 스케줄이 이 한도를 초과하면 경고 문구를 표시한다. (상세 기준은 6장 참고)

### 기능 4. 로컬 저장

로그인 없이 브라우저 `localStorage`에 최근 계산 결과·입력값을 저장한다. 같은 기기·브라우저에서는 다음 방문 시 이어서 확인할 수 있다. 여러 기기 간 동기화는 범위 밖(7장 향후 고려 기능 참고).

## 4. 화면 흐름

**화면 목록 (5개)**

| # | 화면 | 설명 |
|---|---|---|
| 1 | 홈 | 서비스 소개, 시작하기, (저장된 기록이 있으면 최근 결과 미리보기) |
| 2 | 정보 입력 | 캘린더/폼 기반 입력 (자연어는 보조 기능) |
| 3 | 처리 중 | 계산 진행 상태 표시 |
| 4 | 결과 | 각성도 그래프 + 추천 스케줄 + (필요 시) 안전 한도 경고 |
| 5 | 스케줄 조정 | 슬라이더로 조건 수동 조정 → 재계산 |

**흐름**: 홈 → 정보 입력 → 처리 중 → 결과 → (필요 시) 스케줄 조정 → 처리 중으로 되돌아가 재계산 → 결과 갱신

### 화면 1. 홈
- 서비스 소개
- "시작하기" 버튼
- `localStorage`에 저장된 최근 계산 기록이 있으면 미리보기 카드 노출 (로그인 불필요)

### 화면 2. 정보 입력 (전체 항목)
1. **시험 목록** — 과목명 + 시험 일시, "+ 시험 추가"로 여러 개 등록 가능, 각 시험별 남은 공부 시간(24시간 제한 없음, 최대 며칠 전부터 계획 가능)
2. **평소 수면 패턴** — 평소 취침 시각 / 기상 시각
3. **오늘 이미 섭취한 카페인** — 음료 종류 선택(또는 mg 직접 입력) + 섭취 시각, 여러 잔 추가 가능
4. **카페인 민감도** — 둔감 / 보통 / 예민 (3단계)
5. **나이, 성별, 건강 상태 간단 체크** — 임신 여부, 심장질환 여부 등 (일일 카페인 한도 계산용)
6. **최소 수면시간** — 사용자가 직접 조정 가능한 슬라이더 (기본값 제안 + 수동 조정), 이동시간을 감안해 시각을 조절하라는 안내 문구 함께 노출
7. *(보조 기능, 스트레치)* 자연어로 상황을 설명하면 위 항목들을 자동으로 채워주는 텍스트박스

### 화면 3. 처리 중
계산 단계를 순서대로 노출: 입력 조건 확인 → 평소 수면 패턴 반영 → Two-Process Model 계산 → 카페인 상호작용 모델 계산 → 후보 스케줄 비교 → 다중 시험 통합 최적화 → 결과 화면으로 이동

### 화면 4. 결과
- 오늘부터 마지막 시험까지, 며칠에 걸친 시간대별 예측 각성도 그래프 (각 시험 시각 마커 표시)
- 추천 타임라인 (수면 / 공부 / 카페인 섭취 구간)
- 날짜별 구체적 추천 문구 (예: "월 23:30 취침 → 화 05:30 기상 → 화 06:00 카페인 100mg")
- 추천 스케줄이 안전 섭취 한도를 넘는 경우, 경고 문구 + 대안 표시
- "조건 조정하기" / "저장하고 마치기" 버튼

### 화면 5. 스케줄 조정
- 취침 / 기상 / 카페인 섭취 시각·용량을 슬라이더로 직접 조정
- 조정한 값이 안전 한도를 넘으면 실시간 경고
- "재계산하기" → 처리 중 화면으로 이동 → 결과 갱신

## 6. 계산 로직 상세

### 6.1 모델 개요
- **Process S (수면압)**: 깨어있는 시간이 길수록 지수적으로 증가하고, 수면 중에는 지수적으로 감소하는 항상성 수면 압력
- **Process C (일주기리듬)**: 하루 주기로 진동하는 생체시계 성분
- **각성도(Alertness)**: Process S와 Process C를 결합해 예측 (Borbély, 1982)
- **카페인 상호작용(UMP)**: 카페인이 아데노신 수용체를 경쟁적으로 억제해 Process S의 체감 수면압을 일시적으로 낮추는 효과를 반영, 원하는 시각의 각성도를 최대화하는 방향으로 수면·카페인 스케줄을 역산 (Vital-Lopez et al., 2024)

### 6.2 카페인 대사 파라미터 (민감도 3단계)

| 민감도 | 카페인 반감기(가정값) |
|---|---|
| 둔감 | 4시간 |
| 보통 | 5시간 |
| 예민 | 7시간 |

- 근거: Vital-Lopez et al. (2024)이 Monte Carlo 시뮬레이션에 사용한 카페인 반감기 범위(1.2~6.8시간, 141개 연구·4,700명 이상 참가자 메타분석 기반)와, CYP1A2 유전자에 따른 대사 속도 차이(빠른 대사 2~4시간, 느린 대사 6~8시간 이상) 문헌을 종합해 근사한 값이다.
- 실제 유전자 검사 없이 정확한 개인차를 알 수는 없으므로, 화면에 "논문이 검증한 범위 안에서 잡은 근사치"임을 명시한다.

### 6.3 카페인 안전 섭취 기준

- 건강한 성인: 일일 **400mg**까지 안전 (FDA)
- 단일 섭취 **1,200mg 이상**은 급성 중독 위험 (드물게 사망 사례 존재)
- 임신부·심장질환자 등: 위 기준보다 낮게, **200mg 이하** 권장
- 20세 미만: 성인 기준을 그대로 적용하기 어려워 더 보수적으로 **100mg/day 또는 체중 kg당 2.5mg** 중 낮은 값 적용 제안
- 참고용 음료별 카페인 함량 (예: 스타벅스 아이스 아메리카노 톨 사이즈 ≈ 150mg) — UI 제작 시 몇 가지 더 조사해 목록화 예정
- 오늘 이미 섭취한 카페인은 반감기에 따라 체내 잔존량을 계산해(1차 소실 동역학), 위 한도에서 차감한 뒤 "추가로 마셔도 되는 양"을 산출한다.
- 추천/조정된 스케줄의 총 카페인이 개인별 한도를 넘으면 경고 문구를 표시한다.

> 위 수치는 공신력 있는 공개 가이드라인을 참고한 근사치이며, 의학적 진단이나 처방을 대체하지 않는다. 화면 어딘가에 "참고용 정보이며 의료 조언이 아니다"라는 안내를 명시한다.

### 6.4 다중 시험 통합 최적화 알고리즘

- **시간 해상도**: 30분 단위 그리드
- **탐색 범위(horizon)**: 오늘부터 마지막 시험까지, 최대 약 7일
- **결정 변수**: 각 밤의 취침/기상 시각 후보, 카페인 섭취 시각·용량 후보
- **목적함수**: 입력된 모든 시험 시각의 예측 각성도 총합(또는 최솟값)을 최대화
- **제약 조건**: 사용자가 설정한 최소 수면시간, 개인별 카페인 안전 한도, 남은 공부 시간 확보
- **탐색 방법**: 완전 전수탐색은 경우의 수가 너무 커서 4주 일정 안에 구현이 어려우므로, 국소 탐색 기반 휴리스틱(예: simulated annealing류)으로 근사 최적해를 찾는다. 수학적으로 100% 전역 최적이라는 보장은 없지만, 실용적으로 좋은 스케줄을 짧은 시간 안에 찾는 것을 목표로 한다.
- "목표 각성 시각 = 시험 시작 시각 − 여유시간(기본 15~20분)"으로 계산한다. 이동시간은 입력받지 않고, 정보 입력 화면의 안내 문구를 통해 사용자가 스스로 감안해 조정하도록 한다(2026-07-15 결정).
- 기상 직후 일시적인 그로기(sleep inertia) 구간은 모델이 직접 표현하지 않으므로, 기상 후 일정 시간(기본 30분)은 별도 "적응 구간"으로 표시하고 이 구간에 카페인 섭취를 권장하는 방식으로 보완한다.

## 7. 4주 개발 일정

| 주차 | 내용 |
|---|---|
| 1주차 | 아이디어 구상 및 기획 |
| 2주차 | 계산 엔진 구현 (Two-Process Model + UMP + 안전 한도 로직) |
| 3주차 | 화면 개발 + 시각화 연동 |
| 4주차 | 추가 기능 구현(다중 시험 통합 최적화 확장, 여유 시 자연어 보조 입력) + 테스트·마무리 |

**설계 과정 요약**: 아이디어 검증(실현 가능성·차별성 확인) → 전공 지식 기반 설계(수면과학 논문을 계산 근거로) → 시나리오·기획서 완성(사용자 흐름 중심 화면 시각화) → 개발 4주.
