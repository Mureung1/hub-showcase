## 0. 전제 조건 (틀리면 알려줘)

- **가용 시간**: 매주 월~목 하루 3~4시간, 주말은 여유 있을 때 추가 진행
- **기준일**: 오늘 2026-07-10(금). 1주차(기획·디자인·프로토타입·화면 이식)는 사실상 완료
- **현재 상태 재확인 결과**: `client/`에 5개 화면(홈·정보입력·처리중·결과·조정)이 컴포넌트 단위로 이미 다 만들어져 있음. 다만 **전부 하드코딩된 mock 데이터**이고, 계산 엔진·백엔드·DB·localStorage 저장이 전혀 없음 → 그래서 원래 계획("3주차=화면 개발")보다 **2~3주차를 계산 엔진 + 연동에 더 몰아서** 재배치했다
- **카페인 근사 모델**: PPT 작업 때 제안한 대로, 논문에서 못 구한 정확한 Hill 방정식 대신 **공개된 표준 포화형 용량-반응 곡선(Hill/Michaelis-Menten 형태)으로 근사**하는 방향을 기본값으로 잡고 진행함 (2주차 Day 3에서 파라미터 확정)
