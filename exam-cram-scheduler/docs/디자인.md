# 디자인 문서

> [프로토타입](https://dodeho.github.io/hub/)(`docs/prototype/`)에 이미 구현된 디자인을 React 컴포넌트로 옮길 때 참고할 설계도. 프로토타입에 있는 내용만 정리했고, 프로토타입에 없는 상태(로딩/빈 상태/에러 등)는 다루지 않는다.

---

## 1. 디자인 컨셉

- 모바일 앱 UI (390×844 디바이스 프레임 기준)
- 갈색(브라운) 브랜드 컬러
- Toss 앱의 리스트 / 바텀시트 / 세그먼트 컨트롤 UI 패턴을 참고해 갈색 톤으로 재구성

## 5. 공통 컴포넌트 목록

React로 옮길 때 컴포넌트 단위 후보로 볼 수 있는 것들.

| 컴포넌트 | 관련 클래스 | 설명 |
|---|---|---|
| 카드 | `.card` | 섹션 내용을 감싸는 기본 컨테이너 |
| 리스트 로우 | `.row`, `.row-icon`(sleep/study/caffeine/exam 색상 variant), `.row-body`, `.row-title`, `.row-sub`, `.row-value`, `.row-chevron`, `.row.is-add` | 시험/음료/기록 항목을 나열. `is-add`는 "추가하기" 항목 스타일 |
| 세그먼트 컨트롤 | `.segmented` | 2~3개 선택지 중 하나를 고르는 탭형 버튼 (카페인 민감도, 성별) |
| 토글 스위치 | `.switch`, `.knob`, `.switch.on` | on/off 스위치 (임신·심장질환·불안 여부) |
| 입력 필드 | `.field`, `.field-label`, `input`/`select`/`textarea` | 텍스트/숫자/날짜/시간 입력, 포커스 시 브랜드색 테두리 |
| 슬라이더 | `.slider-row`, `.slider-head`, `input[type=range]`, `.range-bounds` | 범위값 조정 (최소 수면시간, 카페인 용량·시각) |
| 자연어 보조 입력 박스 | `.nl-box` | 점선 테두리의 스트레치 기능 영역 |
| 진행 표시 | `.progress-track`, `.progress-seg`(`is-done`/`is-current`) | 5단계 중 현재 위치 표시 바 |
| 체크리스트 아이템 | `.check-item`(`is-done`/`is-active`), `.check-dot` | 처리 중 화면의 단계별 진행 표시 |
| 경고 배너 | `.warning-banner` | 안전 섭취 한도 경고 문구 |
| 범례 | `.legend`, `.dot`(sleep/study/caffeine) | 차트 하단 색상 범례 |
| 버튼 | `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-sm` | 주요/보조/작은 버튼 |
| 아이콘 버튼 | `.icon-btn`(`ghost`/`filled`/`is-disabled`) | 뒤로가기 등 네비게이션 아이콘 버튼 |
| 바텀시트 | `.sheet-backdrop`, `.sheet`, `.sheet-handle`, `.sheet-title`, `.sheet-row` | 하단에서 올라오는 선택 패널 (시험 추가, 음료 선택) |
| 차트 영역 | `.chart-wrap` | SVG 각성도 그래프를 감싸는 컨테이너 |
| 뱃지 | `.badge-pill` | 클래스는 정의되어 있으나 현재 5개 화면에서는 미사용 |

## 6. 화면 공통 레이아웃 (앱 셸)

모든 화면이 공유하는 뼈대 구조 (위 → 아래 순서).

| 영역 | 클래스 | 설명 |
|---|---|---|
| 디바이스 프레임 | `.device` | 390×844 모바일 프레임. 목업 전용 장식(둥근 모서리, 그림자) |
| 상태바 | `.statusbar` | 시각 + 신호/와이파이/배터리 아이콘. 목업 전용 장식 |
| 네비게이션 바 | `.navbar`, `.nav-side`, `.nav-title` | 뒤로가기 아이콘 버튼 + 화면 타이틀. 홈 화면만 뒤로가기 없이 타이틀만 표시 |
| 진행 표시 | `.progress-track` | 5개 세그먼트로 현재 화면 위치 표시 |
| 본문 스크롤 영역 | `.screen` | 화면마다 달라지는 실제 콘텐츠가 들어가는 영역 |
| 하단 고정 액션바 | `.footer-cta` | 화면 하단에 고정된 버튼 1~2개 |
| 홈 인디케이터 | `.home-indicator-wrap`, `.home-indicator` | iOS 스타일 홈 바. 목업 전용 장식 |
| 화면 이동 탭 | `.screen-jump` | 5개 화면을 오가는 프로토타입 전용 네비게이션 (실제 서비스 화면 흐름과 무관) |

## 7. 반응형 처리

`@media (max-width: 480px)` 구간에서:
- `.stage`의 여백 제거
- `.stage-caption`, `.screen-jump` 숨김 (프로토타입 전용 UI라서)
- `.device`가 실제 화면 전체를 채우도록 전환 (`width: 100%`, `height: 100dvh`, 모서리·그림자 제거)

즉 데스크톱에서는 "목업 프레임 안에 든 앱 화면"으로 보이고, 실제 모바일 화면 폭에서는 프레임이 사라지고 화면 전체를 채우는 방식.

## 8. 화면별 컴포넌트 매핑

모든 화면 공통: 상태바, 네비게이션 바, 진행 표시, 홈 인디케이터, (프로토타입 전용) 화면 이동 탭

| # | 화면 | 이 화면에서만 쓰이는 구성 |
|---|---|---|
| 1 | 홈 | `eyebrow` + `display-num` + `subtext`, 섹션(`card` + `row`) 2개 — "최근 계산 기록"(chevron 있는 row), "이렇게 계산해요"(아이콘만 있는 row 3개), 하단 버튼 1개(`btn-primary`) |
| 2 | 정보 입력 | `headline` + `subtext`, `nl-box`(자연어 입력), 시험 목록 섹션(`row` ×3 + `row.is-add`), 수면 패턴(`field` 시간 입력 ×2), 카페인 섭취 섹션(`row` + `row.is-add`), 민감도 `segmented`, 나이/체중/성별/건강상태 카드(`field` 숫자 ×2 + `segmented` + `hairline` + `switch` ×3), 최소 수면시간 `slider-row` + `warning-banner`(이동시간·준비시간 안내), 하단 버튼 1개, 바텀시트 2개(시험 추가: `field`+`slider-row`+버튼 / 음료 선택: `sheet-row` ×4) |
| 3 | 처리 중 | 중앙 정렬 아이콘 원, `headline` + `subtext`, `check-item` 5개(완료 3 · 진행중 1 · 대기 1), 하단 버튼 1개(자동 이동 안내용) |
| 4 | 결과 | `eyebrow` + `display-num` + `subtext`, `chart-wrap`(SVG 각성도 그래프 + `legend`), `warning-banner`, 날짜별 추천 스케줄 섹션(`card` + `row` ×3), 하단 버튼 2개(`btn-secondary` + `btn-primary`) |
| 5 | 스케줄 조정 | `headline` + `subtext`, `card` 안에 `slider-row` 4개(취침/기상/카페인 용량/카페인 시각), `warning-banner`, 최소 수면시간 섹션(`card` + `row`), 하단 버튼 2개(`btn-secondary` + `btn-primary`) |

## 9. 동적 데이터 영역 (🔄)

프로토타입에서는 고정 텍스트/도형으로 보이지만, 실제 서비스에서는 계산 결과나 사용자 입력에 따라 값이 바뀌는 자리. 폰트·크기는 3번(타이포그래피) 표의 클래스를 그대로 따른다 — 이 표는 "어디가 동적인지"만 표시하고, 실제 문구는 개발 시점에 채운다.

| 화면 | 위치 (클래스) | 프로토타입 예시 문구 | 데이터 출처 |
|---|---|---|---|
| 홈 | `.display-num` | "D-2 · 생화학" | 저장된 기록 중 가장 가까운 시험의 D-day·과목명. **최초 접속(저장 기록 없음) 시 문구는 별도 결정 필요** |
| 홈 | `.subtext` (상단) | "금요일 10:00 시작 · 지금부터 계산하면..." | 가장 가까운 시험의 요일·시각 |
| 홈 | "최근 계산 기록" `.row-title` / `.row-sub` | "생화학 외 2개 시험" / "2026.07.06 저장 · 화 05:30 기상 스케줄" | localStorage에 저장된 최근 계산 결과 |
| 정보 입력 | 시험 일정 `.row-title` / `.row-sub` | "세포생물학" / "월 09:00 · 남은 공부 3시간" | 사용자가 입력한 시험 목록 |
| 정보 입력 | 시험 일정 `.meta` | "3개" | 등록된 시험 개수 |
| 정보 입력 | 카페인 섭취 `.row-title` / `.row-sub` / `.row-value` | "아이스 아메리카노" / "오늘 09:00" / "150mg" | 사용자가 입력한 오늘 섭취 카페인 |
| 정보 입력 | 카페인 섭취 `.meta` | "150mg" | 오늘 섭취 카페인 합계 |
| 정보 입력 | 음료 선택 시트 `.row-title` / `.row-value` | "아이스 아메리카노 (톨)" / "150mg" | DB 참고 데이터(`caffeine_reference`) 목록 |
| 결과 | `.eyebrow` | "오늘부터 금요일 시험까지" | 계산 대상 기간(오늘~마지막 시험일) |
| 결과 | `.display-num` | "오늘 23:30 취침" | 계산된 추천 스케줄의 첫 취침 시각 |
| 결과 | `.subtext` (상단) | "→ 월 05:30 기상 · 06:00 카페인 100mg 섭취 시..." | 계산된 추천 스케줄 요약 |
| 결과 | `.chart-wrap` 내 SVG (그래프 곡선·시험 마커·요일 라벨) | 각성도 곡선 예시 | 계산 엔진이 반환한 시간대별 예측 각성도 |
| 결과 | `.warning-banner` | "오늘 카페인 총 섭취량이... 92%..." | 안전 섭취 한도 대비 비율. 초과분 없으면 배너 자체가 표시 안 될 수 있음 |
| 결과 | 날짜별 추천 스케줄 `.row-title` / `.row-sub` | "월 05:30 기상" / "06:00 카페인 100mg → 09:00 세포생물학" | 계산된 날짜별 추천 스케줄 |
| 스케줄 조정 | `.headline` | "월요일 스케줄 조정" | 사용자가 선택한 조정 대상 날짜 |
