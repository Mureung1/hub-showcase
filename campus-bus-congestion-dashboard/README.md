# Campus Flow — 대학 버스 혼잡도

대학 캠퍼스 정류장별 버스 혼잡도를 비교하고, 시간대별 혼잡 패턴을 확인하는 대시보드입니다.

## 주요 기능

- 경북대·부산대·전남대·충남대·전북대 캠퍼스 전환
- 캠퍼스 지도에서 정류장 선택
- 시간 슬라이더 기반 정류장 혼잡도 비교
- 선택 정류장의 24시간 혼잡도 패턴
- 키보드와 터치 조작 지원

현재 데이터는 실제 버스 API가 아닌 시간대·수업 패턴을 반영한 예측 데이터입니다.

## 실행

```bash
npm install
npm run dev
```
