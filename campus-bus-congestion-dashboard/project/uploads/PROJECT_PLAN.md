# [기획서 v2] 대학가 버스 정류장 혼잡도 대시보드

## 1. 프로젝트 개요

### 프로젝트명
전국 대학가 캠퍼스별 버스 정류장 혼잡도 시각화 대시보드

### 기획 배경
대학가 버스 정류장은 **배차 시간표가 고정적**이라 "몇 분 후 도착"보다 **"이 시간대에 얼마나 붐빌지"**가 학생들에게 더 실용적인 정보다. 강의 시작/종료 시각, 점심시간 등 대학 특유의 생활 패턴이 정류장별 혼잡도에 뚜렷한 시간대 곡선을 만든다.

### 해결하고자 하는 문제
- 학생들은 정류장에 도착해서야 혼잡도를 체감함 — 미리 알면 시간을 조정하거나 다른 정류장을 선택할 수 있음
- 같은 캠퍼스라도 정문/북문 등 정류장별로 혼잡 패턴이 다름 — 비교 정보가 없음
- 기존 대중교통 앱은 실시간 도착시간은 알려줘도 "혼잡도"는 알려주지 않음

### 핵심 솔루션
캠퍼스 지도 위에 주요 정류장을 핀으로 표시하고, **시간대별 혼잡도 추정 모델**(강의시간표 + 유동인구 데이터 기반)을 시각화. 정류장 간 실시간 비교와 정류장별 24시간 흐름을 함께 제공.

---

## 2. 핵심 기능 명세

### ① 캠퍼스 선택 (Campus Selector)
- 상단 버튼/드롭다운으로 캠퍼스 전환
- **MVP**: 경북대학교 1곳
- **최종 목표**: 전국 지역거점 국립대 등 **10개 캠퍼스** 지원

### ② 캠퍼스 지도 + 정류장 핀 (Campus Map)
- API 기반 실시간 지도가 아닌 **일러스트 형태의 캠퍼스 외곽 지도** (SVG)
- 캠퍼스당 대표 정류장 **3~5개 고정 좌표**로 핀 표시
- 핀 클릭 시 해당 정류장이 강조되고, 아래 두 그래프가 함께 갱신됨

### ③ 정류장별 실시간 비교 막대그래프 (Live Comparison)
- 캠퍼스 내 모든 정류장의 **현재 혼잡도를 한 화면에서 비교**
- "지금 어디가 가장 붐비는지" 한눈에 파악
- 선택된 정류장은 막대에 강조 테두리로 표시

### ④ 정류장별 24시간 혼잡도 그래프 (Daily Pattern)
- 선택한 정류장의 **0시~23시 혼잡도 추정치**를 막대그래프로 표시
- 강의 시작(9시)/점심(12-1시)/강의 종료(5-6시) 시간대에 피크 반영
- 여유(초록)/보통(황색)/혼잡(빨강) 3단계 색상 구분
- "현재 O시 기준" 배지로 실제 시각과 연결

## 3. 혼잡도 추정 방법론

실시간 API 없이 아래 데이터를 조합해 시간대별 혼잡도를 추정한다.

| 데이터 소스 | 활용 방식 |
|---|---|
| 대학 강의 시간표 패턴 | 수업 시작/종료 시각 기준 피크 시간대 반영 |
| 소상공인시장진흥공단 유동인구 데이터 | 시간대별 유동인구로 보정 (기존 프로젝트 데이터 재활용) |
| 공공데이터포털 생활인구 데이터 (선택) | 행정동 단위 시간대별 인구밀도로 정확도 향상 |
| TAGO 버스 배차 정보 (확장 단계) | 배차 간격 기반 가중치 — 배차가 뜸한 시간대는 혼잡도 상향 |

**MVP는 강의시간표 기반 추정 모델만으로 구현**하고, 유동인구 데이터는 정확도 보정용으로 이후 단계에서 결합한다.

## 4. 기술 스택

```
[Frontend]      React 19 + TypeScript
[Visualization] Chart.js (혼잡도 막대/비교 그래프)
[Campus Map]    SVG 일러스트 (캠퍼스별 정적 좌표 데이터)
[Data Pipeline] Python (Pandas) — 유동인구/강의시간표 데이터 가공
```

## 5. 프로젝트 일정 (4주 로드맵)

### 1주차: 환경 설정 및 프로토타입
- React 19 + TypeScript 환경 구성
- 경북대 캠퍼스 SVG 지도 및 정류장 3곳 좌표 확정
- 혼잡도 추정 모델 초안 (강의시간표 기반 24시간 곡선)

### 2주차: 핵심 컴포넌트 구현
- 캠퍼스 지도 + 핀 클릭 인터랙션
- 정류장별 실시간 비교 막대그래프
- 정류장별 24시간 혼잡도 그래프
- 핀 선택 ↔ 그래프 연동 로직

### 3주차: 데이터 고도화
- 소상공인 유동인구 데이터 결합해 추정 정확도 향상
- 캠퍼스 선택 버튼 UI (2~3개 캠퍼스로 확장 테스트)
- 반응형 디자인 적용

### 4주차: 마무리 및 배포
- 전체 대시보드 통합 (지도 + 비교 + 상세 흐름)
- 사용성 테스트 및 버그 수정
- 최종 배포 준비

## 6. MVP 우선순위

### 필수 기능 (4주 안에)
1. **캠퍼스 지도 + 정류장 핀** (경북대 1곳, 정류장 3곳)
2. **정류장별 실시간 비교 막대그래프**
3. **정류장별 24시간 혼잡도 그래프** (강의시간표 기반 추정)

### 선택 기능 (시간 남으면)
- 유동인구 데이터 결합한 정확도 보정
- 캠퍼스 2~3곳으로 확장 (부산대, 전남대)
- 정류장 확대(3개 → 5개)

---

## 7. 향후 확장 계획 (4주 범위 밖)

### 캠퍼스 10곳 확장
- 전국 지역거점 국립대(부산대, 경북대, 전남대, 충남대, 전북대, 강원대, 충북대, 제주대, 경상국립대, 부경대 등) 순차 추가
- 캠퍼스별 SVG 지도 및 정류장 좌표 데이터베이스화
- 캠퍼스 선택 버튼 → 드롭다운/그리드 형태 UI로 전환

### 실시간 데이터 레이어 추가
- TAGO 실시간 버스 위치정보 API로 "예측 vs 실측" 비교 기능
- 시간이 지나며 실측 데이터가 누적되는 실시간 검증 그래프

### 영상 자동화 (Remotion)
- 대시보드 데이터를 유튜브 숏츠/릴스용 영상으로 자동 렌더링
- 개인 유튜브 프로젝트로 별도 진행 예정

## 8. 기대 효과
