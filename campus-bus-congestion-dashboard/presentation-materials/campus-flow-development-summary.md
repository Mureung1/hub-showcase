# Campus Flow 개발 내용 정리

## 1. 프로젝트 개요

Campus Flow는 전국 주요 거점국립대 학생들이 본인 학교의 주요 접근 정류장을 빠르게 확인할 수 있도록 만든 캠퍼스 정류장 지도 서비스입니다.

현재 구현본은 `service/national-live` 브랜치를 기준으로 하며, 실시간 혼잡도 API가 확정되기 전까지는 실제 캠퍼스 지도와 실제 정류장 위치를 중심으로 보여 줍니다. 화면 확인을 위해 샘플 혼잡도 모드는 제공하지만, 실제 서비스 모드에서는 혼잡도 값을 실제 데이터처럼 노출하지 않습니다.

## 2. 서비스 목표

- 전국 거점국립대의 캠퍼스 경계와 접근 정류장을 한 화면에서 탐색
- 학생들이 자기 학교를 선택하고 주요 정류장 위치를 빠르게 확인
- 향후 실시간 혼잡도 API 연동을 고려한 화면 구조와 데이터 구조 확보
- 데모용 가짜 예측 데이터와 실사용 지도 자산을 분리해 관리

## 3. 대상 대학

현재 서비스는 다음 10개 대학 본교를 대상으로 구성했습니다.

| 구분 | 대학 | 캠퍼스 |
| --- | --- | --- |
| 1 | 강원대학교 | 춘천캠퍼스 |
| 2 | 경북대학교 | 대구캠퍼스 |
| 3 | 경상국립대학교 | 진주 가좌캠퍼스 |
| 4 | 부산대학교 | 장전캠퍼스 |
| 5 | 서울대학교 | 관악캠퍼스 |
| 6 | 전남대학교 | 광주 용봉캠퍼스 |
| 7 | 전북대학교 | 전주캠퍼스 |
| 8 | 제주대학교 | 아라캠퍼스 |
| 9 | 충남대학교 | 대전캠퍼스 |
| 10 | 충북대학교 | 청주 개신캠퍼스 |

각 대학은 캠퍼스 경계 이미지 1개와 대표 접근 정류장 3개를 기준으로 구성했습니다.

## 4. 핵심 화면 구조

기존에는 하나의 대시보드 중심 화면에 가까웠지만, 현재는 다음과 같은 2단계 탐색형 구조로 개편했습니다.

1. 전국 대학 둘러보기
   - Campus Flow 헤더
   - 학생 친화적인 소개 문구
   - 10개 대학 카드 그리드
   - 대학별 대표색과 심볼 적용
   - 카드에는 가짜 혼잡도 수치를 표시하지 않음

2. 선택 대학 상세 화면
   - 선택한 대학의 테마 헤더
   - 실제 캠퍼스 경계 지도
   - 주요 정류장 3개 마커
   - 정류장 선택 영역
   - 샘플 비교 그래프와 24시간 패턴 그래프
   - `다른 대학 보기` 버튼으로 목록 복귀

## 5. 디자인 개선 내용

### 학생 친화적 문구 적용

첫 화면과 상세 화면의 문구를 기능 설명 중심에서 학생들이 바로 이해하기 쉬운 표현으로 수정했습니다.

주요 문구 예시는 다음과 같습니다.

- `우리 학교 가는 길, 정류장부터 한눈에`
- `내 학교를 선택해 주세요`
- `학교 카드를 누르면 주요 정류장 위치를 바로 볼 수 있어요`
- `캠퍼스 이동을 더 쉽고 가볍게`

### 대학 카드 디자인

대학 카드에는 기존 캠퍼스 지도 이미지 대신 대학 심볼을 사용하도록 변경했습니다.

- 학교별 대표색을 카드 배경과 버튼에 반영
- 로고와 워드마크가 섞여 있던 구성을 심볼 중심으로 통일
- 경북대, 경상국립대, 부산대 등 저해상도 로고를 교체
- 경북대, 부산대, 전북대 로고의 흰 배경 문제를 제거
- 강원대 로고가 원 밖으로 튀어나오지 않도록 별도 크기 조정

### 지도 영역 개선

상세 화면의 캠퍼스 맵 높이가 낮아 정류장명과 라벨이 잘리는 문제가 있어 지도 영역 높이를 늘렸습니다.

- 데스크톱 상세 지도 높이 확대
- 태블릿과 모바일에서도 지도, 정류장, 그래프 순서로 자연스럽게 배치
- SVG 안의 정류장 라벨이 바깥으로 밀려나지 않도록 안전 위치 처리

### 정류장 선택 인터랙션 변경

정류장 클릭 시 퍼져 나가는 원 애니메이션은 시선이 산만해 보여 제거했습니다.

현재는 선택한 정류장 주변에 고정된 반투명 강조 링만 표시됩니다. 이 방식은 클릭 결과를 명확히 보여 주면서도 지도 화면을 과하게 움직이지 않게 만듭니다.

## 6. 정류장 데이터 변경

부산대와 강원대는 실제 사용 맥락에 맞춰 정류장 구성을 조정했습니다.

### 부산대학교

현재 구성은 다음 순서입니다.

1. 부산대정문
2. 부산대역
3. 새벽벌도서관

`부산대학교후문`, `장전역`은 제거했습니다.

부산대역과 새벽벌도서관은 부산대학교 금정7번 순환버스 공식 안내를 근거로 반영했습니다. 일반 OSM 버스 정류장 노드가 아닌 지점도 공식 노선 검증 정보가 있는 경우 예외적으로 허용하도록 데이터 구조를 확장했습니다.

### 강원대학교

기존 `강원대학교동문`을 제거하고 `강원대중앙도서관` 정류장을 추가했습니다.

현재 구성은 다음 순서입니다.

1. 강원대정문
2. 강원대중앙도서관
3. 강원대후문

## 7. 데이터 및 자산 구조

주요 데이터와 자산은 다음 구조로 관리합니다.

- `src/data/live-campuses.json`
  - 대학 ID
  - 대학명
  - 캠퍼스 경계 이미지 경로
  - 정류장 ID, 명칭, 좌표
  - OSM 출처 정보

- `src/data/campus-presentation.ts`
  - 대학별 짧은 학교명
  - 지역명
  - 공식 대표색
  - 대표색 출처 URL
  - 대학 심볼 이미지 경로
  - 카드 표시용 로고 보정값

- `public/campuses/<대학-id>/`
  - 캠퍼스 경계 SVG
  - 대학별 `SOURCE.txt`
  - OSM 기반 출처와 라이선스 정보

- `public/campus-marks/`
  - 대학 카드에 사용하는 심볼 이미지
  - 심볼 출처 정리 파일

## 8. 혼잡도 표시 정책

현재는 실제 혼잡도 API가 연결되지 않은 상태입니다.

따라서 서비스는 두 가지 모드로 구분됩니다.

### 샘플 데이터 보기

화면 출력 형태를 확인하기 위한 샘플 혼잡도 값을 표시합니다.

- 정류장별 샘플 혼잡도 수치
- 시간 슬라이더
- 24시간 그래프
- 정류장 간 비교 막대

샘플 값은 별도 저장 데이터가 아니라 정류장 순서와 시간대 기준으로 자동 생성됩니다.

### 실제 지도만 보기

실제 서비스 준비 상태를 보여 주는 모드입니다.

- 실제 캠퍼스 경계 표시
- 실제 정류장 위치 표시
- 혼잡도 수치 숨김
- `실시간 혼잡도 데이터 연동 준비 중` 안내 표시

이 모드는 실제 API가 연결되기 전까지 공개 서비스의 기준 화면으로 사용할 수 있습니다.

## 9. 기술 구현 요약

현재 구현은 React 기반 화면 구조와 `vinext` 개발 환경을 사용합니다.

핵심 구현 방향은 다음과 같습니다.

- 앱 최상위에서 대학 목록 화면과 상세 화면 상태 관리
- 대학 카드를 선택하면 선택 대학 ID를 상세 대시보드에 전달
- 다른 대학을 다시 선택하면 첫 번째 정류장부터 시작
- `BusDataProvider` 인터페이스를 유지해 향후 실제 API 공급자로 교체 가능
- `ready`, `pending` 상태를 통해 데이터 준비 상태 구분
- 실제 API 호출은 향후 Worker에서만 처리하도록 설계 가능

## 10. 현재 검증 상태

최근 작업 기준으로 다음 검증을 진행했습니다.

- `npm.cmd run build` 성공
- 대학 카드 목록 표시 확인
- 대학별 로고와 대표색 적용 확인
- 상세 지도 높이 조정
- 정류장 라벨 잘림 방지
- 정류장 선택 강조 방식 변경
- 로컬 개발 서버 `http://localhost:5173/` 실행 확인

현재 수정 사항은 로컬 작업 기준이며, 사용자가 별도로 요청하기 전까지 새 배포는 진행하지 않는 방식으로 관리하고 있습니다.

## 11. 발표에서 강조할 수 있는 포인트

### 문제 인식

대학생들은 등하교나 캠퍼스 이동 시 정류장 위치와 접근 지점을 빠르게 확인해야 하지만, 학교별 정보가 흩어져 있어 한눈에 보기 어렵습니다.

### 해결 방향

Campus Flow는 전국 거점국립대의 캠퍼스 경계와 주요 정류장을 학교별 카드와 지도 화면으로 정리해, 학생들이 본인 학교의 이동 정보를 빠르게 확인하도록 돕습니다.

### 차별점

- 단순 지도 링크가 아니라 대학 선택형 서비스 구조
- 실제 OpenStreetMap 기반 캠퍼스 경계와 정류장 좌표 사용
- 대학별 대표색과 심볼을 활용한 친숙한 카드 UI
- 향후 실시간 혼잡도 API를 연결할 수 있는 공급자 구조
- 실제 데이터 미연결 상태에서는 혼잡도 값을 숨기는 안전한 정책

### 향후 확장

- 실제 혼잡도 제공처 확정
- 정류장 매핑 검증
- Worker 기반 API 연동
- 갱신 시각, 지연 상태, 오류 상태 표시
- 대학별 정류장 추가 검토
- 모바일 중심 사용성 개선

8. 혼잡도 정책
   - 샘플 모드와 실제 지도 모드 구분

    - Worker 연동
    - 정류장 매핑 검증
    - 비공개 배포 후 공개 전환

## 13. 현장 피드백 기반 정류장 개선 후보

실제 프로그램 데이터에 바로 반영하기 전, 사용자 피드백과 실제 통학 경험을 바탕으로 정류장 구성 개선 후보를 정리했습니다. 이 내용은 향후 정류장 데이터 교체와 발표 자료의 개선 방향 설명에 활용할 수 있습니다.

### 강원대학교

추천 정류장은 다음과 같습니다.

- 강원대백록관
- 강원대중앙도서관

실제 통학 경험 기준으로 이용 빈도가 높은 정류장으로 피드백되었습니다. 현재 반영된 `강원대중앙도서관`은 유지 후보이며, `강원대백록관`은 추가 검토 대상입니다.

### 전남대학교

최종 추천 정류장은 다음 후보를 중심으로 검토합니다.

- 전남대 또는 전남대사거리
- 전남대스포츠센터 또는 전남대공과대학
- 도로교통공단 대신파크

구역별 피드백은 다음과 같습니다.

| 구역 | 추천 후보 | 메모 |
| --- | --- | --- |
| 정문 | 전남대, 전남대사거리 | `전남대용봉탑`은 777번 마을버스만 출입해 대표 정류장으로는 부적합 |
| 후문 | 전남대스포츠센터, 전남대공과대학, 전남대후문 | 유동인구는 `전남대스포츠센터`가 가장 많다는 피드백 |
| 상대 | 도로교통공단 대신파크 | 다수 노선 경유로 유동인구와 대표성이 높음 |

`전남대동문`은 대표 접근 정류장으로 부적합하다는 피드백이 있어 제외 후보로 둡니다.

### 충남대학교

추천 정류장은 다음과 같습니다.

- 충남대산학연
- 충남대도서관

비추천 정류장은 다음과 같습니다.

- 충대농대종점

현재 정류장 구성과 비교해 학생 실사용률이 높은 지점 중심으로 재검토할 필요가 있습니다.

### 제주대학교

추천 정류장은 다음과 같습니다.

- 제주대병원

제주대병원은 캠퍼스와 물리적 거리가 있지만 환승 거점으로 활용도가 높다는 피드백이 있습니다.

비추천 정류장은 다음과 같습니다.

- 제대아파트

제대아파트는 교수 기숙사 인접 구역으로 학생 실사용률이 낮다는 피드백이 있어 제외 후보로 둡니다.

### 부산대학교

부산대는 `금정구7` 버스가 실질적인 메인 통학 버스 기능을 수행한다는 피드백이 있었습니다.

따라서 부산대 정류장 구성은 일반 시내버스 정류장뿐 아니라 금정구7 순환버스의 실제 이용 지점을 우선 근거로 삼는 방향이 타당합니다. 현재 반영된 `부산대역`, `새벽벌도서관`도 이 기준과 연결됩니다.

### 서울대학교

Top 3 추천 정류장은 다음과 같습니다.

1. 서울대입구역 3번출구
2. 서울대학교 정문
3. 기숙사삼거리 또는 관악사삼거리

동선별 피드백은 다음과 같습니다.

- 등교 시: 캠퍼스 외부의 `서울대입구역 3번출구` 활용도가 압도적으로 높음
- 등교 연계: 5511번, 5513번, 셔틀버스 탑승 지점으로 활용
- 하교 시: `서울대학교 정문`, `기숙사삼거리` 이용 비중이 높음

서울대는 캠퍼스 내부 정류장만 기준으로 잡기보다, 등교 출발 거점인 지하철역 접근 지점을 함께 고려해야 합니다.

### 전북대학교

정문 구역 추천 정류장은 다음과 같습니다.

- 전북은행본점

구정문 구역 추천 정류장은 다음과 같습니다.

- 전북대학교.소나무한의원
- 전북대학교.덕진성당

전북대는 정문과 구정문 생활권이 나뉘므로, 단순 거리보다 학생 이용 동선 기준으로 정류장을 다시 검토하는 것이 좋습니다.

### 구현 전 확인할 점

이 피드백을 실제 프로그램 데이터에 반영하기 전에는 다음 확인이 필요합니다.

- 각 정류장의 OSM node 또는 공식 좌표 확보
- 동일 명칭 정류장의 상행/하행 방향 구분
- 공식 버스 노선 또는 지자체 정류장 데이터 근거 확보
- 기존 정류장 3개 제한을 유지할지, 대학별 예외를 둘지 결정
- 샘플 모드와 실제 지도만 보기 모드에 동일하게 반영되는지 검증

## 14. 현재 남은 작업

- 공식 API 제공처와 사용 권한 확정
- 실제 혼잡도 데이터의 정류장 ID 매핑
- 대학별 정류장 구성 추가 검토
- 발표용 화면 캡처 정리
- 소셜 미리보기 이미지 문구 최신화
- 필요 시 로컬 변경 사항 커밋 정리
