# 정류장 이용 집중도 데이터 파이프라인

## 데이터 성격

이 서비스의 점수는 실시간 차량 내부 혼잡도가 아니다. 국토교통부의 AI 합성 교통카드 월별 승·하차 통계로 계산한 정류장 이용 집중도다. 화면에는 항상 기준 월을 함께 표시한다.

첫 기준 월은 API 응답이 확인된 `202509`다. 현재 캠퍼스 목록의 10개 지역 모두 정류장 목록과 월별 이용량 API 응답이 확인되었다. 개별 정류장은 이름과 지역이 명확하게 검증된 경우만 연결하며, 전국 정류장 목록에서 확인되지 않은 지점은 `unmapped`로 유지한다.

## 처리 순서

1. `data:map`이 `국토교통부_버스정류장` API에서 지역별 정류장 목록을 받는다.
2. 공백과 구두점을 제거한 정류장명이 하나만 정확히 일치할 때만 자동 매핑한다.
3. `data:refresh`가 매핑된 정류장의 월별 이용량을 조회한다. 검증된 방향 매핑은 A/C를 분리하고, 방향이 미확정된 대학은 동일 이름의 모든 승강장을 합산한다.
4. 같은 시간대의 모든 이용자 유형에서 버스 승차량과 하차량을 합산한다.
5. 캠퍼스 안의 모든 정류장·시간대 이용량 중 95백분위 값을 100점 기준으로 환산한다. 방향형 캠퍼스는 양방향 전체가 하나의 기준을 공유한다.
6. 생성 결과를 `src/data/generated-stop-usage.json`에 저장하고 웹사이트는 이 정적 JSON만 읽는다.

```text
이용량[h] = 승차량[h] + 하차량[h]
집중도[h] = min(100, round(이용량[h] / 캠퍼스 P95 × 100))
```

등급은 `0~39 여유`, `40~69 보통`, `70~100 혼잡`이다. 정상 응답에서 빠진 시간대는 0으로 채우지만, API 오류·매핑 실패·전체 0건은 점수로 만들지 않는다.

## 파일 역할

- `src/data/public-stop-mappings.json`: 앱 정류장 ID와 공공데이터 정류장 ID 연결
- `src/data/generated-stop-usage.json`: 기준 월, 원시 24시간 승·하차량, 집중도 점수
- `reports/stop-mapping-candidates.json`: 자동 매핑되지 않은 정류장의 검토 후보
- `.env.local`: 공공데이터 인증키와 선택 기준 월·일자

API 키는 브라우저 코드와 생성 JSON에 저장하지 않는다. 배포 전에는 대화에 노출된 기존 키를 재발급해 교체한다.
