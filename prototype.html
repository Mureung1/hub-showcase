미션

버튼을 클릭할 때마다 count가 1씩 증가하도록 구현합니다.

AI Tutor 공식 문서 기반
개념 설명

state는 컴포넌트가 기억해야 하는 값입니다. 이벤트 핸들러에서 setCount를 호출하면 React가 바뀐 값을 기준으로 화면을 다시 그립니다.

힌트

버튼의 onClick 안에서 현재 count를 읽고, 다음 값을 setCount에 전달해보세요.

참고 문서 State: A Component Memory Responding to Events
Counter.jsx 
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  )
}
